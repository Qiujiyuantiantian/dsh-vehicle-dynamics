# dsh-vehicle-dynamics

## 这是什么，不是什么

**这是**一套工程检查单：每条告诉你该算什么、需要哪些输入、方法在什么条件下失效、
以及到书里哪一页去核对。

**这不是**教材，也不是教材的替代品。本包**刻意不含**：

- 原书的理论讲解和推导过程；
- 论证某个方法为什么成立的推理；
- 任何图、表、页或版式；
- 任何让人只靠这个包就学会车辆动力学的东西。

每张卡给的是**页码**而不是解释——因为解释属于原书。**手上没有这本书，多数卡片用不了**：
它让你去查 p214，而不是告诉你 p214 说了什么。

想学车辆动力学，请买原书。本包回答的是"该算什么、算的时候会在哪里出错"，**它不教这门课**。
本包免费分发，不是商业产品。


一个 DSH 技能，把 Thomas D. Gillespie《车辆动力学基础》（清华大学出版社 2006 中译，英文原版 1992）**整本书**蒸馏成可执行的能力卡。

## 怎么用

只有一个入口 `vehicle-dynamics`。两级路由：

1. **先分章**：SKILL.md 的「第 0 步：先分章」表按问题指向章节
2. **再进卡**：每章有「意图索引」表（高频入口精选）+ `capability-index.md`（全量）+ `_chapter-routing.md`（编译生成的路由表）

每张卡是六段结构：R（原文引用）/ I（原理）/ A1（做法）/ A2（变体）/ E（边界）/ B（反例）。

## 它诚实的地方

这本书是扫描件 OCR 出来的，本身有大量排印错误和 OCR 损坏。这个技能**没有假装它们不存在**：

- SKILL.md 底部「已知硬伤速查」表**逐条列出 60+ 处原文错误**，写清"正确值是什么、错在哪、照抄会得到什么"。
- 公式残缺到无法恢复的（式 8-17、式 5-11、式 5-15/5-16），**明确标"不可用"**，只保留可确证的边界，绝不猜测补全。
- 图只有曲线没有数据表的（大量），**标"零读数"**，只给判据不给数值。
- 有些缺失是**全书缺**的（轮胎载荷敏感性的 a/b 系数、侧偏刚度的绝对值），标为"需另找数据源"。

举几个例子：

| 原文 | 问题 |
|---|---|
| 式(1-5) | 惯性项符号错（OCR 作 `−`，应为 `+`）；照抄得 W_r=1119 而非 1347 |
| 例题 2.2 | "1 挡 88 ft/s（60 mph）"是 OCR 错误，应为 38.7 ft/s（26.4 mph） |
| p241 | "侧倾率要尽可能的**高**"与式(9-6) 矛盾，应为**低** |
| 式(4-11) | 分母 OCR 损坏 → 横风敏感度只能定性，不可公式化 |
| p268 | 车辙判据前后半句一个说"系数"一个说"刚度"，单位却都一样 |
| 例题 4.5-1 | 油耗链不闭合：215 hp × 0.35 = 75.3 lb/h，书上印 82.6 |
| 式(5-11) | 整条缺失（正文引用了它，OCR 里没有） |
| 第 5 章 | "200% 阻尼"是 ζ=2.0（100% 才是临界），不是"阻尼翻倍" |

| 第 10 章 | "驻波"在本章一次都没出现 |

## 版权加固

初版卡片的 R 段是从原书逐字摘的引文。发布前做了机械审计，发现**逐字照录的规模远超预期**——引文常把原文两句拼在一起，简单检测会漏掉大半。

处理分三步：

1. **重新量**：改用"最长连续公共片段"而不是"整段是否包含"，量出 469 条引用行里有 202 条与原书连续相同 ≥15 字。
2. **全部重写**：按"不得与原文连续 10 字相同"的硬约束改成转述，保留页码与小节号，保留全部公式与数值。分 10 批、每批 20–42 条。
3. **复测**：458 条要点行对**全书 21.9 万字**（归一化后）逐条核验，结果：

| 检查 | 结果 |
|---|---|
| 与原文连续相同 ≥10 个**中文**字 | **0 条** |
| 仍带 `「」` 的引文行 | **0 条** |
| 更长的命中 | 仅 7 条英文技术词（如 `acceleration performance`、`vehicle dynamics`）——书本身就用这些词，属领域词汇而非表达 |

最后 3 处"引用原文以指出它错"的短句也改成了转述，使"少于 10 字"这句话可以被机械验证。

同时：`LICENSE` 加了 scope carve-out（MIT 只覆盖原创部分），`NOTICE` 重写为十章版、写明"不复制 10 字以上连续片段"、声明与原出版方无关联。

## 已知局限

- 全书**英制口径**（ft/s、lb、in、deg/g），不换算公制。
- **准静态、开环**为主；瞬态响应、极限工况、控制算法（ESC/EBD/ABS 标定）不在范围。
- 1970–90 年代技术背景：无 EPS、无线控转向、无现代低滚阻胎；风阻系数讨论以 0.30–0.35 为"现代水平"。
- 图内数据（大量）不可读，相关判据只能定性。
- 部分算例数字**不是同一辆车**（第 4 章分三仓），卡内已隔离。
- 第 10 章的正文只到 p280；p281 起是附录 A（SAE J670e 术语表）/B（振动公式）/C。
