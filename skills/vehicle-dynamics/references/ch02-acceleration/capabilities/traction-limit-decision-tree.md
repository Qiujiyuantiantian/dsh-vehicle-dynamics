# 附着极限最大驱动力的四分支决策树：锁止/不锁止 × 前驱/后驱

## R — 原文 (Reading)

> **原书要点**（p53 §2.3 式2-13）：发动机功率再充裕，加速也未必能全用上——轮胎与地面之间的摩擦系数会先把上限卡住。此时驱动力只能取 $F_x=\mu W$。
>
> **原书公式**（p58 注）：其中，$\mu$—最大摩擦系数；$W$——驱动轮上的重量。
>
> — 2.3 节，p53 式(2-13)（`source.md` L441–L446）；四分支见 p56 式(2-23)~(2-26)

## I — 方法论骨架 (Interpretation)

一句话：**附着极限不是"$\mu$ 乘车重"，而是"驱动轮当时实际载荷乘 $\mu$"；而载荷本身又被驱动力改变，于是 $F_x$ 出现在自己的分母里，必须解一个自洽方程。**

- 分子 $=\mu\times$**驱动轴静载**：后驱取 $Wb/L$（静态后轴载荷，例 2.4-1 已知 1850 lb），前驱取 $Wc/L$（静态前轴载荷，例 2.4-2 为 1950 lb）。这是"停车时轮胎能接住多少"。
- 分母第一项恒为 1，是基准；另外两项是两个通道的修正：
  - **第二项 $\mp(h/L)\mu$**：纵向载荷转移。后驱加速时后轴加载 → 分母变小 → $F$ 变大（例 2.4-1 分母 −12.1%）；前驱加速时前轴卸载 → 符号翻正 → $F$ 变小（例 2.4-2 +11.2%）。
  - **第三项 $+\big(2\mu r/(N_f t)\big)(K_{\phi f}/K_\phi)$**：驱动扭矩引起的横向载荷转移，纯损失（只会让分母变大）。后驱用 $K_{\phi f}/K_\phi$、前驱用 $K_{\phi r}/K_\phi$——选错一根轴的刚度会高估 6.4%（例 2.4-1：$K_{\phi r}$ 给出 1277 lb）。
- **两个"消项"条件是独立的两条**：差速器能锁止（载荷大的一侧也能用上附着力），或该驱动轴为独立悬架（反作用力作用在装于底盘的差速器上）→ 第三项消失。这两条不是同义词，也不能互推。
- 四分支表（后驱 $b$＝重心到前轴距离，前驱 $c$＝重心到后轴距离）：

| 构型 | 公式 | 分母第二项 | 第三项 |
|---|---|---|---|
| 后驱·整体轴·不锁止 | 式(2-23) | $-(h/L)\mu$ | $+(2\mu r/(N_f t))(K_{\phi f}/K_\phi)$ |
| 后驱·锁止 或 后独立悬架 | 式(2-24) | $-(h/L)\mu$ | 0 |
| 前驱·整体前轴·不锁止 | 式(2-25) | $+(h/L)\mu$ | $+(2\mu r/(N_f t))(K_{\phi r}/K_\phi)$ |
| 前驱·锁止整体前轴 或 独立前轴 | 式(2-26) | $+(h/L)\mu$ | 0 |

- 交付物：$F_{x\max}$ + 分母三项的逐项数值 + $a_x$（g）+ 分支声明 + 自洽检验。

## A1 — 应用示例 (Application Example)

### 示例 1：例 2.4-1 后驱不锁止（原书例题，数值全部复算）

- **类型与来源**：**原书例题**（2.4 第 1 题，p57）。$W=3950$ lb、后轴静载 1850 lb、$h=21$ in、$L=108$ in、$\mu=0.62$、$t=59$ in、$N_f=2.90$、$r=13.0$ in、$K_{\phi f}=1150$、$K_{\phi r}=280$（$K_\phi=1430$ ft·lb/deg）。
- **方法的使用**：①分子 $0.62\times1850=\mathbf{1147}$ lb；②第二项 $(21/108)\times0.62=\mathbf{0.120556}$；③第三项 $2\times0.62\times13/(2.90\times59)\times(1150/1430)=\mathbf{0.075767}$；④分母 $1-0.120556+0.075767=\mathbf{0.955211}$。
- **结论/结果（复算值）**：$F_{x\max}=1147/0.955211=\mathbf{1200.9}$ lb（原文 **1201**）；$a_x=1201/(3950/32.2)=\mathbf{9.79}$ ft/s² $=\mathbf{0.304}$ g。
- **自洽检验（本卡硬性要求）**：$W_r=1850+1201\times21/108=2083.5$ lb；$W_{rr}=2083.5/2-73.4=968.35$ lb（$W_y=1201\times13/(2.90\times59)\times0.804196=73.4$ lb）；$2\mu W_{rr}=2\times0.62\times968.35=\mathbf{1200.8}$ lb ✓。
- **必须显式标注的硬伤（I-02）**：每轮 $1201/2=\mathbf{600.5}$ lb。原文 OCR 残片"…= 1201 lb 548"里的"548"**不成立**（疑为分母 0.9548 的残片）；任何"每轮 548 lb"作废。

### 示例 2：例 2.4-2 前驱（原书例题，式(2-26)）

- **类型与来源**：**原书例题**（2.4 第 2 题，p58）。$W=3100$ lb、前轴静载 1950 lb、后轴 1150 lb、$h=19$ in、$L=105$ in、$\mu=0.62$、$t=60$ in、$N_f=3.70$、$r=12.59$ in、$K_{\phi f}=950$、$K_{\phi r}=620$。
- **方法的使用**：①分子 $0.62\times1950=\mathbf{1209}$ lb；②第二项 $(19/105)\times0.62=\mathbf{0.112190}$；③独立前轴 → 第三项 0；④分母 $1.112190$。
- **结论/结果（复算值）**：$F_{x\max}=\mathbf{1087.0}$ lb；$a_x=1087/3100=\mathbf{0.35065}$ g $=\mathbf{11.29}$ ft/s²（三值互闭 ✓）。
- **必须显式标注的硬伤（I-05）**：原文一处印 $1+\mathbf{0.0122}$、一处印 $1+0.1122$。正确值是 $(19/105)\times0.62=0.1122$；0.0122 是 OCR 错位。用 0.0122 会得 1194.4 lb（高 9.9%）。

### 示例 3：μ 从 0.62 提到 0.80（合成演练，书中未算）

- **类型与来源**：**合成演练**。例 2.4-1 其余参数不变，仅 $\mu=0.80$。
- **方法的使用**：分子 $0.8\times1850=1480$；第二项 0.155556；第三项 $2\times0.8\times13/171.1\times0.804196=0.097763$；分母 0.942207。
- **结论/预期输出**：$F_{x\max}=\mathbf{1570.8}$ lb；自洽 $2\times0.8\times981.7=\mathbf{1570.7}$ lb ✓（差 0.1 lb）。锁止分支 $=1480/(1-0.155556)=\mathbf{1752.6}$ lb，故**横向转移的绝对损失从 103 lb（μ=0.62）升到 182 lb（μ=0.80）**——损失变大不等于性能变差（N5 的误读）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 问"这台后驱车起步最大能有多大驱动力/几 g"。
2. 改装了差速器（开放式 → LSD/锁止），问"实际能提升多少"。
3. 问"为什么后驱比前驱起步强""前驱加了配重为什么没变强"。
4. 有人用 $\mu\times$整车重量得出 2449 lb，需要当场纠正。
5. 算 0–60 时发现低速段永远打滑，要定位是载荷转移还是横向转移在拖后腿。

### 语言信号（中英双写）

- 「附着极限」「最大驱动力」「打滑」「几 g 起步」「差速器锁不锁」
- 「载荷转移」「后轴加载」「横向转移损失」「LSD 有用吗」
- 「traction limit」「mu times weight」「weight transfer」「limited slip」「launch grip」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `longitudinal-load-transfer`：本卡只把该项当"分母第二项"，其 $W_r$ 的完整算法在那边。
- 与 `lateral-load-transfer-from-drive-torque`：本卡的第三项是它的闭式；$W_y$ 的推导与 $N_{ft}$ 读法在那边。
- 与 `open-differential-traction-limit`：那张卡把不锁止分支展开成"单轮载荷 + 每轮力"，并给自洽路径；本卡给四分支选择与总结果。
- 与 `locked-or-independent-drive-axle`：那张卡专讲"为什么第三项会消失"与两条条件的区别。
- 与 `front-drive-traction-limit`：那张卡专讲前驱两分支（符号、$Wc/L$、$K_{\phi r}$）。

## E — 可执行步骤 (Execution)

**必需输入**：驱动形式（前/后/四驱）、差速器是否锁止、驱动轴整体式/独立悬架、$\mu$、$W$、驱动轴静载（$Wb/L$ 或 $Wc/L$）、$h$、$L$；若走不锁止分支还须 $t$、$N_f$、$r$、$K_{\phi f}$、$K_{\phi r}$。

**交付物与完成标准**：$F_{x\max}$（lb）+ 分母三项逐项数值 + $a_x$（ft/s² 与 g）+ 分支声明 + 自洽检验结论。

1. **定构型，选公式**
   - 完成标准：写出"驱动形式／锁止／轴型式"三格，映射到式(2-23)/(2-24)/(2-25)/(2-26) 之一。
   - 判停：任一格不明 → **停**，先问；锁止与不锁止差 104 lb（8.7%），前驱符号错差 25%。
2. **算分子**
   - 完成标准：$\mu\times$驱动轴静载；写明"是驱动轴静载，不是整车重量"（用整车重量会得 2449 lb，真值 1201）。
3. **算分母三项**
   - 完成标准：第二项 $\mp(h/L)\mu$（**后驱负、前驱正**）；第三项 $\big(2\mu r/(N_f t)\big)(K_{\phi f}/K_\phi)$（**后驱用 $K_{\phi f}$、前驱用 $K_{\phi r}$**）；三项各自列出数值。
   - 判停：若 $t$ 或 $N_f$ 缺失 → 只能走锁止/独立悬架分支；不得凭"大约"补 $t$。
4. **解 $F_{x\max}$**
   - 完成标准：$F=\text{分子}/\text{分母}$；同时给出"若第三项为 0 会是多少"（即锁止分支），两者的差就是横向转移损失。
5. **自洽检验**
   - 完成标准：不锁止 → $F=2\mu W_{rr}$（$W_{rr}=W_r/2-W_y$）；锁止 → $F=\mu W_r$（$W_r=$ 静载 $+Fh/L$）。两条都必须回代闭合（±2 lb）。
6. **交付**
   - 完成标准：一句话"后驱 3950 lb、$\mu=0.62$、不锁止：$F_{x\max}=1201$ lb（分母 0.9552 = 1−0.1206+0.0758），$a_x=0.304$ g；锁止为 1305 lb，横向转移损失 104 lb"。

**计算约定（原书未规定，本卡设定）**：$F$ 与 $W$ 保留 1 lb；分母保留 6 位；$g$ 数保留 4 位；$a_x$ 保留 2 位。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **把分母里的量读成总传动比。** **本卡最关键的一处符号陷阱**：分母第三项的 $N_{ft}$ 是 $N_f\times t$（主减速比 × 轮距，例 2.4-1 为 $2.90\times59=171.1$），**不是** $N_{tf}$（总传动比）。误用总传动比 $N_{tf}=12.50$（仍乘轮距 59）→ 第三项 0.0176、分母 0.8970、$F=\mathbf{1279}$ lb（+6.5%）。判定证据：只有 $N_f t$ 能复现原文的 0.0758。**附着限制全段不出现 $N_{tf}$。**
- **用整车重量代 $\mu W$。** 式(2-13) 的 $W$ 是"驱动轮上的重量"；$0.62\times3950=2449$ lb，真值 1201（2.04 倍）。
- **把"独立悬架"当"差速器锁止"。** 原文给的是两个**独立**的充分条件（锁止，或该驱动轴为独立悬架），第三项都消失，但机制不同；且**锁止后 $W_y$ 仍然存在**，消失的只是它造成的驱动力损失。不许写"独立悬架没有横向载荷转移"。
- **混用式(2-25) 与式(2-26)。** 前者是整体前轴**不锁止**（第三项还在），后者是锁止或独立前轴（第三项消去）；例 2.4-2 用的是后者（1087 lb），若误用前者得 1060.6 lb（低 2.5%）。
- **引用"每轮 548 lb"。** I-02：每轮 600.5 lb（$1201/2$），548 是 OCR 残片。
- **把第三项的侧倾刚度选错。** 后驱用 $K_{\phi f}/K_\phi$；用 $K_{\phi r}/K_\phi$ 得 1277 lb（+6.4%，ce19）。
- **给 $\mu$ 的"随载荷/滑移率"修正。** 本章 $\mu$ 取单值；载荷敏感性属第 3 章，本卡不建项。
- **在四驱车上直接套两驱分支。** 四驱的驱动轴载荷与前后分配都不同，原文未给公式 → **停**。

### 作者在书中警告的失败模式

- ce16：以为横向载荷转移"只是左减右加"——它是纯损失，损失量 104 lb（p58）。
- ce17：独立悬架套整体轴公式（本卡的四分支表就是防这一条）。
- ce19：横向转移公式里选错一根轴的侧倾刚度（属推断，但数值可复算：1277 vs 1201）。
- ce18：用前轴静态载荷比例外推前驱性能（p58 注）。

### 作者的盲点 / 时代局限

- $\mu$ 取单值、与载荷/滑移率无关；实际轮胎的 $\mu$ 随载荷上升而下降（第 3 章），故高载荷侧的真实极限会低于本卡估值。
- 只建"锁止/不锁止"两个离散状态，**没有**锁止率连续值、LSD 预紧力矩、轴扭转刚度、轮胎垂直刚度耦合。
- 未处理 $\mu$-split（左右不同附着）、四驱扭矩分配、扭矩矢量。
- 1992 年视角：现代电控差速器与 ESC 的轮端制动力干预会改变实际极限。

### 容易混淆的邻近方法论

- **$\mu W$（式 2-13，粗口径）vs 四分支闭式（式 2-23~2-26）**：前者只在"载荷不变"的近似下成立，后者把载荷随 $F$ 变化解进去了。
- **$N_{ft}=N_f\cdot t$ vs $N_{tf}=N_tN_f$**：一字之差，差 6.5%。
- **"横向转移"（左右）vs "纵向转移"（前后）**：前者进第三项（纯损失），后者进第二项（后驱是收益）。
