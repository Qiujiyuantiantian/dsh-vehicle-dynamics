# 传动比的等比级数校验：级比、公比 q、逐挡偏差

## R — 原文 (Reading)

> **原书要点**（p50–51 §2.1.3）：每一挡的传动比数值，多半是围着某个指定工况挑出来的；不过做完优化之后会发现，相邻挡的比值往往拉得很平均，接近一个恒定值——也就是近似等比级数。
>
> **原书要点**（p50–51 §2.1.3 图2.8）：图 2.8 里画的是市面上某款在产轿车的转速—车速关系；走势虽大致按几何级数排布，细看仍有几处出入。
>
> — 2.1.3 节，p50–51（`source.md` L306–L311）

## I — 方法论骨架 (Interpretation)

一句话：**"配得匀不匀"可以量化成三件事——相邻挡级比是否恒定、公比 q 是多少、每一挡偏离理想序列多少。**

- 等比级数的定义：$N_{tf,1}/N_{tf,2}=N_{tf,2}/N_{tf,3}=\dots=\text{常数}$。等比的意义是"每次升挡，转速落差相同"，也就是每次换挡后发动机回到曲线上同一个相对位置。
- 公比由首末两级唯一确定：$q=(N_{tf,1}/N_{tf,n})^{1/(n-1)}$；理想序列为 $N_{tf,1}/q^{i}$。
- 逐挡偏差 $=N_{tf,i}/(N_{tf,1}/q^{i-1})-1$。偏差的正负告诉你"这一挡偏疏还是偏密"：负值＝该挡比理想更小（级距偏大）。
- 它是**近似模型**，不是设计规范：原文说"通常接近于""略有出入"，实车（图 2.8）也印证了偏差存在。把它当"实际齿比应该等于理想序列"就错了（ce15）。
- 该模型是单一目标（换挡落差恒定）下的最优；一旦把燃油经济性、排放、NVH 拉进来，偏差是**故意的**。
- 交付物：级比表 + 公比 + 理想序列 + 逐挡偏差（%）+ 一句"这是近似校验，不是合格判定"。

## A1 — 应用示例 (Application Example)

### 示例 1：例 2.2 五挡序列的等比校验（原书数据 + 复算，书中未做此校验）

- **类型与来源**：**引用数据 + 复算**。齿比 4.28/2.79/1.83/1.36/1.00 出自例 2.2 数据表（p52）；"级比/公比/偏差"是本研究补算，原文未做。
- **输入**：$n=5$、$N_{tf}$ 序列如上（$N_f$ 对级比无影响，可只用 $N_t$）。
- **方法的使用**：①级比 $=N_i/N_{i+1}$；②$q=(4.28/1.00)^{1/4}$；③理想序列 $4.28/q^{i}$；④偏差。
- **结论/结果（复算值）**：级比 **1.534 / 1.525 / 1.346 / 1.360**；公比 $q=\mathbf{1.4386}$；理想序列 **4.28 / 2.975 / 2.068 / 1.438 / 1.000**；偏差 **−6.2% / −11.5% / −5.4% / +0.1%**。
- **读法**：前两挡级距**偏大**（该挡齿比小于理想值），后两挡**偏密**；即该变速器把 1–2 挡拉开、3–5 挡挤密——与"1 挡起步、2/3 挡超车、最高挡巡航"的用途分配一致。

### 示例 2：实车样本（引用数据，只引两个读数）

- **类型与来源**：**引用数据**。图 2.8 给出 1989 Taurus SHO 的 1 挡 12.01、4 挡 3.81。图上**无数据表**（I-10），中间两挡不可读，故只用这两个端点。
- **复算**：$n=4$ → $q=(12.01/3.81)^{1/3}=\mathbf{1.466}$；若严格等比，中间两挡应为 8.19 与 5.59。
- **必须标注的推断（C-05）**：12.01/3.81 究竟是"变速器速比"还是"含主减速器的总速比"，原文图 2.8 未明说；本卡按总速比读，属**推断**，不得当作原文事实引用。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 拿到一串齿比，问"这变速箱配得匀不匀/级距合理吗"。
2. 自定义齿比（赛车、改装、电机减速器）时要生成一列候选。
3. 问"为什么 1–2 挡落差大、4–5 挡几乎一样"。
4. 比较两台车的齿比序列（一台偏等比、一台偏密）。
5. 判断某资料给出的"等比级数"是实测齿比还是拟合值。

### 语言信号（中英双写）

- 「齿比合理吗」「级距」「换挡落差」「等比级数」「公比」
- 「为什么二挡到三挡落差小」「齿比怎么排」
- 「gear ratio spacing」「geometric progression」「step ratio」「progressive ratio」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `shift-point-at-force-intersection`：本卡只校验"齿比序列本身匀不匀"；换挡点由驱动力交点决定，与等比无直接关系（例 2.2 车恰好在表内没有交点）。
- 与 `tractive-effort-map-and-envelope`：齿比决定曲线族的横向间距；本卡只给间距的统计量。
- 与 `power-torque-rpm-conversion`：换挡后的转速落差最终要落到扭矩上，那张卡给扭矩值。
- 与 `torque-converter-start-boost`：自动变速器的等效级比会因变矩器滑差而改变，本卡只适用于机械啮合挡位。

## E — 可执行步骤 (Execution)

**必需输入**：$n$ 个挡位的传动比序列（**必须声明是变速器速比 $N_t$ 还是总速比 $N_{tf}=N_tN_f$**——混用会让级比全部偏移）。

**交付物与完成标准**：级比表（$n-1$ 行）+ 公比 + 理想序列 + 逐挡偏差（%）+ 近似性声明。

1. **统一速比口径**
   - 完成标准：写出"用 $N_t$（变速器）"或"用 $N_{tf}$（含主减速器）"；同一表内不得混。
2. **算级比**
   - 完成标准：逐对相除，$n-1$ 个值；标出最大与最小级比。
3. **算公比与理想序列**
   - 完成标准：$q=(N_1/N_n)^{1/(n-1)}$；理想序列逐项写出，末项应回到 $N_n$（±0.5%）。
4. **算偏差**
   - 完成标准：偏差表；给出"哪几挡偏疏、哪几挡偏密"的一句话。
   - 判停：若首末速比相同或 $n<3$ → **停**，等比校验无意义。
5. **交付**
   - 完成标准：一句话"公比 1.4386，理想序列 4.28/2.98/2.07/1.44/1.00；实际前两挡偏疏（−6.2%/−11.5%）、后两挡偏密（−5.4%/+0.1%）"。

**计算约定（原书未规定，本卡设定）**：级比保留 3 位小数；公比保留 4 位；偏差保留 1 位小数（%）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **把等比级数当实际齿比。** ce15：原文只说"通常接近于""略有出入"；偏差是设计选择，不是误差。把理想序列当"应该如此"会得出"这台变速箱设计错了"的荒谬结论。
- **用它判定齿比"合格/不合格"。** 原书没有验收阈值；本卡只给偏差表，不给通过线。
- **引用"末挡常被拉长以压巡航转速"。** C-03：该说法被阶段 1.5 剔除——例 2.2 的末两级级比 1.346/1.360 **小于**公比 1.4386，末段反而更密。
- **把 $\xi$ 当已知符号。** E-4：图 2.7 的 $\xi_1/\xi_2=\xi_2/\xi_3=$常数 中 $\xi$ 在正文**从未定义**；应读作"相邻挡总传动比之比"。
- **把 Taurus 的 12.01/3.81 当变速器速比。** C-05：是否含主减速器属推断。
- **对 CVT/电动单速箱套用。** 无"挡"即无级比。

### 作者在书中警告的失败模式

- ce15：把等比级数当实际传动比（p50–51，"虽然接近几何级数，但略有出入"）。
- ce09：把换挡点取在最大转速/最大扭矩点——与本卡的"级距"是两件事，不要互相推导。

### 作者的盲点 / 时代局限

- 图 2.8 只有两个可读点，中间挡不可读（I-10），所以实车"偏离多少"无法从本章数据量化。
- 1992 年四/五速视角；现代 8–10 挡的级比分布更接近等比，但也更受排放循环约束。
- 未讨论"级比 × 扭矩比"才是换挡后力是否连续的判据（那在 `shift-point-at-force-intersection`）。

### 容易混淆的邻近方法论

- **级比（相邻挡之比）vs 总速比（$N_tN_f$）vs 公比（全序列的几何平均比）**：三者层次不同。
- **等比（几何级数）vs 等差**：前者保证转速落差恒定，后者保证车速增量恒定；本章只用前者。
- **"接近等比"vs"最优"**：前者是现象描述，后者要指定目标函数。
