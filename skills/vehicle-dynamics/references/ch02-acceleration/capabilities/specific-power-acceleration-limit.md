# 比功率粗估加速度上限：$a_x=550\,(g/V)(hp/W)$

## R — 原文 (Reading)

> **原书要点**（p44–45 §2.1.1 式2-4）：把发动机功率除以整车自重，得到比功率，用它就能先粗估一辆车加速行不行；车速不高时把各项阻力全部略去，这个比值可以直接当加速度上限用。
>
> **原书要点**（p44–45 §2.1.1 式2-4）：式子的分母里带着速度，所以车速越高，能拿到的加速度上限就被压得越低，这是必然的。
>
> — 2.1.1 节，p44–45，式(2-4)（`source.md` L60–L61、L87）

## I — 方法论骨架 (Interpretation)

一句话：**把所有阻力与惯量都扔掉之后，加速度只剩"比功率 ÷ 车速"这一项，所以它是一条与车速成反比的上限线，不是一个预测值。**

- 式子来自 $M a_x=F_x$ 与"驱动功率 = 驱动力 × 车速"两条恒等式的联立：$a_x=550\,(g/V)(hp/W)$。没有拟合参数，全是定义。
- 被扔掉的项很清楚：滚动阻力 $R_x$、空气阻力 $D_A$（∝$V^2$，是唯一随速度平方增长的项）、挂车牵引力、坡度 $W\sin\theta$、传动效率、全部转动惯量。误差在高速端爆炸。
- 分母只有一个 $V$，所以 $a\cdot V$ 在给定 $hp/W$ 下是常数——这是本卡最好用的自检。
- 三个限定语是**合同条款**，不是修辞："初步估计""上限""中低车速"。去掉任一条，就把量级工具变成了承诺。
- 它真正的用途是公路几何设计（长坡坡度、交叉口视距、匝道加速段），不是车型横评。
- 交付物：一条"$a$–$V$"上限关系（两三个点即可）+ 比功率口径（hp/lb 还是 lb/hp）+ 限定语。

## A1 — 应用示例 (Application Example)

### 示例 1：图 2.2 的两条标注线（引用数据 + 复算）

- **类型与来源**：**引用数据**。图 2.2 只有曲线、无数据表（I-10），故只引用图上标注的两个比功率值：轿车 **40 lb/hp**、典型重型货车 **250 lb/hp**；加速度值由式(2-4) 复算，**不读曲线**。
- **输入**：$hp/W=1/40=0.025$ 与 $1/250=0.004$；$V=30$ mph（44.0 ft/s）与 60 mph（88.0 ft/s）。
- **方法的使用**：$a=550\times32.2/V\times(hp/W)=17710/V\times(hp/W)$。
- **结论/结果（复算值）**：轿车 30 mph **10.06 ft/s²（0.312 g）**、60 mph **5.03 ft/s²（0.156 g）**（恰好减半）；货车 **1.61 / 0.81 ft/s²（0.050 / 0.025 g）**。
- **注意**：图 2.2 上"10% 轿车"的含义 OCR 不可判（I-10），本卡不解释、不作数。

### 示例 2：比功率很小时也会越界（合成演练，非书中事实）

- **类型与来源**：**合成演练**。自造车 N2（$W=3000$ lb、$P_{\max}=250$ hp → **12 lb/hp**），与书中两道例题车型都不同。
- **输入**：$V=30$ mph 与 60 mph；$\mu=0.80$（干沥青粗值）。
- **方法的使用**：$a=17710/V/12$；再与附着上限 $a_\mu=\mu g=25.76$ ft/s² 比。
- **结论/预期输出**：30 mph **33.54 ft/s²（1.04 g）** > 25.76 → **该值在物理上不可达，必须被附着封顶**；60 mph **16.77 ft/s²（0.521 g）** < 25.76，尚在界内。→ 演练的用途正是演示"上限也可能越界"，此时应交 `acceleration-limit-triage`。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 只有功率和车重，要一个"能跑多快/多猛"的数量级，30 秒内交付。
2. 公路设计：匝道加速段长度、长坡上的速度损失、交叉口视距。
3. 对比两台比功率差 3 倍以上的车（轿车 vs 重卡），要一个共同标尺。
4. 需要一条"任何配置都不可逾越"的上限，用于给仿真结果做护栏。
5. 用户把 hp/lb 与 lb/hp 写反了，要现场判出量级异常。

### 语言信号（中英双写）

- 「比功率多少」「这车大概几个 g」「粗估加速能力」「上坡能保持多少速度」
- 「匝道加速段」「长坡速度损失」「功率重量比」
- 「power-to-weight ratio」「specific power」「acceleration upper bound」「gradeability estimate」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `acceleration-limit-triage`：本卡只给功率支的**上限**；与附着支比、取小、解交点在那边。
- 与 `acceleration-precision-ladder`：本卡是第 1 档的公式本体；那张卡负责"何时用它、何时必须升档"。
- 与 `longitudinal-force-balance`：那张卡把滚阻/风阻/坡度/惯量逐项加回来，是本卡的"完整版"。
- 与 `tractive-effort-map-and-envelope`：等功率线的 $F=550\eta P/V$ 与本卡同源，但那张卡画的是力，本卡给的是加速度。

## E — 可执行步骤 (Execution)

**必需输入**：$hp$（稳态最大功率，英制马力）、$W$（lb）、$V$（ft/s 或 mph，须注明）。**比功率方向（hp/lb 还是 lb/hp）必须显式写出**，这是本卡唯一的输入陷阱。

**交付物与完成标准**：2–3 个车速点的 $a$（ft/s² 与 g）+ 比功率口径 + "上限/忽略项"声明 + 一条自检。

1. **统一比功率口径**
   - 完成标准：写成 $hp/W=0.025$（对应 40 lb/hp）这种双向对照；抄反必须当场判出 1600 倍异常。
2. **换算车速**
   - 完成标准：mph×1.467=ft/s；写出对照行。
3. **算上限**
   - 完成标准：$a=550\,g\,hp/(WV)$；给出至少两个车速点；写出 $a\cdot V$ 的常数。
4. **越界检查（判停点）**
   - 判据：$a>\mu g$ 或 $V<15$ mph。
   - 动作：标"本值被附着封顶，实际 $a_x\le\mu g$"，并转 `acceleration-limit-triage`；**不得**把越界值作为结论交付。
5. **交付**
   - 完成标准：一句话"40 lb/hp 轿车在 30 mph 的上限为 0.31 g、60 mph 为 0.16 g；本值为上界，未计滚阻、风阻、惯量与效率"。

**计算约定（原书未规定，本卡设定）**：$g=32.2$ ft/s²；$a$ 保留 2 位小数；g 数 3 位；1 mph=1.467 ft/s。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **当预测值用。** ce02：这是本章最容易被误用的一条。去掉"上限"二字、拿它排车型优劣、写进报告，都是过度承诺。
- **算 0–60 mph 时间。** 0–60 横跨低速附着段与高速风阻段，两端都超出式(2-4) 的定义域；必须走第 3 档（`acceleration-precision-ladder`）。
- **70 mph 以上仍当量级可信。** 风阻 ∝$V^2$ 被整体丢弃，高速端误差最大；至少在结论里写明"高速端偏乐观"。
- **把 hp/lb 与 lb/hp 混用。** 40 lb/hp $=0.025$ hp/lb；抄反错 1600 倍（`chapter-units-and-conventions`）。
- **读图 2.2 的曲线取中间值。** I-10：图无数据表，只可引用标注的 40 / 250 lb/hp 两个点。
- **用"两上限差 10% 内即敏感区"之类阈值。** C-02：原书无据，本 Bundle 不采用。

### 作者在书中警告的失败模式

- ce02：比功率直算当实测预测（p44–45，三个限定语）。
- ce01：只算这一支、不做附着校验（低速时式(2-4) 必然越界）。

### 作者的盲点 / 时代局限

- 只说"中低车速"，**没给**"中低"的数值边界；本卡的 15 mph/越界判据是工程约定，不是原文规定。
- 未讨论变速器、驱动形式、轮胎对同一比功率下加速度的影响（那正是第 2、3 档要补的）。
- 全章英制；现代电机的恒扭矩段会让"$a\propto1/V$"在低速端完全不成立。

### 容易混淆的邻近方法论

- **比功率（hp/W）vs 质量功率比（W/hp）**：互为倒数，前者越大越快，后者越大越慢。
- **上限 vs 实际**：本卡给"物理上最多"，不给"这一脚油门给出多少"。
- **$a$–$V$ 双曲线 vs 等功率线**：前者是加速度坐标、后者是力坐标，同一件事的两种投影。
