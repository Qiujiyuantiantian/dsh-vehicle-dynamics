# 决策规则速查 — 《车辆动力学基础》第 2 章 加速性能

| 能力 | 一句话规则 |
|---|---|
| 加速极限分诊：先判"功率限制"还是"附着限制"，再解交叉车速 | 两条上限取小不取大：$a_p=550g\,hp/(WV)$ 与 $a_\mu=F_{x\max}/M$，交点 $V^*=550g\,hp/(Wa_\mu)$；分诊前必须声明驱动形式/锁止状态。 |
| 加速计算的三级精度阶梯：比功率粗估 → 单点稳态 → 逐速度迭代 | 数据只够 hp/W → 第 1 档（只能报上限）；有扭矩表+齿比+惯量 → 第 2 档单点；要 0–60 或曲线 → 第 3 档逐点 $\Delta t=\Delta V/a_x$；每份结果必须带"第几档、忽略了什么"。 |
| 功率-扭矩-转速换算：$hp=T\omega_e/550=T\cdot rpm/5252$，最大功率点不在最大扭矩点 | $hp=T\cdot rpm/5252=T\omega_e/550$；两个常数差 9.55 倍；最大功率点在最大扭矩点右侧（168.41 vs 180.96 hp）；反算 $T=hp\times5252/rpm$。 |
| 比功率粗估加速度上限：$a_x=550\,(g/V)(hp/W)$ | $a_x=550\,g\,hp/(WV)$，只给上界；$a\cdot V$ 恒定；越界（$a>\mu g$ 或 $V<15$ mph）时转分诊，不许把它当预测值。 |
| 由发动机扭矩逐级折算到轮上驱动力：$F_x=T_eN_{tf}\eta_{tf}/r-\{I_{ef}\}a_x/r^2$ | 稳态项 $T_eN_{tf}\eta_{tf}/r$ 与惯性项 $I_{ef}a_x/r^2$ 必须分开算；$\eta$ 只乘第一项；1 挡 2290 lb 必须含 $\eta_{tf}=0.95634$，漏了得 2394（+4.5%）。 |
| 有效转动惯量 → 等效质量 → 等效重量：$I_{ef}/r^2\times386$，1 挡让车"变重"877 lb（+35%） | $I_{ef}/r^2\times386$ 三步换算出等效重量；只计驱动轮；1 挡 877 lb/系数 1.351、2 挡 353 lb/1.141；半径 in 配 386，混 32.2 差 12 倍。 |
| 挡位与车速的换算：$\omega_w=\omega_e/N_{tf}$、$V=\omega_w r$，以及"一次方 / 平方"的分界 | $\omega_w=\omega_e/(N_tN_f)$、$V=\omega_wr$；一阶量乘一次速比、惯量乘平方；1 挡 4400 rpm 是 38.7 ft/s（26.4 mph），不是 88 ft/s（OCR 错误）。 |
| 整车纵向力平衡：$Ma_x=F_x-R_x-D_A-R_{hx}-W\sin\theta$ | $\Sigma F_x=F_x-R_x-D_A-R_{hx}-W\sin\theta$，除以 $(W+W_{eff})/32.2$；惯性只在分母，分子再减 $Ma_x$ 就是双扣。 |
| 驱动力-车速图的绘制与包络自检：曲线族 + 等功率线 + 阻力线族 | 各挡曲线（$T N_{tf}\eta/r$）+ 等功率线（$550\eta P_{\max}/V$）+ 阻力线族；每个点必须满足 $F\cdot V\le\eta P_{\max}$，越界先怀疑数据。 |
| 传动比的等比级数校验：级比、公比 q、逐挡偏差 | $q=(N_1/N_n)^{1/(n-1)}$；级比=相邻挡总速比之比；偏差正负说明偏疏/偏密；等比只是近似，不是验收标准。 |
| 最佳换挡点＝相邻挡驱动力曲线的交点（不是红线，也不是最大扭矩点） | 同车速下 $F_{低}=F_{高}$ 的点才是最优升挡点；力比=级比×扭矩比；表内无交点时在表端升挡，不许编交点。 |
| 液力变矩器：失速点约 2 倍扭矩放大，随转速比升到 1 | $TR\approx2$ 只在转速比→0；$SR\to1$ 时 $TR\to1$；效率 $=TR\times SR$；锁止原文无定义，不许补条件。 |
| 本章单位制与换算清单：in/ft、386/32.2、5252/550、hp/lb 与 lb/hp | 半径 in 配 386 in/s²、ft 配 32.2；5252 与 550 差 9.55 倍；hp/lb 与 lb/hp 互为倒数（差 1600 倍）；换算后再做量纲检查。 |
| 附着极限最大驱动力的四分支决策树：锁止/不锁止 × 前驱/后驱 | 分子 $\mu\times$驱动轴静载；分母 $1\mp(h/L)\mu+\big(2\mu r/(N_f t)\big)(K_{\phi f}/K_\phi)$；四分支按"前/后 + 锁止/独立"选，选错差 2.5%–25%。 |
| 纵向载荷转移：$W_r=W(b/L+a_x h/(gL))$，后驱加载、前驱卸载 | $\Delta W=F_xh/L$；后轴 $+\Delta W$、前轴 $-\Delta W$；$b$ 是重心到**前**轴距离，后轴静载用 $Wb/L$；校验 $W_f+W_r=W$。 |
| 驱动扭矩引起的横向载荷转移：$W_y=\dfrac{F_xr}{N_ft}\cdot\dfrac{K_{\phi f}}{K_\phi}$ | $W_y=(F_xr/(N_f t))(K_{\phi f}/K_\phi)$；$T_d=F_xr/N_f$（除不是乘）；$N_{ft}=N_f\times t$ 不是 $N_{tf}$；该项是纯损失。 |
| 不锁止差速器：从单轮载荷到总驱动力 $F_x=2\mu W_{rr}$ | $W_{rr}=W_r/2-W_y$、$F_x=2\mu W_{rr}$；漏减 $W_y$ 高估 7.6%；每轮 $=F_x/2=600.5$ lb（不是 548）。 |
| 锁止差速器 / 独立悬架驱动轴：分母第三项消去，多出 104 lb | 锁止 **或** 该驱动轴为独立悬架 → 分母第三项消去（两条独立充分条件）；锁止后 $W_y$ 仍在，消失的只是损失；差额 104 lb @ μ=0.62。 |
| 前驱附着极限：$F_{x\max}=\dfrac{\mu Wc/L}{1+(h/L)\mu}$，三处替换与两个分支 | 三处替换：$Wc/L$、第二项翻正、$K_{\phi r}/K_\phi$；独立/锁止前轴走式(2-26) 得 1087 lb（0.3506 g = 11.29 ft/s²）；写成后驱负号得 1361.8（+25%）。 |
| 前驱 vs 后驱的附着差异：三处替换、差异归因、不能相减 | 三处替换（$Wc/L$、符号翻正、$K_{\phi r}$）后同参数对比；差异排序：符号 > 项数 > 刚度份额；跨车型不得相减（G-4），只能给"静态份额不能单独外推"。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
