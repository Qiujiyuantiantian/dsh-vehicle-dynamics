# 决策规则速查 — 《车辆动力学基础》第 5 章 乘适性

| 能力 | 一句话规则 |
|---|---|
| 乘适性分诊：先归到「输入—传递—判据」三段，再用频率窗判共振命中 | 把症状换成频率 → 对撞四个频率窗（激励 0.005–0.5 cyc/ft×V、刚体 1–1.5 Hz、hop 10–12 Hz、内部阶次 nV/2πr）→ 输出"可改/改不动/不在模型内"三列预算表，目标是谱形整形而不是 RMS 最小。 |
| 路面输入的两条腿：纵向（$f=\nu V$、$a\propto V^2$、板接缝）与横向（轮辙和/差、侧倾比） | $f=\nu V$ 一次换算 + 固定 $\nu$ 时幅值 $\propto V^2$（PSD 再平方）+ 谱形状四件（$\nu^{-4}\to\nu^{-2}$、$\nu_0$、0.005–0.5 cyc/ft、两档差 10 倍）+ 轮辙和/差给侧倾（长波 10%、$\nu\approx0.1$ 时 100%）；绝对值一律不给。 |
| 四分之一车辆增益与谱相乘：$G_{zs}=|H_v|^2G_{zr}$，但力通道在本章不可复现 | 四个归一化参数（$K_1,K_2,C,\chi$）→ 式(5-14) 加速度传递比 → $G_{zs}=|H_v|^2G_{zr}$（功率关系，RMS 开方）→ 力通道与图5.16 后两条曲线只能定性，不许补全式(5-15)(5-16)。 |
| 乘适刚度与跳动固有频率：$RR=K_sK_t/(K_s+K_t)$ → $f_n=0.159\sqrt{RR/(W/g)}$ → 静挠度尺 | 串联 $RR=K_sK_t/(K_s+K_t)$ → $f_n=0.159\sqrt{RR\times386/W}$ → $\delta=W/RR$ 对照 10/5/1 in 尺；频率一律用 $RR$ 不用 $K_s$（否则高估约 6%），0.159 绑英制。 |
| 频率的可行下限与阻尼的可用上限：1 Hz 要 5 in 行程吸收 0.5 g；ζ 只把频率拉低 8% | $f_n$ 的可行下限由行程定（1 Hz ⇒ ≥5 in 吸收 0.5 g；量产锁 1–1.5 Hz）而非舒适性；ζ 只把频率拉低 2%/8%（ζ=0.2/0.4），100%=临界、200%=ζ2.0 过阻尼，式(5-11) 缺失故 ζ 取式(5-19c) 并标"非原文"。 |
| 阻尼不是"一个数"：四档语义、阀配置评审，以及线性谱方法在真实悬架上失效的判据 | 四档 10/40/100/200% = ζ=0.1/0.4/1.0/2.0（100% 临界、200% 过阻尼 ⇒ 车身在轮胎上 3–4 Hz）；真车是量孔 $v^2$+卸荷+1:3 方向不对称；叶片弹簧迟滞使有效刚度 3×（极端 10×）⇒ 必须时基模拟。 |
| 主动 vs 被动的诚实收益：−30% 与 −10% 必须成对，天花板在"反作用点"而不是算法 | 收益必须成对报（无约束 −30% / 约束 ζ_un=20% 后 −10%，同一硬件同一控制）＋代价（ζ_un=5% ⇒ 接地性崩）＋架构限定（无预瞄/全状态反馈/液压/x=0.15）；天花板在"控制车轮的力必须反作用到车身"。 |
| 车轮 hop 与非悬挂质量：$f_a=0.159\sqrt{(K_t+K_s)g/W_a}$，串并联一错全错 | hop 用并联 $K_t+K_s$（跳动用串联 $RR$）；$W_a$ 是车轴重不是轮荷；100/1000/100 lb/in ⇒ 10.36 Hz（含摩擦 12–15 Hz）；$W_a$ 加倍 ⇒ 7.33 Hz，减半 ⇒ 14.65 Hz，且"共振以上有些变差"。 |
| 车上激振源：用"阶次"把"某车速才抖"归一成"某转速的某阶穿过共振" | 阶次 = 相对转速的倍数（峰随车速移动的才是旋转件）；轮胎一阶 10–15/二阶 20–30 Hz、每阶约 −30%、摆差力只 70%、径向力与速度无关而牵引力 5–60 mph 约 5 倍；传动轴阶次=主减速比（∝ω²）、万向节二阶（∝扭矩×夹角，峰值 1/cosθ）；四缸 600 rpm ⇒ 20 Hz ⇒ 悬置 ≤10 Hz。 |
| 轴距滤波：$t=L/V$，跳动零点在 $V/2L$ 的奇次倍、俯仰零点在偶次倍 | $t=L/V$；跳动零点 = $V/2L$ 的奇次倍（1、3、5）、俯仰零点 = 偶次倍（2、4、6 = $V/L$ 整数倍）；9 ft/50 mph ⇒ 4.07/12.22/20.37 与 8.15/16.30/24.44；照抄"整数倍"会在 $V/L$ 处多算一个跳动零点。 |
| 跳动/俯仰双模态：$\alpha,\beta,\gamma$ 与两个运动中心——什么时候该信区间、什么时候只能读量级 | $\alpha=(K_f+K_r)/M$、$\beta=(K_rc-K_fb)/M$、$\gamma=(K_fb^2+K_rc^2)/(Mk^2)$ → 闭式解给 $\omega_1$=7.10 rad/s=1.130 Hz、$\omega_2$=6.71=1.069 Hz → $Z/\theta_1$=$-230\sim-260$、$Z/\theta_2$=+11.7 in/rad，判据是"中心是否超出轴距"而非符号。 |
| Olley 四准则与动态指数：一张能落到设计动作的校核清单，也是一张只准筛不准定的清单 | ① 前乘适刚度比后低 30%（或弹性中心后移 6.5%L）② $DI\approx1$（编号缺失）③ 前后频率 ≤1.3 Hz（⇒ 静挠度 >6 in）④ 侧倾频率≈跳动/俯仰；四条是 1930s 单车单人的经验法则、互相不独立、"低 30%"⇔后移 8.8%L 而 6.5%L⇔前低 23%，只能筛不能定。 |
| 人体判据只给形状，谱只在线性-线性下读：这一端没有公认换算尺 | 判据端只交付三样：三条形状性结论（垂直 4–8 Hz、纵向 1–2 Hz、10–20 Hz 波动）、1/3 倍频带取最差带的读法、线性-线性（面积＝均方值）的画法；全章无以 m/s² 或 g 表示的限值，ISO 只有"第二版"且标准号缺失 ⇒ 禁写 1997、禁引 VDV。 |
