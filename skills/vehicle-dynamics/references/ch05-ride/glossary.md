## 符号约定（先读这一段，否则下面的 ω、ζ、RR 会读反）

| 符号 | 书中含义 | 备注 |
|---|---|---|
| $\nu$ | 波数（空间频率），cyc/ft 或 cyc/m | 与车速**无关**；路面专用 |
| $f$ | 时间频率，Hz | 车辆响应用；$f=\nu V$ |
| $V$ | 车速，ft/s 或 m/s | 与 $\nu$ 的长度单位必须配套（mph×1.467、km/h×0.9113） |
| $G_z(\nu)$ | 路面轮廓 PSD，ft²/cyc/ft | 式(5-1)；**绝对值禁出**（见 g06） |
| $G_0$ | 不平度幅值系数 | 1.25e−5 不平 / 1.25e−6 平坦；管**好坏** |
| $\nu_0$ | 截止波数 | 0.05 沥青 / 0.02 PCC；管**类型**（折线拐点） |
| $G_{zr}$ / $G_{zs}$ | 路面/车身**加速度** PSD | 式(5-17) 的输入与输出 |
| $H_v(f)$ | 响应增益（传递函数） | 仅线性系统；$G_{zs}=|H_v|^2G_{zr}$ |
| $M$ / $m$ | 悬挂（簧上）/ 非悬挂质量 | lb·s²/in；$M=W/g$ |
| $W$ / $W_a$ | **单轮**荷 / **车轴**重（非悬挂重量） | $W$ 用于跳动；$W_a$ 用于 hop |
| $K_s$ / $K_t$ | 悬架刚度 / 轮胎刚度，lb/in | 跳动串联、hop 并联 |
| $RR$ | 乘适刚度，lb/in | $=K_sK_t/(K_s+K_t)$，**≠ $K_s$** |
| $K_f,K_r$ | 前/后**轴端总**乘适刚度 | $=2\times$单轮 $RR$（原文未明说，由例题反推） |
| $\zeta$ | 阻尼比 | **100%=临界**、200%=ζ2.0 过阻尼；式(5-11) 缺失，取式(5-19c) |
| $\omega_n,\omega_d$ | 无阻尼/阻尼固有频率，rad/s | $\omega=2\pi f$；$f_n=0.159\sqrt{RR g/W}$ |
| $f_a$ | 车轮 hop 频率，Hz | 式(5-20)，用 $K_t+K_s$ |
| $Z/\theta$ | 运动中心位置，in/rad | **正=重心前**；病态，只给区间 |
| $DI$ | 动态指数 $k^2/(bc)$ | **≠ 动载系数** |
| $t$ | 轴间时滞 $L/V$，s | 式(5-39) |
| $\omega,\ \zeta_{un}$ | 主动悬架讨论中的非悬挂固有频率/阻尼比 | 与乘适 $\zeta$ **不同源** |

## A. 输入与路面

| id | 术语 | 原文要点 | **必须随条交付的校正与纪律** |
|---|---|---|---|
| g01 | 乘适性（ride / ride quality） | 主观感觉，主要与经座椅、手脚传入的**触觉振动**相关 | 是主观量、非"悬架软硬"；本条附带 5.3 三条反证（Healey / 多通道 / 问句），不得删；`ride quality` 是含座椅/温度/空间的总括词 |
| g02 | 激振源 | 路面不平度 + 车上旋转件（轮胎/车轮总成、传动系、发动机） | **4 个源**（外 1 + 内 3），不是"颠=路面"；四源在频谱上同时存在，原文自陈"经常难以确认" |
| g03 | 路面不平度 | 从局部凹坑到"始终存在的随机高度变化"，沿轮辙的轮廓高度 | 含"始终存在的随机分量"（好路也有 $G_0$，只是小）；≠ 二维形貌；≠ IRI 单指标 |
| g04 | 功率谱密度 PSD | 轮廓高度经傅里叶展开后幅值随空间频率的分布 | **密度语义 ⇒ 面积=均方值**；不是幅值谱（否则式5-17 的平方会写成一次方）；不是一个"路面等级数" |
| g05 | 波数 $\nu$ / 频率 $f$ | $\nu$ 是波长倒数；$f=\nu V$ | 路面用 $\nu$、响应用 $f$；两图（5.2 cyc/ft 与 5.3 Hz）**不可叠比**；$\nu$ 与车速无关 |
| g06 | $G_0$ | 1.25×10⁻⁵ 不平坦 / 1.25×10⁻⁶ 平坦 | **只给两档、相差 10 倍**；不平坦档指数 OCR 丢失（印作 `1.25×10-°`）⇒ **绝对数值待核（H-1：与图5.2 刻度差两个数量级）**；不得换算成 ISO 8608 A–H 级 ⚠️ |
| g07 | 截止波数 $\nu_0$ | 0.05 沥青 / 0.02 PCC | 是式(5-1) 的**折线拐点**，不是滤波器截止；管"类型"不管"好坏"；沥青能量偏低波数、PCC 偏高波数 |
| g08 | 混凝土板接缝周期成分 | 0.01?–0.1 cyc/ft（0.03–0.3 cyc/m） | 区间起点缺字，现值为公制换算所得（须回查）；**全章唯一的非随机成分**，不能塞进随机谱；离散冲击必须单列 |
| g09 | 侧倾激振输入 | 轮辙**差值**=侧倾输入、**平均**=跳动/俯仰输入；归一化比值 | 10% 只对长波成立（60 mph/1 Hz ⇒ $\nu$=0.011 ⇒ 10%；6 mph ⇒ $\nu\approx0.1$ ⇒ ≈100%）；"10%"不可外推为"侧倾永远小" |

## B. 部件与质量

| id | 术语 | 原文要点 | **必须随条交付的校正与纪律** |
|---|---|---|---|
| g10 | 轮胎/车轮不均匀性 | 三类偏差（质量不平衡、尺寸变差、刚度变差）× 三向力 | 不是"轮胎质量不好"；**径向力与速度无关（可外推）**、**牵引力 5–60 mph 约 5 倍（不可外推）** |
| g11 | 合成力变化 CFV | 等半径滚动一周内径向力变化的全振幅，用傅里叶谐量描述 | 是**峰峰值**、非一阶谐量；各阶约 −30%（轿车）；相位"与乘适性关系不密切"，工程上只用幅值 |
| g12 | 径向摆差（自由/承载）与选配安装 | 自由=空载几何偏心；承载=额定载荷下滚动；选配安装用偏心度抵消 | 摆差×$K_t$ 只给实际力的 **70%**（"会高估 43%"是 $1/0.7$ 的换算，原文只说 70%）；p121 的 70% 与 p123 的"承载摆差×径向刚度"是**两个口径**；**本章未使用 enveloping 一词** |
| g13 | 牵引力变化 | 两个机制：偏心滚动的几何分量（与速度无关）与半径变化引起的惯性分量（5–60 mph 约 5 倍） | **两个机制必须分开**；"5 倍"不可外推到 80 mph 以上；低速台架测不到惯性分量 |
| g14 | 传动系：不平衡 vs 次级力偶 | 不平衡 $F\propto\omega^2$、阶次=主减速比；万向节二阶、∝扭矩×夹角、峰值 $1/\cos\theta$ | **别把两者都叫"传动轴不平衡"**；3.7×/7.4× 是那一辆货车的实测，通用值是主减速比及其二阶；式(5-6) 的 $\theta/\beta$ 语义可疑，**只许用式(5-7)** ⚠️ |
| g15 | 阶次 / 谐量 | 激励频率 = 转速 × 阶数；轮胎一阶 10–15 Hz、二阶 20–30 Hz（高速正常车速） | 阶次是**无量纲倍数**、与 Hz 不同；四缸四行程点火阶 = **2 阶**（600 rpm ⇒ 20 Hz），别把"2 阶"当 2 Hz |
| g16 | 悬置侧倾轴解耦 | 悬置侧倾轴与发动机惯性侧倾轴共线 + 绕该轴共振低于最低点火频率 | 两条件同时成立；四缸 ⇒ ≤10 Hz（**缸数特例，非通用限值**）；**反向用法**：动力总成可当 12–15 Hz 消振器，但"质量比要求"原文未给 |
| g17 | 悬挂 / 非悬挂质量 | 两个刚体（各一自由度）；经验 10%/15% GAWR | 10%/15% 是**经验值非推导**；**校正**：原文只说"较轻一般较好、共振以上有些变差"，"几乎没有代价"是过强表述，交付时须改写 |
| g18 | 四分之一车辆模型 | 单角、两自由度、只垂向；轮胎用简单弹簧 | **不能**算轴距滤波/Olley/侧倾；轮胎无阻尼、无包络；图5.16–5.28 的全部结论都建立在这个结构上 |

## C. 隔振链

| id | 术语 | 原文要点 | **必须随条交付的校正与纪律** |
|---|---|---|---|
| g19 | 乘适刚度 $RR$ | $=K_sK_t/(K_s+K_t)$，悬架与轮胎**串联** | **≠ $K_s$**（本例 143→127.8，软化 10.7%）；0.89 只对本例刚度比成立；**同词二义**：5.2.7 图5.27 把"有效刚度 300"也叫乘适刚度——两义必须并列写 ⚠️ |
| g20 | $K_s$ / $K_t$ | 悬架刚度 / 轮胎刚度；$r=K_t/K_s$=5 跑车 … 20 空气悬架 | **跳动串联、hop 并联**；式(5-19d) 的 $K$ 未指明（按 $K_t+K_s$ 取，差约 5%）；$K_s/K_t$ 记反 ⇒ $r$ 变成 0.05–0.2，整张工作点图搬错 ⚠️ |
| g21 | 跳动固有频率 $f_n$ | $\omega_n=\sqrt{RR/M}$；$f_n=0.159\sqrt{RR/(W/g)}$ | 特指车身跳动（≈1 Hz），**不是** hop / 结构模态 / 俯仰；0.159=$1/(2\pi)$ 且绑 $g=386$ in/s²，搬 SI 会错；$W$ 是单轮荷 |
| g22 | 静挠度 | $W/K$，频率的替身 | **≠ 行程**；1 Hz↔10 in、1.4↔5、3.13↔1；行程约束：1 Hz 需 ≥5 in 吸收 0.5 g（大型 7–8 in、紧凑 5–6 in） |
| g23 | 阻尼比 / 阻尼固有频率 | $\omega_d=\omega_n\sqrt{1-\zeta^2}$；轿车 ζ=0.2–0.4 | **100%=临界；200%=ζ2.0 过阻尼（车身在轮胎上 3–4 Hz）**；ζ=0.2→98%、0.4→92%；式(5-11) 缺失，取式(5-19c) 重构（分母 $K_s$ 不是 $RR$）⚠️；主动的 5%/20% 是**非悬挂** ζ，不同源；本章**未定义任何衰减率** |
| g24 | 增益 / 传递率 / 隔振 | 同一物理量之比的幅值比；"传递函数"限线性系统 | 必须同物理量之比；图5.16 一张图三条定义（对路面低频→1、对车轴力零频→0、对车身力高频→1）**不可互算**；"隔振"=低频放大+高频衰减，不存在全频段都好的被动悬架 |
| g25 | 车轮 hop 共振 | 10–12 Hz；含悬架摩擦升至 12–15 Hz；$f_a=0.159\sqrt{(K_t+K_s)g/W_a}$ | 不是"车轮跳离地面"的日常义；**并联**；$W_a$ 是车轴重（误用轮荷会压低 $\sqrt2$ 以上）；hop 处不均匀力直接传到簧上（增益=1）；12–15 Hz 无算式 ⚠️ |
| g26 | 悬架行程 / 限位块 | 1 Hz 需 ≥5 in 吸收 0.5 g；量产锁 1–1.5 Hz；特技车 2–2.5 Hz | 全章"为什么不能更软"的唯一硬约束（几何空间，不是舒适性）；**撞限位的是峰值位移（≈3–4σ）不是 RMS**；0.5 g 事件来源原文未交代 |
| g27 | 悬架迟滞 / 有效刚度 | 叶片弹簧小振幅有效刚度≈名义 3 倍（极端一个数量级）；平路 2.5 Hz、增益>5；粗糙路频率与幅值双降 | **名义≠有效**；"平路 2.5 Hz 与 $\sqrt3=1.73$ Hz 不一致"须一并写，**不得把 3× 当频率系数**（要 2.5 Hz 需 ≈6.3×）；仅对叶片弹簧重型货车成立；必须时基模拟 |

## D. 主动

| id | 术语 | 原文要点 | **必须随条交付的校正与纪律** |
|---|---|---|---|
| g28 | 主动悬架（力发生器） | 全状态反馈、无预瞄、液压（Chalasani 1986）；$x=m/M=0.15$ | **收益必须成对**：无约束 −30%（$\zeta_{un}$=5%，接地性崩）／约束 20% 后 −10%；天花板在**反作用点**（控制车轮的力必须反作用到簧上质量）；不可外推为"主动没价值"（无半主动/天棚/预瞄） |

## E. 整车刚体

| id | 术语 | 原文要点 | **必须随条交付的校正与纪律** |
|---|---|---|---|
| g29 | 轴距滤波 | 后轮输入 = 前轮轮廓滞后 $t=L/V$；部分波长上输入相消 | **不是电路滤波器，是几何时滞造成的相消**；**跳动零点 = $V/2L$ 的奇次倍、俯仰零点 = 偶次倍（= $V/L$ 整数倍）**（原句"整数倍"是误写，已在阶段 1.6 修正为奇/偶倍）⚠️；算例 9 ft/50 mph ⇒ 4/12/20 与 8/16/24 Hz；货车相反 |
| g30 | 弹性中心 | 前后乘适刚度的垂向合力作用点（$\beta=0$ 处）；Olley① 的"6.5%L"即指它 | 与**侧倾中心毫无关系**（后者横向平面内，本章全文未出现）；也不是重心（只在 $\beta=0$ 时重合）；读成"降低侧倾中心"会做出完全无效的改动 |
| g31 | 运动中心（振动中心） | 每模态一个，$x=Z/\theta$，正=重心前；判据"是否超出轴距" | **每模态一个**，不是车上的固定点；判据是**距离**不是符号；**病态**：只读量级（例1 取 $-230\sim-260$ in/rad），行 725 的 957.3 不可引用；7.19 为书误（取 7.10）⚠️ |
| g32 | 动态指数 $DI$ | $DI=k^2/(bc)=1$ ⇔ 共轭打击中心、振动中心在车轴处 | **≠ 动载系数**；$DI$ 对载荷敏感（例2 表固定 $DI$=1.05 是**假设**）；$DI$=1 单独满足不够（见 g33 的四组合） |
| g33 | Olley 准则（欧雷准则） | ①前乘适刚度低 30% 或弹性中心后移 6.5%L；②$DI\approx1$（**编号与句首缺失**）；③前后频率 ≤1.3 Hz（⇒ 静挠度 >6 in）；④侧倾频率≈跳动/俯仰 | **经验法则非定律**（1930s 单车 + 单人主观 + 无统计样本）；四条**不独立**（"4 过 3"不比"过 1"更有信息量）；**两种表述不等价**（30% ⇔ 后移 8.8%；6.5% ⇔ 前低 23%）；仅低频刚体；原文末句"最佳频率比要由实验确定" |

## 三张必读对照表

### A. 三中心：弹性中心 vs 侧倾中心 vs 运动中心

| | 弹性中心 | 侧倾中心 | 运动中心（振动中心） |
|---|---|---|---|
| 平面 | 纵向（俯仰） | **横向（侧倾）** | 纵向 |
| 定义 | 前后乘适刚度的垂向合力作用点 | 车身侧倾的瞬时转动中心 | 某模态下 $Z/\theta$ 给出的虚拟转轴距离 |
| 由什么决定 | $K_f,K_r$ 与 $b,c$（$K_rc=K_fb$） | 悬架几何 | 前后频率比 |
| 判据 | $\beta=0$ ⇔ 在重心处 ⇔ 无耦合 | 侧倾力矩臂 | $\lvert x\rvert>$ 轴距 ⇒ 跳动主导；$<$ ⇒ 俯仰主导 |
| 本章出处 | p146、p148（Olley①） | **❌ 本章未出现**（属第 6/7 章） | p147、图5.33/5.34 |
| 数量 | 每车 1 个 | 每轴 1 个 | **每模态 1 个** |

### C. 阻尼 vs 衰减（"阻尼百分比"）

| 说法 | 含义 | 出处 |
