# 乘适刚度与跳动固有频率：$RR=K_sK_t/(K_s+K_t)$ → $f_n=0.159\sqrt{RR/(W/g)}$ → 静挠度尺

## R — 原文 (Reading)

> **原书要点**（5.2.1 节，式 5-8，p130）：悬架弹簧与轮胎径向刚度可看作串接在一起，二者合成的等效刚度即乘适刚度，其倒数等于两个刚度倒数之和，写成 $RR=(K_sK_t)/(K_s+K_t)$。
>
> **原书公式**（p131）：无阻尼时……跳动的固有频率……可由下列方程式确定：$\omega_n=\sqrt{RR/M}$；$f_n=0.159\sqrt{RR/(W/g)}$（式 5-9a、5-9b，p130）

## I — 方法论骨架 (Interpretation)

一句话：**"悬架软不软"不需要试车，只需要三次运算——把两根弹簧串成一个刚度、把这个刚度除以簧上质量开方、再把结果折成一英寸数。**

- **第一层：串联。** 车身坐在"悬架弹簧 + 轮胎弹簧"的串联链上，所以等效力 $RR=K_sK_t/(K_s+K_t)$ 一定小于 $K_s$。本例 $K_t/K_s\approx8.4$ ⇒ $RR\approx0.89K_s$，轮胎柔度"软化"约 11%。**这个 0.89 只对这一个刚度比成立**，换胎就变，不是通用系数。
- **第二层：开方。** $\omega_n=\sqrt{RR/M}$，换成工程单位 $f_n=0.159\sqrt{RR/(W/g)}$。0.159 就是 $1/(2\pi)$，它与 $g=386$ in/s² **绑定**：把 lb/in、in、lb 换成 N/m、m、kg 而沿用 0.159，得到的不是"差百分之几"，而是量纲上就错的数。搬运时必须回到 $\omega_n=\sqrt{RR/M}$ 重推系数。
- **第三层：折算成静挠度。** 因为 $f_n$ 只由 $W/RR$ 决定，频率与"静态压缩量"一一对应：**10 in ↔ 1.0 Hz、5 in ↔ 1.4 Hz、1 in ↔ 3.13 Hz**。于是"软不软"变成"停车时量一下悬架被压下去多少"，这是全章性价比最高的一步——不需要任何仪器。
- **不要犯的三个错**：用 $K_s$ 代替 $RR$（频率高估约 6%）；用轴荷代替单轮荷（$f_n$ 低估 $\sqrt2$）；把 0.159 带到 SI。
- 例题 5.2.2 的 Mustang 恰好是"反面样板"：前后频率 1.142 / 1.111 Hz 几乎相等，正是 Olley 准则①要避免的配置（前乘适刚度没有比后低 30%）。

## A1 — 应用示例 (Application Example)

### 示例 1：例 5.2.2（5.0 L Mustang）的四步复算（原书例题）

- **类型与来源**：**原书例题**（例 5.2.2，p134）。题面：$K_t=1198$ lb/in、前 $K_s=143$、后 $K_s=100$ lb/in、前/后单轮荷 957 / 730 lb。答案原文给 127 / 92.3 lb/in 与 1.14 / 1.11 Hz。
- **输入/问题**：求前后乘适刚度与跳动固有频率。
- **方法的使用**：① $RR_f=143\times1198/(143+1198)$；② $RR_r=100\times1198/(100+1198)$；③ $f_{n,f}=0.159\sqrt{RR_f\times386/957}$；④ 同式算后轴。
- **结论/结果（复算值）**：$RR_f=\mathbf{127.8}$ lb/in（原文取整 127）、$RR_r=\mathbf{92.3}$ lb/in；$f_{n,f}=\mathbf{1.142}$ Hz、$f_{n,r}=\mathbf{1.111}$ Hz。自检：$RR/K_s=0.893$（软化 10.7%）；若误用 $K_s$ 直接算，得 $0.159\sqrt{143\times386/957}=\mathbf{1.208}$ Hz（比 1.142 高 **5.8%**，与 $1/\sqrt{0.893}=1.058$ 一致，即"约 6%"）。
- **已知原文取整的后果**：例 5.2.11-1 直接引用了**取整后的 127**，复算 $Z/\theta$ 时若也用 127 而非 127.8，会带来 0.6% 的偏差并传到病态的 $Z/\theta$（见 `pitch-bounce-bimodal-and-centers`）。**引用时必须写 127.8。**

### 示例 2：一辆自造车的三件套（合成演练，非书中事实）

- **类型与来源**：**合成演练**。自造车 C1（$K_s=180/120$ 前/后、$K_t=1500$ lb/in、单轮荷 1000/850 lb），参数与书中三道例题均不同。
- **输入**：同上；目标：判断这车的软硬与是否满足"前软后硬"。
- **方法的使用**：① $RR_f=180\times1500/1680=160.7$；② $RR_r=120\times1500/1620=111.1$；③ $f_{n,f}=0.159\sqrt{160.7\times386/1000}$；④ $f_{n,r}=0.159\sqrt{111.1\times386/850}$；⑤ 静挠度 $\delta=W/RR$。
- **结论/预期输出**：$RR_f=\mathbf{160.7}$、$RR_r=\mathbf{111.1}$ lb/in；$f_{n,f}=\mathbf{1.252}$ Hz、$f_{n,r}=\mathbf{1.129}$ Hz；$\delta_f=\mathbf{6.22}$ in、$\delta_r=\mathbf{7.65}$ in。自检：$0.159\sqrt{386/6.22}=1.252$ ✓ 与频率一致。判读：前后频率比 $1.252/1.129=\mathbf{1.11}$，**前比后硬**，方向与 Olley①（前乘适刚度应比后**低 30%**）相反 ⇒ 不通过，动作是把前簧降下来（合格判定见 `olley-criteria-and-dynamic-index`）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 拿到弹簧刚度/轮胎刚度/轮荷，要算跳动固有频率。
2. 想"把悬架调软一点"，要先知道现在是多少 Hz、软到什么程度。
3. 只有静态压缩量（或只有频率），要在两者之间换算。
4. 要判断"换软胎能不能变舒服"——必须回答"对跳动几乎无效，对 hop 影响大"。
5. 要核对一份规格书里的频率：它用的是 $K_s$ 还是 $RR$、轴荷还是轮荷。

### 语言信号（中英双写）

- 「固有频率怎么算」「ride rate」「乘适刚度」「跳动频率」「静态压缩量对应的频率」「1 Hz 要多少挠度」
- 「换软胎有用吗」「弹簧刚度 143 对应多少 Hz」「前后频率比」
- 「bounce frequency」「static deflection」「wheel rate」「corner weight」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `quarter-car-gain-and-spectrum-product`：本卡只出**峰位**（一个标量），那张卡出整条增益曲线与谱相乘。
- 与 `travel-budget-and-damping-limits`：本卡出频率，那张卡判"这个频率做不做得到"（行程）与"阻尼能不能忽略"（ζ、$\omega_d$）。
- 与 `wheel-hop-and-unsprung-mass`：本卡用**串联** $RR$；hop 用**并联** $K_t+K_s$。同一对弹簧，两处连接方式相反。
- 与 `olley-criteria-and-dynamic-index`：本卡出单轴频率，那张卡用频率比做四准则校核；本卡的 c01 是那张卡的反面样板。

## E — 可执行步骤 (Execution)

**必需输入**：每个角一套 $\{K_s, K_t, W\}$（$K_s,K_t$ 单位 lb/in；$W$ 是**单轮荷** lb）。**缺 $K_t$ 时停**：没有 $K_t$ 就没有 $RR$，用 $K_s$ 代替会系统性高估频率；若用户只给 $\delta$（静挠度），可直接走 $f_n=0.159\sqrt{386/\delta}$ 并说明这是"以 $RR$ 为弹簧"的口径。

**交付物与完成标准**：一张两行表（前/后：$RR$、$f_n$、$\delta$）+ 三处自检 + 一句"是否满足前软后硬"。

1. **统一单位与口径**
   - 完成标准：写明 $W$ 是**单轮荷**（轴荷 ÷2 或直接给 corner weight）、$K_s$ 是**轮端**刚度（若是弹簧刚度须先乘安装比平方——本章未给安装比，缺则停）；英制。
2. **算 $RR$（串联）**
   - 完成标准：$RR=K_sK_t/(K_s+K_t)$；给出 $RR/K_s$ 的软化比例，并声明"该比例只对本例刚度比成立，不是通用 0.89"。
3. **算 $f_n$**
   - 完成标准：优先用 $f_n=0.159\sqrt{RR\times386/W}$；同时给 $\omega_n=\sqrt{RR/M}$ 交叉核对（$f=\omega/2\pi$）——两条路径必须一致到 0.1%。
4. **折算静挠度并对照尺子**
   - 完成标准：$\delta=W/RR$（in）；用 10 in↔1.0 Hz、5 in↔1.4 Hz、1 in↔3.13 Hz 三点检验量级；声明"图 5.15 是列线图，中间值只能内插"。
5. **判前软后硬（与 Olley 的接口）**
   - 完成标准：给出 $RR_f$ 与 $0.7RR_r$ 的比较（或 $f_f/f_r$）；**只报方向与比值，不下"合格"结论**（合格判定与不等价说明在 Olley 卡）。
6. **交付**
   - 完成标准：一句话"该车 $RR_f=127.8$、$RR_r=92.3$ lb/in ⇒ $f_{n,f}=1.142$、$f_{n,r}=1.111$ Hz（$\delta$=…/… in）；用 $K_s$ 会高估约 6%"。

**计算约定（原书未规定，本卡设定）**：$RR$ 保留 1 位小数（lb/in）、$f_n$ 保留 3 位小数（Hz）、$\delta$ 保留 2 位（in）；$g=386$ in/s²；中间量不提前舍入（尤其 $RR$ 不要先取整成 127 再往下算）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **不要用 $K_s$ 代替 $RR$**（g19）。频率会高估约 6%，行程预算会整体偏乐观；而且这个错不会自曝——算出来的数照样"像对的"。
- **不要把 $RR\approx0.89K_s$ 当通用系数**（p17 boundary）。0.89 只来自 $K_t/K_s\approx8.4$ 这一例；换轮胎刚度比就变。
- **不要把 0.159 带到 SI 单位**。0.159=$1/(2\pi)$ 与 $g=386$ in/s² 绑定；SI 下必须回到 $\omega_n=\sqrt{RR/M}$ 或重推系数。
- **不要用轴荷算 $f_n$**。$W$ 是单轮荷；误用轴荷会把频率压低 $\sqrt2$（约 29%）。
- **不要把它当"隔振能力"的全部。** 它只描述 hop 以下的固频；10–12 Hz 的 hop、以及"200% 阻尼时车身在轮胎上 3–4 Hz 共振"，本卡都不覆盖（ce11）。
- **不要在同一张卡里混用两义"乘适刚度"**（g19）。5.2.7 图 5.27 把叶片弹簧小振幅**有效刚度**（300 lb/in，名义 100）也叫"乘适刚度"——那是迟滞现象，不是式(5-8) 的 $RR$。
- **不要用本卡结果判"这车舒服"。** 频率低只说明隔振带宽有利；能不能接受由行程（撞不撞限位块）与阻尼（峰高）决定，本章也没有舒适性数值限值。

### 作者在书中警告的失败模式

- ce11（p133/p136/p141）：只用 $f_n$ 与 $\zeta$ 两个数描述整车隔振 ⇒ 丢掉 hop 峰、丢掉"悬架不动时车身在轮胎上 3–4 Hz"这一支、丢掉簧下质量这个杠杆。
- ce05（p131）：只看频率不看行程 ⇒ 调软后撞限位块。
- 原文 p130：阻尼只把共振频率拉低 8% 以内（ζ=0.4），所以工程上直接用无阻尼频率——这是**允许 8% 误差的近似**，不是恒等式（详见 travel/阻尼卡）。

### 作者的盲点 / 时代局限

- 全章英制且无换算表；0.159、386 都绑死在英制上。
- 轮胎是"简单弹簧"：无阻尼、无包络、刚度不随频率/胎压/载荷变（g20）。现代低扁平比胎的 $K_t$ 更高，$RR$ 更接近 $K_s$。
- 例 5.2.2 的 1198/100 是 OCR 由 "11981b/in"、"1001b/in" 复原（1↔l 混淆），有同页算式互证——引用时须注明复原过程。
- 前/后"单轴频率"忽略另一轴的影响（原文未声明），真实整车频率由双模态计算给出（见 `pitch-bounce-bimodal-and-centers`）。

### 容易混淆的邻近方法论

- **$K_s$（弹簧/轮端刚度）vs $K_t$（轮胎径向刚度）vs $RR$（串联等效）vs 有效刚度（迟滞切线）**：四个量在书中都出现过，只有 $RR$ 能代入式(5-9)。
- **$f_n$（跳动，≈1 Hz）vs $f_a$（hop，10–12 Hz）vs 双模态 $\omega_1,\omega_2$（≈1.1 Hz 一对）**：三个"频率"来自三个不同模型，不可互换。
- **静挠度（静态压缩量）vs 悬架行程（可用动程）**：前者是频率的替身，后者是"做不做得到"；10 in 静挠度不等于 10 in 可用行程（g22）。
