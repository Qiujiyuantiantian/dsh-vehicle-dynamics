# 四分之一车辆增益与谱相乘：$G_{zs}=|H_v|^2G_{zr}$，但力通道在本章不可复现

## R — 原文 (Reading)

> **原书要点**（5.2 节开篇，p129）：响应幅值除以激励幅值所得的比值，即该动态系统的“增益”；文献中常用“传递率”一词指代同一概念。它描述系统处于稳态强迫振动时，输出幅值与输入幅值之间的无量纲比。
>
> **原书要点**（p141–142）：$G_{zs}=|H_v|^2G_{zr}$（式 5-17，p133；原文另注"作为线性系统模型"）

## I — 方法论骨架 (Interpretation)

一句话：**把"路面被摇成什么样"变成"车被摇成什么样"，只需要三件东西——两自由度运动方程给出的复增益 $H_v(\omega)$、输入谱 $G_{zr}$、以及一条"功率相乘"的规则。三件里只有一件半是本卡能负责的。**

- 模型只有两个自由度：簧上 $Z$、簧下 $Z_u$（式 5-12/5-13）。合并成四个归一化参数：$K_1=K_s/M$、$K_2=K_t/M$、$C=C_s/M$、$\chi=m/M$。**这四处最容易错的是并联/串联**：簧下方程里是 $(K_s+K_t)$ 并联，簧上方程里只有 $K_s$。
- 加速度传递比（式 5-14）是**唯一可用的通道**：$\omega\to0$ 时 $|H|\to1$（车身随路面同动），$\omega\to\infty$ 时 $\to0$（高频被隔掉）。两端极限就是"隔振"的完整含义——**低频放大、高频衰减，共振处最差**。
- 谱相乘是**功率**关系：$G_{zs}=|H_v|^2G_{zr}$。要 RMS 就开方；把 $|H|^2$ 写成 $|H|$（一次方），全章预测差一倍。
- 反推用法（原文给的捷径）：由实测车内谱的形状反读 $|H_v|$ 的形状——因为路面谱本身是单调的，峰只可能来自传递函数。
- **本卡的硬缺口：力通道没有。** 式(5-15)(5-16) 在 p132 被印成 6 行重复错序的残片（出现 `(K_1+K_2+K_9)^2` 这类非法项），$F_w$（车轴力）与 $F_b$（直接作用于簧上质量的力）的幅值比**不可复现**。后果：接地性/轮胎动载只剩概念（"三个性能参数量"里的第三个），**没有可算的传递函数**；图 5.16 的后两条曲线只能核形状，不能取数。
- 一张图上其实有**三条不同定义**的增益（对路面输入、对车轴力输入、对车身直接力输入），低频极限分别是 1、0、1。先判"这是哪一条"，再取数——三条不可相减、不可相除。

## A1 — 应用示例 (Application Example)

### 示例 1：两端极限与"PSD ×4 / RMS ×2"（原书引用数据 + 复算）

- **类型与来源**：**原书引用数据**（式 5-14，p131–133；f08 的 V2 纸面走查）。原文只给"低频随路面同动、高频被隔掉"的文字与符号表，未给逐步算术。
- **输入/问题**：同一辆车，$|H_v|=2$ 在 1 Hz；问输出谱与 RMS 各放大多少；再问 $\omega\to0$、$\omega\to\infty$ 的极限。
- **方法的使用**：① $G_{zs}=|H_v|^2G_{zr}=4G_{zr}$（PSD ×4）；② RMS $=\sqrt{4}=2$（×2）；③ $\omega\to0$：分子分母同为 $K_1K_2$ ⇒ 比 =1；④ $\omega\to\infty$：分子 $\sim jK_1C\omega$、分母 $\sim\chi\omega^4$ ⇒ 比 →0。
- **结论/结果（复算值）**：PSD **×4**、RMS **×2**、低频极限 **1.00**、高频极限 **0**。量纲自检：分子分母同为 $1/\mathrm{s^4}$，比值无量纲 ✓。

### 示例 2：由 ζ 估共振峰高（合成演练 + 本卡约定）

- **类型与来源**：**合成演练**。峰值增益用线性单自由度式 $1/(2\zeta\sqrt{1-\zeta^2})$——**本章未给该式**，属通用动力学，故标为"本卡约定"，只用于与原文区间（轿车 1.5–3、货车最差 5–6）对照。
- **输入**：$\zeta=0.30$（落在原文"现代轿车 0.2–0.4"内）。
- **方法的使用**：① $2\zeta\sqrt{1-\zeta^2}=0.6\times0.9539=0.5724$；② 取倒数。
- **结论/预期输出**：峰高 **1.75**，落在原文"轿车 1.5–3"的下半段 ✓。若 $\zeta=0.40$ ⇒ **1.36**（原文说 40% 代表多数车，与此下限互证）；若 $\zeta=0.10$ ⇒ 5.03（"float"，接近货车最差档 5–6）。**这一步只校准量级，不能替代图 5.16 的读数**（图是 PNG 占位，零读数）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 有了路面谱和悬架参数，要预测车内加速度谱（或其形状）。
2. 有了实测车内谱，要反推"是输入大还是传递差"。
3. 问"隔振到底怎么定义""为什么低频反而放大"。
4. 问"轮胎动载/接地性能不能算"——必须回答"本章不能"。
5. 要判断某个仿真模型是否退化成了单自由度（丢掉了 hop）。

### 语言信号（中英双写）

- 「预测车内谱」「输入谱乘传递函数」「隔振曲线为什么有峰」「传递率/增益」「PSD 相乘」
- 「轮胎动载能不能算」「接地性」「contact patch load」「transfer function quarter car」
- 「为什么我的模型只有 1 Hz 一个峰」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `road-input-spectrum-and-track-split`：那张卡出 $G_{zr}$（输入侧），本卡出 $|H_v|^2$ 与乘积。**两张卡必须先统一频率点**（$f=\nu V$），否则整体错位。
- 与 `ride-rate-and-bounce-frequency`：那张卡算 $f_n$（一个标量），本卡算整条曲线；$f_n$ 只是 $|H_v|$ 的峰位，不能替代曲线。
- 与 `wheel-hop-and-unsprung-mass`：本卡的 $|H_v|$ 在 10–12 Hz 只有"一个小突起"，hop 的频率与幅值敏感性在那张卡。
- 与 `damper-valving-and-hysteresis`：本卡假设线性粘性 $C_s\dot Z$，而那张卡说明真实减振器是非线性阀 + 迟滞，谱相乘的合法性在那里被否证。

## E — 可执行步骤 (Execution)

**必需输入**：簧上质量 $M$（或单轮荷 $W$）、$K_s$、$K_t$、$C_s$（或 $\zeta$ 与 $M,K_s$）、簧下质量 $m$（算 $\chi$ 时必需）、输入谱 $G_{zr}(f)$（与 $H$ **同频点**）。**缺 $m$ 时只能给"忽略非悬挂质量"的近似并显式声明**（该近似会把 10–12 Hz 的突起抹掉）。

**交付物与完成标准**：四个归一化参数表 + $|H_v|$ 的两端极限 + 一张"输入谱/增益/输出谱"三行对照 + 力通道的"不可算"声明。

1. **算四个归一化参数**
   - 完成标准：$K_1=K_s/M$（1/s²）、$K_2=K_t/M$（1/s²）、$C=C_s/M$（1/s）、$\chi=m/M$（无量纲）；逐个标单位。
2. **建 $H_v(\omega)$（只用式 5-14）**
   - 完成标准：写出表达式；给 $\omega\to0$ 与 $\omega\to\infty$ 两个极限并与"同动/隔掉"对上；量纲检查通过。
3. **谱相乘**
   - 完成标准：$G_{zs}=|H_v|^2G_{zr}$；RMS 处开方；**同一句声明"这是功率关系"**。
   - 判停：**若用户要"轮胎动载/接地性的传递函数" → 停**。按 B 段 G-1：式(5-15)(5-16) 损坏，$F_w/F_b$ 不可复现；只能给"有这个概念、没有这个算式"。
4. **判图/判曲线归属**
   - 完成标准：若引用图 5.16，先声明"这是三条定义中的哪一条"（对路面 1 / 对车轴力 0 / 对车身力 1 的低频极限）；三条不可互算。
5. **反推（可选）**
   - 完成标准：由实测谱的峰位与峰宽反读 $|H_v|$ 的峰位与 $\zeta$，并声明"路面谱单调 ⇒ 峰来自传递函数"这一前提。
6. **交付**
   - 完成标准：一句话"该参数下 $|H_v|$ 在 … Hz 达峰 …（或：峰高按 ζ 估计 …），输出谱 = 输入谱 × …²；力通道本章不可算"。

**计算约定（原书未规定，本卡设定）**：$\omega$ 用 rad/s、$f$ 用 Hz（$f=\omega/2\pi$）；$|H|$ 保留 3 位有效数字；PSD 倍数保留 2 位；峰值增益公式标"本卡约定（非原书）"；中间量不提前舍入。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **不要算力通道**（G-1，硬缺口）。式(5-15)(5-16) 不可读、不许自行补全；需要 $F_w/F_b$ 只能回查英文原版 p132 或由式(5-12)(5-13) 重推——**后者已不是"原文提取"**，须标"重推"。图 5.16 后两条曲线只能核形状，不能取数。
- **不要用线性谱相乘解释非线性悬架、离散冲击或轮胎包络**（ce06）。式(5-17) 的前提是 $H$ 与输入幅值无关；5.2.7 自证叶片弹簧小振幅有效刚度可达名义值 3 倍（极端一个数量级）⇒ $H=H(\text{幅值})$，谱相乘在这个系统上**没有定义**（不是精度问题，是合法性问题）。
- **不要把单自由度（车身挂在 $RR$ 上）当成本卡**（ce11）。丢掉 $m$ 就丢掉了 hop 峰、"200% 阻尼时车身在轮胎上 3–4 Hz 共振"、以及簧下质量这个唯一的纯收益杠杆。
- **不要把三条不同定义的增益混算。** 对路面输入的增益低频 →1；对车轴力输入的增益零频 →0（车轴力被轮胎弹性吸收）；对车身直接力的增益高频 →1。混用会得出"零频处车身加速度等于车轴力"这种量纲上就错的结论（g24）。
- **不要把 $|H|^2$ 写成 $|H|$。** PSD 与 RMS 差一次开方，与幅值差一次平方；口径错一处差一倍到四倍。
- **不要在 $H_v$ 与 $G_{zr}$ 不同频点时相乘。** 漏掉 $f=\nu V$ 会让整条输出谱错位（这是"换了个车速，谱就整体挪走"的常见事故）。
- **不要把本卡的结论外推到俯仰/侧倾。** 四分之一车辆模型在结构上**排除了**俯仰与侧倾（g18）；轴距滤波与双模态必须转另外两张卡。

### 作者在书中警告的失败模式

- p129：把"传递率"用于非线性系统（原文："尽管此术语一般专门用于线性系统"）。
- p133：把随机输入下的"单一传递率"当常数用——原文要求用 PSD 比或 $|H|^2$。
- ce06（p141–142）：用一条固定 $H$ 跨越平路与烂路外推，符号都可能反。

### 作者的盲点 / 时代局限

- **线性粘性阻尼未声明**（式 5-12/5-13 用 $C_s\dot Z$），而 5.2.4 末自证减振器是非线性阀 + 卸荷 + 压缩/回弹 1:3 ⇒ 线性化只在"小振幅、单一频率"下勉强成立。
- **轮胎只给刚度**：无阻尼、无包络（无"enveloping"概念），短波路面输入被系统性高估。
- **章内逻辑冲突**：5.2.1–5.2.6 建立在线性上，5.2.7 证伪，5.2.8–5.2.10 又回到线性刚体模型。凡引用式(5-17) 的结论，都必须连带声明这个冲突。
- **41 张图全是 PNG 占位**：图 5.16/5.17 的曲线读数一律为零，本卡不得凭图给数。

### 容易混淆的邻近方法论

- **$RR$（串联，跳动）vs $K_t+K_s$（并联，hop）**：同一对弹簧，两种模态连接方式相反；本卡的两个方程正好各用一种，抄错一处频率就错 5% 以上。
- **$H_v$（复传递函数，仅线性）vs 传递率（幅值比，任何系统）vs 增益（泛称）**：三个词在本章各有定义，混用会让"能不能用于非线性"这一判断失效（g24）。
- **$G_{zs}$（输出加速度谱）vs $G_{zr}$（输入加速度谱）**：后者是"路面加速度"而不是"路面位移谱"，两次微分已在定义里做过；再除一次 $(2\pi\nu V)^2$ 会把高频压回去。
