# Olley 四准则与动态指数：一张能落到设计动作的校核清单，也是一张只准筛不准定的清单

## R — 原文 (Reading)

> **原书要点**（5.2.9 节，p148）：奥利准则的第一条可写成两种等价说法：其一，令前轴的乘适刚度比后轴低 30%；其二，把弹性中心放在重心之后、距重心 6.5% 轴距处。
>
> **原书要点**（p149）：车辆对路面输入的响应会随行驶速度、凸包几何形状而变化，所以前后悬架固有频率之比取多少最合适，无法只靠理论导出，须借助实测标定。

## I — 方法论骨架 (Interpretation)

一句话：**Olley 把"调校"压缩成四条可打勾的检查项，物理依据只有一条——人对跳动比对俯仰更能忍，所以让后悬架先动、把激励"翻译"成纯跳动；但四条既不独立、也不等价，作者自己在段末就把它降级为"起点"而不是"答案"。**

- **四条原文**：① 前乘适刚度比后**低 30%**，或弹性中心在重心后 **6.5% 轴距**；②（**原文编号与句首缺失**，内容为 $DI\approx1$）；③ 前后频率均**不超过 1.3 Hz**（⇒ 有效静挠度须**超过 6 in**）；④ 侧倾频率应**大致等于**俯仰与跳动频率。
- **方向必须记死**：是"**前乘适刚度低 30%**"（前软后硬），不是"前硬后软"。原文紧接一句"这不一定能把前后固有频率定死，但轿车前后配重接近各半，「后悬架频率比前边」高"——**方向写反，四条全反。**
- **两种表述不等价**（这是最容易被当成"两条硬约束"的地方）：按 $K_rc=K_fb$ 复算，$RR_f=0.7RR_r$ ⇔ 弹性中心后移 **8.8%** 轴距；反过来"后移 6.5%L" ⇔ 前刚度只低 **23%**。原文用"或"连接，应读作**同一意图的两种近似**，不是两条必须同时满足的约束（同时满足会自相矛盾）。
- **四条互相不独立**：①与③通过 $RR$ 互相牵连（降前簧同时改 $f_f$）；③的 1.3 Hz 与"6 in 静挠度"是同一个条件的两种写法（6 in ⇒ 1.275 Hz）；②"$DI\approx1$"与"现代车轮靠近底盘两端"是同一件事的两种说法，原文的措辞是"通常这个条件可以满足"（**描述现状**，不是要求）。所以"4 条过 3 条"并不比"过 1 条"更有信息量。
- **证据等级**：1930 年代、**一辆可调 $k^2$ 的改装车**、**Olley 单人主观判断**、**无统计样本**，作者自己把适用范围限定为"至少对低频，刚体模态振动"。所以本卡称它**经验法则**，不称定律。
- **动态指数**：$DI=k^2/(bc)$，$k$ 为俯仰回转半径。$DI=1$ ⇔ 前后悬架互为**共轭打击中心**（一个悬架的输入对另一个没有反作用）⇔ 振动中心落在车轴处。$DI$ **对载荷敏感**：装货会改 $b,c$，从而改 $DI$；例 2 的整张表在**固定 $DI=1.05$** 下扫描，那是假设。
- **四种组合的判定**（p149）：$DI=1$ 单独、$\beta=0$ 单独、$DI>1$、两者同时满足——其中"$\beta=0$ 完全不耦合"导致运动不规则、乘适性变差；"$DI=1$ 且 $\beta=0$"则跳动与俯仰频率相等，**较难预测**。两个想当然（"完全解耦是好事""频率相等是好事"）都被推翻。

## A1 — 应用示例 (Application Example)

### 示例 1：用例 5.2.2 的 Mustang 实测点跑四准则（原书数据 + 复算）

- **类型与来源**：**原书数据 + 复算**（$RR$ 与频率来自例 5.2.2，p134；四准则来自 p148；$DI$ 取 1.1 见例 5.2.11-1）。原文未把两者放在一起跑清单，这一步是本卡的执行演示。
- **输入**：$RR_f=127.8$、$RR_r=92.3$ lb/in；$f_f=1.142$、$f_r=1.111$ Hz；$DI=1.1$；侧倾频率无数据。
- **方法的使用**：① 比 $RR_f$ 与 $0.7RR_r=64.6$；② 比 $DI$ 与 1（原文容差 ±10%）；③ 比两个频率与 1.3 Hz；④ 查侧倾频率。
- **结论/结果（复算值）**：
  - ① **不通过**：$127.8$ vs $64.6$，前比后**硬 38%**，与"前低 30%"完全反向（这正是 c01 指出的反面配置：前后频率 1.142/1.111 几乎相等）。
  - ② **通过**：$DI=1.1$ 在 ±10% 内。
  - ③ **通过**：$1.142$、$1.111$ 均 ≤1.3 Hz（对应静挠度 6.22 / 7.65 in，均 >6 in）。
  - ④ **待测**：侧倾频率无数据，不得填"通过"。
  - **输出**：2 通过 / 1 不通过 / 1 待测，动作＝**降前簧**。
- **修正后的自洽校验**：把前簧降到 $0.7\times92.3=64.6$ lb/in（−54%），$f_f$ 会落到 $0.159\sqrt{64.6\times386/957}=0.815$ Hz——**低于 1 Hz 且远低于后轴**，说明"直接照 30% 硬套"会把前悬架调到不现实的软度；实践中通常取"降 30% 的刚度差"与"频率比 ≤1.3"之间的折中（原文也承认"不能明确决定前后固有频率"）。

### 示例 2：一辆自造车的四准则（合成演练，非书中事实）

- **类型与来源**：**合成演练**。自造车 O1：$RR_f=130$、$RR_r=150$ lb/in、前/后单轮荷 900/800 lb、$L=110$ in、$DI$ 未提供。
- **方法的使用**：① $0.7RR_r=105$ vs $130$；② $DI$ 待测；③ $f_f=0.159\sqrt{130\times386/900}$、$f_r=0.159\sqrt{150\times386/800}$；④ 侧倾频率待测。
- **结论/预期输出**：$f_f=\mathbf{1.187}$ Hz、$f_r=\mathbf{1.353}$ Hz。① 不通过（前比后硬 24%）；② 待测；③ **不通过**（$f_r=1.353>1.3$，对应静挠度 5.33 in <6 in）；④ 待测。**输出**：1 通过 / 2 不通过 / 2 待测。**动作必须联合求，不能各给各的**（这正是"四条不独立"的实证）：先定后簧 → 降 $RR_r$ 到 **≤138.5** lb/in（$f_r\Rightarrow1.300$ Hz ✓）；再按①回算前簧上限 $=0.7\times138.5=\mathbf{96.95}$ lb/in（$f_f\Rightarrow1.025$ Hz ✓）。**注意 105 不是答案**：若后簧已降到 138.5、前簧只降到 105，则 $105>0.7\times138.5=96.95$，①**仍不通过**（偏硬 8.3%）——只降前簧不降后簧才会得到 105 这个数（那时后簧 150、$0.7\times150=105$）。两个动作的先后顺序会改变答案，必须按"后簧先定、前簧回算"执行。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 做前后悬架匹配校核，要一张"通过/不通过"清单与修改方向。
2. 问"前簧该比后簧软多少""6.5% 轴距是什么意思"。
3. 问"$DI$ 是什么、等于 1 有什么好处"。
4. 评审一份调校方案，要判断它是不是只在抄 Olley 的四条。
5. 问"Olley 准则还成立吗/能不能当标准用"。

### 语言信号（中英双写）

- 「Olley 准则」「欧雷准则」「前软后硬」「前后频率比」「6.5% 轴距」「弹性中心」「动态指数」「DI」
- 「调校校核清单」「改装该动哪根簧」「optimize ride」「pitch inertia」「共轭打击中心」「conjugate striking center」
- 「这套准则靠谱吗」「有没有统计依据」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `pitch-bounce-bimodal-and-centers`：本卡用**单轴频率比**与 $DI$ 做筛选；真实两模态频率、$\beta$、$Z/\theta$ 在那张卡。$DI=1$ 只是"共轭打击中心"这一个特例。
- 与 `ride-rate-and-bounce-frequency`：本卡的 ①③ 需要 $RR$ 与 $f_n$，由那张卡产出；本卡只做判定与给动作。
- 与 `travel-budget-and-damping-limits`：③ 的"静挠度 >6 in"与行程预算同源；能不能做到由那张卡判。
- 与 `wheelbase-filter-zeros`：本卡调的是"频率比"，那张卡说明同一个频率比在不同车速下会被几何重排（零点移动）。

## E — 可执行步骤 (Execution)

**必需输入**：$RR_f,RR_r$（lb/in）、$W_f,W_r$（单轮荷）、$b,c$ 或 $L$ 与重量分配、$k^2$ 或 $DI$、侧倾频率（可缺）。**缺 $DI$ 与 $k^2$ 时第 ② 条只能写"待测"**，不得默认 1.0。

**交付物与完成标准**：四行判定表（每条：数值 / 阈值 / 通过与否 / 依据）+ 修改动作（每条不通过给一个可执行的量）+ 证据等级声明。

1. **核方向（先做这一步）**
   - 完成标准：写出"前乘适刚度应比后**低** 30%"；若用户材料写的是"前硬后软"，**先纠正再算**。
2. **判①（刚度差）**
   - 完成标准：比 $RR_f$ 与 $0.7RR_r$；给出实际百分比差；若用"弹性中心后移 6.5%L"表述，必须同时给复算值（$RR_f=0.7RR_r$ ⇔ 后移 **8.8%L**；后移 6.5%L ⇔ 前低 **23%**），并声明"两者是同一意图的两种近似，不等价"。
3. **判②（$DI$）**
   - 完成标准：$DI=k^2/(bc)$；与 1 比（原文容差 ±10%）；缺数据写"待测"。
   - 说明：$DI=1$ ⇔ 共轭打击中心 ⇔ 振动中心在车轴处；$DI>1$ ⇔ 有较长前/后悬。
4. **判③（频率上限）**
   - 完成标准：$f_f,f_r$ 均 ≤1.3 Hz；同时给静挠度（>6 in）作为等价表述；两者必须一致（6 in ⇒ 1.275 Hz）。
5. **判④（侧倾频率）**
   - 完成标准：侧倾频率与跳动/俯仰频率"大致相等"；缺数据写"待测"，**不得**用"通常满足"填通过。
6. **给动作（每条不通过一条动作）**
   - 完成标准：动作必须是可执行的量，且**联合求得**（先定后簧到 ≤138.5 lb/in，再由 $RR_f\le0.7RR_r$ 回算前簧 ≤96.95 lb/in；不许把 105 当答案，那是后簧未动时的数）；并说明动作会同时改变哪几条（因为四条不独立）。
7. **声明证据等级（强制）**
   - 完成标准：一句话"这是 1930 年代单车 + 单人主观 + 无统计样本的**经验法则**，适用域为低频刚体模态；原文结论是'最佳频率比要由实验确定'，本清单只能筛、不能定"。

**计算约定（原书未规定，本卡设定）**：$RR$ 保留 1 位小数；频率 3 位小数；百分比 1 位；中心位置用 %L 保留 1 位；判定只用"通过/不通过/待测"三态，不设"部分通过"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **不要把四条当定律打分**（ce13）。它们是经验法则；"4 条过 3 条"因四条不独立而没有额外信息量。凡写成评审表并算总分，都是越界。
- **不要用在高频、冲击或结构模态问题上**（ce13）。原文限"至少对低频，刚体模态振动"；拿它治 10–20 Hz 的振动毫无依据。
- **不要把"低 30%"与"后移 6.5%L"当两条硬约束同时满足。** 二者⇔关系是 8.8% vs 23%，同时满足会推出矛盾。
- **不要把 ① 读成"前硬后软"**（第 1 条硬伤）。方向反了，四条全反。
- **不要默认 $DI=1$**。$DI$ 对载荷敏感；例 2 固定 1.05 是**假设**。也**不得**把 $DI$ 读成"动载系数/动态系数"（g32）。
- **不要把"完全解耦（$\beta=0$）"当目标**（p44）。原文：完全不耦合 ⇒ 运动不规则、乘适性变差；$DI=1$ 且 $\beta=0$ ⇒ 频率相等 ⇒ 较难预测。
- **不要在没有车速与路面信息时给"最佳频率比"**。原文末句明说"要由实验确定"。
- **不要把 ⑥ 的"侧倾频率"与"侧倾中心"混为一谈**。侧倾中心是横向平面内的几何点，**本章全文未出现**。
- **不要用本卡结论替代舒适性判定**。四条只保证"低频刚体模态的分配合理"，本章判据端无数值限值。

### 作者在书中警告的失败模式

- ce13（p148–149）：把准则当定律、丢掉"至少对低频"与"要由实验确定"。
- p148：①"不能明确决定前后固有频率"——即 30% 只是起点，不是充分条件。
- p149：$\beta=0$ 与 $DI=1$ 同时满足是最难预测的组合（推翻"解耦=好"的直觉）。

### 作者的盲点 / 时代局限

- **证据等级未标注**：作者称它"仍然是现代汽车设计的经验方法"，但没有标注"1930s 单车单人"的证据等级——这一条由 BOOK_OVERVIEW 的阶段 0 批判补上。
- 四条只覆盖纵向平面；侧倾只给"频率应大致相等"，无侧倾刚度/力矩分配（属第 6/7 章）。
- $DI$ 与载荷的耦合只在一张表里以固定 $DI$ 的方式处理，未讨论"装货后重新匹配"的实际问题。
- 现代车（前置前驱、电池包、低扁平比胎、副车架）的 $k^2$、$b,c$ 分布与 1930s 完全不同，30% 这个数没有更新依据。

### 容易混淆的邻近方法论

- **$DI=k^2/(bc)$（几何/惯量）vs 动载系数（轮胎动载/静载）**：同缩写不同义；本章 $DI$ 只说"前后悬是否互为共轭打击中心"（g32）。
- **Olley ①（刚度差 30%）vs ③（频率 ≤1.3 Hz）**：一个是前后**相对**分配，一个是**绝对**上限；降前簧会同时改善①、也会拉大与③中后轴的关系，两者必须同看。
- **弹性中心（$\beta=0$）vs 侧倾中心 vs 运动中心**：三个"中心"分属纵向平面、横向平面、模态虚拟转轴；本章没有侧倾中心（g30）。
