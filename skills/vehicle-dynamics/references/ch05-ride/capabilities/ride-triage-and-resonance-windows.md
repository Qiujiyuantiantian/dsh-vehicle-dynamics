# 乘适性分诊：先归到「输入—传递—判据」三段，再用频率窗判共振命中

## R — 原文 (Reading)

> **原书要点**（5.1 节开篇，图 5.1，p116）：引起车辆振动的激励不止一处，大体可归为两类：一类来自路面起伏，另一类由车上部件产生。后者又集中在旋转件上，例如车轮与轮胎总成、传动系以及发动机。
>
> **原书要点**（5.4 节结论，p157）：容易误以为乘适性工作的目标是让车辆一点振动都不剩，这对汽车做不到，而且也不该这样要求。驾驶员正是靠车身振动获得路面信息，这是其判读路况的主要来源。

## I — 方法论骨架 (Interpretation)

这张卡**不产出数**，它决定"该用哪张卡算"。骨架三句话：

1. **全章只有一条链：输入 → 传递 → 判据。** 输入＝路面（外部 1 类）+ 轮胎/车轮、传动系、发动机（车上 3 个旋转件）；传递＝四分之一车辆 → 刚体双模态 → 非线性 → 主动；判据＝人体容许界限。归错段，后面每一步都白算：拿 Olley 准则去治 20 Hz 的方向盘麻手，改前簧什么也不会变。
2. **归段的依据是频率，不是症状词。** 用户说的是"颠""晃""麻手""发飘"，这些词在三个不同的段里。要先把工况换成频率：激励窗＝波数窗 × 车速（0.005–0.5 cyc/ft，即某些车速下 0.37–36.7 Hz）；车身刚体窗≈1–1.5 Hz（双模态时 1.07–1.13 Hz 一对）；hop 窗 = 10–12 Hz（含悬架摩擦 12–15 Hz）；内部阶次是**随车速移动的线族**（$f=nV/2\pi r$、点火频率、主减速比阶），不是固定频率。
3. **归段的交付物是一张预算表，不是一个结论。** 三列必须同时写：可改的频段（对应哪张卡）、改不动的（受行程或"反作用点"锁死）、**模型里根本没有的通道**（转向盘、驾驶室颤动、噪声、视觉）。第三列是本章的自我否定：5.2 全部输出只有"车身垂直加速度"一个量，而 5.3 的实测说转向盘与驾驶室颤动权重更高。

由此得到本卡的**目标函数口径**：乘适性的目标是"谱的形状"，不是"振动总量最小"。理由不是审美，而是作者自己给的两条：消除一个振动会暴露下一个（掩蔽），且振动是驾驶员感知路面的主要信息通道——把 0.5–2 Hz 的路感压掉，账面上 RMS 下降，车上人却说"没底"。

## A1 — 应用示例 (Application Example)

### 示例 1：60 mph 抱怨"车晃"——归到输入段的侧倾通道（原书引用数据 + 复算）

- **类型与来源**：**原书引用数据**（5.1.1 末，p119–120，算例 c04）。原文给"侧倾固有频率 1.0 Hz、60 mph 时该波长的侧倾幅值仅为垂直的 10%"，未给中间步骤。
- **输入/问题**：车速 60 mph 的"晃"，是侧倾模态被激起，还是别的段？
- **方法的使用**：① $V=88$ ft/s；② $f=\nu V$ 反解 $\nu=f/V=1.0/88=0.0114$ cyc/ft（原文取 0.011）；③ 该波数落在"长波端"，查图 5.4 的归一化侧倾/垂直比 → 约 10%。
- **结论/预期输出**：归段＝**输入段（轮辙差值通道）**，不是 Olley、不是阻尼。动作＝查轮辙相干性/路面长波成分，而不是调前簧。同一算例在 6 mph 时 $\nu=1.0/8.8=0.114$，比值≈100%——**同一个侧倾模态，高速几乎激不起来、低速与垂直输入相当**，这就是 4×4 "低速晃、高速颠"的分诊结论。

### 示例 2：90 km/h 方向盘麻手——归到内部阶次段（合成演练，非书中事实）

- **类型与来源**：**合成演练**（工况与数字为自造，规则取自 f16 的 V2 纸面走查：车内 44 Hz 峰 / 车轮 12 Hz 转频）。
- **输入/问题**：车内 44 Hz 峰，车速对应车轮转频 12 Hz；用户只描述"方向盘麻手"。
- **方法的使用**：① 判该峰是否随车速同步移动（是 ⇒ 旋转件，不是路面）；② 阶次 $n=44/12=3.7$；③ 与主减速比对照（该货车实测 3.7×，通用值是主减速比及其二阶 7.4×）；④ 归段＝内部输入段（传动系一阶），传递段高频端（hop 以上）。
- **结论/预期输出**：归到"传动系不平衡/万向节"诊断（卡 `onboard-excitation-orders`），**不是** Olley、不是跳动频率；若峰在 148 Hz 同为 $7.4\times$ ⇒ 二阶（万向节）。若用户接着说"平路也麻" ⇒ 排除路面源，进一步确认为车上源。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 用户给一句主观抱怨（"高速发飘""过坎顶到底""方向盘麻手""低速晃"），要判断这是哪一类问题、该改哪里。
2. 手上有一张实测频谱（或一段描述），要判断峰是谁、属于哪一段。
3. 拿到了一个"舒适性提升方案"，要判断它在哪一段起作用、有没有漏掉某个通道。
4. 要决定"下一笔钱花在弹簧、减振器、轮胎、悬置还是转向盘隔振上"。
5. 被问到"这车为什么高速反而比低速舒服"（或反过来）。

### 语言信号（中英双写）

- 「车颠/晃/抖/麻手/发飘」「过减速带顶到底」「某个车速才抖」「高速反而舒服」「该改哪里」
- 「ride comfort 怎么排查」「which frequency」「road input or vehicle」「NVH 分诊」「先看什么」
- 「这个峰是什么」「44 Hz 是哪来的」「为什么换了减振器没用」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `road-input-spectrum-and-track-split`：本卡只判"要不要进输入段"，换算与 $V^2$ 倍数由那张卡算。
- 与 `ride-rate-and-bounce-frequency`：本卡判"是不是低频刚体问题"，频率与静挠度由那张卡算。
- 与 `wheel-hop-and-unsprung-mass`：本卡判"是不是 10–12 Hz"，hop 频率与簧下质量敏感性由那张卡算。
- 与 `onboard-excitation-orders`：本卡只判"是车上旋转件"，阶次定位与悬置规则在那张卡。
- 与 `human-limit-and-spectrum-presentation`：本卡判"要不要进判据段"，判据段本身在本章**无换算尺**，只能给形状与出处。

## E — 可执行步骤 (Execution)

**必需输入**：① 工况（车速 mph 或 km/h、路面类型/好坏、是稳态还是过坎）；② 症状描述（部位：座椅/地板/转向盘/后视镜；时域特征：持续/某车速才出现/冲击）；③ 若已有频谱，给峰频与对应车速。**缺车速不得开算**——本章所有频率都通过 $f=\nu V$ 与车速绑定，没有车速就没有频率窗。

**交付物与完成标准**：一张三列表（可改频段 / 改不动 / 不在模型内）+ 一句归段结论 + 一句"该用哪张卡"。

1. **把症状换成频率**
   - 完成标准：每个症状至少给一个频率或频率区间，并注明来源（实测峰 / $f=\nu V$ 反算 / 阶次 $n\times$ 转频）。无法换成频率的症状单列"无法归段"。
2. **套频率窗**
   - 完成标准：写出四个窗并逐一对撞——激励窗（0.005–0.5 cyc/ft × $V$）、刚体窗（1–1.5 Hz）、hop 窗（10–12 Hz，含摩擦 12–15 Hz）、内部阶次（$nV/2\pi r$、点火频率、主减速比阶）。
   - 判停：若主频 **>25 Hz 或属车身结构模态** → 停，声明本章不覆盖（5.2 只在开头一句提到"还要关注结构模态"）。
3. **判"命中"并给方向**
   - 完成标准：写出"哪个模态窗与激励窗重叠"，并声明这是**方向判断**——原文没有"多模态同时被激"的定量叠加法，不得输出加权合成谱。
4. **列预算三列**
   - 完成标准：①可改（对应卡号）；②改不动（写明是行程锁死还是反作用点锁死）；③不在模型内（转向盘/驾驶室/噪声/视觉，逐项点名，引用 5.3.2 的五通道实测）。
5. **写目标口径**
   - 完成标准：一句话写明"目标是谱形整形，不是 RMS 最小"，并点出必须**保留**的频带（0.5–2 Hz 的路感频带）。

**计算约定（原书未规定，本卡设定）**：频率保留 1 位小数（Hz）；阶次保留 1 位；区间端点四舍五入到 0.1；所有换算先统一到 ft/s（mph×1.467、km/h×0.9113）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **不要把它当"舒适性判定器"。** 归段只回答"问题在哪一段"，不回答"能不能接受"——本章人体判据端**没有任何以 m/s² 或 g 表示的数值限值**（ce01 / ce08）。
- **不要把"降低座椅垂直 RMS 加速度"当分诊的目标函数**（ce01，Healey 反证：简单 RMS 与任何加权组合同样好 ⇒ 加权这个动作本身未被验证）。分诊的输出是"哪一段"，不是"降了多少 dB"。
- **不要只测座椅垂直一个通道就下结论**（ce02）。5.3.2 的十人五通道实测里，**转向盘与驾驶室颤动**才是拉低评分的主因（尤其二、三阶谐量），而这两个通道在 5.2 的模型里根本不存在。
- **不要把"消掉某个振动"当成功**（ce03，p157 原文）。掩蔽意味着"消一个、冒一个"，且 0.5–2 Hz 是路感反馈的来源；压掉它就是删掉驾驶员对路面的感知。
- **不要用 >25 Hz 的问题来调用本卡。** "0–25 Hz 分析带宽"只是图 5.16/5.18/5.19 的横轴右端（图 5.17 到 100 Hz、图 5.37 到 30 Hz），**不是作者给的定义**；更不得据此编造">25 Hz 归噪声"的数字判据（原文只有 p124 一句定性）。
- **不要在没有车速的情况下归段。** 同一个振动在 60 mph 与 6 mph 属于不同段（侧倾输入比 10% ↔ 100%），车速缺失时任何段归属都是猜。

### 作者在书中警告的失败模式

- ce03（p157）：把"消除振动"当目标，会导致消除一个暴露下一个，并删掉路感。
- ce01/ce02（p155–157）：用座椅 RMS 当唯一 KPI、或用单通道代表乘员感受，都是作者用反证数据直接否定的做法。
- p157 的问句效应（ce20）：连"你问的措辞"都会改变主观分——所以任何"客观量 ↔ 主观感受"的映射在分诊阶段都不成立。

### 作者的盲点 / 时代局限

- **模型只有一个输出量**：5.2 全线输出"车身垂直加速度"，而 5.3 说人评的是多通道；这个矛盾被并列陈述而非解决（BOOK_OVERVIEW §3）。
- **离散冲击缺席**：全章把路面当平稳随机输入，而投诉主体是坑洞/减速带/接缝（唯一例外是 5.2.8 图 5.35 的凸起响应，仍回到频域）。分诊遇到">过坎顶到底"必须转行程预算卡，不能用本卡收尾。
- **货车视角**：最厚的数值证据都是货车；乘用车读者会低估车身模态、座椅系统、转向盘通道。

### 容易混淆的邻近方法论

- **"归段" vs "定位"**：归段只到"输入/传递/判据"三段与四个频率窗；具体是哪个零件，必须进对应卡（阶次、hop、行程）才能定位。
- **激励窗 vs 模态窗**：一个是输入侧（cyc/ft × V），一个是车辆侧（Hz）。把两者当同一张图叠比，是全章最常见的错位（g05）。
- **"频段重要" vs "面积大"**：判"哪个频段值得改"必须在线性-线性坐标下看面积；双对数图上目测面积会系统性偏向低频（ce10）。
