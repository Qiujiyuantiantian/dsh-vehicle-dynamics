# 决策规则速查 — 《车辆动力学基础》第 1 章 绪论

| 能力 | 一句话规则 |
|---|---|
| 静态轴荷与重心纵向位置：$W_{fs}=Wc/L$、$W_{rs}=Wb/L$ 的双向换算（b = 前轴→重心） | 先锁方向（b = 前轴→重心、c = 重心→后轴）→ $b=L\,W_{rs}/W$、$c=L-b$ → 三条自检（和=W、b+c=L、反代回读数）；只有总重与轴距时不得反求。 |
| 动态车轴载荷一般式：对另一轴接地点取矩、六类力清点、退化表与求和自检（式 1-5 惯性项取 +） | 对另一轴接地点取矩 → 六类力逐一清点（重力/惯性/支撑/牵引与滚阻/风阻/拖钩）→ 代入 (1-4)(1-5)，惯性项在 $W_r$ 取 **+** → 用 $W_f+W_r=W\cos\theta+R_{hz}$ 收尾；缺 $h_a/d_h$ 记信息不足，不得默认 0。 |
| 加速/减速的轴荷转移：$\Delta W=W(a_x/g)(h/L)$ 一个量管两轴，减速不另立公式 | $\Delta W=W\,(a_x/g)\,(h/L)$ → $W_f=W_{fs}-\Delta W$、$W_r=W_{rs}+\Delta W$ → 水平路面必验 $W_f+W_r=W$；有坡/拖挂/高速任一出现即转一般式。 |
| 坡道轴荷与坡度换算：$i=\tan\theta$ 先换弧度，再算 $\Delta W'=W\theta(h/L)$（小角度式与精确式并列） | $i\to\theta=\arctan i$（同时给度与弧度，代入用弧度）→ $\Delta W'=W\theta h/L$ @ 前减后加 → 小角度式与精确式并列，差值归因到 $\cos\theta$；式(1-10) 右端写 $W_{fs}$。 |
| 排障：坡上两轴载荷之和小于总重（$W_f+W_r=W\cos\theta+R_{hz}$ 三档判据） | 算 $S_{exp}=W\cos\theta+R_{hz}$ 与 $S_{obs}=W_f+W_r$ → 差 $\approx W(1-\cos\theta)$ 判正常、$\approx 2(W/g)a_xh/L$ 判惯性项符号错、水平路面和 $\ne W$ 判必错。 |
| 拖挂爬坡：先拆两体解拖钩力，再用 $\mu W_{driven}$ 判驱动形式优劣（绝对百分比只作原书报告值） | 拆拖车两式解 $F_{xb}=W_b\sin\theta$、$F_{zb}=W_b[f\cos\theta+(h_2-h_3)\sin\theta]/L_t$（θ=0 须回到题给拖钩载荷）→ 带回汽车三式（4 方程 4 未知量）→ 令 $(W+W_b)\sin\theta=\mu W_{driven}$ → 只给排序与"附着受限上限"，绝对值给"报告值 + 重建值"两列。 |
| 建模入口三连：选自由度（单质量 / 两质量）→ 自由体（清点接触点）→ 核对假设 | 求解量是否依赖车身—车轮相对运动 → 单/两质量；逐接触点清点力（重力/接地/气动/拖钩）；未知量数 = 方程数；假设逐条 ✓/✗ 并点名被删项。 |
| 符号与力矩正方向校核：法向力向下、垂直力向上，取矩前先声明往哪边转 | 四行校核：z 向下 → 向下=法向力、向上=垂直力（$W_f$、$W_r$ 取正）→ 每个取矩式单独声明正方向（整式乘 −1 才等价）→ 角速度按轴不按字母（绕 x=侧倾 p）。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
