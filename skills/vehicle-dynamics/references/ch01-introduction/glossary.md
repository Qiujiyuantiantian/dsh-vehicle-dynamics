## 0. 三条硬约定（下游 skill 必须逐条引用）

1. **坐标系统一是 SAE**：x 向前、y 向右、**z 向下**；绕 x 侧倾、绕 y 俯仰、绕 z 横摆；原点在重心，随车运动。
2. **力名系统一是 SAE J670e**：**向下的力叫"法向力"，向上的力叫"垂直力"**（与其他国家标准相反）。见 §3.1。
3. **本章 $b$、$c$ 的方向与很多文献相反**：$b$ = **前轴到重心**，$c$ = **重心到后轴**，$L=b+c$。见 §3.3（含三条内部验证）。

> 单位制：本章**全英制**——力 lb、长度 in、加速度 ft/s²（$g=32.2$ ft/s²）、转动惯量 $\text{in}\cdot\text{lb}\cdot\text{s}^2$。
> ⚠️ 标记规则：凡标 ⚠️ 者，是 OCR 残缺 / 印刷不自洽 / 与他书冲突之处。

## 3. 易混对照（本章最高价值部分）

> 本章最容易出的错不是"不懂定义"，而是"两个像的东西拿错了一个"。每组给出：差别在哪 + **现场判别法**。

### 3.1 法向力 vs 垂直力（SAE 命名，方向相反）

| | 法向力 normal force | 垂直力 vertical force |
|---|---|---|
| 正方向 | **向下** | **向上** |
| 物理内容 | 重力、车轮对地面的压力、气动下压力 | 轮胎对车身的支撑力（= 车轴载荷 $W_f$、$W_r$） |
| 符号角色 | 在 (1-4)(1-5) 中不直接出现（$W$ 本身按向下计） | $W_f$、$W_r$ 取**正值**（向上） |
| 常见错误 | 把轮胎支撑力叫"法向力"（因为几何上确实垂直于路面） | 把"垂直力"当"竖直方向力"的泛称 |

**判别法**：看箭头，不看词。向下 → 法向力；向上 → 垂直力。
**⚠️ 本章的用词陷阱**：1.4 第 (3) 条说"轮胎承受**沿路面法向方向**的作用力，分别为 $W_f$ 和 $W_r$"——这里的"法向"是**几何**意义（垂直于路面），而 SAE 命名的"法向力"指**方向向下**。两处"法向"含义相反，所以 $W_f$、$W_r$ 按 SAE 命名属于**垂直力**（向上），这也是它们在 (1-4)(1-5) 里取正号的原因。
**跨文献警告**：原文明确"在其他国家，这些规则会有所不同"。从德/日标准文献抄公式，第一件事就是查正方向。

### 3.2 β（侧滑角）vs α（轮胎侧偏角）vs α_x（角加速度）

| 符号 | 名称 | 层级 | 夹的是哪两个方向 | 本章有无 |
|---|---|---|---|---|
| β | 侧滑角 sideslip | **整车** | 车辆速度向量 ↔ 车身 x 轴 | ✅ 1.3.4 有定义 |
| α | 轮胎侧偏角 slip angle | **轮胎** | 车轮平面 ↔ 车轮速度向量 | ❌ 本章未出现（第 10 章） |
| $\alpha_x$ | 绕 x 轴角加速度 | 刚体 | ——（是角加速度，不是角） | ✅ 式 (1-2) |

**判别法**：与 ψ、ν、X 轴一起出现、无下标 → **β**；与 $F_y$、侧偏刚度 $C_\alpha$ 一起出现、有轮胎下标 → **α**；出现在 $I_{xx}$、$T_x$、$\Sigma T$ 旁边、带下标 x → **$\alpha_x$**。
**为什么容易错**：β 与 α 量级相近（都是几度），公式形式相似。混用后果：整车侧偏刚度与轮胎侧偏刚度的单位/量级对不上，稳态转向梯度 K 会差一个数量级。

### 3.3 b vs c（本章方向与多数文献相反 —— 已用三条内部证据锁定）

| | 本章（Gillespie 中译本，第 1 章） | 很多其他文献 |
|---|---|---|
| b | **前轴 → 重心** | 重心 → 后轴 |
| c | **重心 → 后轴** | 重心 → 前轴 |
| L | $L=b+c$ | $L=b+c$ |
| 对应公式 | $W_{fs}=Wc/L$；$W_{rs}=Wb/L$ | $W_f=Wb/L$；$W_r=Wc/L$（互换） |

**三条内部验证（任一条都足以判定，建议当场算一遍）**：

1. **取矩点**：1.4 明说"对**后**轮胎下方 A 点的力矩平衡"求**前**轴载荷，力臂就是 A 到重心的水平距离 ⇒ 前轴载荷 ∝ **重心到后轴**的距离 ⇒ 式 (1-6) 里的 $c$ = 重心→后轴 ✓
2. **例题 1 数值**：$b=L\,W_{rs}/W=109\times1322/3635=39.64$ in，原文紧接着写"即**前轴**距重心 39.64 in" ✓（前轴重 2313 > 后轴 1322，重心必然靠近前轴，$39.64<69.36$ ✓）
3. **例 3 的力矩式**：对**后**轴取矩的方程写成 $Wc\cos\theta$、对**前**轴取矩的方程写成 $Wb\cos\theta$，且前轴方程里拖钩力臂为 $(b+c+d)$ —— 只有 $b$ = 前轴→重心、$c$ = 重心→后轴时，$b+c+d$ 才等于"前轴到拖钩"的总距离 ✓

**判别口诀**：用 $W_{rs}=Wb/L$ 试一次。**$b$ 大 ⇒ 后轴重**。若某文献里"$b$ 大 ⇒ 前轴重"，那本书的 $b/c$ 与本章相反。
**下游动作**：从本章搬 (1-6)(1-7) 到别的书/别的章之前，先查该书的 $W_{fs}$ 表达式；不一致就整组互换，不要只换一个。

### 3.4 坡度 % vs 坡度角 °

| | 坡度 i（%） | 坡度角 θ（°） |
|---|---|---|
| 定义 | $i=\tan\theta$ = 上升高度 / 行驶距离（水平投影） | $\theta=\arctan i$ |
| 常见值 | 高速 < 4%；中等路面 10–12% | 6% → **3.433°** |
| 小角度关系 | $\theta(\text{rad})\approx i$（**弧度**，不是度） | $\theta(°)\approx i\times57.3$ |
| 例题 3 答案 | 10.18% / 11.42% / 19.44% | 5.84° / 6.51° / 11.0° |

**换算锚点**：4% → 2.291°（0.03998 rad）；6% → 3.433°（0.05993 rad）；10% → 5.711°（0.09967 rad）；12% → 6.843°（0.11943 rad）；20% → 11.310°（0.19740 rad）。
**⚠️ 书中一处舍入不严**：10.18% 的反正切是 **5.81°**，书中给 5.84°（= arcsin 0.1018；另两个 11.42%↔6.51°、19.44↔11.0° 是准的）。引用时以 % 为准，或标注"书中 5.84° 系 arcsin 舍入"。
**例题 2 的"载荷之和不等于总重"**——本章最著名的困惑，答案就在这一组里：$W_f+W_r=W\cos\theta=3246\times0.9982=3240$ lb < 3246 lb。不是算错，是坡度让**只有余弦分量**进入车轴载荷。

### 3.5 方向角 ψ vs 路径角 ν vs 侧滑角 β

| 符号 | 相对哪根轴 | 回答的问题 |
|---|---|---|
| ψ 方向角 | 车身 x 轴 ↔ 地面 X 轴 | **车头朝哪** |
| ν 路径角 | 速度向量 ↔ 地面 X 轴 | **车实际往哪跑** |
| β 侧滑角 | 速度向量 ↔ 车身 x 轴 | **车头与实际行进差多少** |

关系：$\nu=\psi\pm\beta$（符号取决于三者的正方向约定）。**⚠️ 本章没有写出这个关系式**，只给了三个定义与图 1.5（图注"侧滑角 β（所示为负角度）"）。下游若要写这个式子，必须回到"各自相对哪根轴"重新对符号，不要凭记忆。

### 3.6 符号复用冲突（同一字母两义 —— 本章的隐藏地雷）

| 符号 | 义一 | 义二 | 判别 |
|---|---|---|---|
| **θ** | 坡度角（1.4.3，显式使用） | 欧拉俯仰角（1.3.5，符号未印出，按 SAE 惯例） | 与 sinθ/cosθ、坡度、轴荷一起 → 坡度角；与姿态/坐标变换一起 → 俯仰角 |
| **ψ** | 方向角（1.3.4，x 轴 vs X 轴） | 欧拉横摆角（1.3.5） | 本章语境下数值常相同，但**定义基准不同**：一个是 x↔X，一个是绕 z 的旋转量 |
| **R** | $R_{hx}$、$R_{hz}$：拖钩力 | $R_{xf}$、$R_{xr}$：滚动阻力 | 带 h 下标 → 拖钩；带 x 下标 + 接地区 → 滚动阻力 |
| **h** | h：重心高度 | $h_h$ 拖钩高度、$h_a$ 风压中心高度、$h_1/h_2/h_3$ 例 3 三处高度 | 单写 h 且与 $Wa_x$ 或 $W\theta$ 相乘 → 重心高度；带下标 → 看下标 |
| **α** | $\alpha_x$：角加速度（式 1-2） | α：轮胎侧偏角（本章无，后续章有） | 见 §3.2 |
| **$W_f$ / $W_r$** | 动态载荷（随 $a_x$、$\theta$ 变） | 有人误当静态轴荷 | 见 §3.7 |

### 3.7 动态载荷 vs 静载荷（$W_f/W_r$ vs $W_{fs}/W_{rs}$）

| 例 2 数值 | 含义 |
|---|---|
| $W_{fs}=2047$ lb | 水平静止时的前轴静载荷 |
| $W_f=1892.2$ lb | 6% 坡 + 6 ft/s² 加速时的前轴**动态**载荷 |
| 差 155 lb | = 加速度项 114.1 + 坡度项 36.7 + $\cos\theta$ 项 3.7（合计 154.5，取位差 0.3），约占总重 4.8% |

**判别法**：带 s 下标（static）= 静止值，是常数；不带 = 动态值，是 $a_x$、$\theta$ 的函数。
**错误后果**：用 $W_{fs}$ 代替 $W_f$ 算爬坡能力，等于假设"上坡时载荷不转移"，FWD 会被**高估**（因为上坡卸载前轴）。

### 3.8 附着力 vs 牵引力

| | 附着力（adhesion limit） | 牵引力（tractive force, $F_x$） |
|---|---|---|
| 性质 | **上限**（能力） | **实际值**（需求） |
| 表达式 | $\mu\cdot W_{\text{驱动轴}}$ | $(W+W_b)\sin\theta$（例 3） |
| 关系 | 爬坡能力问题 = 令两者相等，解 $\theta_{max}$ | 超出上限即打滑 |

**易错**：把"附着力"当"驱动力"→ 会认为"驱动力越大爬坡越强"，忽略驱动力本身受轴荷限制。

### 3.9 操控 vs 转向 / 转弯 / 方向响应

| 词 | 层 | 度量 |
|---|---|---|
| 操控 handling | 客观 + 主观（双层） | 无单一指标 |
| 转向 cornering | 客观 | 稳态侧向加速度**幅值** |
| 转弯 turning | 客观（过程/几何） | 轨迹 |
| 方向响应 directional response | 客观 | 达到指定侧向加速度的**时间** |

**易错**：把"方向响应"当"转向灵敏度"（比值）——一个是时间，一个是增益，量纲都不同。

### 3.10 集中质量 vs 悬挂 + 非悬挂质量

| | 集中质量（单质量） | 悬挂 + 非悬挂（两质量） |
|---|---|---|
| 适用 | 加速、制动、大多数转向 | 乘适性（ride） |
| 是否含转动惯量 | **必须含**（否则式 1-2 不成立） | 各自含 |
| 忽略什么 | 部件间**相对运动** | 不忽略车身—车轮相对运动 |

**易错**：以为"集中质量 = 简单 = 不要转动惯量"。
