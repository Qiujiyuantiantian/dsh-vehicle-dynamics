## 基本信息

- **书名**：Fundamentals of Vehicle Dynamics 第 1 章 绪论（中译《车辆动力学基础》，赵六奇、金达锋译，清华大学出版社 2006；英文原版 1992）
- **作者**：Thomas D. Gillespie
- **原文范围**：p28–p41，20 条公式块，三个数值例题（例题 1 p37、例题 2 p37–38、例题 3 p38–40）
- **本章性质**：**奠基章，且一半是叙事**——1.1 学科史、1.2 经验 vs 分析几乎占一半篇幅，但它们不产出可执行能力（只贡献两条：核对假设、力的命名）；真正可执行的是 1.3 的坐标系与符号、1.4 的轴荷一般式与三个特例、1.5 的三个例题。

## 一句话主旨

**全书剩下的每一章都建立在这一章定下的三件事上：SAE 坐标系与符号规则、牛顿第二定律的自由体写法、以及「车轴载荷随加速度和坡度变化」——后者是所有附着力分析的入口。**

## 骨架（10 步）

1. **学科史很短也很晚**：1769 Cugnot 蒸汽三轮车 → 1886 汽油车 → 1908 T 型车；车辆动力学的力学解释要等 1931 年轮胎测力计问世之后才可能（此前缺轮胎力学知识）。
2. **"操控"是多义词**：转向（cornering）/转弯（turning）/方向响应（directional response）是车辆的**客观特性**；"操控"还包含反馈给驾驶员的**主观部分**。作者明确不打算统一术语，只按语境选用。
3. **经验 vs 分析**：经验法容易在"新情况"上整体失效；分析法能辨识重要因素，但**必须严格把握假设**，否则假设本身就制造错误。
4. **建模的第一步是选自由度**：加速/制动/多数转向 → 整车一个集中质量（在重心、**必须带转动惯量**）；乘适性 → 拆成"悬挂质量 + 非悬挂质量"。
5. **SAE 坐标系是硬约定**：x 向前、y 向右、z 向下；绕 x 侧倾、绕 y 俯仰、绕 z 横摆；**向下的力叫法向力，向上的支撑力叫垂直力**（与其他国家标准相反）。
6. **地面固定坐标系与车辆固定坐标系用欧拉角连接**，转动次序（横摆 → 俯仰 → 侧倾）**不能换**；侧滑角 β 是速度向量与车身 x 轴的夹角。
7. **牛顿第二定律两条式子是全书工具**：$\Sigma F_x=Ma_x$、$\Sigma T_x=I_{xx}\alpha_x$；自由体图要求"每个与外界接触的点都有对应的力"。
8. **动态车轴载荷是第一个应用**：对轮胎接地点取矩，得 $W_f$、$W_r$ 的一般式（含空气阻力、拖钩力、坡度、加速度）。
9. **三个特例贯穿全书**：水平静止（$W_{fs}=Wc/L$）、低速加速（载荷后移 $\propto a_xh/(gL)$）、坡道上（载荷后移 $\propto h\theta/L$）。
10. **忽略与计入的差别是"平方项"**：小坡度下 $\cos\theta\approx1$、$\sin\theta\approx\theta$，于是"6% 坡算出来两轴载荷之和少了 6 lb"——少了 $\cos$ 那一点，不是算错。

**论证链**：历史 → 学科定位 → 方法论 → 建模自由度 → 坐标系 → 运动变量 → 欧拉角 → 力与符号 → 牛顿定律 → 轴荷一般式 → 三个特例 → 三个例题（求 b/c、算坡道载荷、算 FWD/RWD/4WD 爬坡能力）。

## 核心命题（用自己的话）

1. 车辆动力学的关键在四块手掌大的接地区。
2. 分析法的价值是"辨识重要因素"，代价是"假设必须可信"；**能解出闭式解 ≠ 假设成立**。
3. 选错自由度（该拆两质量时用了单质量）会让乘适性分析全错，而且不报错。
4. 符号约定（尤其法向/垂直力、b/c 方向、力矩正方向）错一次，后面全部符号错。
5. 车轴载荷**不是常数**：加速后移、上坡后移、空气阻力也参与转移（还带高度 $h_a$）。
6. 三个特例都可以从一般式退化得到——记住一般式比记三个特例安全。
7. 小坡度近似会带来 0.2% 量级的"载荷之和不等于总重"，这是物理（$\cos\theta<1$），不是误差。

## 叙事部分（1.1 与 1.2）的素材，**不建卡**

> 按用户口径与阶段 1.5 判定：叙事段落作为 overview/glossary 的素材保留，不硬做成能力卡。下列材料只在回答"这一章讲了什么 / 为什么这么建模"时引用，**不得**写成可执行步骤或能力断言。

- **1.1 学科史**（p28–30）：Cugnot 1769 → Watt 1784 失败 → Trevithick 1802 → 1886 Benz/Daimler → 1908 T 型车与 GM → 1909 年美国 600 余种车型。图 1.2 给"产品车速史"，但**正文无逐点数值**（H13），只能写趋势与轴量程（0–120 mph / 1880–1930）。
- **为什么转向要等轮胎力学**：Lanchester 1908 在舵柄转向车上观察到"过多转向"，1931 年轮胎测力计问世后才可能有力学解释；Segel 指出早期对转向特性与摆振的认识受"轮胎力学知识匮乏"限制。**用法：作"无轮胎力学数据时不要下转向结论"的适用前提，不作操作反例。**
- **Olley 1957 回忆**（p29）"后座乘客仍像配重一样悬在后轮后面……工程师把每个部件做到尽善尽美，组合起来却不令人满意"。**用法：作"局部最优 ≠ 整车可用"的引子；不得写成"后置配重 = 错误设计"。**
- **1.2 经验 vs 分析**（p31–32）：经验的掌握靠反复实践，但"经验方法经常可能导致失败"——因为新工况落在样本外时，误差由**未被建模的物理**决定，而经验法没有任何机制指出"哪一项变了"。分析法建模型、能辨识重要因素，但"必须做一些假设……这些假设时常导致严重错误"。**这两段是 `model-setup-fbd-and-assumptions` 的 B 段来源（ce01/ce02），也是全章唯一的元层级规则。**
- **1.3.3–1.3.5 坐标系与欧拉角**（p33–34）：两个坐标系、六个运动方向、三个欧拉角与"次序不可换"。**因 OCR 残缺（p/r 互换、z 与横摆整句丢失、三个角符号未印、无旋转矩阵），只能以 reference + ⚠️ 形态进 glossary，不得作为硬事实引用。**

## 13 条硬伤（下游一律按此处理，不擅自改原文）

1. **式(1-5) 的惯性力项符号错（最重要）**：OCR 作 $-\tfrac{W}{g}a_xh$，应为 $+$。照抄得 $W_r=1119.4$ lb（书中 1347.3），两轴之和 3011.9 lb，比 $W\cos\theta=3240$ 少 **228.3 lb** $=2(W/g)a_xh/L$。
2. **自检恒等式**：$W_f+W_r=W\cos\theta+R_{hz}$；无拖车时 $=W\cos\theta$。例题 2 的 3239.5 ≠ 3246 正是此式（$W\cos\theta=3240.2$）。
3. **b/c 方向**：$b$ = 前轴→重心、$c$ = 重心→后轴，**与很多英文文献相反**；三条内部证据锁定。
4. **p/r 被 OCR 互换**（侧倾角速度印成"绕 r 轴"），z 与横摆整句丢失；**以"绕哪根轴"为准，不以字母为准**。
5. **式(1-10) 右端** OCR 作 $W_{rs}$，应为 $W_{fs}$。
6. **式(1-3) 正文尾部残缺**，只能按原图公式块重建。
7. **例题 3 的 4WD 式不自洽**：按 $\theta=\mu/(1+\zeta)$、$\zeta=0.4494$ 得 20.70%，书中 19.44%（差 6%）。
8. **例题 3 的 RWD 11.42% 不可复现**（对称转移只得 9.18%），FWD/RWD 闭式解 OCR 残缺 → **只引用答案，不引用公式**。
9. **10.18% 的反正切是 5.813°**，书中 5.84° 是 arcsin 反算；以 % 为准。
10. **例题 3 题干"前驱（AWD）"应为 FWD**。
11. **例题 3 用例题内局部编号 (1)–(5)**，与章内 (1-1)~(1-11) 不是一套。
12. **坡度按正切**（"上升高度/行驶距离"若按沿坡面距离读则是 sinθ，与原文"即正切值"矛盾）。
13. **图 1.2 正文无逐点数值**，不得给具体车速。

> 另有低 severity 的 OCR 瑕疵：`cos θ = 0.99† ≅ 1` 应为 0.998 的截断；"车辆固定坐标系选择与操纵的起始点相一致"主语错位（应为地面固定坐标系）；1.4 第 (3) 条用"沿路面法向方向"（几何义）而 SAE 的"法向力"是命名义（向下），两处"法向"含义相反。

## 批判与时代局限（B 段素材来源）

- **1992 年视角**：无 ESC、无电控转向、无混合动力；史观停在 T 型车 → Taurus；全章英制（lb、in、ft/s²），$in\cdot lb\cdot s^2$ 这类转动惯量单位对现代读者很陌生。
- **假定读者是工程系学生**：直接给 SAE 坐标系与自由体图，没有为自学者搭桥。
- **例题 3 是"手算 + 小角度近似"的产物**：三档答案内部口径不一致（5.84° 用 arcsin），且与印刷式差 6%——它不能被当作精确基准。
- **四个未被证明的假设**：无俯仰角加速度、拖车刚体且拖钩高度不变、$\mu$ 为常数、小角度近似在 10–12% 坡仍可接受。
- **最强反对意见**：「这一章的公式都是准静态、单自由度刚体的；把它们当成'基础'会让人以为后面各章只是'加项'，而实际瞬态、多体、非线性才是常态。」作者的防线在 1.2：**"分析方法只是接近真实，必须严格把握任何假设"**——这句话本身就是本章最该传递的东西。
