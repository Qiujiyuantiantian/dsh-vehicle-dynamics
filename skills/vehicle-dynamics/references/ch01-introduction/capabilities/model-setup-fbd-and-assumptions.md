# 建模入口三连：选自由度 → 画自由体（清点接触点）→ 核对假设

## R — 原文 (Reading)

> **原书要点**（p32 §1.3.1 集中质量）：研究加速、制动以及多数转向问题时，把整车当成一个集中质量已足以应付；换成乘适性课题，就要把每个车轮各自当作集中质量，这时车身归入“悬挂质量”，车轮归入“非悬挂质量”。
>
> **原书要点**（p34–35 §1.3.7）：牛顿第二定律这条定律（英文缩写 NSL）的用法，是先把研究对象的外形收起、只留轮廓；再把该有的力、力矩连同重力，一项项画到它与外部相接触的位置上——这样得到的图就是自由体受力图。
>
> **原书要点**（p31 §1.2）：要让模型算得下去，总得砍掉一些次要因素、立几条假设；可这些假设一旦用进分析里，往往就把结果带偏得很厉害。所以做工程的人对模型里的每一条假设都得心里有数，才不至于踩这个坑。
>
> — 1.3.1 集中质量（p32）；1.3.7 牛顿第二定律（p34–35）；1.2 车辆动力学简介（p31）

## I — 方法论骨架 (Interpretation)

一句话：**动手算之前先过三道门——①这个分析需要哪个自由度？②研究对象与外界有几个接触点、每个点上有几个力？③我打算用的公式，它的假设逐条对得上当前工况吗？三关不过，后面算得再准也是错的。**

- **第一道门：自由度。** 判据只有一条——**要求解的量是否依赖车身与车轮之间的相对运动**。加速、制动、大多数转向：不依赖 → 整车一个集中质量（在重心、**必须带转动惯量**）。乘适性、轮跳、冲击、悬架灵敏度：直接依赖 → 两质量（悬挂质量 = 车身，非悬挂质量 = 车轮）。
- 这条判据的厉害处在于：选错时模型**不会报错**。单质量模型里根本不存在"轮跳"这个自由度，路面激励没有传递路径，于是必然给出"车身永远平稳"的结论；症状是"改了弹簧/减振器，结果几乎不变"。
- **第二道门：自由体。** 把研究对象抽象成"质量 + 惯性"，然后在**每个与外界接触的点**上放力/力矩。本章的接触点清单固定为四类：重力（作用在重心）、轮胎接地（支撑力 + 牵引力 + 滚动阻力）、空气动力（风压中心）、拖钩（纵向 + 垂直）。漏一个接触点 = 少一个力 = 后面所有结论偏，而方程照样能解出来。
- **第三道门：方程计数。** 数未知量、数独立方程，两者必须相等才"有可能"解出。这一步是必要条件而非充分条件（线性相关它查不出），但它能挡住最常见的"漏一个接触点/多一个未知量"。
- **第四道门（元规则）：假设清单。** 任何公式都是一组假设的产物；假设不满足时误差**不会报错**，而是以"看起来合理"的数出现。所以每次套公式前，把该式的假设列成清单，逐条与工况比对，并**点名被删掉的项**——这样即便越界也能说清偏差方向。
- 这四道门合起来的价值不在"更精确"，而在**在错误发生之前拦住它**：本章后面所有轴荷、坡度、爬坡计算都建立在这套建模动作之上。

## A1 — 应用示例 (Application Example)

### 示例 1：原书的分界线本身（原书依据，非例题）

- **类型与来源**：**原书依据**（1.3.1，p32）。**原书没有为例题形式演示这条判据**，只给了"乘适性 vs 其余"这一条分界线与两类质量的定义。
- 分界线内容：加速 / 制动 / 大多数转向 → 单质量；乘适性 → 两质量（车身 + 逐个车轮）。

### 示例 2：三组新输入的判定（合成演练，非书中事实）

- **类型与来源**：**合成演练**。原书未给这三组算例，判定依据是"求解量是否依赖车身—车轮相对运动"这一条判据。
- **A：求 0–60 mph 加速时间与驱动轴附着需求** → 单质量。理由：输出量由整车纵向力与轴荷决定，不含轮跳自由度；加悬架细节不改变结果。
- **B：求过减速带时车身垂向加速度与悬架行程**（路面谱激励）→ 两质量。理由：输出直接由轮跳决定；用单质量做会得出"改悬架结果不变"——与 ce07 记录的失败模式同源。
- **C：把例题 3 的"小艇 + 拖车"当独立研究对象，求拖钩两分力** → 单质量（拖车一个刚体），接触点只有三个（拖车轮接地、拖钩、拖车重力），未知量 $F_{xb}$、$F_{zb}$ 两个、方程两个 → **闭合**。
- **反向复核**：把 B 用单质量做，模型内不存在轮跳自由度，"改悬架参数结果不变"，判据成立。

### 示例 3：假设清单的三档判定（合成演练，非书中事实）

- **类型与来源**：**合成演练**（纸面）。用一个具体工况验证"逐条核对假设"这条动作。
- **输入**：手上只有式 (1-8)(1-9)（水平 / 低速 / 无拖挂 / 无风阻），当前工况是"6% 坡 + 牵引 1200 lb 拖车 + 起步加速"。
- **方法的执行**：列假设清单并逐条比对——$\theta=0$ ✗（题含 6% 坡）、$D_A=0$ ✓（低速可略）、$R_{hx}=R_{hz}=0$ ✗（有拖车）、无俯仰加速度 ✓、单质量刚体 ✓。
- **结论/预期输出**：**判不适用**，改用 (1-4)(1-5) 全式；并点名被删掉的三项：坡度项 $Wh\sin\theta/L$、拖钩项 $R_{hx}h_h/L$ 与 $R_{hz}d_h/L$。若硬套 (1-8)(1-9)，本例会漏掉约 54 lb 的前轴卸载量与约 36 lb 的坡度转移量——**都不报错，只是悄悄算错**。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 要写/选用一个车辆动力学模型，先问"该用几自由度、要不要拆簧上簧下"。
2. 做乘适性或悬架参数灵敏度分析，怀疑模型里缺了轮跳通路。
3. 要画某工况的自由体图，担心漏接触点（尤其风压中心与拖钩）。
4. 套用一个现成公式前，要确认它的假设在本题成立。
5. 结果"看起来很合理"但与实测有系统性偏差，怀疑是假设越界而非算术错。

### 语言信号（中英双写）

- 「该用单质量还是两质量」「簧上簧下要不要分开」「模型要几个自由度」
- 「自由体图怎么画」「漏了哪个力」「这个公式的假设成立吗」「能不能直接套这个式子」
- 「lumped mass」「sprung unsprung」「free body diagram」「model assumptions」「DOF selection」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与所有计算卡（`static-axle-load-and-cg-location`、`dynamic-axle-load-general-form`、`acceleration-load-transfer`、`grade-axle-load-and-grade-angle`、`towing-gradeability-analysis`）：本卡是它们的**前置**，输出"用哪个模型、哪几条假设"，不出数值；数值一律在那些卡里产出。
- 与 `axle-load-sum-diagnostic`：本卡防"建模阶段就错了"，那张卡事后查"数值符号错了"。
- 与 `sign-convention-and-moment-direction-check`：两者都是前置；本卡管"有哪些力、几个方程"，那张卡管"力朝哪、力矩往哪转"。

## E — 可执行步骤 (Execution)

**必需输入**：要回答的问题（求解量是什么、精度要求）、研究对象（整车 / 车身 / 车轮 / 拖车 / 挂车）、工况（加速/制动/转向/乘适性，是否含坡度、风阻、拖挂）、候选公式（如果已有）。

**缺什么必须问**：求解量不明确 → 停（自由度无从判）；研究对象含挂车/多体而仍要"整车单质量" → 说明超出本章判据（G-05）并声明；候选公式的假设清单缺失 → 先补清单，不许"先用着看结果"。

**交付物与完成标准**：四行结论——①自由度选择及理由；②接触点与力的清单；③未知量数 = 方程数；④假设核对表（逐条 ✓/✗ + 被删项点名）。四条齐备才算完成。

1. **定自由度（第一道门）**
   - 完成标准：写出"求解量 = X；X 是否依赖车身与车轮的相对运动 → 是/否 → 两质量/单质量"。若选单质量，必须写明"该质量带转动惯量"。
   - 判停：若问题涉及乘适性、轮跳、冲击、悬架行程、接地性任一 → **必须两质量**；若仍用单质量，先停并告知结论会整体失效。
2. **抽象研究对象并清点接触点（第二道门）**
   - 完成标准：把对象抽象为"质量 + 惯性"；列出每个接触点及该点上的力。本章清单：重力（重心）、轮胎接地（$W_f$/$W_r$ + $F_x$ + $R_x$）、空气动力（$D_A$ @ $h_a$）、拖钩（$R_{hx}$ @ $h_h$、$R_{hz}$ @ $d_h$）。逐点写"有力/无力"，无力也要写出来。
3. **列方程并数未知量（第三道门）**
   - 完成标准：三个方向（或所需方向）的 $\Sigma F=Ma$ / $\Sigma T=I\alpha$；列出未知量清单，数出个数，与方程数相等。例题 3 的样例：4 个未知量（$F_{xb}$、$F_{zb}$、$W_f$、$W_r$）对 4 个方程。
   - 判停：不等 → 回第 2 步找漏掉的接触点，或确认是否真少一个条件；**不许**用"再补一个假设"凑数。
4. **列假设清单并逐条比对（第四道门，元规则）**
   - 完成标准：对候选公式逐条写假设（本章常用：水平 / 低速 / 无拖挂 / 无风阻 / 无俯仰角加速度 / 单质量刚体 / 小角度 / $\mu$ 为常数），每条标 ✓ 或 ✗，✗ 的**点名被删掉的项**与其量级。
   - 判停：出现任一 ✗ → 不得使用该式，改用更一般的式子；若没有更一般的式子，输出"该问题超出本章范围"。
5. **二选一：达朗贝尔式还是 NSL 式**
   - 完成标准：显式声明"用平衡写法（画惯性力 $(W/g)a_x$，右边为零）"或"用 NSL 写法（不画惯性力，右边写 $Ma_x$）"；**两者不得同时出现**（ce10）。
6. **交付**
   - 完成标准：一句话"本问题用单质量（含 $I_{xx}$）、四类接触点、4 方程 4 未知量、假设清单 6 条中 2 条不满足 → 改用 (1-4)(1-5)"，并附假设核对表。

**计算约定（本卡设定）**：本章一律在 SAE 车辆固定坐标系下列式（x 前、y 右、z 下、原点在重心）；方程计数只作必要条件声明，不得声称"计数通过即方程独立"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **用单质量做乘适性 / 轮跳 / 冲击分析。** 模型里没有那个自由度，结论必然是"车身平稳"，且"改悬架参数结果不变"（ce07）。
- **反过来用两质量算加速与制动。** 多出的自由度对结果无贡献，却让人误以为更准；本卡的判据是"求解量是否依赖相对运动"，不是"越复杂越准"。
- **把自由体图当示意图画。** 少一个接触点 = 少一个力 = 后面全偏，而方程照样能解；必须逐点"有力/无力"都写出来。
- **以为"未知量数 = 方程数"就解得出。** 计数只是必要条件，不保证方程线性无关（原文未讨论）；真解不出要回第 2 步查重复方程。
- **用"能解出闭式解"证明假设成立。** 作者明说：为了闭式解而砍掉的项，恰恰常是支配项（"很多情况下，这限制了分析方法"）。
- **把本卡判据外推到货车、挂车、多体、>2 自由度。** 原文只给"乘适性 vs 其余"一条分界线，货车另行讨论（G-05）；用在多体上必须声明"超出本章判据"。
- **在同一方程里既画惯性力又写 $Ma_x$。** 惯性效应翻倍（ce10）；两种写法只能选一种并在输出声明。

### 作者在书中警告的失败模式

- ce01（明确警告）：只靠经验外推新工况——"经验方法经常可能导致失败"，新工况落在样本外时误差由未建模的物理决定，且没有任何机制指出"哪一项变了"。
- ce02（明确警告）：分析法假设不严——"这些假设时常导致严重错误"；为闭式解砍掉的项常是支配项，所以"能解出来"不是"假设成立"的证据。
- ce07（暗示）：选错自由度，用单质量做乘适性，表现为"改悬架参数结果不变"。
- ce11（暗示）：忽略"无俯仰角加速度"假设，拿准静态轴荷式解释点头/抬头。

### 作者的盲点 / 时代局限

- 只给"乘适性 vs 其余"一条分界线，没有 3 自由度以上、多体、货车/挂车的判据；自由度选择在本书其余章节才展开。
- 假设清单没有"应该多长"的标准，误差量级须自行估算（本章可用的三个锚点：$\cos\theta$ 误差 0.18%@6%、0.71%@12%；$\sin\theta\approx\theta$ 误差 0.02%@6%）。
- 1992 年视角：建模取舍以"能否闭式解/手算"为界，未考虑现代仿真中可以保留更多非线性项。

### 容易混淆的邻近方法论

- **集中质量 vs "简化模型"**：集中质量**必须含转动惯量**（否则式 1-2 不成立）；把"简单"读成"不要惯量"会让力矩平衡整条错。
- **自由度选择 vs 假设核对**：前者决定"哪些运动能被激发"，后者决定"哪些力被丢掉"；两件事都要做，顺序是先自由度后假设。
- **达朗贝尔力 vs 真实力**：惯性项不是任何物体施加的力，只是把 $Ma$ 搬到等号左边的记账方式（ce10）。
