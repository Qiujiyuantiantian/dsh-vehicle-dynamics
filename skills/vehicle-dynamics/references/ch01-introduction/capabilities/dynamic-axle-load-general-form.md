# 动态车轴载荷一般式：对另一轴接地点取矩、六类力清点、退化表与求和自检

## R — 原文 (Reading)

> **原书要点**（p35–36 §1.4 式1-3/1-4/1-5、图1.6）：任一车轴上的载荷由两块叠加而成：车静止时已有的那一份，加上在前后两轴间来回搬动的动态部分。要算前轴那一份，就取后轮接地处 A 点为矩心列平衡；前提是不计俯仰角加速度，此时绕 A 的合力矩为零。按 SAE 约定，绕 A 顺时针方向的力矩取正值。
>
> **原书要点**（p35–36 §1.4 式1-3）：风阻 $D_A$ 不是一个孤立的力：它既可以说成作用在离地 $h_a$ 高的风压中心那个点上，也可以等价地挪到地面高度，写成同样大小的水平纵向力外加一个力偶——也就是气动俯仰力矩，大小等于 $D_A h_a$。
>
> — 1.4 动态车轴载荷（p35–36，式 1-3/1-4/1-5，图 1.6 说明 (1)–(6)）

## I — 方法论骨架 (Interpretation)

一句话：**要求某个轴的载荷，就对"另一个轴"的接地点取矩——那一轴上所有接地力的力臂为零，方程自动只剩一个未知量；然后把六个力臂项逐一清点，最后用"两轴之和 = $W\cos\theta+R_{hz}$"反查符号。**

- 整个 1.4 节只有一条母式家族，两条式子：
  $$W_f=\frac{Wc\cos\theta-R_{hx}h_h-R_{hz}d_h-\tfrac{W}{g}a_xh-D_Ah_a-Wh\sin\theta}{L}$$
  $$W_r=\frac{Wb\cos\theta+R_{hx}h_h+R_{hz}(d_h+L)+\tfrac{W}{g}a_xh+D_Ah_a+Wh\sin\theta}{L}$$
  **惯性项在 $W_r$ 里是 $+$**（加速时载荷后移，后轴必须增大）。OCR 把 (1-5) 的这一项印成 $-$，照抄必错（见 B 段）。
- 六类力必须一次清点完，缺一项就少一个力臂项：①重力 $W$（坡度分成 $W\cos\theta$ 与 $W\sin\theta$）②达朗贝尔惯性力 $(W/g)a_x$（作用在重心，方向与加速度相反）③轮胎支撑力 $W_f$、$W_r$（向上为正）④牵引力 $F_{xf}$、$F_{xr}$ 与滚动阻力 $R_{xf}$、$R_{xr}$（作用在接地区，对取矩点力臂为零，故不进式子）⑤空气阻力 $D_A$（在 $h_a$ 处，可等价为地面纵向力 + 俯仰力矩 $D_Ah_a$）⑥拖钩力 $R_{hx}$（在 $h_h$ 处）与 $R_{hz}$（在 $d_h$ 处，对后轮接地点力臂是 $d_h+L$）。
- 一般式**退化**出三个特例，只需把关键词置零：$\theta=0$ 且 $a_x=0$ 且 $D_A=R_h=0$ → 水平静止 (1-6)(1-7)；$\theta=D_A=R_h=0$ → 水平加速 (1-8)(1-9)；$a_x=D_A=R_h=0$ → 坡道 (1-10)(1-11)。**记住一般式比背四条特例安全**——特例不能反推一般式。
- 一般式自带一个不看答案的钩子：两式相加，除 $R_{hz}$ 外所有项两两抵消，
  $$W_f+W_r=W\cos\theta+R_{hz}$$
  无拖车时就是 $W\cos\theta$。任何一次计算先用它验一遍；不平就是符号或力臂错。
- 取矩消元的代价是：**作用线不过取矩点的力必须显式带入**。$D_A$、$R_{hx}$、$R_{hz}$ 都不接地，所以它们出现在式子里；而牵引力与滚阻恰好接地，力臂为零，所以它们不出现——这不是"忽略了它们"，是"它们对该方程无贡献"。

## A1 — 应用示例 (Application Example)

### 示例 1：例题 2 的完整代入（原书例题）

- **类型与来源**：**原书例题**（例题 2，p37–38）。Taurus GL，6% 坡、以 6 ft/s² 起步加速、无拖挂、忽略风阻。
- **输入**：$W=3246$ lb、$b=39.15$ in、$c=66.85$ in、$L=106$ in、$h=20$ in（原书因缺数据而假设）、$a_x=6$ ft/s²（$a_x/g=0.186335$）、$\theta=\arctan 0.06=3.433^\circ$（$\cos\theta=0.998205$、$\sin\theta=0.059885$）、$D_A=R_{hx}=R_{hz}=0$。
- **方法的使用**：①按本章方向取 $b$、$c$；②把六类力中"非零的四个"（$W\cos\theta$、$W\sin\theta$、惯性项、无风阻无拖钩）逐项代入 (1-4)(1-5)；③求和自检。
- **结论/结果（复算值）**：$W_f=\mathbf{1892.2}$ lb、$W_r=\mathbf{1347.3}$ lb（书中值；独立复算 1892.5 / 1347.7，差异来自 $c$ 取位 66.8454 vs 66.85）；之和 $\mathbf{3239.5}$ lb，而 $W\cos\theta=3246\times0.998205=\mathbf{3240.2}$ lb（书中印"3240"）。
- **符号自检（本卡强制保留的一行）**：加速时后轴必须**加载**，故 $\partial W_r/\partial a_x>0$。若照 OCR 的 $-$ 号算，$W_r=\mathbf{1119.4}$ lb、$W_f+W_r=\mathbf{3011.9}$ lb，比 $W\cos\theta$ 少 **228.3 lb**，恰好等于 $2(W/g)a_xh/L=2\times114.12$——**见到这个"恰好两倍"，立刻判符号错，不必再查算术。**

### 示例 2：加风阻与拖钩（合成演练，非书中事实）

- **类型与来源**：**合成演练**（纸面复算）。车与坡度仍取例题 2 的参数，另设 $D_A=100$ lb @ $h_a=30$ in、$R_{hz}=250$ lb @ $d_h=23$ in、$R_{hx}=0$。**$h_a=30$ in 与 $d_h=23$ in 都是本卡自设，原书未给这两个量的取值方法（缺口 G-01）。**
- **方法的使用**：①在示例 1 的分子上各加减一项：$W_f$ 减 $D_Ah_a=3000$ 与 $R_{hz}d_h=5750$；$W_r$ 加同样两项，但 $R_{hz}$ 的力臂是 $d_h+L=129$ in；②求和自检。
- **结论/预期输出**：仅加 $D_A$ → $W_f=1864.3$、$W_r=1375.8$、和 $=3240.1$（气动项在两式中反号，**相消**，总和不变）；再拖钩 → $W_f=\mathbf{1810.1}$、$W_r=\mathbf{1680.0}$、和 $=\mathbf{3490.1}=3240.2+250$ ✓。拖钩垂直力把前轴卸掉 54.2 lb、给后轴加 304.2 lb。
- **注意**：风阻与拖钩的"和不变 / 和增多"是两种不同的自检结果，别混：$D_A$ 只改变分配，$R_{hz}$ 改变总和。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 工况同时含两项以上（坡度 + 加速、拖挂 + 加速、高速 + 制动），没有现成特例式子可用。
2. 算高速行驶/加速时的轴荷，需要考虑空气阻力及其作用高度 $h_a$。
3. 算拖挂工况的轴荷，需要拖钩纵向力 $R_{hx}$ 与垂直力 $R_{hz}$ 及其力臂 $h_h$、$d_h$。
4. 手上有某条特例式子的结果，想核对它是否漏项、符号是否对。
5. 要写/改一段车辆纵向动力学代码，需要"一条一般式 + 一张置零表"作为唯一实现。

### 语言信号（中英双写）

- 「坡上加速时前后轴各多少」「拖挂之后轴荷怎么变」「风阻对轴荷有影响吗」
- 「有坡又有加速度，用哪个公式」「(1-4)(1-5) 怎么用」「对后轮接地点取矩」
- 「dynamic axle load」「weight transfer with grade」「hitch force axle load」「aerodynamic pitch moment」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `static-axle-load-and-cg-location`：那张卡是 $a_x=\theta=D_A=R_h=0$ 的特例，并负责给出 $b$、$c$；本卡以那张卡的输出为输入。
- 与 `acceleration-load-transfer`、`grade-axle-load-and-grade-angle`：那两张卡是"单一因素"的转移量算法（$\Delta W$ 加加减减），只在本卡退化的两种情形下更快；一旦多因素并存，必须回本卡全式。
- 与 `axle-load-sum-diagnostic`：本卡负责"算出来"，那张卡负责"和不对时怎么判"。
- 与 `towing-gradeability-analysis`：那张卡从拖钩力出发解爬坡能力；本卡只到"给定 $R_{hx}$、$R_{hz}$ 求轴荷"为止。

## E — 可执行步骤 (Execution)

**必需输入**：$W$（lb）、$b$、$c$、$L$（in）、$h$（重心高，in）、$a_x$（ft/s²，**带符号：加速为正**）、$\theta$（°，**上坡为正、下坡为负**）。按工况另需：$D_A$（lb）与 $h_a$（in）、$R_{hx}$（lb）与 $h_h$（in）、$R_{hz}$（lb）与 $d_h$（in）。

**缺什么必须问、不得默认 0**：$h$、$h_a$、$h_h$、$d_h$ 任一缺失 → 记"信息不足"，给出"该缺失项只能使结果偏向某方向"的定性说明；**$h_a$、$d_h$ 尤其不许默认为 0**（默认为 0 等于删掉该项，而它往往是拖挂工况的主导项）。

**交付物与完成标准**：一张六行力臂清单表 + $W_f$、$W_r$ + 求和自检一行 + 一句口径声明（英制、无俯仰加速度、取矩点与正方向）。

1. **声明取矩点与力矩正方向（先做，后算）**
   - 完成标准：写出"对后轮接地点 A 取矩求 $W_f$，顺时针为正；对前轮接地点 B 取矩求 $W_r$"。**同一张卡内不许混用两套正方向**（例题 3 另行声明逆时针为正，见 `sign-convention-and-moment-direction-check`）。
2. **清点六类力并标注力臂**
   - 完成标准：六行表——重力（$c\cos\theta$ / $b\cos\theta$、$h\sin\theta$）、惯性力 $(W/g)a_x$（$h$）、支撑力 $W_f$/$W_r$（0 / $L$）、牵引力与滚阻（0，注明"过取矩点故不入式"）、$D_A$（$h_a$）、拖钩（$h_h$、$d_h$、$d_h+L$）。六行缺一行 → 判未完成。
3. **逐项代入一般式**
   - 完成标准：两条式子的每一项都能对应到第 2 步表格的一行；**惯性项在 $W_r$ 中写 $+$、在 $W_f$ 中写 $-$**；$D_A$ 项同样反号（$W_f$ 减、$W_r$ 加），$R_{hz}$ 的力臂在 $W_r$ 中是 $d_h+L$。
4. **判是否需要退化**
   - 判停点：若某关键词恰好为 0（$\theta=0$、$a_x=0$、$D_A=0$、$R_h=0$），可用对应特例式（水平静止/水平加速/坡道）加速，但**必须在输出里写出"按 X 特例计算"并列出被置零的项**；多因素并存时不得用特例。
5. **求和自检（强制）**
   - 完成标准：验 $W_f+W_r=W\cos\theta+R_{hz}$（无拖钩时 $=W\cos\theta$），容差 0.5 lb。
   - 判停：和偏小且差值 $\approx2(W/g)a_xh/L$ → 惯性项符号错，回第 3 步；和偏小且差值 $\approx W(1-\cos\theta)$ 而工况无坡 → 检查 $\theta$；和偏大而 $R_{hz}=0$ → 符号错。
6. **交付**
   - 完成标准：一句话"在 6% 坡、$a_x=6$ ft/s² 下 $W_f=1892.2$、$W_r=1347.3$ lb，和 3239.5 = $W\cos\theta$=3240 lb ✓"，并声明"准静态、无俯仰角加速度、英制"。

**计算约定（原书未规定，本卡设定）**：轴荷报 1 位小数（lb）、中间量不提前舍入、$g=32.2$ ft/s²、$\theta$ 同时给度与弧度；求和自检容差 0.5 lb。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **照抄式(1-5) 的惯性项负号（本章第一号硬伤）。** OCR 作 $-\tfrac{W}{g}a_xh$，物理与例题 2 都要求 $+$。照抄得 $W_r=1119.4$ lb（书中 1347.3），和少 228.3 lb $=2(W/g)a_xh/L$。**必须写 $+$，并在输出留一行符号自检。**
- **把 $h_a$、$h_h$、$d_h$ 默认为 0。** 原文只给符号定义，没给测量/估算方法（缺口 G-01）；默认为 0 等于删掉该项，应显式记为"信息不足"并说明偏差方向。
- **同时用两种空气阻力写法。** "$h_a$ 处一个力"与"地面纵向力 + 俯仰力矩 $D_Ah_a$"等价，选一种；两种都写等于把气动项算两遍。
- **在式子右边又写 $\Sigma F=Ma_x$。** 达朗贝尔力 $(W/g)a_x$ 已经把惯性项搬到左边；再写一次等于惯性效应翻倍（ce10）。反过来，用 NSL 写法时必须删掉 FBD 上的惯性力箭头。
- **拿它解释点头/抬头（dive/squat）。** 本卡的前提是"无俯仰角加速度"；急加速、急制动、过坎时须补 $I_{yy}\dot q$（本章未给该项，属章外）。
- **用它算拖挂爬坡能力的绝对百分比。** 本卡只给"给定 $R_{hx}$、$R_{hz}$ 求轴荷"；爬坡能力的附着判据与拖钩力的求解在 `towing-gradeability-analysis`，且该处闭式解残缺（G-03）。
- **把 (1-3) 的残缺正文当原文。** 正文尾部只剩 "g (1-3)"，完整式只能取原图公式块 $W_fL+D_Ah_a+\tfrac{W}{g}a_xh+R_{hx}h_h+R_{hz}d_h+Wh\sin\theta-Wc\cos\theta=0$，不得据残缺正文另造（H6）。

### 作者在书中警告的失败模式

- ce15：把 (1-8)(1-9) 当通用式——它们是 $D_A=R_h=\theta=0$ 的特例，高速时 $D_Ah_a$ 可与加速度项同量级，拖挂时拖钩项常是主导项。
- ce16：只把风阻/拖钩当"额外纵向阻力"加进驱动力平衡，忘了它们同时改轴荷分配；或用高度算力矩却忘了它本身是阻力。
- ce11：把准静态轴荷式用于瞬态（用同一个 $W_f$ 描述整个制动过程）。
- ce08：用静态轴荷代替动态轴荷去算附着力（$\mu W_{fs}$ 而非 $\mu W_f$）。

### 作者的盲点 / 时代局限

- 全章英制且无换算表；$h_a$、$h_h$、$d_h$ 无取值方法（推到第 4 章或"另行测量"），本章不能自足。
- 假设拖车刚体、拖钩高度不随载荷与坡度变化（例题 3 括号内明说）。
- 只以"纵向力 + 俯仰力矩"进入气动，忽略侧风与气动升力。
- 忽略俯仰角加速度；对现代带 EBD/ESC、半主动悬架的车辆，瞬态轴荷与本卡差异显著。

### 容易混淆的邻近方法论

- **取矩点 A（后轮接地点）求 $W_f$ vs 取矩点 B（前轮接地点）求 $W_r$**：搞反会得到一个"看起来像"的解，必须靠求和自检暴露。
- **$W\cos\theta$ vs $W$**：坡道上进入轴荷的只有余弦分量，用 $W$ 会让两轴同时偏大（例题 2 的 3239.5 vs 3246）。
- **$b\cos\theta$ / $c\cos\theta$ 与 $h\sin\theta$ 的符号**：$W\sin\theta$ 项在两式中反号（前轴减、后轴加），这是"上坡载荷后移"的全部来源。
- **本章的 (1-4)(1-5) vs 例题 3 的局部式 (1)–(5)**：后者是例题内编号，与章内编号不是一套（H11），且力矩正方向相反（ce09）。
