# 静态轴荷与重心纵向位置：$W_{fs}=Wc/L$、$W_{rs}=Wb/L$ 的双向换算

## R — 原文 (Reading)

> **原书要点**（p36 §1.4.1 式1-6/1-7）：车停着不动、路面又水平，式子就简了：正弦为 0、余弦为 1，$R_{hx}$、$R_{hz}$、$a_x$、$D_A$ 全都归零，于是 $W_{fs}=Wc/L$、$W_{rs}=Wb/L$，即每轴按重心到对面那根轴的距离占比来分重量。
>
> **原书要点**（p36 §1.4.1 式1-6/1-7）：水平停放时，$c$ 是重心到后轴的那一段、$b$ 是重心到前轴的那一段；用式(1-7) 反解，就能从轴荷把 $b$ 算回来，本例得 39.64 in。
>
> **原书要点**（p36 §1.4.1 式1-6/1-7；p37 例题1）：这一小节处理车停在水平路面时的静载分配，两条式子分别给出前后轴；例题 1（p37）是它的算例。

## I — 方法论骨架 (Interpretation)

一句话：**一对式子同时是"算轴荷"和"反求重心"的两条通路——正着用给出 $W_{fs}$、$W_{rs}$，反着用给出 $b$、$c$，而两条通路能不能对上，只取决于 $b$、$c$ 的方向有没有搞反。**

- 全部内容就是杠杆原理：对**后**轮接地点取矩求前轴载荷，力臂是"重心到后轴"的距离，所以 $W_{fs}\propto c$；对**前**轮接地点取矩求后轴载荷，力臂是"前轴到重心"，所以 $W_{rs}\propto b$。
- 本章的方向是 **$b$ = 前轴→重心、$c$ = 重心→后轴**，$L=b+c$。这与很多英文教材正好互换——那些书写 $W_f=Wb/L$、$W_r=Wc/L$。**同名字母不同义，是本章最贵的一个坑。**
- 正因为是一对互逆映射，它自带三条不看答案就能判对错的检查：①$W_{fs}+W_{rs}=W$；②$b+c=L$；③反代回 $Wc/L$ 与 $Wb/L$ 必须回到原始读数。
- 这条式子还决定了"前轴重 ⇒ $c$ 长"的直觉：例题 2 前轴 2047 > 后轴 1199，于是 $c=66.85 > b=39.15$。**凡是算出"前轴重但 $b>c$"的，方向一定反了。**
- 它本身只是静力学，不含 $h$、不含 $a_x$、不含 $\theta$——所以它是全章后续所有计算卡的**输入口径**：先有 $b$、$c$，才谈得上载荷转移。

## A1 — 应用示例 (Application Example)

### 示例 1：例题 1（原书例题）

- **类型与来源**：**原书例题**（例题 1，p37）。空载 Continental 四门轿车。
- **输入**：$W_{fs}=2313$ lb、$W_{rs}=1322$ lb、$L=109$ in（题设"没有乘客或载货"）。
- **方法的使用**：①$W=W_{fs}+W_{rs}$；②$b=L\,W_{rs}/W$；③$c=L-b$；④反代校核。
- **结论/结果（复算值）**：$W=\mathbf{3635}$ lb、$b=\mathbf{39.64}$ in（39.6418）、$c=\mathbf{69.36}$ in（69.3582）。原文只给 $b=39.64$ 与"即前轴距重心 39.64 in"，未直接印 $c$。
- **对上的锚点**：反代 $Wc/L=3635\times69.3582/109=2313.0$ lb、$Wb/L=3635\times39.6418/109=1322.0$ lb，与题给两读数一致（差 <0.1 lb）。

### 示例 2：例题 2 的静态段（原书例题）

- **类型与来源**：**原书例题**（例题 2 前半，p37–38）。Taurus GL，含 200 lb 驾驶员按 MVMA 的 49%/51% 分配。
- **输入**：$W_{fs}=1949+200\times0.49=2047$ lb、$W_{rs}=1097+200\times0.51=1199$ lb、$L=106$ in。
- **方法的使用**：同示例 1，只是总重由两读数相加得 3246 lb，不是厂商给出的整车质量。
- **结论/结果（复算值）**：$W=\mathbf{3246}$ lb、$b=\mathbf{39.15}$ in（39.1546）、$c=\mathbf{66.85}$ in（66.8454）。
- **方向自检**：前轴 2047 > 后轴 1199，而 $c=66.85>b=39.15$ ✓；若谁算出 $b>c$，其人已把 b/c 互换。

### 示例 3：换一组输入的纸面演练（合成演练，非书中事实）

- **类型与来源**：**合成演练**。自造车 M1（$W_{fs}=1750$ lb、$W_{rs}=1250$ lb、$L=104$ in），数值与书中三道例题均不同，避免把例题结果当演练结果。原书未给此算例。
- **方法的使用**：①$W=1750+1250=3000$ lb；②$b=104\times1250/3000$；③$c=104-b$；④反代。
- **结论/预期输出**：$b=\mathbf{43.33}$ in（43.3333）、$c=\mathbf{60.67}$ in（60.6667）；反代 $Wc/L=3000\times60.6667/104=1750.0$ lb ✓、$b+c=104$ ✓、$W_{fs}+W_{rs}=3000$ ✓。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 手上有地磅/轴重仪的两轴读数与轴距，要反求重心纵向位置（改装、配重、装货后重心移动）。
2. 要给后续载荷转移/制动/爬坡计算准备 $b$、$c$、$L$ 三个输入。
3. 想核对自己（或别的书、别的软件）算出的重心位置为什么与手册对不上。
4. **已知改装后的两轴轴荷**（如换电池包、加拖钩、后排坐人后重新过磅），问"重心前后移了多少、轴荷怎么变"。
   - ⚠️ **边界**：本卡能做的是"由**新轴荷**反求新 $b,c$ 及变化量"。若用户只给"加了 150 kg、装在后排"，**本章未给"由质量增量求新轴荷"的方法**（需质量位置与整车质量，属装载计算）→ **判停**，要求先提供过磅后的轴荷，或另找装载计算资料；不要凭直觉直接移动 $b$。
5. 从英文资料搬公式时，要判断对方那本书的 $b$、$c$ 是否与本章相反。

### 语言信号（中英双写）

- 「重心到前轴多远」「由前后轴荷算重心位置」「轴距 106 in，前轴 2047 后轴 1199，重心在哪」
- 「b 和 c 是什么」「为什么前轴重反而是 c 长」「CG location from axle loads」「static axle load」
- 「前轴载荷 2313、后轴 1322，轴距 109」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `dynamic-axle-load-general-form`：本卡只做**静止、水平**（$a_x=\theta=D_A=R_h=0$）的特例；一旦出现加速度、坡度、风阻或拖钩，转那张卡，本卡的 $W_{fs}$、$W_{rs}$ 只作为它的两个输入项。
- 与 `acceleration-load-transfer`、`grade-axle-load-and-grade-angle`：那两张卡在本卡给出的静载荷上加/减一个转移量 $\Delta W$，本身不再反求 $b$、$c$。
- 与 `axle-load-sum-diagnostic`：本卡的检查①（和=总重）只在水平静止成立；坡道上的"和小于总重"是正常现象，归那张卡判。

## E — 可执行步骤 (Execution)

**必需输入**：两轴载荷 $W_{fs}$、$W_{rs}$（lb，**同一载荷状态、同一水平地面**测得）与轴距 $L$（in）。可选：整车总重 $W$（厂商值，用于交叉核对）、载荷状态说明（空载/含驾驶员/满载）。

**缺什么必须问、不得猜**：只有总重 $W$ 与轴距 $L$ 而无两轴分配 → **停**，$b$、$c$ 不可定（无穷多解）；只有一轴载荷 → 停；称重地面坡度未知 → 先问，坡上称重得到的不等于 $W_{fs}$、$W_{rs}$。

**交付物与完成标准**：一张四行表（$W$、$b$、$c$、$b+c$）+ 三条自检结论 + 一句"本章方向声明"。

1. **锁方向（先做，最贵的一步）**
   - 完成标准：在输出里写死一行"**$b$ = 前轴→重心、$c$ = 重心→后轴；$W_{fs}=Wc/L$、$W_{rs}=Wb/L$**（本章方向，与部分英文文献相反）"。不写这一行不得往下算。
2. **算总重并核状态**
   - 完成标准：$W=W_{fs}+W_{rs}$；若同时有厂商总重，写出两者差值与是否含驾驶员/燃油（例题 2 的 3246 lb 就含 200 lb 驾驶员）。
3. **反求 $b$**
   - 完成标准：$b=L\,W_{rs}/W$，保留 4 位有效数字（例题 1：39.64 in）。
4. **求 $c$ 并闭合轴距**
   - 完成标准：$c=L-b$，且 $b+c=L$ **精确**成立（不许分别取整后相加再对）。若要独立算 $c$，用 $c=L\,W_{fs}/W$ 交叉核对，两者差 <0.01 in。
5. **三条自检（缺一不可）**
   - ①$W_{fs}+W_{rs}=W$；②$b+c=L$；③反代 $Wc/L\to W_{fs}$、$Wb/L\to W_{rs}$，误差 <0.1%。
   - 判停：若①③不成立而输入无误 → 检查是否把 $b$、$c$ 互换了（方向错会让两轴读数整体互换，而 $b+c$ 仍然成立，所以**只有①②还不够**）。
6. **交付**
   - 完成标准：一句话"该状态 $W=3246$ lb、$b=39.15$ in、$c=66.85$ in，$b+c=106$ in ✓；前轴重故 $c>b$"，并声明这是水平静止口径。

**计算约定（原书未规定，本卡设定）**：**全章英制；公制输入必须先换算，不许直译** —— 1 kg = 2.205 lb；1 t（公吨）= **2204.6 lb**（不是 2000 lb），故"1.5 吨"= 1500 kg = **3307 lb**；1 in = 25.4 mm；1 lb/in = 0.1751 N/mm。**最常见错**：把"1.5 吨"当 1500 lb（差 2.2 倍），而量纲一致、所有自检照样通过，只是结果整体偏小：$b$、$c$ 报 2 位小数（in）、中间量不提前舍入；$W$ 取整数 lb；$g=32.2$ ft/s²（本卡不出现）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **把 $b$、$c$ 按"其他书"的方向代入。** 很多英文文献是 $b$ = 重心→后轴、$c$ = 重心→前轴，且公式写成 $W_f=Wb/L$、$W_r=Wc/L$。跨书搬公式必须**整组互换**，只换一个会让两轴读数整体互换而自检①②照样通过——这是本章最难自查的错误（H3）。
- **在坡道上称重。** 坡上只有 $W\cos\theta$ 压向路面，读数偏小且前后分配被 $\theta$ 改写；本卡的公式要求水平静止。
- **拿它算加速、制动、上坡的轴荷。** 静载荷不含 $h$：$a_x=0.3g$、$h/L=0.2$ 时转移量已占 6%，用静值代动态值会系统性错（见 `acceleration-load-transfer` B 段）。
- **只有总重与轴距就来求 $b$、$c$。** 两个未知量一个方程，无解；必须有一组实测/厂商的两轴分配。
- **把"载荷在车内两轴间怎么分配"当通用规则。** 原文只援引 MVMA 的"前排乘客 49% 前 / 51% 后"，没有通用分配方法；别的车型、别的座位不能照搬。
- **把空载 $b$、$c$ 用到满载工况。** 载荷状态变了 $b$、$c$ 就变了；例题 2 的 2047/1199 已含 200 lb 驾驶员，不是空载值。

### 作者在书中警告的失败模式

- 本章没有为本条写失败模式；但作者在 1.4.3 明确"正坡度导致载荷由前轴向后轴转移"，等于提醒：**静止式不能带进坡道工况**。
- ce08（用静态轴荷算附着力）与本卡配对：本卡的输出是"输入"，不是"性能结论"；把 $W_{fs}\mu$ 当可用附着力，是本章最常见的越界。

### 作者的盲点 / 时代局限

- 全章英制且无换算表（lb、in、ft/s²）；$b$、$c$ 的口径靠"前轴距重心"一句自注锁定，没有独立定义段。
- 未讨论测量不确定度：地磅精度、燃油/乘员状态、左右不等重（横向偏载）对 $b$ 的影响原文全无。
- 未给"载荷移动后如何修正 $b$、$c$"的方法（只能重称或按质量矩手算）。

### 容易混淆的邻近方法论

- **$b$ vs $c$**：本章与多数文献方向相反（见 §3.3 式三条证据）。判别口诀：用 $W_{rs}=Wb/L$ 试一次，**$b$ 大 ⇒ 后轴重**；若某文献"$b$ 大 ⇒ 前轴重"，那本书与本章相反。
- **静载荷 $W_{fs}$ vs 动态载荷 $W_f$**：带 $s$ 下标（static）是常数，不带的是 $a_x$、$\theta$ 的函数（例题 2：2047 → 1892.2）。
- **$b$、$c$（几何）vs $W_{fs}$、$W_{rs}$（结果）**：反求时容易把两者当同一层；$b$、$c$ 是因，轴荷是果。
