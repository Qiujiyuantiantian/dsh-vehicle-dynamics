# 拖挂爬坡：先把拖车拆出来解拖钩力，再用 $\mu W_{driven}$ 判哪个驱动形式更强

## R — 原文 (Reading)

> **原书要点**（p38–40 §1.5 例题3，例题内式(1)-(5)）：要写出附着受限的爬坡能力式，第一步是把船和拖车整体拿出来单独作自由体，先解出拖钩处的力随坡角怎么变；四个方程正好配四个未知数，于是这些量都能定下来。至于前轮驱动的情况，能用的牵引力上限就是前轴那份载荷乘上地面摩擦系数 $\mu$。
>
> **原书要点**（p40 §1.5 例题3、例题内式(1)–(5)）：例题里前轴的静止份额本来就偏大（占总重的 57%），可一旦上坡，重量会顺着车身纵轴往后挪，于是反倒是后轮驱动的方案能爬得更陡。
>
> — 1.5 例题 3（p38–40，例题内式 (1)–(5)）；结论 p40

## I — 方法论骨架 (Interpretation)

一句话：**挂上拖车之后，"整车"不再是一个自由体——必须先把拖车单独拆出来解出拖钩力，再回到汽车上列轴荷方程，最后令"驱动力需求 = $\mu$ × 驱动轴载荷"求坡度；而比大小只看一件事：驱动轴是不是被上坡卸载的那一轴。**

- 两体分解是唯一正确的入口。拖车两个方程（对拖车接地点取矩 + 纵向力平衡）解出拖钩两分力：
  $$F_{xb}=W_b\sin\theta,\qquad F_{zb}=\frac{W_b\left[f\cos\theta+(h_2-h_3)\sin\theta\right]}{L_t}$$
  其中 $L_t=e+f$ 是拖车轴距（拖钩到拖车轮），$h_3$ 拖车重心高、$h_2$ 拖钩高。$F_{zb}$ 随 $\theta$ 增大而**减小**——上坡时拖钩往下压得轻了。
- 把 $F_{xb}$、$F_{zb}$ 带回汽车的三个方程（对后轮接地点、对前轴、纵向平衡），未知量从 4 个降到 2 个，才解得动 $W_f$、$W_r$。**四方程四未知量**就是这个闭环的计数检查：$F_{xb}$、$F_{zb}$、$W_f$、$W_r$。
- 判据是"不等式转等式"：需求侧 $(W+W_b)\sin\theta$，供给侧 $\mu W_{driven}$（前驱取 $W_f$、后驱取 $W_r$、四驱取 $\mu W$ 的完全防滑情形）。两者相等处即附着受限的最大坡度。
- 排序规则（本卡真正可复用的结论）：**上坡使载荷从前轴移到后轴**（1.4.3），所以 FWD 的驱动轴被卸载、RWD 的驱动轴被加载。即使前轴静载占 57%，RWD 仍可能胜出——这不是反例，是同一机制的必然。判据一句话：**看驱动轴是不是被卸载的那一轴。**
- 四驱的上限最简：完全防滑传动下 $\theta=\mu W/(W+W_b)=\mu/(1+\zeta)$，$\zeta=W_b/W$。不具备完全防滑的 4WD，原文明确说"需要更复杂的方法"，即本卡三式不适用。
- 三个数（10.18% / 11.42% / 19.44%）只能当"原书报告值"引用：FWD/RWD 的闭式解 OCR 残缺，RWD 的 11.42% 用对称转移模型复现不出（只得 9.18%），4WD 式按 $\zeta=0.4494$ 算得 20.70% 与书中 19.44% 差 6%。**方向与排序稳健，绝对值不可当基准。**

## A1 — 应用示例 (Application Example)

### 示例 1：例题 3 的拖车自由体（原书例题）

- **类型与来源**：**原书例题**（例题 3，p38–40）。旅行车 1520/1150 lb（$W=2670$）、$h_1=24.5$、$L=120$；拖钩高 $h_2=14$、距后轮 $d=23$；小艇/拖车总重 $W_b=1200$、拖钩负载 250 lb、$L_t=110$、$h_3=35$；$\mu=0.3$。
- **方法的使用**：①由题给拖钩负载反解拖车重心位置 $f=F_{zb}L_t/W_b=250\times110/1200=22.92$ in，$e=110-22.92=87.08$ in；②代 $F_{zb}(\theta)$；③$F_{xb}=W_b\sin\theta$。
- **结论/结果（复算值）**：$\theta=0$ 时 $F_{zb}=\mathbf{250.0}$ lb——**与题给拖钩载荷精确吻合**，这是本例最硬的一条自检（它也反证 $f=22.92$ 是 250 lb 的等价写法）。$\theta=0.06$ → $F_{zb}=\mathbf{235.8}$ lb、$F_{xb}=\mathbf{71.9}$ lb；$\theta=0.1944$ → $F_{zb}=\mathbf{201.0}$ lb、$F_{xb}=\mathbf{231.8}$ lb。趋势：上坡 → 拖钩下压减轻、牵引力增大。

### 示例 2：例题 3 的三档答案（引用数据，非本卡复算）

- **类型与来源**：**原书报告值**（例题 3 计算结果，p40）。**只作引用，不得当黄金测试基准。**
- **FWD 10.18%（书中 5.84°）、RWD 11.42%（6.51°）、4WD 19.44%（11.0°）**，前轴静载占 $1520/2670=57\%$。
- **如实标注的三处不自洽**：①4WD 按 $\theta=\mu/(1+\zeta)$、$\zeta=1200/2670=0.4494$ 得 **20.70%**，与书中 19.44% 差 6%（要凑 19.44% 需 $\zeta=0.5432$，即 $W_b=1450=1200+250$，把拖钩载荷放在"总重 1200"之外另计）；②RWD 的 11.42% 用对称转移模型只得 **9.18%**，闭式解 OCR 残缺，**不引用公式**；③10.18% 的反正切是 **5.813°**，书中 5.84° 是 arcsin 反算（H9）。
- **独立重建（ce24）**：按原文几何由四方程数值解，得 FWD≈**10.9%**、RWD≈**11.6%**、4WD≈**20.7%**，与书中三档差 3%–7%。**这就是本 Bundle 能诚实交付的上限。**

### 示例 3：排序结论的一次新输入演练（合成演练，非书中事实）

- **类型与来源**：**合成演练**。新车：前轴静载 60%（≠ 本例 57%）、$h/L=0.2$、$\mu=0.3$、上坡、拖挂 $\zeta=0.3$。只判方向，不引用任何百分点。
- **方法的执行**：①机制一——上坡 $Wh\sin\theta/L$ 使 $W_f$ 减、$W_r$ 增，前轴被卸载；②机制二——FWD 分母含 $+\mu h_1/L$（载荷转移削弱附着），RWD 含 $-\mu h_1/L$（载荷转移变成增益）。
- **结论/预期输出**：**判 RWD 更强**，FWD 最弱，4WD 最高（完全防滑时）。两法同向；**不得**给出 10.18% 这类具体数值。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 买/改一辆车要去拖挂（拖船、拖房车），问"这车能不能把这东西从坡上拖上来"。
2. 问"为什么前轴更重的前驱车，爬坡反而不如后驱"。
3. 已有拖钩垂直载荷，要算坡度变化时它怎么变、对前轴卸多少。
4. 要评估 FWD/RWD/4WD 三种配置在同一拖挂条件下的相对优劣。
5. 拿到书中 10.18%/11.42%/19.44% 三个数，想知道能不能当基准用（不能）。

### 语言信号（中英双写）

- 「拖挂爬坡能力」「这车能拖船爬多陡」「前驱拖车爬坡行不行」「拖钩载荷对轴荷的影响」
- 「为什么前轴 57% 反而爬坡差」「FWD RWD 4WD 爬坡对比」「附着受限坡度」
- 「gradeability」「towing capability」「hitch load」「traction limited grade」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `dynamic-axle-load-general-form`：那张卡处理"给定拖钩力求轴荷"；本卡自己解拖钩力，并把结果接到附着判据上求坡度。
- 与 `grade-axle-load-and-grade-angle`：那张卡给"坡度 → 轴荷"，无拖挂、无附着判据；本卡是它的拖挂 + 能力版。
- 与 `axle-load-sum-diagnostic`：本卡的汽车轴荷必须满足 $W_f+W_r=W\cos\theta+F_{zb}$；和不对先回那张卡。
- 与 `sign-convention-and-moment-direction-check`：本卡用的是例题内局部式，力矩**逆时针为正**，与 1.4 节相反，必须显式声明。

## E — 可执行步骤 (Execution)

**必需输入**：汽车 $W$、$W_{fs}$、$W_{rs}$、$h_1$、$L$、拖钩高 $h_2$、拖钩距后轴 $d$；拖车 $W_b$、$h_3$、$L_t$（$=e+f$）、拖钩垂直载荷 $F_{zb}(0)$（或 $f$、$e$）；$\mu$。全部英制（lb、in）。

**缺什么必须问**：缺 $\mu$ → **停**（$\mu$ 直接决定上限，猜一个等于给出假答案）；$f$ 与 $e$ 都缺且无拖钩载荷 → **停**（拖车重心位置不可定）；缺 $h_2$、$d$ → 停（拖钩力的两个力臂）；$\mu$ 是否对应湿滑/干路未说明 → 先问，并声明"$\mu$ 为常数"。

**交付物与完成标准**：拖车自由体两式 + $F_{zb}(\theta)$、$F_{xb}(\theta)$ 的数值 + 三种驱动形式的**排序结论** +（若要数值）"原书报告值 + 重建值 ±3%–7%"两列 + 一句"附着受限上限、非实际能力"。

1. **声明约定（先做）**
   - 完成标准：写出"用例题内局部式 (1)–(5)，力矩**逆时针为正**（与 1.4 节顺时针相反）；单轴拖车、刚体、拖钩高度不随坡度和载荷变化"。
2. **拆拖车、解拖钩力**
   - 完成标准：$\Sigma T_y=0=W_bh_3\sin\theta+F_{zb}(e+f)-W_bf\cos\theta-F_{xb}h_2$ 与 $\Sigma F_x=0=F_{xb}-W_b\sin\theta$ 两式齐备；解出 $F_{xb}=W_b\sin\theta$、$F_{zb}=W_b[f\cos\theta+(h_2-h_3)\sin\theta]/L_t$。
   - **自检（强制）**：$\theta=0$ 时 $F_{zb}$ 必须精确回到题给拖钩载荷（例题 3：250.0 lb）。回不去 → $f$ 或 $L_t$ 取错。
3. **带回汽车三式**
   - 完成标准：对后轮接地点 $\Sigma T_y=0=Wh_1\sin\theta-Wc\cos\theta+F_{zb}d+F_{xb}h_2+W_f(b+c)$ 等三式写出，并数未知量：初始 4（$F_{xb}$、$F_{zb}$、$W_f$、$W_r$），第 2 步已解 2 → 剩 2，方程 2 → **闭合**。计数不闭合 → 漏了接触点。
4. **接附着判据**
   - 完成标准：$\mu W_{f}$（FWD）或 $\mu W_{r}$（RWD）或 $\mu W$（完全防滑 4WD）与 $(W+W_b)\sin\theta$ 相等，解出 $\theta$；输出必须写"**附着受限上限**"，并与功率受限区分。
5. **判停点（三条）**
   - ①用户要求 FWD/RWD 的**绝对坡度百分比**：**停**——原书闭式解 OCR 残缺、答案与式子不自洽（G-03）。只能给"原书报告值（10.18/11.42/19.44%）+ 独立重建值（10.9/11.6/20.7%，±3%–7%）"，并标注二者不一致。
   - ②用户要求引用 FWD/RWD 的**闭式公式**：**停**——不引用（分子被 OCR 成 $\mu L$ 与"分子代表前轴静载"自相矛盾）。
   - ③$\mu h_1/L\to1$（RWD 分母 $1-\mu h_1/L\to0$）：**停**——模型在该边界外发散，原文未讨论。
6. **交付**
   - 完成标准：一句排序结论"上坡卸载前轴，故 FWD 最弱、RWD 更强、完全防滑 4WD 最高"，附 $F_{zb}$ 与 $F_{xb}$ 的数值与 $\theta=0$ 自检；数值另附"报告值/重建值"两列并注明不可复现。

**计算约定（原书未规定，本卡设定）**：$\theta$ 用弧度、结果同时给 % 与 °；$F_{zb}$、$F_{xb}$ 报 1 位小数（lb）；百分点差用"重建值 − 报告值"表示并标注百分比；$g=32.2$ ft/s²（本卡推导不显含）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **把 10.18% / 11.42% / 19.44% 当黄金基准或实测值。** 三档里有 1 档与印刷式差 6%、1 档复现不出；独立重建差 3%–7%。它们只能作"原书报告值"引用（ce20、ce24、G-03）。
- **引用 FWD/RWD 的闭式解。** OCR 括号不配对、分母缺项，且 FWD 式块的分子写成 $\mu L$，与紧随其后"分子代表作用在前轴的静态重力"直接冲突。**只能引用答案，不引用公式**（H8、ce24）。
- **用 $\theta=\mu/(1+\zeta)$ 复算 4WD 后宣称书中答案错。** 该式与答案不自洽是原书题面口径问题（$250$ lb 是否含在 $1200$ lb 内，ce19）；正确姿势是**两读法都列、标明书中答案对应读法 B、并注明与题面矛盾**（H7）。
- **把题干"前驱（AWD）"当第四种配置。** 是笔误，应为 FWD；下文与答案只给三档，前驱对应最小值（H10、ce23）。
- **把结果说成"这车实际能爬多陡"。** 三式前提是 $a_x=0$（稳态匀速）、忽略滚阻、$\mu$ 为常数；实际还受功率/扭矩、$\mu$ 随滑移与温度变化、传动系统是否真有防滑差速器、拖挂纵向冲击四重约束（ce20）。
- **把它用到不具备完全防滑功能的 4WD 上。** 原文明确"其求解需要更复杂的方法"，本章三式不适用。
- **混用两套力矩正方向。** 例题内式是逆时针为正、1.4 节是顺时针为正；只改部分项会让两轴载荷互换或出现负值（ce09）。
- **把章内编号 (1-1)~(1-11) 与例题局部的 (1)–(5) 混写。** 引用必须写"例题内式 (n)"（H11）。

### 作者在书中警告的失败模式

- ce17：按静轴荷配比判断驱动形式优劣（"前轴 57% 所以前驱强"），方向恰好相反。
- ce20：把附着力上限当实际爬坡能力（跨车型、跨路面直接套用）。
- ce19：拖钩载荷 250 lb 被当"附加重量"重复计入（或反过来只当垂直力、忘了它来自拖车自重）。
- ce24 / ce23：照抄 OCR 残缺的三条闭式解、照抄"前驱（AWD）"。

### 作者的盲点 / 时代局限

- 例题 3 是"手算 + 小角度近似"的产物，答案本身不是精确基准（ce25：三档角度换算口径不一致）。
- 假设拖车刚体、拖钩高度不随载荷与坡度变化（例题括号内明说），忽略纵向冲击。
- 只讨论上坡；下坡（载荷前移、前驱占优）与拖车下坡制动原文未讨论，若要使用必须标"由本章机制外推"。
- 功率受限、无锁止四驱、$\mu$–滑移依赖全部章外。

### 容易混淆的邻近方法论

- **附着力（$\mu W_{driven}$，上限）vs 牵引力（$(W+W_b)\sin\theta$，需求）**：爬坡能力问题就是令两者相等；混淆会得出"驱动力越大爬坡越强"而忽略轴荷限制。
- **$F_{zb}$（拖钩对汽车的垂直力）vs $W_b$（拖车总重）**：前者只是后者通过拖钩传过来的那一份（例题 3 中 250/1200 = 20.8%）。
- **$W$（汽车）vs $W+W_b$（系统）**：需求侧用系统总重，供给侧只用 $W_{driven}$，两者不能混。
- **排序结论（稳健）vs 绝对百分比（不可复现）**：本卡可交付前者，交付后者必须带双列标注。
