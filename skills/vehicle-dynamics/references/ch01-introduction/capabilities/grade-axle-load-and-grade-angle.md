# 坡道轴荷与坡度换算：$i=\tan\theta$ 先把 % 变成弧度，再算 $\Delta W'=W\theta(h/L)$

## R — 原文 (Reading)

> **原书要点**（p37 §1.4.3 式1-10/1-11）：所谓坡度，指的就是升高多少与车走了多远之比，数值上等于 $\theta$ 角的正切（$\tan\theta$）。高速公路上正常的纵坡被限制在 4% 以内；等级不高的中等路面，纵坡偶尔会做到 10%～12%。
>
> **原书要点**（p37 §1.4.3 式1-10/1-11）：坡度既然这么小，$\theta$ 的余弦就可以当作 1、其正弦可以直接用角度（弧度）代替；由此也能看出：上坡时前轴会被卸掉一部分载荷，这部分转到了后轴上。
>
> **原书要点**（p37 §1.4.3 式1-10/1-11；p38 例题2）：该小节推出坡道上前、后两轴载荷的式子（小角度近似）；例题 2 则把 6% 的坡度先折成 3.433° 的坡角再代入。

## I — 方法论骨架 (Interpretation)

一句话：**先把坡度百分比按 $\theta=\arctan i$ 换成角度（代入时用弧度），再用与加速工况完全同构的转移量 $\Delta W'=W\,\theta\,(h/L)$ 加加减减——但必须同时记住 $\cos\theta<1$ 会让两轴之和不等于总重。**

- 两条式子：小角度式 $W_f=W_{fs}-Wh\theta/L$、$W_r=W_{rs}+Wh\theta/L$；精确式 $W_f=W(c\cos\theta-h\sin\theta)/L$、$W_r=W(b\cos\theta+h\sin\theta)/L$。小角度式就是精确式在 $\cos\theta\to1$、$\sin\theta\to\theta$ 下的结果。
- 结构与加速工况**同构**：把 $a_x/g$ 换成 $\theta$（弧度）即可。所以"上坡载荷后移"与"加速载荷后移"是同一件事的两种输入，不必背两套。
- 但两者有一个关键差别：**水平加速时两轴之和严格等于 $W$；坡道上等于 $W\cos\theta<W$。** 6% 坡差 5.8 lb（0.18%）、12% 坡差 23 lb（0.71%）、20% 坡差 64 lb（2.0%）。这不是误差，是"只有重力的法向分量压向路面"。
- 换算链只有一条：$i\ (\%)\to\theta=\arctan(i)\to$ 弧度代入。**"% 与 ° 混用"是本章最容易发生且最难自查的量纲事故**：6% ↔ 3.433°、12% ↔ 6.843°、4% ↔ 2.291°，三组数都小到"抄错也看不出来"。
- 符号也在这一层：上坡 $\theta>0$、下坡 $\theta<0$。下坡的真实情况是载荷**前移**；把 $\theta$ 取绝对值会让最危险的长下坡工况算成"前轴卸载"。
- 式 (1-10) 右端第二项在原 OCR 里印成 $W_{rs}$，应为 $W_{fs}$（左端是 $W_f$，且 (1-6) 给出 $W_{fs}=Wc/L$）。引用时必须写 $W_{fs}$。

## A1 — 应用示例 (Application Example)

### 示例 1：例题 2 的坡道分项（原书例题的分项复算）

- **类型与来源**：**原书例题 2 的分项**（p37–38）。同一组参数（$W=3246$ lb、$W_{fs}=2047$、$W_{rs}=1199$、$h=20$ in、$L=106$ in、6% 坡）由本卡单独取出坡度项；**原书并未单列这道"只有坡度"的算例**（例题 2 是坡度 + 加速同时作用）。
- **换算（引用数据）**：$\theta=\arctan0.06=3.4336^\circ=0.059928$ rad。原文印"6% 的坡度等于 3.433° 坡度角（反正切值 0.06）"。
- **方法的使用**：①$i\to\theta$；②$\Delta W'=W\theta h/L$；③$W_f=W_{fs}-\Delta W'$、$W_r=W_{rs}+\Delta W'$；④与精确式对照。
- **结论/结果（复算值）**：$\Delta W'=3246\times0.059928\times20/106=\mathbf{36.7}$ lb；小角度式 $W_f=\mathbf{2010.3}$、$W_r=\mathbf{1235.7}$ lb（和 $=3246$，因为 $\cos\theta$ 被置 1）。
- **精确式对照**：$W_f=2006.6$、$W_r=1233.5$ lb，和 $=\mathbf{3240.1}=W\cos\theta$；与小角度式差 3.7 / 2.2 lb，**合计 5.9 lb ≈ $W(1-\cos\theta)=5.83$ lb**，0.18%。近似代价可量化、可接受。

### 示例 2：同一辆车上 12% 坡（合成演练，非书中事实）

- **类型与来源**：**合成演练**。车仍取例题 2 的参数，坡度改为初级中等路面上限 12%（原文提到"有时会达到 10%～12%"，但**未给这辆车的 12% 算例**）。
- **换算**：$\theta=\arctan0.12=6.8428^\circ=0.119428$ rad；$\cos\theta=0.992878$、$\sin\theta=0.119144$。
- **结论/预期输出**：小角度式 $\Delta W'=3246\times0.119428\times20/106=\mathbf{73.1}$ lb → $W_f=\mathbf{1973.9}$、$W_r=\mathbf{1272.1}$（和 3246）；精确式 $W_f=\mathbf{1959.4}$、$W_r=\mathbf{1263.4}$（和 $\mathbf{3222.9}=W\cos\theta$）。
- **两个可讲的点**：①近似误差升到 14.5 lb（0.74%），全部来自 $\cos\theta$；②**转移量本身几乎没错**（73.1 vs 72.97，差 0.2%）——小角度近似丢的是"总量缩放"，不是"前后分配"。

### 示例 3：坡度换算锚点（引用数据）

- **类型与来源**：**引用数据**（1.4.3 的两个阈值 + 例题 2 的一个锚点）。本卡只做核对，不据此下新结论。
- 4% → 2.291°（0.03998 rad）；6% → 3.433°（0.05993 rad）；10% → 5.711°（0.09967 rad）；12% → 6.843°（0.11943 rad）；20% → 11.310°（0.19740 rad）。
- **原书经验值**：正常高速爬坡 <4%，初级/中等路面 10%–12%（1992 年美国口径，无出处编号）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 给定坡度百分比，问坡上前后轴各多少（爬坡、拖船下水坡道、地库入口、装卸台）。
2. 手上只有"12% 坡"这种说法，要换算成角度或弧度才能代公式。
3. 想解释"为什么坡上两轴之和小于总重"（本题的机制一半在本卡）。
4. 长下坡制动/拖挂下坡前，要判断前轴是加载还是卸载。
5. 核对别人的结果：坡道项有没有用 $\theta$ 的弧度、有没有把 $W_{fs}$ 写成 $W_{rs}$。

### 语言信号（中英双写）

- 「12% 坡是多少度」「6% 坡度角」「坡上前后轴载荷」「上坡轴荷转移」「下坡前轴更重吗」
- 「grade percent to degrees」「road grade」「arctan 坡度」「坡度 0.06 是多少度」
- 「为什么坡上轴荷加起来不等于总重」（本卡给机制，判定归 `axle-load-sum-diagnostic`）

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `acceleration-load-transfer`：同构（$a_x/g\leftrightarrow\theta$）但前提不同——那张要 $a_x\ne0$、$\theta=0$；本卡要 $\theta\ne0$、$a_x=0$。两者并存时都不能用，回 `dynamic-axle-load-general-form`。
- 与 `dynamic-axle-load-general-form`：本卡是它在 $a_x=D_A=R_h=0$ 处的退化；有拖钩或风阻时必须回一般式。
- 与 `axle-load-sum-diagnostic`：本卡解释"和为什么小于 $W$"，那张卡判"什么时候这个差值是错的"。
- 与 `towing-gradeability-analysis`：本卡给轴荷，不给"能爬多陡"；后者以本卡的 $\theta$ 口径为输入，但绝对百分比不可复现（G-03）。

## E — 可执行步骤 (Execution)

**必需输入**：坡度（% 或 °，**须注明哪一种**）或 $\theta$；$W$、$W_{fs}$、$W_{rs}$、$h$、$L$（lb、in）。

**缺什么必须问**：只给"陡坡"这类定性别 → 停，要一个数；给出"12"而不说 % 还是 ° → 停（差 4.7 倍）；缺 $h$ → 停（本卡一切乘 $h$）；$W_{fs}+W_{rs}\ne W$ → 先核对载荷状态。

**交付物与完成标准**：$\theta$（度 + 弧度两列）+ $\Delta W'$ + $W_f$、$W_r$ + 与精确式的差距 + 一句"坡度按正切"的口径声明。

1. **认口径（先做）**
   - 完成标准：写出"坡度 $i=\tan\theta$，分母取**水平投影**；若原始数据是'沿坡面行驶距离'之比，那是 $\sin\theta$，须换算后再用——本章按正切"。**H12：原书定义句有 sin/tan 歧义，冲突按"正切"定案。**
2. **换算角度**
   - 完成标准：$\theta=\arctan(i)$，同时给度与弧度；$i$ 若已是角度，则 $i=\tan\theta$ 反核一次。锚点自检：6% → 3.433°（0.05993 rad）。
   - 判停：$\theta$ 用度数直接代入 $\sin\theta\approx\theta$ → 错 57.3 倍，必须用弧度。
3. **定符号**
   - 完成标准：上坡 $\theta>0$、下坡 $\theta<0$，并在输出回显"上坡/下坡"字样；下坡必须验"前轴加载"（$W_f>W_{fs}$）。
4. **算转移量并加减**
   - 完成标准：$\Delta W'=W\theta h/L$（$\theta$ 用弧度）；$W_f=W_{fs}-\Delta W'$、$W_r=W_{rs}+\Delta W'$；引用式 (1-10) 时右端写 $W_{fs}$（不是 $W_{rs}$，H5）。
5. **判是否要精确式（判停点）**
   - 判据：$i\le12\%$ 可用小角度式，但**必须写出 $\cos\theta$ 造成的和差**（$W(1-\cos\theta)$：6% 为 5.8 lb、12% 为 23 lb）；$i>20\%$ 或用户要求精确值 → 走精确式 $W(c\cos\theta-h\sin\theta)/L$。
   - 完成标准：小角度式与精确式的 $W_f$、$W_r$ 并列给出，差值归因到 $\cos\theta$（而不是归因到算术）。
6. **交付**
   - 完成标准：一句话"6% 坡 $=3.433^\circ=0.05993$ rad，转移 36.7 lb：$W_f=2010.3$、$W_r=1235.7$（小角度）；精确 2006.6 / 1233.5，和 3240.1 $=W\cos\theta$"，并声明坡度按正切、$\theta$ 用弧度。

**计算约定（原书未规定，本卡设定）**：$\theta$ 报 3 位小数（°）与 5 位小数（rad）；轴荷 1 位小数（lb）；小角度式与精确式**并列**输出，不只给小角度式。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **把"6% 坡"当"6°"代入。** 两者差 43%（$6\%=3.433^\circ$）。凡公式里 $\sin$ 与 $\tan$ 混用而无换算说明，一律判错（ce12）。
- **把度数代进 $\sin\theta\approx\theta$。** 小角度近似要求弧度；用度会错 57.3 倍。本书式 (1-10)(1-11) 里的 $\theta$ 是弧度。
- **照抄式 (1-10) 的右端第二项。** OCR 印 $W_{rs}$，应为 $W_{fs}$；写错等于把前轴静载换成后轴静载（H5）。
- **下坡把 $\theta$ 取绝对值。** 下坡真实是载荷前移；取绝对值会把长下坡/拖挂下坡这个最危险工况算成最安全（ce13）。
- **用"两轴之和 = 总重"去校核坡道结果。** 坡上恒有 $W_f+W_r=W\cos\theta<W$，差 $W(1-\cos\theta)$。（判定见 `axle-load-sum-diagnostic`。）
- **在 20% 以上坡度继续用 $\cos\theta\approx1$。** 20% 时误差 2.0%，越野坡、装卸台、拖船坡道常超此值，须走精确式。
- **把原书的两个坡度阈值当现行规范。** "<4% / 10%–12%"是无出处的 1992 年美国工程经验值，引用须标"原书经验值"，不能当法规。

### 作者在书中警告的失败模式

- ce12：% 与 ° 混用（定义型错误，作者明确定义坡度=正切，违规即错）。
- ce13：上坡 $\theta$ 正、下坡 $\theta$ 负填反（作者明说"上坡坡度的角度是正值……下坡坡度这个值为负"）。
- ce25：连原书自己都串过一次口径——例题 3 的 10.18% 对应 5.84° 是 **arcsin** 反算的，按 arctan 应为 5.81°。**以 % 为准**。
- ce14：以为坡上两轴之和等于总重（作者自问自答）。

### 作者的盲点 / 时代局限

- 没给"多大坡度之后小角度近似失效"的定量界线，只明示 10%–12% 仍在使用（本卡补算：12% 时 $\cos\theta$ 误差 0.71%，20% 时 2.0%，属补充而非原文）。
- 定义句"上升高度/行驶距离"若按沿坡面距离读则是 $\sin\theta$，与"即正切值"矛盾（H12）；本章按正切采用。
- 隐含前提 $a_x=0$、$D_A=0$、无拖挂，1.4.3 未重复声明。
- 未讨论坡度与侧倾、单侧车轮载荷的耦合（那是横向载荷转移，章外）。

### 容易混淆的邻近方法论

- **$i$（%）vs $\theta$（°）vs $\theta$（rad）**：三个数在 6% 附近分别是 0.06、3.433、0.05993——数值上 $i\approx\theta_{rad}$，正因为近似相等才最容易抄错。
- **小角度式 vs 精确式**：和一个是 $W$、一个是 $W\cos\theta$；混用会让"求和自检"误报。
- **$\Delta W'$（坡度转移）vs $\Delta W$（加速转移）**：同构、前提互斥。
