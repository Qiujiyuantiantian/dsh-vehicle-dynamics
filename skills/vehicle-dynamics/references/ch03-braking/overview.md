## 一句话主旨

**制动性能的瓶颈不在制动器，而在「哪个轮先抱死」——所以整章的重心是把前后制动力按载荷转移配平，让抱死顺序可控，并用制动效率这一个数衡量配平的好坏。**

## 骨架（八步递进：输入 → 系统 → 判据 → 评分）

1. **基本方程是牛顿第二定律的减法**：$D_x=\Sigma F_x/M$，由此派生 $SD=V_0^2/(2D_x)$ 与 $t_s=V_0/D_x$——**距离与速度平方成正比，时间与速度成正比**。
2. **除制动器外还有四种力**：滚动阻力（≈0.01 g）、空气阻力（∝$V^2$，$C_D$ 带量纲）、传动系统阻力（**随减速度符号翻转**）、坡度（上坡帮/下坡害）。
3. **制动器提供的是力矩**：$T_b=G\cdot P_a$、$F_b=T_b/r$；鼓式的制动因数含自增势项（增益换稳定性），摩擦材料会衰退（fade），需要磨合（burnish）。
4. **轮胎-路面摩擦是天花板**：$\mu$-滑移曲线有峰值（10%–20%），峰值本身是**不稳定平衡**——ABS 的全部意义就是让车轮待在峰值附近而不是滑移区。
5. **动态载荷转移把「能刹多狠」与「配比对不对」耦合起来**：减速时前轴加载、后轴卸载，$W_d=(h/L)(W/g)D_x$。
6. **配比设计的核心冲突**：固定配比（1 个自由度）穿不过轻载/满载 × 干/湿的多个效能三角形（2N 个约束），所以要么折一次（压力比例阀），要么感测载荷/减速度，要么上 ABS。
7. **抱死顺序决定失控方式**：前轮先抱 → 失转向但方向稳定；后轮先抱 → 横摆正反馈发散。设计共识是取偏大前制动力——**是两害相权，不是安全**。
8. **制动效率 $\eta_b$ 是唯一可横向比较的配平指标**：效率低 → 摩擦需求右移 → 抱死频次上升（此链条的定量部分不可复现，只能定性）。

**论证链**：牛顿定律 → 等减速解 → 加风阻的积分解 → 四种非制动器阻力 → 制动器力矩与增益 → μ-滑移特性 → 动态载荷转移 → 两条最大制动力线 → 交点（理想点）→ 固定配比失败 → 阀/感载阀/惯性阀/ABS → 效率定义与计算 → 后轮抱死的不稳定性 → 抱死频次 → 踏板力增益 → 例题表格验证整条链。

## 核心命题（用自己的话）

1. 制动距离对速度是二次的：**降速比增力更有效**。
2. 配比不是自由参数，它被「减速时前轴加载」这一物理事实约束。
3. 固定配比不可能对所有工况最优，这是**结构性限制**（1 自由度 vs 2N 约束），不是设计者偷懒。
4. 前后轴同时抱死是理想但几乎不可实现，因此必须选一个「更可接受」的失效方向——**选前轮**。
5. 后轮抱死不是「刹不住」，而是**方向发散**；短轴距轿车普通驾驶者救不回来。
6. 制动效率低会让同一辆车在同样路面上更早抱死：**效率不是评分，是抱死频次的预测器**（定量部分不可复现）。
7. 人机工程（踏板力增益）决定驾驶者能否用出车辆的全部制动能力——**能力不等于可用能力**（本章无判据，只能定性）。

## 六处口径与硬伤（下游一律按此处理，不擅自改原文）

1. **$\eta_b$ 分母口径冲突（最重要）**：式(3-33) 写 $\eta_b=D_{act}/\mu_p$（路面峰值），例题 3.12 全表实际用 $\eta_b=D/\max(\mu_f,\mu_r)$（该压力点最高轴制动系数）。两者只在「该轴恰好用满路面 $\mu_p$」时相等（例题 400 psi 行即此情形）。阶段 1.5 登记同一工作点可差 **27 个百分点**（N1、300 psi：88.7% vs 61.7%）；本次复算该工作点为 88.7%（max 口径）与 70.5%（$\mu_p=0.70$），差 18.2 点。**故不写死差值，只强制每次计算声明口径；跨口径比较一律无效。**
2. **本章内部矛盾（线性化）**：式(3-23)(3-24) 与所有直线边界/交点/三角形都假设「$\mu_p$ 与载荷无关」，而 3.4.3 说 +10% 载荷 → 制动系数 −0.01。凡用上述任一条，必须同时声明「忽略载荷敏感性」；「边界线是弯的」只能作 ⚠️ 推断。
3. **SN 口径**：文中把「SN 81」当 $\mu_p=0.81$ 用。按 ASTM E274（$SN=100\mu$）这**换算本身成立**，错的是原文「一般假定此数值与摩擦系数相同」这句（数值相等）；且 SN 由**标准试验胎**测得，不是本车轮胎的实际 $\mu_p$。凡依赖处必须标注。
4. **$C_D$ 带量纲**（lb·s²/ft²，$=\tfrac12\rho C_dA$）：式(3-8)~(3-10) 只在该口径下成立；用户给无量纲 $C_d$ 必须先换算，换不出就停算。
5. **$F_b$ 同字母双义 + 三处 OCR 串号**：$F_b$ 在 3.1.2 节＝前后制动力之和、在 3.3/3.7 节＝单轮；式(3-31) 的 $G\cdot T_a/r$ 应为 $G\cdot P_a/r$；式(3-7) 分母 $F_{x1}$ 应为 $F_{xt}$；式(3-22) 的 $W_{r0}$ 即 $W_{rs}$；式(3-27) 的 $n/L$ 应为 $h/L$；式(3-18) 的 $I_b$ 应为 $T_b$。
6. **两处图无可用数值**：图 3.16（抱死频次）的 8 个标签与 6 个横轴刻度的对应关系丢失；图 3.17（踏板力增益）阴影区无上下边界数值，顶部 1.0/0.065/0.037/0.021/0.012/0.007/0.004 是坐标轴标度而非带宽边界。**二者只能定性，严禁编造阈值。** 另：例题 3.5 的 $t_s$ 在平均功率式内印作 4.996 s（应 4.966 s）、初始风阻印 74.4 lb（应 72.4 lb）；例题 3.12 表 500 psi 行 $\mu_f$ 印 0.6617（应 0.617）；原注(1)「效率随减速度增加而降低」与表非单调矛盾 → **照表不照注**。

## 批判与时代局限（B 段素材来源）

- **1992 年液压系统视角**：压力比例阀是主角，几乎没有 EBD；现代车基本用 EBD 替代了比例阀，ESC 会掩盖部分失稳但不消除力学机制。
- **法规只讲美标**：只有 FMVSS 105/121，无 ECE R13、无 GB 21670；105 只考干路（SN 81），**合规 ≠ 安全**。
- **四个未被证明的假设**：$\mu_p$ 是单一常数（忽略滑移率/速度/温度/胎压）、载荷转移按准静态、力矩-压力线性（忽略迟滞与衰退）、同时抱死判据基于单点 $\mu_p$。
- **最强反对意见**：「这一章教的是准静态配比设计，但真正的制动性能由瞬态决定：压力建立时间、ABS 循环频率、热衰退曲线。用本章的稳态三角形去评价一辆带 EBD+ESC 的现代车，结论会系统性地乐观。」作者的防线是把 ABS 与效率当作「配平不够好时的补救」，并承认固定配比的结构性失败。
- **作者自己承认的破口**：$\eta_b$ 的定义依于不可复现的 $\mu_p$，因此「拿效率做法规并不成功」；鼓式力矩在单次制动中「下陷」，静态配比图只代表起点。
