# 决策规则速查 — 《车辆动力学基础》第 3 章 制动性能

| 能力 | 一句话规则 |
|---|---|
| 制动距离与停车时间：$SD=V_0^2/(2D_x)$、$t_s=V_0/D_x$，高初速再走风阻闭式解 | 先组 $\Sigma F_x$（阻力逐项带符号）→ $D_x=\Sigma F/M$ → $t_s=V_0/D_x$、$SD=V_0^2/(2D_x)$；$F_a/F_b\ge2\%$ 且 $V_0\ge60$ mph 才转风阻闭式解，并用 $t_sD_x=V_0$ 与 $SD\propto V_0^2$ 自检。 |
| 制动效率七步表格法：$\eta_b=D/\max(\mu_f,\mu_r)$，表就是交付物 | 以 $P_f$ 为自变量按七步填十列表（$P_r$ 分段→$F=2GP/r$→$D$→$W_f/W_r$→$\mu_f/\mu_r$→$\eta_b=D/\max$），逐行自检 $W_f+W_r=W$ 与 $\max\le\mu_p$，读表即诊断（谁先到极限、配比偏前/偏后）。 |
| 抱死顺序与后果：工作点在线的哪一侧，决定「失转向」还是「横摆发散」 | 算两轴利用率 $u_f=F_{xf}/F_{xmf}$、$u_r=F_{xr}/F_{xmr}$ 比大小，先到 1 的先抱；前抱＝失转向但方向稳定（能力归零，不是安全），后抱＝横摆正反馈发散（短轴距轿车不可救）。 |
| 前后轴最大制动力边界线：联立消去 $D_x$，两条直线划出抱死域 | 前界 $F_{xmf}=\mu_p[W_{fs}+(h/L)F_{xr}]/(1-\mu_ph/L)$、后界 $F_{xmr}=\mu_p[W_{rs}-(h/L)F_{xf}]/(1+\mu_ph/L)$；斜率只由 $\mu_ph/L$ 定、截距只由载荷定，交点处 $F_{xfi}+F_{xri}=\mu_pW$ 是最强自检。 |
| 制动力配比设计与评价的九步总流程（编排层） | 九步：输入口径→载荷转移→边界线→交点/理想 k→三角形与交集→机构选型→配比线→抱死顺序+效率→人机（定性）；计算类从第 2 步进、选型类从 4–5 步进、诊断类从 7–8 步反向进。 |
| 动态载荷转移：$W_d=(h/L)(W/g)D_x$，前轴加、后轴减，和恒等于 $W$ | $W_d=(h/L)MD_x$（或 $(h/L)WD$）→ $W_f=W_{fs}+W_d$、$W_r=W_{rs}-W_d$；必须写自检 $W_f+W_r=W$，并算离地临界 $D_{crit}=W_{rs}/((h/L)W)$。 |
| 同时抱死点与理想配比斜率 $k(\mu_p)$ | $F_{xfi}=\mu_p(W_{fs}+\mu_pWh/L)$、$F_{xri}=\mu_p(W_{rs}-\mu_pWh/L)$，交点处 $D=\mu_pg$；换算出 $k(\mu_p)=F_{xfi}/F_{xri}$ 当标尺，$\mu_p\to0$ 时退化为静态轴荷比。 |
| 效能三角形与多工况交集：把「配比够不够」变成可行域问题 | 每个工况画一个三角形（两条抱死边界 + 一条等减速度线 $F_{xf}+F_{xr}=MD_{target}$），多工况求交集；$D_{target}>\mu_pg$ 即不可达；交集为空是几何过约束，不是调参。 |
| 配比线斜率：增益定直线、比例阀定折点 | 等压段斜率 $=G_f/G_r$（半径与每轴制动器数约掉），拐点后 $=(G_f/G_r)/k$ 且**过拐点不过原点**；与 $k(\mu_p)$ 比大小即得偏前/偏后预判。 |
| 压力比例阀两段式：拐点压力与增量比 | $P_a\le P_{knee}$ 时 $P_f=P_r=P_a$；超过后 $P_r=P_{knee}+k(P_a-P_{knee})$，k 只作用于增量；反算 $P_a=P_{knee}+(P_r-P_{knee})/k$。 |
| 固定配比无解时的方案选择：按差异来源选机构，选完必须复验 | 交集为空 → 问「差异来自载荷还是减速度幅值」→ 感载阀 / 惯性阀 / 压力比例阀 / ABS（各自测什么量）→ 叠回三角形复验 → 兜底工况先抱前轮才是可接受。 |
| 从作用压力到地面制动力：$T_b=G\cdot P_a$、$F_b=T_b/r$，整轴乘每轴制动器数 | $T_b=G P_a$ → $F_w=T_b/r$ → $F_{axle}=nF_w$；量纲自检 in·lb/psi ÷ in = lb，并用 $2G/r$（lb/psi）作轴系数；与 $\mu_pW_{axle}$ 比对判是否已抱死。 |
| 峰值摩擦是不稳定平衡：$d\mu/ds>0$ 稳定、$<0$ 正反馈 | 恒力矩下看 $d\mu/ds$ 的符号：正值稳定（自行回到平衡），负值正反馈（滑移单调升到 100%）；峰值本身是分界点，压力闭环无效，唯一出路是减压/释放。 |
| 载荷敏感性：+10% 轴荷 ≈ 制动系数 −0.01 | 额定载荷附近轴荷每 +10% 使该轴制动系数降约 0.01（绝对量）；净制动力仍增但低于线性，且方向是「后轴被低估、前轴被高估」——只用来声明代价与方向，不用来重画边界线。 |
| 制动能量与功率：$E=M(V_0^2-V_f^2)/2$ 定热容量，$P_{peak}=F_bV_0$ 与 $P_{avg}=E/t_s$ 定热流 | $E=\frac{M}{2}V_0^2$（与减速度无关）→ $P_{peak}=F_bV_0$、$P_{avg}=E/t_s$ → 自检比值 2.00 → 单次紧急看峰值、连续下坡看平均。 |
| FMVSS 105/121 减速度符合性初判：要求值 → 允许距离 → 比限值 | 按 载荷×磨合×初速 定位五效能之一 → 取要求减速度（ft/s²）→ $SD=V_0^2/(2D_{req})$ → 与实测比（或反算 $D_{avg}$）→ 声明 SN 口径与覆盖缺口。 |
| 非制动器阻力的折 g 速算：滚阻 ≈0.01 g、坡度 4% ≈0.04 g | 滚阻 $R=f_rW$（只乘总重、与载荷分布无关，0.01 g=0.322 ft/s²）；坡度 $R_g=W\theta$（4%=0.04 g=1.288 ft/s²，上坡帮、下坡扣）；占比 <2% 可略但必须写出占比。 |
| 鼓式制动因数与自锁阈：$\mu e/(m\mp\mu n)$ | 领蹄 $\mu e/(m-\mu n)$、从蹄 $\mu e/(m+\mu n)$；自锁阈 $\mu\to m/n$，余量 $m/n-\mu_{\max}$ 小于 0.2 判高风险；因数越高对 μ 越敏感。 |
| 转动惯量并入有效质量：$F_b=(T_b-I\alpha_w)/r$ | $F_b=(T_b-I\alpha_w)/r$，因 $\alpha_w=a_x/r$ 可并入质量；单轮约 3% 级，驱动轮还要叠传动系惯量；抱死即失效。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
