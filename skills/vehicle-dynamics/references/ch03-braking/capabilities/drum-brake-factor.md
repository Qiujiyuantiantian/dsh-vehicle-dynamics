# 鼓式制动因数：领蹄 $\mu e/(m-\mu n)$、从蹄 $\mu e/(m+\mu n)$，自锁阈 $\mu\to m/n$

## R — 原文 (Reading)

> **原书要点**（p64–65 §3.3 式3-15/3-16）：领蹄一旦自增势，制动器里就多出一份机械助力；这份助力有多大，统一拿"制动因数"来度量。
>
> **原书要点**（p64–65 §3.3 式3-16）：不难看出，摩擦系数一旦偏大，$\mu n$ 这一项追平 $m$ 时，分母归零、放大倍数冲向无穷，制动器随即自锁抱死。
>
> **原书要点**（p64–65 §3.3 式3-15/3-16）：一旦把制动因数做得很高，代价就是衬片摩擦系数但凡有点变化，最终的制动效果都会被明显牵动。
>
> — 3.3 式(3-15)(3-16)（p64–65）

## I — 方法论骨架 (Interpretation)

一句话：**鼓式蹄片的制动因数是"增益换稳定性"的买卖：分母里那个 $-\mu n$ 是正反馈项，它把增益放大，同时把工作点推向奇点。**

- 两个分式结构对称，只差一个符号：领蹄 $\mu e/(m-\mu n)$（增势），从蹄 $\mu e/(m+\mu n)$（减势）。$e$、$m$、$n$ 都是力臂长度（in），$\mu$ 是衬片摩擦系数。
- 分母里的 $-\mu n$ 不是笔误，是物理：蹄片被鼓带着转，摩擦力自己把自己压得更紧 → 正反馈。所以**增势不是免费的**。
- 奇点判据：$\mu\to m/n$ 时分母归零、因数发散 → 制动器自锁。这是"锁死"（self-lock，制动器内部），与"抱死"（wheel lockup，轮胎-路面）完全不同的一件事。
- 灵敏度是判据的推论：在奇点附近 $d(\text{因数})/d\mu$ 发散，所以"因数高"的直接代价是对 $\mu$ 的批次波动、热衰退、水汽极其敏感，副产品是噪音/尖叫（自激振动，同一机制）。
- 盘式没有这一项（无领蹄效应），所以因数低、要更高压力，但力矩稳定。**这是取舍，不是先进与落后**——作者的结论恰恰是稳定性赢了。
- 工程用法：选型时把"因数"与"$\mu$ 的公差上限"一起看，先算 $\mu_{\max}$ 是否逼近 $m/n$。

## A1 — 应用示例 (Application Example)

### 示例 1：原书只给公式与警告，无数值例题

- **类型与来源**：**原书无例题**。3.3 节（p64–65）给出式(3-15)(3-16)、领蹄/从蹄的定性差别、自锁警告与"鼓式力矩不稳定"的结论，但**没有给 $e$、$m$、$n$、$\mu$ 的任何数值**，也没有算例。
- 因此本卡的数值演示只能是合成演练，且必须显式标注（见下）。

### 示例 2：同一几何下领/从蹄与自锁阈值（合成演练，非书中事实）

- **类型与来源**：**合成演练**。几何与 $\mu$ 由本卡设定（原书未提供典型比例，**不得**当成书中数据）。
- **输入**：$e=3.0$ in、$m=2.0$ in、$n=1.0$ in、$\mu=0.40$；再取 $\mu=0.45$ 做灵敏度对照。
- **方法的使用**：①领蹄 $\mu e/(m-\mu n)$；②从蹄 $\mu e/(m+\mu n)$；③令分母为零求自锁阈 $\mu=m/n$；④对 $\mu$ 求差看灵敏度。
- **结论/预期输出**：$\mu=0.40$ → 领蹄 $\mathbf{0.75}$、从蹄 $\mathbf{0.50}$（差 1.5 倍）；$\mu=0.45$ → 领蹄 $\mathbf{0.871}$（+16.1%）、从蹄 $\mathbf{0.551}$（+10.2%）→ **领蹄灵敏度约为从蹄的 1.6 倍**；自锁阈 $\mu=m/n=\mathbf{2.0}$。
- **读法**：同样的 $\mu$ 变化（+0.05，即 +12.5%），领蹄的力矩变化 16.1%、从蹄 10.2%。这就是"高因数换稳定性"的定量版本：**增益高的那一侧，对同一个 $\mu$ 扰动放得更大**。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 选鼓式还是盘式，问"鼓式是不是更省力/更落后"。
2. 问"为什么鼓刹热了会突然变强或变弱、为什么会尖叫"。
3. 衬片换批次/$\mu$ 公差变大后出现制动跑偏、左右不一致。
4. 校核"这个鼓式制动器会不会自锁"（换高摩擦系数衬片前）。
5. 想把制动因数当"制动效率"或"制动力增益"来用（需纠正）。

### 语言信号（中英双写）

- 「制动因数怎么算」「领蹄从蹄有什么区别」「鼓刹为什么省力」「鼓刹会不会自锁」「刹车尖叫」
- 「drum brake factor」「leading/trailing shoe」「self-energizing」「self-lock」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `pressure-to-brake-force`：本卡给"因数"（无量纲机械增益），那张卡给"$G$"（in·lb/psi，把几何+摩擦+有效半径打包）。因数变 → $G$ 变 → 配比线斜率变，三段是串联的。
- 与 `brake-efficiency-table`：$\eta_b$ 是**整车配平**效率，与制动因数毫无关系；混用会得出"鼓式效率高"的荒谬结论。
- 与 `mu-peak-instability`：那是轮胎-路面峰值的不稳定（抱死），本卡是制动器内部的自锁；两个"不稳定"不能互相解释。
- 与 `lockup-order-and-consequence`：本卡解释"为什么鼓式前轴热态会改变配比"，那张卡判"改了之后谁先抱"。

## E — 可执行步骤 (Execution)

**必需输入**：$e$、$m$、$n$（in，须注明各自是"作用力/摩擦力/法向力到支承销的垂直距离"）、$\mu$（衬片摩擦系数，含公差上限 $\mu_{\max}$）、蹄型（领/从/双领/双从）。**缺 $\mu_{\max}$ 不得给"安全"结论**——奇点判据靠的正是上限。

**交付物与完成标准**：领/从蹄因数、自锁余量 $m/n-\mu_{\max}$、灵敏度（$\mu$ 变动 $\pm0.05$ 时的因数变化）、一句选型或整改结论。

1. **认符号**
   - 完成标准：写明 $e$=作用力到支承销的垂直距离、$n$=衬片摩擦力到支承销、$m$=法向力到支承销；并声明式(3-15) 中的 $\eta$ 是 OCR 噪声、应为 $n$。
2. **算两个因数**
   - 完成标准：$F_A/P_a=\mu e/(m-\mu n)$、$F_B/P_a=\mu e/(m+\mu n)$；同时给比值（领/从），量级应 >1。
3. **算自锁阈与余量（判停点）**
   - 完成标准：$\mu_{lock}=m/n$；余量 $\mu_{lock}-\mu_{\max}$；若余量 < 0.2 或 $\mu_{\max}/\mu_{lock}>0.8$ → **判为高风险**，直接建议降低衬片 $\mu$ 或改几何，不再往下算。
4. **算灵敏度**
   - 完成标准：给"$\mu$ 从 $x$ 到 $x+0.05$ 时领蹄因数变化 $y\%$"，并与从蹄对比；用于说明"为什么这一侧会跑偏/尖叫"。
5. **交付**
   - 完成标准：一句话"$\mu=0.40$ 时领蹄 0.75、从蹄 0.50，自锁阈 2.0；$\mu$ +0.05 使领蹄 +16.1%，故该侧对批次波动最敏感"。

**计算约定（原书未规定，本卡设定）**：因数保留 3 位有效数字；$\mu$ 用两位小数；**本卡不假设 $e/m/n$ 的典型比例**（原书未给），必须由具体制动器几何输入。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **把它当"制动效率"或"制动增益"。** 三个"制动×"不可互换：制动因数（无量纲机械自增势）、$G$（in·lb/psi）、$\eta_b$（减速度/摩擦系数）。把因数当效率会得出"鼓式优于盘式"的反向结论。
- **用它评价盘式制动器。** 式(3-16) 是领/从蹄的鼓式模型，盘式没有自增势项，套用会得到一个不存在的奇点。
- **给"制动因数越高越好"的选型建议。** 作者的结论相反：高因数换来的是 $\mu$ 敏感、噪音、左右不平衡（ce11），盘式正是靠"低因数 + 稳定"成为主流。
- **自行补 $e/m/n$ 的典型值。** 原书**没有任何数值**，只有字母定义；本卡不给典型比例，也不得用"常见 3:2:1"这类说法。
- **忽略衬片大圆弧修正。** 原文明说"若衬片分布在一较大圆弧上，则公式将变得更加复杂，但仍表现出相同的影响效果"——本章**未给**该式，凡大包角蹄片只能定性。
- **把自锁（制动器）与抱死（车轮）混用。** 前者与路面无关、发生在制动器内部；后者是滑移饱和。混用会把材料问题误判成配比问题。

### 作者在书中警告的失败模式

- ce11：双领蹄式因数很高，但"热、磨损或其他因素导致的 $\mu$ 的微小变化将使得制动器的制动效果更加不稳定"，并"可能产生较大的噪音或尖叫"（p65）。
- ce12：鼓式力矩在单次制动中"下陷"（sag）→ 最大作用力制动时"很难保证前、后制动力适当的平衡"，导致减速不稳定与更长距离（p65）。
- ce18：>650 °F 后材料永久改变、27 系数作废——因数模型也随之失效（p66）。

### 作者的盲点 / 时代局限

- 假设刚性蹄、单点支承、$\mu$ 沿衬片均布——三项都是教科书简化，实车的热-弹变形会把因数拉离计算值。
- 全节无数值、无台架对照；"制动因数"与 $G$ 的换算关系（有效半径、蹄片数量）原文未写，读者无法从因数直接走到制动力。
- 1992 年视角：未涉及现代低金属/NAO 衬片的 $\mu$ 温度曲线，也未涉及 EPB（电子驻车）对后鼓式的替代。

### 容易混淆的邻近方法论

- **制动因数 vs 制动系数**：前者是制动器内部机械倍数，后者是"该轴用掉了自身载荷的百分之几"（$F_x/W$）。
- **自锁 vs 抱死 vs 滑水**：三个不同部位、三种机理（制动器内部 / 轮胎-路面滑移饱和 / 水膜抬起胎面）。
- **鼓式的"增势" vs 盘式的"稳定"**：这是同一枚硬币的两面，不能只取其一作为选型依据。
