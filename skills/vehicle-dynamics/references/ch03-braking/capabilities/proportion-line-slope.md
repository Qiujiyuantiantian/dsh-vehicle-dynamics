# 配比线斜率：增益定直线、比例阀定折点，再拿它和理想 $k(\mu_p)$ 比

## R — 原文 (Reading)

> **原书要点**（p73–74 §3.7 式3-31）：所谓“制动力配比”，说的是前轴与后轴制动力之间怎么对应；这一对应取决于各自制动器上施加的压力和它的增益，图上画成一条从原点朝右上方拉出的射线，分配比固定时它就是一条直线。
>
> **原书要点**（p73–74 §3.7 式3-31）：设计者最费劲的地方，在于选定配比线的斜率——也就是前后制动力此消彼长的那个比值。
>
> — 3.7（p73–74），式(3-31)

## I — 方法论骨架 (Interpretation)

一句话：**配比线的斜率是"两轴力之比"，而力 =（增益/半径）× 压力；半径和每轴制动器数会约掉，只剩下增益比与压力比。**

- 逐项展开就很干净：$F_{xf}/F_{xr}=\dfrac{G_fP_f/r}{G_rP_r/r}\cdot\dfrac{n}{n}=\dfrac{G_f}{G_r}\cdot\dfrac{P_f}{P_r}$。所以**斜率由两个可独立动手的东西决定**：增益比（换卡钳/换盘径就变）与压力比（装阀就变）。
- 等压段（$P_f=P_r$）斜率就是 $G_f/G_r$；装了比例阀后，**拐点之后**的斜率变成 $(G_f/G_r)/k$。注意结构：折线不是"过原点的两条射线"，第二段**过拐点**——这是本章最容易画错的一处。
- 拿斜率和理想 $k(\mu_p)$ 一比，就得到一个不依赖试错的诊断：实车斜率 < 理想 $k$ → 同一 $F_{xr}$ 下 $F_{xf}$ 偏低 → 工作点更靠近后轴边界 → **预判后轮先抱死**；反过来则偏前（前轮先抱，可控）。
- 这条诊断的妙处是它只需要两个数（$G_f/G_r$ 与 $k(\mu_p)$），不用画整张图。但它是**预判**，最终结论仍要由三角形与边界线给出。
- 一个必须记住的口径：**压力比 ≠ 制动力比**，两者差 $G_f/G_r$（例题正是 20/14 体现这一点）。把 0.3 当"后轴只得到 30% 的制动力"是本章最典型的错。

## A1 — 应用示例 (Application Example)

### 示例 1：例题 3.12 的增益比（原书例题参数）

- **类型与来源**：**原书例题**（3.12，p80–81）。$G_f=20$、$G_r=14$ in·lb/psi，阀 290/0.3，$r=12.11$ in，每轴 2 个制动器。
- **方法的使用**：①$G_f/G_r$；②拐点后 $(G_f/G_r)/k$；③拐点压力 290 psi 对应的 $F_{xr}$ 位置由步骤(2)(3) 给出。
- **结论/结果（复算值）**：等压段斜率 $=\mathbf{1.429}$（20/14）；拐点后斜率 $=1.429/0.3=\mathbf{4.762}$。**注意第二段过拐点、不过原点**。
- **压力比 ≠ 力比**：300 psi 时 $P_r=293$ psi（比 0.977），但力比是 $\dfrac{20\times300}{14\times293}=\mathbf{1.462}$——差的就是 $G_f/G_r$。

### 示例 2：N1 的实车线与理想线（合成演练，非书中事实）

- **类型与来源**：**合成演练**。自造车 N1（$G_f=22$、$G_r=15$、$r=12.5$、每轴 2 个、阀 400/0.35、$\mu_p=0.70$）。
- **方法的使用**：①轴系数 $2G/r$：前 3.52、后 2.40 lb/psi；②等压段斜率 $=3.52/2.40$；③拐点后 $/0.35$；④与理想 $k(0.70)=2.141$ 比较。
- **结论/预期输出**：等压段 $\mathbf{1.4667}$（$=22/15$ ✓，量纲 lb/lb）；拐点后 $\mathbf{4.190}$。
- **诊断**：$1.4667<2.141$ → 同一 $F_{xr}$ 下 $F_{xf}$ 偏低 → 工作点更靠近后轴边界 → **预判后轮先抱死**。与 300 psi 行的 $\mu_r(0.556)>\mu_f(0.458)$ 一致 ✓，也与"后轴在 $P_f\approx358$ psi 时先用满 $\mu_p$"一致。
- **反例校验**：若把拐点后斜率也画成过原点，$F_{xf}$ 在高压力段会被系统性高估，诊断会翻成"偏前"——结论完全反了。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 问"我的配比线斜率是多少、怎么算"。
2. 换了卡钳/盘径/衬片后问"配比会怎么变"（$G$ 变 → 斜率变）。
3. 只有 $G_f/G_r$ 与一个路面 $\mu_p$，想快速判"偏前还是偏后"。
4. 装了比例阀后问"折线怎么画、拐点在哪、两段斜率差多少"。
5. 误以为"阀的 0.3 就是后轴制动力占 30%"，需要纠正。

### 语言信号（中英双写）

- 「配比线斜率」「前后制动力比」「G_f/G_r」「比例阀折点后斜率」「偏前还是偏后」
- 「0.3 是不是后轴只占 30%」「brake proportioning slope」「split point」「brake force distribution line」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `proportioning-valve`：那张卡给"压力怎么分段"（$P_r$ 的数值），本卡给"分段之后的斜率"。压力是输入、斜率是输出。
- 与 `simultaneous-lockup-point`：那张卡给理想 $k(\mu_p)$，本卡给实车斜率；两者比较才有诊断。
- 与 `pressure-to-brake-force`：那张卡给单点力换算，本卡把两轴之比抽出来。
- 与 `effectiveness-triangle`：本卡给一条线，那张卡给可行域；最终判定仍归三角形。

## E — 可执行步骤 (Execution)

**必需输入**：$G_f$、$G_r$（in·lb/psi，**单轮口径**）、每轴制动器数（若两轴相同则约掉）、比例阀参数（拐点 $P_{knee}$、增量比 $k$，若无阀则注明"固定配比"）、以及对比用的 $\mu_p$。**缺 $G$ 的口径（单轮/整轴）不得开算**。

**交付物与完成标准**：两段斜率（或一段）、折点位置、与理想 $k(\mu_p)$ 的比较结论、以及"偏前/偏后"的预判。

1. **确认增益口径**
   - 完成标准：写明 $G$ 是单轮增益；若用户给整轴增益，先除 $n$；两轴 $n$ 不同则斜率要带上 $n_f/n_r$（不可约）。
2. **算等压段斜率**
   - 完成标准：$G_f/G_r$（若 $r$ 不同则 $\dfrac{G_f/r_f}{G_r/r_r}$）；量纲检查 lb/lb。
3. **算拐点后斜率（若有阀）**
   - 完成标准：$(G_f/G_r)/k$；**显式写出"第二段过拐点 $(F_{xr,knee},F_{xf,knee})$、不过原点"**；给出拐点坐标（由阀参数与 $2G_r/r$ 算出）。
4. **与理想线比较（判停点）**
   - 完成标准：取工况 $\mu_p$ 算 $k(\mu_p)$（`simultaneous-lockup-point`）；比较斜率；给出"偏前/偏后"预判。若两者相差 <5% → 判"接近理想"，**但不得据此宣布合格**（还要过三角形与兜底工况）。
5. **与图核对**
   - 完成标准：把线叠到 `effectiveness-triangle` 的图上，验证"低 $\mu$ 工况是否掉出"；若掉出，转 `no-solution-decision-tree`。
6. **交付**
   - 完成标准：一句话"等压段 1.467、拐点后 4.190；理想 $k(0.70)=2.141$，故实车偏后，预判后轮先抱死"。

**计算约定（原书未规定，本卡设定）**：斜率保留 4 位有效数字；$k$ 保留 3 位；"斜率"统一指 $F_{xf}/F_{xr}$（不是 $F_{xr}/F_{xf}$，方向必须声明）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **假设前后轮滚动半径相同、每轴制动器数相同却不说。** 本章推导把 $r$ 与 $n$ 约掉，是因为例题车两者都相同；换成前后不同规格的车，必须把 $\dfrac{n_fG_f/r_f}{n_rG_r/r_r}$ 写全。
- **把"压力比"当"制动力比"。** 两者差 $G_f/G_r$。把 500/0.3 的 0.3 当成"后轴制动力降到 30%"是高发误读（g14）。
- **把第二段画成过原点。** 比例阀的折线在拐点处**连续**，第二段过拐点；过原点会高估高压力段的前制动力。
- **把 $G_f/G_r$ 当常数外推。** 鼓式的 $G$ 随 $\mu$、温度、磨损漂移（ce11/ce12），热态下配比线会自己转；本卡给的是冷态名义斜率。
- **用斜率代替三角形判定。** 斜率"对不对"最终由 `effectiveness-triangle` 的可行域决定，不由计算自身决定。
- **把 500/0.3 当普适阀参数。** 500 是**作者举例**；例题车是 290/0.3，不同车不同。拐点压力没有设计准则（原文未给），只能回三角形里试。
- **忽略磨损/规格差异。** 本章假设左右对称、四轮同规格；实际偏差会改变有效斜率，本章不覆盖。

### 作者在书中警告的失败模式

- ce03：一条固定斜率的直线无法穿过所有效能三角形（p71、p74）。
- ce09：折一次（斜率 + 拐点）仍救不了"低 $\mu$ + 满载"，最大只到 <0.25 g，但各工况仍先抱前轮（p74）。
- ce20：制动增益的漂移本身就是"保证前轮先抱死并非易事"的四约束之一（p78）。

### 作者的盲点 / 时代局限

- 未讨论前后 $r$、$n$ 不等的情形，也未给 $G$ 的温度/磨损修正。
- 拐点压力"如何选"无设计准则（原文只说"超过作用压力范围的某数值时"），只能试算。
- 1992 年视角：比例阀是主角；现代 EBD 会按轴实时改写压力比，静态斜率只是设计起点。

### 容易混淆的邻近方法论

- **$G$（制动器增益，in·lb/psi）vs 踏板力增益（g/lb）**：同名不同物，前者参与斜率、后者属人机工程。
- **配比线（过原点/过拐点，正斜率）vs 等减速度线（斜率 −1）**：两条线在图上相交，角色完全不同。
- **斜率 $F_{xf}/F_{xr}$ vs 斜率 $F_{xr}/F_{xf}$**：取倒数会得出"偏前/偏后"的相反结论，方向必须写在卡片外。
