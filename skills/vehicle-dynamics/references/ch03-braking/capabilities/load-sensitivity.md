# 载荷敏感性：+10% 轴荷 ≈ 制动系数 −0.01，所以 $F=\mu_pW$ 只是线性化

## R — 原文 (Reading)

> **原书要点**（p68 §3.4.3）：干地也好湿地也好，轴荷压得越重，轮胎给出的制动力系数 $F/F_z$ 反而越低——峰值摩擦与滑动摩擦这两个系数，都不随载荷按同一比例上升。在额定载荷附近，轴荷多加一成，这两个系数大致各掉 0.01。
>
> — 3.4.3 垂直载荷（p68）

## I — 方法论骨架 (Interpretation)

一句话：**轮胎给的"每磅载荷能换多少制动力"随载荷下降——所以"重一点就多刹一点"的线性直觉在高载荷端偏高、低载荷端偏低。**

- 原文给的是一个**绝对量**修正：额定载荷附近，轴荷每 +10%，该轴制动系数（= 制动力/载荷）降约 0.01。方向与量级都给了，但**只限额定值附近**。
- 后果是双面的：$\mu$ 下降，但 $W$ 上升，净制动力**仍增加**，只是低于线性预测。所以这不是"重载更刹不住"，而是"重载的增益低于按比例"。
- 制动工况会让这个修正**同向叠加**而非相互抵消：载荷转移把前轴推向高载荷（$\mu$ 更低）、后轴推向低载荷（$\mu$ 更高）→ **前轴可用力被高估、后轴被低估**，安全余量的方向被侵蚀。
- 换算成百分比就有意思了：同样 −0.01，对 $\mu=0.3$ 是 −3.3%，对 $\mu=0.8$ 只有 −1.25%——**低摩擦路面上这条修正更狠**，而低摩擦路面正是抱死高发区。
- 工程上它只有两个用途：①声明"用了线性假设，所以要打这个折扣"；②在配比/抱死顺序结论上加一句"方向是后轴更早到极限"。**它不是用来重画边界线的**（本章没有 $\mu(W)$ 的解析式）。

## A1 — 应用示例 (Application Example)

### 示例 1：原书只给一个绝对量，无算例

- **类型与来源**：**原书无例题**。3.4.3（p68）给出"+10% → −0.01 左右"这一条结论与"并非同载荷成比例增加"的解释，**没有函数形式、没有不同胎型/胎压的差异、没有算例**。
- 所以本卡的定量演示只能是合成演练；"额定载荷 1500 lb"这类数字必须标注为设定值。

### 示例 2：前后轴反向偏移的净效应（合成演练，非书中事实）

- **类型与来源**：**合成演练**。额定载荷与基准 $\mu$ 由本卡设定。
- **输入**：额定 1500 lb、基准 $\mu=0.80$；前轴 +20%（1800 lb）、后轴 −20%（1200 lb）。
- **方法的使用**：①按 "+10% → −0.01" 线性折算 $\Delta\mu$（+20% → −0.02，−20% → +0.02）；②$F=\mu W$ 与线性预测 $0.80W$ 对比；③看两轴偏差方向。
- **结论/预期输出**：前轴 $\mu=0.78$、$F=\mathbf{1404}$ lb（线性 1440，少 36 lb，−2.5%）；后轴 $\mu=0.82$、$F=\mathbf{984}$ lb（线性 960，多 24 lb，+2.5%）。
- **读法**：总量只少 12 lb（可略），但**分配**上前轴被高估、后轴被低估——方向正好是"后轮比计算更早抱死"，与 ce14 描述的安全余量侵蚀一致。**这就是为什么它必须写进 B 段而不是改进公式。**

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 问"重载是不是制动力按比例增加""为什么满载制动距离不是线性变长"。
2. 用了式(3-23)(3-24) 或画了直线边界后，被追问"这个线性假设有多准"。
3. 空载/满载两套配比对比，需要解释差异来源。
4. 低摩擦路面（湿路、雪路）工况，要判断线性假设的代价是否变大。
5. 讨论轮胎规格/胎压对制动的影响（本章只给载荷这一维的定量）。

### 语言信号（中英双写）

- 「载荷对摩擦系数的影响」「重载是不是摩擦系数更低」「+10% 载荷 −0.01」「线性假设准不准」
- 「load sensitivity」「tire load sensitivity」「μ vs vertical load」「为什么不能按 F=μW 线性外推」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `lockup-boundary-lines` / `simultaneous-lockup-point` / `effectiveness-triangle`：本卡是那三张卡的**免责声明来源**（"忽略载荷敏感性"这句必须由本卡提供），不是它们的替代。
- 与 `dynamic-load-transfer`：那张卡算"载荷移多少"（线性、可靠），本卡说"载荷变了系数也变"（非线性、只有量级）；两者串联但不互算。
- 与 `resistance-terms`：滚阻与载荷**分布**无关（只乘总重），附着系数与载荷**大小**有关——两条结论方向完全不同，常被混引。
- 与 `mu-peak-instability`：那张卡是 $\mu$ 随**滑移率**的非单调，本卡是 $\mu$ 随**载荷**的单调下降。

## E — 可执行步骤 (Execution)

**必需输入**：该轴的额定（或基准）载荷、实际载荷（或变化百分比）、基准制动系数 $\mu_p$。**缺"额定载荷"不得开算**——"+10%→−0.01"是以额定值为基准的相对量。

**交付物与完成标准**：$\Delta\mu$（绝对量）、修正后 $\mu$、修正后 $F$ 与线性 $F$ 的差值与百分比、一句"方向性"结论（哪一轴被高估）。

1. **认基准**
   - 完成标准：写出"基准 = 额定载荷；$\Delta\mu$ 是**绝对量** 0.01，不是 1%"；标注适用范围 ±10–20%。
2. **算 $\Delta\mu$**
   - 完成标准：$\Delta\mu=-0.01\times(\Delta W/W_{rated})/0.10$；载荷增加取负、减少取正。
3. **算修正后的力**
   - 完成标准：$F_{corr}=(\mu_p+\Delta\mu)W$ 与 $F_{lin}=\mu_pW$ 同时给出；给差值与百分比；**同时给两个百分比**（相对线性值、相对 $\mu$ 本身）——后者才是灵敏度。
4. **判工况分支（判停点）**
   - 完成标准：若载荷偏离额定 >20% → **停**，声明"超出原文适用范围，只能给方向（后轴更早到极限），不得给数值"。
5. **落笔为声明**
   - 完成标准：凡下游用了线性边界/交点/三角形，必须附一句"本结论忽略载荷敏感性（3.4.3：+10% 载荷 → 系数 −0.01），真实边界在该方向上弯曲"。
6. **交付**
   - 完成标准：一句话"前轴 +20% 载荷使系数由 0.80 降到 0.78，可用力 1404 lb（线性预测 1440），故前轴余量被高估、后轴被低估"。

**计算约定（原书未规定，本卡设定）**：$\Delta\mu$ 按载荷百分比线性折算（原书只给 10% 一个点，线性折算本身是约定）；$\mu$ 保留 2 位小数；力保留 3 位有效数字。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **拿它重画边界线/重算交点。** 本章**没有** $\mu(W)$ 的函数形式。ce14 说"边界其实是弯的"是**⚠️ 推断**（作者给出载荷敏感性事实，未把它接到配比边界线上），引用必须保留 ⚠️，且只能定性。
- **外推到远离额定载荷的工况。** 原文限定"在轮胎的额定载荷附近"；空载皮卡后轴、重载前轴这类极端点只能给方向。
- **把 $\Delta\mu$ 当百分比。** 它是绝对量 0.01。把它当 1% 会在低 $\mu$ 路面上严重低估修正（对 0.3 是 3.3%）。
- **用它解释"重载刹不住"。** 净制动力仍随载荷上升，只是低于线性；真正的危险是**分配**（后轴系数被推高 → 后轮先抱）。
- **在只做刚性/准静态设计时忽略这句声明。** 本章式(3-23)(3-24) 与所有直线边界都建立在"$\mu_p$ 与载荷无关"上——这是**本章内部矛盾**，凡调用必须显式声明。
- **把它当轮胎选型依据。** 原书未给不同胎型/胎压下的差异；"换宽胎能不能提高 $\mu$"这章答不了。

### 作者在书中警告的失败模式

- ce14（⚠️ 推断）：用 $F_{xm}=\mu_pW$ 画直线边界并求交点，在载荷偏离额定较远时"同时抱死"判据失准，前轴余量被高估（p68 + p71–73 的接合）。
- ce20：保证"前轮先抱死"之所以"并非易事"，四约束之一正是重心高度与载荷变化——本卡给的是这条约束的定量一半。
- ce19（⚠️ 推断）：把"物理上能产生 0.8 g"当"用得出 0.8 g"，与载荷敏感性叠加后可用能力更虚。

### 作者的盲点 / 时代局限

- 只给一个绝对量（0.01/10%），未给函数、未给不同胎型/胎压/温度的差异，也未给"额定载荷"的取值规则。
- 未讨论载荷敏感性与车速敏感性的交互（湿路高速下两者叠加，实际 $\mu_p$ 可能远低于标称）。
- 1992 年视角：现代宽基胎/低扁平比的载荷敏感性曲线形状可能不同，本章无数据。

### 容易混淆的邻近方法论

- **载荷敏感性（$\mu$ 随 $W$）vs 载荷转移（$W$ 随 $D_x$）**：前者是"系数变"，后者是"载荷变"；本章的线性理论只承认后者。
- **绝对量 0.01 vs 相对 1%**：低 $\mu$ 路面上两者差 3 倍，口径必须写明。
- **"边界线弯曲"（推断）vs "边界线斜率由 $\mu h/L$ 定"（原文）**：后者是本章的可用结论，前者是外推；混用会把一条推断当定理。
