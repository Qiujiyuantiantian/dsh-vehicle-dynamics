# 前后轴最大制动力边界线：联立消去 $D_x$，两条直线划出抱死域

## R — 原文 (Reading)

> **原书要点**（p71–73 §3.7 式3-23～3-28）：这些式子里还挂着减速度这个未知量，因此单靠它们无法把某根轴上制动力能到多大直接定下来。
>
> **原书要点**（p71–73 §3.7 图3.8）：图上代表前轴制动力上限的线朝右上走，代表后轴制动力上限的那条则朝右下走。
>
> — 3.7 式(3-23)~(3-28)、图 3.8（p71–73）

## I — 方法论骨架 (Interpretation)

一句话：**"该轴最大制动力"里嵌着一个未知的减速度，所以要先把它消掉；消完之后，两个轴各自变成一条直线，线的位置告诉你"越过就抱死"。**

- 原始式是循环的：$F_{xmf}=\mu_pW_f$，而 $W_f$ 依赖 $D_x$，$D_x$ 又依赖两轴制动力之和。作者的做法是把 $D_x=(F_{xmf}+F_{xr})/M$ 代回去，得到显式式(3-27)(3-28)。
- 显式式整理后是两个一次函数（横轴 $F_{xr}$、纵轴 $F_{xf}$）：
  - 前轴：$F_{xmf}=\dfrac{\mu_p\left[W_{fs}+(h/L)F_{xr}\right]}{1-\mu_p h/L}$
  - 后轴：$F_{xmr}=\dfrac{\mu_p\left[W_{rs}-(h/L)F_{xf}\right]}{1+\mu_p h/L}$
- 分工极其干净：**斜率只由 $\mu_p h/L$ 定，截距只由载荷定**。于是两种工况变化有两条完全不同的对策：换路面（$\mu_p$ 变）→ 线**转**；换载荷（$W_{fs}/W_{rs}$ 变）→ 线**平移**。
- 几何读法：图 3.8 里前界线以正斜率上升、后界线以负斜率下降；两条线之间是"还没抱死"的带，越过前界线 → 前轮抱死，越过后界线 → 后轮抱死。
- 两条线相交处就是"同时抱死点"（式 3-29/3-30，见 `simultaneous-lockup-point`）。所以本卡是那张卡的来源，两张卡不能互相替代。
- 有一个原文未讨论的奇点：$1-\mu_p h/L\to0$（即 $\mu_p\to L/h$）时前轴可无限加载，公式发散。$h/L=0.35$ 的车在 $\mu_p=2.86$ 时触发——现实中不可达，但外推时要知道它在那里。

## A1 — 应用示例 (Application Example)

### 示例 1：原书只给结构与斜率符号，图 3.8 不可读

- **类型与来源**：**原书无算例**。3.7（p71–73）给出式(3-23)~(3-28)、两条线的斜率符号、原点求法（"将相应轮轴制动力设置为零分别代入"）与图 3.7/3.8，但图 3.8 的坐标刻度在 OCR 中残缺。
- 处置：**绝对值一律用式(3-27)(3-28) 计算，不以读图为准**；本卡不给"从图上读出的"任何数。

### 示例 2：N1 的两条线与交点（合成演练，非书中事实）

- **类型与来源**：**合成演练**。自造车 N1（$W=3600$、$W_{fs}=1950$、$W_{rs}=1650$、$h/L=0.20$、$\mu_p=0.70$）。
- **方法的使用**：①前界截距 $\mu_pW_{fs}/(1-\mu_ph/L)$；②前界斜率 $\mu_ph/L/(1-\mu_ph/L)$；③后界用"$F_{xf}=0$ 时 $F_{xr}=\mu_pW_{rs}/(1+\mu_ph/L)$"或 "$F_{xr}=0$ 时 $F_{xf}=(L/h)W_{rs}$"；④联立求交点。
- **结论/预期输出**：前界线 $F_{xf}=\mathbf{1587.2}+\mathbf{0.1628}F_{xr}$（正斜率）；后界线 $F_{xf}=\mathbf{8250}-\mathbf{8.143}F_{xr}$（负斜率，$x$ 截距 1013.2）；交点 $(\mathbf{802.2},\ \mathbf{1717.8})$。
- **耦合自检（p23 的用途）**：任取 $F_{xr}=720$ → 前界允许 $F_{xmf}=(1365+0.14\times720)/0.86=\mathbf{1704.4}$ lb；代回 $D=(1704.4+720)/3600=0.6734$ g → $W_f=2434.9$ → $0.7\times2434.9=1704.4$ ✓ 自洽。后界同理：$F_{xf}=1056$ → $F_{xmr}=(1155-0.14\times1056)/1.14=\mathbf{883.5}$ lb。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 问"某配比在某路面上，两轴各自最多能出多少制动力"。
2. 问"为什么最大制动力不是 $\mu_p\times$静态轴荷、而要联立减速度"。
3. 要在 $F_{xf}$–$F_{xr}$ 图上画抱死边界（配比图的第一步）。
4. 换路面或换载荷后问"边界怎么动"（转线 vs 平移）。
5. 校验别人给的边界线方程（斜率/截距是否与 $\mu_p h/L$ 一致）。

### 语言信号（中英双写）

- 「最大制动力线怎么画」「抱死边界」「前后轴制动力临界」「配比图的两条线」
- 「换路面边界怎么变」「为什么不能直接用 μp 乘轴荷」「lockup boundary」「braking force distribution diagram」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `dynamic-load-transfer`：本卡的 $W_{fs}$、$W_{rs}$ 来自那张卡/静态数据；本卡已经把 $D_x$ 消掉了，不再需要逐步转移。
- 与 `simultaneous-lockup-point`：本卡给两条线，那张卡给交点坐标与理想 $k(\mu_p)$。先画线才有点。
- 与 `effectiveness-triangle`：本卡的两条线是三角形的两条边，第三条边（等减速度线）在三角形卡里。
- 与 `lockup-order-and-consequence`：本卡给"界限在哪"，那张卡给"某工作点在线的哪一侧、后果是什么"。

## E — 可执行步骤 (Execution)

**必需输入**：$\mu_p$（**须声明口径**，见 B 段）、$W_{fs}$、$W_{rs}$、$h$、$L$。**缺 $\mu_p$ 或轴荷不得开算**；$\mu_p$ 必须来自确定的轮胎-路面副或滑动数换算。

**交付物与完成标准**：两条线（斜率 + 截距 + 定义域）、交点（可交给下一张卡）、一句"换路面转线 / 换载荷平移"的说明、以及线性化免责声明。

1. **算公共项**
   - 完成标准：$h/L$（4 位小数）、$\mu_ph/L$、$1-\mu_ph/L$、$1+\mu_ph/L$ 四个量写清。
2. **写前界线**
   - 完成标准：截距 $\mu_pW_{fs}/(1-\mu_ph/L)$、斜率 $\mu_ph/L/(1-\mu_ph/L)$；定义域 $F_{xr}\ge0$。
3. **写后界线**
   - 完成标准：用"$F_{xr}=0\Rightarrow F_{xf}=(L/h)W_{rs}$"与"$F_{xf}=0\Rightarrow F_{xr}=\mu_pW_{rs}/(1+\mu_ph/L)$"两点定线；斜率 $-(1+\mu_ph/L)/(\mu_ph/L)$。
4. **求交点并自检**
   - 完成标准：交点处 $F_{xfi}+F_{xri}=\mu_pW$ 必须成立（这是最强的一条自检，N1：1717.8+802.2=2520=0.7×3600 ✓）。
5. **奇点检查（判停点）**
   - 完成标准：算 $L/h$；若 $\mu_p$ 与 $L/h$ 同量级（例如 $\mu_p>0.8L/h$）→ 标注"前界逼近发散，结论不可用"，停止外推。
6. **交付 + 声明**
   - 完成标准：给两条方程 + 交点 + "本结论建立在 $\mu_p$ 与载荷无关的线性化上（与 3.4.3 的 +10%→−0.01 冲突），且 $\mu_p$ 两轴相同、路面均匀"。

**计算约定（原书未规定，本卡设定）**：系数保留 4 位有效数字，坐标保留 1 位小数（lb）；$\mu_p$ 保留 2 位小数；**不用图读数**替代计算。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **把直线当真理。** 两条线是直线，前提是"$\mu_p$ 与轴荷无关"。3.4.3 说 +10% 载荷 → 系数 −0.01，这是**本章内部矛盾**；重载前轴/空载后轴时边界实际弯曲（ce14 标 ⚠️ 推断）。凡用本卡必须在 B 段写明"忽略载荷敏感性"。
- **在 $1-\mu_ph/L\to0$ 附近外推。** 前轴公式发散，原文未讨论该奇点；这里给不出有意义的边界。
- **用图 3.8 的刻度读数。** OCR 残缺；绝对值以式(3-27)(3-28) 计算为准。
- **把 $\mu_p=0.81$ 当"路面标签"。** 那是 SN 81（ASTM E274，SN=100μ）的换算值，且由**标准试验胎**测得，不等于本车轮胎的实际 $\mu_p$；凡引用必须标口径。
- **把滚阻/坡度/风阻并进这两条线。** 原文推导明说"简单起见，忽略其他可能出现的力"；把附加阻力加进去会破坏"截距只由载荷定"的干净结构。
- **把两轴用不同 $\mu$ 代进同一组式。** 两线共用同一个 $\mu_p$ 是前提；split-$\mu$（左右不等）本章未讨论。
- **把它当"能刹多狠"的答案。** 它给的是"各轴不抱死时最多出多少力"，整车减速度还要与配比线联立（`proportion-line-slope`）。

### 作者在书中警告的失败模式

- ce03：一条固定斜率的直线穿不过多个效能三角形——这是几何过约束，不是调参问题（p71、p74）。
- ce14（⚠️ 推断）：μ 随载荷下降使边界弯曲，前轴余量被高估、后轴被低估，安全余量方向被侵蚀（p68 + p71–73 接合）。
- ce20：四约束（增益漂移、重心高、路面 μ、驻车制动）同时拉扯，使"保证前轮先抱死"无法被证明（p78）。

### 作者的盲点 / 时代局限

- 未讨论 $1-\mu_ph/L$ 的奇点，也未讨论 $\mu_p$ 两轴不等、路面不均匀、左右不对称。
- 图 3.7/3.8 的刻度在本次数字化中不可读，作者也未给数值表；本章的可复算入口只有式(3-27)(3-28)。
- 1992 年视角：现代 EBD 会按轴实时改压力，静态边界图对闭环系统只是"设计阶段的骨架"。

### 容易混淆的邻近方法论

- **边界线（本卡）vs 配比线（`proportion-line-slope`）**：边界线由 $\mu_p$ 与载荷决定、不一定过原点；配比线由增益决定、**必须过原点**。两者交点才是工作点。
- **前界线正斜率 vs 后界线负斜率**：符号来自公式不是约定；把后界线画成正斜率，抱死域就整个反了。
- **式(3-27) 的 $n/L$（OCR）vs $h/L$**：OCR 把 $h$ 认成 $n$；用 $n/L$ 会得到一个无意义的截距。
