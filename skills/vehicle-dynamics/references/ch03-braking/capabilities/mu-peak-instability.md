# 峰值摩擦是不稳定平衡：$\mathrm{d}\mu/\mathrm{d}s>0$ 稳定、$<0$ 正反馈，唯一出路是"释放"

## R — 原文 (Reading)

> **原书要点**（p68 §3.4 式3-20 之后）：制动时，峰值附着 $\mu_p$ 对应着理论上能拿到的最大制动力；"理论上"三个字才是关节所在——系统恰好在这个点上不稳，实际上停不住。
>
> **原书要点**（p68 §3.4 式3-20 之后）：此刻唯一的办法是松掉制动——防抱死控制做的正是这件事——车轮才会重新回到 $\mu_p$ 那个工作点。
>
> — 3.4（p68），式(3-20) 之后的段落

## I — 方法论骨架 (Interpretation)

一句话：**把车轮的稳定性问题翻译成"看曲线斜率"——峰值左侧自动回到平衡，右侧越滑越滑，而峰值点本身停留时间为零。**

- 判据只有一条：恒制动力矩下，若 $\mathrm{d}\mu/\mathrm{d}s>0$（左支），扰动使 $s$ 增大 → $\mu$ 增大 → 制动力增大 → 轮子被拖回来，**稳定**；若 $\mathrm{d}\mu/\mathrm{d}s<0$（右支），扰动使 $s$ 增大 → $\mu$ 减小 → 制动力矩大于地面阻力矩 → 轮子继续减速 → $s$ 继续增大，**正反馈直到 100% 抱死**。
- 所以峰值点是 $\mathrm{d}\mu/\mathrm{d}s=0$ 的**分界点**：左稳定、右不稳定，点本身停留时间测度为零。作者用词很准——"理论上可以得到"。
- 由此得到两条推论：①$\mu_p$ **不可持续使用**，只能"靠近"；②想靠近就必须有外部闭环（ABS 的加压—保压—减压循环），开环的固定压力系统必然穿过峰值落入滑移区。
- 这条判据的价值不在算一个数，而在**纠正一条直觉**："压力越大制动越强"在过峰值之后是反的。它也是"为什么固定配比/固定压力不够"的力学内核。
- 用它的前提是先有曲线；没有曲线时只能给方向（过峰值更弱），不能给"哪一个压力过峰值"。

## A1 — 应用示例 (Application Example)

### 示例 1：原书只给图形与峰值区间，无逐点数值

- **类型与来源**：**原书无数值例题**。3.4（p67–68）给出图 3.6（制动系数 vs 滑动率，30 mph 干/湿两条）、峰值位置"10%–20%"、100% 滑动率时为最低值 $\mu_s$，以及本卡的稳定性论证，但**没有逐点读数、没有解析式**。
- 因此"某轮胎在 $s=0.15$ 处 $\mu=0.80$"这类输入只能来自合成演练或外部数据，**不得声称是书中数值**。

### 示例 2：两点差分定稳定性（合成演练，非书中事实）

- **类型与来源**：**合成演练**。曲线点与恒力矩由本卡设定。
- **输入**：某轮胎-路面副，$s=0.15$ 处 $\mu=0.80$；$s=0.25$ 处 $\mu=0.70$；恒力矩 $T_b$ 对应 $\mu_{req}=0.75$。
- **方法的使用**：①算两段斜率 $\Delta\mu/\Delta s$；②按恒力矩的力矩平衡判左右支；③推演扰动后的走向。
- **结论/预期输出**：$0\to0.15$ 段 $\Delta\mu/\Delta s=+5.33>0$ → 稳定；$0.15\to0.25$ 段 $=-1.0<0$ → 不稳定。工作点 $\mu_{req}=0.75$ 落在右支 → 压力不降则 $s$ 单调升到 1（抱死）；**只有把压力降到 $\mu$ 回到 0.80 以下才能恢复**，压力闭环无效。
- **反向自检**：若算出的稳定支在 "$s>0.25$" 一侧，说明把横轴方向读反了（本章 $s$ 由 0 到 100% 增大）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 问"为什么 ABS 是必须的/为什么不能一直踩死"。
2. 问"最大制动力是不是就等于 $\mu_p\cdot W$、能不能一直用"。
3. 问"为什么压力再大反而刹不住"（过峰值后 $\mu$ 下降）。
4. 判断某个标定压力/配比是否会让工作点穿过峰值落入滑移区。
5. 解释 ABS 的"加压—保压—减压"循环为什么长这样（而不是 PID 式连续调节压力）。

### 语言信号（中英双写）

- 「为什么需要 ABS」「踩死刹车为什么更差」「峰值附着能不能用满」「滑移率峰值不稳定」
- 「μ-slip curve」「unstable equilibrium」「peak mu」「为什么泄压才能恢复」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `lockup-order-and-consequence`：本卡讲"为什么峰值不可持续"（单轮力学），那张卡讲"哪个轴先抱、后果是什么"（整车配比）。前者是后者的前置机理，不互为替代。
- 与 `drum-brake-factor`：那是制动器**自锁**（内部正反馈），本卡是轮胎-路面**抱死**（滑移饱和）；两个"不稳定"机理不同、部位不同。
- 与 `load-sensitivity`：本卡讲 $\mu$ 随**滑移率**的非单调，那张卡讲 $\mu$ 随**垂直载荷**的下降；两条曲线不同轴。
- 与 `no-solution-decision-tree`：本卡给"为什么开环不够"，那张卡给"改用哪个机构"。

## E — 可执行步骤 (Execution)

**必需输入**：$\mu$-$s$ 曲线的至少两个点（或外部数据/图），以及当前工作点的力矩平衡量（$T_b$ 或 $\mu_{req}$）。**只有"压力"没有曲线时不得开算**，只能给方向性结论。

**交付物与完成标准**：两支斜率、稳定性判定、扰动后的走向、以及"要恢复需要把压力降到多少"的量级结论。

1. **确认曲线口径**
   - 完成标准：写明滑动率定义是 $s=(V-\omega r)/V$（本章式 3-20，分母是**车速**）；若用户给的是以轮速为分母的定义，先声明换算，否则"峰值在 10%–20%"会漂。
2. **算斜率**
   - 完成标准：至少两段 $\Delta\mu/\Delta s$，符号明确；峰值位置落在 10%–20%（原文区间）之外时要标注"与本图不符，须复核数据"。
3. **判稳定性**
   - 完成标准：$\mathrm{d}\mu/\mathrm{d}s>0$ → 稳定支；$<0$ → 正反馈支；工作点在峰值上时判"临界、不可停留"。
4. **推演扰动（判停点）**
   - 完成标准：给出"扰动 → $s$ 增 → $\mu$ 变 → 力矩差 → $s$ 再变"的完整链条与方向。若在右支且无闭环 → **停**，结论只能是"必须减压/释放"，不得给"加大压力弥补"。
5. **划出能力边界**
   - 完成标准：写明本卡不给 ABS 的阈值、升压率、循环频率（原文全无），也不给"某车最大减速度 = $\mu_p$"这类结论（那是把理论上界当可达工作点）。
6. **交付**
   - 完成标准：一句话"该工作点在右支（斜率 −1.0），恒力矩下将滑到抱死；只有把压力降到 $\mu\le0.80$ 才能回到稳定支"。

**计算约定（原书未规定，本卡设定）**：斜率用差分（本章无解析式），保留 2–3 位有效数字；滑动率用百分数或小数须全文统一并声明。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **在没有曲线时给定量结论。** 图 3.6 只有形状与峰值区间（10%–20%），**无逐点值、无解析式**；"外来干扰"的量级原文也未给。凭空给"$s=0.12$ 时为 0.82"就是编数据。
- **用 $\mu_p$ 直接当"可达减速度"报性能。** 峰值不可持续，且要停在那里需要主动控制（ce15）。这是本卡存在的理由本身。
- **把结论外推到松软路面。** ⚠️ 推断（ce16）：雪/碎石/松土上 100% 滑移可能形成楔积而摩擦**更高**，此时"维持峰值"反而延长距离。原文未讨论松软路面，引用必须带 ⚠️。
- **把它当 ABS 标定依据。** 原文对阈值、升压率、循环频率**一个字都没有**；本 Bundle 不给这些数。
- **与"锁死"混用。** 制动器自锁靠 $\mu\to m/n$（与路面无关），抱死靠滑移饱和；用错会把材料问题当配比问题。
- **在侧向耦合工况里单用。** 本章判据是纵向纯滑移；弯道制动时侧向力与制动力共用摩擦圆，本卡不覆盖（原文亦未给侧向耦合式）。

### 作者在书中警告的失败模式

- ce15：把峰值当"可持续使用的最大制动力"，据此宣称"本车最大减速度 = $\mu_p$"（p68）。
- ce16：把 ABS 当"抓地力增强器"或"必然缩短距离"，进而放宽配比设计（p75–76）。
- ce08：效率低 → 摩擦需求右移 → 需求与可用分布重叠面积增大 → 抱死频次上升；而抱死一旦发生在后轴就是方向发散（p79）。

### 作者的盲点 / 时代局限

- μ-滑移关系只有一条 30 mph 的定性曲线（图 3.6 干/湿各一条），未给速度、温度、胎压族；3.4.1–3.4.3 只给方向、不给斜率。
- 未讨论 ABS 循环中滑移率的动态轨迹（图 3.10/3.11 只有示意），也未讨论 ESC 对横摆的叠加作用。
- 1992 年视角：无电控四驱/扭矩矢量，抱死后的整车响应比现代车更"裸"。

### 容易混淆的邻近方法论

- **$\mu_p$（峰值）vs $\mu_s$（滑动）**：抱死时能用的是 $\mu_s$，两者之差（干路约 0.8 vs 0.6）就是 ABS 的全部收益来源。
- **峰值点不稳定 vs 峰值点不可达**：前者是动力学（停留时间为零），后者是控制（需要闭环）——同一件事的两个说法，别当成两条独立结论。
- **"压力越大越强" vs "过峰值更弱"**：这条直觉反转是本卡最该交付的一句话。
