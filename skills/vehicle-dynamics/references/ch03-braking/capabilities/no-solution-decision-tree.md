# 固定配比无解时的方案选择：按"差异来源"选机构，选完必须复验

## R — 原文 (Reading)

> **原书要点**（p74–75 §3.7）：若前后制动力被一条比例固定的直线绑死，就通不过上面这些要求；办法是在液压回路里串入一个阀来改变分配。
>
> **原书要点**（p74–75 §3.7）：各样工况下画出的效能三角形彼此错开、叠不到一起，所以不存在一条固定的分配比例能同时满足全部目标；于是要在车轴上装一个比例阀，靠它感测载荷状况来调整压力的分配。
>
> — 3.7（p74–75）

## I — 方法论骨架 (Interpretation)

一句话：**无解时不要继续调斜率，先问"差异来自哪一维"，然后按那一维去选一个能感测它的机构。**

- 问题的结构：固定配比只有 1 个自由度（斜率），而要覆盖的工况有 N 个三角形（2N 个约束）。所以"无解"是几何性质，不是精度问题。出路只有一条——**增加自由度**。
- 三条出路各自测一个不同的量，这就是选择依据：
  - **压力比例阀**：测**压力**（前馈）——折一次，把配比线变成两段。适合"差异主要表现为高压力段"的车。
  - **载荷感应比例阀**：测**载荷**（车轴之上的感测件）——把轴荷这一维直接测进来。适合"空/满载差异极大"的货车。
  - **惯性比例阀**：测**减速度**（反馈）——按减速度大小调配比。适合"差异随减速度幅值变化"的车。
  - **ABS**：测**滑移**——不改变配比，而是把每个轮胎摁在峰值附近。它解决的不是配比不足，而是"开环配比必然在某些工况失效"这件事。
- 决策的两个问题（这才是可执行的部分）：①差异主要来自**载荷**还是**减速度幅值**（决定感测量）；②兜底工况（最低 $\mu$ × 最大载荷）先抱哪个轮（决定是否可接受）。
- 选完必须复验：把新机构的等效折线叠回三角形图，逐工况再判"穿过/相切/在外"，并回到抱死顺序那一关。**不复验的选型等于没选。**
- 作者自己给了一个必须先看的先例：$500/0.3$ 的配比线穿过了所有干路三角形，**唯一例外是低摩擦路面满载**——此时达不到 0.25 g，但各工况仍先抱前轮。这是"性能缺口"而非"安全失效"的样板判定。

## A1 — 应用示例 (Application Example)

### 示例 1：原书的两个实例（原书结论，非逐步算例）

- **类型与来源**：**原书结论**（p74–75），无逐步算例。
- **实例 A（乘用车 + 压力比例阀）**：$500/0.3$ 的折线穿过所有干路效能三角形；**唯一例外**：低摩擦路面满载做不到 0.25 g，但"此图显示在各种状况下都将首先发生前轮抱死"。
- **实例 B（货车）**："货车满载与空车状态差别很大"→ 三角形不重叠 → 无法选出一个满足全部目标的配比 → 三条出路（感载阀/惯性阀/ABS），并说明欧洲货车长期使用感载阀。
- **读法**：A 说明"折一次够用到什么程度"，B 说明"什么时候折一次也不够"。两者的分界不是车种，而是**工况差异的幅度**。

### 示例 2：轻卡的空/满载差异（合成演练，非书中事实）

- **类型与来源**：**合成演练**。工况为假设：某轻卡空载/满载静态轴荷差 2.5 倍；干路两工况三角形可穿，湿路满载 0.25 g 达不到。
- **方法的使用**：①用 `effectiveness-triangle` 判交集；②用"轴荷变化倍数"而非"目标减速度差"识别差异来源；③按来源选机构；④复验折线与兜底工况。
- **结论/预期输出**：干路两三角形交集非空（可穿）；湿路满载三角形与干路不重叠 → 交集为空；差异来源是**载荷**（2.5 倍）→ 指向**载荷感应阀**。复验：该折线在湿路满载仍达不到 0.25 g，但工作点在交点之前 → 仍先抱前轮 → 判"可接受的性能缺口，非安全失效"（与 p74 的"惟一的例外"表述一致）。
- **反例对照**：若把同一问题判成"差异来自减速度幅值"→ 选惯性阀 → 空载时后轴仍过量 → 后轮先抱。**分诊错一步，方案就错。**

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 问"我的配比怎么调都过不了所有工况，该怎么办"。
2. 问"该装比例阀、感载阀、惯性阀，还是直接上 ABS"。
3. 货车/牵引车空满载差异大，问"为什么乘用车那套经验不能用"。
4. 已选完阀，问"还要复核什么"（复验流程）。
5. 问"某工况达不到目标减速度，是不是就不能交付"（性能缺口 vs 安全失效）。

### 语言信号（中英双写）

- 「配比无解怎么办」「装什么阀」「感载阀还是惯性阀」「要不要上 ABS」「低摩擦满载达不到目标」
- 「proportioning valve vs load sensing」「EBD」「performance gap vs safety failure」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `effectiveness-triangle`：那张卡判"有没有解"，本卡判"无解时怎么办"。
- 与 `proportioning-valve`：那张卡给"某个阀怎么算压力"，本卡给"该不该装、装哪种"。
- 与 `lockup-order-and-consequence`：本卡的最后一步必须回到那张卡做安全验收（兜底工况先抱前轮）。
- 与 `fmvss-compliance-screen`：那张卡判"法规过不过"，本卡判"工程上够不够"；两者结论可以相反（ce17：合规 ≠ 安全）。

## E — 可执行步骤 (Execution)

**必需输入**：工况集合（每格：$\mu_p$、载荷状态、$W_{fs}/W_{rs}$、目标减速度）、现有配比参数、以及"交集是否为空"的判定结果（来自 `effectiveness-triangle` 的 LP 判据）。**缺目标减速度不得判"缺口"**——缺口是相对目标定义的。

**交付物与完成标准**：差异来源判定、机构建议（含它测的是什么量）、复验后的逐工况结论、以及"性能缺口/安全失效"的定性。

1. **确认无解**
   - 完成标准：写明"用 LP 判交集为空"，并列出矛盾的不等式对；不得凭目视。
2. **判差异来源（分诊，判停点）**
   - 完成标准：比较**轴荷变化幅度**（空/满载倍数）与**目标减速度分布**：轴荷差异主导 → 载荷维；减速度幅值主导 → 减速度维；两维都大 → 直接考虑 ABS。
   - **本章没有给出这条分诊规则的原文表述**（needs_review f14 是另一件事，且其"低压段/高压段分散"的分诊规则系提取器自拟，**本卡不采用**）；本卡只用"哪一个自变量变化更大"这一工程判断，并标注为约定。
3. **选机构**
   - 完成标准：载荷维 → 载荷感应比例阀（感测轴荷）；减速度维 → 惯性比例阀（感测减速度）；仅高压力段偏差 → 压力比例阀（感测压力，前馈）；仍不足或需鲁棒 → ABS（感测滑移）。**每个建议必须写出"它测的是什么量"。**
4. **复验（不可跳过）**
   - 完成标准：把等效折线（或 ABS 的"峰值附近"工作带）叠回三角形图，逐工况重判；再回 `lockup-order-and-consequence` 判兜底工况。
5. **定性缺口（判停点）**
   - 完成标准：若某工况达不到目标但**仍先抱前轮** → 判"性能缺口，可接受的降级"；若出现后轮先抱 → 判"安全失效，必须返工"。**不得**把前者写成"合格"。
6. **交付**
   - 完成标准：一句话"湿路满载达不到 0.25 g，但各工况仍先抱前轮 → 性能缺口；整改方向为感载阀而非继续调斜率"；并声明这是 1992 年液压阀语境（无 EBD）。

**计算约定（原书未规定，本卡设定）**："差异来源"用轴荷倍数与目标减速度幅度的相对变化判定（阈值由用户给定，本卡**不给**自拟阈值）；"可接受"仅指方向稳定性，不含法规符合性。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **把"交集为空"当"还要再调斜率"。** ce03：这是自由度 1 对约束 2N 的过约束；继续微调永远出不来。
- **给成本/复杂度排序。** 原文**没有**三种机构的成本、重量、可靠性对比，也没有 EBD（1992 年视角）。不得据此说"现代车仍应如此选"。
- **自行发明分诊阈值。** 本卡不给"轴荷差多少倍算载荷主导"这类数字；原文亦无。凡是把工程判断写成"若 >X 则…"的地方，必须标为约定并请用户确认（参考被拦下的 f04 的 2%/10%、f06 的 0.05 这类自拟阈值——**一律不采用**）。
- **在 ABS 上套"改配比"的表述。** ce16：ABS 并非直接改变制动力配比，它维持滑移在峰值附近；说它"重新分配前后制动力"是错的。
- **把"低 $\mu$ 满载达不到目标"直接判为不合格。** ce09：若仍先抱前轮，那是性能缺口；把它升级成"安全失效"会误导整改方向（反过来把安全失效降级成"缺口"更危险）。
- **跳过复验。** 选完阀不叠回三角形、不回抱死顺序，等于把"加了个自由度"当成"问题解决了"。
- **对液压与气压制动混用结论。** 法规侧（`fmvss-compliance-screen`）105 与 121 的适用对象与路面要求不同；机构侧同理，货车的气压系统有自己的阀与 ABS 法规。

### 作者在书中警告的失败模式

- ce04：货车轻/满载三角形根本不重叠，"无法选择可满足所有目标的制动力配比"——这是无解的典型样本（p75）。
- ce09：折一次仍有"低摩擦 + 满载"例外，最大只到 <0.25 g（p74）。
- ce03：固定配比线无法穿过所有三角形，属结构性不可行（p71、p74）。

### 作者的盲点 / 时代局限

- 无 EBD、无 ESC、无成本/重量/可靠性对比；三种机构各一句原理，无公式、无选型表。
- "决策树"本身是对原文的归并（原文按段落叙述，未写成表），因此**每一步的判断依据都需要工程约定补足**，本卡已逐处标注。
- 1992 年视角：现代乘用车基本用 EBD 取代独立比例阀，感载阀主要在商用车上。

### 容易混淆的邻近方法论

- **压力比例阀（测压力，前馈）vs 载荷感应阀（测载荷）vs 惯性比例阀（测减速度，反馈）**：三者自变量不同，不能互换，也不能只看"都能折线"。
- **ABS（改滑移）vs 配比机构（改分配）**：前者不动配比，后者动配比；把两者当同类会得出"有 ABS 就不用管配比"的错误结论。
- **性能缺口 vs 安全失效**：判据是"兜底工况先抱哪个轮"，不是"达没达到目标减速度"。
