# 法规减速度初判：查五效能表 → 换成允许距离（或由实测距离反算）→ 比限值

## R — 原文 (Reading)

> **原书要点**（p70 §3.6）：第二效能针对满载且制动器已磨合的轿车：从 30、60、80 mph 三种初速起刹，各自的停车距离不得超过按 17、19、18 ft/s² 平均减速度算出的那一段。
>
> **原书要点**（p70 §3.6）：在液压制动这块，FMVSS105 给出停车距离指标时，只针对滑动数 SN 为 81 的干燥路面这一种情形。
>
> — 3.6（p70）

## I — 方法论骨架 (Interpretation)

一句话：**法规给的是"要求减速度"，不是"要求距离"；距离这一列必须自己用 $SD=V_0^2/(2D_{req})$ 算出来，然后才谈达标。**

- 五张效能表就是五个"工况格子"：载荷状态（轻载/满载）× 磨合状态（未磨合/已磨合）× 初速。取格子 → 拿到要求减速度（ft/s²）→ 换算成允许距离 → 与实测比。
- 换算只有一条式子：$SD=V_0^2/(2D_{req})$。反算同一式子：$D_{avg}=V_0^2/(2SD)$。所以"实测距离 → 平均减速度 → 与要求比"是一条完全对称的路。
- 三个口径是全章最集中的陷阱：①**单位**：要求值是 ft/s²，不是 g（19 ft/s²≈0.59 g，8.5 ft/s²≈0.264 g）；②**速度**：mph 必须先乘 1.467；③**平方**：原文的"20 ft/s""8.5 ft/s"缺平方记号，按 ft/s² 读。
- 还有两个"标准本身"的口径：105 只考**干路**（SN 81），121 才含**湿路**（SN 30）；而 $SN$ 是 ASTM E274 用**标准试验胎**测得的路面评分（$SN=100\mu$，故 SN 81 → $\mu$=0.81），**不等于**本车轮胎的实际 $\mu_p$。
- 所以这条链的正确用法是"初判 + 声明边界"：它回答"能不能过某一条款"，不回答"这辆车安全不安全"。ce17 正是这条边界：通过 105 的车在法规层面完全不必校核湿路，而湿路恰是抱死高发区（$\mu$ 0.4–0.6）。
- 五效能之外的条款（故障指示、过水恢复、衰退恢复、制动控制力极限）本章只列了标题，没有判据——只能列项，不能判定。

## A1 — 应用示例 (Application Example)

### 示例 1：原书的五效能数值表（原书数值，非算例）

- **类型与来源**：**原书数值**（3.6，p70），无逐步算例。五格如下（要求平均减速度，ft/s²）：
  1. 第一效能：未磨合、满载，30 / 60 mph → 17 / 18；
  2. 第二效能：已磨合、满载，30 / 60 / 80 mph → 17 / 19 / 18；
  3. 第三效能：已磨合、轻载，60 mph → 20；
  4. 第四效能：已磨合、满载，30 / 60 / 80 / 100 mph → 17 / 18 / 17 / 16；
  5. 部分失效：轻载与满载，60 mph → 8.5。
- **换算演示（复算值）**：60 mph = 88 ft/s → 第二效能允许 $88^2/(2\times19)=\mathbf{203.8}$ ft；第三效能 $88^2/(2\times20)=\mathbf{193.6}$ ft；部分失效 $88^2/(2\times8.5)=\mathbf{455.5}$ ft；第四效能 100 mph（146.67 ft/s）$146.67^2/(2\times16)=\mathbf{672.2}$ ft；30 mph（44 ft/s）第一效能 $44^2/(2\times17)=\mathbf{56.9}$ ft；80 mph（117.33 ft/s）$117.33^2/(2\times18)=\mathbf{382.4}$ ft。
- **单位校验**：19 ft/s²=0.59 g、8.5 ft/s²=0.264 g——写出来可防止"0.5 g 就够法规"这类错判。

### 示例 2：实测 225 ft 的反算（合成演练，非书中事实）

- **类型与来源**：**合成演练**。实测值由本卡设定，用来演示反算路径。
- **输入**：满载、已磨合、60 mph，实测制动距离 225 ft。
- **方法的使用**：①$D_{avg}=V_0^2/(2SD)$；②与第二效能的 19 ft/s² 比。
- **结论/预期输出**：$D_{avg}=7744/450=\mathbf{17.2}$ ft/s² < 19 → **不达标**（差约 9.5% 的减速度，对应距离超出约 21 ft）。
- **对照自检**：若把 225 ft 除以 88 得 2.56（无意义），说明用了 $SD=V_0/D$ 而不是 $V_0^2/(2D)$——这是本卡最常见的算术错。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 问"这车符合 FMVSS 105 吗 / 能不能过法规"。
2. 给了实测制动距离，问"按法规算达标吗"。
3. 问"法规要求多少 g"（需要 ft/s² ↔ g 的换算）。
4. 问"为什么我的车过了法规，雨天还是容易甩尾"（合规 ≠ 安全）。
5. 出口/认证场景下要先做一次"初判 + 缺口清单"。

### 语言信号（中英双写）

- 「FMVSS 105」「FMVSS 121」「法规制动距离」「第二效能」「滑动数 81」「过不过法规」
- 「brake compliance」「stopping distance requirement」「SN 81」「ECE R13 / GB 21670」（出现时须说明本章不覆盖）

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `braking-distance-and-time`：那张卡算"这车的 $SD$"，本卡算"法规允许多远"；两者口径不同（法规距离≠本章有效减速段 $SD$，且法规用平均减速度）。
- 与 `lockup-order-and-consequence`：本卡只判"过不过"，不判"安全不安全"；方向稳定性归那张卡。
- 与 `effectiveness-triangle`：本章的效能三角形用的是 105 的干路条件与 SN 30 湿路假设，本卡解释这些条件的来源。
- 与 `no-solution-decision-tree`：法规不达标是"工程缺口"的一种特例，但整改方向由那张卡给。

## E — 可执行步骤 (Execution)

**必需输入**：车辆类型（液压/气压）、载荷状态（轻载/满载）、磨合状态（未磨合/已磨合）、初速（mph）、以及实测距离（ft）或实测平均减速度。**缺"磨合状态"不得判达标**——第一效能与第二~四效能的门槛不同，答错会得到相反的结论。

**交付物与完成标准**：所取效能的编号与要求值（ft/s² 与 g 双写）、允许距离、实测对应减速度、达标/不达标、以及"本章未覆盖的条款清单"。

1. **选标准与效能格**
   - 完成标准：液压 → 105；气压 → 121（121 才含湿路）；按载荷×磨合×初速定位到具体效能编号，写出要求值。
2. **单位换算**
   - 完成标准：mph→ft/s（×1.467）；ft/s²→g（÷32.2）；**原文"20 ft/s""8.5 ft/s"按 ft/s² 读**。
3. **算允许距离**
   - 完成标准：$SD_{req}=V_0^2/(2D_{req})$；保留 1 位小数（ft）。
4. **比对（判停点）**
   - 完成标准：$SD_{meas}\le SD_{req}$ → 达标；否则不达标。同时给反算的 $D_{avg}=V_0^2/(2SD_{meas})$ 与差额百分比。
   - 若用户要"符合 ECE R13 / GB 21670" → **停**，声明本章只有 FMVSS 105/121。
5. **声明边界**
   - 完成标准：写出①105 只考干路（SN 81），121 含湿路（SN 30）；②SN 是 ASTM E274 标准胎口径（$SN=100\mu$，SN 81→$\mu$=0.81），不是本车轮胎的 $\mu_p$；③五效能之外只能列项（故障指示、过水恢复、衰退恢复、制动控制力极限）。
6. **交付**
   - 完成标准：一句话"满载已磨合 60 mph、实测 225 ft → 平均 17.2 ft/s² < 要求 19，不达标；且本章不覆盖湿路与 ECE/GB"。

**计算约定（原书未规定，本卡设定）**：距离保留 1 位小数（ft），减速度保留 1 位小数（ft/s²）；$g=32.2$ ft/s²；mph→ft/s 用 1.4667。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **把"通过 FMVSS 105"当"安全"。** ce17：105 只在 SN 81 的**干路**上考你，法规层面完全不必校核湿路，而湿路是抱死高发区（$\mu$ 0.4–0.6）。法规是**下限集合**，不是覆盖集合。
- **对非美市场直接套用。** 本章**无** ECE R13、**无** GB 21670；出现这两者只能声明"本章不覆盖"。
- **拿本章的 $SD$ 当法规距离。** 本章 $SD$ 是有效减速段，不含反应时间与压力建立时间；法规距离是整段实测。
- **把要求值当距离限值。** 原书只给减速度，距离必须自算；反过来把自算距离当"标准原文的数值"引用也不行。
- **忽略磨合状态。** ce13：未磨合与已磨合是两个独立法规试验；用磨合后的 $\mu$ 去预测"第一效能"会得到错误的达标结论。>650 °F 后性能永久改变，原标定作废（ce18）。
- **把 SN 当本车 $\mu_p$。** $SN=100\mu$ 是路面评分（标准试验胎），不是这辆车这套胎的附着系数；"SN 81 所以 $\mu_p$=0.81"只在该口径下成立，凡据此推进的配比/距离结论都要标注。
- **用它判五效能之外的条款。** 故障指示、过水恢复、衰退恢复、制动控制力极限：原文只有条目标题，**没有判据**——只能列项，不得判定。

### 作者在书中警告的失败模式

- ce17：105 的"遗漏"是制度性盲区，"谨慎的制动系统设计者们也会将滑动数为 30 至 81 的表面摩擦状况都考虑进去"（p70、p73）。
- ce13：未磨合/已磨合、冷态/热态是两个不同状态，法规把它们并列为独立试验（p66、p70）。
- ce18：>650 °F 后 27 个系数作废，法规的"衰退及恢复"试验正为此设（p66、p70）。

### 作者的盲点 / 时代局限

- 只讲 1990 年前后的美国标准；无 ECE R13、无 GB 21670、无 UN R13-H，也未讨论电子制动的法规适配。
- 只列效能要求，未给标准原文的试验规程（路面、风速、载荷分布、制动初温），这些都在标准本体里，本章没有。
- 未讨论"平均减速度"的积分定义与本章"恒定 $D_x$"的差别（g02 的口径差）。

### 容易混淆的邻近方法论

- **要求减速度（ft/s²）vs 减速度的 g 数**：19 ft/s²=0.59 g，不是 0.19 g。
- **法规距离 vs 本章 $SD$**：前者含反应与建立时间，后者只含有效减速段。
- **SN（路面评分，标准胎）vs $\mu_p$（本车轮胎-路面副）**：数值可能相等，含义不同。
