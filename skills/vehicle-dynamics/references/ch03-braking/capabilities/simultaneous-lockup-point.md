# 同时抱死点（理想配比点）：$F_{xfi}=\mu_p(W_{fs}+\mu_pW h/L)$、$F_{xri}=\mu_p(W_{rs}-\mu_pW h/L)$

## R — 原文 (Reading)

> **原书要点**（p71 §3.7 式3-29/3-30）：最理想的配比，是让前后两轴在同一时刻一起抱死；但车辆实际会碰上的工况太多样，这一点基本做不到。
>
> **原书要点**（p73 §3.7 式3-27/3-28）：把式(3-27) 与式(3-28) 联立，就能解出两条制动力边界线的交点位置。
>
> — 3.7 式(3-29)(3-30)（p71、p73）

## I — 方法论骨架 (Interpretation)

一句话：**两条边界线的交点就是"两轴同时抱死"的那一刻；它的坐标里含 $\mu_p^2$ 项，所以它不是 $\mu_p$ 乘静态轴荷。**

- 交点坐标（式 3-29/3-30）：$F_{x,fi}=\mu_p(W_{fs}+\mu_pWh/L)$、$F_{x,ri}=\mu_p(W_{rs}-\mu_pWh/L)$。两式都把 $\mu_p$ 乘进了载荷转移项，这是它不能退化成「$\mu_p\times$静态轴荷」的原因。
- 交点的物理读法很干净：在该点两轴都用满了 $\mu_p$，于是 $F_{xfi}+F_{xri}=\mu_pW$，整车减速度恰好 $D_x=\mu_pg$。坐标则分别是 $\mu_pW_f$ 与 $\mu_pW_r$，而 $W_f/W_r$ 里已经含了 $\mu_p$ 引起的载荷转移——这就是为什么坐标里出现 $\mu_p^2$。
- 换成"理想配比斜率" $k(\mu_p)=F_{xfi}/F_{xri}$ 更好用：它是一条随 $\mu_p$ 移动的标尺。$\mu_p\to0$ 时 $k\to W_{fs}/W_{rs}$（静态轴荷比）；$\mu_p$ 越大，$k$ 越大（越"偏前"）。
- 这条标尺就是"固定配比必然失败"的数学根源：$\mu$ 从 0.3 到 0.8，理想 $k$ 要动一大截，而实车配比线的斜率（由 $G_f/G_r$ 定）一动也不动。
- 它的用途是**判据基准**而不是目标：把实车配比线放在图上，看它相对于各工况的理想点偏前还是偏后。偏前 → 前轮先抱（可控），偏后 → 后轮先抱（危险）。
- 三个必须一起说的限制：①它是**单点**，绑定一组 $(\mu_p,\ 载荷)$；②作者明说"很难实现"，不能当验收判据；③"偏前多少"的裕度原书**没有给数值**（needs_review p30/p31），不得补造。

## A1 — 应用示例 (Application Example)

### 示例 1：原书只给坐标式，无算例；例题 3.12 的 400 psi 行是"近似到达"的实例

- **类型与来源**：**原书无算例**（3.7 只给式 3-29/3-30 与"很难实现"的评语）。但**例题 3.12**（p81）的 400 psi 行给出了一个可复算的近似实例：
- **输入（例题）**：$W=4074$ lb、$W_{fs}=2210$、$W_{rs}=1864$、$h/L=0.18894$；400 psi 行 $F_{xf}=1321$、$F_{xr}=747$、$D=0.508$ g、$W_f=2601$、$W_r=1473$。
- **方法的使用**：该行 $\mu_f=1321/2601=0.5079$、$\mu_r=747/1473=0.5071$——两轴制动系数几乎相等，即工作点落在交点附近。
- **结论（复算）**：该行 $\eta_b=0.508/0.5079=\mathbf{100\%}$，正是表中唯一 100% 的行。**这不是"效率达到理论上限"的意思，而是"该压力点两轴同时用满"**——把 100% 读成"制动系统完美"是本章最高频的误读之一（ce07、g10）。

### 示例 2：N1 的交点坐标与理想斜率标尺（合成演练，非书中事实）

- **类型与来源**：**合成演练**。自造车 N1（$W=3600$、$W_{fs}=1950$、$W_{rs}=1650$、$h/L=0.20$、$\mu_p=0.70$）。
- **方法的使用**：①$F_{xfi}=\mu_p(W_{fs}+\mu_pW h/L)$；②$F_{xri}=\mu_p(W_{rs}-\mu_pW h/L)$；③$k=F_{xfi}/F_{xri}$；④令 $\mu_p\to0$ 看 $k$ 的极限。
- **结论/预期输出**：$F_{xfi}=0.7(1950+504)=\mathbf{1717.8}$ lb、$F_{xri}=0.7(1650-504)=\mathbf{802.2}$ lb（和 $2520=\mu_pW$ ✓）；$k(0.70)=\mathbf{2.141}$；$\mu_p\to0$ 时 $k\to1950/1650=\mathbf{1.182}$（静态轴荷比）。
- **标尺用法**：同一辆车的实车配比线斜率 1.467（见 `proportion-line-slope`）< 理想 2.141 → 同一 $F_{xr}$ 下 $F_{xf}$ 偏低 → 工作点更靠近后轴边界 → **预判后轮先抱死**，与 300 psi 行 $\mu_r(0.556)>\mu_f(0.458)$ 一致 ✓。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 问"理想的前后制动力分配是多少""同时抱死点在哪个压力/哪组载荷"。
2. 想用一个数判断实车配比偏前还是偏后（理想 $k$ 标尺）。
3. 问"为什么固定配比不可能对所有路面都理想"（$k(\mu_p)$ 随 $\mu$ 大幅移动）。
4. 校核某压力点是否已接近"两轴同时到极限"（$\mu_f\approx\mu_r$ 即到点）。
5. 讨论"要不要把目标定成同时抱死"（答案：只当标尺，不当验收）。

### 语言信号（中英双写）

- 「同时抱死点」「理想制动力分配」「理想配比斜率」「同步抱死」「proportioning 理想点」
- 「simultaneous lockup」「ideal brake distribution」「ideal curve」「k(μ)」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `lockup-boundary-lines`：本卡是那两条线的交点（式 3-29/3-30 由 3-27/3-28 联立而来）。先有线条才能有点。
- 与 `effectiveness-triangle`：三角形是"可行域"，交点是"边界线的交点"（三角形的第三个顶点）；两者共用几何但回答不同问题。
- 与 `proportion-line-slope`：本卡给"应该在哪"（理想 $k$），那张卡给"实际在哪"（$G_f/G_r$）。比较两者才有诊断价值。
- 与 `brake-efficiency-table`：本卡解释"为什么 400 psi 行是 100%"（两系数相等），那张卡给全表与口径。

## E — 可执行步骤 (Execution)

**必需输入**：$\mu_p$（须声明口径）、$W$、$W_{fs}$、$W_{rs}$、$h$、$L$。**缺 $W_{fs}/W_{rs}$ 不得用 $b/L$、$c/L$ 代替**（原文取向未统一）。

**交付物与完成标准**：交点坐标 $(F_{xri},F_{xfi})$、和的自检、理想斜率 $k(\mu_p)$、$\mu_p\to0$ 的极限值、以及一句"这是标尺不是目标"的声明。

1. **算 $\mu_pWh/L$**（载荷转移项，注意它是 $\mu_p$ 乘出来的）
   - 完成标准：N1 例：$0.7\times3600\times0.20=504$ lb；此量出现两次（前加后减）。
2. **算坐标**
   - 完成标准：$F_{xfi}=\mu_p(W_{fs}+504)$、$F_{xri}=\mu_p(W_{rs}-504)$；**必须写自检 $F_{xfi}+F_{xri}=\mu_pW$**。
3. **算理想斜率标尺**
   - 完成标准：$k=F_{xfi}/F_{xri}$；同时给 $\mu_p\to0$ 的极限 $W_{fs}/W_{rs}$（N1：1.182）；再取 $\mu_p=0.30$ 与 $0.80$ 各算一个 $k$，展示它随 $\mu$ 移动的幅度。
4. **判适用性（判停点）**
   - 完成标准：若用户问"能不能把目标定成同时抱死" → **停**，引用作者"很难实现"，改为"用标尺判偏前/偏后"；若问"偏前留多少余量" → **停**，声明原书无此数值（needs_review p30/p31），只能逐工况校核。
5. **交接**
   - 完成标准：把 $k(\mu_p)$ 与实车斜率一起交给 `proportion-line-slope` 做偏前/偏后判定。
6. **交付**
   - 完成标准：一句话"$\mu_p=0.70$ 时理想点为 (802.2, 1717.8)、$k=2.141$；$\mu_p\to0$ 时 $k\to1.182$；该点是标尺不是可达目标"。

**计算约定（原书未规定，本卡设定）**：坐标保留 1 位小数（lb），$k$ 保留 3 位小数；$\mu_p$ 保留 2 位小数；$1-\mu_ph/L$ 的奇点检查同 `lockup-boundary-lines`。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **当验收判据用。** 作者原话是"很难实现"。它是画图用的基准点，不是合格线；拿它判"设计通过"等于要求固定配比线穿过每一个工况的交点（ce03 的几何过约束）。
- **当固定目标用。** 换路面或换载荷，点就移动（含 $\mu_p^2$ 项，移动幅度比直觉大）；把它印在图纸上当"理想点"会误导往下游的所有计算。
- **在两轴 $\mu_p$ 不等时使用。** 式(3-29)(3-30) 共用同一个 $\mu$；split-$\mu$、左右不对称本章未讨论。
- **补造"偏前裕度"数值。** 原书**没有**给"配比线应落在后界上方多少"的数（needs_review p30/p31），本 Bundle 不提供，只能说"逐工况校核、兜底工况必须先抱前轮"。
- **把 100% 效率读成"系统完美"。** 例题 400 psi 行的 100% 只说明该压力点两轴同时用满；它不能推出"全工况合格"（ce07）。
- **用它替代抱死顺序判定。** 点只说明"理想在哪"，实际先抱哪个由工作点相对两条线的位置决定（`lockup-order-and-consequence`）。

### 作者在书中警告的失败模式

- ce03：固定配比线过不了多个三角形/多个交点——自由度 1 对约束 2N，无解是几何性质（p71、p74）。
- ce07：拿效率（及其基准 μ）做立法/排名失败，因为 $\mu_p$ 不可复现（p76）。
- ce20：四个不可控约束使"前轮先抱"无法被证明，只能靠余量 + 逐工况校核（p78）。

### 作者的盲点 / 时代局限

- 式(3-29)(3-30) 的下标 $F_{x,fi}$、$F_{x,ri}$ 中 $i$ 的含义原文未定义（读作 ideal/intersection）。
- 未给"配比线偏离理想点多少算可接受"的判据——这是本章最大的工程空白之一。
- 1992 年视角：现代 EBD 会按载荷/减速度连续改写配比，静态"理想点"对闭环系统只剩设计参考价值。

### 容易混淆的邻近方法论

- **同时抱死点（点）vs 理想配比线（线）**：本章只给点；"理想曲线"是把不同 $\mu_p$ 的点连起来的轨迹，原文未画。
- **$k(\mu_p)$ vs 实车斜率 $G_f/G_r$**：前者随路面移动、后者固定；比较两者才是诊断，单看任何一个都得不出结论。
- **坐标含 $\mu_p^2$ vs 简单的 $\mu_p\times$静态轴荷**：把静态轴荷乘 $\mu_p$ 会得到偏后的点（漏掉了载荷转移那一项）。
