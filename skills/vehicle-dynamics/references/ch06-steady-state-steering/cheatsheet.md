# 决策规则速查 — 《车辆动力学基础》第 6 章 稳态转向

| 能力 | 一句话规则 |
|---|---|
| 转向特性判定：由轴荷与整轴侧偏刚度算 K，再判三态 | 先核「每轴两轮」口径，再算 K=W_fs/C_αf−W_rs/C_αr，正不足、零中性、负过多，并翻译成等半径下转向角随车速的走向。 |
| 前后轴对置判据：任何效应只看它把哪个轴的侧偏角做大 | 先定作用轴，再定该轴等效侧偏角变大还是变小：前轴变大→不足，后轴变大→过多。 |
| 侧倾链：悬架侧倾刚度→侧倾率→前后轴侧倾力矩→轮荷差 | 四环串算 K_φ=0.5K_s s² → R_φ=Wh₁/(ΣK_φ−Wh₁) → 前后轴力矩（弹性项+几何项）→ ΔF_z=M_φ/t，全程 rad 口径。 |
| 外倾推力对 K 的贡献：外倾梯度×侧倾率 | K_camber=(C_γf/C_αf·∂γ_f/∂φ − C_γr/C_αr·∂γ_r/∂φ)·R_φ，整体轴梯度≈0 可跳过。 |
| 侧向力柔顺转向：横摆中心判方向，A 系数算幅值 | 横摆中心在轴的「外侧」→该轴产生不足转向；幅值 K_lfcs=A_f W_f − A_r W_r。 |
| 驱动力影响的三项式读法：前驱/后驱/四驱方向 | 项1 被前轴驱动力改写阿克曼角、项2 原 K 不变、项3 −[前轴项−后轴项] 是修正：前驱加速→过多，后驱加速→不足，四驱后轴力应大于前轴。 |
| 等半径法实测 K：选法、执行流程与 δ–a_y 曲线判读 | 定圆 R≥30 m，按 0.1 g 升速，把转向盘转角÷传动比换成车轮转角，作 δ–a_y 图，线性段斜率即 K（正不足/零中性/负过多）。 |
| 等速法实测 K：用阿克曼梯度线做基准 | 固定 V 变转角，实测斜率减 57.3L/V² 才是 K；与阿克曼梯度线比高低判不足/中性/过多。 |
| 设计调校决策链：改哪个零件→动哪一项→K 往哪个方向（限定版） | 先定位主因，再从「稳定杆装前轴/后轴横摆中心后移/前轴外倾梯度↑/四驱后轴分配↑」里选，只给方向与优先级；只装后稳定杆与动回正力矩是禁止项。 |
| 低速转向几何：阿克曼角与偏离轮迹 | δ_o≈L/(R+t/2)、δ_i≈L/(R−t/2)、δ≈L/R；Δ≈L²/(2R)，只与轴距和半径有关。 |
| 不足转向梯度 K 的定义式与「每轴两轮」口径 | C_α 必须是整轴两轮之和、W 是整轴静态载荷；用单胎值会得 2 倍 K，可作为自检信号。 |
| 特征车速 V_char（只对不足转向） | V_char=√(57.3Lg/K)，仅 K>0；它高说明 K 小、几乎中性——是警号不是奖章。 |
| 临界车速 V_crit（只对过多转向） | V_crit=√(−57.3Lg/K)，仅 K<0；它是不稳定阈值不是极限车速，接近它时增益已放大 5–50 倍。 |
| 质心侧滑角 β 的定义式与 SAE 符号 | β=57.3c/R − W_r V²/(C_αr gR)，c=L·W_fs/W；正=车尾向内（低速），负=车尾外甩（高速）。 |
| β=0 的车速（与转向半径无关） | V_β=0=√(57.3gcC_αr/W_r)，与半径无关，可当车辆常数；低于它 β>0，高于它 β<0。 |
| 静态裕度 e/L 与符号判据 | e/L>0 不足、=0 中性、<0 过多；典型 0.05–0.07 是典型值不是合格线，越接近 0 越危险。 |
| 阿克曼角（内外轮分开，小转向角） | δ_o≈L/(R+t/2)、δ_i≈L/(R−t/2)、δ≈L/R；内轮大于外轮，前提是低速小转角。 |
| 偏离轮迹 Δ 与一次近似 | Δ=R[1−cos(L/R)]≈L²/(2R)，只与轴距与半径有关，与轮距无关；长轴距车在紧弯最严重。 |
| 两轮（自行车）模型的假设清单——代入任何公式前逐条核对 | 七条前置门：R≫L、小转角、忽略内外轮差、左右侧偏力相等、后轮同处理、α≤5°、稳态；任一破即改走几何式或声明出界。 |
| 悬架侧倾刚度 K_φ=0.5K_s s² 及三种代入口径 | K_φ=0.5K_s s²（in·lb/rad）；独立悬架可用轮处刚度与轮距；稳定杆刚度相加；换成 in·lb/deg 要 ÷57.3。 |
| 轮荷差双机制拆分（瞬时项/可调项） | F_zo−F_zi=2F_yh_r/t+2K_φφ/t；几何项瞬时不可调、弹性项才是旋钮，据此可知「只调稳定杆」的收益上限。 |
| 侧倾率 R_φ 及 rad/deg 口径陷阱 | R_φ=Wh₁/(ΣK_φ−Wh₁)，务必 rad 口径；典型 3–7 deg/g，算出负值就是单位错。 |
| 侧倾力矩偏前的四条理由 + 稳定杆布置规则 | 设计上侧倾力矩偏前（独立前悬弹簧间距大、刻意提高前刚度、稳定杆装前轴）；只装后轴稳定杆有推向过多转向的风险。 |
| 地面外倾角合成与含外倾的侧偏力叠加 | γ_g=γ_b+φ；F_y=C_αα+C_γγ；反解 α=F_y/C_α−(C_γ/C_α)γ_g，外倾等于给该轴加一个虚假侧偏角。 |
| 外倾量级三条分流判据 | 斜交胎 4–6°≈1° 侧偏、子午胎 10–15°、整体轴≤10%（可跳过）——先判要不要算，再算。 |
| 回正力矩项 K_at：恒为正、通常 <0.5 deg/g | K_at=(Wp/L)·(C_αf+C_αr)/(C_αf C_αr)，恒为正、通常<0.5 deg/g；只能更不足，但经转向系统的间接影响可能更大。 |
| SAE 对不足转向梯度的定义（转向盘口径） | 本章公式的 δ 是前轮转角；SAE 定义用转向盘转角梯度÷传动比减阿克曼梯度，两者差一个转向系统柔度项，报告必须标口径。 |
| 四种试验法只取两种：K 测量方法选型 | 只有等半径法与等速法「合理地反映通常驾驶」，另两法不采用；选完还要声明口径，不得跨方法比较。 |
| 单位与常数口径清单（全章英制，含 r 的双单位） | 代入前核九项：57.3、L/R 同单位、g=32.2、88 ft/s=60 mph、C_α 整轴、K_φ rad、ε 弧度、r 双单位、p 为长度。 |
| Olley 判据：由扰动后的走向判定不足/过多转向 | 给质心一个侧向扰动：车头朝扰动方向偏→不足；朝扰动内侧转（车尾外滑）→过多，且是正反馈。 |
| 设计入口原则：能动侧偏力的都是旋钮（七通道穷举） | 调校入口不是改 K，而是改任何能改变车轮侧偏力的东西：轮胎、载荷转移、外倾、侧倾转向、柔顺、回正力矩、驱动力。 |
| 横向载荷转移的转向效应不可消除，只能分配 | 机制对所有车、两轴都发生；前轴项恒不足、后轴项恒过多，单轴符号不可改，只能改分配与净和。 |
