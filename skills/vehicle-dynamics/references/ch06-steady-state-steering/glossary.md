# 关键术语（第 6 章稳态转向）

> 来源：阶段 1 glossary 候选 `candidates/glossary.md`（41 条）整理为 40 条；g20（侧向加速度增益）因公式字段沿用印刷错误、已转 `needs_review`，不入本表。
> 用法：凡能力卡或回答中出现这些词，一律按本表的语义使用，不得回退到日常义。原书 p161–p190，全章英制。

## A. 评价体系（本章怎么"看"一辆车）

| id | 术语 | 作者的定义 | 关键约束 / 易错点 |
|---|---|---|---|
| g01 | 操控（handling） | 车辆对驾驶员输入的响应率或控制轻便程度，是**车辆-驾驶员闭环**的整体评价 | 不是单一车辆属性；本章一切定量对象都是开环，凡说"操控"就在评闭环 |
| g02 | 开环特性 / 方向响应 | 仅表征车辆自身：对特定转向输入的响应（δ→a_y、r、β） | 全章范围声明；输出只能是"某 a_y 下 K=x"，不能是"这车很灵活" |
| g03 | 闭环（车辆-驾驶员） | 驾驶员观察运动并修正输入，构成反馈回路 | 闭环＝开环＋驾驶员补偿，补偿有带宽上限（这正是 V_crit 以下能开的原因） |

## B. 主变量

| id | 术语 | 作者的定义 | 关键约束 / 易错点 |
|---|---|---|---|
| g04 | 不足转向梯度 K | δ=57.3L/R+K·a_y 中的斜率，deg/g，有符号 | **两个定义域**：本章 δ 是前轮转角；SAE 定义用转向盘（差一个转向系统柔度项） |
| g05 | 侧偏柔度 | W/C_α，比值反映单位侧向力下该轴的侧偏角，deg/g | 只含轮胎项；与 Bundorf 更宽的口径不同 |
| g06 | 侧偏角 α | 车轮朝前方向与行驶方向的夹角 | 相对**车轮朝向**；低速后轮 α≈0 是低速几何的前提 |
| g07 | 侧偏力 F_y | 外倾为零时的侧向力 | 与外倾推力分开记；线性式 α≤5° |
| g08 | 侧偏刚度 C_α | α=0 处 F_y–α 斜率，SAE 取正，lb/deg | **★ 必须是整轴两轮之和**；用单胎值会让 K 差 2 倍 |
| g09 | 侧偏系数 | C_α/F_z，lb/lb/deg，消除载荷影响 | 满载时典型约 0.2（统计值，不可外推到具体胎） |
| g39 | 外倾角 γ | 车轮相对车身/地面的倾斜；两参考系 γ_g=γ_b+φ | 代进侧向力式必须用 γ_g，否则漏掉车身侧倾 |
| g40 | 外倾推力 / C_γ | 外倾角产生的侧向力；斜交胎 4–6°≈1° 侧偏 | 远小于侧偏力；对载荷与速度较不敏感；胎压对斜交胎敏感 |
| g41 | 外倾梯度 ∂γ/∂φ 与 K_camber | 车身侧倾引起的外倾变化率；K_camber 由梯度×侧倾率 | 梯度=1 表示"相对车身不倾、对地外倾完全随侧倾"（最易读反） |

## C. 模型与低速几何

| id | 术语 | 作者的定义 | 关键约束 / 易错点 |
|---|---|---|---|
| g10 | 两轮（自行车）模型 / 转向方程 | 用一个等效前轮代替两前轮，δ 是**前轮转角** | 不是方向盘转角；前提 R≫L、小转角、忽略内外轮差、左右侧偏力相等 |
| g11 | 侧向加速度 a_y | 全章以 g 为单位 | $a_y=V^2/(Rg)$；换算 g 与 ft/s² 时注意 g=32.2 |
| g12 | 阿克曼角 / 阿克曼几何 / 平行转向 | 前轮平均角 δ≈L/R；内外轮分开 δ_o、δ_i | 三重身份：低速角、高速公式的基准项、等速法的梯度线 |
| g13 | 偏离轮迹 / 等切面曲线 | 车头与车尾轨迹的横向差 Δ=R[1−cos(L/R)]≈L²/(2R) | ≠内轮差；与轮距无关；铰接车需 tractrix（原文无公式） |
| g14 | 中性/不足/过多转向 | 三种状态，不是三种程度 | 过多＝方向不稳定（不是"更灵活"）；由 K 的符号定义 |
| g15 | 不足/过多转向极限 | 同一辆车在不同 a_y 下可表现为异号（图 6.20） | 单一 K 只是原点切线，不能描述全曲线 |
| g16 | Olley 定义 | 由侧向扰动后的走向判不足/过多 | 与转向版等价但推理链不同（轨迹 vs 柔度差）；不给数值 |
| g17 | 方向不稳定 | 线性系统极点穿越虚轴；达到 V_crit 后对扰动发散 | 低于 V_crit 可行驶；V_crit 附近增益已放大 5–50 倍 |

## D. 派生指标

| id | 术语 | 作者的定义 | 关键约束 / 易错点 |
|---|---|---|---|
| g18 | 特征车速 V_char | 任何半径下转向角达 2 倍阿克曼角时的车速，仅 K>0 | K 越小 V_char 越高→越接近中性；不是最高车速，是灵敏度峰值 |
| g19 | 临界车速 V_crit | 过多转向车的不稳定阈值，仅 K<0 | K 本身为负，根号内为正；ft/s→mph ×0.682；轴距越长越高 |
| g21 | 横摆角速度 r | 方向角的转动速率；(6-21) 为 deg/s，(6-71) 为 rad/s | **同一符号两处单位不同**；a_y=V·r 只在 rad/s 下成立 |
| g22 | 横摆角速度增益 r/δ | 中性转向 ∝V；不足有峰值（V_char）；过多在 V_crit 发散 | (6-22) 印刷残缺，本章未将其列为可交付能力 |
| g23 | 侧滑角 β | 车辆纵轴与该点运动方向的夹角，SAE 视图顺时针为正 | **相对车身纵轴**（α 相对车轮）；是位置的函数，公式只对质心成立 |
| g24 | 中性转向点 / 中性转向线 | 施加侧向力不产生稳态横摆的等效作用点及其轨迹 | 三套等价定义（不产生横摆／前后侧偏角相等／静态裕度零点）；c′≈L·C_αf/(C_αf+C_αr) 由例题反推，须核 |
| g25 | 静态裕度（储备系数） | e/L，e 为中性转向点在质心后方的距离 | 不是安全余量；典型 0.05–0.07 是典型值不是合格线；原文"0.0074"与复算 0.0080 不一致 |

## E. 悬架（K 的六项来源）

| id | 术语 | 作者的定义 | 关键约束 / 易错点 |
|---|---|---|---|
| g26 | 侧倾中心 h_r | 侧向力通过车轴传给悬挂质量的那一点 | 三句三定义（传递点／不产生侧倾的点／纯力偶下侧倾的点），同一个点 |
| g27 | 侧倾轴线 | 前后侧倾中心的连线 | h_1（质心到轴线）≠ h_r（侧倾中心高度），常被混用 |
| g28 | 侧倾刚度 K_φ | K_φ=0.5K_s s²，in·lb/rad | 整车抗侧倾＝ΣK_φ−Wh₁；与 in·lb/deg 差 57.3 |
| g29 | 侧倾率 R_φ | dφ/da_y=Wh₁/(ΣK_φ−Wh₁)，典型 3–7 deg/g | **与"侧倾刚度"不是一回事**（例题 2 题干混称）；deg 口径代入会得负值 |
| g30 | 侧倾力矩分配 | 前后轴各分到多少侧倾力矩 | 判据是"力矩分给哪轴"，不是"刚度谁大"；弹性项按刚度比分配 |
| g31 | 横向载荷转移及其 K_lt | 转弯时内外轮垂向载荷差及其转向效应 | 唯一**不可消除**项；前轴项恒不足、后轴项恒过多；ΔF 以平方进入 |
| g32 | 侧倾转向 ε 与 K_rollsteer | 车身侧倾导致车轮相对车身转向；ε=转向角/每度侧倾 | 同号不同义（前正=不足、后正=过多）；⚠️ p178–179 正文与 p188 例题方向冲突，不得当判据 |
| g33 | 柔顺转向 A / 横摆中心 / K_lfcs | A=δ_c/F_y；车轴绕横摆中心转动 | 前后轴结论**相反**；"横摆中心"≠横摆角速度中心 |
| g34 | 回正力矩 / 拖距 p / K_at | 侧向力作用点在轮心后 p 处；K_at 由该后移产生 | 六项中唯一**符号锁死**（恒正、只能更不足）；间接路径（经转向系统）量级更大 |
| g35 | 驱动力修正项 | 式(6-67) 第三项：驱动力对 K 的修正 | 前驱加速→过多、后驱加速→不足、四驱后轴力>前轴；p182 bullet 的 F_xf/F_xr 表述自相矛盾，以 (6-67) 为准 |

## F. 测量与口径

| id | 术语 | 作者的定义 | 关键约束 / 易错点 |
|---|---|---|---|
| g36 | 转向盘转角 / 传动比 / 车轮转角 | 两个测量平面：hand-wheel 与 road-wheel | 传动比**不是常数**；车轮转角口径"不完全"（未含转向系统） |
| g37 | 等半径法 / 等速法 | 定圆升速读 δ–a_y 斜率 / 定速变转角并减阿克曼梯度 | 两法 K 公式不同；只有这两法"合理地反映通常驾驶" |
| g38 | 符号与单位约定 | 全章英制（lb、ft、in、mph）；57.3=180/π；g=32.2 | 四处必核：单胎/整轴、W_fs/W_f、b/c、英制/SI；C_α 两轮之和、K_φ rad、r 双单位 |

## 速度换算备忘

- 60 mph = 88 ft/s；1 ft/s = 0.6818 mph；1 m/s = 3.281 ft/s；1 in = 1/12 ft。
- rad↔deg 只用 57.3（180/π）；$g=32.2$ ft/s²（不是 9.81）。
