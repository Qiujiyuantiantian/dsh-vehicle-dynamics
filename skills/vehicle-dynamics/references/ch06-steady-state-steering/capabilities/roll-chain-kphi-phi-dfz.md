# 侧倾链：悬架侧倾刚度 → 侧倾率 → 前后轴侧倾力矩 → 轮荷差

## R — 原文 (Reading)

> **原书要点**（p173）：第一项 $2F_yh_r/t$ 来自侧向力本身，它的作用不因车身倾角大小或侧倾力矩怎样分配而改变。第二项 $2K_\varphi\varphi/t$ 则由车身侧倾派生，前后轴各自分到多少侧倾力矩，会直接决定这一项的大小。
>
> — Gillespie《车辆动力学基础》6.4.1（p173），式(6-27)

## I — 方法论骨架 (Interpretation)

这是一条**四环链**，每一环都有独立的输入与单位，任何一环错都会让最后一位数字"看起来对、其实是错的"。
1. 每轴侧倾刚度：$K_\varphi=0.5K_ss^2$。整体轴用左右弹簧刚度与弹簧间距；独立悬架可把"轮处刚度"当 $K_s$、"轮距"当 $s$；装了稳定杆就把该杆的侧倾刚度**叠加**上去。
2. 整车侧倾角：$K_\varphi$ 都是抗侧倾的，重力是"帮侧倾"的（$Wh_1$ 项），所以 $\varphi=Wh_1a_y/(\Sigma K_\varphi-Wh_1)$。分母为负说明参数荒谬，通常是单位口径错（in·lb/deg 当成 in·lb/rad）。
3. 前后轴力矩：每轴分到"弹性项"（按侧倾刚度比例分 $Wh_1a_y$）＋"几何项"（该轴自己的 $W_fh_fa_y$，来自侧倾中心高于轮心）。这两项**不是同一个机制**。
4. 轮荷差：$\Delta F_z=M_\varphi/t$。载荷差再经轮胎载荷非线性（侧偏力-载荷曲线）转成"该轴等效侧偏刚度下降"，于是才有转向效应。
关键认知：**第 3 步的几何项不可调、瞬时生效；弹性项才是稳定杆/弹簧能动的部分**。把两者混为一谈，就会得出"加硬弹簧能消除载荷转移"这种不可能的方案。

## A1 — 应用示例 (Application Example)

### 示例 1：例题 2 第 1–2 问（原书例题，p187–188）
- **类型与来源**：原书例题（完整数值题）。
- **输入**：前悬架侧倾刚度 $K_{\varphi f}=1500$ in·lb/deg；后叶片弹簧 $K_s=115$ lb/in、横向间距 $s=40$ in；悬挂质量 2750 lb；质心在侧倾轴线上方 10 in。
- **执行**：① $K_{\varphi r}=0.5\times115\times40^2=92\,000$ in·lb/rad $=1606$ in·lb/deg；② 把前轴也换成 rad 口径 $1500\times57.3=85\,950$ in·lb/rad；$Wh_1=2750\times10=27\,500$ in·lb；$\Sigma K=85\,950+92\,000=177\,950$；$R_\varphi=27\,500/(177\,950-27\,500)=0.1828$ rad/g。
- **结论/结果（复算值）**：$R_\varphi=0.1828$ rad/g $=10.47$ **deg/g**（原书 10.5，差异来自取整）。注意 10.47 deg/g 已超出原书自报的典型 3–7 deg/g。
- **原文瑕疵**：式(6-33) 左端原文印作 $F'_{\varphi f}$（力矩符号与力符号混用），按右端 $=\Delta F_{zf}t_f$ 可确认其为力矩；两端量纲自洽，不影响使用。

### 示例 2：轮荷差（原书例题数据 + 补充假设，属混合演练）
- **类型与来源**：**合成演练（补充假设）**。侧倾率来自原书例题 2，但 $a_y=0.5$、$W_f=1500$ lb、$h_f=18$ in、$t_f=58$ in 是演练假设，原书题面未给。
- **执行**：$\varphi=R_\varphi a_y=0.1828\times0.5=0.0914$ rad；弹性项 $85\,950\times0.0914=7\,855$ in·lb；几何项 $1500\times18\times0.5=13\,500$ in·lb；$M_{\varphi f}=21\,355$ in·lb；$\Delta F_{zf}=21\,355/58=368$ lb。
- **结论**：几何项占 63%——即使把稳定杆加到无穷硬，也消不掉这 13 500 in·lb。这是"只能分配、不能消除"的算术证据。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这条链？

1. 有弹簧刚度、间距、稳定杆数据，要算每轴侧倾刚度与整车侧倾率。
2. 想知道"前后轴各分到多少侧倾力矩/多少轮荷差"。
3. 评估"加粗前稳定杆会不会改变侧倾率、并进而改变外倾项"。
4. 解释为什么"减少侧倾"不等于"改善操控"。
5. 与实测侧倾角对比（$R_\varphi$ 的数量级自检）。

### 语言信号（中英双写）

- 「侧倾刚度怎么算」「侧倾率/侧倾角是多少」「前后轴轮荷差多少」
- 「roll stiffness / roll rate / lateral load transfer」「load transfer distribution」
- 「加了稳定杆侧倾能降多少」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `roll-stiffness-formula`：那张只算 $K_\varphi=0.5K_ss^2$ 与三种口径，是本链第 1 环。
- 与 `roll-rate`：那张只算 $R_\varphi$ 并专讲 rad/deg 陷阱，是本链第 2 环。
- 与 `load-transfer-two-mechanisms`：那张专讲双机制拆分与"哪部分可调"，是本链第 3–4 环的判据版。
- 与 `camber-thrust-k`：外倾项吃本链输出的 $R_\varphi$；本链不负责算外倾。

## E — 可执行步骤 (Execution)

**必需输入**：每轴弹簧刚度 $K_s$（lb/in）与横向间距 $s$（in）、稳定杆侧倾刚度（可选，同口径）、悬挂质量 $W$（lb）、质心到侧倾轴线距离 $h_1$（in）、$a_y$（g）、每轴 $W_f/W_r$、$h_f/h_r$（侧倾中心高度，in）、轮距 $t_f/t_r$（in）。

**交付物与完成标准**：一张表，列出 $K_{\varphi f}$、$K_{\varphi r}$（同时给 in·lb/rad 与 in·lb/deg）、$R_\varphi$（deg/g）、$M_{\varphi f}$、$M_{\varphi r}$、$\Delta F_{zf}$、$\Delta F_{zr}$；每格标单位。

1. **统一到 rad 口径**
   - 完成标准：凡 in·lb/deg 一律 ×57.3 换成 in·lb/rad，并在表里注明原始口径。
2. **算每轴 $K_\varphi$**
   - 完成标准：$K_\varphi=0.5K_ss^2$；独立悬架用轮处刚度与轮距；稳定杆刚度**相加**（不是取大者）。
3. **算侧倾率**
   - 完成标准：$R_\varphi=Wh_1/(\Sigma K_\varphi-Wh_1)$，单位 rad/g；再 ×57.3 得 deg/g。
   - 判停条件：分母 ≤0 → 停，判为单位/输入错误，不继续算（负侧倾率是荒谬值，原书未提示此陷阱）。
4. **算前后轴力矩**
   - 完成标准：$M_{\varphi f}=K_{\varphi f}\dfrac{Wh_1a_y}{\Sigma K-Wh_1}+W_fh_fa_y$（后轴同构），两项分别列出。
5. **算轮荷差并判读**
   - 完成标准：$\Delta F_z=M_\varphi/t$；说明"分到力矩大的轴先进入载荷非线性段"，并注明几何项不可调。

**计算约定（原书未规定，本卡设定）**：中间量保留 4 位有效数字，最终 $\Delta F_z$ 取整数 lb；单位换算只允许 ×57.3（rad↔deg）与 ÷12（in↔ft）两类，出现其他系数即判错。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **不要指望用它"消除"载荷转移。** 机制对所有车辆、两个轴都发生，只能分配（p172）。
- **不要用只装后轴稳定杆的方案去"压侧倾"**：后轴力矩占比↑ → 后轴侧偏角↑ → 过多转向；原书对此有明确警告（p174 第 4 条）。
- **不要用稳态侧倾率预测瞬态侧倾。** 侧倾有阻尼与惯量；$R_\varphi$ 是终值，不给相位与超调。
- **不要在小侧倾角假设外使用。** 式(6-29) 用了 $\sin\varphi\approx\varphi$、$\cos\varphi\approx1$；10.47 deg/g 在 0.5 g 时已达 5.2°，假设已在边缘。
- **不要拿例题 2 的 10.47 deg/g 当"典型轿车"数值**：原书自报典型 3–7 deg/g，该例题落在区间之外（事实可核；"因此不典型"属推断，不要当作者观点引用）。

### 作者在书中警告的失败模式

- ce08：只在后轴装稳定杆 → 不期望的过多转向。
- ce09：以为载荷转移可消除/可变号（前轴项恒正、后轴项恒负，$\Delta F$ 以平方进入）。
- ce21：把例题 2 的悬架项量级当典型值（数值超出自报区间这一事实可用，推断部分不可用）。

### 作者的盲点 / 时代局限

- 全章英制；$K_\varphi$ 的 rad/deg 混用陷阱原文未提示，是本链最高频的出错点。
- 侧倾中心高度 $h_r$、$h_1$ 需要悬架运动学/几何数据，普通读者拿不到；作者默认读者是整车厂工程师。
- 1992 年无主动防倾杆、无电控悬架；这些系统会改变"分配"这一环的前提。

### 容易混淆的邻近方法论

- **侧倾刚度 vs 侧倾率**：一个是 in·lb/deg（抗力矩），一个是 deg/g（每 g 倾多少度）。例题 2 题干自己把"侧倾刚度"当"侧倾率"用，属术语混称。
- **横向载荷转移（ΔF_z）vs 载荷转移引起的转向效应（$K_{lt}$）**：前者是力，后者是 deg/g，中间隔着轮胎载荷灵敏度系数 b（本章无来源值）。
