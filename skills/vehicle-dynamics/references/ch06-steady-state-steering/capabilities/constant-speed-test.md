# 等速法实测 K：用阿克曼梯度线做基准

## R — 原文 (Reading)

> **原书要点**（p184–185）：换个做法，让车速保持不动、只改转角，也能把不足转向量出来。把阿克曼转角梯度当作中性转向的基准：实测梯度若在它之上，就是不足转向；落在它之下，则属于过多转向。
>
> — Gillespie《车辆动力学基础》6.6.2（p184–185），式(6-71)(6-72)(6-73)

## I — 方法论骨架 (Interpretation)

等速法固定车速、改转向角，于是半径连续变化——这更接近日常驾驶（大多数人保持车速不变打方向）。
代价是：**阿克曼项不再是常数**。把 $R=V^2/a_y$ 代回转向方程得 $\delta=57.3La_y/V^2+K a_y$，前一项随 $a_y$ 线性增长，斜率固定为 $57.3L/V^2$。所以：
- 图上画两条线：实测 δ–a_y 直线，与"中性转向基准线"（斜率 $57.3L/V^2$，即阿克曼梯度）。
- **高于基准线 → 不足；重合 → 中性；低于 → 过多。**
- 数值上：$K=\partial\delta/\partial a_y-57.3L/V^2$。这一步减法就是等速法独有的易错点——把实测斜率直接当 K，会多算一个阿克曼梯度。
- 对过多转向车，"斜率为零的点"对应临界车速（稳定极限）。
- 每个测点还要另测 $a_y$ 或 $r$ 反算半径；用 $r$ 时**必须 rad/s**（式(6-71) 的符号表口径），而式(6-21) 的 $r$ 是 deg/s——同一符号两处不同单位，是全章最阴的陷阱。

## A1 — 应用示例 (Application Example)

### 示例 1：原书方法论（原书未提供数值算例）
- **类型与来源**：原书方法论描述（6.6.2 全节），配图 6.21 的判读规则；**作者未给数值算例**。
- **内容**：固定 $V$ → $R=V^2/a_y=V/r$ → 作 δ–a_y 图 → 与阿克曼梯度线比高低 → 过多转向车的"斜率为零"点即临界车速。

### 示例 2：一次完整的合成演练（非书中事实）
- **类型与来源**：**合成演练**。车速、斜率与转角由本卡设定，用于检验"减阿克曼梯度"这一步；不是作者做过的试验。
- **输入**：$V=88$ ft/s（60 mph）、$L=8.383$ ft、实测 δ–a_y 直线斜率 4.50 deg/g。
- **执行**：阿克曼梯度 $=57.3\times8.383/88^2=480.34/7744=0.0620$ deg/g；$K=4.50-0.0620$。
- **结论**：$K=4.44$ deg/g（不足转向）。自检：反代式(6-72)，$a_y=0.3$ 时 $\delta=0.0620\times0.3+4.44\times0.3=1.35°$，与直线自洽。
- **若忘记减法**：会报 4.50，误差 1.4%——量级不大，但在"接近中性"的车上（$K\approx0.1$）会把符号判反。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这张卡？

1. 长直道/环道可变速、要贴近日常定速驾驶做一次 K 测量。
2. 手上有"固定车速、逐级加转角"的数据（δ、V、$a_y$ 或 $r$），要算 K。
3. 想把实测斜率与"中性转向基准线"对照，判不足/中性/过多。
4. 过多转向车要定位"斜率为零"的临界点。
5. 数据里同时有 deg/s 与 rad/s 的横摆角速度，要防单位串。

## E — 可执行步骤 (Execution)

**必需输入**：恒定车速 $V$（ft/s）、$L$（ft）、每点转向盘转角与传动比（或直接给车轮转角）、每点 $a_y$（g）或横摆角速度 $r$（**rad/s**）。缺半径/加速度 → 用 $R=V^2/a_y=V/r$ 反算，但要先确认 $r$ 的单位。

**交付物与完成标准**：δ–a_y 图（含阿克曼梯度基准线）＋实测斜率＋$57.3L/V^2$＋K（deg/g，2 位小数）＋与基准线的相对位置结论。

1. **统一 $r$ 的单位**
   - 完成标准：若用 $R=V/r$，$r$ 必须是 rad/s；若数据是 deg/s，先 ÷57.3。
2. **算阿克曼梯度**
   - 完成标准：$57.3L/V^2$（deg/g），$L$ 用 ft、$V$ 用 ft/s，可手算复核。
3. **拟合实测斜率**
   - 完成标准：线性段最小二乘，报告斜率与 $R^2$（<0.98 不得用单点）。
4. **作减法**
   - 完成标准：$K=\partial\delta/\partial a_y-57.3L/V^2$；两项分别写出，禁止只报斜率。
5. **判读与交付**
   - 完成标准：给出"高于/等于/低于基准线"的结论；过多转向时标出斜率为零的点（临界车速）；声明车轮/转向盘口径与稳态前提。
   - 判停条件：若 $V$ 在测段内不恒定 → 停，该数据不属等速法。

**计算约定（原书未规定，本卡设定）**：$V$ 用 ft/s（60 mph=88 ft/s）；$K$ 保留 2 位小数；容差 ±0.05 deg/g。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **不要把实测斜率直接当 K。** 等速法的斜率 = K + 阿克曼梯度；漏减会把一辆接近中性的车判成明显不足。
- **不要混用 $r$ 的两种单位。** 式(6-21) 的 $r$ 是 deg/s，式(6-71) 的 $r$ 是 rad/s；混用会让半径差 57.3 倍。
- **不要在测段内车速漂移**：等速是方法前提，不是操作建议。
- **不要用瞬态数据**（加减速、快速变角）取斜率。
- **不要跨方法比较**（等速法 vs 等半径法 vs 等转向角法），三种方法的定义域不同。

### 作者在书中警告的失败模式

- ce14：非稳态工况套用稳态方程。
- ce13：不声明 hand-wheel / road-wheel 口径就与厂家数据对比。
- ce17：用一个 K 描述整个 $a_y$ 范围。
- ce15：把等转向角法/等节气门法的结果当本法结果使用。

### 作者的盲点 / 时代局限

- 1992 年：需要能稳定控速的场地与仪器，个人无法复现；无 GPS/IMU。
- 传动比按常数换算（作者自己指出传动比非常数）。
- 未给不确定度与重复性方法；"斜率为零的点=临界车速"是从图上读的，未给拟合/外推流程。

### 容易混淆的邻近方法论

- **阿克曼角（几何量）vs 阿克曼梯度（斜率）vs 阿克曼转向角梯度基准线**：同一个词的三重身份，前者是 deg，后两者是 deg/g。
- **"横摆角速度增益"与"横摆角速度"**：本卡用 $r$ 只为反算半径，不是在算增益（那属派生指标，本章 (6-22) 印刷残缺，未进入能力池）。
