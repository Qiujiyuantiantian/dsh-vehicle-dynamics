# Olley 判据：由扰动后的走向判定不足/过多转向

## R — 原文 (Reading)

> **原书要点**（p171）：前轴柔度偏大时，整车呈不足转向；一旦出现侧向扰动，前轮先偏出去，车头顺势朝扰动所指的方向转。反之若后轴柔度更大（过多转向），车尾会向外甩，车身便绕向扰动的内侧。
>
> — Gillespie《车辆动力学基础》6.4 开篇（p171），图 6.10

## I — 方法论骨架 (Interpretation)

这是一条**不用任何系数**的判据：给质心一个侧向扰动，看车头往哪边偏。
- 车头朝**扰动方向**偏 → 前轴柔度大 → **不足转向**。
- 车头朝**扰动内侧**转（车尾外滑）→ 后轴柔度大 → **过多转向**。
为什么等价于 K：K 的符号本质是"前轴柔度−后轴柔度"；扰动只是把这个差值变成一次可见的运动。
它的独特价值有三点：
1. **不需要轮胎数据**，一次脉冲扰动（试车、仿真、甚至驾驶模拟器）就能判。
2. **能解释"为什么过多转向危险"**：车头往内侧转 → 侧向加速度增大 → 后轴侧偏角更大 → 正反馈。作者引 Rocard：直线行驶的正常扰动就足以在临界车速处触发失稳。
3. **可与 K 交叉验证**：两者结论应一致；不一致说明输入数据或理解有错。
注意"扰动方向"与"内侧"的定义要写清：向外推车尾 = 向扰动方向偏？实际执行时必须先约定坐标系，否则会判反。

## A1 — 应用示例 (Application Example)

### 示例 1：原书的 Olley 定义（原书案例，无算例）
- **类型与来源**：原书正文（p171，图 6.10 的三条轨迹：不足/中性/过多），**无配套数值**。
- **内容**：在同一扰动下，不足转向车沿扰动方向转、中性车直行、过多转向车向扰动内侧转。作者注明这是 Olley 的定义，并与 Rocard 的直线扰动分析互证（同页）。

### 示例 2：一次扰动试验的判读（合成演练，非书中事实）
- **类型与来源**：**合成演练**。200 lb 脉冲由本卡设定，判定按原书两条规则。
- **输入**：在质心处施加向右的侧向脉冲 200 lb（短时）。
- **情形 A**：车头随即向右偏 → 前轴柔度大 → **不足转向**，与 K>0 一致。
- **情形 B**：车头向左偏、车尾向右滑 → 后轴柔度大 → **过多转向**，且侧向加速度会放大扰动（正反馈）。
- **注意**：这是判读演练，不是任何真实车辆的试验结果。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这条判据？

1. 手头没有轮胎数据，只能靠试车/仿真判特性。
2. 向非专业读者解释"为什么过多转向危险"（正反馈）。
3. 与算出的 K 交叉验证（结论应一致）。
4. 分析一次侧风/路面凸起后的车辆姿态反应。
5. 判断某车"高速发飘"是否属于过多转向。

### 语言信号（中英双写）

- 「给个侧向扰动，车头往哪偏算推头」「Olley 判据是什么」「disturbance test understeer」
- 「为什么甩尾会越来越严重」「侧风一吹车就往里转」
- 「不用公式能判吗」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `steer-character-k`：那张用轴荷与刚度算 K；本卡用一次扰动判方向，二者应一致。
- 与 `critical-speed`：本卡的"正反馈"解释是 $V_{crit}$ 的物理基础（Rocard）。
- 与 `axle-rule-direction`：那条判据是"效应→轴→方向"，本卡是"扰动→轨迹→方向"，入口不同。

## E — 可执行步骤 (Execution)

**必需输入**：扰动方向（左/右）、扰动后车头的偏转方向、车尾的运动方向（或侧向加速度变化）。缺"车尾方向"时，仅凭车头方向也可判，但需说明依据。

**交付物与完成标准**：判定（不足/中性/过多）＋判读依据（车头方向 or 车尾方向）＋"是否为正反馈"的说明。

1. **约定坐标**
   - 完成标准：先写"扰动向右为正、车头向右偏为正"，避免左右混。
2. **判车头方向**
   - 完成标准：车头同向 → 不足；车头反向（向扰动内侧）→ 过多；几乎不偏 → 中性。
3. **交叉验证**
   - 完成标准：与 K 的符号比较；不一致则停，回报冲突。
4. **解释机制**
   - 完成标准：过多转向要补一句"侧向加速度放大扰动、形成正反馈，超过 $V_{crit}$ 发散"。
5. **交付**
   - 完成标准：只给定性结论；不据此推算 K 的数值。

**约定（原书未规定，本卡设定）**：扰动用"短时脉冲"表述；判读容差为"车头偏转方向明确可辨"，模糊时判"中性/不明"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用这条判据

- **不要用它算 K 的数值**：它只给方向，不给 deg/g。
- **不要在瞬态强耦合工况下判**（如同时大幅制动/驱动）：驱动力与纵向力会改变侧偏刚度，扰动响应不再只由前后柔度决定。
- **不要忽略扰动幅值**：大幅扰动会让轮胎进入非线性，响应可能非线性甚至反向（不足/过多转向极限）。
- **不要用于四轮转向/主动转向车**：后轮也转角时"车头往哪偏"的判据要重写。
- **不要在低附着路面直接套**：附着率改变侧偏刚度，前后柔度比可能变化。

### 作者在书中警告的失败模式

- ce04：把过多转向当驾驶技术问题——Olley/Rocard 的论证正是"这是物理不稳定，不是操作问题"。
- ce05：在临界车速附近"感觉还有余量"（正反馈增益已放大）。
- ce17：用一个 K 描述整个 $a_y$ 范围（大幅扰动下判据可能失效）。

### 作者的盲点 / 时代局限

- 判据是定性的，作者未给"扰动多大、持续多久"的实验规范。
- 1992 年：实车扰动试验危险且难复现；现代可用驾驶模拟器/硬件在环复现。
- 未讨论驾驶员在环时的补偿（闭环会掩盖开环的不稳定趋势）。

### 容易混淆的邻近方法论

- **Olley 判据 vs 转向版定义（K 的符号）**：结论等价但推理链不同（一个是轨迹，一个是柔度差）。
- **"向扰动内侧转"vs"向弯内侧转"**：前者是直线扰动，后者是转弯工况，别混。
