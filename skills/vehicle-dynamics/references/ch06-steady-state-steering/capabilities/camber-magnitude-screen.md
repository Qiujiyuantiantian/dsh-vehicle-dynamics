# 外倾量级三条分流判据

## R — 原文 (Reading)

> **原书要点**（p176–177）：书中的换算关系是：斜交胎做出 4°～6° 外倾时，其横向力与 1° 侧偏相当；子午线胎则常要求做到 10°～15°。整体式车轴的外倾变化量很小，对侧偏力的改动最多一成左右，甚至更低。
>
> — Gillespie《车辆动力学基础》6.4.2（p176–177），图 6.14

## I — 方法论骨架 (Interpretation)

在动笔算 $K_{camber}$ 之前，先用三条**量级判据**决定"值不值得算"：
1. **斜交胎**：4–6° 外倾 ≈ 1° 侧偏 → $C_\gamma/C_\alpha\approx1/5\sim1/4$（0.17–0.25）。
2. **子午胎**：要达到同样侧向力，需要 10–15° 外倾 → 比值更小（约 1/10 量级；例题用的 0.1 相当于子午胎的高端）。
3. **整体轴**：外倾变化小，"最多仅改变侧偏力的 10% 或更低" → **可忽略，不必进入 (6-56)**。
分流结论：
- 整体轴车 → 跳过外倾项（不是"算出来很小"，而是"结构上就没多少"）。
- 独立悬架（尤其平行等长臂、$\partial\gamma/\partial\phi\approx1$）→ 必须算。
- 斜交胎比子午胎更"吃"外倾（同样角度产生更大侧向力），但也更吃胎压。
附带的两条物性（原文）：
- 外倾推力对**载荷与速度**相对不敏感；
- 胎压对斜交胎的外倾推力影响重要，对子午胎不明显。
这三条判据的价值在于**先压期望值**：很多人以为"改外倾能大幅调 K"，量级判据会先告诉他不能。

## A1 — 应用示例 (Application Example)

### 示例 1：原书的量级事实（原书案例，无算例）
- **类型与来源**：原书正文（p176–177），配图 6.14 的定性曲线；**作者未给"是否该算"的算例**。
- **内容**：斜交胎 4–6°≈1° 侧偏；子午胎 10–15°；整体轴 ≤10%；外倾推力对载荷/速度不敏感；胎压敏感性因胎而异。

### 示例 2：三条分流判据的应用（合成演练，非书中事实）
- **类型与来源**：**合成演练**。三辆车由本卡设定，判定全部按原书三条规则。
- **车 A**：整体后轴 → 判"跳过外倾项"，说明"≤10%，不必进 (6-56)"。
- **车 B**：平行等长臂独立前悬 → $\partial\gamma/\partial\phi\approx1$ → 判"必须算"，进入 `camber-thrust-k`。
- **车 C**：斜交胎 + 独立悬架 → 若取 $C_\gamma/C_\alpha=0.2$（4–6°≈1° 的倒数区间），外倾项量级会是例题（0.1）的两倍——同时提醒胎压敏感性更高。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这三条判据？

1. 开工前决定"这辆车要不要算外倾项"（省时间、防过度建模）。
2. 评估"改外倾能不能解决推头"的期望值。
3. 判断某份报告"外倾项 1.05 deg/g"是否可能适用于自己的车。
4. 区分斜交胎/子午胎在外倾上的量级差异。
5. 判断整体轴车是否需要外倾调校。

### 语言信号（中英双写）

- 「外倾对 K 影响大不大」「整体轴要不要算外倾」「camber worth modeling?」
- 「斜交胎和子午胎外倾差多少」「solid axle camber effect」
- 「改外倾能治推头吗」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `camber-thrust-k`：本卡判"要不要算"，那张负责"怎么算"。
- 与 `camber-angle-composition`：那张做角度合成，本卡做量级筛选。
- 与 `understeer-tuning`：本卡的结论会降低"改外倾"在调校清单里的优先级。

## E — 可执行步骤 (Execution)

**必需输入**：悬架形式（整体轴/独立）、轮胎类型（斜交/子午）、$\partial\gamma/\partial\phi$（若已知）、$C_\gamma/C_\alpha$（若已知）。

**交付物与完成标准**：三行判定（该车属于哪一类）＋"算/不算"的结论＋若算，给出 $C_\gamma/C_\alpha$ 的取值区间与来源。

1. **判悬架**
   - 完成标准：整体轴 → 结论"跳过"（≤10%），并注明这是量级结论而非精确为 0。
2. **判轮胎**
   - 完成标准：斜交 → 0.17–0.25 区间；子午 → 约 0.1 或更低；若用户给了实测值，以实测为准。
3. **判梯度**
   - 完成标准：$\partial\gamma/\partial\phi$ 已知则用；未知则说明"平行等长臂≈1，其余需运动学分析"，不得默认为 1。
4. **交付**
   - 完成标准：给出"算/不算"与期望量级；若判"算"，列出还需哪些输入。

**约定（原书未规定，本卡设定）**：量级区间按原文文字换算（4–6°≈1° → 0.17–0.25）；"≤10%"按上限理解为 0.1 倍侧偏力。

## B — 边界 (Boundary) ★

### 不要在以下情况使用这三条判据

- **不要用它替代精确计算**：它是筛选，不是结果；判"要算"之后仍须走完整公式。
- **不要把整体轴的"≤10%"理解成"外倾完全无关"**：这是量级上限，特定工况（大侧倾、软悬架）仍可能有可测影响。
- **不要跨轮胎型号套比值**：$C_\gamma/C_\alpha$ 随结构、胎压、载荷变化，原文只给量级。
- **不要用它支持"改外倾能大幅调 K"**：恰恰相反，量级判据的作用是压低这个期望。
- **不要忽略代价**：偏磨、直线稳定性、胎压敏感性不在 K 的账本里（部分为推断，引用须标注）。

### 作者在书中警告的失败模式

- ce18：把外倾当调 K 的主要手段（量级有原文，代价部分为推断）。
- ce21：把例题 2 的 1.05 deg/g 当典型值（其侧倾率超出自报 3–7 区间）。

### 作者的盲点 / 时代局限

- 原文的量级是 1992 年轮胎的统计；现代低扁平比子午胎的外倾敏感性已变化。
- 作者未给 $C_\gamma$ 的具体数值表，只说"需由悬架运动学分析得到"。
- 未讨论外倾与纵向力（驱动/制动）的耦合。

### 容易混淆的邻近方法论

- **外倾推力（$C_\gamma$）vs 外倾梯度（$\partial\gamma/\partial\phi$）**：一个来自轮胎、一个来自悬架几何。
- **"整体轴不必算"vs"独立悬架必须算"**：这是两条独立的判据（悬架形式、轮胎类型），要分别过。
