# 设计调校决策链：改哪个零件 → 动哪一项 → K 往哪个方向（限定版）

## R — 原文 (Reading)

> **原书要点**（p182 §6.5）：不足转向系数 $K$ 并非单一来源，而是轮胎、整车、转向系统等多方面参数共同作用的结果；它的总量由表中各项效应逐条相加得到。
>
> — Gillespie《车辆动力学基础》6.5（p182）；各分项见 6.4.1–6.4.6（p172–182）

## I — 方法论骨架 (Interpretation)

从"描述"走到"改变"，只需要三步，但每一步都有硬约束。
1. **先定位**：在能算的分项里找出主因（轮胎项、载荷转移项、外倾项、柔顺项、回正力矩项、驱动力项）。哪些算不了要先说清楚，不能装作全能。
2. **再选旋钮**：调校入口不是"改 K"，而是"改任何能让车轮多产生/少产生侧偏力的东西"——弹簧、稳定杆、衬套、导向臂、外倾、驱动力分配、轮胎本身。
3. **只出方向与优先级**：每个动作→动的分项→K 的移动方向。**不给 ΔK 数值**（本章的定量链不闭合：b、A、p、ε 四类系数原文一个数值都没给，"转向系统"行连公式都没有）。
判断一个方案能不能用，看两条铁律：
- **轴别铁律**：动作使哪个轴的侧偏角变大 → 前轴变大更不足、后轴变大更过多。
- **单向项铁律**：回正力矩项恒为正（只能更不足），横向载荷转移只能分配不能消除。
最后要回看阈值指标：K 变小时 $V_{char}$ 变大、$V_{crit}$ 变小——"更中性"不等于"更安全"。

## A1 — 应用示例 (Application Example)

### 示例 1：原书正文的调校结论（原书案例，非例题）
- **类型与来源**：原书正文案例（p172、p174、p176–178、p180、p182），无配套算例。
- **内容**：稳定杆装前轴→增加不足、装后轴→增加过多（p172）；只装后轴稳定杆"有导致不期望的过多转向的可能"（p174）；外倾走独立悬架才是主战场（p177）；回正力矩恒正、通常 <0.5 deg/g（p180）；四驱建议后轴驱动力大于前轴（p182）。

### 示例 2：一辆过多转向车的调校清单（合成演练，非书中事实）
- **类型与来源**：**合成演练**。车辆描述与 $K=-0.4$ deg/g 由本卡设定，输出的动作全部来自原书规则，但"这样就够不够"原书没有答案。
- **输入**：$K=-0.4$ deg/g（过多）、独立前悬架、整体后轴、无后稳定杆。
- **执行与结论（动作 → 分项 → 方向）**：
  - 加粗前稳定杆 → $K_{lt}$ 前项↑ → 更不足；
  - 把后轴横摆中心移到轴后 → $K_{lfcs}$ 反向 → 更不足（须先确认原车中心位置）；
  - 提高前轴外倾梯度（独立悬架）→ $K_{camber}$ 前项↑ → 更不足；
  - 若为四驱 → 后轴分配更多驱动力 → 项 3 → 更不足。
- **禁止项（原书依据）**：只加后稳定杆（反向，p174 警告）；指望调回正力矩把车推向过多（$K_{at}$ 恒正，p180）。
- **未做**：不给 ΔK，不承诺调完就中性——因为缺 b、A、p 的数值。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这条链？

1. "这车推头/甩尾，该动什么？"——要的是零件清单与方向，不是公式。
2. 改装方案评审：给一串改动（稳定杆、弹簧、衬套、轮胎、四驱分配），要判断方向是否互相打架。
3. 样车后期调校：时间不够做完整六项计算，只能按方向试。
4. 解释"为什么只加后稳定杆更危险"给非工程读者。
5. 判断某个"调校秘方"在哪一层是错的。

### 语言信号（中英双写）

- 「怎么把推头/甩尾调回来」「改哪个零件能让车更中性」「这套改装的方向对不对」
- 「how to fix understeer/oversteer」「sway bar tuning」「alignment and bushing tuning for balance」
- 「不想算，就告诉我动哪儿」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `design-lever-inventory`：那张是"找手段"的穷举清单（七条通道），本卡是"选手段 + 定方向 + 排优先级"的决策链。
- 与 `axle-rule-direction`：本卡每一步的方向判定都调用那条轴别判据。
- 与 `steer-character-k`：那张告诉你现在是什么特性；本卡告诉你怎么改。
- 与 `load-transfer-only-distributed`：本卡里"只能分配"这条约束来自那张。

## E — 可执行步骤 (Execution)

**必需输入**：当前特性（$K$ 的符号与量级，或至少不足/过多判定）、悬架形式（独立/整体，前后轴）、现有稳定杆配置、驱动形式（前/后/四驱）、可改范围（哪些件允许动）。缺悬架形式 → 先问，不能默认独立悬架。

**交付物与完成标准**：一张改动清单，每行含「改这个 / 动哪项 / 方向 / 依据（页码或分项式）」＋明确的禁止项＋阈值回看说明。**不含 ΔK 数值**。

1. **定位主因**
   - 完成标准：写出当前 K 的构成判断（哪几项可算、哪几项缺系数）；明确标注"数值层不闭合"的部分。
2. **从下表选动作**（限定版，已剔除不可用行）
   | 改这个 | 动哪项 | 方向 | 依据 |
   |---|---|---|---|
   | 稳定杆装前轴 / 提高前侧倾刚度 | 前轴侧倾力矩占比↑ → $K_{lt}$ 前项↑ | 更不足 | p172、p174 |
   | 稳定杆只装后轴 | 后轴侧倾力矩↑ | 更过多（原文明确警告） | p174 |
   | 后轴横摆中心由轴前改到轴后（衬套/杆系） | $K_{lfcs}$ 反向 | 更不足 | p179–180 |
   | 前轴外倾梯度↑（独立悬架） | $K_{camber}$ 前项↑ | 更不足 | p176–178 |
   | 四驱前后驱动力分配 | 项 3 修正 | 后轴力 > 前轴 → 更不足 | p182 |
   | 加长轴距 | 不改任何分项 | 特性不变，$V_{char}$/$V_{crit}$ 同时抬高 | p168 |
   | 回正力矩 / 主销后倾（想往过多调） | $K_{at}$ 恒正 | **不可用**（只能更不足） | p180 |
   - 完成标准：每选一行都能说出作用轴与机制；不能说出机制的行不得使用。
3. **排优先级**
   - 完成标准：按"改动成本 × 方向确定性 × 可逆性"排序；方向依赖未解冲突的动作（后轴导向臂倾角）**不得进入清单**。
4. **写禁止项**
   - 完成标准：至少列出"只加后稳定杆""指望回正力矩""指望消除载荷转移"三条。
5. **阈值回看**
   - 完成标准：说明 K 变化后 $V_{char}$（K 变小→变大）与 $V_{crit}$（K 变大→变小）怎么动；提醒"接近中性 = 裕度小"。

**约定（原书未规定，本卡设定）**：只输出方向与优先级，不输出 ΔK；若用户坚持要数值，转到对应分项卡并说明缺哪些系数。

## B — 边界 (Boundary) ★

### 不要在以下情况使用这条链

- **不要给 ΔK 数值。** 本章的定量链不闭合：$K_{lt}$ 缺二阶系数 b、$K_{lfcs}$ 缺 A、$K_{at}$ 缺拖距 p、$K_{rollsteer}$ 缺符号定义，6.5 表的"转向系统"行只有名称没有公式。任何"算出整车 K 总和"的输出都缺一块。
- **不要给"改后轴拖曳导向臂倾角 β"的方向。** 原书 **p179 正文**（支点低于轮心→不足转向）与 **p188 例题**（同一几何→过多转向）**自相矛盾**，故该行已从本卡剔除。凡涉及该动作，一律标注「**原文自相矛盾（p179 正文 vs p188 例题），需实车/台架标定**」，不给确定方向。
- **不要把"减少侧倾"当成"改善操控"。** 判据是"力矩分给哪个轴"，不是"刚度谁大"。
- **不要承诺调完就"安全"**：$V_{char}$ 变大意味着更接近中性、离过多转向更近。
- **不要用在主动悬架/四轮转向/扭矩矢量车上**：这些系统实时改变分项本身，本章的静态叠加模型不适用。

### 作者在书中警告的失败模式

- ce07（最重）：只算轮胎项就宣布"接近中性，没问题"。
- ce08：只装后轴稳定杆 → 不期望的过多转向。
- ce09：以为载荷转移可消除或可变号。
- ce18：把外倾当调 K 的主手段。
- ce12：因 $K_{at}$ 恒正且小就跳过它（转向系统间接路径更大）。

### 作者的盲点 / 时代局限

- 1992 年：无 ESC/电控悬架；现代车上"过多转向"可被电子系统掩盖，物理机制不变。
- 作者的调校建议默认读者能拿到轮胎表与悬架运动学数据；缺数据时本卡只能给方向。
- 本章不谈瞬态与主观手感，调校效果最终仍需实车主观+客观联合验收。

### 容易混淆的邻近方法论

- **"改 K"vs"改某分项"**：不能先在 K 上做算术再倒推零件；正确顺序是从零件出发看分项。
- **侧倾刚度分配 vs 侧倾率大小**：前者决定方向（哪轴更不足），后者决定外倾/侧倾转向项被放大多少倍。
