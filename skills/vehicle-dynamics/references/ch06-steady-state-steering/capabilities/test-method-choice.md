# 四种试验法只取两种：K 测量方法选型

## R — 原文 (Reading)

> **原书要点**（p183 §6.6）：测定不足转向特性的试验手段共四类：固定半径、固定车速、固定转向角、固定节气门开度。四者之中只有前两类与日常驾驶情形较为吻合，故书中的讨论只覆盖这两类。
>
> — Gillespie《车辆动力学基础》6.6 引言（p183）

## I — 方法论骨架 (Interpretation)

选方法不是选精度，而是选**"测出来的量回答哪个问题"**。
四种方法固定的量不同：
| 方法 | 固定 | 变化 |
|---|---|---|
| 等半径法 | 半径 R | 车速、$a_y$ |
| 等速法 | 车速 V | 转向角、半径、$a_y$ |
| 等转向角法 | 转向角 δ | 半径、车速、$a_y$ |
| 等节气门开度法 | 油门 | 全部 |
作者的取舍标准只有一条：**是否"合理地反映通常的驾驶情况"**。前两种对应真实驾驶（定圆匝道 / 定速巡航打方向），后两种不 correspond 任何常见工况，而且几何项不再是常数，测出的斜率混进了别的成分。
所以"跨方法比较"等于"跨定义比较"——两个 K 不可比，不是误差问题。
选型逻辑：
- 有定圆场地 → 等半径法（设备最少，但操纵精度要求高）。
- 有长直道、要贴近日常 → 等速法（数据量更大，要减阿克曼梯度）。
- 只有油门与转角可控 → **不采用**（不在可用两法内），而不是"凑合用一个"。

## A1 — 应用示例 (Application Example)

### 示例 1：原书的方法清单（原书案例，无算例）
- **类型与来源**：原书正文（p183 一段），**无数值算例**；后续 6.6.1/6.6.2 分别展开前两种。

### 示例 2：三次选型演练（合成演练，非书中事实）
- **类型与来源**：**合成演练**。约束条件由本卡设定，取舍依据原书"是否反映通常驾驶"这一条。
- **场景 A**：只有一块 30 m 定圆场地 + 转向盘转角传感器 → **选等半径法**（设备最少；半径正好在下限）。
- **场景 B**：长直道、可变转向、要最接近日常定速驾驶 → **选等速法**（须另测半径或横摆角速度，并减阿克曼梯度）。
- **场景 C**：只有油门与转向角可控、场地不规则 → **判"不采用"**：后两种方法不在此章可用范围内，硬用得到的不是同一个 K。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这次选型？

1. 策划一次稳态回转试验，先定方法。
2. 手上数据来源不明，要判断"这算哪种方法、能不能用"。
3. 两份 K 数据差异很大，要排查是否跨方法。
4. 设备/场地受限，需要知道"哪些妥协不可接受"。
5. 写试验报告的方法学章节。

### 语言信号（中英双写）

- 「用哪种方法测 K」「等半径还是等速」「which steady-state test method」
- 「只有油门和方向盘可控，能测吗」「constant steer test valid?」
- 「两种方法测出来不一样，哪个对」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `constant-radius-test` / `constant-speed-test`：那两张是选定后的执行流程；本卡只做选型。
- 与 `sae-k-definition`：选完方法还要定口径，两件事不同。
- 与 `two-wheel-preconditions`：方法有效性的前提是稳态与线性，那张卡管模型域。

## E — 可执行步骤 (Execution)

**必需输入**：可用场地（半径/长度）、可测变量（转角/车速/$a_y$/横摆角速度）、目标用途（对标厂家 / 内部调校 / 科研）。

**交付物与完成标准**：选定方法＋理由（对应"是否反映通常驾驶"）＋该方法的必备测量项＋不可接受的替代方案清单。

1. **列约束**
   - 完成标准：场地、设备、目标三项写清。
2. **筛掉不可用法**
   - 完成标准：明确排除等转向角法与等节气门开度法，并说明理由（不反映通常驾驶、几何项非常数）。
3. **在两法间选**
   - 完成标准：定圆场地 → 等半径；长直道/日常工况 → 等速；两者都可 → 优先等半径（设备最少）。
4. **列必备测量**
   - 完成标准：等半径法需转向盘转角、$a_y$（或车速+半径）、传动比；等速法另需半径或横摆角速度（rad/s）。
5. **交付**
   - 完成标准：写明"不跨方法比较"的约束；若用户已有跨方法数据，只比符号与量级。

**约定（原书未规定，本卡设定）**：方法名统一用"等半径法/等速法"；报告中必须写明方法与口径两项。

## B — 边界 (Boundary) ★

### 不要在以下情况使用这次选型

- **不要用等转向角法/等节气门开度法的结果与本法结果比较**：定义域不同，测的不是同一个量。
- **不要因为设备简单就选后两种**：作者用"合理地反映"划界——不是不能测，是测出来的不是公路驾驶的 K。
- **不要在非稳态工况套任何一种方法**：四法都以稳态为前提。
- **不要忽略半径下限**：等半径法最小半径一般 30 m（≈100 ft）；更小的圆会让小角度假设失效。
- **不要用于多轴车而不按目标半径实测**：多轴车 K 对半径敏感，单一试验半径的结果不能外推（ce16）。

### 作者在书中警告的失败模式

- ce15：选等转向角法/等节气门法并外推到公路驾驶，或与等半径法数据直接比较。
- ce16：把双轴"K 与半径无关"用于三轴以上。
- ce14：用瞬态数据（J-turn/蛇行）算 K。

### 作者的盲点 / 时代局限

- 作者只说后两种"不反映通常驾驶"，未给它们的定量偏差量级。
- 1992 年：方法选择受场地与仪器限制很大；现代 GPS/IMU 与自动驾驶试验场让"等速法"更容易实施。
- 未讨论 ISO 4138 等标准的试验条件（只在参考文献列出）。

### 容易混淆的邻近方法论

- **"方法选型"vs"口径声明"**：前者决定怎么开，后者决定算的是谁的转角。
- **"稳态回转试验"vs"瞬态操控试验"**：后者（双移线、蛇行）不产出 K。
