# 低速转向几何：阿克曼角与偏离轮迹

## R — 原文 (Reading)

> **原书要点**（p162–163）：在小转角假设下整理几何关系，可写出内、外前轮的转角：外侧 δ_o≈L/(R+t/2)，内侧 δ_i≈L/(R−t/2)。书中还指出，后轮跟不上前轮轨迹的情况，多见于轴距较长的车，例如载货汽车与大客车。
>
> — Gillespie《车辆动力学基础》6.2（p162–163），式(6-1)(6-2)(6-3)(6-4a)(6-4b)

## I — 方法论骨架 (Interpretation)

低速时轮胎不产生侧偏角，转向是**纯几何**问题——不需要任何轮胎数据，这是全章唯一能"脱手就用"的块。
前提只有一条：后轮无侧偏角 → 转向中心必在后轴延长线上。由此得到三个量：
1. 内轮角比外轮角大：$\delta_o\approx L/(R+t/2)$、$\delta_i\approx L/(R-t/2)$。两轮转角不同，是因为它们绕同一个圆心、半径不同。
2. 阿克曼角（前轮平均角）：$\delta\approx L/R$。它是后面所有高速公式的"基准项"（$57.3L/R$）。
3. 偏离轮迹：$\Delta=R[1-\cos(L/R)]\approx L^2/(2R)$。车头走大圈、车尾切内圈，尾迹比前迹更靠内。
物理含义与工程含义要分开：
- 偏离轮迹只由 $L^2/R$ 决定，与轮距、车宽无关 → 长轴距车（货车、客车）在紧弯最严重，乘用车在停车场几乎可忽略。
- 阿克曼误差（实际内外轮角与理想几何的偏差）影响的是**轮胎磨损与定心力矩**，不显著影响方向响应——它不在 K 的账本里。

## A1 — 应用示例 (Application Example)

### 示例 1：例题 1 第 1 问（原书例题，p186）
- **类型与来源**：原书例题。
- **输入**：$L=100.6$ in $=8.383$ ft；半径 500 / 200 / 100 / 50 ft。
- **执行**：$\delta=L/R$（弧度）→ 换算成度。
- **结果（复算值）**：0.96° / 2.40° / 4.80° / 9.61°（原书 0.96 / 2.4 / 4.8 / 9.6，一致）。
- **补充**：取 $t=4.8$ ft、$R=50$ ft，$\delta_o=9.17°$、$\delta_i=10.09°$，平均 9.63°≈$\delta$，验证"平均角≈阿克曼角"。

### 示例 2：偏离轮迹的复算演练（非书中算例）
- **类型与来源**：**复算演练**。原书只给式(6-4a)(6-4b)、未给算例；数值由本卡按例题 1 的轴距算出，不是作者做过的计算。
- **执行**：$R=50$ ft、$L=8.383$ ft → $\Delta=50[1-\cos(0.1677)]=0.701$ ft（8.41 in）；一次近似 $L^2/(2R)=0.703$ ft。
- **结论**：差 0.3%，近似式可用；$R=100$ ft 时 $\Delta=0.351$ ft。
- **原文瑕疵**：p163 级数印作 $\cos z=1-x/2$（漏平方与阶乘），但 (6-4b) 另以独立公式块给出，可由 (6-4a) 推出，不影响使用。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这套几何？

1. 算某半径下的阿克曼角（设计转向梯形、校核最大转角）。
2. 算内外轮转角差，判断阿克曼误差有多大。
3. 算货车/客车的偏离轮迹（内轮差），评估通过性与站台间隙。
4. 判断"停车场打方向刮胎"是几何问题还是轮胎问题。
5. 给高速公式提供基准项（$57.3L/R$）。

### 语言信号（中英双写）

- 「最小转弯半径对应的转角是多少」「内轮差/偏离轮迹怎么算」「阿克曼角怎么算」
- 「Ackerman angle / off-tracking / turning circle」「why do trailer wheels cut the corner」
- 「大车内轮差多少」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `ackerman-angle`：那张专算内外轮分开的三个角，本卡把几何与偏离轮迹合为一条低速流程。
- 与 `off-tracking`：那张专讲 Δ 与一次近似、铰接车的 tractrix。
- 与 `steer-character-k`：本卡不需要轮胎数据；一旦需要轮胎数据，就进入高速域，改用 K。

## E — 可执行步骤 (Execution)

**必需输入**：轴距 $L$（ft 或 in，与 R 同单位）、转向半径 $R$（ft）、轮距 $t$（ft，仅内外轮分开时需要）。缺 $t$ 时只能给阿克曼角，不能给内外轮角。

**交付物与完成标准**：$\delta_o$、$\delta_i$、$\delta$（deg，2 位小数）与 $\Delta$（ft 或 in，2 位小数）；注明"低速、后轮无侧偏角"前提。

1. **单位统一**
   - 完成标准：$L$ 与 $R$ 同单位；in→ft 除以 12（100.6 in = 8.383 ft）。
2. **算基准角**
   - 完成标准：$\delta=L/R$（rad）×57.3 得 deg；可手算复核。
3. **算内外轮角**
   - 完成标准：$\delta_o=L/(R+t/2)$、$\delta_i=L/(R-t/2)$；检查 $\delta_o<\delta<\delta_i$。
4. **算偏离轮迹**
   - 完成标准：$\Delta=R[1-\cos(L/R)]$，并用 $L^2/(2R)$ 互校（差 <1% 视为通过）。
5. **判读**
   - 完成标准：说明 $\Delta\propto L^2/R$ 的适用结论（长轴距车显著、与轮距无关）；若 $R<3L$，声明小角度近似已偏，改用精确式。

**约定（原书未规定，本卡设定）**：角度一律 deg、长度一律 ft（大车可用 m 但须全表统一）；$\Delta$ 同时给 ft 与 in。

## B — 边界 (Boundary) ★

### 不要在以下情况使用这套几何

- **不要用它解释高速推头/甩尾。** 那属于 K 的账；阿克曼误差"不会对方向响应特性产生重要影响"（p162），两者指标域不相交。
- **不要用 K 判断"阿克曼误差该不该修"。** 该修的判据是磨损与定心力矩，不是 K。
- **不要把偏离轮迹与"内轮差"混为一谈再套到铰接车上。** 铰接式车辆的几何要用等切面曲线（tractrix）方程，原书只说"非常复杂"，**未给公式**。
- **不要在高速/大转角下用**：R≫L 与小转向角是前提；停车场满舵时近似误差上升。
- **不要用平行转向机构还指望力矩单调**：平行转向在超过临界点后回正力矩会减小甚至变负（趋于过多转向），作者明确说"这种类型的特性是不期望的"（p162–163）。

### 作者在书中警告的失败模式

- ce02：平行转向机构 → 低速大转角时回正力矩非单调，方向盘"自己往转角方向转"；这是几何选型的代价，不是故障。
- ce03：用"对方向响应影响不大"论证阿克曼误差不必修（两个方向都错）。

### 作者的盲点 / 时代局限

- 只处理刚性双轴车；铰接车/多轴车的几何被一句"非常复杂"带过，无公式。
- 未讨论轮胎锥度、胎压不均导致的"跑偏"（那是另一个几何-力学混合问题）。
- 1992 年：无四轮转向；四轮转向车的低速几何完全不同（后轮也转角）。

### 容易混淆的邻近方法论

- **阿克曼角（几何）vs 阿克曼梯度（$57.3L/V^2$，斜率）vs 阿克曼误差（实际与理想的差）**：三个不同量，单位与用途都不同。
- **偏离轮迹（$\Delta$）vs 内轮差**：前者是车头与车尾轨迹的横向距离，后者是内外轮轨迹差，别混算。
