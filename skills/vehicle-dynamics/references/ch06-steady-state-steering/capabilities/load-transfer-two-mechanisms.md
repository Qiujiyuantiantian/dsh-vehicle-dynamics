# 轮荷差双机制拆分（瞬时项 / 可调项）

## R — 原文 (Reading)

> **原书要点**（p173）：其一为 $2F_yh_r/t$，源自侧向力直接压在车轴上，作用立竿见影，不受车身侧倾角大小或侧倾力矩如何分配的影响。其二是 $2K_\varphi\varphi/t$，由车身侧倾带动，其大小与前后轴之间的侧倾力矩分配直接挂钩。
>
> — Gillespie《车辆动力学基础》6.4.1（p173），式(6-27)

## I — 方法论骨架 (Interpretation)

同一条轴上的左右轮荷差，来自**两个完全不同的机制**，它们的可调性相反：
$$F_{zo}-F_{zi}=\underbrace{2F_yh_r/t}_{\text{几何/瞬时项}}+\underbrace{2K_\varphi\varphi/t}_{\text{弹性/可调项}}=2\Delta F_z$$
- **几何项 $2F_yh_r/t$**：侧向力作用在侧倾中心（高出地面 $h_r$）处产生的力矩，**瞬时**建立，与车身侧倾角、与前后力矩分配**无关**。它由 $h_r$、$t$、侧向力决定——换稳定杆改不了它。
- **弹性项 $2K_\varphi\varphi/t$**：弹簧/稳定杆通过侧倾角把力矩传到车轴，**有滞后**（要等车身倾起来），且**直接由前后侧倾力矩分配决定**。这是唯一的调校旋钮。
工程结论（本章最容易被忽略的一条）：
1. 想靠"加硬弹簧/加稳定杆"消除载荷转移，不可能——几何项动不了。
2. 只调稳定杆能改的上限，就是弹性项占的比例；低侧倾中心、宽轮距的车，几何项占比更高，调校余地更小。
3. 两项的时间常数不同：几何项瞬时，弹性项滞后。所以"稳态看起来没问题，入弯瞬间有异样"往往来自两者的时序差。

## A1 — 应用示例 (Application Example)

### 示例 1：原书规则（原书未给算例）
- **类型与来源**：原书正文（p173 两条机制 + 式(6-27)），**作者未给数值算例**；p172 的 800→400/1200 lb 例子只说明"载荷转移会让平均侧向力下降"，不是本条算例。

### 示例 2：双机制的数值拆分（合成演练，非书中事实）
- **类型与来源**：**合成演练**。$F_y=1000$ lb、$h_r=20$ in、$t=60$ in、$K_\varphi=92\,000$ in·lb/rad、$\varphi=0.026$ rad 由本卡设定（$K_\varphi$ 沿用例题 2 的后轴值，其余为假设）。
- **执行**：几何项 $2\times1000\times20/60=666.7$ lb；弹性项 $2\times92\,000\times0.026/60=79.7$ lb；合计 $746.4=2\Delta F_z$。
- **结论**：$\Delta F_z=373$ lb（单侧）。几何项占 89%——即使把稳定杆加到无穷硬，也只能改那 79.7 lb 的一部分。
- **推论**：这台车"只调稳定杆"的收益上限约 11%；要真正改变载荷转移，只能动 $h_r$、$t$ 或侧向力本身。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这次拆分？

1. 评估"加稳定杆/换弹簧能减少多少轮荷差"。
2. 解释"为什么调了悬架，轮胎还是偏磨/抓地没改善"。
3. 判断某车的调校余地（几何项占比越高，稳定杆越没用）。
4. 分析瞬态与稳态的差异（几何项瞬时、弹性项滞后）。
5. 与 $K_{lt}$ 的定性结论对齐（前轴恒不足、后轴恒过多）。

### 语言信号（中英双写）

- 「加稳定杆能减少多少载荷转移」「轮荷差怎么拆分」「lateral load transfer instantaneous vs roll」
- 「为什么调了避震还是推头」「load transfer can't be eliminated」
- 「几何项和弹性项各占多少」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `load-transfer-only-distributed`：那张给"不可消除、只能分配"的结论与符号规则；本卡给"两项各是多少"的算术拆分。
- 与 `roll-chain-kphi-phi-dfz`：那张算 $M_\varphi$ 与 $\Delta F_z$ 的整条链；本卡专讲 $\Delta F_z$ 的两个来源。
- 与 `camber-thrust-k`：外倾项是"侧偏角等效替换"，与轮荷差是两条不同的路径。

## E — 可执行步骤 (Execution)

**必需输入**：$F_y$（该轴侧向力，lb）、$h_r$（该轴侧倾中心高度，in）、$t$（轮距，in）、$K_\varphi$（该轴侧倾刚度，in·lb/rad）、$\varphi$（车身侧倾角，rad）。缺 $h_r$ 时先问或从悬架几何求，不得默认 0（默认 0 会把几何项算没，得出"全靠稳定杆"的错误结论）。

**交付物与完成标准**：几何项（lb）、弹性项（lb）、合计（$2\Delta F_z$）、$\Delta F_z$（单侧 lb）＋几何项占比＋可调性结论。

1. **算几何项**
   - 完成标准：$2F_yh_r/t$；注明它"瞬时、与侧倾分配无关"。
2. **算弹性项**
   - 完成标准：$2K_\varphi\varphi/t$；$K_\varphi$ 与 $\varphi$ 必须同口径（rad）。
3. **合成**
   - 完成标准：两者相加 $=2\Delta F_z$；$\Delta F_z$ 为单侧值，不要漏除以 2。
4. **算占比**
   - 完成标准：几何项/合计；据此给出"稳定杆调校收益上限"的定性结论。
5. **交付**
   - 完成标准：写明两项的时序差（瞬时 vs 滞后）与"只能分配不能消除"的结论。

**约定（原书未规定，本卡设定）**：结果保留整数 lb；占比保留整数百分比；$\varphi$ 与 $K_\varphi$ 的 rad 口径必须标出。

## B — 边界 (Boundary) ★

### 不要在以下情况使用这次拆分

- **不要指望用它"消除"载荷转移**：机制对所有车辆、两轴都发生，只能分配（p172）。
- **不要忽略 $h_r$**：把它当 0 会让几何项消失，得出"载荷转移全靠侧倾"的错误模型。
- **不要用它算转向效应的幅值**：本卡输出的是力（lb）；转成 deg/g 需要轮胎载荷灵敏度系数 b，而 b 在原文中**没有任何数值**（$K_{lt}$ 数值层不闭合）。
- **不要在瞬态工况只用稳态式**：弹性项有滞后，入弯首段两项的时间演化不同。
- **不要用于主动悬架/防倾杆解耦系统**：那些系统可以实时改变 $K_\varphi$ 甚至施加反向力矩，本模型不适用。

### 作者在书中警告的失败模式

- ce09：以为载荷转移可消除或可变号（前轴恒不足、后轴恒过多，$\Delta F$ 以平方进入）。
- ce08：只加后轴稳定杆 → 后轴轮荷差↑ → 后轴侧偏角↑ → 过多转向。
- ce21：把例题 2 的 $K_\varphi$/侧倾率当典型值（超出 3–7 deg/g 自报区间）。

### 作者的盲点 / 时代局限

- 式(6-27) 假设左右轮载荷关于静载对称变化、轮距不变、侧倾中心固定；实际悬架在行程中 $h_r$ 会变。
- 作者未讨论轮胎动载与垂向频率耦合（本章把它列为隐含前提之外的内容）。
- 1992 年：无主动防倾杆；现代系统可把弹性项"归零"甚至反向，超出本章模型。

### 容易混淆的邻近方法论

- **$\Delta F_z$（轮荷差，lb）vs $K_{lt}$（不足转向贡献，deg/g）**：中间隔着轮胎载荷灵敏度（b），不能直接换算。
- **侧倾力矩 $M_\varphi$（in·lb）vs 轮荷差 $\Delta F_z$（lb）**：差一个 $t$。
