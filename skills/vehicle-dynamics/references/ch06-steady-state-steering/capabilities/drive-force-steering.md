# 驱动力影响的三项式读法：任何新力源只改动这三处

## R — 原文 (Reading)

> **原书要点**（p181–182）：等式右边共有三项。第一项是把阿克曼角按前轴驱动力修正后的结果，其中不含后轴驱动力；第三项则刻画驱动力怎样改变整车的不足转向特性。
>
> — Gillespie《车辆动力学基础》6.4.6（p181–182），式(6-67)

## I — 方法论骨架 (Interpretation)

把驱动力代进转向方程，得到的仍是一个三项式——结构没变，只是每一项被改写：
- **项 1（阿克曼角）**：被 $1+F_{xf}/C_{\alpha f}$ 改写。只有**前轴**驱动力进这一项；后轴驱动力不出现。前驱加速时分母变大 → 同样半径所需转角变小（"拉着转"）。
- **项 2（原 K）**：$W_f/C_{\alpha f}-W_r/C_{\alpha r}$，**完全不变**。
- **项 3（驱动力修正）**：$-[\,(W_f/C_{\alpha f})(F_{xf}/C_{\alpha f})-(W_r/C_{\alpha r})(F_{xr}/C_{\alpha r})\,]$。前面带负号，所以前轴驱动力使 K 变小（推向过多），后轴驱动力使 K 变大（推向不足）。
- 读法意义：任何新的纵向力源（前驱/后驱/四驱/制动/能量回收）都只可能通过这三处改变转向特性，不必重推方程。
- 方向结论：前驱加速 → 过多；后驱加速 → 不足；四驱 → 后轴力应大于前轴才能保住不足转向。
- **但作者自己说这条几何投影不是全部**：驱动力对轮胎特性的影响（消耗附着、改变 $C_\alpha$）比这个直接力学作用更大，本章没展开。

## A1 — 应用示例 (Application Example)

### 示例 1：原书的方向结论（原书案例，无算例）
- **类型与来源**：原书正文结论（p181–182 的三条 bullet），**原书未给数值算例**。
- **内容**：前驱低速"拉着转"；$F_{xf}>0$ 使项 3 产生过多转向；后驱 $F_{xr}>0$ 产生不足转向；四驱建议后轴驱动力大于前轴。
- **结果**：方向判据完整，无数值。

### 示例 2：三项式的数值演练（合成演练，非书中事实）
- **类型与来源**：**合成演练**。$F_{xf}=300$ lb、$F_{xr}=300$ lb、$C_{\alpha f}=464$、$C_{\alpha r}=390$ lb/deg、$W_f=1901$、$W_r=1552$ lb 由本卡设定（沿用例题 1 的车，但驱动力为假设）。
- **执行（前驱，$F_{xr}=0$）**：项 3 扣减 $4.0970\times(300/464)=4.0970\times0.6466=2.649$；$K_{eff}=0.1175-2.649$。
- **结论**：$K_{eff}\approx-2.53$ deg/g → 加速使该车**从不足转向翻成过多转向**。项 1 同步缩小：$R=800$ ft 时阿克曼角 $0.6006°\to0.6006/(1+0.6466)=0.365°$，即前驱低速所需转角变小。
- **执行（后驱，$F_{xf}=0$）**：$3.9795\times(300/390)=3.061$；$K_{eff}=0.1175+3.061=+3.18$ deg/g → **更不足**。
- **注意**：这两组数只验证代数结构，实车量级会因轮胎特性变化而显著不同（作者自认，见 B 段）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这张卡？

1. 判断前驱/后驱/四驱在出弯加油时车头往哪边走。
2. 电动车前后双电机扭矩分配（相当于四驱分配）对转向特性的影响方向。
3. 解释"为什么大马力前驱车出弯会推头/反而甩尾"（两种机制并存时要说清楚是哪一层）。
4. 把制动/能量回收的纵向力纳入定性分析（符号取负即可）。
5. 与实测不符时，判断问题出在几何投影层还是轮胎特性层。

### 语言信号（中英双写）

- 「前驱/后驱/四驱哪个更推头」「加油门车头往哪偏」「扭矩分配怎么影响转向」
- 「throttle-induced understeer/oversteer」「power oversteer」「torque vectoring effect on handling」
- 「四驱前后扭矩比例该多少」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `understeer-gradient-definition`：那张给无驱动力的基准 K；本卡在它之上加修正项。
- 与 `understeer-tuning`：那张的表格里"四驱前后驱动力分配"一行来自本卡。
- 与 `axle-rule-direction`：本卡是那条通用判据在纵向力上的具体化（前轴驱动力→该轴等效侧偏角变化）。

## E — 可执行步骤 (Execution)

**必需输入**：$F_{xf}$、$F_{xr}$（lb，驱动力为正）、$C_{\alpha f}$、$C_{\alpha r}$（lb/deg，整轴）、$W_f$、$W_r$（lb）、$L$、$R$、$V$（若需算项 1）、基准 $K$。缺 $F_x$ 时先问工况（油门开度/扭矩分配），不得默认取 0 后仍声称"已考虑驱动力"。

**交付物与完成标准**：三项分别写出（含数值）＋$K_{eff}$（deg/g）＋方向结论＋"几何投影层"与"轮胎特性层"的分离说明。

1. **确认 $C_\alpha$ 与 $W$ 口径**
   - 完成标准：$C_\alpha$ 为整轴两轮之和；$F_x$ 为该轴总驱动力。
2. **算项 1（仅前轴驱动力）**
   - 完成标准：$\delta_{Ack}/(1+F_{xf}/C_{\alpha f})$；若 $F_{xf}=0$ 则项 1 不变。
3. **写项 2**
   - 完成标准：明确声明"原 K 不变"，不得把驱动力影响重复计进项 2。
4. **算项 3**
   - 完成标准：$-\left[\dfrac{W_f}{C_{\alpha f}}\dfrac{F_{xf}}{C_{\alpha f}}-\dfrac{W_r}{C_{\alpha r}}\dfrac{F_{xr}}{C_{\alpha r}}\right]$；两个乘积分别写出，符号由括号前的负号决定。
5. **合成与判读**
   - 完成标准：$K_{eff}=K_{项2}+K_{项3}$；给出"前驱→过多 / 后驱→不足 / 四驱后轴力应大于前轴"三条映射的对应结论。
   - 判停条件：若用户要求预测**大油门实车表现**，停在本卡的定性结论，并说明作者自认几何层会系统性漏掉主要机制（见 B 段）。

**计算约定（原书未规定，本卡设定）**：$F_x/C_\alpha$ 无量纲，须远小于 1（原书假设）；若算得 $F_x/C_\alpha>1$，线性化失效，结果不可用。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **不要用本卡的几何投影去预测大油门实车表现。** 作者明确写道：前驱节气门打开产生的过多转向"对于大多数车辆来说并不明显"，驱动力改变轮胎转向特性的影响"要大于该力对车辆的直接作用"——公式不是错，是**只抓了次要机制**。
- **不要在 $F_x/C_\alpha$ 接近或超过 1 时用它**：式(6-66) 的近似只在小量下成立；此时应改用式(6-65) 原始形式，而 (6-65) 在原书印刷时根号套错（$\sqrt{W_f/Rg}$ 应为 $V^2/(Rg)$），引用须标注。
- **不要把前轮滑转（冰面零半径）当"转向更灵敏"。** $C_{\alpha f}\to0$ 时转向增益失控，车被驱动力矩"拖着"转，没有可预测响应、没有回正能力，作者称之为 trick（特技）而非 technique（技术）。
- **不要跨附着条件比较**（干/湿/冰），$C_\alpha$ 与附着率同时变，本卡的三项式不含附着模型。

### 作者在书中警告的失败模式

- **原文冲突（必须随身携带）**：p182 第三项首条 bullet 印作"如果 $F_{xr}$ 为正值，它将产生过多转向的影响"，紧接着第二条又说"对于后轮驱动的车辆，如果 $F_{xr}$ 为正值则产生不足转向"——**二者不能同时成立**。按式(6-67) 的括号结构，产生过多转向的是 **$F_{xf}$**。引用时须原样标注该冲突，不得把 bullet 原文当规则。
- ce11：拿式(6-67) 第三项解释实车大油门过多转向，对不上就怀疑公式。
- ce10：把冰面零半径转向当掉头技巧（转向增益失控，非能力）。
- ce14：用瞬态油门工况的斜率当 K。

### 作者的盲点 / 时代局限

- 1992 年：没有电驱动、没有扭矩矢量（torque vectoring）。四驱"后轴力大于前轴"是笼统建议，现代矢量控制可逐轮分配，本章模型无法描述。
- 轮胎纵向力与侧向力的联合滑移（摩擦椭圆）不在本章；作者把它推到"转向系统"一节，但该节未包含在本章范围内。
- 制动工况可以完全同构处理（$F_x$ 取负），但作者只讨论驱动。

### 容易混淆的邻近方法论

- **驱动力对转向的"直接力学作用"vs"轮胎特性作用"**：本卡只做前者；后者量级更大且本章无公式。
- **横向载荷转移**：那是垂直载荷的移动，与纵向驱动力无关；不要因为"都叫载荷转移"而混用。
