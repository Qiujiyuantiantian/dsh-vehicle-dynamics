# 前后轴对置判据：任何效应只看它把哪个轴的侧偏角做大

## R — 原文 (Reading)

> **原书要点**（p172 §6.4.1）：比较前后轴的侧倾力矩分配：哪个轴分到的更多，车就朝那个方向偏——前轴多则不足转向，后轴多则过多转向。
>
> — Gillespie《车辆动力学基础》6.4.1（p172）

## I — 方法论骨架 (Interpretation)

这是全章的**方向层公共内核**：不必记住六条公式的符号，只需回答两个问题。
1. 这个效应作用在**哪个轴**（前 / 后）？
2. 它使该轴的**等效侧偏角变大还是变小**？
然后套一条映射：**前轴侧偏角变大 → 不足转向；后轴侧偏角变大 → 过多转向**（变小则反之）。
为什么这条映射成立：不足/过多转向的定义本身就是"前轴侧偏角是否大于后轴"（p167 三态判据）。所以任何效应只要能改变某一轴的侧偏角需求，就能被判方向，不需要算出数值。
原书在四个地方用同一个句式做同构应用：侧倾力矩分配（p172）、横向载荷转移（p176）、侧倾转向（p178）、回正力矩（p180）——它们的物理机制完全不同，判据却是同一条。
本卡只出**方向**，不出幅值；幅值必须回到各分项公式。方向判错是本章最贵的错误（调校方向会整个反过来），所以宁可只给方向也要给对。

## A1 — 应用示例 (Application Example)

### 示例 1：原书正文的四处同构应用（原书案例，非例题）
- **类型与来源**：原书正文案例（作者在 6.4 各小节逐条给出判断句），不是编号例题，也没有数值。
- **四个实例**：① 稳定杆装前轴 → 前轴侧倾力矩占比↑ → 前轴轮荷差↑ → 前轴等效侧偏刚度↓ → 前轴侧偏角↑ → **不足转向**（p172 明写）；② 横向载荷转移：前轴项恒为不足、后轴项恒为过多（p176）；③ 侧倾转向：后轴正的侧倾转向是过多转向，前轴正的侧倾转向是不足转向（p178）；④ 回正力矩 $K_{at}$ 恒正 → 永远只增加不足转向（p180）。
- **结果**：四处结论都可回原文定位；作者未给数值。

### 示例 2：新效应判向的合成演练（非书中事实）
- **类型与来源**：**合成演练**。问题由本卡构造，规则取自原书，结论不是书中给出的结果。
- **问题**："把后轴衬套改软，车会往哪边偏？"
- **执行**：作用轴=后轴；软衬套 → 侧向力柔顺转向系数 $A_r$ 变大 → 后轴等效侧偏角变大。
- **结论**：后轴侧偏角变大 → **过多转向**。可用式(6-60) $K_{lfcs}=A_fW_f-A_rW_r$ 复核：$A_r\uparrow\Rightarrow K\downarrow$，与方向结论一致。
- **第二个演练**：前轴外倾梯度从 0 改到 0.8 → 前轴获得外倾推力，等效地"替掉"一部分侧偏角 → 前轴侧偏角需求↓ → 更不足；与式(6-56) 前项符号一致。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个判据？

1. 听到一个改装动作（加稳定杆、换衬套、改导向臂、加大外倾、调四驱分配），只想知道"往哪边变"。
2. 手头没有系数、算不出 deg/g，但仍需要一个可靠的定性结论。
3. 六项分项算完、符号互相矛盾，需要一个独立判据做仲裁。
4. 向非专业读者解释"为什么只加后稳定杆更危险"。
5. 审阅别人的调校方案，检查方向是否反了。

### 语言信号（中英双写）

- 「加装/加硬 XX 会让车更推头还是更甩尾」「这个改动方向对不对」
- 「which axle does it affect」「will this make it understeer or oversteer」
- 「为什么后稳定杆会让车尾更活」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `understeer-gradient-definition` / `steer-character-k`：那两张给**数值**与符号；本卡在缺系数时给**方向**。
- 与 `understeer-tuning`：本卡是判据（一把尺），那张是决策链（选零件、排优先级）。
- 与 `roll-moment-front-bias`：那张专讲侧倾力矩分配这一路；本卡横向覆盖全部六路。

## E — 可执行步骤 (Execution)

**必需输入**：效应的物理描述（作用在哪个轴、改变了什么：刚度／力／角度／力矩）。可选：对应分项公式与系数（用于复算符号）。

**交付物与完成标准**：一句话方向结论（不足／中性／过多）＋作用轴＋机制链（"该轴侧偏角变大/变小"）＋可复算的公式依据（若给得出）。

1. **定作用轴**
   - 完成标准：明确写出"前轴 / 后轴 / 两轴都有"；若两轴都有，分别判、再按净效应说话（不得含糊成"有影响"）。
2. **定该轴等效侧偏角的变化方向**
   - 完成标准：写出中间机制（例如"轮荷差↑ → 该轴等效侧偏刚度↓ → 维持同样侧向力需要更大侧偏角"），不能跳步。
3. **套映射**
   - 完成标准：前轴↑→不足、后轴↑→过多；前轴↓→过多、后轴↓→不足。
4. **用公式复核符号**
   - 完成标准：能找到对应式（6-49/6-56/6-57/6-60/6-61/6-67）时，代数符号须与第 3 步一致；不一致则停并回报冲突。
   - 判停条件：涉及后轴导向臂角度（β）→ 见 B 段第一条，**停止给方向**。
5. **交付**
   - 完成标准：只声明方向与置信度；明确说明"未给幅值"，幅值需回各分项公式并具备系数。

**约定（原书未规定）**：本卡不输出数值；若用户追问"差多少度"，转到对应分项卡并索取系数。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **不要用它给"后轴导向臂支点高低 → 不足/过多"下确定方向。** 原书 **p179 正文**（支点低于轮心 → 获得不足转向）与 **p188 例题**（同一几何、$\varepsilon_r=-0.122$ rad，判为过多转向）**直接相反**，全章三处符号约定至多两处成立。凡涉及该映射，本卡一律标注「**原文自相矛盾（p179 正文 vs p188 例题），需实车/台架标定**」，不给确定方向。
- **不要用它出幅值。** 方向对≠量级对；$K_{lt}$、$K_{rollsteer}$ 的数值层在本章不闭合（系数 b、$\varepsilon$ 定义与算例缺失）。
- **不要用它处理瞬态。** 一切"变大了"的说法都是稳态终值；侧倾转向要等车身侧倾建立才发生，瞬态首秒可能相反。
- **不要用在主动/四轮转向、电控悬架等改变输入的系统中**——那类系统改写的是转向输入本身，不是某一轴的侧偏角需求（原文未涉及）。

### 作者在书中警告的失败模式

- ce19：把柔顺转向判据照搬到另一轴——前后轴结论**正好相反**，判据必须写成"轴＋位置＋方向"三元组。
- ce08：只加后轴稳定杆 → 不期望的过多转向（p174 明确警告）。
- ce09：以为载荷转移可以消除或变号——单轴内部符号不可改，只能改分配。
- ce12：因 $K_{at}$ 恒正且小就把它划掉——间接路径经转向系统，量级更大。

### 作者的盲点 / 时代局限

- 判据只谈"轴"，不谈"左右轮"与轮胎非线性细节；极限工况下两轴耦合，线性叠加前提破。
- 作者把"侧倾转向"的符号规则写在正文，却与自己的例题冲突——说明该判据在 1992 年的表述本身不稳固，本卡只能保留"轴别→方向"这一层。

### 容易混淆的邻近方法论

- **侧偏角 α 定义域**：α 是相对**车轮朝向**的角度，不是相对车身；求 β（相对车身纵轴）时不要混用。
- **横向载荷转移"不可消除"**：那是本判据的一个特例（前恒不足、后恒过多），但"不可消除"是更强的结论，见 `load-transfer-only-distributed`。
