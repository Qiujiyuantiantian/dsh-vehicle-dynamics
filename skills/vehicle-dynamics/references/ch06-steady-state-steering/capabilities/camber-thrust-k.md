# 外倾推力对 K 的贡献：外倾梯度 × 侧倾率

## R — 原文 (Reading)

> **原书要点**（p176–178）：只要做一次悬架运动学计算，就能求出车身侧倾时车轮外倾角如何变化，即梯度 $\partial\gamma/\partial\varphi$；这个量由轮距、悬架几何和侧倾角共同决定，见式(6-51)。每根车轴因外倾而贡献的不足转向量记作 $K_{camber}$，对应式(6-56)。
>
> — Gillespie《车辆动力学基础》6.4.2（p176–178），式(6-50)–(6-56)

## I — 方法论骨架 (Interpretation)

外倾推力不是"另一个 K"，它是**给该轴偷偷加了一个虚假侧偏角**。
- 轮胎的侧向力同时由侧偏角和外倾角产生：$F_y=C_\alpha\alpha+C_\gamma\gamma$。反解就是 $\alpha=F_y/C_\alpha-(C_\gamma/C_\alpha)\gamma$——外倾每多 1°，等效于少要 $(C_\gamma/C_\alpha)$ 度的侧偏角。
- 车在转弯时车身侧倾 $\varphi$，悬架运动学让车轮相对车身再转一个角度，于是**相对地面**的外倾是 $\gamma_g=\gamma_b+\varphi$。这一项存在的全部理由，是防止把车身侧倾算两次（一次在 $\varphi$，一次在 $\gamma_b$）。
- 所以进 K 的路径是三级串联：外倾刚度比（轮胎属性）→ 外倾梯度 $\partial\gamma/\partial\phi$（悬架几何）→ 侧倾率 $\partial\phi/\partial a_y$（整车属性）。
- 量级意识：$C_\gamma$ 远小于 $C_\alpha$（斜交胎 4–6° 外倾 ≈ 1° 侧偏），所以它**之所以能进 K，全靠侧倾率这个放大器**。整体轴 $\partial\gamma/\partial\phi\approx0$，可直接跳过不算。
- 这就是"改外倾调 K"通常无效、而"改侧倾刚度"更有效的算术原因——但改外倾真正的代价（偏磨、直线稳定性）不在这本账里。

## A1 — 应用示例 (Application Example)

### 示例 1：例题 2 第 3 问（原书例题，p187–188）
- **类型与来源**：原书例题（完整数值题）。
- **输入**：外倾刚度与侧偏刚度之比 $C_\gamma/C_\alpha=0.1$（题面"外倾刚度是侧偏刚度的 10%"）；平行等长臂独立前悬架 → 跳动/回弹中车轮不倾斜 → $\partial\gamma_f/\partial\phi=1.0$；整体后轴 → $\partial\gamma_r/\partial\phi=0$；侧倾率 10.5 deg/g（书值）。
- **执行**：$K_{camber}=(0.1\times1.0-0.1\times0)\times10.5$。
- **结论/结果（复算值）**：$K_{camber}=+1.05$ **deg/g**，正 → 不足转向。与书中 1.05 一致。
- **口径提醒**：前轴正、后轴项为零，所以净贡献为正；若两轴都有外倾梯度，减法结构（前减后）会让后轴外倾梯度**减少**不足转向。

### 示例 2：换一组输入（合成演练，非书中事实）
- **类型与来源**：**合成演练**。数值由本卡设定，用于检验"梯度×侧倾率"的乘法结构，不是作者结论。
- **输入**：前 $C_\gamma/C_\alpha=0.15$、$\partial\gamma_f/\partial\phi=0.7$；后 $C_\gamma/C_\alpha=0.05$、$\partial\gamma_r/\partial\phi=0.2$；$R_\varphi=6$ deg/g（落在原书典型 3–7 内）。
- **执行**：$(0.15\times0.7-0.05\times0.2)\times6=(0.105-0.010)\times6$。
- **结论**：$+0.57$ deg/g（不足转向），量级约为例题 2 的一半——差异主要来自侧倾率从 10.5 降到 6。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这张卡？

1. 独立悬架车要估算外倾对不足转向梯度的贡献（deg/g）。
2. 手上有悬架运动学曲线（$\partial\gamma/\partial\phi$）或外倾刚度数据，想知道怎么接进 K。
3. 想知道"这辆车值不值得算外倾项"（整体轴 → 跳过）。
4. 质疑"调大外倾能不能治推头"。
5. 与实测 K 对账时，判断剩下那几个 deg/g 可能来自哪里。

### 语言信号（中英双写）

- 「外倾对不足转向有多大影响」「camber 贡献多少 deg/g」「外倾梯度怎么算进 K」
- 「camber thrust / camber stiffness / camber gain」「should I add camber to fix understeer」
- 「整体轴要不要算外倾」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `camber-magnitude-screen`：那张先判"要不要算"（三条量级分流），本卡执行"怎么算"。
- 与 `camber-angle-composition`：那张只做 $\gamma_g=\gamma_b+\varphi$ 与 $F_y=C_\alpha\alpha+C_\gamma\gamma$ 的合成与反解，不到 K。
- 与 `roll-rate`：本卡把它的输出当输入；侧倾率错，外倾项按比例错。
- 与 `understeer-tuning`：调校决策链里"提高前轴外倾梯度"只是候选之一，且优先级低。

## E — 可执行步骤 (Execution)

**必需输入**：每轴 $C_\gamma/C_\alpha$（无量纲）、每轴 $\partial\gamma/\partial\phi$（deg/deg）、侧倾率 $\partial\phi/\partial a_y$（deg/g）。缺 $C_\gamma$ 时可查轮胎外倾刚度或按量级取值，但**必须标为估算**并给区间。缺悬架几何时不得凭空假设梯度=1——那是"平行等长臂"的特例，不是默认值。

**交付物与完成标准**：$K_{camber}$（deg/g，保留 2 位小数）＋符号结论＋每个输入的来源与不确定性标注。

1. **分流：要不要算**
   - 完成标准：整体轴 / $\partial\gamma/\partial\phi\approx0$ → 判"跳过，贡献 ≤10%"，直接输出 0 并说明理由；独立悬架 → 继续。
2. **取外倾梯度**
   - 完成标准：写明来源（运动学曲线 / 结构判断）；平行等长臂=1.0 必须注明"相对车身不倾、对地外倾完全随侧倾"这一含义。
3. **取侧倾率**
   - 完成标准：rad/deg 已统一为 deg/g；直接引用 `roll-rate` 的输出或用户给值。
4. **代入减法式**
   - 完成标准：$K_{camber}=(C_{\gamma f}/C_{\alpha f}\partial\gamma_f/\partial\phi-C_{\gamma r}/C_{\alpha r}\partial\gamma_r/\partial\phi)R_\varphi$；前项与后项分别写出，禁止合并成一个"总梯度"。
5. **量级自检**
   - 完成标准：结果与典型量级（0.1–1 deg/g 数量级）比对；超过 3 deg/g 先查侧倾率是否用了 rad 值或梯度是否取了角度制的 57.3 倍。

**计算约定（原书未规定，本卡设定）**：梯度用 deg/deg 或 rad/rad 均可，但必须与侧倾率口径一致；结果保留 2 位小数，容差 ±0.05 deg/g。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **不要把外倾当成调 K 的主手段。** 外倾刚度远小于侧偏刚度（斜交胎 4–6° 外倾≈1° 侧偏；子午胎要 10–15°），整体轴"最多仅改变侧偏力的 10% 或更低"。真正被调的是"侧倾率 × 外倾梯度"的乘积，动外倾不如动侧倾刚度有效。
- **不要给整体轴车算这一项**：$\partial\gamma/\partial\phi\approx0$，算了也只是噪声。
- **不要用"大外倾治推头"的方案而不管代价**：轮胎偏磨、直线稳定性、斜交胎的胎压敏感性都不在 K 的账本里。（"偏磨/直线稳定性代价"是反例提取者的推断，原文只给量级与胎压敏感性，引用时须标注。）
- **不要把例题 2 的 1.05 deg/g 当典型值**：其侧倾率 10.5 deg/g 已超出原书自报的 3–7 deg/g。
- **不要在 $\alpha>5°$ 的极限工况用它**：线性外倾推力假设与线性侧偏力假设同时失效。

### 作者在书中警告的失败模式

- ce18：把外倾当调 K 的主要手段（量级部分有原文，代价部分为推断）。
- ce21：引用例题 2 的外倾项（1.05 deg/g）做量级标尺，忽略其侧倾率超出自报典型区间。
- ce17：用低 g 段的 $K_{camber}$ 外推到极限（侧倾率本身随 $a_y$ 非线性）。

### 作者的盲点 / 时代局限

- 1992 年：无主动外倾控制、无电控悬架；现代独立悬架的外倾梯度在跳动行程内是**非线性**的，单一 $\partial\gamma/\partial\phi$ 是线性化近似。
- $C_\gamma$ 的数值依赖具体轮胎型号，作者把它当可查参数，但普通读者拿不到。
- 本章不讨论外倾对纵向力、磨损与直线稳定性的影响（作者把它们推到别的章节/别的书）。

### 容易混淆的邻近方法论

- **外倾角 $\gamma$ vs 外倾梯度 $\partial\gamma/\partial\phi$ vs 外倾刚度 $C_\gamma$**：角度、无量纲导数、lb/deg，三者单位完全不同，混用会让结果差 57.3 倍或更多。
- **两个参考系**：$\gamma_b$（相对车身）与 $\gamma_g$（相对地面）；把 $\gamma_b$ 直接代进 $F_y=C_\alpha\alpha+C_\gamma\gamma$ 会漏掉车身侧倾。
