# 地面外倾角合成与含外倾的侧偏力叠加

## R — 原文 (Reading)

> **原书要点**（p176–177）：转弯时车轮相对地面的总外倾角 γ_g，等于车身侧倾带来的 φ 与车轮原有外倾 γ_b 之和，见式(6-50)。轮胎侧向力并不只由侧偏角 α 决定，外倾角 γ 也贡献一部分，两部分各乘刚度后相加，即式(6-52)。
>
> — Gillespie《车辆动力学基础》6.4.2（p176–177），式(6-50)(6-52)(6-53)

## I — 方法论骨架 (Interpretation)

这一步只做两件事：**把两个外倾角合成一个**，**把外倾折成一个等效侧偏角**。
1. 合成：$\gamma_g=\gamma_b+\varphi$。相对车身的外倾（悬架几何给的）加上车身侧倾角，才是轮胎相对**地面**的外倾。这一项存在的全部理由，是防止把车身侧倾算两次。
2. 叠加：$F_y=C_\alpha\alpha+C_\gamma\gamma$。同样的侧向力，可以由侧偏角产生，也可以由外倾产生。
3. 反解：$\alpha=F_y/C_\alpha-(C_\gamma/C_\alpha)\gamma_g$。外倾每 1°，等效于"少要"$(C_\gamma/C_\alpha)$ 度的侧偏角——这就是"外倾推力替代部分侧偏角"的算术表达。
关键口径：
- 进公式的必须是 $\gamma_g$（相对地面），不是 $\gamma_b$；用错会漏掉车身侧倾那部分。
- $C_\gamma/C_\alpha$ 是轮胎属性（量级：斜交胎 4–6° 外倾≈1° 侧偏，即 0.17–0.25；例题用 0.1）。
- 这一步的输出是"该轴等效侧偏角"，再往上才进 K（见 `camber-thrust-k`）。

## A1 — 应用示例 (Application Example)

### 示例 1：原书规则（原书无独立算例）
- **类型与来源**：原书正文（p176–177 的式(6-50)–(6-53) 与两个参考系说明），**作者未给"合成+反解"的数值算例**；例题 2 只用到最后一步 $K_{camber}$。

### 示例 2：一次合成与反解（合成演练，非书中事实）
- **类型与来源**：**合成演练**。$\gamma_b=0.5°$、$\varphi=1.5°$、$F_y=800$ lb、$C_\alpha=464$ lb/deg、$C_\gamma/C_\alpha=0.1$ 由本卡设定。
- **执行**：$\gamma_g=0.5+1.5=2.0°$；$\alpha=800/464-0.1\times2.0=1.724-0.200$。
- **结论**：$\alpha=1.524°$（等效侧偏角）。
- **口径自检**：若误用 $\gamma_b=0.5°$：$\alpha=1.724-0.05=1.674°$，差 0.15°（约 10%）——把"换算两次"的错误变成可检测的差值。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这一步？

1. 已知车身侧倾角与悬架外倾梯度，求轮胎相对地面的实际外倾。
2. 从实测侧向力反推"等效侧偏角"（考虑外倾贡献）。
3. 校核别人算外倾项时是否漏了 $\varphi$。
4. 解释"为什么同一辆车在不同侧倾角下侧偏角需求不同"。
5. 作为 `camber-thrust-k` 的前置步骤。

### 语言信号（中英双写）

- 「地面外倾角怎么算」「外倾和侧倾角是什么关系」「camber relative to ground」
- 「外倾推力等效多少侧偏角」「camber thrust equivalent slip angle」
- 「两个外倾角要不要相加」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `camber-thrust-k`：那张把本卡的输出接进 $K_{camber}$；本卡只到等效侧偏角。
- 与 `camber-magnitude-screen`：那张判"外倾值不值得算"；本卡是算的过程。
- 与 `roll-rate`：$\varphi$ 来自那张（$\varphi=R_\varphi a_y$）。

## E — 可执行步骤 (Execution)

**必需输入**：$\gamma_b$（相对车身外倾，deg）、$\varphi$（车身侧倾角，deg）、$C_\alpha$（lb/deg，整轴）、$C_\gamma/C_\alpha$（无量纲）、$F_y$（该轴侧向力，lb）。缺 $C_\gamma$ 时可用量级值但须标注估算。

**交付物与完成标准**：$\gamma_g$（deg）、$\alpha$（deg，3 位小数）＋两项各自的贡献值＋口径声明（相对地面）。

1. **合成**
   - 完成标准：$\gamma_g=\gamma_b+\varphi$，两个角同号约定（外倾正=车轮上端外张）。
2. **取刚度比**
   - 完成标准：$C_\gamma/C_\alpha$ 无量纲，注明来源（轮胎数据/量级估算）。
3. **反解**
   - 完成标准：$\alpha=F_y/C_\alpha-(C_\gamma/C_\alpha)\gamma_g$；两项分别写出（如 1.724 与 0.200）。
4. **自检**
   - 完成标准：用 $\gamma_b$ 再算一次，差值应等于 $(C_\gamma/C_\alpha)\varphi$；不等说明漏项或符号错。
5. **交付**
   - 完成标准：声明"外倾的作用等价于给该轴加一个虚假侧偏角"；若 $|\alpha|>5°$，提示已出线性域。

**约定（原书未规定，本卡设定）**：角度保留 3 位小数（deg）；外倾符号统一为"车轮上端外张为正"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用这一步

- **不要把 $\gamma_b$ 直接代进 $F_y$ 公式**：会漏掉车身侧倾；这是本卡要防的头号错误。
- **不要在整体轴车上期待大外倾**：整体轴外倾变化"最多仅改变侧偏力的 10% 或更低"。
- **不要在 $\alpha>5°$ 时用线性叠加**：$C_\alpha$、$C_\gamma$ 都随载荷/角度非线性。
- **不要把外倾当"免费的侧向力"**：外倾推力远小于侧偏力（斜交胎 4–6°≈1°），且代价（偏磨、直线稳定性）不在本式里。
- **不要跨轮胎类型套 $C_\gamma/C_\alpha$**：斜交胎与子午胎差一个量级（子午胎需 10–15° 才等效 1° 侧偏）。

### 作者在书中警告的失败模式

- ce18：把外倾当调 K 的主要手段（量级有原文，代价部分为推断）。
- ce17：用低 g 段的线性外倾关系外推到极限。
- （"漏加 $\varphi$ 导致重复/漏算侧倾"是本卡根据式(6-50) 的存在理由指出的操作层风险，非作者原话。）

### 作者的盲点 / 时代局限

- $C_\gamma$ 对胎压敏感（斜交胎明显、子午胎不明显），作者提了一句但未给数据。
- 1992 年：外倾梯度靠悬架运动学手算；现代 K&C 试验台可直接测。
- 作者未讨论外倾对纵向附着与磨损的影响（推到别的章节）。

### 容易混淆的邻近方法论

- **$\gamma_b$（相对车身）vs $\gamma_g$（相对地面）**：两个参考系，差一个 $\varphi$。
- **外倾角 $\gamma$ vs 外倾梯度 $\partial\gamma/\partial\phi$**：一个是角度，一个是无量纲导数。
