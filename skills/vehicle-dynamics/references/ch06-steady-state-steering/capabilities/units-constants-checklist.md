# 单位与常数口径清单（全章英制，含 r 的双单位）

## R — 原文 (Reading)

> **原书要点**（p166、p185）：p166 的符号表把 $C_{\alpha f}$ 记作前轴两只轮胎合计的侧偏刚度，单位 lb/deg；p185 处则把 $r$ 记作横摆角速度，单位 rad/s。同一个字母 r 在式(6-21) 里以 deg/s 计（$r=57.3V/R$），到式(6-71) 又按 rad/s 使用（$R=V/r$），两式单位并不一致。
>
> — Gillespie《车辆动力学基础》6.3.2（p166）、6.6.2（p185）

## I — 方法论骨架 (Interpretation)

这是全章最高频的失败源：单位/口径错**不会自曝**，数值仍然"像真的"。代入前逐项核对下面这张清单：
| 项 | 正确口径 | 易错点 |
|---|---|---|
| 57.3 | $=180/\pi$，rad↔deg | 与 32.2、0.6818 混用 |
| $L$、$R$ | 必须同单位 | 100.6 in 当 ft → $V_{char}$ 虚高 3.46 倍 |
| $g$ | 32.2 ft/s² | 用 9.81（SI）会全盘错 |
| 车速 | 60 mph = 88 ft/s | 1 ft/s = 0.6818 mph |
| $C_\alpha$ | lb/deg，**每轴两轮之和** | 用单胎值 → K 差 2 倍 |
| $K_\varphi$ | in·lb/rad 与 in·lb/deg 差 57.3 | 直接代 deg → 侧倾率为负 |
| $\varepsilon$ | 弧度制下数值上等于导向臂倾角 $\beta$ | 角度制要换算；**方向不可判**（见 B） |
| $r$ | (6-21) deg/s；(6-71) rad/s | 混用 → 半径差 57.3 倍 |
| $p$ | 长度（in 或 ft） | 与力矩符号混用 |
| 全章 | 英制，**无 SI 换算表** | 唯一的例外：p185 允许 $V$ 用 m/s、$a_y$ 用 m/s² |
三个"即时判错"的自检（本卡提供）：
1. 把 $L=100.6$ 误当 ft 代入 (6-18) → $V_{char}$ 虚高 $\sqrt{12}=3.46$ 倍。
2. 把 $K_\varphi=92\,000$ 当 in·lb/deg 代入 (6-32) → 侧倾率为**负**（荒谬）。
3. 把 (6-71) 的 $r$ 用 deg/s → 半径大 57.3 倍。
只要出现"负的侧倾率""三四百 mph 的特征车速""半径几千英尺"，先回这张表。

## A1 — 应用示例 (Application Example)

### 示例 1：例题 1 的换算过程（原书例题，p186–187）
- **类型与来源**：原书例题中的换算示范。
- **内容**：$L=100.6$ in ×(1 ft/12 in) $=8.38$ ft（作者在 (6-18) 里直接用 8.38 ft）；60 mph = 88 ft/s；$g=32.2$ ft/s²；57.3 deg/rad 显式写在式(6-18)(6-20) 的分母里。
- **结果**：换算本身正确；真正的坑在 $K$ 的取值（0.11 vs 0.1175）与轮胎口径。

### 示例 2：三个错值的自检（合成演练，非书中事实）
- **类型与来源**：**合成演练**。用同一组输入故意犯三种单位错，验证"能否被立刻识别"。
- **① 100.6 当 ft**：$V_{char}$ 从 362.7 变 $\sqrt{12}$ 倍 ≈ 1256 ft/s（856 mph）→ 荒谬，立刻判错。
- **② $K_\varphi$ 用 deg 口径代 (6-32)**：$R_\varphi=-1.12$ rad/g → 负值，立刻判错。
- **③ $r$ 用 deg/s 代 (6-71)**：$R=V/r$ 大 57.3 倍 → 半径异常大，立刻判错。
- **结论**：每个错误都产生一个"物理上不可能"的值，所以自检比核对更有效。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这份清单？

1. 任何一次代入公式前的最后检查。
2. 结果"看起来不对"时（负侧倾率、超高特征车速、异常半径）。
3. 要把英制数据换给用 SI 的同事。
4. 审阅别人的计算表，检查口径列。
5. 从论文/厂家资料抄数据时，确认单位。

### 语言信号（中英双写）

- 「单位怎么换算」「这个公式用英制还是 SI」「为什么我算出负的侧倾率」
- 「ft/s to mph」「in·lb/rad vs in·lb/deg」「rad/s or deg/s」
- 「结果数量级不对」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `understeer-gradient-definition`：那张管"轮数"口径，本卡管"单位"口径。
- 与 `two-wheel-preconditions`：那张管模型适用域；本卡管代入前的单位检查。
- 与 `sae-k-definition`：那张管 hand-wheel/road-wheel 定义域；本卡管单位与常数。

## E — 可执行步骤 (Execution)

**必需输入**：待计算的全部输入量与它们的原始单位；目标输出的单位。

**交付物与完成标准**：一张"量—原始单位—换算后单位—换算系数"的表＋三条自检的通过情况。

1. **列清单**
   - 完成标准：每个输入都写出原始单位与换算后单位。
2. **统一到 ft-lb-deg-s**
   - 完成标准：长度 ft、力 lb、角 deg、时间 s、$g=32.2$；$r$ 若用于 $R=V/r$ 必须是 rad/s。
3. **核对三个"轮数"**
   - 完成标准：$C_\alpha$ 整轴、$W$ 整轴、$K_\varphi$ rad。
4. **跑三条自检**
   - 完成标准：结果不出现负侧倾率、不出现 >1000 ft/s 的特征车速、不出现异常半径。
5. **交付**
   - 完成标准：报告里保留单位表；若用户要 SI，先声明"原书无 SI 形式，以下为换算结果"。

**约定（原书未规定，本卡设定）**：换算系数固定为 57.3（rad↔deg）、32.2（g）、0.6818（ft/s→mph）、12（in→ft）；不得使用其它近似值。

## B — 边界 (Boundary) ★

### 不要在以下情况依赖这份清单

- **不要以为清单能覆盖所有口径问题**：轮数（单胎/整轴）、定义域（hand-wheel/road-wheel）、参考系（相对车身/地面）是另外三类，分别由其它卡负责。
- **不要用它处理 SI 输入而不换算**：原书没有 SI 形式；"把 9.81 代进 g"会全盘错。
- **不要忽略 $\varepsilon$ 的方向问题**：$\varepsilon$ 在弧度制下数值上等于导向臂倾角 $\beta$，但 **p179 正文与 p188 例题对"支点低于轮心"给出相反方向**——凡涉及该方向，一律标注「**原文自相矛盾（p179 正文 vs p188 例题），需实车/台架标定**」，本卡只负责"数值上等于"，不负责"方向"。
- **不要在瞬态计算中套用稳态单位约定**（如 $a_y=V^2/(Rg)$ 只在稳态成立）。

### 作者在书中警告的失败模式

- ce13：不标口径就与厂家数据比较。
- ce14：非稳态套稳态方程。
- （单位错误本身在原书中未被单列警告，但式(6-21)/(6-71) 的双单位是原书自身留下的陷阱。）

### 作者的盲点 / 时代局限

- 全章英制且无 SI 换算表——对非美国读者是额外门槛（作者未做任何说明）。
- 式(6-21) 与 (6-71) 对 $r$ 用了不同单位，作者未在同一处提示；读者只能靠符号表分别核对。
- 1992 年：工程界英制/SI 并存，作者选择了英制。

### 容易混淆的邻近方法论

- **57.3（rad↔deg）vs 0.6818（ft/s→mph）vs 32.2（g）**：三个常数长得都像"魔法数"，混用会导致量级错但不一定荒谬，所以必须逐项核对。
- **"单位统一"vs"口径统一"**：前者是量纲，后者是物理定义（单胎/整轴、车轮/方向盘），两件事都要做。
