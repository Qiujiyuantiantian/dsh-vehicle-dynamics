# 决策规则速查 — 《车辆动力学基础》第 10 章 轮胎

| 能力 | 一句话规则 |
|---|---|
| 符号与量纲前置闸：$W=-F_z>0$、$C_\alpha>0$、外倾角两套正方向、系数是 /deg 不是 /rad | 出手前先过五闸：$W=-F_z>0$ → $C_\alpha$ 取正、$C_\gamma$ 无负号 → 外倾逐轮声明基准 → α/β 分层 → 系数带 /deg（per-rad ×57.3）；任一闸不过就停算。 |
| 附着系数选值：先定"用哪个 $\mu$"（$\mu_p$/$\mu_s$/滑动数），再定路面档 | 先按用途定 $\mu$ 的身份（无 ABS→$\mu_s$、有 ABS→$\mu_p$、驱动→曲线工作点、路面评分→SN），再按干 0.70–0.90 / 湿 0.25–0.50 / 冰 0.10–0.15 取值，并报"轮胎+路面+载荷"三件套。 |
| 纵滑曲线判读：滑动率 $s=(1-r\omega/V)\times100$ 与"斜率共、峰值分" | $s=(1-r\omega/V)\times100$ 定横轴 → 判工作点在峰前/峰值/峰后（干 15%–20%、冰百分之几、湿未给）→ 归因"斜率变=换胎、峰值变=换路"，只有一个 $\mu$ 就不算归因。 |
| $\mu$ 的载荷与气压敏感性：局部斜率（+10% → −0.01）与全域割线（50%→125% 降 >20%）分域使用 | 载荷落在额定 ±20% 内用 $\Delta\mu=-0.01$ 每个 10%；超出则只报"50%→125% 降 >20%、降幅加速"，两段不得衔接、不得插值；气压只给方向（干不敏感/湿显著增大）。 |
| $F_y(\alpha)$ 三区段与建立过程：线性段、峰值段、大角度正弦渐近，外加"半圈到一圈"的滞后 | 先算 $\alpha^*=\mu_pW/C_\alpha$ 定线性段终点 → 判段（线性 $C_\alpha\alpha$ / 峰值 $\mu_pW$ / 大角 $\mu_sW\sin\alpha$）→ 双检连续性与上限 → 瞬态加"半圈–1 圈"滞后（0.05 s = 10 r/s 的半圈）。 |
| 侧偏刚度反算：$C_\alpha=k\times W$，$k$=0.12 / ≈0.15 / 0.25–0.30 $\mathrm{deg^{-1}}$ | 认口径（lb/deg vs 1/deg，差一个 $W$ 约 1000 倍）→ 按胎型取 $k$（斜交 0.12/子午线 0.15/低高宽比 0.25–0.30）→ $C_\alpha=k\times W$ → per-rad ×57.3 → 标"反算，非原始数据"。 |
| 外倾推力估算：$C_\gamma$=(0.10–0.20)$C_\alpha$，子午线再乘 (0.40–0.50) | $C_\gamma=C_\alpha\times(0.10\text{–}0.20)\times f_{type}$（斜交 1.0 / 子午线 0.40–0.50）→ $F_y=C_\gamma\gamma$ → 用"推力指向倾斜方向"复核；0.25 lb/deg/psi 只给斜交、且只给 $C_\gamma$。 |
| 车辙判据：$C_\gamma/W$ 与 $\sin\gamma^\prime$ 比大小，1° 横坡的阈值是 0.0175 = 1/57.3 | 左边只能是 $C_\gamma/W$（不是 $C_\gamma$）→ 右边按实际横坡算 $\sin\gamma'$（1°→0.0175、2°→0.0349）→ 比较给三态（爬出/沿辙/带内不可判）；外倾对 $K$ 的贡献独立悬架至多 25%、整体轴≈0。 |
| 回正力矩三来源：侧偏项（0.033/0.043）、外倾项（约 10%）、路径曲率项（低速主项） | 稳态转弯用 $M_z=k_\alpha W\alpha$（0.033 斜交/0.043 子午线）且 $\alpha<8°$；外倾项 $k_\gamma W\gamma$ 约 10% 可略；原地/低速路径曲率项接管——但数值不可给（图 10.21 无表）。 |
| 复合滑动与摩擦圆：制动/驱动不对称的方向表 + 0.3g 最不利点 + 抱死顺序 | 摩擦圆只作上限包络（$\sqrt{F_x^2+F_y^2}\le\mu W$）→ $F_x$ 分正负（制动压 $M_z$ 可致负、驱动抬 $M_z$）→ 4° 中等制动力 $F_y$ 略增必须保留 → 0.3g 最不利 + 抱死顺序定失控形态；工作点不可算。 |
| 跑偏归因：正反滚动两次测量，半差 = 圆锥度、平均 = 帘布层转向 | 正反两向各测一次 $F_y$ → 半差 = 圆锥度（可变号、可调气压/转位）、平均 = 帘布层转向（不变号、只能补偿转向盘）→ 两个都要 /2；单向数据不得归因。 |
| 台阶冲击：$\Delta F_z\approx h\times k_t$，纵向力是两个负向机制之和 | 只在"高速 + 特征长度≈接触区长度"用 $\Delta F_z=k_t h$，并查 $\Delta F_z/W\le0.5$；纵向力 = 几何爬升 + 有效半径变小两机制叠加（都负、都随车速增强）；$k_t$ 须外部取数。 |
| 轮胎模态与反共振：60 / 90 / 110 Hz 判"传不传"，<20 Hz 是轮轴跳动 | 60 Hz 一阶传力、90/110 Hz（图注值）二阶以上不传、<20 Hz 是轮轴跳动、相邻共振之间的反共振才是传递率与轮迹刚度的峰值；传递率按 p278（1/s²）。 |
| 不足转向的轮胎层判据：比 $C_\alpha/W$ 不比 $C_\alpha$；后轴要相对大 | 两轴都化成 $C_\alpha/W$（$\mathrm{deg^{-1}}$）→ 后 > 前 = 不足、前 > 后 = 过多（绝对值比较必错）→ 载荷转移使该轴有效刚度下降（损失 $\propto d^2$）→ 只给倾向，不给 $K$ 数值。 |
| 结构决定系数：帘布角与带束层定 $C_\alpha$、$C_\gamma$，不归摩擦 | 结构（帘布角/带束/高宽比）→ 动 $C_\alpha$ 与 $C_\gamma$；摩擦副（路面/胶料/载荷）→ 动 $\mu$；所以换低高宽比胎让转向更灵敏（$k$ 0.15→0.25–0.30）但不改 $\mu_p$。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
