## 符号约定（先读这一段，否则下面的 $\mu$、$C_\alpha$、$\gamma$ 会读反）

| 符号 | 书中含义 | 备注 |
|---|---|---|
| $F_z$ | 法向力（沿 $Z'$，**下正 ⇒ 数值为负**） | p255 定义(7)；OCR 退化为"F。" |
| $W$ | 垂直载荷 $=-F_z>0$ | 所有 $\mu W$、$C_\alpha/W$ 用它；p262 原文把 F 两用 |
| $F_x$, $F_y$ | 纵向力（沿 $X'$）、侧向力（沿 $Y'$） | 下标 OCR 几乎全丢 |
| $M_x,M_y,M_z$ | 翻转力矩 / 滚动阻力矩 / 回正力矩（ft·lb） | 与整车同名力矩不同义 |
| $\alpha$ | **轮胎**侧偏角（$X'$ 与运动方向夹角，deg） | ≠ 整车侧滑角 $\beta$ |
| $\gamma$ | 外倾角（deg） | **两套正方向**；$\gamma'$ 是路面横坡 |
| $s$ | 滑动率（%），式(10-1)，分母 $V$ | ≠ 滑动数 SN |
| $\mu_p$, $\mu_s$ | 峰值 / 滑动摩擦系数 | 下标在 OCR 中全失 |
| $C_\alpha$ | 侧偏刚度（**lb/deg**），全书取正 | $=-\partial F_y/\partial\alpha\vert_0$ |
| $C_\alpha/W$ | 侧偏系数（**$1/\mathrm{deg}$**，不是无量纲） | 0.12 / ≈0.15 / 0.25–0.30 |
| $C_\gamma$ | 外倾刚度（lb/deg），**无负号** | $=+\partial F_y/\partial\gamma\vert_0$ |
| $C_\gamma/W$ | 外倾系数（$\mathrm{deg^{-1}}$），判据 0.0175 | 与 $C_\gamma$ 差一个 $W$ |
| 回正力矩系数 | ft·lb/lb/deg：侧偏 0.033/0.043、外倾 0.003/0.001 | 已除以载荷 |
| SN | 滑动数 $=100\mu_s$（ASTM E-274） | 干 81 / 湿 30 / 波特兰 45–50 / Jennite 20–25 |
| $K$ | 不足转向梯度（本章/附录均未给符号） | 附录 A 9.4.7 只给操作定义 |
| $\gamma'$ | **路面**横坡倾斜角（deg） | 式(10-4) 用；≠ 轮胎外倾 $\gamma$ |

## A. 结构与规格

| id | 术语 | 书中定义（摘要·页） | 关键区分 / 易错点 |
|---|---|---|---|
| g01 | 轮胎三大功能 | 支撑垂直载荷并缓冲、提供纵向力、提供侧向力（p252）；"四块不大于人手掌大小的接触区"承担全车控制力 | ≠ 性能指标清单（滚阻/磨耗/噪声/耐久一个都不算"功能"）。三条力学通道与整车承载/纵向/侧向一一对应 |
| g02 | 胎体 / 胎侧 | 帘线固定在胎圈钢丝上、胎圈坐落轮辋；充气压力使胎体受力，任何变形都产生反力（p253）。子午线胎侧"非常富有弹性" | ⚠️ 胎侧的"软"是**弯曲柔度**，不是**侧向刚度**：子午线胎侧最软、$C_\alpha$ 却最大。两个"软硬"方向正交 |
| g03 | 带束层 | 周向硬环带，帘线与周向夹角 ≤20°，转向时"帮助稳定胎面"（p253）；轿车子午线 2 层胎体 + 1–2 层钢丝带束或 2–6 层纤维带束 | ≠ "缓冲层"（旧译名）。**只有子午线与带束斜交有，纯斜交没有**。它是"胎侧极软 + 胎面必硬"的唯一解 |
| g04 | 帘布角 | 子午线名义 90°（对周向）；斜交 35°–40° 逐层交替；带束 ≤20°（p253）。夹角↑→变软→乘适性↑；夹角↓→方向稳定性↑ | **本章唯一的结构自变量**；层数是次要修正。规格里的 "R" 只是子午线代号，不含角度信息 |
| g05 | 高宽比 | 断面高/宽（p254）；常规轿车 0.78–0.70，"更扁平 0.60 或更低"（p264） | ⚠️ 正文"断面高（胎圈座→胎面最外沿）"与附录 A 7.1.6"（外径−轮辋直径）/2"**不等价**；用规格反算只能用后者 |
| g06 | 子午线 / 斜交 / 带束斜交 | 两种基本结构 + 过渡物种带束斜交（已绝迹）；货车"各占一半"（p253） | **1992 年历史样本**：今天乘用车/商用车子午线都接近 100%。图 10.14/10.17 是 1970s 分布 |
| g07 | 额定载荷 / 载荷等级 | 节标题 10.2；只有 T&RA"标准载荷及充气压力"（附录 A 7.1.1） | ⚠️ 全章**没有给"载荷等级"定义**；≠ load index。它是两条载荷规则的隐含分母，缺它就无法把 ±10% 换成绝对值 |

## B. 坐标系与符号

| id | 术语 | 书中定义（摘要·页） | 关键区分 / 易错点 |
|---|---|---|---|
| g08 | SAE 轮胎坐标系 | 原点＝接触中心；$X'$＝轮面与地面交线、前正；$Z'$ 垂直路面、**下正**；$Y'$ 按右手定则（p254–255；附录 A 7.3.1） | 三个反常识：$Z'$ 下正、原点在接触中心（非轮心）、$X'$ 随侧偏角转动。符号错则第 6 章 $K$ 整体反号 |
| g09 | 六分力 | 纵向力 $F_x$、侧向力 $F_y$、法向力 $F_z$、翻转力矩 $M_x$、滚动阻力矩 $M_y$、回正力矩 $M_z$（p255 定义(5)–(10)） | ⚠️ 与整车六分力**同名不同轴**（轮胎 $F_y$＝轮面法向；整车 $F_y$＝车身右向）。轮胎 $M_z$ 只是整车 $M_z$ 的输入 |
| g10 | 法向力 $F_z$ 与垂直载荷 | $F_z$ 数值为负；"垂直载荷为法向反作用力的负值，因此该力为正"（p255；A 7.3.3.13） | = 恒等式 $W=-F_z>0$；所有 $\mu F_z$ 型公式里的量其实是 $W$。⚠️ p262 把 F 同时用作 $F_z$ 与 $W$ |
| g11 | 侧偏角 $\alpha$ | 车轮平面与行驶方向夹角；正 $\alpha$＝向前行驶时轮胎向**右**移动（p255；A 7.3.2.1 用"接触中心运动方向"） | ≠ 整车侧滑角 $\beta$、≠ 前轮转角 $\delta$。小角度 $\delta\approx\alpha+\beta$，但三层不可换。正 $\alpha$ 出负 $F_y$ 是 $C_\alpha$ 负号的唯一来源 |
| g12 | 外倾角 $\gamma$ | p255"上端朝车辆**外侧**为正"；p266"沿行驶方向前看、上端向**右**为正"；A 7.3.2.2 称"倾斜角"（$Z'$ 与轮面夹角） | ⚠️⚠️ **正文内部两套正方向**：右轮一致、左轮相反。用错则 $C_\gamma$ 与外倾 $M_z$ 整体反号 |
| g13 | 侧偏力 / 侧向力 $F_y$ | 沿 $Y'$ 的分量（p255 定义(6)）；随 $\alpha$ 三区段、峰值名义 $\mu_pW$、大角 $\mu_sW\sin\alpha$（p262） | ≠ 车身横向力。三区段边界是范围（5°–10° / 15°–20°）；线性段真正的终点是 $\mu_pW/C_\alpha$ |
| g14 | 侧偏刚度 $C_\alpha$ | $C_\alpha=-(\partial F_y/\partial\alpha)\vert_{\alpha=0}$，lb/deg，全书取正（p263；A 7.4.1） | 负号是**约定**不是物理。本章**不给绝对值**（G1），只能 $k\times W$ 反算；拟合前须扣残差 |
| g15 | 侧偏系数 / 侧偏刚度系数 | $C_\alpha/W$（p263；A 7.5.1 标准用名"侧偏刚度系数"） | ⚠️ **量纲 $1/\mathrm{deg}$，不是无量纲**。斜交 0.12 / 子午线 ≈0.15 / 低高宽比 0.25–0.30；per-rad ×57.3。p263 的"10%"应读 12% |

|---|---|---|---|
| g16 | 滑动率 | $s=(1-r\omega/V)\times100$（p256 式 10-1）；$r$ 是有效滚动半径 | ≠ 附录 A 7.2.8（分母 $r\omega$，抱死趋于无穷）。以 (10-1) 为准；制动 $s>0$、驱动 $s<0$ |
| g17 | $\mu_p$ / $\mu_s$ | 峰值摩擦系数与滑动摩擦系数，"附着力除以负载"（p258） | 干 $\mu_p$ 0.70–0.90（$s_p$ 15%–20%）；$\mu_s$ 只在 $s=100\%$（干路 SN 81 → 0.81）。⚠️ 下标 OCR 全失；$\mu_p$ 还分侧向/驱动/制动三通道（a08） |

| g19 | 滑动数（SN） | $\mu\times100$，抱死拖曳，ASTM E-274 + E-501 标准胎（p259） | 干 81 / 波特兰水泥 45–50 / 湿 30 / Jennite 20–25。≠ 滑动率；只能当 $\mu_s$。是全书唯一可外部对标的路面标尺 |
| g20 | 附着与迟滞（摩擦两机理） | 附着＝橡胶分子与路面团粒的分子结合（干路主导，遇水骤降）；迟滞＝橡胶在凸起上变形的内部损失（几乎不受水影响）（p256） | 推论：湿路是**配方**问题（高迟滞胶），干路极限是**结构**问题；两者不可互相替代 |

## D. 拖距·外倾·车辙

| id | 术语 | 书中定义（摘要·页） | 关键区分 / 易错点 |
|---|---|---|---|
| g21 | 充气轮胎拖距 | 接触区侧向力合力点位于印迹几何中心**之后**的纵向偏移；$M_z=F_y\times$ 拖距（p261） | 拖距是**长度**、$M_z$ 是**力矩**。$M_z=F_y t$ 是**定义式不是模型**：$t$ 随 $\alpha$ 先增后减、可反号。≠ 后倾拖距、≠ 磨胎半径 |
| g22 | 松弛长度 | 转向角变化后需滚过半圈–1 圈才建立稳态侧向力；10 r/s → 0.05 s（p261） | 是**瞬态参数**不是几何尺寸。第二个后果更重要：载荷瞬时减小 ⇒ 整块印迹滑动 ⇒ 侧壁伸直 ⇒ 侧向力清零、"烂路抓地差"。0.05 s 只对应**半圈** |
| g23 | 外倾推力 | 轮胎在与路面非垂直方向滚动时产生的侧向力；"推力始终指向轮胎倾斜的方向"（p266） | **第二条独立通道**：$\alpha\to0$ 时侧偏力趋零而外倾力不趋零。正 $\gamma$ 出 $+F_y$，正 $\alpha$ 出 $-F_y$——两条通道符号相反 |
| g24 | 外倾刚度 $C_\gamma$ / 外倾系数 | $C_\gamma=+(\partial F_y/\partial\gamma)\vert_0$（式 10-3）；为 $C_\alpha$ 的 10%–20%，子午线再 ×40%–50%（p266–267） | ⚠️ **无负号**（与 $C_\alpha$ 不对称）。两个倍率必须连乘，否则高估 2–2.5 倍。0.25 lb/deg/psi 只属**斜交 $C_\gamma$**，不是 $C_\alpha$、不是 $\mu$ |
| g25 | 车辙判据（0.0175） | $F_y/W=\sin\gamma'\approx\gamma'$（式 10-4）；1° 横坡 → $1/57.3=0.0175$；外倾系数 >0.0175 爬辙、<0.0175 沿辙（p267–268） | ⚠️ $\gamma'$ 是**路面倾角**不是轮胎外倾；判据左边必须是 $C_\gamma/W$，拿 $C_\gamma$（30–100）比会恒判"爬出"。0.0175=$\sin1°$=0.017452；原文"0.01751"是"0.0175"+单位 lb 首字母的 OCR 粘连 |

## E. 力矩与复合滑动

| id | 术语 | 书中定义（摘要·页） | 关键区分 / 易错点 |
|---|---|---|---|
| g26 | 回正力矩 $M_z$ | 地面力矩沿垂直地面轴的分量；正 $M_z$ 使轮胎转回直行（p255 定义(10)、p269） | ≠ 整车横摆力矩（作者明说"影响非常小"）。主渠道是转向系柔度 → 转向变形角（几分之一度）。⚠️ 大 $\alpha$ 或制动近极限可为负；附录 A 7.3.4.3 的顺时针约定待核 |
| g27 | 回正力矩系数 | 侧偏项：斜交 0.033、子午线 0.043；外倾项：0.003 / 0.001 ft·lb/lb/deg（p269–270） | 已除以载荷。⚠️ 两个方向相反：子午线**侧偏项更大**、**外倾项更小**。$\alpha<8°$ 增、>8° 减；载荷增加时**超线性**（系数×载荷只在额定附近） |
| g28 | 路径曲率 $M_z$ / 磨胎半径 | 弯道滚动"即使没有侧向力，也会有回正力矩"；原地/极低速时是主体，半径→0 时"需要很大的力矩"（p270–271） | 第三副面孔，$F_y=0$ 时仍存在。**无数据表**（图 10.21，作者自承试验数据很少）⇒ 只判"必须计入"，不给数值。磨胎半径（scrub radius）＝主销偏距，原书用法正确 |
| g29 | 复合滑动 / 摩擦圆 | $\sqrt{F_x^2+F_y^2}\le\mu W$；两向极值相等才是圆，专用胎是椭圆（p272） | 只是**包络**：本章无 $F_y(F_x)$ 解析式（G3）。制动压 $M_z$（可负）、驱动抬 $M_z$（不为负）；4° 中等制动力 $F_y$ **略增**。$\mu$ 随载荷变 ⇒ 是"圆族"不是定圆 |
| g30 | 抱死顺序 | 制动+转向在 $a_y\approx0.3g$ 时纵向能力最低；前轮抱死失转向、后轮抱死"急剧回转（spin out）"（p274） | 抱死的**位置**决定失控**形态**，不是程度。0.3g 是干路轿车经验值，本章**无按 $\mu$ 缩放的规则**（不得自拟 0.12g） |

## F. 残差

| id | 术语 | 书中定义（摘要·页） | 关键区分 / 易错点 |
|---|---|---|---|
| g31 | 圆锥度（conicity） | 零侧偏时 $F_y\ne0$ 的分量，反向滚动时**变号**；源于环带定位不对称等两侧微小差异（p274–275） | 判据是**半差**（差值须 /2）。方向有随机性；可在轮辋上转位、换装位置、调气压改变。⚠️ "变号"的唯一推理句在 p274–275 被排版丢失 |
| g32 | 帘布层转向（ply steer） | 反向滚动**不变号**的分量；源于帘线角不可能完全平衡，由设计固定（p275–276） | 判据是**平均值**。转位不变、气压不是它的因 ⇒ 只能靠转向盘平衡位置补偿。⚠️ 段首条件句缺失 |
| g33 | 侧拉（pull）/ 跑偏（drift） | 圆锥度与帘布层转向的后果：转向系常备一个偏置力矩、驾驶员疲劳（p276） | 不是"轮胎不圆"也不是定位角异常。诊断捷径：换位后跑偏方向变 ⇒ 圆锥度为主；不变 ⇒ 帘布层转向为主 |

### 2.1 最关键的一条：$C_\alpha$ 与侧偏系数

$C_\alpha$ 是 lb/deg（约 50–250），侧偏系数是 $C_\alpha/W$（约 0.10–0.30 $\mathrm{deg^{-1}}$）。三层坑：①当成同一个量 → 差 $W$ 倍；②以为"系数"无量纲 → 差 57.3 倍（deg/rad），与 Pacejka 对不上；③忘了 $C_\alpha/W$ 随载荷下降 → 用绝对 $C_\alpha$ 比前后轴，把不足转向判成过多转向。

### 2.2 第二关键：$\mu_p$ 的"25%–50%"

"湿路摩擦力的最大值通常在垂直载荷的 25%–50% 之间"——这是 $\mu_p$（占载荷比例），**不是**峰值滑动率 $s_p$。湿路 $s_p$ 全章未给。干路 $s_p$ 15%–20%、冰"百分之几"才是峰位。本词典的 g18 已按此修正（原条目把两个量并在一列，属系统性误读）。

### 2.3 第三关键：$C_\gamma$ 没有负号

$C_\alpha=-(\partial F_y/\partial\alpha)$ 有负号（正 $\alpha$ 出 $-F_y$）；$C_\gamma=+(\partial F_y/\partial\gamma)$ 没有（正 $\gamma$ 出 $+F_y$）。照抄 $C_\alpha$ 的负号 ⇒ 外倾推力反向 ⇒ 车辙判据判反。
