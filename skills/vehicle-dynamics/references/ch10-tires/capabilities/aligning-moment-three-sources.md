# 回正力矩三来源：侧偏项（0.033/0.043）、外倾项（约 10%）、路径曲率项（低速主项）

## R — 原文 (Reading)

> **原书要点**（p269）：回正力矩系数指单位载荷所摊到的回正力矩。按书中给的量级，斜交胎约为 0.033、子午线胎约为 0.043，两者单位都是磅·英尺／磅／度。
>
> **原书要点**（p270）：侧偏角不到 8° 时，切向力越大，回正力矩也随之上扬；越过 8° 以后，胎面端部渐渐被滑动区占去，回正力矩转而回落；侧偏角极大时，它甚至会翻成负值。
>
> **原书要点**（p270）：轮胎被逼着沿弯道轨迹滚动时，即便侧向力等于零，仍会冒出回正力矩。
>
> — 10.8.1（p269–270）；10.8.2 路径曲率（p270–271）；图 10.19/10.20/10.21

## I — 方法论骨架 (Interpretation)

一句话：**回正力矩有三副面孔——侧偏产生（有系数、只在 $\alpha<8°$ 线性）、外倾产生（约侧偏项的 10%、两个小系数）、路径曲率产生（没有系数、只在原地/极低速才是主项）；三者的适用工况几乎不重叠，混算必错。**

- **侧偏项**：$M_z=\text{系数}\times W\times\alpha$，系数 0.033（斜交）/0.043（子午线）ft·lb/lb/deg。$W=1000$ lb、$\alpha=4°$ 的子午线 ⇒ **172 ft·lb**。$\alpha>8°$ 后曲线掉头向下，**不能用系数外推**；极大 $\alpha$ 可为负（拖距反号）。
- **外倾项**：约侧偏项的 **10%**（斜交），系数 0.003/0.001。斜交 $W=1000$、$\gamma=2°$ ⇒ **6 ft·lb**；同工况侧偏项（$\alpha=2°$）66 ft·lb ⇒ 比值 **9.1%** ✓。子午线该项极小（2 ft·lb vs 86 ft·lb，**2.3%**）⇒ 常可量级剔除。
- **路径曲率项**：弯道滚动即使 $F_y=0$ 也有 $M_z$。半径 → 0（原地打方向）时"需要很大的力矩"，随载荷**不成比例**增长（超线性）。它是动力转向部件尺寸与疲劳试验的输入——**低速/原地是主项，中高速可略**。
- **两种"随载荷"的方向相反，别记混**：$M_z$ 随载荷**加速**增长（新增接触区都在端部、力臂最大处），而 $C_\alpha/W$ 随载荷**下降**。同一几何原因的两个相反表现。
- **作用渠道**：作为直接作用于整车的力矩，$M_z$ 对不足转向"仅占很小百分比"；真正的通道是 $M_z\to$ 转向系柔度 $\to$ 转向变形角（正常驾驶几分之一度）$\to$ 前轮侧偏角 $\to F_y$。**把 $M_z$ 直接加进整车横摆方程是路径错误**。
- 交付物：$M_z$（ft·lb）+ 用的是哪一项（或哪几项）+ 该项的适用工况 + "拖距是定义不是模型"的声明。

## A1 — 应用示例 (Application Example)

### 示例 1：四个数一组的量级核对（原书引用数据 + 复算）

- **类型与来源**：**原书引用数据**（p269–270 四个系数、8° 分界、10% 比例），本卡复算。
- **输入**：$W=1000$ lb。
- **方法的使用**：①子午线 $\alpha=4°$：$0.043\times1000\times4$；②斜交 $\alpha=2°$：$0.033\times1000\times2$；③斜交 $\gamma=2°$：$0.003\times1000\times2$；④子午线 $\gamma=2°$：$0.001\times1000\times2$。
- **结论/结果（复算值）**：**172 / 66 / 6 / 2** ft·lb。核对：6/66=**9.1%**（原文"约 10%"✓）；2/86=**2.3%**（子午线外倾项可略）。$\alpha=10°$ 时已过 8°，须报"端部被滑动区侵蚀、$M_z$ 开始下降，不能再用线性系数"。

### 示例 2：原地打方向，两项归零、第三项接管（合成演练，非书中事实）

- **类型与来源**：**合成演练**。工况构造依据 p270–271，力矩数值不可算（原文无数值）。
- **输入**：原地/极低速打方向（路径曲率半径 → 0）；$\alpha\approx0$、$\gamma\approx0$。
- **方法的使用**：①侧偏项 $=\text{系数}\times W\times0=0$；②外倾项 $=\text{系数}\times W\times0=0$；③路径曲率项是主体。
- **结论/预期输出**：此时 **$M_z$ 只能由路径曲率项解释**，且"有可能相当大"；必须计入动力转向部件选型与疲劳谱。中高速弯道（半径 >30 ft）该项可略。**数值不可给**：图 10.21 无数据表，原文自承"试验数据很少"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 算回正力矩，问"系数取多少、单位是什么"。
2. 原地/低速打方向很沉，问力矩从哪来。
3. 换子午线胎后转向手感变了（回正更强/更弱）。
4. 讨论柔顺转向、转向系刚度对不足转向的影响。
5. 看到"$M_z$ 很大"与"$M_z$ 影响非常小"两句，判断哪句在什么语境。

### 语言信号（中英双写）

- 「回正力矩怎么算」「aligning moment」「$M_z$ 系数」「0.033 还是 0.043」
- 「原地打方向为什么沉」「parking torque」「路径曲率回正力矩」
- 「外倾产生的回正力矩」「回正能力」「steering feel / on-center」
- 「$M_z$ 对横摆影响大吗」「柔顺转向」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `camber-stiffness-magnitude`：那张卡算外倾**力**；本卡算外倾**力矩**（约侧偏项的 10%）。
- 与 `combined-slip-and-friction-circle`：有纵向力时 $M_z$ 会被压小甚至反号；本卡假设纯侧偏/纯外倾。
- 与 `understeer-balance-by-normalized-stiffness`：本卡给"$M_z$ 只占很小百分比"的边界；$K$ 的主体在前後轴侧偏刚度平衡。
- 与第 8 章转向手感：本卡到"轮胎力矩"为止，转向系传动比与助力特性不在本卡。

## E — 可执行步骤 (Execution)

**必需输入**：$W$（lb）、$\alpha$（deg）或 $\gamma$（deg）、胎型（斜交/子午线）、工况（稳态转弯 / 原地低速 / 中高速弯道）。可选：载荷是否在额定附近、是否有纵向力。**缺工况不得选源项**。

**交付物与完成标准**：$M_z$（ft·lb）+ 源项清单 + 每项的适用性与判停 + 作用渠道说明。

1. **选源项**
   - 完成标准：稳态转弯 → 侧偏项（+外倾项若 $\gamma\ne0$）；原地/极低速 → 路径曲率项为主；中高速 → 路径曲率可略。
2. **侧偏项（判停点）**
   - 完成标准：$M_z=k_\alpha W\alpha$，$k_\alpha=0.033$（斜交）/0.043（子午线）。**判停**：$\alpha\ge8°$ → 停用系数，只报"已过峰值、曲线下降、可能转负"。
3. **外倾项**
   - 完成标准：$M_z=k_\gamma W\gamma$，$k_\gamma=0.003$（斜交）/0.001（子午线）；并给与侧偏项的比值（应 ≈10% 或更小）。**判停**：比值 >20% → 检查是否把 $C_\gamma$ 当成了 $k_\gamma$。
4. **路径曲率项**
   - 完成标准：只判"是否必须计入"与方向（半径↓→力矩↑、载荷↑→超线性↑），**不给数值**；若必须计入，声明"图 10.21 无数据表，需实测/厂商数据"。
5. **载荷与渠道**
   - 完成标准：写明"$M_z$ 随载荷超线性，系数×载荷只在额定 ±20% 内"；写明作用渠道是"转向系柔度 → 变形角（几分之一度）"，不是"整车横摆力矩"。
6. **交付**
   - 完成标准：一句话"$W=1000$、$\alpha=4°$、子午线 ⇒ $M_z\approx172$ ft·lb（侧偏项），外倾项可略；该力矩经转向系柔度影响手感，对整车横摆贡献很小"。

**计算约定（本卡设定）**：$M_z$ 保留 3 位有效数字；系数用原文 3 位小数；比值保留 1 位小数；$\alpha\ge8°$ 一律不报价。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **把 $M_z$ 当整车横摆力矩。** 量级小两个数量级，且物理路径错；正确路径是"转向系柔度 → 转向变形角 → $F_y$"（ce27）。
- **因为"影响非常小"就把 $M_z$ 整项删掉。** 会漏掉柔顺转向这一整个通道与回正能力（ce27）。
- **把"正 $M_z$ 一律稳定"当无条件结论。** 只在 $\alpha<8°$、无纵向力、转向系刚度足够时成立；$\alpha$ 很大或制动近极限时 $M_z$ 可为负，反成"推着轮胎继续偏"的发散项（ce28）。
- **只算两项就做转向部件选型。** 原地/低速时路径曲率项才是主项（ce29）。
- **按 $M_z\propto W$ 线性缩放。** 载荷加倍时 $M_z$ 增长**快于**线性（新增区域都在端部）（ce30）。
- **用固定拖距算 $M_z$。** $M_z=F_y\times t$ 是**定义**，$t$ 随 $\alpha$ 先增后减、可反号；固定 $t$ 等于删掉峰值后的塌陷（ce31）。
- **在有纵向力时用本卡系数。** 制动会压小 $M_z$ 甚至使其为负，驱动会显著增大；不对称，必须转 `combined-slip-and-friction-circle`。

### 作者在书中警告的失败模式

- **ce27**：$M_z$ 当第八个外力矩；或整项丢弃。
- **ce28**：大侧偏/弯道制动下仍说"正 $M_z$ 所以稳定"。
- **ce29**：只算侧偏+外倾，原地转向力矩算成接近零。
- **ce30**：用 0.043×载荷 算重载胎。
- **ce31**：拖距当几何常数（"印迹长度的一半"）。
- **ce32**（相关）：从制动 $M_z$ 数据外推驱动工况。

### 作者的盲点 / 时代局限 / 原文硬伤（不得当正确结论）

- **p269 的"总是"与 p270/p273 的反例是原文内部张力**：引用"正 $M_z$ 稳定"必须同时引 p270 的负值条件。
- **图 10.19/10.20 无数据表**；四个系数无样本量、无胎规格、无测试条件。
- **拖距、后倾拖距、磨胎半径（scrub radius）三个"拖距"在中文里都叫拖距**，量级与符号各不相同；本章只给定义，不给数值。
- **p270 把"磨胎半径（the scrub radius——偏距）"与小半径轨迹并置**：这是原书正确用法（scrub radius 即主销偏距），**不是**"把滚动半径混进来"，早期提取器的这条批评已被更正（coverage-audit §3-⑭）。
- **本段末句 OCR 断义**（外倾项段），不可作规则引用。
- **$M_z$ 对整车横摆的直接贡献"非常小"** 未限定转向系刚度，是作者的简化。

### 容易混淆的邻近方法论

- **回正力矩（轮胎 $M_z$）vs 整车横摆力矩**：前者是后者的一个输入，且很小。
- **气胎拖距 vs 后倾拖距 vs 磨胎半径**：印迹后移 / 主销后倾 / 主销横偏。
- **"回正能力"（手感）vs "不足转向"（稳定性）**：$M_z$ 对前者贡献等于或大于主销后倾角，对后者只占很小百分比。
- **侧偏项系数（0.033/0.043）vs 外倾项系数（0.003/0.001）**：差一个数量级，且方向规律不同。
