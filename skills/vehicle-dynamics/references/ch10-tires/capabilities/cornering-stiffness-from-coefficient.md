# 侧偏刚度反算：$C_\alpha=k\times W$，$k$=0.12 / ≈0.15 / 0.25–0.30 $\mathrm{deg^{-1}}$

## R — 原文 (Reading)

> **原书要点**（p263）：侧偏系数是把侧偏刚度除以垂直载荷之后得到的归一化量。斜交胎该值仅约 0.12，折算下来，侧偏角 1° 时它发出的侧向力大致只相当于垂直载荷的一成。
>
> **原书要点**（p263–264）：高宽比相近的子午线胎则不同，侧偏系数普遍更高，1° 时约能给出载荷一成半（15%）上下的侧向力；再好一些的型号可达 0.25～0.30，甚至更大。
>
> — 10.6.2 轮胎类型（p263–264）；式(10-2)（p263）

## I — 方法论骨架 (Interpretation)

一句话：**本章不给你 $C_\alpha$（lb/deg），只给你一张"每度侧向力占载荷多大比例"的表（1/deg）；要落到 lb/deg，就乘一次载荷——并且必须声明这是反算值，不是原始数据。**

- **两个量差一个 $W$**：$C_\alpha$（lb/deg，典型 50–250）与侧偏系数 $C_\alpha/W$（$\mathrm{deg^{-1}}$，典型 0.10–0.30）。$W\approx1000$ lb 时差约 1000 倍——这是本章最贵的单位坑。
- **量纲不是无量纲**：$\mathrm{(lb/deg)/lb=1/deg}$。正因为带 $1/\mathrm{deg}$，"$0.12\times1°=12\%$ 载荷"才成立；若真无量纲，这个换算就没有依据。转 per-rad 一律 ×57.3。
- **三档系数是结构分档，不是性能排序**：斜交 0.12、子午线（同高宽比）≈0.15、低高宽比高性能胎 0.25–0.30。差异来自帘布角/带束层，不来自胶料或路面。
- **p263 的"10%"要改读 12%**：0.12 应读 12%，原文做了向下取整。可复算场合一律用 $k\times100\%$；叙述场合才可用"约 10%"，两者不进同一条计算链。
- **$k$ 随载荷下降，$C_\alpha$ 绝对值随载荷上升**：$C_\alpha(F_z)$ 凹面向下 = 增速递减。所以"乘一次载荷"只在**额定载荷附近**近似成立；重载时 $k\times W$ 是上界（V-19/nf04）。
- **拟合前必须扣残差**：附录 A 7.3.3.10 的"侧偏角力"才是扣掉帘布层转向力与圆锥力之后的纯侧偏分量；不扣，$C_\alpha$ 与零点偏移互相吃误差。
- 交付物：一个 lb/deg 的数 + 它对应的 $k$（带 $\mathrm{deg^{-1}}$）+ "反算"标记 + 三项适用域（载荷窗口、角度窗口、胎型样本）。

## A1 — 应用示例 (Application Example)

### 示例 1：同一载荷下的三种胎（原书引用数据 + 复算）

- **类型与来源**：**原书引用数据**（p263–264 三档侧偏系数），$C_\alpha$ 由本卡复算。
- **输入**：$W=1200$ lb（额定附近）；$k=0.12$（斜交）、$0.15$（子午线）、$0.25$–$0.30$（低高宽比）。
- **方法的使用**：$C_\alpha=k\times W$；同时给出 $\alpha=1°$ 时的 $F_y$。
- **结论/结果（复算值）**：$C_\alpha=\mathbf{144}$ / $\mathbf{180}$ / $\mathbf{300}$–$\mathbf{360}$ lb/deg；对应 $1°$ 的 $F_y=$ 载荷的 **12% / 15% / 25%–30%**。per-rad：$k\times57.3=\mathbf{6.88}$ / $\mathbf{8.60}$ / $\mathbf{14.33}$–$\mathbf{17.19}\ \mathrm{rad^{-1}}$；$C_\alpha\times57.3=\mathbf{8251}$ / $\mathbf{10314}$ / $\mathbf{17190}$–$\mathbf{20628}$ lb/rad。自检：144–360 lb/deg 落在图 10.15 纵轴 0–200 lb/deg 的量级内（轴到 200 ≠ 曲线到 200）。

### 示例 2：漏乘载荷，错三个数量级（合成演练，非书中事实）

- **类型与来源**：**合成演练**，专门演示 ce15 的失败模式。
- **输入**：有人报"该胎侧偏刚度 0.15"，$W=1200$ lb。
- **方法的使用**：①若 0.15 是侧偏系数 → $C_\alpha=0.15\times1200=180$ lb/deg，$1°$ 出 180 lb；②若 0.15 真是 $C_\alpha$ → $1°$ 只出 0.15 lb，侧向加速度几乎为零。
- **结论/预期输出**：**0.15 lb/deg 不可能是 $C_\alpha$**（量级差 $10^3$）。判据：$C_\alpha/W$ 不在 0.10–0.30 → 单位错；$C_\alpha$ 不在 50–250 lb/deg → 数量级错。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 要第 6 章 $K$ 的输入，问"这胎的侧偏刚度是多少 lb/deg"。
2. 手上只有"侧偏系数 0.15"，要换成绝对刚度。
3. 换低高宽比胎，问"转向会不会更灵敏、能灵敏多少"。
4. 跨文献对比：一篇用 1/deg、一篇用 lb/deg、一篇用 N/deg。
5. 拟合实测 $F_y$–$\alpha$ 斜率，问"要不要先扣掉零侧偏处的偏置力"。

### 语言信号（中英双写）

- 「侧偏刚度多少」「cornering stiffness lb/deg」「侧偏系数 0.15 是多少」
- 「换宽胎转向更灵敏吗」「低高宽比 $C_\alpha$」
- 「1/deg 还是 lb/deg」「$C_\alpha$ 无量纲吗」「per rad 怎么换」
- 「拟合侧偏刚度要不要扣残差」「ply steer 影响 $C_\alpha$ 吗」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `tire-sign-and-unit-gate`：符号与 /deg 口径的前置校验在那张卡；本卡只算数值。
- 与 `lateral-force-three-regimes`：本卡给原点斜率；那张卡用它判"在哪个区段"，并给出线性段终点 $\mu_pW/C_\alpha$。
- 与 `understeer-balance-by-normalized-stiffness`：本卡给单胎/单轴 $C_\alpha$；"前后轴谁大"的判据必须用正则化后的系数，在那张卡。
- 与 `tire-structure-coefficient-map`：结构因果与方向表在那张卡；本卡只做"系数 → 刚度"一步。

## E — 可执行步骤 (Execution)

**必需输入**：$k$（侧偏系数，$\mathrm{deg^{-1}}$）或 $C_\alpha$（lb/deg）之一、$W$（lb）、胎型（斜交/子午线/低高宽比）。可选：高宽比、气压、是否实测拟合值。**缺 $W$ 不得反算**；**缺胎型不得选 $k$ 档**。

**交付物与完成标准**：$C_\alpha$（lb/deg）+ $k$（$\mathrm{deg^{-1}}$，并给 $\mathrm{rad^{-1}}$）+ "反算"标记 + 三项适用域。

1. **认口径**
   - 完成标准：判断输入是 $k$ 还是 $C_\alpha$；$k\in[0.10,0.30]$、$C_\alpha\in[50,250]$ lb/deg 之外 → 先怀疑单位（ce15）。**判停**：用户称"本章给了 $C_\alpha$ 绝对值" → 停，声明 G1（`needs_review`）。
2. **取 $k$ 档**
   - 完成标准：斜交 0.12；子午线（同高宽比）≈0.15；低高宽比 0.25–0.30；并注明这是 1992 年样本，现代 UHP 胎已突破 0.30（ce43）。
3. **反算**
   - 完成标准：$C_\alpha=k\times W$，中间量写明 lb；$1°$ 自检 $F_y/W=k\times100\%$（0.12→**12%**，不写 10%）。
4. **换算与标注**
   - 完成标准：per-rad 值 = 上面 ×57.3；表里同时给 lb/deg 与 $\mathrm{deg^{-1}}$，永不裸写"侧偏刚度 0.15"。
5. **声明适用域（三条）**
   - 完成标准：①载荷窗口——仅额定附近，重载时 $k\times W$ 是上界；②角度窗口——仅 $\alpha\to0$ 线性区；③样本——斜交为主、子午线定量薄。
6. **交付**
   - 完成标准：一句话"$W=1200$ lb、$k=0.15\ \mathrm{deg^{-1}}$ ⇒ $C_\alpha=180$ lb/deg（**反算值，非原始数据**）；$1°$ 出 15% 载荷"，并附 per-rad 值。

**计算约定（本卡设定）**：$C_\alpha$ 保留 3 位有效数字；$k$ 保留 2 位；per-rad 乘 57.3；反算值必须带"≈"或"反算"字样。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **把"系数"当无量纲。** $C_\alpha/W$ 的量纲是 $1/\mathrm{deg}$；把它当无量纲，就失去了"×1°=载荷百分比"的依据，也无法与 Pacejka 对齐（nf12）。
- **把反算值当原始数据。** 本章**没有** $C_\alpha$ 绝对值的原始数据（G1，`needs_review`）；图 10.15 只有曲线、无数据表，"轴到 200 lb/deg"不等于"典型值是 200"。
- **用绝对 $C_\alpha$ 比较前后轴。** 前后静态载荷差很多（典型 60/40），绝对值天然前大后小；必须用 $C_\alpha/W$（ce14）。
- **用 p263 的"10%"做算术。** 0.12 应读 12%；10% 只是叙述取整（nf02）。
- **把 $k$ 当与载荷无关的常数。** $k$ 随载荷下降、$C_\alpha$ 绝对值上升；重载时线性反算会高估（nf04）。
- **用 1992 年的 0.25–0.30 当现代上界。** 30/25 系列量产之后该上界已被突破；用老分布校核现代 UHP/EV 胎会系统性低估（ce43）。
- **直接拿未扣残差的实测斜率拟合。** 零侧偏处的 $F_y\ne0$（圆锥度 + 帘布层转向），不扣会把零点偏移吃进 $C_\alpha$，系统偏差可达 5%–10%（a02）。
- **在复合滑动下用本卡的 $C_\alpha$。** 有纵向力时有效侧偏刚度会变（4° 附近甚至上升），本章无解析式（转 `combined-slip-and-friction-circle`）。

### 作者在书中警告的失败模式

- **ce01**：$C_\alpha$ 写成负值（符号卡）；**ce15**：刚度与系数混用、当成无量纲（本卡首要误读）。
- **ce14**：用绝对 $C_\alpha$ 比前后轴，几乎所有车都被判成过多转向。
- **ce43**：把 1992 年分布当现代上界。
- **ce13**：$C_\alpha$ 当常数，忽略凹面向下。
- **nf02 / nf12**：0.12 与 10% 的取整差；"侧偏系数无量纲"这一说法的纠正。

### 作者的盲点 / 时代局限 / 原文硬伤（不得当正确结论）

- **$C_\alpha$ 绝对值全章未给**（G1）：只能反算或读图，反算值≠原始数据。这是本章对下游第 6 章最大的欠账。
- **"0.12 约 10% 载荷"与 12% 不自洽**（p263）：四舍五入级，但复算口径必须统一为 $k\times100\%$。
- **数据以斜交胎为主**：子午线常只有"更大/更小"一句话；图 10.13/10.16 明确标"斜交轮胎"。
- **侧偏系数上限随年代移动**：0.25–0.30 是 1992 年的激进值。
- **$k$ 的气压系数缺**：p265 只给方向（"单调且相当密切"）；0.25 lb/deg/psi 是外倾刚度的，不得挪用（f09/ce21 的错版即此）。

### 容易混淆的邻近方法论

- **$C_\alpha$（lb/deg）vs $C_\alpha/W$（$\mathrm{deg^{-1}}$）vs 图 10.15 纵轴（lb/deg）**：三个不同的"刚度"。
- **"附录 A 侧偏刚度系数"vs 正文"侧偏系数"**：同义异名（附录 A 7.5.1 注明确弃用旧称），真正的问题是单位不是名字（nf11）。
- **反算 $k\times W$ vs 实测拟合斜率**：前者是量级估计，后者才是数据；两者不可互相"校准"。
