# 轮胎模态与反共振：60 / 90 / 110 Hz 判"传不传"，<20 Hz 是轮轴跳动

## R — 原文 (Reading)

> **原书要点**（p277–278）：二阶模态下胎面按椭圆形状变形，却始终对竖直轴与水平轴都保持对称；顶部与底部反相运动，净垂直力互相抵消，车轮感受不到合力，输入的能量被轮胎大量吸收，传不到轮轴上。
>
> **原书要点**（p278）：这些峰值所在的频率恰好落在反共振模态、也就是反共振点上，同时也与传递率、轮胎轮迹刚度的极大值位置相重合。
>
> — 10.12 轮胎振动（p277–278）；图 10.28/10.29/10.30

## I — 方法论骨架 (Interpretation)

一句话：**共振频率表 ≠ 传力频率表。一阶（60 Hz）胎面整体平动、净力直传轮轴；二阶以上（90/110 Hz）上下反相、净力为零、能量就地吸收；真正把力传上去的是**反共振点**（共振之间），那里传递率与轮迹刚度同时取峰值。**

- **三个频率的读法**：一阶 **60 Hz**（胎面整体在垂直平面内上下平动）在正文；二阶 **90 Hz**、三阶 **110 Hz** **只出现在图 10.28 图注**——引用时必须标"图注值"，不能当正文数据。
- **"传不传"的判据**：一阶有净垂直力 ⇒ 传；二阶是椭圆呼吸、顶底反相 ⇒ 净垂直力与净纵向力都为零 ⇒ 不传；三阶以上同理。所以"90 Hz 抖动"不能归因于二阶共振，它更可能是反共振。
- **反共振才是最坏传递点**：反共振处胎面变形不对称、接触区偏移小，合力直接作用到车轮；传递率与轮迹刚度都在此处取峰。设计隔振时只盯 60/90/110 三峰，会漏掉真正的传力峰。
- **低频另一件事**：**<20 Hz** 是轮轴跳动（axle hop），该频段非悬挂质量的"弹簧"主要来自轮胎。它既不是轮胎模态，也不是反共振。
- **子午线 vs 斜交的差异**：50–100 Hz 垂直力子午线明显更大；纵向响应除 **15–20 Hz** 窄带外子午线都更敏感；**10 Hz 附近子午线纵向传递率更高**——这正是子午线胎初入美国市场要做"乘适性调节"、并在悬架上补纵向柔度的原因。
- **量纲警告**：p278 的传递率是"轮轴加速度 / 路面位移"，量纲 **1/s²**，不是无量纲比值；附录 A 2.8 的"力/力"是另一个定义，不可互换。
- 交付物：频率归属（模态/反共振/轮轴跳动）+ "传不传"结论 + 传递率口径声明。

## A1 — 应用示例 (Application Example)

### 示例 1：三个频率各归哪一类（原书引用数据 + 图注值）

- **类型与来源**：一阶 60 Hz 为**原书引用数据**（p277 正文）；90 / 110 Hz 为**图注值**（图 10.28 图注，正文未给）。
- **输入**：激励频率 60 Hz、90 Hz、110 Hz、25 Hz。
- **方法的使用**：①60 Hz → 一阶，胎面整体平动 → **传力**；②90 Hz → 二阶椭圆呼吸 → **不传**；③110 Hz → 三阶 → **不传**；④25 Hz → 高于轮轴跳动（<20 Hz）、低于一阶，落在**反共振区** → 传递率与轮迹刚度取峰值。
- **结论/结果（复算/判读值）**：**60 Hz 传**；**90、110 Hz 不传**；**25 Hz 是最坏传递点**（不是"无共振所以没事"）。这一条是本章最容易被反过来用的判据（ce41）。

### 示例 2：换子午线胎，10 Hz 附近变闷（合成演练，非书中事实）

- **类型与来源**：**合成演练**。依据 p278 的三条定性结论，柔度改动量不可算。
- **输入**：原装斜交胎的车改子午线胎；悬架不动。
- **方法的使用**：①50–100 Hz 垂直力上升；②10 Hz 附近纵向传递率上升；③15–20 Hz 是例外窄带（子午线不一定更敏感）。
- **结论/预期输出**：判"车体纵向振动增大"，处置是**在悬架补纵向柔度**（原文只给方向，无柔度值）。若判"加质量/加阻尼治 90 Hz"，方向就错了——90 Hz 本来就不传（ce41）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 某个频率的抖动，问"是不是轮胎共振、会不会传到方向盘/座椅"。
2. 换胎后 NVH 变化，问原因与对策。
3. 轮轴跳动（<20 Hz）与轮胎模态（60 Hz+）分不清。
4. 看到"60/90/110 Hz"三个数，问它们各自对应什么振型。
5. 问"传递率峰值在哪"、"轮迹刚度是什么"。

## E — 可执行步骤 (Execution)

**必需输入**：激励频率（Hz）或其来源（路面波长 × 车速）、轮胎类型（子午线/斜交）、关心的方向（垂直/纵向）。可选：实测传递率曲线。**缺频率不得判"传不传"**。

**交付物与完成标准**：频率归属 + 传/不传结论 + 传递率口径 + （换胎时）柔度建议。

1. **算激励频率**
   - 完成标准：$f=V/\lambda$（$V$ 与 $\lambda$ 同单位），或直接用实测频谱峰；写出换算。
2. **归类**
   - 完成标准：$f<20$ Hz → 轮轴跳动；$f\approx60$ Hz → 一阶（传）；$f\approx90$ → 二阶（不传，**图注值**）；$f\approx110$ → 三阶（不传，**图注值**）；落在相邻两共振之间 → 反共振（**最坏传递点**）。
3. **判传力**
   - 完成标准：只有一阶（及可能的反共振）传净力；二阶以上"对车轮无总垂直力作用"。**判停**：把 90 Hz 当归因对象 → 停，改查反共振（ce41）。
4. **声明口径**
   - 完成标准：传递率写"轮轴加速度 / 路面位移（1/s²）"；若引附录 A 2.8 的"力/力"，必须另标来源、不可混用。
5. **（换胎时）给方向**
   - 完成标准：写"50–100 Hz 垂直力子午线更大；10 Hz 附近纵向传递率更高 ⇒ 补纵向柔度"，**不给柔度值**。
6. **交付**
   - 完成标准：一句话"$f=x$ Hz 属一阶/二阶/反共振/轮轴跳动，传/不传；传递率口径为 p278"，并声明样本是轿车轮胎、垂直平面。

**计算约定（本卡设定）**：频率保留整数 Hz；90/110 Hz 必须标"图注值"；反共振频率**不给数值**（原文未给）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **把共振频率表当传力频率表。** 两者相位错开：二阶以上不传，反共振才传（ce41）。
- **用 90 Hz 解释轮轴抖动。** 二阶净力为零；该频率附近的传递峰属反共振。
- **把反共振频率说成一个具体数。** 原文只给"共振之间的波峰"这一定性位置，**未给数值**，不得自拟。
- **把 p278 的传递率与附录 A 2.8 互换。** 一个是 1/s²，一个是无量纲；混用会让频谱幅值错量纲（硬伤 #19 相关）。
- **把 <20 Hz 的轮轴跳动当轮胎模态。** 它是非悬挂质量在轮胎刚度上的跳动，不是胎体模态。
- **把货车/低扁平胎直接套轿车数据。** 原文只标"轿车轮胎"，无规格、载荷、气压条件。
- **讨论"驻波"。** **本章全文一次都没出现"驻波"**（检索 0 次）；不得用本章数据讨论驻波临界车速，也不得在本 Bundle 内给出它的定义——那条知识来自本章之外，挂在本章名下即为编造。

### 作者在书中警告的失败模式

- **ce41**：把二阶/高阶模态共振当"传到轮轴的振动"去治（加阻尼/加质量）；只盯 60–110 Hz 三个共振峰，漏掉反共振峰。
- **ce20**（相关）：把斜交胎的花纹规律外推到子午线；本卡的子午线差异只有三条频段结论，不能外推成"子午线全面更差"。
- **ce19**（相关）：把"侧偏刚度对车速不敏感"外推到瞬态；本卡正是那条边界的下游。

### 作者的盲点 / 时代局限 / 原文硬伤（不得当正确结论）

- **90 / 110 Hz 只印在图 10.28 图注**，正文只给 60 Hz；引用必须标"图注值"。
- **反共振频率未给数值**；图 10.29 只有曲线，无数据表；"<20 Hz"是原文唯一可引的低频界。
- **p278 一阶模态句缺主语**（"轮胎作为整体"被排版丢失）；同段"三阶和三阶以上"重复"三阶"。
- **图 10.29/10.30 的坐标轴与图例被 OCR 混排进正文**，定义句被图例切断；引用图时必须回原始 PDF 核对。
- **样本为 1992 年轿车轮胎**；现代低扁平/EV 胎的模态频率与传递率会移动，幅度未知。
- **只有垂直平面内的模态**；横向/扭转模态不在本章。

### 容易混淆的邻近方法论

- **共振（能量集中、可能不传力）vs 反共振（传力峰）**：本章最反直觉的一对。
- **轮轴跳动（<20 Hz）vs 轮胎一阶（60 Hz）vs 反共振（之间）**：三个不同的物理机制。
- **轮迹刚度（lb/in，接地刚度）vs 轮胎垂直刚度（$k_t$）vs 悬架刚度**：三个串联刚度。
- **传递率（p278，1/s²）vs 附录 A 2.8（力/力）**：同名不同义。
