# 不足转向的轮胎层判据：比 $C_\alpha/W$ 不比 $C_\alpha$；后轴要相对大

## R — 原文 (Reading)

> **原书要点**（p266）：该特性直接取决于前后轴侧偏刚度按各自载荷归一化之后的配比。想要不足转向，后轴的这一刚度需相对偏大；若前轴侧偏刚度过高又不另加补偿，车辆会转向过度，并出现临界车速。
>
> **原书要点**（p264）：侧偏角一定时，垂直载荷愈大，转向力也愈大，但增幅并不成比例；折算到单位载荷上，最大转向力反倒出现在载荷最轻处。侧偏刚度随载荷变化的曲线向下凹，这一点对不足转向梯度十分关键。
>
> **原书要点**（p264、p266）：10.6.3 节谈载荷，10.6.8 节谈其给车辆性能带来的后果，另见图 10.15。

## I — 方法论骨架 (Interpretation)

一句话：**判不足/过多转向，比的是"每磅载荷每度出多少侧向力"（$C_\alpha/W$，$\mathrm{deg^{-1}}$），不是 $C_\alpha$ 的绝对值；后轴这个比值相对大 = 不足转向，前轴相对大 = 过多转向 + 临界车速。**

- **为什么不能用绝对值**：前后静态载荷天然差很多（典型 60/40），$C_\alpha$ 的绝对值必然前大后小。用绝对值比，几乎所有前置前驱轿车都被判成"前更硬 ⇒ 过多转向"——这是 ce14 的系统性错。
- **正确比较量**：$C_{\alpha f}/W_f$ 与 $C_{\alpha r}/W_r$，都带 $\mathrm{deg^{-1}}$。相等 ⇒ 中性；后大 ⇒ 不足；前大 ⇒ 过多。**量纲一致才可比**，这也是符号闸卡的意义。
- **凹面向下是这条判据的物理根**：$C_\alpha$ 随载荷单调增、但增速递减 ⇔ $C_\alpha/W$ 随载荷单调减。于是转弯时载荷由内轮搬到外轮：外轮多得的侧向力**小于**内轮失去的 ⇒ 该轴两轮之和**下降**。任何有载荷转移的轴，其有效侧偏刚度都低于静态值；前后轴转移量不同（由侧倾刚度分配定），这个"损失差"就是 $K$ 的物理来源之一。
- **损失是二阶量**：对凹函数 $F$，$F(W+d)+F(W-d)\le 2F(W)$（Jensen 不等式），差额 $\approx |F''|\,d^2$。所以"载荷转移降低总侧向力"是**恒真的方向结论**，但其量级随转移量的平方走——**不能用两个载荷点反推整条曲线**（G1/G2 都不支持）。
- **两条曲线的方向相反，别记混**：$C_\alpha$ 绝对值随载荷**上升**（增速递减），$C_\alpha/W$ 随载荷**下降**。说"$C_\alpha$ 随载荷下降"是高频误读（nf04），会让载荷转移的效果彻底反号。
- **边界**：本判据只到"轮胎层的转向平衡倾向"，不含外倾项（独立悬架可达 $K$ 的 25%）与回正力矩项（只占很小百分比）；本章也不给 $K$ 的表达式与"后轮要大多少"的门槛。
- 交付物：两个 $\mathrm{deg^{-1}}$ 数 + 比较结论 + "绝对值的坑"提示 + 一句"这是倾向不是 $K$ 的数值"。

## A1 — 应用示例 (Application Example)

### 示例 1：绝对值判反、正则化判对（合成演练，非书中事实）

- **类型与来源**：**合成演练（+ 原书引用数据）**。载荷与刚度为假设值；"以各自载荷正则化"与"后轴需相对大"为 p266 原文规则，"凹面向下"为 p264 原文。
- **输入**：前轴 $W_f=1200$ lb、$C_{\alpha f}=180$ lb/deg；后轴 $W_r=800$ lb、$C_{\alpha r}=132$ lb/deg。
- **方法的使用**：①正则化：$180/1200$ 与 $132/800$；②比较；③对照绝对值比较的结论。
- **结论/结果（复算值）**：前 **0.150**、后 **0.165** $\mathrm{deg^{-1}}$；后 > 前 ⇒ **趋向不足转向**。若用绝对值（180 vs 132）会得"前更硬 ⇒ 过多转向"，**结论相反**。若两者都等于 0.15（如 180/1200 与 120/800），判**中性**，不是过多转向。

### 示例 2：载荷转移让该轴"变软"（合成演练，非书中事实）

- **类型与来源**：**合成演练**。只验证不等式方向，不构造凹曲线（本章无 $\mu(F_z)$/$C_\alpha(F_z)$ 拟合式，G1/G2）。
- **输入**：某轴两轮静态各 1000 lb；转弯后外轮 1200、内轮 800（±20%）。
- **方法的使用**：①写出凹性 $F(1200)+F(800)\le2F(1000)$；②结论方向：该轴有效侧偏刚度低于静态值；③量级：损失 $\propto d^2$，$d/W=20\%$ ⇒ 二阶小量（个位数百分比），**不给具体数**。
- **结论/预期输出**：判"该轴有效侧偏刚度下降、下降量随转移量平方增长"；**不得**用两个载荷点反算曲线，也**不得**把损失写成线性。前后轴转移量差 ⇒ $K$ 的载荷项。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 换胎/改胎宽后，问"车会变得更推头还是更甩尾"。
2. 手上有前后轴 $C_\alpha$，要判不足/过多转向。
3. 问"为什么后轮胎压/后轴刚度要相对高"。
4. 满载/空载或载荷转移后，问平衡怎么变。
5. 看到"前轮侧偏刚度越大越好"的说法，要判断对不对。

### 语言信号（中英双写）

- 「不足转向还是过多转向」「understeer / oversteer」「推头 / 甩尾」
- 「前後侧偏刚度比」「cornering stiffness balance」「正则化侧偏刚度」
- 「换宽胎会推头吗」「后轮要不要更硬」
- 「载荷转移让侧向力变小」「$C_\alpha$ 随载荷下降吗」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `cornering-stiffness-from-coefficient`：那张卡给单个 $C_\alpha$（反算）；本卡做"除以各自载荷再比较"这一步。
- 与 `rut-criterion-0175`：外倾项对 $K$ 的贡献（独立悬架至多 25%、整体轴≈0）在那张卡给开关；本卡不含外倾项。
- 与 `aligning-moment-three-sources`：$M_z$ 对 $K$ 的直接贡献"仅占很小百分比"，主渠道是转向系柔度；本卡不含。
- 与第 6 章稳态转向：本卡只给"倾向"，$K$ 的数值、特征车速/临界车速在那章。

## E — 可执行步骤 (Execution)

**必需输入**：前/后轴 $W$（lb，静态）与 $C_\alpha$（lb/deg）或"侧偏系数 + 载荷"；四轮是否同型同压。**缺任一轴的载荷不得比较**；**缺 $C_\alpha$ 来源不得开算**（反算须标 G1）。

**交付物与完成标准**：两个 $\mathrm{deg^{-1}}$ 数 + 三态结论 + 绝对值陷阱提示 + 边界声明。

1. **统一口径**
   - 完成标准：两轴都化成 $C_\alpha/W$，单位 $\mathrm{deg^{-1}}$；写出中间量（$180/1200=0.150$）。
2. **比较并给三态**
   - 完成标准：后 > 前（差 >5%）⇒ 不足；前 > 后（差 >5%）⇒ 过多；差 ≤5% ⇒ 中性/不可判（5% 为本卡设定）。
3. **反查绝对值的坑**
   - 完成标准：同时给出"若用绝对值会比出什么结论"，并指出它为何错（载荷分配）。**判停**：用户坚持用绝对值 → 停，先讲 ce14。
4. **判载荷效应（方向）**
   - 完成标准：写"$C_\alpha$ 绝对值上升、$C_\alpha/W$ 下降（凹面向下）"；载荷转移 ⇒ 该轴有效刚度下降，损失 $\propto d^2$；**不给拟合式**（G1/G2）。
5. **声明边界**
   - 完成标准：写"不含外倾项（独立悬架可达 $K$ 的 25%）与 $M_z$ 项；本章不给 $K$ 表达式与'后轮要大多少'的门槛"。
6. **交付**
   - 完成标准：一句话"前 0.150、后 0.165 $\mathrm{deg^{-1}}$ ⇒ 趋向不足转向；这是轮胎层倾向，不是 $K$ 的数值"。

**计算约定（本卡设定）**：$C_\alpha/W$ 保留 3 位小数；判"中性"的带宽 ±5%（本卡设定，非原文）；比较前不四舍五入到 2 位。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **用 $C_\alpha$ 绝对值比前后轴。** 几乎所有车都会被判成过多转向，$K$ 的符号系统性出错（ce14）。
- **说"$C_\alpha$ 随载荷下降"。** 绝对值是上升的，下降的是 $C_\alpha/W$；写反会让载荷转移效果反号（nf04、ce13）。
- **把它当 $K$ 的计算。** 本卡只给倾向；$K$ 还要外倾项、$M_z$ 项、转向系柔度与整车几何（第 6 章）。
- **在 0.4g 以上用它。** 判据建立在线性区（$\alpha$ 小、$C_\alpha$ 为原点斜率）；极限工况要转三区段与复合滑动。
- **忽略"四轮同型同压"前提。** 前后不同胎/不同压时，$C_\alpha/W$ 的差异有一部分来自胎本身，须分开说。
- **用两个载荷点反推 $C_\alpha(F_z)$ 曲线。** 本章只有凹性方向，无拟合式（G1/G2）；两点连线会造出假曲线。
- **用它解释"雨天变推头"。** 路面改的是峰值 $\mu_p$，不是 $C_\alpha$；雨天"提前进入非线性"不等于"刚度变小"（ce18）。

### 作者在书中警告的失败模式

- **ce14**：用绝对 $C_\alpha$ 比较前后轴（含一个数值不自洽的例子：1200/1200 lb 被写成 0.15）。
- **ce13**：$C_\alpha$ 当常数，忽略凹面向下；满载/空载算出同一个 $K$。
- **ce17**：以为"前轮侧偏刚度大"是操控升级，只改前轴（更宽/更低高宽比/更高胎压/更大外倾），把车推向过多转向与临界车速。
- **ce18**：以为湿路/粗糙路会让 $C_\alpha$ 下降，把"极限降低"误算成"转向不足增加"。
- **ce26**：整体轴车按 25% 计外倾对 $K$ 的贡献（整体轴接近零）。

### 作者的盲点 / 时代局限 / 原文硬伤（不得当正确结论）

- **$C_\alpha$ 绝对值本章不给**（G1）：本卡的 $C_\alpha$ 只能来自反算或用户提供。
- **$\mu(F_z)$/$C_\alpha(F_z)$ 的 a、b 系数全书缺值**（G2）：凹面只有形状，没有函数。
- **p264 有一处残句**（"反的情况。"），前半句丢失；不得当完整命题引用（nf13）。
- **"以各自载荷正则化"只有一句话**，作者没给"后轮要大多少"的门槛；本卡的 ±5% 是自设判读带。
- **样本以斜交胎为主，$k$ 值 1992 年**；现代低高宽比胎的平衡会移动（ce43）。

### 容易混淆的邻近方法论

- **$C_\alpha$（lb/deg）vs $C_\alpha/W$（$\mathrm{deg^{-1}}$）**：判据只用后者。
- **不足转向（轮胎层倾向）vs 过多转向 + 临界车速（整车失稳）**：前者是平衡，后者是稳定性；前轴过强才会出现临界车速。
- **"载荷转移让总侧向力下降"vs"载荷转移让某轮侧向力上升"**：外轮升、内轮降、总和降。
- **"K 的符号"vs"K 的大小"**：本卡只判符号（倾向）。
