# 外倾推力估算：$C_\gamma$=(0.10–0.20)$C_\alpha$，子午线再乘 (0.40–0.50)

## R — 原文 (Reading)

> **原书要点**（p266）：只看绝对值，外倾刚度通常只相当于同一条胎侧偏刚度的一至两成，即 10%～20% 的范围。
>
> **原书要点**（p267）：换成轿车常用的子午线胎，其外倾刚度大约只有斜交胎的四成到五成（40%～50%）。
>
> **原书要点**（p268）：胎压究竟怎样作用于外倾刚度，目前还谈不上普遍规律；斜交胎随气压升高会小幅变硬，约每 psi 增 0.25 磅每度，子午线胎对此却几乎不敏感。
>
> — 10.7–10.7.4 式(10-3)（p266–268）

## I — 方法论骨架 (Interpretation)

一句话：**外倾推力是第二条侧向力通道，但它只有比例锚、没有绝对值——$C_\gamma$ 由"$C_\alpha$ 的 10%–20%"起算，子午线再乘一个 0.40–0.50 的结构因子；两个倍率必须连乘，缺一个就高估约 2 倍。**

- **两个倍率不是二选一**：10%–20% 是"所有胎"的通用锚；40%–50% 是"子午线相对斜交"的**额外**结构修正。只写 10%–20%，等于默认所有胎都是斜交（ce24）。
- **式(10-3) 没有负号**：$C_\gamma=+(\partial F_y/\partial\gamma)|_0$。正 $\gamma$ 出正 $F_y$，与 $C_\alpha$ 的负号不对称。这是全章符号系统唯一的不对称处——照抄 $C_\alpha$ 的负号，外倾推力与车辙判据一起反（ce03/ce22）。
- **方向口诀胜过符号**："推力始终指向轮胎倾斜的方向"（p266）。在左右轮符号相反的情况下，用方向自检比记两套基准可靠。
- **量级有多大**：$C_\alpha=150$ lb/deg 的子午线 ⇒ $C_\gamma=150\times(0.10\text{–}0.20)\times(0.40\text{–}0.50)=\mathbf{6}$–$\mathbf{15}$ lb/deg；斜交 $C_\alpha=120$ ⇒ **12–24** lb/deg。$1°$ 外倾的可比推力是"个位数到二十几磅"，相对 $1°$ 侧偏的百磅级很小——但在零侧偏时，它是唯一的侧向力来源。
- **三处修正的量级**：载荷 600→1800 lb 只 +约 20%（量级，且与"额定载荷附近"自相矛盾）；气压 +0.25 lb/deg per psi（**仅斜交**）；柔顺胎面 −20%~40%。
- **零侧偏处的地位**：$\alpha\to0$ 时侧偏力趋于零，外倾力不趋于零——所以"直线行驶性、车辙跟随、定心感"归外倾，"转弯极限"归侧偏。
- 交付物：$C_\gamma$（lb/deg）+ 两个倍率都写出来 + 方向结论 + 一处"绝对值不可得"的声明。

## A1 — 应用示例 (Application Example)

### 示例 1：子午线胎的 $C_\gamma$ 区间（原书引用数据 + 复算）

- **类型与来源**：**原书引用数据**（p266 10%–20%；p267 40%–50%），本卡复算。
- **输入**：子午线、$C_\alpha=150$ lb/deg、$\gamma=1°$。
- **方法的使用**：$C_\gamma=C_\alpha\times(0.10\text{–}0.20)\times(0.40\text{–}0.50)$。
- **结论/结果（复算值）**：$C_\gamma=\mathbf{6}$–$\mathbf{15}$ lb/deg，$1°$ 外倾推力 **6–15 lb**。若有人按"20% × $C_\alpha$"给 30 lb/deg → 高估 **2–5 倍**（**两个基准要分清**：同分位下端 30/15=**2.0 倍**；跨到最轻端 30/6=**5.0 倍**），且会让车辙判据误判为"爬出"。

### 示例 2：雪地胎的三处修正连乘（合成演练，非书中事实）

- **类型与来源**：**合成演练**。参数为假设，修正方向取原书。
- **输入**：斜交、$C_\alpha=120$ lb/deg、$\gamma=1°$、柔顺胎面（雪地胎类，取 −30%）；若气压 +4 psi。
- **方法的使用**：①$C_\gamma\approx0.15\times120=18$ lb/deg；②胎面修正 ×(1−0.30)=12.6 lb/deg；③气压修正 +0.25×4=+1 lb/deg（仅斜交）。
- **结论/预期输出**：$C_\gamma\approx\mathbf{13.6}$ lb/deg，$F_y\approx\mathbf{13.6}$ lb，方向＝倾斜方向。若换成子午线同规格：18×0.45=8.1 lb/deg，**气压项不得使用**（"不敏感"≠"零"，但无系数 ⇒ 不可算，须实测）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 给外倾角，问"外倾能出多少侧向力"。
2. 只有侧偏刚度，要估外倾刚度。
3. 换子午线胎后，外倾推力会变大还是变小。
4. 想用加大外倾来补直线行驶性/定心感，问量级够不够。
5. 看到"0.25 lb/deg per psi"，问这是 $C_\alpha$ 还是 $C_\gamma$ 的系数。

### 语言信号（中英双写）

- 「外倾推力怎么算」「camber thrust」「$C_\gamma$ 是多少」「外倾刚度占侧偏刚度多少」
- 「子午线外倾刚度」「radial camber stiffness」「负外倾能出多大力」
- 「胎压对外倾刚度的影响」「0.25 lb/deg/psi 是什么的系数」
- 「外倾和侧偏哪个在直线时更重要」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `rut-criterion-0175`：本卡算 $C_\gamma$ 与 $F_y$；判"爬辙/沿辙"要拿 $C_\gamma/W$ 比 0.0175，在那张卡。
- 与 `cornering-stiffness-from-coefficient`：本卡以那张卡的 $C_\alpha$ 为输入；$C_\alpha$ 的绝对值只能反算（G1）。
- 与 `aligning-moment-three-sources`：外倾还产生 $M_z$（约侧偏项的 10%），那在力矩卡；本卡只管力。
- 与 `tire-sign-and-unit-gate`：外倾角两套正方向与"$C_\gamma$ 无负号"的前置校验在那张卡。

## E — 可执行步骤 (Execution)

**必需输入**：$C_\alpha$（lb/deg）或"侧偏系数 + $W$"、胎型（斜交/子午线）、逐轮外倾角 $\gamma$（含基准）。可选：气压变化、胎面类型。**缺胎型不得乘 40%–50%**；**缺基准不得定号**。

**交付物与完成标准**：$C_\gamma$（lb/deg）+ $F_y$（lb）+ 方向结论 + 两个倍率显式写出。

1. **定 $C_\alpha$ 来源**
   - 完成标准：写明是反算还是实测；反算须带标记（G1）。
2. **算 $C_\gamma$（两个倍率连乘）**
   - 完成标准：$C_\gamma=C_\alpha\times(0.10\text{–}0.20)\times f_{type}$，$f_{type}=1.0$（斜交）或 $0.40$–$0.50$（子午线）；给出区间与中值。**判停**：只乘了一个倍率 → 退回重算（ce24）。
3. **加修正（逐项、带前提）**
   - 完成标准：载荷修正只用"600→1800 lb 约 +20%"的量级，并注明与"额定载荷附近"矛盾；气压 +0.25 lb/deg per psi **仅斜交**；胎面 −20%~40%（柔顺胎面）。
   - **判停**：子午线 + 气压 → 停，无系数，只能"不敏感、须实测"，不得按 0 也不得按 0.25（ce25）。
4. **算力并定方向**
   - 完成标准：$F_y=C_\gamma\gamma$（$\gamma$ 用逐轮符号）；用"推力指向倾斜方向"复核。$\gamma>5°$ → 出线性区，只报"超出线性区"。
5. **交付**
   - 完成标准：一句话"子午线、$C_\alpha=150$ ⇒ $C_\gamma\approx6$–$15$ lb/deg（$1°$ 出 6–15 lb），方向向左/右"，并声明绝对值不是本章原始数据。

**计算约定（本卡设定）**：$C_\gamma$ 保留 2 位有效数字；倍率区间不取整；中值用区间几何平均（子午线 $\sqrt{0.15\times0.45}\approx0.26$ 倍 $C_\alpha$）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **只乘 10%–20% 就给子午线胎。** 会高估 **2–5 倍**（ce24，同分位下端 2 倍、最轻端 5 倍）；两个倍率必须连乘。
- **给 $C_\gamma$ 加负号。** 式(10-3) 无负号；加负号会让外倾推力反向、车辙判据判反。
- **把 0.25 lb/deg per psi 挪给 $C_\alpha$ 或 $\mu$。** 该数只属**斜交胎的外倾刚度**（p268）；$C_\alpha$ 的气压只有方向、$\mu$ 的气压无系数（ce21/ce25、f09 的错版即此）。
- **把"子午线不敏感"当"零"。** 无系数 ⇒ 不可算，须实测（ce25 的内部矛盾已按此修正）。
- **按 $C_\alpha$ 的比例直接猜 $C_\gamma$ 的绝对值。** 本章不给 $C_\gamma$ 绝对值；比例锚只能给区间。
- **用 $C_\gamma$ 去比 0.0175。** 那是 $C_\gamma/W$ 的事（转 `rut-criterion-0175`）。
- **把外倾项当"转弯极限"的主力。** $\alpha\to0$ 时它是主项，$\alpha$ 大时侧偏项占绝对优势；对不足转向的贡献至多 25% 且仅限独立悬架（ce26，转 `understeer-balance-by-normalized-stiffness`）。
- **在 $\gamma>5°$ 用线性系数。** 线性区只在小角度；大外倾的曲线形状本章无数据。

### 作者在书中警告的失败模式

- **ce03**：左右轮共用一套外倾符号；前轴外倾推力相互抵消。
- **ce24**：$C_\gamma\approx0.15C_\alpha$ 给子午线（两倍率不连乘）。
- **ce25**：拿 0.25 lb/deg/psi 算子午线；或把不敏感写成零。
- **ce21**：把 0.25 挪用到 $C_\alpha$，用来算前后胎压差造成的侧偏刚度差。
- **ce26**：整体轴车按 25% 校核外倾对 $K$ 的贡献（整体轴接近零）。

### 作者的盲点 / 时代局限 / 原文硬伤（不得当正确结论）

- **$C_\gamma$ 的正文公式残缺**：式(10-3) 原文作"其定义如下式所示 y1y=0 (10-3)"，靠页末补录块还原为 $C_\gamma=(\partial F_y/\partial\gamma)|_{\gamma=0}$。引用须注明。
- **p268 "600→1800 lb 仅 +20%"与同句"额定载荷附近"自相矛盾**：该 +20% 只能当量级，不能当斜率。
- **气压"尚无一般规律"是作者自述**：这一条本身就是限权，不是遗漏。
- **图 10.16/10.17 无数据表**，且以斜交胎为样本；子午线只有"更小"一句话。
- **左右轮符号相反的根源在 p255 定义(12) 与 p266 两套定义**（正文内部冲突），本卡靠"逐轮定号 + 方向口诀"兜底。

### 容易混淆的邻近方法论

- **$C_\gamma$（lb/deg）vs 外倾系数 $C_\gamma/W$（$\mathrm{deg^{-1}}$）**：与 $C_\alpha$ 完全平行的一对；判据用后者。
- **外倾角 $\gamma$ vs 路面横坡角 $\gamma'$**：式(10-4) 的 $\gamma'$ 是路面倾角，不是轮胎外倾。
- **外倾推力 vs 外倾回正力矩**：后者约是侧偏项的 10%，量级更小（转 `aligning-moment-three-sources`）。
- **"外倾能提高极限侧向力"vs"外倾主要作用于零侧偏附近"**：后者才对。
