# 车辙判据：$C_\gamma/W$ 与 $\sin\gamma'$ 比大小，1° 横坡的阈值是 0.0175 = 1/57.3

## R — 原文 (Reading)

> **原书要点**（式 10-4）：侧向力与垂直载荷之比等于外倾角的正弦值（$F_y/W=\sin\gamma'$）；角度很小时该正弦又近似等于角度本身（$\sin\gamma'\approx\gamma'$），故可直写作 $F_y/W\approx\gamma'$。
>
> **原书要点**（p267–268）：在 1° 的横坡上，重力沿下坡方向给出的侧向力折算为每磅载荷 0.0175 磅（1/57.3）。外倾系数若超过 0.0175 磅每磅每度，轮胎尚有机会爬出车辙；低于此值，它更愿意往辙底滚。
>
> — 10.7.1 式(10-4) 与车辙判据（p267–268）；图 10.18

## I — 方法论骨架 (Interpretation)

一句话：**横坡把车往坡下推，外倾推力把车往坡上推；两者都除以载荷之后才能比——阈值就是 $\sin1°=0.0175$，左边必须是外倾系数 $C_\gamma/W$，不是外倾刚度 $C_\gamma$。**

- **这是一个可自证的几何平衡，不是标定值**：横坡角 $\gamma'$ 下重力沿坡分量 $W\sin\gamma'$，除以 $W$ 得 $\sin\gamma'$。1° → 0.017452；2° → 0.034899；0.5° → 0.008727；1% 坡度 → 0.0100。**坡度变了，阈值必须跟着变**（ce23）。
- **两边必须同量纲**：左边 $C_\gamma/W$（$\mathrm{lb/lb/deg}\equiv\mathrm{deg^{-1}}$），右边 $\sin\gamma'$（$\mathrm{lb/lb}$，无量纲）。原文同一句里"外倾系数"与"外倾刚度"混用，但括号里的 lb/lb/deg 暴露了它指的是**系数**——这是原文自身的口径滑移（ce22）。
- **判反的后果是恒真**：拿 $C_\gamma=30$–100 lb/deg 去比 0.0175，永远"大于"⇒ 永远判"爬出车辙"，与实车（子午线沿辙、斜交爬辙）完全相反。
- **复算交叉核对（本卡新增，原文未做）**：把前面的量级锚代进来，$C_\gamma/W=(0.10\text{–}0.20)\times k\times f_{type}$：
  - 斜交（$k=0.12$，$f=1.0$）：**0.0120–0.0240**，中值 0.0180；
  - 子午线（$k=0.15$，$f=0.40$–$0.50$）：**0.0060–0.0150**，中值 0.0105。
  两条带**在 0.0120–0.0150 重叠**，中值分居阈值两侧。所以"子午线必沿辙"在全部区间内成立（上限 0.0150 < 0.0175），而"斜交必爬辙"只在斜交胎的外倾刚度达到 $C_\alpha$ 的 **≥14.6%**（0.0175/0.12）时才成立——**判据是"典型值分居两侧"，不是"胎型决定结论"**。
- **等价换算式**：阈值 0.0175 ⇔ $C_\gamma/C_\alpha\ge0.0175/k$：斜交 **14.6%**；子午线 **11.7%**（乘 0.40–0.50 之前），乘完相当于 $C_\alpha$ 的 **4.7%–5.8%**；低高宽比（$k=0.25$–$0.30$）**5.8%–7.0%**。
- **顺带的上界**：外倾推力对不足转向梯度的贡献，独立悬架**至多 25%**，整体轴很小（p269）。这是"要不要把它算进 $K$"的开关，不是"它有多大"的数值。
- 交付物：一个"爬出/沿辙/在带内"的三态结论 + 阈值随坡度重算的一行 + 口径声明。

## A1 — 应用示例 (Application Example)

### 示例 1：0.0175 是怎么来的（原书引用数据 + 复算）

- **类型与来源**：**原书引用数据**（p267–268 式(10-4) 与 1/57.3），复算为本卡所做。
- **输入**：1° 横坡。
- **方法的使用**：$\sin1°=0.017452$；$1/57.3=0.017452$；原文印作 0.0175（差 **0.27%**）。
- **结论/结果（复算值）**：阈值 **0.0175**（保留 4 位）。原文的 "0.01751" 是 0.0175 与单位"lb"首字母 l 的 OCR 粘连，与 $\sin1°$ 差 **0.33%**，不影响判据。2° 横坡 → **0.0349**，判据必须换成 0.0349；继续用 0.0175 等于把坡度当 1°（ce23）。

### 示例 2：同一辆斜交胎车，结论可能翻转（合成演练，非书中事实）

- **类型与来源**：**合成演练**。用本章的比例锚构造，专门演示"胎型不决定结论"。
- **输入**：斜交、$W=1000$ lb、$C_\alpha=120$ lb/deg；情形 A：$C_\gamma=20$ lb/deg（$C_\alpha$ 的 16.7%）；情形 B：$C_\gamma=13$ lb/deg（10.8%）。
- **方法的使用**：①$C_\gamma/W$：A=0.0200，B=0.0130；②阈值 0.0175；③比较。
- **结论/预期输出**：A → $0.0200>0.0175$，**爬出车辙**；B → $0.0130<0.0175$，**沿辙**。两者都是斜交胎。所以"斜交爬辙"是典型值结论，个案必须实算 $C_\gamma/W$；**报告里不得只写胎型**。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 问"这车在车辙路上会不会自己往辙里跑 / 会不会爬上辙边"。
2. 换子午线胎后高速"发飘/找辙"，要判断是不是外倾推力不足。
3. 看到 0.0175 这个数，问它是经验值还是能推导的。
4. 横坡不是 1°（2°、3%、0.5°），阈值该取多少。
5. 判"外倾项要不要算进不足转向梯度 $K$"。

### 语言信号（中英双写）

- 「车辙」「爬出车辙」「沿辙走」「rut」「tramlining」「groove wander」
- 「0.0175 是什么」「外倾系数判据」「1/57.3」
- 「横坡 2° 阈值多少」「cross slope」
- 「外倾对不足转向贡献多少」「camber contribution to understeer」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `camber-stiffness-magnitude`：那张卡算 $C_\gamma$ 与 $F_y$；本卡只做"除以载荷再比阈值"这一步。
- 与 `understeer-balance-by-normalized-stiffness`：本卡给出"外倾项至多 25%、整体轴接近零"的开关；$K$ 的前后轴平衡在那张卡。
- 与 `conicity-and-ply-steer`：本卡判"路把人往哪推"，那张卡判"胎自己往哪偏"（零侧偏残差），两者都表现为跑偏但机理不同。
- 与 `tire-sign-and-unit-gate`：$C_\gamma$ 无负号、外倾角两套基准在那张卡。

## E — 可执行步骤 (Execution)

**必需输入**：$C_\gamma$（lb/deg）或"$C_\alpha$ + 胎型"、$W$（lb）、横坡角 $\gamma'$（deg 或 %）。**缺 $W$ 不得算系数**；**缺坡度不得用 0.0175**。

**交付物与完成标准**：$C_\gamma/W$ 的数值 + 阈值（按实际坡度）+ 三态结论（爬出/沿辙/在带内）+ 口径声明。

1. **认口径（判停点）**
   - 判据：左边必须是 $C_\gamma/W$；若手上是 $C_\gamma$（30–100 量级）→ **先除以 $W$**。
   - **判停**：直接拿 $C_\gamma$ 比 0.0175 → 停，判"口径错，结论无效"（ce22）。
2. **算阈值**
   - 完成标准：$\sin\gamma'$（$\gamma'$ 用度）或 $\gamma'$（用弧度）；1°→0.0175、2°→0.0349、0.5°→0.0087、1%→0.0100。写出你用的是哪一个坡度。
3. **算左边**
   - 完成标准：$C_\gamma/W$，保留 4 位小数；同时给出等价比值 $C_\gamma/C_\alpha$，并与 $0.0175/k$ 对照（斜交 14.6%、子午线 11.7%）。
4. **比较并给三态**
   - 完成标准：$>0.0175$（且超出量 >10%）→ 爬出；$<0.0175$（且低于量 >10%）→ 沿辙；落在 ±10% 带内 → **"在带内，判据不可判"**，只报数值不报结论。
5. **（若用于 $K$）判是否计入**
   - 完成标准：独立悬架 → 计入，且**至多 25%**；整体轴 → 约 0，可略；若算出 >30% → 检查是否把 $C_\gamma$ 当成了 $C_\alpha$ 的 20% 而未乘结构因子（ce24/ce26）。
6. **交付**
   - 完成标准：一句话"$C_\gamma/W=0.0xx$、1° 横坡阈值 0.0175 ⇒ 爬出/沿辙"，并声明这是准静态、干路、无制动/驱动。

**计算约定（本卡设定）**：$C_\gamma/W$ 保留 4 位小数；阈值保留 4 位；±10% 为"不可判带"（本卡设定，非原文）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **拿 $C_\gamma$ 比 0.0175。** 恒"大于"⇒ 永远判"爬出"，与实车相反（ce22）。这是本章最典型的量纲错。
- **把 0.0175 当与坡度无关的行业常数。** 它是 $\sin1°$；换坡度必换阈值（ce23）。
- **在制动/驱动/大侧偏下用本判据。** 判据假设纯外倾、无纵向力、$\alpha\approx0$、准静态；一旦踩制动/驱动，侧向力预算被占，判据不再直接成立。
- **用胎型替代计算。** 复算显示两条量级带在 0.0120–0.0150 重叠："斜交必爬辙"只在 $C_\gamma\ge14.6\%C_\alpha$ 时成立；必须实算。
- **把"外倾贡献 25%"不分悬架套用。** 整体轴的外倾变化被车轴锁死，该项接近零（ce26）。
- **用"外倾推力大"解释高速发飘。** 高速段还叠加 $C_\alpha$ 的车速不敏感前提失效、轮胎模态与反共振（转 `tire-modes-and-anti-resonance`）。

### 作者在书中警告的失败模式

- **ce22**：车辙判据里拿 $C_\gamma$ 比 0.0175（原文自身"系数/刚度"混用是诱因）。
- **ce23**：把 0.0175 当"轮胎行业经验常数"，坡度变了不换阈值。
- **ce24**：$C_\gamma\approx0.15C_\alpha$ 给子午线，导致把子午线判成"爬出"。
- **ce26**：整体轴车按 25% 校核外倾对 $K$ 的贡献。
- **ce03**：左右轮共用外倾符号，前轴外倾推力抵消 ⇒ 判据的左边直接算错。

### 作者的盲点 / 时代局限 / 原文硬伤（不得当正确结论）

- **p268 判据自身口径滑移**："外倾系数 > 0.0175"与"外倾刚度 < 0.0175"同句出现，单位都写 lb/lb/deg。本卡统一为**系数**；原文的第二种写法不得引用。
- **"0.01751"是 OCR 粘连**：原文 `1/57.3=0.01751Ib/1b`，是 0.0175 + "lb" 首字母 l。
- **判据的样本与年代**：以斜交/子午线两类胎的典型值为据，1992 年；现代低高宽比胎的 $k$ 更大，等价阈值更低（$0.0175/k$ 更小 ⇒ 更容易"爬出"）。
- **$\gamma'$ 与 $\gamma$ 同页并存**：$\gamma'$ 是路面倾角，不是轮胎外倾角；引用时逐字核对。
- **图 10.18 是示意**，无数值；判据的可信度来自几何而非实测。

### 容易混淆的邻近方法论

- **$C_\gamma$（lb/deg）vs $C_\gamma/W$（$\mathrm{deg^{-1}}$）**：判据只用后者。
- **横坡 $\gamma'$ vs 轮胎外倾 $\gamma$**：一个来自路，一个来自悬架几何。
- **"沿辙"（外倾推力不够）vs "跑偏"（零侧偏残差）**：前者是路推车，后者是胎推车（转 `conicity-and-ply-steer`）。
- **"外倾对 $K$ 的 25% 上界"vs"外倾对极限侧向力的贡献"**：前者是转向平衡项，后者几乎为零。
