# $\mu$ 的载荷与气压敏感性：局部斜率（+10% → −0.01）与全域割线（50%→125% 降 >20%）分域使用

## R — 原文 (Reading)

> **原书要点**（p258）：载荷越接近额定值，这两个系数就越往下走——每多压上 10% 的载荷，它们大约各降 0.01。
>
> **原书要点**（p265）：载荷加重时，转向中能达到的摩擦系数峰值会跟着下降；载荷由 50% 提到 125%，这个峰值可以掉两成以上（超过 20%）。
>
> **原书要点**（p259）：胎压的影响须按路面分开看——干燥路面上，气压调高或调低，几乎都不改变摩擦因数的峰值与滑动值；潮湿路面上则一般认为，气压一旦打高，这两个值会一并明显上升。
>
> — 10.5.1 垂直载荷（p258）；10.6.3（p265）；10.5.2 充气压力（p259）

## I — 方法论骨架 (Interpretation)

一句话：**载荷敏感性在书里是两条互不相容的口径——近额定的局部斜率（每 +10% 载荷 $\mu$ 降 0.01）与全载荷域的割线（50%→125% 降幅 >20%）。它们不是同一条曲线的两段，不能连、不能插值；该用哪条，由载荷落在哪个窗口决定。**

- **两条口径的数学身份不同**：0.01/10% 是**导数**（局部斜率，只在额定载荷附近有效，原文有"接近额定载荷时"这一限定）；20% 是**割线**（跨 2.5 倍载荷的端点差）。导数与割线只有在函数是直线时才相等，而 $\mu(F_z)$ 是凹面向下——所以两数字必然不相容，且**不相容本身是信息**：降幅随载荷加速。
- **复算一下差多大**：50%→125% 是 7.5 个"10% 步长"；线性外推给 $7.5\times0.01=0.075$ 的绝对降幅；若 50% 处 $\mu\approx0.95$，这只相当于 **约 8%** 的相对降幅，而原文说 **>20%**。差 $\ge2.4$ 倍。**任何"把 0.01 写进代码当全域公式"的做法，都会在高载端系统性低估衰减**（ce09）。
- **窗口划分是本卡的判读约定（非原文原话）**：额定载荷 ±20% 内用局部斜率；超出该窗口只用割线量级，并报"降幅随载荷加速"这一定性结论，**不给中间点**。
- **气压是方向题，不是数值题**：干路不明显、湿路显著增大（排水改善）、货车"相当复杂"。本章**没有** $\mu$ 的气压系数——注意 0.25 lb/deg per psi 是**外倾刚度**的系数（p268），不是 $\mu$ 的，也不是 $C_\alpha$ 的。
- 交付物：一个带窗口声明的修正量（要么 $\Delta\mu$，要么"只报量级"），加一句"这不是曲线"。

## A1 — 应用示例 (Application Example)

### 示例 1：近额定 +30%，两个系数同幅下降（原书引用数据 + 复算）

- **类型与来源**：**原书引用数据**（p258 的 0.01/10% 规则），数值按规则复算。
- **输入**：基准 $\mu_p=0.90$、$\mu_s=0.81$（干路），某轮载荷 +30%（仍在额定附近）。
- **方法的使用**：3 个 10% 步长 × 0.01 = 0.03 的绝对降幅，$\mu_p$ 与 $\mu_s$ **同幅**下降。
- **结论/结果（复算值）**：$\mu_p=\mathbf{0.87}$、$\mu_s=\mathbf{0.78}$。若载荷到 125% 额定 → **停用本式**，改报"50%→125% 降 >20%"的割线量级。

### 示例 2：把线性式推到全域，看它怎么崩（合成演练，非书中事实）

- **类型与来源**：**合成演练**，专门演示 ce09 的失败模式。
- **输入**：同上，$\mu_0=0.95$（取 50% 载荷附近），载荷 50%→125%。
- **方法的使用**：①线性外推：7.5 步 × 0.01；②割线：原文"减小超过 20%"。
- **结论/预期输出**：线性给 $\Delta\mu=\mathbf{0.075}$（相对 **7.9%**），原文给 **>20%**（$\Delta\mu>0.19$）。两者差 **$\ge2.5$ 倍**，且方向一致、量级相反 ⇒ 判"不得衔接"。正确交付是两句话：窗口内给 0.075 级修正，窗口外只给"降幅加速、至少 20%"，**不给中间点、不画曲线**。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 满载/超载/电动车高载荷工况，问"抓地掉多少"。
2. 做载荷转移后的轴荷校核，要更新该轴 $\mu$。
3. 前后轴载荷差很大（60/40），问能否用同一个 $\mu$。
4. 想靠调胎压提高抓地，问干路/湿路分别有没有用。
5. 看到报告里同时引用"0.01/10%"与"降 20%"却不说口径。

### 语言信号（中英双写）

- 「载荷大了抓地掉多少」「超载 20% $\mu$ 降多少」「load sensitivity」
- 「$\mu$ 随载荷变化」「50% 到 125% 降 20%」
- 「胎压高能不能提高抓地」「inflation pressure grip」「干路胎压敏感吗」
- 「前后轴载荷不同能用一个 $\mu$ 吗」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `mu-surface-selection`：本卡只给修正量，基准值在那张卡。
- 与 `understeer-balance-by-normalized-stiffness`：本卡改的是 $\mu$（摩擦上限）；$C_\alpha$ 随载荷的凹面是另一条曲线，不要混（$C_\alpha$ 绝对值随载荷**上升**，$\mu$ 随载荷**下降**）。
- 与 `camber-stiffness-magnitude`：0.25 lb/deg/psi 属外倾刚度，本卡明确不采用它作 $\mu$ 或 $C_\alpha$ 的气压系数。
- 与 `longitudinal-slip-and-mu-s-curve`：本卡给 $\mu$ 的高度，那张卡给峰位与斜率。

## E — 可执行步骤 (Execution)

**必需输入**：基准 $\mu$（哪一个：$\mu_p$ 或 $\mu_s$）、基准载荷 $W_0$ 与"额定载荷"的关系（百分比）、目标载荷 $W$。可选：气压变化量、干/湿。**缺"额定载荷"参照不得开算**——本章没给载荷等级表，额定载荷须由用户给或外部 T&RA 表取。

**交付物与完成标准**：$\Delta\mu$（或"只报量级"）+ 窗口声明 + 一句"不得插值"。

1. **算载荷比**
   - 完成标准：$W/W_0$ 写成百分数；同时写出 $W_0$ 是否等于额定载荷（不是则先说明"以 $W_0$ 为局部基准"）。
2. **判窗口（判停点）**
   - 判据：$W/W_0\in[0.8,1.2]$ → 用局部斜率；否则 → 只用割线。
   - **判停**：$W/W_0>1.25$ 或 $<0.5$ → 停，声明"本章无该区间数据，只能定性"。
3. **局部斜率分支**
   - 完成标准：$\Delta\mu=-0.01\times\dfrac{(W/W_0-1)}{0.10}$，$\mu_p$ 与 $\mu_s$ 同幅；写出绝对降幅与相对降幅两个数。
4. **全域分支**
   - 完成标准：只写"50%→125% 峰值 $\mu$ 降幅 >20%"，并注明"降幅随载荷加速"；**不填中间点、不做线性衔接、不画拟合曲线**（G2，`needs_review`）。
5. **气压分支**
   - 完成标准：干路判"不明显，别指望加胎压提抓地"；湿路判"显著增大（排水改善）"；货车判"相当复杂"；**不给系数**。**判停**：用户要求"每 psi 提高多少 $\mu$" → 停（本章未给）。
6. **交付**
   - 完成标准：一句话"在 ±20% 窗口内 $\mu_p$ 降 0.03（相对 3.3%）；超出窗口只能报量级"，并声明用的是哪条口径。

**计算约定（本卡设定）**：$\mu$ 保留 3 位小数（因为 0.01 的步长要求）；百分比保留 1 位；两段之间**不设过渡值**。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **把 0.01/10% 当全域公式。** 原文限定"接近额定载荷时"；外推到 125% 会把降幅低估 2.5 倍以上（ce09）。
- **把两个数字线性衔接或插值成曲线。** 局部斜率与全域割线不相容，接起来会造出一条"看起来平滑、实际无依据"的 $\mu(F_z)$（G2）。
- **在缺少额定载荷参照时给绝对 $\mu$。** 本章无 T&RA 载荷表，"额定载荷"须外部给。
- **用 0.25 lb/deg per psi 改 $\mu$ 或 $C_\alpha$。** 该数只属**斜交胎的外倾刚度**（p268）；子午线的外倾刚度对气压"不敏感"，且不得把不敏感写成零（ce25）。
- **用干路的"不敏感"推断湿路。** 两者方向相反（ce11）。
- **把载荷敏感性与 $C_\alpha$ 的凹面混为一谈。** $\mu$ 随载荷降、$C_\alpha$ 绝对值随载荷升（增速递减）；两条曲线方向不同，混用会让载荷转移的效果反号（nf04）。

### 作者在书中警告的失败模式

- **ce09**：把"载荷 +10% → $\mu$ 降 0.01"当全域线性规律；用低载数据外推到 125% 以上；同一报告同时引用 0.01 与 20% 却不解释。
- **ce11**：把"提高胎压能增大 $\mu$"当通则，在干路上靠加胎压求抓地（几乎无效，还牺牲乘适性）。
- **ce21**：照搬"前后胎压差调转向"的老办法；在子午线/货车胎上用 0.25 lb/deg/psi 定量算 $C_\alpha$ 之差（跨量挪用）。
- **ce25**：子午线胎按 0.25 算外倾刚度；或把"不敏感"写成"零"。

### 作者的盲点 / 时代局限 / 原文硬伤（不得当正确结论）

- **$\mu(F_z)$ 的 a、b 多项式系数全书缺值**（G2，`needs_review`）：本章只有一句局部斜率与一句全域割线，图 10.8 只有曲线、无数据表。**"算连续 $\mu(F_z)$"不可算**。
- **两数字不相容是原文内部张力**：这不是读者误读（nf05），但也不是可以调和的——唯一自洽解释是"降幅随载荷加速"，而作者未明说。本卡把它写成判读约定，并标注"非原文原话"。
- **p268 的 600→1800 lb 与"额定载荷附近"自相矛盾**：该段属外倾刚度，但同一类"限定语与数据范围打架"的毛病在本章反复出现，引用时须逐句核对限定语。
- **气压只有方向、无系数**：$\mu(p)$ 不可定量；货车"相当复杂"原文自述。

### 容易混淆的邻近方法论

- **局部斜率（导数）vs 全域割线（端点差）**：同一函数的两把尺子，不能互相换算。
- **$\mu$ 的载荷敏感性 vs $C_\alpha$ 的载荷敏感性**：一个降、一个升（增速递减）。
- **$\mu$ 的气压效应（无系数）vs $C_\gamma$ 的气压效应（斜交 0.25 lb/deg/psi）**：后者有数，前者没有。
