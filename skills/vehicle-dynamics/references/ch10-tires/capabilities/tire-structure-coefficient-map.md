# 结构决定系数：帘布角与带束层定 $C_\alpha$、$C_\gamma$，不归摩擦

## R — 原文 (Reading)

> **原书要点**（p253）：方向稳定性来自夹在胎体与胎面之间、沿圆周铺开的一层坚硬纤维或钢丝带束。带内帘线与周向的夹角通常不大于 20°；转弯之际，正是这层带束把胎面扶稳。
>
> **原书要点**（p253）：帘线相对周向做成较大夹角（35°～40°），相邻帘布层的走向左右交替。夹角放大，胎体更软，乘坐更舒服；夹角收小，则换来更好的方向稳定性。
>
> — 10.1 轮胎结构（p253）；10.6.2–10.6.7（p263–266）

## I — 方法论骨架 (Interpretation)

一句话：**"换胎能改什么、不能改什么"这条线，靠结构因果划开——帘布角、带束层、高宽比决定 $C_\alpha$ 与 $C_\gamma$（转向平衡与转向灵敏度），路面与胶料决定 $\mu$（附着上限）。所以换一套胎可以把过多转向改回不足转向，却几乎不改变极限侧向加速度。**

- **唯一的结构自变量是帘布角**：子午线名义 90°（对周向）+ 带束层 ≤20°；斜交 35°–40° 逐层交替。夹角↑→变软→乘适性↑；夹角↓→方向稳定性↑。全部"类型对比"结论都能追到这个角。
- **带束层是"胎侧极软 + 胎面必硬"这对矛盾的唯一解**：侧向柔度交给胎侧，胎面刚性交给带束。于是子午线**胎侧最软却 $C_\alpha$ 最大**——两个"软硬"方向正交，不可互推（g02/g03）。
- **两个方向相反的比例**：子午线 $C_\alpha/W$ 更大（0.15 vs 0.12，同高宽比），$C_\gamma$ 更小（斜交的 40%–50%）。任何"子午线都更大/都更小"的说法都错。
- **高宽比是第二自变量**：0.78–0.70 的常规胎 → 0.60 或更低的高性能胎，$k$ 从 0.15 升到 0.25–0.30。这是"低扁平胎转向更灵敏"的结构解释。
- **方向表（除载荷/气压外全部定性）**：气压↑→$C_\alpha$↑（"单调且相当密切"，**无系数**）；尺寸/宽度↑→↑；轮辋加宽→↑；胎面越开放越软→↓（**仅斜交**，子午线"尚无定论"）；胶料硬度↑→小幅↑（"十分小"）；车速与路面→在"高速公路正常车速范围"内基本不敏感。
- **$\mu$ 不走这条链**：路面与胶料改的是峰值 $\mu_p$ 与峰位，不是线性段斜率。把"雨天转向变钝"归因于 $C_\alpha$ 下降是 ce18。
- 交付物：一张"改什么 → 动哪个系数 → 动不动 $\mu$"的三列表 + 每条的方向与不确定性标注。

## A1 — 应用示例 (Application Example)

### 示例 1：换低高宽比胎，能改什么（原书引用数据 + 复算）

- **类型与来源**：**原书引用数据**（p263–264 三档 $k$；p253 结构；p267 外倾 40%–50%），推演为本卡所做。
- **输入**：原车 $k=0.15$（子午线、高宽比 0.78–0.70）；换 0.60 或更低的低高宽比高性能胎；$W$ 不变；$\mu_p$ 不变（同一路面/胶料档）。
- **方法的使用**：①$C_\alpha=k\times W$ 变化；②$C_\gamma$ 随之变化（比例锚）；③$\mu_p$ 与峰位不变。
- **结论/结果（复算值）**：$k$ 由 **0.15 → 0.25–0.30**（$+67\%$~$+100\%$），$C_\alpha$ 由 150 → **250–300** lb/deg（$W=1000$）；而 $\mu_p$ 与极限侧向加速度**基本不变**。所以"转向更灵敏"能改，"极限更高"不能靠换胎改（ce43 的现代胎另论）。

### 示例 2：只改前轴，把车推向过多转向（合成演练，非书中事实）

- **类型与来源**：**合成演练**。数值假设，判据取 p266 与 p263–264。
- **输入**：前轴 $W_f=1200$、$k_f$ 由 0.15 升到 0.25（只换前胎）；后轴 $W_r=800$、$k_r=0.15$ 不变。
- **方法的使用**：①$C_{\alpha f}/W_f$：0.15→0.25；②$C_{\alpha r}/W_r=0.15$；③比较。
- **结论/预期输出**：前 0.25 > 后 0.15 ⇒ **过多转向**（原本中性）。若同时把后轴也换到 0.25 ⇒ 恢复中性。**判停**：只改单轴必须重算平衡并提示临界车速风险（ce17）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 换胎/换规格后，问"操控会变成什么样""能不能治好推头"。
2. 问"换胎能不能提高极限侧向加速度"。
3. 想用胎压/花纹/轮辋宽度调转向，问方向对不对、量级有没有。
4. 看到"子午线侧偏刚度更大、外倾刚度更小"，问为什么。
5. 比较货车子午线/斜交、或评估 1992 年数据能不能用于现代胎。

### 语言信号（中英双写）

- 「换胎能改转向吗」「换宽胎会推头还是甩尾」「低扁平胎更灵敏吗」
- 「换胎能提高极限吗」「grip vs handling」「结构决定还是胶料决定」
- 「胎压调转向」「花纹影响侧偏刚度」「轮辋加宽」
- 「子午线侧偏刚度大」「radial vs bias」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `cornering-stiffness-from-coefficient`：本卡给"为什么是这一档 $k$"；那张卡做"系数 → lb/deg"的反算。
- 与 `understeer-balance-by-normalized-stiffness`：本卡给"改哪个结构会动 $C_\alpha$"；判"改完是推头还是甩尾"在那张卡。
- 与 `camber-stiffness-magnitude`：本卡只给"子午线 $C_\gamma$ 是斜交的 40%–50%"这条方向；量级估算在那张卡。
- 与 `mu-surface-selection`：本卡明确"结构不改 $\mu$"；$\mu$ 的取值在那张卡。

## E — 可执行步骤 (Execution)

**必需输入**：改动项（胎型/高宽比/气压/尺寸/花纹/轮辋）、目标（改转向平衡 / 改极限 / 改乘适性）、当前 $k$ 或 $C_\alpha$。**缺目标不得给建议**——同一个改动对"平衡"与"极限"的作用不同。

**交付物与完成标准**：三列表（改动 → 动的系数 → 动不动 $\mu$）+ 每行方向 + 不确定性标注。

1. **判改动属于哪条链**
   - 完成标准：结构项（帘布角/带束/高宽比/尺寸/轮辋）→ 动 $C_\alpha$、$C_\gamma$；摩擦项（路面/胶料/载荷/气压对 $\mu$）→ 动 $\mu$；两类同时动要分开说。
2. **给方向与倍率**
   - 完成标准：子午线同高宽比 $k$ 更大（0.15 vs 0.12）；$C_\gamma$ 为斜交 40%–50%；高宽比 0.60 或更低 → $k=0.25$–0.30；气压↑→$C_\alpha$↑（**无系数**）；胎面开放/软→$C_\alpha$↓（**仅斜交**）；硬度↑→小幅↑。
3. **标不确定性（判停点）**
   - 完成标准：子午线的花纹/胶料影响标"尚无定论"；硬度标"十分小"；货车胎气压标"相当复杂"。**判停**：要给这些项的数值 → 停（本章无系数）。
4. **判"能不能改极限"**
   - 完成标准：结构改动**不改** $\mu_p$ ⇒ 极限侧向加速度基本不变；要改极限须改路面/胶料（或载荷），不是换结构。
5. **交付**
   - 完成标准：一句话"换低高宽比胎使 $k$ 由 0.15 升到 0.25–0.30 ⇒ 转向更灵敏、平衡向过多转向移动；$\mu_p$ 不变 ⇒ 极限不变"，并声明数据为 1992 年样本。

**计算约定（本卡设定）**：倍率给区间不给点值；方向表每条必须带"原文语气"（明确/尚无定论/十分小/相当复杂）；不得把方向升级为数值。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **把斜交胎的花纹/胶料规律外推到子午线。** 原文连用两个"尚无定论"（ce20）。
- **用结构改动去改极限侧向加速度。** 结构定 $C_\alpha$/$C_\gamma$，$\mu$ 由摩擦副定；换胎改的是"多快达到极限"，不是"极限多高"。
- **用 1992 年的分布当现代上界。** 0.25–0.30 是当年的激进值，今天 30/25 系列已突破（ce43）；货车子午线"各占一半"、带束斜交已绝迹。
- **只改前轴就宣称"操控升级"。** 会把车推向过多转向并引入临界车速（ce17）。
- **把"路面让车变钝"归因于 $C_\alpha$ 下降。** 路面改峰值与峰位（ce18）。
- **用胎压差当转向调校主手段。** 那是"过去通常采用"的老办法，子午线/货车不成立（ce21）。
- **把硬度/花纹的影响写成数值。** 本章只有"十分小"与"尚无定论"。

### 作者在书中警告的失败模式

- **ce20**：斜交花纹规律外推子午线；换雪地胎后按斜交规律预测转向变化。
- **ce43**：把 1970s–80s 的侧偏系数分布当现代胎上界；用 0.15 算现代轿车 $K$。
- **ce17**：只改前轴（更宽/更低高宽比/更高胎压/更大外倾），推向过多转向与临界车速。
- **ce18**：湿路/粗糙路 ⇒ 以为 $C_\alpha$ 降。
- **ce21 / ce25**：胎压差调转向；0.25 lb/deg/psi 挪用给 $C_\alpha$ 或子午线。
- **nf13**：用 p264 的残句"反的情况。"推翻"子午线通常更大"的总体规律。

### 作者的盲点 / 时代局限 / 原文硬伤（不得当正确结论）

- **数据重心在斜交胎，与叙述自相矛盾**：正文反复说子午线 $C_\alpha$ 更大，但主力图（图 10.13/10.16）明确标"斜交轮胎"；子午线常只有"更大/更小"一句话。
- **高宽比停滞在 0.60**：今天 30/25 系列量产，$k$ 的上界已被突破。
- **无现代胎品类**：缺气保用、自修复、EV 专用胎、半热熔、冬季胎全部缺席；温度不作为变量。
- **$C_\alpha$/$C_\gamma$ 的气压项只有方向**（0.25 仅属斜交 $C_\gamma$）。
- **g05 的高宽比定义有两套**（p254 断面高 vs 附录 A 7.1.6（外径−轮辋直径）/2），用规格反算时只能用后者。

### 容易混淆的邻近方法论

- **结构（$C_\alpha$、$C_\gamma$）vs 摩擦副（$\mu_p$、$s_p$）**：两条链，改一个不动另一个。
- **"转向更灵敏"vs"极限更高"**：前者是 $C_\alpha$，后者是 $\mu$。
- **胎侧"软"vs 侧偏刚度"大"**：弯曲柔度与侧向刚度正交。
- **帘布角（结构自变量）vs 帘布层数（次要修正）**：角度是主变量。
