# 附着系数选值：先定"用哪个 $\mu$"（$\mu_p$/$\mu_s$/滑动数），再定路面档

## R — 原文 (Reading)

> **原书要点**（p258）：干路上滑动率到 15%～20% 附近，摩擦力见顶，峰值一般是载荷的 70%～90%；湿路上垂直载荷里只有 25%～50% 能化作摩擦力的上限；结冰路面仅剩 10%～15%，且滑动率才百分之几就已到顶。
>
> **原书要点**（p259）：路面单独拿出来并无摩擦系数一说；唯有轮胎与路面配成一对摩擦副，才谈得上对应的摩擦系数。
>
> **原书要点**（p260）：自从 ABS 这类防抱死装置上车，衡量轮胎时最要紧的一项参数就变成了峰值摩擦系数。
>
> — 10.5（p258–p260）；10.5.3 滑动数（p259）

## I — 方法论骨架 (Interpretation)

一句话：**$\mu$ 不是一个数，是四个身份——峰值 $\mu_p$（有 ABS / 极限侧向用）、滑动 $\mu_s$（无 ABS 抱死 / 驱动打滑用）、滑动数 SN（用标准胎给路面打分）、以及"湿 25%–50%"这类"占载荷比例"的峰值表述。选错身份，错的是 20%–50%，不是小数点。**

- **$\mu$ 属于摩擦副，不属于轮胎、也不属于路面**。报 $\mu$ 必须三件套：轮胎（规格/磨耗/气压）+ 路面（材质/湿度）+ 载荷。唯一的合法单边化是 ASTM E-274 用**标准试验胎**把路面差异压成滑动数——那是固定轮胎之后的相对比较。
- **$\mu_p$ 与 $\mu_s$ 是曲线上的两个工作点，不是两个精度等级**：$\mu_p$ 在峰值滑动率处（干 15%–20%），$\mu_s$ 在 $s=100\%$ 抱死态。有 ABS ⇒ 工作点被钉在峰值附近 ⇒ 用 $\mu_p$；无 ABS ⇒ 抱死难免 ⇒ 用 $\mu_s$。
- **$\mu_p$ 本身还不唯一**：附录 A 7.6 把它拆成侧向（7.6.1）、驱动（7.6.2）、制动（7.6.3）三条通道，均限"车轮未抱死"；$\mu_s$ 只对应"滑动制动附着系数"（7.6.3.1），限"车轮抱死"。**同一个 $\mu_p$ 不能横跨三条通道使用**。
- **滑动数不是滑动率**：SN 是抱死拖曳下的 $\mu\times100$（运动学量的"自变量" vs 力学量的"因变量端点"）。本章的四档 SN 是全书唯一有法规背书、可外部对标的数。
- 本章只给三档路面（干/湿/冰/封层），**没有雪、砂石、赛道胶，也没有温度维度**——这不是提取遗漏，是 1992 年样本的边界。
- 交付物：一组带口径的 $\mu$（数值区间 + 身份 + 路面档 + 载荷条件），加一句"这个数能用来算什么、不能算什么"。

## A1 — 应用示例 (Application Example)

### 示例 1：从滑动数反推 $\mu_s$，并证明它不等于 $\mu_p$（原书引用数据）

- **类型与来源**：**原书引用数据**（p258 三档峰值 + p259 四档滑动数），复算为本卡所做。
- **输入**：法规干路 SN$=81$；波特兰水泥 SN$=45$–50；湿沥青 SN$=30$；Jennite 封层 SN$=20$–25。
- **方法的使用**：①SN$=100\mu$ ⇒ $\mu_s=$SN/100；②这些值全部来自**抱死拖曳**，故是 $\mu_s$，不是 $\mu_p$；③要 $\mu_p$ 须另取 p258 的 0.70–0.90。
- **结论/结果（复算值）**：干路 $\mu_s=\mathbf{0.81}$、波特兰水泥 $\mathbf{0.45}$–$\mathbf{0.50}$、湿沥青 $\mathbf{0.30}$、Jennite 封层 $\mathbf{0.20}$–$\mathbf{0.25}$。与 $\mu_p$ 干 0.70–0.90 对照：SN 81 的 0.81 落在 $\mu_p$ 区间内只是数值巧合，**口径完全不同**。

### 示例 2：同一辆车，三种路面的校核值（合成演练，非书中事实）

- **类型与来源**：**合成演练**。车辆参数自造，路面值取原书区间中值。
- **输入**：$W=3600$ lb（四轮均载 900 lb），无 ABS，直线制动；干 $\mu_s=0.81$、湿 $\mu_s=0.30$、冰 $\mu_s=0.12$。
- **方法的使用**：①无 ABS ⇒ 用 $\mu_s$；②$F_{x,\max}=\mu_sW$；③$D_x=F_x/M$，$M=W/32.2$。
- **结论/预期输出**：$F_{x,\max}$ 分别为 **2916 / 1080 / 432 lb**，$D_x$ 分别为 **0.81g / 0.30g / 0.12g**。三档相差 2.7 倍与 2.5 倍——**任何"打个八折"的保守修正都不够**（ce06）。若同一车加装 ABS，则应改用 $\mu_p$（干 0.70–0.90），数值反而可能略低，因为 $\mu_p$ 与 $\mu_s$ 的排序并非处处相同。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 要算制动距离/最大驱动力，问"$\mu$ 取多少"。
2. 拿到一个"路面摩擦系数 0.8"或"这条沥青 $\mu=0.3$"，判断它是什么口径、能不能用。
3. 有 ABS 与无 ABS 两种配置，校核时该换哪个 $\mu$。
4. 拿到滑动数报告（SN 45、SN 30），要换算成设计用的附着系数。
5. 冰面/湿路事故分析，要区分"峰值低"与"到峰窗口窄"。

### 语言信号（中英双写）

- 「摩擦系数取多少」「$\mu$ 0.8 够不够」「湿路 $\mu$ 是多少」「冰面附着系数」
- 「$\mu_p$ 和 $\mu_s$ 有什么区别」「有 ABS 用哪个」「滑动数怎么换算」
- 「friction coefficient」「peak mu」「slide mu」「skid number」「ASTM E-274」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `longitudinal-slip-and-mu-s-curve`：本卡给"用哪个 $\mu$"的**取值**；那张卡给"工作点在峰前还是峰后"的**判读**与归因。
- 与 `mu-load-and-pressure-sensitivity`：本卡给基准值，那张卡给载荷/气压修正量。
- 与 `combined-slip-and-friction-circle`：本卡只给单通道 $\mu$；一旦纵向与侧向同时用，转那张卡（本章无解析式）。
- 与第 3 章 `brake-efficiency-table`（若已编译）：本卡给 $\mu$，那张卡算该轴把载荷用成制动力的比例。

## E — 可执行步骤 (Execution)

**必需输入**：用途（无 ABS 制动 / ABS 制动 / 驱动 / 极限侧向）、路面档（干/湿/冰/封层）、载荷 $W$。可选：SN 值、轮胎规格与磨耗、气压、是否台架值。**缺用途不得开算**——同一个"$\mu$"在四个用途下是四个数。

**交付物与完成标准**：一张"用途 → 身份 → 数值 → 适用域"四列表 + 一句口径声明。

1. **定身份**
   - 完成标准：写出四选一：$\mu_p$（ABS/极限侧向）、$\mu_s$（无 ABS 抱死）、曲线工作点的 $\mu(s)$（驱动打滑，$s$ 20%–60%）、SN（路面评分）。**判停**：用户要求"用制动台架值算极限侧向加速度" → 停，声明 $\mu_s$ 限抱死、$\mu_p$ 分三通道，二者不可互换。
2. **选路面档并给区间**
   - 完成标准：干 $\mu_p=0.70$–$0.90$（峰位 $s_p=15\%$–$20\%$）；湿 $\mu_p=0.25$–$0.50$（**峰位本章未给**）；冰 $\mu_p=0.10$–$0.15$（$s_p$"百分之几"）。**判停**：用户要求"湿路峰值滑动率" → 停；原文只说"湿路最大摩擦力是载荷的 25%–50%"，那是 $\mu_p$，不是 $s_p$。
3. **若有 SN，先换算再降级**
   - 完成标准：$\mu_s=$SN/100，并标"标准试验胎、抱死拖曳、规定洒水量"；干 81 / 波特兰水泥 45–50 / 湿 30 / Jennite 20–25。**判停**：把 SN 直接当本车 $\mu_p$ → 停。
4. **报三件套**
   - 完成标准：轮胎（规格/磨耗/气压）+ 路面（材质/湿度）+ 载荷条件，缺一不交付。
5. **声明能算什么**
   - 完成标准：写清"可算：最大制动力 $\mu W$、无 ABS 减速度 $\mu_s g$、法规定量对标；不可算：给定 $F_x$ 下的剩余 $F_y$（本章无解析式）、雪/砂石/赛道胶、胎温效应"。

**计算约定（本卡设定）**：$\mu$ 保留 2 位小数；区间取原文端点不取整；由 SN 换算时保留原文精度（SN 45 → 0.45，不写 0.450）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **用 $\mu_s$ 算驱动打滑或爬坡。** 驱动打滑的工作点在 $s=20\%$–60%，$\mu_s$（$s=100\%$）只是上界的粗略近似（ce08，p260 原文自述"仅能近似"）。
- **用 $\mu_p$ 算无 ABS 车的制动距离。** 抱死车够不到峰值，会系统性偏乐观（ce08）。
- **把"湿路 25%–50%"读成峰值滑动率。** 那是 $\mu_p$（占载荷比例）；湿路 $s_p$ 本章**未给**。这是本章最容易被转述污染的一处（coverage-audit §3-⑤ 记录了 5 处提取器犯此错，含任务书口径）。
- **把 $\mu$ 归给轮胎或归给路面。** "某型号轮胎的 $\mu$"、"这条路的 $\mu$"都不成立（ce07）。
- **用干路 $\mu$ 算湿路/冰面。** 差 2–8 倍，且峰位同时前移（ce06、ce10）。
- **把"高胎压抓地好"当通则。** 干路不明显、湿路才显著（ce11）。
- **把 $\mu(F_z)$ 当常数。** 载荷敏感性见 `mu-load-and-pressure-sensitivity`；本条与那条共用同一组 $\mu$，不得各取一半。

### 作者在书中警告的失败模式

- **ce05**：用一条 $\mu$–$s$ 曲线（通常干路）缩放/平移描述湿路与冰面——曲线是三参数结构（斜率/峰值/峰位），不是单参数。
- **ce06**：用干路 $\mu$ 算雨天/冰雪，制动距离偏短 2–3 倍。
- **ce07**：报 $\mu$ 不带轮胎与路面条件，跨路面比较用同一张轮胎表。
- **ce08**：ABS 车仍把 $\mu_s$ 当主设计指标；无 ABS 车按 $\mu_p$ 校核。
- **ce10**：把冰面操纵性差只归因"$\mu$ 小"，忽略"到峰窗口窄"（冰面 $s_p$ 只有百分之几）。
- **ce11**：把"提高胎压能增大 $\mu$"当通则，不分干湿。
- **ce12**：把滑动率（横轴）与滑动数（纵轴端点）混用；两者只在 $s=100\%$ 处相遇：SN/100$=\mu_s$。

### 作者的盲点 / 时代局限 / 原文硬伤（不得当正确结论）

- **$\mu_p$ 不唯一**：附录 A 7.6 给出侧向/驱动/制动三条通道，全部限"车轮未抱死"；$\mu_s$ 只限"抱死"。**因此不能用制动台架（抱死态）值去算极限侧向加速度**。
- **本章无温度变量**（全章 0 次把胎温当 $\mu$ 的因）；无雪/砂石/赛道胶。
- **p259 该段三处缺句首**（"路面本身是没有摩擦系数可言的"缺首字等），引用须修复但不改实义。
- **$\mu_s$ 的下标在 OCR 中全失**：p258"峰值摩擦系数（μ）和滑动摩擦系数（μ）"两个 $\mu$ 同名，靠上下文复原。
- **图 10.9 的车速修正只有曲线无系数**：$\mu(V)$ 不可定量，只能说"高速+厚水膜更危险"。

### 容易混淆的邻近方法论

- **$\mu_p$ vs $\mu_s$ vs SN**：峰值 / 抱死 / 路面评分，三个工作点。
- **滑动率 $s$（%）vs 滑动数 SN**：横轴 vs 纵轴端点；都乘 100，但一个是自变量。
- **"占载荷的 25%–50%"（$\mu_p$）vs "滑动率 25%–50%"（$s$）**：数值可以相同，物理量完全不同；本章湿路只给了前者。
