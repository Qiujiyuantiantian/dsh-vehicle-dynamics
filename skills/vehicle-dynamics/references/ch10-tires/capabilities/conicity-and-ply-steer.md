# 跑偏归因：正反滚动两次测量，半差 = 圆锥度、平均 = 帘布层转向

## R — 原文 (Reading)

> **原书要点**（p275）：把轮胎反过来滚、对照前行与后行两个方向，圆锥度便体现为零侧偏角下这两个方向侧向力之差。
>
> **原书要点**（p276）：正反两个滚动方向上侧向力的均值并不为零，这个均值也就是帘布层转向所带来的侧向力偏移量。
>
> **原书要点**（p276）：圆锥度受胎压影响明显，可借调整气压把它压下来；至于帘布层转向力，可行的对策是让方向盘的居中位置预先偏置一点来抵消。
>
> **原书要点**（p274–276：10.10 节）：圆锥度与帘布层转向这两部分内容，另见图 10.25 和图 10.26。

## I — 方法论骨架 (Interpretation)

一句话：**零侧偏时 $F_y$ 不为零，这个残差由两个分量组成——随滚动方向**变号**的是圆锥度（半差），**不变号**的是帘布层转向（平均）；两者处置不通用：圆锥度可"改"（气压/轮辋转位/换位），帘布层转向只能"补"（转向盘平衡位置偏移）。**

- **判据本质是奇偶分解**：$F_y(+V)$ 与 $F_y(-V)$ 两次测量。奇部（半差）$=(F_+-F_-)/2$ 是圆锥度；偶部（平均）$=(F_++F_-)/2$ 是帘布层转向。**两者都要 /2**——只需要"平均值"时天然带了 /2，只说"差值"时最容易被漏掉。
- **量级复算**：$F_+=+30$ lb、$F_-=-10$ lb ⇒ 帘布层转向 $=(30-10)/2=\mathbf{+10}$ lb，圆锥度 $=(30+10)/2=\mathbf{+20}$ lb。若照原文"差值"不加 /2 ⇒ 40 lb——**把两个分量加在一起**（ce37）。
- **成因不同**：圆锥度来自环带定位不对称等两侧微小差异（几何锥形），方向有随机性，可在轮辋上转位、换装胎位置、调气压来改变；帘布层转向来自帘线角不可能完全平衡，同一设计"大小和方向几乎一样"，转位不变。
- **后果不是抓地而是跑偏**：车要靠转向盘常备一个偏置力矩来平衡，表现为侧拉（pull）/跑偏（drift）、驾驶员疲劳；**四轮定位参数改不了这个零偏**（ce36）。
- **一个诊断捷径**：换位/换胎后跑偏方向改变 ⇒ 几乎可锁定轮胎；跑偏量随载荷变化（原文"大小均取决于垂直载荷"）、圆锥度随气压变化。
- 交付物：两个分量（lb）+ 一个处置方案 + "单向测量无法分离"的声明。

## A1 — 应用示例 (Application Example)

### 示例 1：一组正反读数（合成演练，非书中事实）

- **类型与来源**：**合成演练**。读数为假设，判据取 p275–276。
- **输入**：正向滚动 $F_y=+30$ lb，反向滚动 $F_y=-10$ lb（同一胎、同一载荷、近零侧偏）。
- **方法的使用**：①平均 $=(30+(-10))/2$；②半差 $=(30-(-10))/2$；③判处置。
- **结论/结果（复算值）**：帘布层转向 $=\mathbf{+10}$ lb；圆锥度 $=\mathbf{+20}$ lb。处置：$+20$ lb 的圆锥度先试调气压 → 轮辋上转位 → 换装胎位置；$+10$ lb 的帘布层转向只能做转向盘平衡位置补偿。**若把半差写成 40 lb**，就同时犯了"不除 2"与"把偶部混进奇部"两个错。

### 示例 2：换位后方向变了，说明什么（合成演练，非书中事实）

- **类型与来源**：**合成演练**。依据"圆锥度随装胎位置可变、帘布层转向转位不变"。
- **输入**：换位前松手向右跑；前后轮换位后改为向左跑。
- **方法的使用**：①跑偏方向随换位改变 ⇒ 主因是圆锥度（或胎位敏感项）；②若换位后方向不变、量也不变 ⇒ 主因是帘布层转向。
- **结论/预期输出**：方向变 ⇒ 走"调气压/转位/换位"路径；方向不变 ⇒ 走"转向盘平衡位置补偿"路径。**两条路径不通用**（ce38）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 新车/换胎后跑偏，四轮定位数据全部合格。
2. 保修争议：是轮胎问题还是悬架/定位问题。
3. 方向盘需要一直拉住才走直，问原因与处置。
4. 拿到正反两次滚动试验数据，要分离两个分量。
5. 想知道"调气压能不能修好跑偏"。

## E — 可执行步骤 (Execution)

**必需输入**：正向与反向滚动两次的 $F_y$（同一胎、同一载荷、近零侧偏、等速）。**只有单向数据不得开算**——两个分量无法分离。

**交付物与完成标准**：圆锥度（lb）+ 帘布层转向（lb）+ 处置方案 + 一句"两力都要 /2"。

1. **查条件**
   - 完成标准：同一胎、同一载荷、同一气压、$\alpha\approx0$、正反两向等速；若换过位/换过气压，须回到同一状态再测。**判停**：只有一次测量 → 停（ce37）。
2. **分离（两个 /2 都写出来）**
   - 完成标准：帘布层转向 $=(F_++F_-)/2$；圆锥度 $=(F_+-F_-)/2$；写出两个中间量。**判停**：结果等于 $F_+-F_-$ → 漏了 /2，退回。
3. **判方向与量级**
   - 完成标准：给出两个分量的符号（相对车轮坐标）与"合计 = 实测零偏"的核对（$F_+=$ 平均+半差）。
4. **选处置**
   - 完成标准：圆锥度 → 调气压（原文"比较敏感"但**无灵敏度系数**）→ 轮辋上转位 → 换装位置；帘布层转向 → 只能转向盘平衡位置补偿（或换设计）。**判停**：对帘布层转向开"调气压"处方 → 停（ce38）。
5. **交付**
   - 完成标准：一句话"圆锥度 +20 lb、帘布层转向 +10 lb；前者按气压/转位处理，后者只能补偿"，并声明本章**不给两力的量级范围与气压灵敏度**。

**计算约定（本卡设定）**：力保留 2 位有效数字；两个分量必须同时给，不给单分量；处置建议按"可改 / 只能补"分类。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **只做单向滚动就归因。** 两个分量在数学上不可分离（ce37）。
- **"差值"不除 2。** 会把圆锥度算成两分量之和（40 而非 20），处置随之全错。
- **把圆锥度与帘布层转向的判别量搞反。** 平均值 = 帘布层转向、半差 = 圆锥度；反了就会对不可修的分量开"调气压"处方（ce37/ce38）。
- **把跑偏当四轮定位问题。** 定位参数改的是几何，改不了零侧偏残差（ce36）。
- **对帘布层转向承诺"调气压能修好"。** 半条规律被当整条（nf14）；帘布层转向由帘线角定，转位不变、气压不是它的因。
- **把"圆锥度可由气压调整"当定量公式。** 只有方向，**无灵敏度系数**（多少 psi 抵多少 lb 不可算）。
- **把某次测量结果当轮胎型号的固有属性。** 圆锥度"方向具有随机性，由轮胎质量决定"，同型号不同条可以相反。

### 作者在书中警告的失败模式

- **ce36**：跑偏就做四轮定位、调前束；定位合格后换悬架件。
- **ce37**：差值/平均值互换；只测一个方向；以为两个量都要取绝对值。
- **ce38**：对帘布层转向开"调气压/换位"处方；以为圆锥度能靠一次换位永久消除。
- **nf14**：把"圆锥度可由气压调整"推广成"跑偏都能靠调气压解决"。

### 作者的盲点 / 时代局限 / 原文硬伤（不得当正确结论）

- **p274–275 的"变号"论证缺整句**："若滚动方向反向，则车轮前进方向变为朝下"被排版丢失——这是"圆锥度变号"的唯一推理。本卡按奇偶分解自行补全，并标注缺句。
- **p275–276 帘布层转向段缺句首**（条件句"如果前后轮帘布层转向力不平衡，会使……"），引用须注明。
- **两力的量级本章未给**（c10 如实登记"零数值"）；圆锥度对气压的灵敏度未给。
- **图 10.25/10.26 为示意**，无数据表。
- **样本为 1992 年轮胎**；现代胎的制造一致性已提高，但机理不变。

### 容易混淆的邻近方法论

- **圆锥度（奇部、变号）vs 帘布层转向（偶部、不变号）**：处置一个可改、一个只能补。
- **跑偏（胎的零偏）vs 车辙跟随（路推车）vs 定位角偏差（几何）**：三种"往一边跑"，判据分别是正反滚动 / 换路段 / 定位台。
- **"平均值"vs"差值"**：前者天然含 /2，后者必须显式 /2。
