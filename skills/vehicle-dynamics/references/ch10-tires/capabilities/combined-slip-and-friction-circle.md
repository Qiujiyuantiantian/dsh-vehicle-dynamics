# 复合滑动与摩擦圆：制动/驱动不对称的方向表 + 0.3g 最不利点 + 抱死顺序

## R — 原文 (Reading)

> **原书要点**（p273）：轮胎上作用制动性质的负纵向力时，侧向力略微抬头，回正力矩反而下降；制动力逼近极限，回正力矩甚至可能带上负号。
>
> **原书要点**（p273–274）：纵向力若换成中等大小的正驱动力，情形正好倒过来——侧向力稍降，回正力矩却明显上升；即便驱动力顶到极限，回正力矩也不会变为负的。
>
> **原书要点**（p274）：一边制动一边转向，当侧向加速度升到 0.3g 上下，制动能力会跌到最差。
>
> — 10.9（p272–274）；图 10.23/10.24

## I — 方法论骨架 (Interpretation)

一句话：**$F_x$ 与 $F_y$ 共用同一个 $\mu W$ 天花板（摩擦圆只是包络），但制动与驱动对 $F_y$、$M_z$ 的作用**不对称**——制动压 $M_z$、可致负；驱动抬 $M_z$、极限处也不为负。这条不对称就是"制动入弯比驱动出弯更危险"的轮胎层解释。**

- **能给的只有"方向 + 包络"，给不了"工作点"**：本章有摩擦极限不等式与圆/椭圆判断，**没有** $F_y(F_x)$ 的权重函数、没有椭圆参数。所以"给定 $F_x$ 还剩多少 $F_y$"**不可算**（G3，`needs_review`）。
- **4° 的反常项必须保留**：中等侧偏角（≈4°）、中等制动力时 $F_y$ **略增**。两个反向效应叠加——纵向力把胎体"绷紧"（刚度效应，$F_y$↑）与共享上限（上限效应，$F_y$↓）；中等输入时前者占优。到 8° 时已近峰值，上限效应一开始就压制刚度效应，所以反常只出现在 4°。
- **制动与驱动的差别在拖距方向**：制动时纵向剪应力朝后，把合力点往前拉（拖距缩短）⇒ $M_z$ 减；近极限拖距反号 ⇒ $M_z<0$ ⇒ **负 $M_z$ 试图增大侧偏角**（发散）。驱动时剪应力朝前，合力点后移（拖距加长）⇒ $M_z$ 显著增；几何上不反号。
- **宏观后果两条**：①制动+转向在侧向加速度约 **0.3g** 时纵向能力最低（不是越接近极限越糟，而是**中段交叉处**最差）；②接近极限时失控形态由**抱死顺序**决定——前轮抱死失转向、后轮抱死急剧回转。
- **0.3g 是经验值不是常数**：原文是"0.3g 左右"，轿车样本、干路。**本章没有"按 $\mu$ 缩放"的规则**，不得自拟 0.12g 之类（ce34 的错版即此）。
- 交付物：方向表（$F_x$ 正负 → $F_y$、$M_z$ 各怎么变）+ 包络判定 + "工作点不可算"的声明 + 0.3g/抱死顺序两条宏观结论。

## A1 — 应用示例 (Application Example)

### 示例 1：包络能说什么、不能说什么（合成演练，非书中事实）

- **类型与来源**：**合成演练（+ 原书引用数据）**。$W$、$\mu$、$F_x$ 为假设值；摩擦极限 $\mu W$ 与"圆/椭圆"判断取 p272，"先略增后降"取 p273。
- **输入**：$W=1000$ lb、$\mu=0.9$ ⇒ $\mu W=900$ lb；$F_x=450$ lb（制动）；$\alpha=4°$。
- **方法的使用**：①包络：$F_y\le\sqrt{(\mu W)^2-F_x^2}$；②若照此算，$F_y$ 上限只剩 0.866 倍；③但原文的实测趋势是 4°、中等制动力时 $F_y$ **略增**。
- **结论/结果（复算值）**：圆包络给 $F_y\le\mathbf{779}$ lb（$=\sqrt{900^2-450^2}$，**0.866×900**）。**但这不是答案**：真实曲线在该点先略增后降，包络只说明"不可能超过 900"。凡把 779 当工作点，就是把 ce35 的错版重演一遍。

### 示例 2：同一辆车，制动入弯 vs 驱动出弯（合成演练，非书中事实）

- **类型与来源**：**合成演练**。方向取原文，幅值不可算（原文只给方向）。
- **输入**：稳态 $\alpha=4°$、$F_y=700$ lb；情形 A 加 200 lb 制动力；情形 B 加 200 lb 驱动力。
- **方法的使用**：①A：$F_y$ 略增（约 +1%~3% 量级，原文只给方向）、$M_z$ 减小；②B：$F_y$ 略减、$M_z$ 显著增大；③两侧近极限：A 的 $M_z$ 可转负（发散），B 的 $M_z$ 仍为正。
- **结论/预期输出**：A 的 $F_y$ 约 **707–721 lb**（示意，非原文），$M_z$ 下降；B 的 $F_y$ 略低于 700。**不得给"$F_y$ 随 $F_x$ 的曲线"**——本章无解析式、图 10.23/10.24 无数据表。宏观结论只写"制动入弯更危险，因为 $M_z$ 可反号；驱动出弯的 $M_z$ 始终在稳定侧"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 弯道中同时制动/加速，问"还剩多少侧向力"。
2. 问"为什么制动入弯比驱动出弯更容易失控"。
3. ESC/TC 的分工依据、EBD 的分配目标。
4. 问"侧向加速度多大时制动性能最差"。
5. 事故归因：甩尾（后轮先抱死）vs 推头（前轮先抱死）。

### 语言信号（中英双写）

- 「弯道制动」「braking in a corner」「combined slip」「摩擦圆」「friction circle」
- 「有制动力侧向力还剩多少」「$F_y$–$F_x$ 曲线」「轮胎极限包络」
- 「制动入弯为什么危险」「驱动出弯更安全吗」
- 「0.3g 最不利」「先抱死哪个轮」「甩尾还是推头」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `mu-surface-selection`：那张卡给单通道 $\mu$ 的取值；本卡处理两通道争夺同一个 $\mu W$。
- 与 `lateral-force-three-regimes`：本卡假设纯侧偏的三段已成立，再叠加 $F_x$；三段边界会内缩，但本章无解析式。
- 与 `aligning-moment-three-sources`：本卡只讲"有 $F_x$ 时 $M_z$ 怎么变"，$M_z$ 的三来源与系数在那张卡。
- 与第 3 章抱死顺序/配比：本卡给轮胎层结论（前轴失转向/后轴甩尾），制动力分配与法规在那章。

## E — 可执行步骤 (Execution)

**必需输入**：$W$、$\mu$（说明是 $\mu_p$ 还是 $\mu_s$）、$F_x$（带符号：制动为负、驱动为正）、$\alpha$（或 $F_y$）、工况是否接近极限。**缺 $\mu$ 口径不得算包络**（$\mu_pW$ 与 $\mu_sW$ 差 10%–20%）。

**交付物与完成标准**：方向表（4 行）+ 包络值 + "工作点不可算"声明 + 两条宏观结论。

1. **算包络**
   - 完成标准：$\mu W$ 与 $\sqrt{F_x^2+F_y^2}$ 同时给出；结论写"上限"，不写"工作点"。**判停**：用户要求"给定 $F_x$ 的精确 $F_y$" → 停，声明 G3。
2. **判 $F_x$ 符号与量级**
   - 完成标准：制动（$F_x<0$）/驱动（$F_x>0$）/接近极限（$|F_x|>0.7\mu W$）三档；每档给出 $F_y$、$M_z$ 的方向。
3. **给四行方向表**
   - 完成标准：制动中等 → $F_y$ 略增、$M_z$ 减；制动近极限 → $F_y$ 降、$M_z$ 可负（发散）；驱动中等 → $F_y$ 略减、$M_z$ 显著增；驱动近极限 → 两者均减、$M_z$ 仍正。
   - **判停**：把制动/驱动当对称（奇函数）→ 停（ce32）。
4. **宏观结论**
   - 完成标准：写"0.3g 左右纵向能力最低（干路轿车经验值，本章无缩放规则）"+"抱死顺序决定失控形态"；**不得**写"0.3g 以下无损失"、**不得**自拟 0.12g（ce34 已判 needs_review）。
5. **交付**
   - 完成标准：一句话"$\mu W=900$、$F_x=450$ ⇒ 包络 $F_y\le779$，但工作点需实测；该点属中等制动、$F_y$ 略增段"，并声明本章无解析式。

**计算约定（本卡设定）**：力保留 3 位有效数字；方向结论必须带"原文只给方向"的标注；包络式只写在"$\le$"一侧。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **把 $F_y=\sqrt{(\mu W)^2-F_x^2}$ 当模型。** 它是候选在"圆假设"下的重排，**不是原文**；且与实测"先略增后降"矛盾，只能当上限包络（ce35、G3）。
- **以为本章给了复合滑动解析式。** 没有；椭圆参数也没给，不得自拟。
- **把制动与驱动当对称（奇函数）。** 用 $|F_x|$ 建单参数模型会把 $M_z$ 的符号与大小一起算错（ce32）。
- **用"有制动力 $F_y$ 必减"一刀切。** 4°、中等制动力时 $F_y$ 略增（ce33）。
- **把 0.3g 当普适常数。** 重卡、赛车、低 $\mu$ 路面都不适用；本章也没有"按 $\mu$ 缩放"的规则，**不得自拟 0.3×0.4≈0.12g**（ce34 的 correct_practice 已按 coverage-audit §5 删去该自造规则）。
- **把 $\mu$ 当各向同性真值。** 原文只说"两向极值相等才是圆"，专用胎是椭圆；$\mu$ 本身还随载荷变（nf06 的边界）。
- **用本卡算弯道制动的制动距离。** 本卡只到轮胎力；制动距离与配比在第 3 章。

### 作者在书中警告的失败模式

- **ce32**：制动/驱动当对称，从制动数据外推驱动。
- **ce33**：以为"有制动力 $F_y$ 必减"，把 4° 的反常项当噪声删掉。
- **ce34**：0.3g 当普适常数，或自拟按 $\mu$ 缩放的 0.12g。
- **ce35**：摩擦圆当解析式；$\mu$ 各向同性当结论。
- **ce28**（相关）：$M_z$ 在近极限可转负，与"正 $M_z$ 稳定"冲突。
- **ce27**（相关）：把 $M_z$ 的作用渠道搞错。

### 作者的盲点 / 时代局限 / 原文硬伤（不得当正确结论）

- **G3：复合滑动无解析式**（`needs_review`）：只有摩擦圆几何与图 10.23/10.24 的定性趋势。任何"给定 $F_x$ 求 $F_y$"的定量回答都是编造。
- **0.3g 无缩放规则**：原文只说"0.3g 左右"，未给按 $\mu$、车型、配比移动的规律。
- **$\mu$ 各向同性是作者的简化假设**，且他自己补了"专用胎是椭圆"却没给参数化。
- **p272 段末断句**（"时）发生的现象"）：该段条件句丢失，引用须注明。
- **图 10.23/10.24 无数据表**：只有定性趋势可引。
- **无胎温、无 ABS 循环频率**：瞬态与热效应不在本章。

### 容易混淆的邻近方法论

- **摩擦圆（包络）vs 摩擦椭圆（形状）vs 实测 carpet plot（工作点）**：三者信息量递增，本章只有前两者的定性。
- **制动 $F_x<0$ vs 驱动 $F_x>0$**：不是符号对称，$M_z$ 的符号行为完全不同。
- **0.3g（最不利点）vs 极限侧向加速度（$\mu$ 决定）**：一个是"纵向能力最低处"，一个是"侧向能力上限"。
- **前轮抱死（失转向、可救）vs 后轮抱死（甩尾、不可救）**：后果不对称。
