# 决策规则速查 — 《车辆动力学基础》第 8 章 转向系统

| 能力 | 一句话规则 |
|---|---|
| 转向盘转角→车轮转角：设计传动比 15:1–36:1，实测恒大于设计（货车 37→76） | 先问传动比是设计值还是实测值；设计口径给区间 $\delta\in[\delta_{sw}/(2i),\ \delta_{sw}/i]$，实测口径给单点，且只在低速用。 |
| 阿克曼内外轮转角（式 8-1）与低速自定心力矩行为（阿克曼单调增 / 平行转向先增后减可负） | 低速几何用 $\delta_i=\arctan\frac{L}{R-t/2}$、$\delta_o=\arctan\frac{L}{R+t/2}$（急弯回 arctan）；手感上阿克曼=阻力矩单调增、平行转向=先增后减可负，且自定心力矩≠$M_z$。 |
| 转向几何误差方向判定：纵向偏移→前束变化（两轮反向）、垂向偏移→侧倾转向（两轮同向） | 先钉基准（理想运动中心 = 球头弧线曲率中心，不是两臂交点）→ 偏移是横向还是垂向 → 后置横拉杆下低于→增不足、高于→多足（前置整体反号）→ 动作是改球头位置而非修装配。 |
| 侧倾转向的不足转向贡献：$K_{rollsteer}=\varepsilon\,d\phi/da_y$（ε 带符号，量纲 deg/deg） | $\varepsilon$ 是 deg/deg 且带符号（正=增不足），必须再乘 $d\phi/da_y$（deg/g）才是 deg/g；$\varepsilon$ 只能来自外部实测，图 8.7 零读数。 |
| 内倾项垂直力力矩 $M_V$（式 8-4 第一项）：与总载荷成正比、与左右载荷差无关、三个梯度旋钮 | $M_V=-\Sigma F_z\,d\sin\lambda\sin\delta$；只看 $d$、$\lambda$、轴荷三个旋钮，左右配重无效；这是几何自定心力矩，不是轮胎回正力矩 $M_z$。 |
| 侧向力经后倾的力矩（式 8-5）与回正力矩沿转向轴的分量（式 8-7） | $M_L=-(F_{yl}+F_{yr})r\tan\nu$（正后倾阻碍转向=增不足）；$M_{AT}=(M_{zl}+M_{zr})\cos\sqrt{\lambda^2+\nu^2}\approx$ 全额；正常驾驶总阻碍转向，只有紧急制动反向。 |
| 牵引力经主销偏距的力矩（式 8-6）与「制动经悬架、力臂就是 $d$」 | $M_T=(F_{xl}-F_{xr})d$（$F_x$ 向前为正、制动取负）；制动力臂就是 $d$（内侧制动 $d+r\sin\lambda$），驱动才是 $d+r\sin(\lambda+\zeta)$——套错就是 3 倍误差。 |
| 柔顺性不足转向增量 $K_{strg}=W_f(r\nu+p)/K_{ss}$ 与三口径换算（150 / 4 / ≈0） | $K_{strg}=W_f(r\nu+p)/K_{ss}$（$W_f$ 按「每 g 前轮载荷」读、$\nu$ 用 rad、本式不含 $M_V$）；必须同报 150/4/≈0 三口径，并附 $K_{ss}$ 敏感性（600→4.76、900→3.17）。 |
| 制动时的转向：轮胎后倾效应 ≡ 4°–8° 后倾角，制动力不平衡的「转向」放大 2–3 倍 | 自由滚动时轮胎回正力矩等效 4°–8° 后倾角；高制动系数下反向（过多转向）——但翻向阈值原文未给；对开路面制动的转向效应比直接力矩大 2–3 倍，方向由 $d$ 的符号定。 |
| 前驱五机制分解与净效果：四条推头 + 一条甩尾（$<0.5$），书报 4–5 deg/g 是取整 | ①$<0.5$ 过多、②≈1、③1–1.5、④0.5–1、⑤≈1（不足）→ 逐项和 3.0–4.5，书报 4–5 是取整汇总；加油门更推头，减小节气门整体反号。 |
| 四轮转向：$R=L/[\delta_f(1+\xi_{4WS})]$（ξ=0.5 减 1/3、ξ=1 减 50%），低速反向 / 高速同向 | $R=L/[\delta_f(1+\xi_{4WS})]$，$\xi=0.5$ 缩 1/3、$\xi=1$ 缩 50%，但先校验 $\delta_r=\xi\delta_f\le5°$；低速反向、高速（≥20 mph）同向小角度；轨迹偏移不给（式 8-17 残缺）。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
