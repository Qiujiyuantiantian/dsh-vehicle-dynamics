## 一句话主旨

**驾驶员转的是转向盘，车响应的是车轮转角，而这两者之间隔着传动比、杆系几何、悬架位移、转向轴倾角、轮胎力矩与柔顺性——这一章就是逐项算清「设计值被改了多少」，并指出哪些改动是运动学必然、哪些是可以调的设计杠杆。**

## 骨架（11 步递进：几何 → 悬架耦合 → 力与力矩 → 柔顺性 → 特例 → 主动扩展）

1. **转向系统的功能是把转向盘转角按传动比降到车轮转角**，而这个传动比随转角变化（轿车 15:1–20:1、货车 20:1–36:1），且**实测约为设计的两倍**（货车理论 37／实测 76）——“总是大于设计值”，影响的是低速操纵。
2. **阿克曼几何让内侧轮转角大于外侧轮**：$\delta_i=\arctan\frac{L}{R-t/2}$、$\delta_o=\arctan\frac{L}{R+t/2}$，$R$、$L$、$t$ 决定理想关系；实际靠**梯形布置**逼近，因为纯阿克曼与车轮会干涉（前置横拉杆要求球头外置）。
3. **阿克曼只影响低速自定心力矩**（正阿克曼使阻力矩随转角增大；平行转向在某一角度后阻力矩反而下降甚至变负），对高速方向响应影响很小。
4. **转向几何误差来自悬架运动**：转接杆系球头弧线若不跟随转向节臂弧线，车轮跳动就“自己转向”。判据只有一个自变量——**转接杆系内侧铰点相对「理想运动中心」偏在哪一侧**；横向偏移 → 前束变化（两轮反向），垂向偏移 → 侧倾转向（两轮同向）。
5. **理想运动中心由运动学决定**（球头弧线的曲率中心），**不等于**抗点头/抗后蹲的虚拟中心（两臂延长线交点）；用错基准，侧倾转向的符号会整体判反。
6. **前轮几何（主销内倾 $\lambda$、偏距 $d$、后倾角 $\nu$）决定转向力矩的大小与方向**：内倾 + 后倾使车轮转向时车轴升高，这是自定心力矩的来源；偏距是“把各种力折成转向轴力矩”的公共力臂。
7. **转向系统的力矩分四类**：垂直力（经 $d\sin\lambda$）、侧向力（经后倾纵向偏移 $r\tan\nu$）、牵引力（经 $d$）、回正力矩（沿转向轴分量 $\cos\sqrt{\lambda^2+\nu^2}\approx1$）。滚动阻力矩与翻转力矩是二阶量，作者声明忽略。
8. **转向柔顺性把“轮胎力矩”折成“转向盘转角”**：$K_{strg}=W_f(r\nu+p)/K_{ss}$，典型 4–6 deg/g——同一辆车，转向盘口径的不足转向梯度可以比车轮口径大一个数量级（150 vs 4，而直接测车轮近于 0）。
9. **制动时后倾角的作用会翻向**：自由滚动时轮胎回正力矩相当于 4°–8° 后倾角（不足转向），高制动系数下反向（过多转向）；同时俯仰会吃掉几度结构后倾角。制动力不平衡经柔性转向系统的“转向”效应比直接力矩大 2–3 倍，方向由偏距符号定。
10. **前轮驱动有五条额外路径**（合计 4–5 deg/g）：驱动推力侧向分量（**过多**，$<0.5$）、驱动轴力矩（≈1）、侧向力损失（1–1.5）、回正力矩增量（0.5–1）、前后载荷转移（≈1，FWD/RWD 皆有）。净效果是**加油门更推头**；其中 2–4 项产生力矩反馈 = torque steer 的主因；差速器摩擦 10%–15% 未计入。
11. **四轮转向分两段用**：低速后轮反向（$\xi_{4WS}=0.5$ 减 1/3、$1$ 减 50%，后轮一般 ≤5°），高速后轮同向小幅（原文举例 ≥20 mph，收益只在瞬态：横摆振荡、侧滑角）。

**论证链**：传动比 → 阿克曼 → 悬架耦合（前束变化/侧倾转向）→ 前轮几何 → 四类力矩 → 柔顺性模型 → 影响因素实例（传动比、不足转向、制动）→ 前驱五机制 → 四轮转向。

## 核心命题（用自己的话）

1. 传动比不是常数，实测恒大于设计（约 2 倍），因为它把柔顺性也算了进去。
2. 阿克曼是**低速**问题：它决定内外轮转角差与满舵手感，几乎不影响高速方向响应。
3. 悬架一跳，转向就变——这是**运动学必然**，不是装配缺陷；能改的只有球头位置。
4. 侧倾转向的**符号**决定它是帮忙还是帮倒忙（铰点低于理想中心点→增不足，高于→过多；前置横拉杆整体反号）。
5. 柔顺性会把不足转向梯度放大一个数量级：车轮口径 4 deg/g、转向盘口径 150、直接测车轮 ≈0——三个数同车、同时为真。
6. 后倾角在制动时“反水”：常规更稳，紧急制动时可能显著降低或完全消失。
7. 前驱五条路径里只有一条是过多转向，其余四条都是不足转向——净效果加油门更推头。
8. 四轮转向低速与高速用**相反**的后轮方向；高速收益只在瞬态，稳态觉察不到。
9. 口径比数值重要：转向盘／车轮、设计比／实测比、$K_{ss}$／$K_\phi$、$M_V$／$M_z$、$\xi_{4WS}$／别章 $\xi$——每一条错都能静默通过。

## 数值锚点（供对账用；全部为本 Bundle 的复算/引用值）

- 转向传动比：轿车 **15:1–20:1**、货车 **20:1–36:1**；**实测≈设计 2 倍**（货车理论 37 → 实测 76，2.05×）。$i=36$、$\delta_{sw}=360°$ → 设计口径 10.0°、区间 5.0–10.0°。
- 阿克曼：$L=100$、$t=60$、$R=400$ in → $\delta_i=15.12°$、$\delta_o=13.09°$、差 2.03°；$R=100$ in 时线性式误差 49%。
- 主销内倾：货车 **0–5°**、轿车 **10–15°**；后倾角 **0–5°**；偏距正 = 车轮在地面交点**外侧**。
- 内倾项 $M_V$：$d=1$ in、$\lambda=10°$、1400 lb → $\delta=45°$ 时 **−171.9 in·lb**；$\delta=15°$ 时 −62.9；单轮 800 lb、45° 时 −98.2；左右 700/700 结果不变。
- 侧向力经后倾：$F_y=1000$ lb、$r=15$ in、$\nu=3°$ → $M_L=$ **−786.1 in·lb**。
- 回正力矩沿轴：$M_z=200$ in·lb、$\lambda=10°$、$\nu=3°$ → $M_{AT}=$ **196.7**；$\lambda=15°$、$\nu=5°$ → **192.4**（因子 0.962–1.000）。
- 牵引力经偏距：$F_{xl}-F_{xr}=800$ lb、$d=1.5$ in → $M_T=$ **1200 in·lb**；平衡工况 0。
- 制动力臂：外置制动 $=d$（$500\times1.5=$ **750** in·lb）；误用驱动力臂 $d+r\sin(\lambda+\nu)=4.874$ in → **2437**（**3.25 倍**）；内侧制动 $d+r\sin\lambda=4.105$ in。
- 柔顺性：$W_f=1800$ lb、$r\nu+p=1.5854$ in、$K_{ss}=600$ → $K_{strg}=$ **4.76 deg/g**；$K_{ss}=900\to$ **3.17**；$450\to$ **6.34**；$\nu$ 误用度数 → **137** deg/g。
- 三口径（同一辆货车）：**150 deg/g（转向盘）/ 4 deg/g（÷36 折算，$150/36=4.17$）/ ≈0（实测车轮）**；柔顺性差额 ≈4 deg/g。
- 前驱五机制：**$<0.5$（过多）/ ≈1 / 1–1.5 / 0.5–1 / ≈1（不足）** → 逐项和 **3.0–4.5**（中点 3.6），书报 **4–5**；差速器摩擦 **10%–15%**。
- 制动：轮胎后倾效应 ≡ **4°–8°** 后倾角（$t_p=1.05$–$2.11$ in，$r$ 的 7%–14%）；制动力不平衡放大 **2–3 倍**。
- 四轮转向：$\xi_{4WS}=0.5$ → $R$ 减 **1/3**；$=1$ → 减 **50%**；后轮 **≤5°**；低速反向、高速（≥**20 mph**）同向。$L=100$ in、$\delta_f=6°$、$\xi=0.5$ → $R=$ **636.6** in（基准 954.9，缩 33.3%），$\delta_r=3°$。

## 六处口径与硬伤（下游一律按此处理，不擅自改原文）

1. **式(8-4) 内部冲突（最重要）**：第二项在公式块写 $\sin\delta$，同段正文与图 8.14 图注写 $\cos\delta$ → **后倾项不可用**（定性可以、定量不行）；本 Bundle 只算式(8-4) **第一项**（内倾项，三处写法一致）。
2. **式(8-17) 残缺**：只剩 $L^2(1-\ ^2)$，$\xi$ 幂次与分母丢失 → **严禁补全**；只给两个边界（$\xi=0$ 退化为式 6-4、$\xi=1$ 为 0）。
3. **式(8-9)~(8-12) 力臂不自洽（本轮新增 #18）**：式内 $d+r\sin(\lambda+\zeta)$ vs 正文“$\zeta=0$ 时力臂 $=d$”，$\lambda\neq0$ 时不成立 → 不可用该式复算；前驱机制②只引文献估值 ≈1 deg/g。
4. **自定心力矩 ≠ 回正力矩**（作者自己埋的歧义）：前者几何项（$M_V$，不进 K、低速、与载荷差无关）；后者轮胎项（$M_z$，进式(8-8)、制动会变号）。
5. **$K_{ss}$ vs $K_\phi$**：同单位 in·lb/deg、量级可比，**代错不报错**；式(8-8) 只接受 $K_{ss}$。
6. **理想中心点 ≠ 抗点头/抗后蹲虚拟中心**：沿用第 7 章作图法会让侧倾转向符号**整体判反**。
   另：$\xi$ 全书四章四义（第 1/2/7/8 章，第 3 章无 $\xi$），本章一律写 $\xi_{4WS}$ 且**可负**；图 8.18/8.19/8.20/8.24/8.25 无数据表 → **零读数**；小角度近似**原文从未给角度上限**；$p$ 是轮胎拖矩（in）不是压力；8.8.4 把前驱写成“AWD”是笔误。

## 批判与时代局限（B 段素材来源）

- **1992 年液压/机械视角**：无 EPS、无线控转向；四轮转向是机械/液压方案（本田 Prelude 类），无现代电控后轮转向、无扭矩矢量、无车道保持介入。
- **只讲一个指标**：几乎全部公式围着“不足转向”转，转向手感/中心感/回正速度只提了一句“由车辆制造商评估”。
- **四个未被证明的假设**：小角度近似贯穿全章；柔顺性用集中刚度 $K_{ss}$ 代表分布柔度；侧倾转向按线性系数 $\varepsilon$；轮胎力矩全按准静态（无松弛长度）。
- **最强反对意见**：“本章把转向系统拆成一堆可加的力矩与小角度线性化，但真实手感是强非线性的（摩擦、间隙、助力曲线），可加性在中心区附近最不可靠——而那正是驾驶员最敏感的区域。”作者的防线：他明确把模型定位为“适合描述低频特性的简单模型”，并把柔顺性作为“集中”参数处理。
- **作者自己的破口**：$K_{ss}$、$p$、$\varepsilon$、$F_y$、$d\phi/da_y$ 全部没有取值法或数值；$W_f$ 的“每 g”读法是量纲必需但原文未明说。
