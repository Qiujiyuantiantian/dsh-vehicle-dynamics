# 牵引力经主销偏距的力矩（式 8-6）与"制动经悬架、力臂就是 $d$"

## R — 原文 (Reading)

> **原书要点**（p225 §8.5.3 图8.16）：纵向的驱动力落在主销偏距这个力臂上，同样绕转向轴拧出一个力矩，两轮合起来即式(8-6)；图8.16 画的正是这套几何。
>
> **原书要点**（p225 §8.5.3 式8-6）：两侧纵向力之差乘上主销偏距，就是绕转向轴的合力矩，符号随差值的正负而变：$M_T=(F_{xl}-F_{xr})\,d$。
>
> **原书要点**（p225 §8.5.3）：$F_{xl}$、$F_{xr}$ 是两轮各自的纵向力，朝前取正。正常时左右拧出的力矩方向相抵，经拉杆传到方向盘上大体抵消；一旦两侧不再对等——爆胎、制动器失灵、或压在左右附着不同的路面上——就会冒出一股大小随侧向偏距走的转向力矩。
>
> **原书要点**（p230 §8.8.1 括注）：制动这一路的力矩不是从半轴进来的，它经由悬架杆件反传到车身，因此力臂取的就是接地点到主销的那段侧向偏距；若把制动器挪到内侧，力臂也只多出轮胎半径乘内倾角正弦那一小段。
>
> — 8.5.3 p225，式(8-6)，图 8.16；8.8.1 p230 括注（中译本）

## I — 方法论骨架 (Interpretation)

一句话：**纵向力（牵引或制动）在左右不等时，会绕转向轴形成一个力矩，力臂就是主销偏距 $d$；但“驱动”和“制动”的力臂规则不同——制动力矩经悬架反作用，力臂就是 $d$（内侧制动是 $d+r\sin\lambda$），绝不是驱动力臂 $d+r\sin(\lambda+\zeta)$。**

- 平衡工况下 $M_T=0$：左右牵引力相等 → 两侧力矩方向相反、经杆系相抵。这是“直线大油门方向盘不跑”的原因。
- 不平衡只有三个源（原文清单，避免无限排查）：**轮胎爆胎、制动器故障、对开附着系数路面**。三者共同点是左右纵向力不等。
- 方向：$d>0$（车轮在交点外侧）时，力矩指向**纵向力大的一侧**；$d$ 换符号，方向翻。这就是“负偏距可以抵消对开路面制动偏转”的机制（见 `braking-caster-and-split-mu`）。
- 力臂规则（本卡的第二半，也是 8.8 的护栏）：
  - **驱动**：力臂是 $d+r\sin(\lambda+\zeta)$（$\zeta$ 为半轴倾角）——“驱动力作用在轮心”的修正项。
  - **制动（外置）**：力臂**就是 $d$**。原因是制动力矩经悬架反作用，不经过半轴。
  - **制动（内侧制动）**：力臂是 $d+r\sin\lambda$——只有 $\lambda$、**没有 $\nu$**（原因原文未说，属推断）。
- 这个区别不是学术细节：在 $d=1.5$ in 这种小偏距上，误用驱动力臂会把力矩算成 3.25 倍（见 A1 探针）。而“3 倍量级”的错误不会触发任何量纲检查。
- 本卡**不**使用式(8-9)~(8-12)。那组式子的力臂写 $d+r\sin(\lambda+\zeta)$，与同一段正文“当半轴为水平时（$\zeta=0$）……力臂等于轮心偏距 $d$”在 $\lambda\neq0$ 时**不自洽**（硬伤 #18）→ 该式不可用于复算；本卡只取“三种情形的力臂口径”这一层结论。

## A1 — 应用示例 (Application Example)

### 示例 1：平衡与非平衡（合成演练，非书中事实）

- **类型与来源**：**合成演练**。原书未给式(8-6) 的数值算例。
- **输入**：$d=+1.5$ in；工况①正常行驶 $F_{xl}=F_{xr}=500$ lb；工况②对开路面制动 $F_{xl}=800$ lb、$F_{xr}=0$ lb。
- **方法的使用**：①$M_T=(500-500)\times1.5$；②$M_T=(800-0)\times1.5$；③方向判读：指向纵向力大的一侧。
- **结论/预期输出**：工况① $M_T=\mathbf{0}$；工况② $M_T=\mathbf{1200}$ in·lb，方向指向高附着侧（$d>0$）。
- **灵敏度探针**：$d$ 加倍 → 力矩加倍（与“和侧向偏距大小相关”一致）；$d\to-1.5$ in → 力矩反号（这就是负偏距对策的机制）。

### 示例 2：驱动 vs 制动，力臂差 3.25 倍（合成演练，非书中事实）

- **类型与来源**：**合成演练**。原书只给一句括注，未给数值对比。
- **输入**：单边 $F_x=500$ lb（制动，取负值）、$d=1.5$ in、$r=15$ in、$\lambda=10°$、$\nu=3°$。
- **方法的使用**：①制动力臂 $=d=1.5$ in；②误用驱动力臂 $d+r\sin(\lambda+\nu)=1.5+15\sin13°=4.874$ in；③内侧制动臂 $=d+r\sin\lambda=1.5+15\sin10°=4.105$ in。
- **结论/预期输出**：制动 $M=\mathbf{750}$ in·lb；误用驱动臂 $M=\mathbf{2437}$ in·lb（**3.25 倍**）；内侧制动 $M=\mathbf{2052}$ in·lb（臂 4.105 in）。
- **判读**：偏距越小，误用驱动臂的相对误差越大（$d=1.5$ in 时 3.25 倍；$d$ 越大越接近 1 倍）——所以“小偏距车”最容易被这个错法坑到。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 对开路面（冰/沥青、积水、油污）制动跑偏，要算激励力矩并判方向。
2. 直线大油门方向盘被拉扯（torque steer），要判是几何必然还是零件故障。
3. 讨论“负偏距（磨胎半径反号）能不能治制动跑偏”，要给出机制与代价。
4. 转向系统力矩账里“牵引力项”占多少，或核对称工况下这一项是否应为零。
5. 有人直接用驱动力臂公式套制动工况，需要拦住这 3 倍量级的错。

### 语言信号（中英双写）

- 「刹车往一边跑」「对开路面制动」「大油门方向盘被拽」「负偏距有用吗」「磨胎半径改小」
- 「split-μ」「split coefficient surface」「torque steer」「tractive force moment」「scrub radius」「brake steer」
- 变体：「制动跑偏」「制动器故障」「对角线双回路失效」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `braking-caster-and-split-mu`：本卡算**直接力矩** $M_T$；那张卡给“该效应的转向放大 2–3 倍”（至少再乘 2–3 倍）与轮胎后倾效应 4°–8°。顺序：先本卡得 $M_T$，再过那张卡得等效激励。
- 与 `caster-and-aligning-torque`：本卡用**纵向力**；那张卡用**侧向力**与**回正力矩**。同一个 $d$ 在两边都是力臂，但力源与符号规则不同。
- 与 `kingpin-inclination-self-centering-moment`：本卡是“左右不等才有力矩”（差动型）；那张卡是“总载荷乘内倾角”（共模型，左右差无关）。两者对“载荷对称”的敏感度正好相反。
- 与 `fwd-five-mechanisms`：本卡是前驱机制②（驱动轴力矩）的**力臂口径**来源；机制②的量级只能引文献估值 ≈1 deg/g，不可用式(8-9)~(8-12) 复算。

## E — 可执行步骤 (Execution)

**必需输入**：$F_{xl}$、$F_{xr}$（lb，**向前为正**；制动时取负）、$d$（in，正 = 车轮在地面交点外侧）、工况类型（驱动 / 外置制动 / 内侧制动）。
**可选**：$r$、$\lambda$、$\nu$、$\zeta$（仅在需要给“驱动力臂”或“内侧制动力臂”时）。

**交付物与完成标准**：$M_T$（in·lb，带符号）+ 方向判读（指向哪一侧）+ **力臂口径声明**（驱动 / 外置制动 / 内侧制动）+ 一句“2–3 倍放大另计”。

1. **定符号约定**
   - 完成标准：写“$F_x$ 向前为正；制动取负值”。若用户给的是制动力大小（正值），显式加负号并注明“制动情形原文未给符号用法，属同构外推”。
2. **选力臂口径（本卡唯一的分叉点）**
   - 判据：驱动 → $d+r\sin(\lambda+\zeta)$；外置制动 → **$d$**；内侧制动 → $d+r\sin\lambda$。
   - 完成标准：写出一行“工况=__，力臂=__ in，口径来源=原文括注/推断”。
   - 判停：若用户要用式(8-9)~(8-12) 复算驱动力矩 → **停**：该式力臂与“$\zeta=0$ 时力臂$=d$”不自洽（硬伤 #18），只可引用其“量级≈1 deg/g”的文献估值。
3. **算力矩**
   - 完成标准：$M_T=(F_{xl}-F_{xr})d$；同时给出 $|M_T|$ 与方向（指向纵向力大的一侧，$d>0$ 时）。
   - 自检：左右相等 → 0（这是原文“经杆系趋于平衡”的定量版）。
4. **判触发源是否在三源清单内**
   - 完成标准：爆胎 / 制动器故障 / 对开附着系数路面——三选一或多项；若都不在，说明还有别的机理，不要硬套本式。
5. **标注放大与后续**
   - 完成标准：写“本 $M_T$ 是直接力矩；该效应的转向放大为 2–3 倍（见 `braking-caster-and-split-mu`），本卡不重复计入”。
6. **交付**
   - 完成标准：一句话形如“对开路面 $F_{xl}=800$、$F_{xr}=0$ lb、$d=+1.5$ in → $M_T=1200$ in·lb 指向高附着侧；若改用负偏距 $d=-1.5$ in 则方向翻转；力臂取 $d$（制动经悬架）”。

**计算约定（原书未规定，本卡设定）**：$M_T$ 保留 1 位小数（in·lb）；$d$ 保留 2 位小数（in）；方向用“指向高/低附着侧”或“指向 $F_x$ 大的一侧”表述，不用“左/右”（左右取决于坐标系）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **用式(8-9)~(8-12) 复算驱动力矩**（硬伤 #18）：式内力臂 $d+r\sin(\lambda+\zeta)$ 与同段正文“半轴水平（$\zeta=0$）时力臂 $=d$”在 $\lambda\neq0$ 时不自洽 → 该式不可用于定量；机制②只能引文献估值 ≈1 deg/g。
- **把制动工况套进驱动力臂**：制动力矩经悬架反作用，力臂就是 $d$；套式(8-12) 会多算 $r\sin\nu$ 一项，小偏距车上误差可达 3 倍以上（见 A1）。
- **用“制动力 × 偏距”直接算跑偏**（ce14）：本卡给的 $M_T$ 只是直接力矩，实际“转向”效应比它大 2–3 倍（柔性转向系统放大）；按 $M=F_x d$ 估跑偏会系统性低估。
- **把 torque steer 当转向系统故障去修**（ce16）：力臂随半轴倾角与车身侧倾变化，是驱动几何与侧倾的必然产物；换转向机、加阻尼解决不了，原文给的两条方向是**降侧倾**与**提 $K_{ss}$**。
- **以为左右力矩一定“可加”**：原文只说“通过转接杆系趋于平衡”，是刚体杆系假设，未论证可加性；左右不等时只能给量级与方向。
- **把滚动阻力矩/翻转力矩补进来**（ce12）：作者声明忽略；补项会与本章锚点不自洽。
- **在平衡工况下索要非零结果**：左右 $F_x$ 相等时 $M_T$ 必须为 0；若算出非零，先查 $d$ 是否被当成“左右各一个”（$d$ 是每轮的力臂，差值已含左右）。

### 作者在书中警告的失败模式

- ce14：对开路面制动的“转向”效应比直接力矩大 2–3 倍；只调制动器平衡、不知道偏距符号本身是设计杠杆，等于放弃一个自由度。
- ce16：驱动力矩的力臂是 $[d+r\sin(\lambda+\zeta)]$，直线时 $\zeta=0$、力臂 $=d$、左右相抵；转向时侧倾使外侧半轴角减小、内侧增大 → 左右力臂不等 → 净力矩 → 拉扯 + 不足转向增量。
- ce12：二阶力矩只在转向轴上产生正弦分量，不要用来凑账。

### 作者的盲点 / 时代局限

- 力臂 $d+r\sin(\lambda+\zeta)$ 的**印刷形式存疑**（OCR 把“$\zeta$”与“$=$”吞掉，正文出现“rsin（入十)”的断句）→ 只能确认“三种情形力臂不同”这层结论，不能确认 $\zeta$ 的精确幂次/符号。
- 内侧制动力臂 $d+r\sin\lambda$ 只有 $\lambda$ 没有 $\nu$，**原因原文未说**，属推断；外置/内置制动的判别标志原文也未给。
- 式(8-6) 未含滚动阻力矩（8.5.5 明说忽略）；爆胎工况的 $F_x$ 变化与轮胎半径变化原文未建模。
- 1992 年语境：无 ABS/ESC，对开路面靠负偏距；现代车多用 ESC 的横摆控制取代，本卡的机制仍在但对策不同。

### 容易混淆的邻近方法论

- **$d$（侧向偏距） vs $r\tan\nu$（后倾拖距）**：一个横向、一个纵向；本卡用前者，`caster-and-aligning-torque` 用后者。
- **直接力矩 $M_T$ vs 放大后的等效激励（2–3 倍）**：前者可算，后者是估算区间；两者不可相加，也不可互相替代。
- **驱动力臂 vs 制动力臂**：同一根转向轴、同一个 $d$，但驱动经半轴、制动经悬架，力臂差一项 $r\sin\nu$——这是“3 倍量级错误”的来源。

- **若用户问的是"方向盘要多大劲"**：本卡给的是**路面/车轮处**的力矩，折到转向盘还要除传动比 —— $M_{sw}\approx M_{wheel}/i$（$i$=转向传动比，轿车 15–20:1、货车 20–36:1，见 `steering-ratio-and-wheel-angle`）。本章**未给转向系统效率**，故只能给量级；**不可反过来**由"手劲"推车轮力矩。
