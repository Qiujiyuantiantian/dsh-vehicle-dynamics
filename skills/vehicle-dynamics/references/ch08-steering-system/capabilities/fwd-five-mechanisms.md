# 前驱五机制分解与净效果：四条推头 + 一条甩尾（$<0.5$），书报 4–5 deg/g 是取整

## R — 原文 (Reading)

> **原书要点**（p229–230 §8.8.1–8.8.2）：前驱车踩下油门时，第一条路子是驱动力本身带出的横向分力，方向上属过多转向，量很小——不到 0.5 deg/g；第二条路子是驱动力绕转向轴形成的扭矩，方向反过来，属不足转向，量级约 1 deg/g。
>
> **原书要点**（p229–231 §8.8）：3）侧向力损失——根源在轮胎的特性，方向为增加不足转向，量级 1～1.5 deg/g。4）此外，回正力矩增量同样出自轮胎，约 0.5～1 deg/g，方向也是不足转向。5）再有，前、后载荷转移——无论 AWD 还是 RWD 车都会遇到，其效果一律把车推向不足转向，约 1 deg/g。
>
> **原书要点**（p229–232 §8.8）：把这些效应叠加，总计不足转向约 4～5 deg/g。其中几项（约 2～4 种机制）会把力矩回灌到转向机构，这通常被公认为前驱车力矩转向的主因。
>
> **原书要点**（p229–232 §8.8）：还有一点值得留意：传动系带载运转时，差速器内部的摩擦可占到 10%～15%，并不算小。书中前面没有讨论它，但在某些工况下，它会给前驱车踩油门→更不足转向这一现象再添一份贡献。
>
> **原书要点**（p229–232 §8.8）：通常踩深油门会让车更偏不足转向，而收油则反过来推向过多转向。
>
> — 8.8 引言 p229；8.8.1–8.8.4 p229–231；8.8.5 p231–232（中译本）

## I — 方法论骨架 (Interpretation)

一句话：**前驱车踩油门会多出五条转向路径——四条把车推向不足转向、一条（最小的）推向过多转向——净效果是“加油门更推头”，量级 4–5 deg/g；但那是取整后的汇总，逐项相加只有 3.0–4.5，不能拿去和别的 deg/g 做减法对账。**

- 五条路径的分工（本书最重要的“反直觉”结论）：
  1. **驱动推力侧向分量**：$<0.5$ deg/g，**过多转向**——唯一的甩尾项，也是最弱的一项。
  2. **驱动轴力矩（绕转向轴）**：≈1 deg/g，不足转向。$\propto 1/K_{ss}$，所以“加强转向刚度 + 减小车身侧倾”是它唯一的两条设计杠杆。
  3. **侧向力损失**（牵引力吃掉侧偏刚度）：**汇总口径 1–1.5 deg/g**，不足转向。注意 8.8.2 单节给的是“0.2 g 加速 → 0.05 g 减速 ⇒ 0–2 deg/g”的**跨度量**，不是单值；汇总时必须用 1–1.5。
  4. **回正力矩增量**（牵引力抬高 $M_z$）：0.5–1 deg/g，不足转向。其大小 $\propto \Delta M_z/K_{ss}$。
  5. **前/后载荷转移**：≈1 deg/g，不足转向。**FWD 与 RWD 都有**（作者自己括注），所以**不能拿它论证“前驱特有”**。
- 加法规则：不足转向取正、过多转向取负。下限 $1+1+0.5+1-0.5=3.0$；上限 $1+1.5+1+1-0=4.5$。中点（各取中值）$1+1.25+0.75+1-0.4=3.6$。
- **不闭合的原因**：书报 4–5 的上限 5.0 比逐项和上限 4.5 高 0.5，下限 4.0 比逐项和中点 3.6 高 0.4 → 差额量级与“差速器摩擦 10%–15% 的附加影响”（作者明说未计入）相容，也与“各条本身是取整的典型值”相容。所以：**方向可判、程序可执行、净值精度只有 ±1 deg/g 级**。
- 归因边界：torque steer 只归到**机制 2–4**（力矩反馈回转向系统的那几项），且验证数据应是**转向盘力矩**，不是横摆角速度——用横摆角速度去验证 torque steer 是口径错。
- 油门方向：以上全部是“加大节气门”的口径；**减小节气门开度则整体反号**（过多转向）。所以“五条推头”不能脱离“加油门”这个前提单独引用。

## A1 — 应用示例 (Application Example)

### 示例 1：五条机制的代数相加（原书估算值 + 本卡演算）

- **类型与来源**：**原书估算汇总**（8.8.5 p231–232 逐条量级 + “全部不足转向约为 4～5 deg/g”）；加法与不闭合校验由本卡完成（作者只给结论，未逐项列算式）。
- **输入**：机制①$-0.5$…$0$；②$+1$；③$+1$…$+1.5$；④$+0.5$…$+1$；⑤$+1$（单位 deg/g）。
- **方法的使用**：①下限 $1+1+0.5+1-0.5$；②上限 $1+1.5+1+1-0$；③中点 $1+1.25+0.75+1-0.4$；④与书报 4–5 比。
- **结论/结果（复算值）**：逐项和 **3.0–4.5** deg/g；中点 **3.6**；书报 **4–5**。
- **不闭合判定**：4.0（书报下限）− 3.6（逐项中点）= **+0.4**；5.0（书报上限）− 4.5（逐项上限）= **+0.5** → 不闭合量级 ≈0.4–0.5 deg/g，与“取整 + 差速器摩擦未计入”相容。**不得**据此反推“差速器摩擦正好等于 0.5 deg/g”。
- **用途**：任何引用“4–5 deg/g”的场合，都必须同时给出 3.0–4.5 这个逐项和，否则读者会把它当精确值去做减法。

### 示例 2：换一个油门工况（合成演练，非书中事实）

- **类型与来源**：**合成演练**。自设 FWD 车，工况从“节气门 0.2 g 加速”切到“0.05 g 减速”（对应 8.8.2 的跨度条件），用于演示“方向反号 + 量级不变”。
- **方法的使用**：①确认工况方向（加速 → 四条推头、一条甩尾）；②减速则全部反号；③机制③的跨度 0–2 deg/g 只作“跨度”看待，汇总仍取 1–1.5。
- **结论/预期输出**：加速工况净 **+4–5**（不足转向）；减速工况净 **−4–5**（过多转向）。**同一台车、同一套机制，方向相反**。
- **判读**：这就是“松油门才更容易甩”的定量来源；反过来，任何“前驱车大油门甩尾”的经验法则都是 ce15。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 问“前驱车大油门为什么会推头/为什么会甩”，需要一次讲清五条路径与净方向。
2. 大油门方向盘被拉扯（torque steer），要判归因（机制 2–4）与两条缓解方向。
3. 标定/调校油门相关的转向特性，需要知道哪几条可动、动哪条最有效。
4. 有人拿“4–5 deg/g”与其它来源的 deg/g 做减法，需要提醒它不闭合。
5. 讨论 FWD vs RWD 的转向差异，需要把“两者都有”的机制⑤剔出去。

### 语言信号（中英双写）

- 「前驱大油门推头还是甩尾」「torque steer 怎么治」「五条机制」「4–5 deg/g 怎么来的」「差速器摩擦有影响吗」
- 「FWD understeer」「throttle-induced understeer」「torque steer」「tractive force effect」「lateral force loss」「load transfer front/rear」
- 变体：「加油门更推头」「松油门甩尾」「前驱转向特性」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `tractive-force-and-brake-lever`：那张卡给机制②的**力臂口径**（驱动 $d+r\sin(\lambda+\zeta)$ / 制动 $d$）；本卡只引机制②的**文献估值 ≈1 deg/g**，并明确“不可用式(8-9)~(8-12) 复算”。
- 与 `braking-caster-and-split-mu`：本卡的机制④是**驱动**工况（牵引力抬高 $M_z$ → 不足转向）；那张卡是**制动**工况（高制动系数下 $M_z$ 反向 → 过多转向）。同一根 $M_z$，方向相反，不可合并计一次。
- 与 `compliance-understeer-and-basis`：机制②与④都 $\propto 1/K_{ss}$，但本卡只给量级不重算 $K_{ss}$；若用户要“改了 $K_{ss}$ 后净效果变多少”，先过那张卡拿新的 $K_{strg}$，再按本卡的加法规则重排。
- 与 `four-wheel-steering-radius-and-phase`：本卡是 FWD 的驱动效应；4WS 是主动后轮转向，机理与判据完全不同。

## E — 可执行步骤 (Execution)

**必需输入**：驱动形式（FWD/RWD/AWD）、油门变化方向（加速 / 减速 / 稳态）、是否要归因 torque steer、是否能给 $K_{ss}$（仅用于灵敏度，可选）。
**缺失即停**：若用户只问“前驱车是不是都推头”而不给油门方向 → 先声明“本卡口径是加大节气门；减小节气门整体反号”。

**交付物与完成标准**：五条机制的**方向 + 量级**表（含每条的来源口径）+ 代数和的区间 + 与书报 4–5 的偏差说明 + torque steer 归因（只 2–4 项）+ 差速器摩擦的定性附加。

0. **锁定工况与驱动形式**
   - 完成标准：写“工况 = 加大节气门（或减小）”“驱动 = FWD”。若原文 8.8.4 写“AWD”，按 **FWD** 读（硬伤 #3，笔误），并声明“机制⑤在 FWD/RWD 都存在”。
1. **列五条（方向 + 量级 + 来源口径）**
   - 完成标准：逐条写“①$<0.5$ 过多（仅一行量级，无专节、无推导）；②≈1 不足（文献[12]估值）；③汇总口径 1–1.5 不足（8.8.2 单节另有 0–2 的**跨度**，不得混用）；④0.5–1 不足；⑤≈1 不足（FWD/RWD 皆有）”。
   - 判停：若有人把机制③的 0–2 代进求和 → **停**，汇总必须用 1–1.5（硬伤 #11）。
2. **代数相加**
   - 完成标准：不足取正、过多取负；给下限、上限、中点三个数；标注“这是逐项和，不是书中 4–5”。
3. **与书报 4–5 对账（判停点）**
   - 完成标准：写出偏差（+0.4 / +0.5）并归因“取整 + 差速器摩擦未计入”；**不得**声称“复算得 4–5”，也不得把 4–5 当精确值。
   - 判停：若用户要求“精确到 0.1 deg/g 的净效果” → **停**：逐项都是取整典型值、无方差、无车型，精度只有 ±1 deg/g 级。
4. **归因 torque steer**
   - 完成标准：只归到机制 2–4；写“验证数据应是转向盘力矩，不是横摆角速度”；写两条缓解方向（降车身侧倾、提 $K_{ss}$）。
5. **差速器摩擦**
   - 完成标准：写“传动系承载时 10%–15%，作者明说未计入 4–5，方向与叠加方式未给 → 只作定性附加，不得算出具体 deg/g”。
6. **交付**
   - 完成标准：一句话形如“FWD、加大节气门：①$-0.5$…0、②$+1$、③$+1$…$+1.5$、④$+0.5$…$+1$、⑤$+1$ → 逐项和 3.0–4.5 deg/g（净不足转向）；书报 4–5 为取整汇总，不闭合 0.4–0.5；减小节气门整体反号”。

**计算约定（原书未规定，本卡设定）**：量级保留 1 位小数（deg/g）；和只给区间与中点；不把“差速器摩擦 10%–15%”折算成 deg/g（原文未给换算）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **把 4–5 deg/g 当精确求和**（硬伤 #10）：逐项和是 3.0–4.5；不得与其他来源的 deg/g 做减法对账，也不得反推“差速器摩擦 = 0.5 deg/g”。
- **把机制③的 0–2 代进求和**（硬伤 #11）：0–2 是“0.2 g 加速 → 0.05 g 减速”的**跨度**，汇总口径是 1–1.5 单值；两者并存、书中未调和，汇总必须用 1–1.5。
- **把 8.8.4 的“AWD”当真**（硬伤 #3）：那是笔误，应按 **FWD** 读；且机制⑤在 FWD/RWD 上都存在（作者自己括注），**不得用它论证“前驱特有”**。
- **用式(8-9)~(8-12) 复算机制②**（硬伤 #18）：该式力臂与“$\zeta=0$ 时力臂$=d$”不自洽 → 只能引文献估值 ≈1 deg/g，不能复算。
- **把前驱净效果判成过多转向**（ce15）：“大油门 = 甩尾”的经验法则与本书结论相反（四条推头压过一条甩尾）；只记住五条中的一条（通常是第①条）就下结论，是同一类错。
- **把 torque steer 当故障去修**（ce16）：它是驱动几何与侧倾的必然产物，可减轻（降侧倾、提 $K_{ss}$）不可消除；换转向机、加阻尼解决不了。
- **给机制①补机理**：本章对第①项只有“一行量级 + 方向”，无专节、无推导、无文献号 → 只能引用“$<0.5$ deg/g、过多转向”，不得补画力臂或补公式。
- **忽略油门方向**：五条是“加大节气门”的口径；减小节气门则整体反号。脱离前提引用“前驱必推头”是工况错配。

### 作者在书中警告的失败模式

- ce15：五条里四条不足、一条过多且最小；净 4–5 deg/g 不足转向——“加油门更推头，松油门才更容易甩”。
- ce16：驱动力矩的力臂随半轴倾角与侧倾变化，左右力臂不等 → 净力矩 → 拉扯 + 不足转向增量；两条缓解方向是降侧倾、提 $K_{ss}$。
- N8（易被误当反例）：扭矩转向是“驱动几何与侧倾的必然产物”，不是质量问题；可减轻不可消除。

### 作者的盲点 / 时代局限

- 五条量级全部是“典型车辆”的估计值，**无方差、无车型、无测试条件**；作者自己也用“大约”“估计”标注。
- 机制③的同源两条口径（0–2 跨度 vs 1–1.5 单值）**书中未调和**；本卡只能强制选一个入求和。
- 差速器摩擦 10%–15% 的方向与叠加方式未给；作者明说“这里没有提到”。
- 1992 年语境：无扭矩矢量、无 ESC、无 EPS 的助力曲线；现代 FWD 车的 torque steer 已被半轴等长化、中间轴、EPS 补偿大幅削弱，本卡的量级不能直接搬到新车上。

### 容易混淆的邻近方法论

- **torque steer（力矩反馈到方向盘） vs 不足转向/过多转向（整车转向特性分类）**：前者是“手被拽”，后者是“车头往哪走”；本卡里前者归机制 2–4，后者是五条的净和。
- **机制④（驱动，$M_z$ 增大 → 不足） vs 制动时 $M_z$ 反向（过多）**：同一根回正力矩，驱动与制动方向相反。
- **机制⑤载荷转移（FWD/RWD 皆有） vs “前驱特有”**：把⑤算进“前驱特有”的账，是本章最容易被引用坏的一处。
- **“4–5” vs “3.0–4.5”**：前者是书中取整汇总（引用口径），后者是逐项和（计算口径）；两个都要报，不能只报一个。
