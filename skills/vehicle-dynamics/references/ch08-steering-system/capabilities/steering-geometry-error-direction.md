# 转向几何误差方向判定：纵向偏移→前束变化（两轮反向）、垂向偏移→侧倾转向（两轮同向）

## R — 原文 (Reading)

> **原书要点**（p218–219 §8.3）：车轮的偏转靠转接拉杆推动，而拉杆的另一端又挂在随悬架跳动的部件上。悬架一起伏就可能顺带把车轮带偏，由此引起的跑偏，书中称作转向系统里的几何误差。
>
> **原书要点**（p219 §8.3.1）：转接杆的位置若落在车轮中心线之后，车轮受激产生的自转向就是朝左的。（原文 p219 页首一句被 OCR 截断，此处只留可辨的方向结论。）
>
> **原书要点**（p219–220 §8.3.2）：这个布置下左右两轮互为镜像，车身一歪，两只前轮便朝同一侧偏转……偏的方向恰好与驾驶员打的那把相反，等于额外添了一层推头；反过来说，若横拉杆内端的球头落在理想中心点上方，账就翻成过多转向。
>
> **原书要点**（p218–219 §8.3）：转向节臂球头该落在哪一点，是由悬架连杆的运动学关系定出来的。要弄清这一点，所用的做法与模拟抗点头、抗后蹲的那套手法并不完全相同，两者之间有一层不太显眼的区别。
>
> — 8.3 p218–219；8.3.1 p219；8.3.2 p219–220；图 8.4/8.5/8.6（中译本）

## I — 方法论骨架 (Interpretation)

一句话：**悬架一跳，车轮就“自己转向”——这是运动学必然，不是装配缺陷；方向只由一个自变量决定：转接杆系内侧铰点相对“理想运动中心”偏在哪一侧。**

- 基准必须先钉对。理想中心点是**转向节臂球头随悬架跳动所走圆弧的曲率中心**（用变形圆/哈特曼/鲍勃利尔作图或 CAD 求），不是第 7 章抗点头/抗后蹲用的“上、下控制臂延长线交点”。作者明说两者“存在微妙的差异”：一个是运动学的瞬时中心，一个是力学的瞬时中心（硬伤 #6）。**用错基准，侧倾转向的符号会整体判反**——这是本卡第 0 步、也是整章唯一能防住符号翻转的检查点。
- 两种偏移 → 两种误差，互斥且可并存：
  - **横向偏移（偏内/偏外）→ 前束变化（bump steer）**：左右轮**反向**（一轮 toe-in、另一轮 toe-out），直线过坎时危害最大。
  - **垂向偏移（高于/低于）→ 侧倾转向（roll steer）**：左右轮**同向**（“两车轮会同时向一个方向旋转”），转弯侧倾时危害最大。
- 符号链（以书中图 8.6 的**后置横拉杆**为例）：铰点低于理想中心点 → 左轮上跳产生向左转 → 右转时车身左倾、左轮上跳 → 两前轮同时向左 = 与转向方向相反 = **增加不足转向**；铰点高于 → **过多转向**。
- 方向结论是**有条件的**：原文只对“转接杆位于车轮中心线后部”逐条给出方向；横拉杆**前置**时球头内外与摆动方向整体反号，属按结构约束的推导，引用必须标条件。
- 分析必须在**悬架摆动平面**内做，再转换到横断面。多数悬架绕一根相对纵轴倾斜的轴线摆动，直接在 CAD 后视图量球头弧线会因 $\cos$ 投影把有效摆臂缩短，理想中心点随之偏移——而它正是符号判据的基准。
- 误差**不可避免**（“因为这种误差是不可避免的，所以在车辆转弯侧倾时总会发生前束变化”）：装配误差只是叠加在上面的可修分量。因此正确动作是“改球头位置”，不是“重做定位”。

## A1 — 应用示例 (Application Example)

### 示例 1：垂向偏移 2 mm 的侧倾转向（合成演练，非书中事实）

- **类型与来源**：**合成演练**。原书未给数值算例与偏移量允差，只给方向；本例自设症状与偏移方向，用于走通判定链。
- **输入**：某独立前悬架，转向横拉杆位于车轮中心线**之后**；转接杆内侧铰点比理想中心点**低 2 mm**（垂向偏移）。症状：直线正常，一进弯就向弯外偏。
- **方法的使用**：①第 0 步——确认基准是球头弧线曲率中心，不是两臂交点；②判偏移类型——只有垂向偏移 → 侧倾转向型；③定符号——后置 + 铰点低于 → 左轮上跳向左转；右转时车身左倾、左轮上跳、右轮回弹相反 → 两前轮同时向左 = 与转向方向相反 → **增加不足转向**；④症状核对——直线正常、一进弯就偏，与“两轮同向”一致。
- **结论/预期输出**：判为**增加不足转向的侧倾转向**；处置是把内侧铰点抬到理想中心点上（而不是做四轮定位）。
- **交叉探针（同一悬架，铰点改为高于理想中心点 2 mm）**：符号整体翻转 → **过多转向**，与“如果转向横拉杆内侧铰点位于理想中心点上方，则会发生过多转向”逐字吻合。
- **对照探针（改成横向偏移）**：若只横向偏内 → 直线跳动时前束变化（两轮反向、toe-in/toe-out 交替）、轮胎偏磨，而“一进弯就偏”应消失 → 用来区分两支。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 直线正常、一过弯/过坎就偏，或轮胎单侧偏磨，定位数据却全绿。
2. 想通过抬/降横拉杆内侧铰点来“治推头或治甩尾”，需要先知道改完会往哪个方向变。
3. 换过转向机、拉杆、球头、加过垫片，症状不变——要判断这是不是运动学误差。
4. 改装降低车身/换短弹簧后出现跑偏，要判是前束变化还是侧倾转向。
5. 台架或 CAD 上要定“球头该放在哪”，需要先明确基准点与允许的近似。

### 语言信号（中英双写）

- 「过坎跑偏」「一进弯就偏」「定位全绿还吃胎」「换完减振器开始跑偏」「球头垫片」
- 「跳动转向」「侧倾转向」「前束变化」「理想中心点」「转向节臂球头位置」
- 「bump steer」「roll steer」「toe change」「instant center」「kingpin inclination effect on steer」「relay linkage inner pivot」
- 变体：「转向几何误差」「悬架运动引起的转向」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `roll-steer-gradient`：本卡只判**方向**（增/减不足转向）；那张卡把方向变成 **deg/g** 的数（$\varepsilon\,d\phi/da_y$）。先判符号，再算大小；符号判反时数值毫无意义。
- 与 `steering-ratio-and-wheel-angle`：本卡的自变量是球头位置（mm 级几何），不是转向盘转角；不要用传动比去解释这类跑偏。
- 与第 7 章悬架几何（抗点头/抗后蹲、侧倾中心）：本卡**只用**理想运动中心这一个点；第 7 章的作图法（两臂延长线交点）在这里是错的基准（硬伤 #6）。
- 与 `caster-and-aligning-torque`：跑偏也可能来自后倾项经左右载荷差产生的净力矩（$M_z$ 一路）；本卡处理的是**几何注入转角**，那条是**力矩注入**。症状可分：几何误差随跳动/侧倾出现，后倾项随载荷分布与人/油量变化。

## E — 可执行步骤 (Execution)

**必需输入**：悬架形式（独立/整体）、横拉杆**前置还是后置**、转接杆内侧铰点相对理想中心点的**偏移方向**（横向偏内/偏外、垂向偏高/偏低）与偏移量（mm）、症状出现条件（直线跳动 / 转弯侧倾 / 两者）。
**缺“基准点怎么来”时**：只可交付“需用变形圆/哈特曼/鲍勃利尔作图或 CAD 求理想中心点”，**不得**用两臂延长线交点代替（f04 为 needs_review 缺口）。

**交付物与完成标准**：误差类型（前束变化 / 侧倾转向 / 两者）+ 每支的增/减不足转向结论 + 一条“改哪里”的动作 + 前置/后置条件声明 + “不可避免、只能减小”的期望管理。

0. **先钉基准（本卡的前置判据，p11）**
   - 判据：问“这个中心点是怎么求的？”——答“两臂延长线交点/抗点头作图” → **停**，判基准错，重求。
   - 完成标准：写出“理想中心点 = 球头弧线曲率中心（变形圆/哈特曼/鲍勃利尔/CAD 求）”，并声明该点需另行求出（原文只给工具名，未给步骤）。
1. **定偏移类型**
   - 判据：偏移是**横向**（左右方向）还是**垂向**（高低）？
   - 完成标准：横向 → 前束变化支；垂向 → 侧倾转向支；两者都有 → 两支并列输出，不得合并成一个结论。
2. **判符号（按前置/后置分叉）**
   - 后置：铰点**外侧**偏离 → 左轮上跳向左转；**内侧**偏离 → 相反；铰点**低于**理想中心点 → 增不足转向，**高于** → 过多转向。
   - 前置：以上左右/高低结论**整体反号**，且必须标“按结构约束推导，非原文直述”。
   - 完成标准：每个结论后面都挂“（后置）/（前置，推导）”。
3. **摆动平面 → 横断面**
   - 完成标准：写出“分析在悬架摆动平面内完成后转换到横断面”；若摆臂有安装角却按纯横向摆动处理，判结果偏小且可能反号。
4. **症状核对（判停点）**
   - 判据：直线跳动出现、转弯侧倾出现、还是都有？
   - 完成标准：症状与偏移类型的对应表要自洽（只有垂向偏移却主诉“直行跑偏” → 说明还有别的源，回第 1 步或转 `caster-and-aligning-torque`）。
   - 判停：若用户主诉“轮胎单侧偏磨 + 定位合格”，先确认不是静态前束/外倾设定问题（外倾前束是磨损参数，见 B 段 ce10），不要一律归给运动学。
5. **给动作与期望**
   - 完成标准：动作是“改内侧铰点的纵向/垂向位置”（不是换件、不是重做定位）；同时声明“误差不可避免，只能减小，不得承诺消除”。
   - 注意：若同一台车还要算柔顺性贡献，横向柔度已在 $K_{ss}$ 的集中柔度里计过一次（见 `compliance-understeer-and-basis`），**勿重复计数**。
6. **交付**
   - 完成标准：一句话形如“后置横拉杆、铰点低于理想中心点 2 mm → 侧倾转向型、增加不足转向；处置为抬高内侧铰点至理想中心点；本例方向结论仅对后置布置成立”。

**计算约定（原书未规定，本卡设定）**：偏移量保留 0.5 mm；方向结论一律用“增/减不足转向”表述，不用“左/右”作结论（左右只是中间步骤）；角度只为定性时不给数值。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **把悬架位移引起的转向当装配质量问题**（ce07）。反复做四轮定位、换转向机、换球头、加垫片，把跳动前束消成零——定位数据全绿，车照样跑偏吃胎。运动学分量不可修，只能改球头位置。
- **把侧倾转向的符号搞反**（ce08）。想让车更稳就抬高铰点，实际得到过多转向；更隐蔽的是把 $\varepsilon$ 的正负号与“左转/右转”“左侧/右侧车轮”混在一起，图上符号与实车相反。
- **在横断面（后视图）直接量球头弧线**（ce09）。摆臂斜置时真实圆弧在倾斜平面内，投影会 $\cos$ 缩短有效摆臂，理想中心点偏移 → 符号判据的基准就错了。
- **靠外倾角/前束去调操控**（ce10）。作者明说这两个角“通常是转向特性和高速转向响应的次要因素”，设置目标是轮胎磨损与直线稳定；调它们治不了几何误差，还会引入偏磨。
- **拿第 7 章抗点头/抗后蹲的虚拟中心当理想中心点**（硬伤 #6）：这是本卡唯一会“整体判反”的错误，必须先过第 0 步。
- **用前置车的结论套后置车**：原文只对后置逐条给方向；前置是推导，且球头必须外置才能逼近阿克曼，几何关系整个换了一套。

### 作者在书中警告的失败模式

- ce07：误差“不可避免”，装配只是可修的叠加分量；转弯侧倾时“总会发生前束变化”（p218–219）。
- ce08：铰点高于/低于理想中心点 → 过多/不足转向，方向与直觉相反（p219–220）。
- ce09：“大多数悬架会在相对车辆纵向轴倾斜的一个平面内摆动……分析必须在摆动平面进行，然后转换到横断面内”（p220，强制语气）。

### 作者的盲点 / 时代局限

- **理想中心点的求法缺失**：变形圆/哈特曼/鲍勃利尔只有名称与文献号，没有任何作图步骤，也没有允差（f04 → needs_review）。本卡因此只能交付“方向 + 该改哪里”，不能交付“偏移多少 mm 对应多少 deg”。
- **p219 页首整句缺失**（“同样道理，右轮向——误差，而由于前轮载荷的变化，很难保持适当的前束”），右轮方向靠左右对称推出；引用该句须注明。
- 误差量（前束变化 deg、侧倾转向 deg）与偏移量（mm）之间**原文没有换算关系**，不得自造灵敏度。
- 1992 年语境：无 CAD 运动学仿真、无 EPS；本章把误差分两支处理，未讨论橡胶衬套柔度与几何误差的耦合（柔度被单独集中到 $K_{ss}$）。

### 容易混淆的邻近方法论

- **前束变化（两轮反向） vs 侧倾转向（两轮同向）**：互斥的两支，判据是偏移方向（横向 vs 垂向），不是“哪个轮”。
- **静态前束（toe 设定值） vs 前束变化（跳动中的变化率）**：前者是磨损参数，后者是运动学误差；零位前束再准也挡不住 bump steer。
- **转向几何误差 vs 装配误差/间隙**：前者运动学必然，后者可修；本章的模型不含摩擦与间隙（§8.6 定位为低频模型）。
- **$\varepsilon$（本章，前轴一个系数，deg/deg） vs 第 6 章的 $\varepsilon_f-\varepsilon_r$**：第 6 章分前后轴取差；本章只前轴、且只经前轴进 $K$。
