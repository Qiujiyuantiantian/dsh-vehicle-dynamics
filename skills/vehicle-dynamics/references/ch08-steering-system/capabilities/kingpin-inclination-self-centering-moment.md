# 内倾项垂直力力矩 $M_V$（式 8-4 第一项）：与总载荷成正比、与左右载荷差无关、三个梯度旋钮

## R — 原文 (Reading)

> **原书要点**（p222–223 §8.5.1 式8-4 第一项 图8.11）：压在前轴上的竖直载荷并不白压着：主销朝车内倾斜了一个角度之后，轮子一打舵，载荷就分出一股横向的力 $F_z\sin\lambda$，大小随该角的正弦缩放；它到主销的横向距离是 $d\sin\lambda$，相乘才凑出绕主销的力矩，舵角归零时力矩也随之归零。
>
> **原书要点**（p222–223 §8.5.1，式8-4）：合力矩的大小随车轮垂向载荷线性增长，却与左右载荷是否相等无关。转弯时车身两侧同时被抬起，这份升高正是人们所说的回正力矩的由来。
>
> **原书要点**（p222–223 §8.5.1 图8.12 要点栏）：图注写成 $-(F_{zl}+F_{zr})\,d\sin\lambda\sin\delta$：左右轮荷之和、偏距、内倾角的正弦、舵角的正弦四者连乘后带负号；配套性质是——打舵时整根车轴被抬起、结果与左右轮荷怎样分配无关，能改动力矩梯度的只有偏距、倾斜角、轴上的载荷三样。
>
> — 8.5.1 p222–223，式(8-4) 第一项，图 8.11/8.12（中译本）

## I — 方法论骨架 (Interpretation)

一句话：**主销内倾角把“压在地上的垂直载荷”变成“转向时要抬车身的功”，于是转向盘上出现阻力矩；这个力矩只看三个量——偏距 $d$、内倾角 $\lambda$、轴上总载荷 $\Sigma F_z$，与左右载荷怎么分**完全**无关。**

- 结构式：$M_V=-(\Sigma F_z)\,d\sin\lambda\sin\delta$。负号的物理含义是“阻碍转向”（抬升车身要耗功），$|\delta|$ 越大越沉，$\delta=0$ 时为零。
- 三条可核验性质（图 8.12 要点栏逐条写出）：①与**总载荷**成正比；②**不依赖左右载荷差**；③转向时“车辆两侧均升高”（不是一侧压一侧抬）。
- 三个梯度旋钮：偏距 $d$、内倾角 $\lambda$、轴荷 $\Sigma F_z$。**左右配重、前后配重都不在旋钮里**——这条能直接否掉两类常见动作（“调左右配重改回正力”“调前后配重改回正力”）。
- 与后倾项的分工（本卡的重要边界）：内倾项是“两侧一起抬高、与载荷差无关、管低速手感”；后倾项是“一侧压一侧抬、对载荷差敏感、管高速稳定”。作者说“可以很容易地分别从侧向倾角和后倾角分析出各个力矩”，所以两项必须分开算、分开命名。
- **术语强制**：本项是几何抬高车身产生的力矩，应称**自定心力矩 / 垂直力力矩 $M_V$**。作者在 8.5.1 末句用“通常所谓回正力矩”指它，是硬伤 #4 的歧义源头；一旦沿用“回正力矩”指 $M_V$，就会与轮胎印迹的 $M_z$ 混为一谈（$M_z$ 进式(8-8)、制动会变号，见 `caster-and-aligning-torque`）。
- 量级直觉：以图 8.12 的参数（$d=1$ in、$\lambda=10°$、总载荷 1400 lb）为例，$\delta=45°$ 时约 $-172$ in·lb，$\delta=15°$ 时约 $-63$ in·lb。这是“手算就能对账”的锚点：任何模型算出的内倾项与该值差一个数量级，就是 $\lambda$ 或 $d$ 的代入口径错了（最常见：把 $\lambda$ 的度数直接当弧度）。

## A1 — 应用示例 (Application Example)

### 示例 1：图 8.12 图注参数下的内倾项力矩（原书算例，本卡复算）

- **类型与来源**：**原书算例参数**（8.5.1 p222–223，图 8.12 图注：1″ 偏距、10° 倾斜角、左轮 600 lb、右轮 800 lb），数值由本卡按式(8-4) 第一项**独立复算**——不是读图结果。
- **输入**：$d=1$ in、$\lambda=10°$、$F_{zl}=600$ lb、$F_{zr}=800$ lb（总 1400 lb），扫 $\delta=0…45°$。
- **方法的使用**：①$M_V=-(\Sigma F_z)\,d\sin\lambda\sin\delta$；②$\sin10°=0.17365$；③分别代 $\delta$。
- **结论/结果（复算值）**：$\delta=45°$ → $-1400\times1\times0.17365\times0.70711=\mathbf{-171.9}$ in·lb；$\delta=15°$ → $\mathbf{-62.9}$ in·lb；单轮 800 lb、$\delta=45°$ → $\mathbf{-98.2}$ in·lb。
- **性质复现（三条探针）**：①载荷改成 700/700 lb → 仍 $-171.9$ in·lb（**与载荷差无关** ✓）；②$\delta=0$ → 0 ✓；③$d$ 加倍到 2 in → $-343.8$ in·lb（线性 ✓）。
- **已知限制**：不得把图 8.12 纵轴刻度（±100/±200 in·lb）当“书中数值”引用；可引“量级约 ±200 in·lb”并注明是图面刻度。图注参数与复算值同阶，差 14% 可由正弦曲线形状与刻度取整解释。

### 示例 2：同一流程换一组轿车参数（合成演练，非书中事实）

- **类型与来源**：**合成演练**。自设轿车 $d=1.5$ in、$\lambda=12°$、$\Sigma F_z=1600$ lb（与书中货车参数不同，避免把例题结果当演练结果）。
- **方法的使用**：$M_V=-1600\times1.5\times\sin12°\times\sin\delta$；$\sin12°=0.20791$。
- **结论/预期输出**：$\delta=10°$ → $\mathbf{-86.6}$ in·lb；$\delta=30°$ → $\mathbf{-249.5}$ in·lb；$\delta=0$ → 0。
- **自检**：$\delta$ 从 10° 到 30°，力矩比 $=0.5/0.1736=2.88$（正弦关系，非线性）——若算出严格 3 倍，说明用了线性化 $\sin\delta\approx\delta$，须声明。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 低速泊车/掉头时方向盘“越打越沉”，要估算阻力矩大小，或判断该调什么。
2. 想通过调前后配重或左右配重来改回正力——需要被拦住（这两个旋钮无效）。
3. 设计主销内倾角（货车 0–5°、轿车 10–15°）与偏距，问“回正力够不够、会不会太沉”。
4. 转向系统力矩账不平：实测与四项之和对不上，需要逐项核内倾项的量级。
5. 区分“几何自定心力矩”与“轮胎回正力矩”各自占多少——尤其当有人把两者都叫“回正力矩”时。

### 语言信号（中英双写）

- 「原地打方向很沉」「回正力多大」「主销内倾角影响什么」「磨胎半径/偏距改大改小」「越打越沉」
- 「自定心力矩」「垂直力力矩」「kingpin inclination」「self-centering torque」「scrub radius」「$M_V$」
- 变体：「内倾角」「侧向倾角」「主销倾斜角」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `caster-and-aligning-torque`：本卡是**垂直力经内倾角**（几何、两侧同升、与载荷差无关、低速手感）；那张卡是**侧向力经后倾角 + 轮胎回正力矩 $M_z$**（高速、与载荷差/侧偏角相关、进 $K$）。两者合计才是“四类力矩”的全部。
- 与 `ackermann-wheel-angles-and-low-speed-torque`：那张卡判“阿克曼还是平行转向”（杆系力臂差 → 阻力矩随转角的形状）；本卡算**单个几何项的大小**。手感投诉先分“形状异常（阿克曼）”还是“整体太沉（内倾/偏距/轴荷）”。
- 与 `steering-geometry-error-direction`：那张卡是悬架跳动注入转角；本卡是转向时几何抬高注入力矩。一个是 deg，一个是 in·lb。
- 与 `tractive-force-and-brake-lever`：本卡用**垂直力**作输入；那张卡用**纵向力/侧向力**。同一个偏距 $d$ 在两张卡里都是力臂，但力源不同、符号规则不同。

## E — 可执行步骤 (Execution)

**必需输入**：$d$（地面侧向偏距，in，**正 = 车轮在地面交点外侧**）、$\lambda$（主销内倾角，deg，代入前转 rad）、$F_{zl}$、$F_{zr}$（左/右车轮垂直载荷，lb）、$\delta$（转向角，deg）。
**不可用替代量**：$\lambda$ 不得与后倾角 $\nu$、车轮外倾角 $\gamma$ 混（三者都在图 8.8，最容易混）；$d$ 不得用“磨胎半径”的字面理解成“磨损半径”。

**交付物与完成标准**：$M_V(\delta)$（in·lb，带符号）+ 三条性质的自检（载荷差无关、$\delta=0$ 为零、$d$ 线性）+ 术语声明（这是 $M_V$ 不是 $M_z$）+ “只含第一项”的范围声明。

1. **统一单位与符号**
   - 完成标准：$d$ 用 in、$F_z$ 用 lb、$\lambda$ 与 $\delta$ 先转 rad（$10°=0.17453$ rad）、结果 in·lb；并写出“$d$ 正 = 车轮在交点外侧”。
   - 判停：若 $\lambda$ 以“度”直接代入 $\sin$ 而不转 rad → 结果错 57 倍量级，**必须停**。
2. **算 $\Sigma F_z$ 与力臂**
   - 完成标准：力臂 $=d\sin\lambda$（in）；$\Sigma F_z=F_{zl}+F_{zr}$（lb）。写出“用总载荷，不用左右差”。
3. **算力矩**
   - 完成标准：$M_V=-\Sigma F_z\,d\sin\lambda\sin\delta$；同时给 $|\delta|$ 与 $M_V$ 两列（至少 $\delta=0,15°,30°,45°$ 四点）。
4. **三条性质自检（一步不能省）**
   - 完成标准：①把载荷改成左右相等（如 700/700）结果**必须不变**；②$\delta=0$ → 0；③$d$ 或 $\Sigma F_z$ 加倍 → 力矩加倍。
   - 判停：若“载荷差”影响了结果 → 说明代数式里混进了后倾项 $(F_{zl}-F_{zr})$，退回第 2 步。
5. **给设计结论**
   - 完成标准：一句话点名三个旋钮（$d$、$\lambda$、轴荷），并明确“调左右配重、调前后配重**无效**”；若用户要“更沉/更轻”，只在这三个量上给方向。
6. **交付**
   - 完成标准：一句话形如“$d=1$ in、$\lambda=10°$、1400 lb → $\delta=45°$ 时 $M_V=-172$ in·lb；这是几何自定心力矩（$M_V$），不是轮胎回正力矩 $M_z$；本卡只覆盖式(8-4) 第一项”。

**计算约定（原书未规定，本卡设定）**：$M_V$ 保留 1 位小数（in·lb）；$\lambda$、$\delta$ 中间量用 rad；不提前舍入；$\sin$ 用真值（不用 $\sin\delta\approx\delta$，因为 45° 处线性化高估 11%）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **算后倾项（式 8-4 第二项）**（硬伤 #1）：式内第二项写 $\sin\delta$，同一段正文与图 8.14 图注写 $\cos\delta$，两者冲突未解决 → **后倾项不可用**，定性可以、定量不行。本卡只覆盖第一项；涉及第二项一律转 `caster-and-aligning-torque` 的定性口径，并标“需纸书复核”。
- **把 $M_V$ 叫“回正力矩”**（硬伤 #4）：$M_V$ 是几何项、不进 $K$、与轮胎无关；$M_z$ 是轮胎印迹项、进式(8-8)、制动会变号。词形相同、物理不同。
- **以为左右载荷对称就能忽略后倾项**（ce11 的反向教训）：载荷差驱动的力矩**只属于后倾项**；本项恰恰对载荷差**不敏感**。若用户主诉“单人开跑偏、副驾坐人就好”，那不是本项，是后倾项 + 载荷不对称（该条结构结论可用，但其机理行的 $\cos\delta$ 属冲突的一支，只作定性）。
- **把滚动阻力矩/翻转力矩补进来“求更精确”**（ce12）：作者声明它们是二阶量、“经常忽略”；自行补项会与本章全部数值锚点不自洽。
- **从图 8.12 读纵轴刻度当书中数值**（硬伤 #13）：图无数据表，只能说“量级 ±200 in·lb（图面刻度）”。
- **在 $\delta>10°$ 处用线性化 $\sin\delta\approx\delta$**：原书从未给角度上限（硬伤 #15），只能用正弦真值；若必须线性化，须声明误差（45° 处约 11%）。

### 作者在书中警告的失败模式

- ce11：左、右车轮力矩方向相反、经杆系趋于平衡，**平衡取决于左右载荷相等**；不平衡载荷会产生 steering pull。但这条走的是后倾项，不是本项。
- ce12：滚动阻力矩与翻转力矩“最多只在转向轴上产生正弦值分量”，是二阶次要影响。
- ce13 的反向教训：正后倾角的稳定效果在紧急制动时可能消失——与本项无关，别把两者混成“回正力矩都会反水”。

### 作者的盲点 / 时代局限

- 本项的推导**明确忽略车轮外倾角**（“假设角度很小并且忽略车轮外倾角”）→ 下游不得擅自加外倾项，否则与第 6 章重复计入。
- 图 8.12 的纵轴刻度与曲线形状是唯一的“数值感”，但无数据表；本节没有给“典型车的手感多少 N·m”这类可直接对标的量。
- $\lambda$ 在 OCR 中被写成汉字「入」（符号说明、8.4 正文、8.8.1 三处），$F_{zl}/F_{zr}$ 被 OCR 成 $F_\Delta/F_\zeta$；引用公式时必须按符号说明还原，否则会与半轴倾角 $\zeta$ 撞形。
- 1992 年语境：无 EPS，转向盘力矩与驾驶员手感直接挂钩；助力后的“手感”不由本项单独决定。

### 容易混淆的邻近方法论

- **$M_V$（本卡，几何自定心） vs $M_z$（轮胎回正力矩）**：判读只看“哪个力产生的”——垂直力 → 几何；侧向力/轮胎印迹 → $M_z$。
- **$\lambda$（主销内倾，横向平面，底部向外） vs $\nu$（后倾，纵向平面） vs $\gamma$（车轮外倾，车轮平面）**：三个角同在图 8.8，混一个力矩就错一个数量级。
- **$d$（侧向偏距，in） vs 后倾拖距（纵向偏移，由 $\nu$ 产生）**：两者正交，分别在式(8-4)/(8-6) 与式(8-5) 里当力臂。

- **若用户问的是"方向盘要多大劲"**：本卡给的是**路面/车轮处**的力矩，折到转向盘还要除传动比 —— $M_{sw}\approx M_{wheel}/i$（$i$=转向传动比，轿车 15–20:1、货车 20–36:1，见 `steering-ratio-and-wheel-angle`）。本章**未给转向系统效率**，故只能给量级；**不可反过来**由"手劲"推车轮力矩。
