# 制动时的转向：轮胎后倾效应 ≡ 4°–8° 后倾角，制动力不平衡的"转向"放大 2–3 倍

## R — 原文 (Reading)

> **原书要点**（p228–229 §8.7.3，图 8.20）：此外，轮胎在自由滚动时本身就会产生回正力矩，效果相当于 4° 至 8° 的后倾角；到了制动的过程中，这股力矩同样能把车轮的偏转方向带偏。
>
> **原书要点**（p228–229 §8.7.3，图 8.20）：该图上，等效后倾角由回正力矩与侧向力相除得到，每个数据点由此确定一个轮胎拖矩；再把拖矩除以轮胎半径作无量纲化，就折成侧向力把轮胎转过的那个有效角度——这正是后倾角的等效作用。
>
> **原书要点**（p228–229 §8.7.3 图8.20）：制动系数还低的时候，轮胎回正力矩把胎面往它自己滚动的朝向带，落到转向轮上就成了往弯外拽的力——车头显得迟钝，是推头；制动系数一高，这个力矩转过来指，负得还挺可观，转向轮于是被往弯里拉，性质翻成过多转向。
>
> **原书要点**（p228–229 §8.7.3，图 8.20）：由制动力引起的这种偏转效应，比得上让车朝高附着一侧拐过去所需力矩的 2～3 倍。为抵消它——无论是对开路面制动，还是对角双回路失效工况——过去有轿车把主销偏距做成负值。
>
> — 8.7.3 p228–229，图 8.20（中译本）

## I — 方法论骨架 (Interpretation)

一句话：**制动把两个“稳定器”同时改写——(1) 轮胎回正力矩的等效后倾角会随制动系数翻向（自由滚动时相当于 4°–8° 的正后倾角，高制动系数下变负）；(2) 左右制动力不平衡经柔性转向系统会产生 2–3 倍于直接力矩的“转向”，方向由偏距符号定。**

- 第一半（轮胎后倾效应）：换算链只有一步——$t_p=M_z/F_y$（拖矩，长度 in），再除以轮胎半径得到“有效转向角”，即 $\arctan(t_p/r)$。自由滚动时这个等效角落在 **4°–8°** 的量级，与结构后倾角（0°–5°）同阶但**不是同一个物理量**。
- 为什么它重要：结构后倾角在紧急制动时会被“吃掉”——“制动时车头下沉、前悬架纵向扭转，会把正常配重下设计的那几度后倾角抵消掉”；同时轮胎回正力矩在高制动系数下反向并“可能达到较高负值”。两条路径同向作用 → “正后倾角与轮胎回正力矩带来的稳定效果”在紧急制动时可能显著降低，甚至完全消失。
- 第二半（制动力不平衡）：对开附着系数路面 → 左右 $F_x$ 不等 → 经偏距 $d$ 产生直接力矩 $M_T=(F_{xl}-F_{xr})d$（见 `tractive-force-and-brake-lever`）→ 但这个力矩走的是“转向”通道（杆系 → 柔顺性 → 车轮转角 → 轮胎侧向力），杠杆比直接通道长，所以**至少再乘 2–3 倍**。
- 方向与对策：$d>0$ 时车向**高附着侧**转（“较大的前轮制动力也会使车辆向此路面转向”）；$d<0$ 把这个方向翻过来，正好抵消——这就是“一些轿车上曾采用负偏距”的机制。代价是路感与静态转向阻力的收益被退回去（正偏距的两项收益在 8.4，p220–221）。
- 本卡的三条硬边界：①**不给阈值**——“低/高制动系数”的分界值只存在于图 8.20，文字里没有；②**不读图**——图 8.20 无数据表（硬伤 #13）；③**不报精确倍数**——2–3 倍原文未给推导、未定义比较基准（力矩比还是转角比）。
- 时代注记：1992 年没有 ABS/ESC 的 split-μ 干预；现代车多用 ESC 的横摆控制与 EBD 取代“负偏距”，但力学机制不变——这正是本卡仍值得保留的原因。

## A1 — 应用示例 (Application Example)

### 示例 1：4°–8° 的反算与量级校验（原书文字锚点 + 本卡复算）

- **类型与来源**：**原书文字锚点**（8.7.3 p228：“类似于 4°～8° 后倾角作用效果”），反算由本卡完成；原书**未给**对应的 $M_z$、$F_y$ 数据点。
- **方法的使用**：①取 $r=15$ in；②$t_p=r\tan(4°\ldots8°)$；③$t_p/r$ 占比。
- **结论/结果（复算值）**：$t_p=\mathbf{1.05}$–$\mathbf{2.11}$ in，即轮胎半径的 **7.0%–14.1%**。
- **用途**：这条反算把“4°–8°”变成一个可核的数——任何轮胎试验给出的 $t_p/r$ 落在 7%–14% 之外，先怀疑单位或口径。

### 示例 2：由 $M_z$ 与 $F_y$ 算等效后倾角（合成演练，非书中事实）

- **类型与来源**：**合成演练**。原书未给单点算例（图 8.20 无数据表）。
- **输入**：某货车轮胎，$F_y=400$ lb、$M_z=600$ in·lb、$r=15$ in（自由滚动附近）。
- **方法的使用**：①$t_p=600/400=1.5$ in；②等效角 $=\arctan(1.5/15)=5.71°$。
- **结论/预期输出**：$t_p=\mathbf{1.5}$ in、等效后倾角 $\mathbf{5.7°}$，落在 4°–8° 内 ✓。
- **小角化检查**：$t_p/r=0.1$ 时 arctan 与线性差 0.33%，可忽略；但**方向**不能靠小角化判断——方向要看 $M_z$ 的符号。

### 示例 3：对开路面制动的放大（合成演练，非书中事实）

- **类型与来源**：**合成演练**。原文只给“2–3 倍”，未给算例。
- **输入**：对开路面，高附着侧 $F_{xl}=800$ lb、低附着侧 $F_{xr}=400$ lb、$d=+1.5$ in。
- **方法的使用**：①$M_T=(800-400)\times1.5=600$ in·lb（直接力矩）；②按“转向效应 = 2–3 倍直接力矩”估算等效激励；③方向判读。
- **结论/预期输出**：$M_T=\mathbf{600}$ in·lb；等效跑偏激励 $\mathbf{1200}$–$\mathbf{1800}$ in·lb，方向指向**高附着侧**；若 $d=-1.5$ in 则方向翻转。
- **判读**：按 $M=F_x d$ 直接估跑偏会**低估 2–3 倍**；据此判“跑偏可接受”是 ce14 的典型错法。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 只在急刹/ABS 介入时方向不稳、常规驾驶正常，要判“后倾角是不是失效了”。
2. 对开路面（积冰、油污、水膜）急刹跑偏，要判方向、估量级、找对策。
3. 讨论“负偏距（磨胎半径反号）值不值得”，要给出机制与代价。
4. 轮胎试验给了 $M_z$ 与 $F_y$，要问“这等效多少后倾角、稳不稳定”。
5. 想用“加大后倾角”治直线稳定性，需要先知道它在紧急制动时靠不靠得住。

### 语言信号（中英双写）

- 「急刹跑偏」「对开路面刹车往一边跑」「制动时方向飘」「加大后倾角有用吗」「轮胎拖矩怎么换算后倾角」
- 「brake steer」「split-mu braking」「caster during braking」「pneumatic trail」「aligning torque reversal」「negative scrub radius」
- 变体：「制动稳定性」「对角线双回路失效」「自由滚动 4°–8°」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `tractive-force-and-brake-lever`：那张卡算**直接力矩** $M_T=(F_{xl}-F_{xr})d$ 与力臂口径（制动走悬架，臂 $=d$）；本卡在其上加“2–3 倍转向放大”与“轮胎后倾翻向”。顺序不能倒。
- 与 `caster-and-aligning-torque`：那张卡给“正常驾驶总阻碍转向、只有紧急制动才反向”的定性规则与 $M_{AT}$ 的算法；本卡给“反向之后等效多少度、放大多少倍”。反向后**没有阈值**可判，只能定性。
- 与 `kingpin-inclination-self-centering-moment`：那张卡的低速自定心力矩与制动无关；不要因为都涉及“回正”就混。
- 与 `fwd-five-mechanisms`：那张卡机制④（牵引力抬高回正力矩，0.5–1 deg/g）是**驱动**工况；本卡是**制动**工况，两者方向相反，不能合并计一次。

## E — 可执行步骤 (Execution)

**必需输入（轮胎后倾支）**：$M_z$（in·lb）、$F_y$（lb）、$r$（in）、工况（自由滚动 / 制动系数 $f_x$ 已知或未知）。
**必需输入（不平衡支）**：$F_{xl}$、$F_{xr}$（lb，向前为正，制动取负）、$d$（in，带符号）、路面附着是否左右不同。
**缺失即停**：若要判“该工况落在低区还是高区” → **停**：原文只给方向，分界值只存在于图 8.20（硬伤 #16）。

**交付物与完成标准**：等效后倾角（deg）+ $t_p$（in）+ 方向结论（低制动系数=不足转向 / 高制动系数=过多转向）+ 不平衡支的 $M_T$ 与 2–3 倍区间 + “无阈值”的显式声明。

1. **算拖矩与等效角（第一支）**
   - 完成标准：$t_p=M_z/F_y$（in）；等效角 $=\arctan(t_p/r)$（deg）；与 4°–8° 对照并注明“这是自由滚动附近的量级”。
   - 自检：$t_p/r$ 应在 7%–14%（对应 4°–8°）；超出先查单位（$M_z$ 是否 in·lb、$F_y$ 是否 lb）。
2. **判方向（不给阈值）**
   - 判据：自由滚动/低制动系数 → 回正力矩使轮胎向行驶方向转 → 车辆偏离转向方向 → **不足转向**；高制动系数 → 反向并可达较高负值 → **过多转向**。
   - 完成标准：写出“方向已知、阈值未知”；若用户追问“多少制动系数翻向”→ 答“原文只在图 8.20 给出，无文字数值，不得读点”。
3. **叠结构后倾角的失效路径**
   - 完成标准：写两条路径——①俯仰 + 前悬纵向扭转抵消几度结构后倾角；②轮胎回正力矩反向。结论句用原文口径：“稳定效果在紧急制动时可能显著降低或完全消失”，**不给“降低百分之几”**。
4. **算不平衡直接力矩（第二支）**
   - 完成标准：$M_T=(F_{xl}-F_{xr})d$；方向指向高附着侧（$d>0$）；随后写“至少再乘 2–3 倍”。
   - 判停：若用户要求“精确倍数”或“换算成跑偏多少米”→ **停**：原文未给推导、未定义比较基准，也无距离换算。
5. **给对策与代价**
   - 完成标准：两条对策——减小 $d$ 或改用负偏距（方向翻转、可抵消 split-μ 偏转），代价是路感与静态转向阻力退化；提高 $K_{ss}$ 削减该路径（属推导，须标注）。
   - 注意：1992 年语境无 ESC；现代车对策可能是 ESC/EBD，须声明时代差异。
6. **交付**
   - 完成标准：一句话形如“自由滚动 $t_p=1.5$ in → 等效后倾 5.7°（不足转向侧）；高制动系数下反向（过多转向），但**翻向阈值原文未给**；对开路面 $F_x$ 差 400 lb、$d=1.5$ in → 直接力矩 600 in·lb，等效激励 1200–1800 in·lb 指向高附着侧”。

**计算约定（原书未规定，本卡设定）**：等效后倾角保留 1 位小数（deg）；$t_p$ 保留 2 位小数（in）；放大倍数只写区间“2–3 倍”，不取中值 2.5 作单点结论。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **试图给出“低/高制动系数”的分界值**（硬伤 #16）：该值只存在于图 8.20，文字里没有；图又无数据表（硬伤 #13）→ 只能说“方向会翻”，不能说“在 $f_x=0.4$ 处翻”。**不许从图上读点，也不许按“大约一半”猜**。
- **以为正后倾角永远稳定**（ce13）：常规驾驶确实更稳，紧急制动时俯仰吃掉后倾、轮胎回正力矩反向——一次急刹跑偏就判定“后倾角设计错了”同样是过度反应。
- **用“制动力 × 偏距”直接算跑偏**（ce14）：低估 2–3 倍；据此判“可接受”会漏掉真实的跑偏量。
- **报“降低 X%”**：原文只说“可能显著降低或完全消失”，没有任何百分比；图 8.24/8.25 与图 8.20 都不可读。
- **以为负偏距是纯改进**：它是**取舍**——正偏距换来路感与更小的静态转向阻力（p220–221），改负偏距等于把这两项退回去；代价原文未量化。
- **把轮胎等效后倾角与结构后倾角混成一个量**：一个来自轮胎印迹（随制动系数变、会翻向），一个来自转向轴几何（0°–5°、随悬架位移变）；两者在式(8-8) 里以 $r\nu+p$ 的形式相加，但不能互相替代。
- **忽略滚动阻力矩/翻转力矩**（ce12 的反向教训）：本卡的两条路径已经足够解释“制动时方向变”，不要拿二阶项去凑账。

### 作者在书中警告的失败模式

- ce13：三条路径同时翻向（俯仰吃掉后倾、轮胎回正力矩反向、回正力矩经柔顺性放大）；症状是“只在急刹/ABS 介入时方向不稳”。
- ce14：制动力不平衡经柔性转向系统的杠杆比直接通道长 2–3 倍；正偏距加剧、负偏距抵消，方向由 $d$ 的符号定。
- 8.7.3 原话：“后倾角在制动时的作用是很有争议的”——本卡不替作者裁决，只把两个方向与量级摊开。

### 作者的盲点 / 时代局限

- **没有阈值、没有数据表**：图 8.20 只有曲线，分界点无法数字化；本节因此只能交付“方向 + 量级”。
- **俯仰/纵向扭转 → 后倾角减少量没有换算**：原文只说“可以抵消……几度的后倾角”，不给刚度、不给俯仰角—后倾角关系。
- 2–3 倍的比较基准未定义（力矩比？转角比？），推导未给。
- 1992 年语境：无 ABS/ESC/EBD；现代车 split-μ 制动由 ESC 干预，负偏距方案基本被取代——本卡的机制仍在，但对策清单已过时。

### 容易混淆的邻近方法论

- **轮胎等效后倾角（本卡，会翻向） vs 结构后倾角（0°–5°，被俯仰吃掉）**：两个“后倾”，一个在轮胎印迹里、一个在转向轴上。
- **$t_p$（拖矩，in） vs $p$（式(8-8) 里的同一个量） vs 压力（psi）**：本章只有一个 $p$，是长度；压力在本章没有符号。
- **直接力矩（可算） vs 2–3 倍放大后的等效激励（估算）**：前者进力矩账，后者进“跑偏严重度”判断；不可相加。
- **split-μ 制动偏转 vs steering pull（直线跑偏）**：前者是左右纵向力不等（本卡），后者常是左右载荷不等 + 后倾项（`caster-and-aligning-torque` 的 ce11）；症状一个在制动时、一个在匀速时。
