# 四轮转向：$R=L/[\delta_f(1+\xi_{4WS})]$（ξ=0.5 减 1/3、ξ=1 减 50%），低速反向 / 高速同向

## R — 原文 (Reading)

> **原书要点**（p232–233 §8.9.1）：让后轮回打、跟前轮朝反方向偏，能把车子的转弯圈收紧，慢速挪车、掉头因此更灵便……后轮转角一般只做成前轮的一个零头，幅度压在 5° 上下，且基本只在慢速、或慢速大把打舵时才让它介入。分析时沿用自行车那样的二自由度简化，前、后轮各取一个平均转角。
>
> **原书要点**（p232–233 §8.9.1，式8-13～8-15）：后轮转角按前轮转角的一个固定比例跟随：$\delta_r$ 与 $\delta_f$ 之比恒为 $\xi$。两轴转角叠加之后，前轮转角乘 (1+$\xi$) 等于轴距除以转弯半径；半径于是等于轴距除以前轮转角与 (1+$\xi$) 的乘积。
>
> **原书要点**（p232–233 §8.9.1，式8-13～8-15）：后轮只参与一半（50%）转角时，转弯半径能缩小约三分之一；若后轮与前轮等角反向（100% 参与），半径直接砍掉一半。
>
> **原书要点**（p232–234 §8.9.1–8.9.2）：让后轮反打能提升低速时的机动性，可一旦上了高速就不合用——后轮朝相反方向动，整车会偏向过多转向。所以车速到 20 mph 以上时，后轮改为与前轮同向偏转，且转角只给极小的一点点。
>
> — 8.9.1 p232–233，式(8-13)(8-14)(8-15)；8.9.2 p233–234（中译本）

## I — 方法论骨架 (Interpretation)

一句话：**后轮也转，就把“轴距参与转弯”这件事改了——$R=L/[\delta_f(1+\xi_{4WS})]$，$\xi_{4WS}=0.5$ 时半径缩 1/3、$\xi_{4WS}=1$ 时缩 50%；但低速该反向（缩半径）、高速该同向（压瞬态），用反了就是过多转向。**

- 符号先钉死：本章 $\xi_{4WS}$ ≡ **−$\delta_r/\delta_f$**（负号吸收反相位；$\delta_r$、$\delta_f$ 都取带符号的实际转角）。于是**低速反相位（后轮与前轮反向）⇒ $\xi_{4WS}>0$ 且缩半径；高速同相位 ⇒ $\xi_{4WS}<0$**。原文没有给符号定义式，但给了两个数值锚点（$\xi=0.5$ 减 1/3、$\xi=1$ 减 50%），足以把“叠加口径”反解出来：
  - **叠加口径（本 Bundle 采用）**：$\delta_f+\delta_r=\delta_f(1+\xi_{4WS})$，低速反相位对应 $\xi_{4WS}>0$（因为 $(1+\xi)$ 必须 >1 才能减小 $R$）。**这与上面 $\xi\equiv-\delta_r/\delta_f$ 的定义一致**：后轮反向时 $\delta_r$ 为负、负号使其变正。
  - **SAE 口径**（同向为正、反相位为负）：方程须改写为 $L/R=\delta_f(1-\xi_{SAE})$。**两种写法都能算对，混用必错**。
- 几何含义：$\delta_f+\delta_r$ 是前后轮转角对“总转向角”的贡献；$L/R$ 是轴距对应的转角。所以只要 $(1+\xi)>1$，同样的前轮转角就能跑更小的半径。
- 三个自校验点：$\xi_{4WS}=0$ → $R=L/\delta_f$（退回两轮转向，即第 6 章的口径）；$\xi_{4WS}=0.5$ → 缩 33.3%；$\xi_{4WS}=1$ → 缩 50%。三个点都在原文里，任何“符号约定搞反”都会破坏它们。
- **回代闸（必做，否则必错）**：拿到任何一组输入，先按 $\xi\equiv-\delta_r/\delta_f$ 算一遍，再代回 $R=L/[\delta_f(1+\xi)]$，看 $R$ 是否**小于**两轮转向的 $L/\delta_f$。算出比两轮转向还大，就是符号取反了 —— 例：前 6°、后反向 5° ⇒ $\xi=+0.833$ ⇒ $R\approx562.6$ in（**小于** 1031 in 的两轮值）；若得 6188 in 则符号错。
- 一条硬约束：后轮转角“一般限制在约 5° 转向角之内”。所以 $R$ 不能靠无限增大 $\xi$ 来压——$\xi=1$ 时若 $\delta_f=6°$，$\delta_r=6°>5°$ **已越限**。本卡把它做成判停条件：先校验 $\delta_r=\xi\delta_f\le5°$，再报 $R$。
- 两段用法：**低速**（泊车、掉头、大转角）→ 后轮**反向**，收益是几何（半径变小）；**高速**（原文举例 20 mph 或更高）→ 后轮**同向**、角度很小，收益是**瞬态**（横摆振荡衰减更快、侧滑角更小），稳态“觉察不到”。
- 失效机理（反向用在高速）：后轮反向运动会削弱静态裕度 → **过多转向**。这条比“半径公式”更重要，因为它是安全性判据而不是性能判据。

## A1 — 应用示例 (Application Example)

### 示例 1：两个原书锚点（原书演算值）

- **类型与来源**：**原书演算**（8.9.1 p233：“在 50% 后轮转角情况下，可以减少三分之一的转向半径……100%……减小了 50%”）。
- **方法的使用**：①$R/R_0=1/(1+\xi)$；②$\xi=0.5\to1/1.5=0.667$（缩 33.3%）；③$\xi=1\to1/2=0.5$（缩 50%）。
- **结论/结果（复算值）**：$\xi=0.5$ → 半径缩 **33.3%（即 1/3）**；$\xi=1$ → 缩 **50%**。两个锚点与原文完全一致，可用来校准符号约定。

### 示例 2：$L=100$ in、$\delta_f=6°$ 的完整流程（合成演练，非书中事实）

- **类型与来源**：**合成演练**。原书未给算例（图 8.23 只有几何示意）。
- **输入**：$L=100$ in、$\delta_f=6°=0.10472$ rad、$\xi_{4WS}=0.5$（低速反相位）。
- **方法的使用**：①基准 $R_0=L/\delta_f=100/0.10472=954.9$ in；②$R=100/(0.10472\times1.5)=636.6$ in；③缩减 $1-1/1.5=33.3\%$；④限位校验 $\delta_r=0.5\times6°=3°\le5°$ ✓。
- **结论/预期输出**：$R=\mathbf{636.6}$ in（相对基准 **954.9** in 缩 **33.3%**），后轮 **3°**，未越限。
- **锚点探针（$\xi=1$）**：$R=477.5$ in、缩 50% ✓ 与原文一致；但 $\delta_r=6°>\mathbf{5°}$ → **违反限位**，必须触发“先校验 $\delta_r$”这条分支，或压小 $\xi$。这正是本卡最实用的判停条件。
- **退化探针**：$\xi_{4WS}=0$ → $R=954.9$ in，退回两轮转向 ✓。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 给定后轮/前轮转角比，问“转弯半径能小多少、泊车好转多少”。
2. 设计或标定 4WS，问“低速和高速该用同向还是反向、切换判据是什么”。
3. 有人用一套固定反相位比例覆盖全速域，需要判“高速会不会过多转向”。
4. 想算轨迹偏移（内轮差），需要知道这一项在本章**能不能算**。
5. 看文献/竞品资料里的“4WS 全速域提升”，需要判断稳态收益是否被夸大。

### 语言信号（中英双写）

- 「四轮转向半径能小多少」「后轮反向/同向」「4WS 低速高速怎么切」「后轮转角 5° 限制」「轨迹偏移/内轮差」
- 「four-wheel steering」「4WS」「rear steer ratio」「counter-phase / in-phase」「turning radius reduction」「off-tracking」
- 变体：「ξ=0.5」「ξ=1」「20 mph」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `ackermann-wheel-angles-and-low-speed-torque`：本卡的 $R$ 用**前轮平均转角** $\delta_f$（自行车模型），丢掉了左右差角；大转角泊车、要求精确到车轮时，先过那张卡的逐轮几何。
- 与 `steering-ratio-and-wheel-angle`：若用户给的是**转向盘**转角，先过那张卡折成 $\delta_f$，再过本卡；本卡不接受转向盘转角。
- 与第 6 章的转弯半径/轨迹（式 6-4）：本卡在 $\xi_{4WS}=0$ 时**退化**为第 6 章结果，这是自校验点，不是巧合。
- 与 `braking-caster-and-split-mu`：两者都在“特例层”，但一个管制动跑偏、一个管低速机动；无重叠。

## E — 可执行步骤 (Execution)

**必需输入**：$L$（in）、$\delta_f$（deg 或 rad，**前轮平均转角**）、$\xi_{4WS}$（无量纲，**符号口径须声明**：叠加口径反相位为正 / SAE 口径反相位为负）。
**方向分支的必需输入**：车速（mph 或 km/h）、前轮转角（或转向盘转角 + 传动比）。

**交付物与完成标准**：$R$（in）+ 缩减率（相对 $\xi=0$）+ $\delta_r$ 与 5° 限位的校验 + 方向结论（低速反向 / 高速同向）+ **“轨迹偏移不可交付”**的显式声明。

1. **钉住 $\xi_{4WS}$ 的口径**
   - 完成标准：写出“$\xi_{4WS}=$__，口径 = 叠加（反相位为正）/ SAE（同相位为正）；本章为叠加口径”。
   - 判停：若用户给的 $\xi$ 来自第 7 章（制动力分配比）或第 2 章（传动比）→ **停**：同名不同义，先回定义式。
2. **校验后轮限位（先于算 $R$）**
   - 判据：$\delta_r=|\xi_{4WS}|\,\delta_f\le5°$。
   - 完成标准：给出 $\delta_r$ 与“≤5° / 越限”结论；越限则压小 $\xi$ 或截断，**不得**直接报一个“更小的半径”。
3. **算 $R$ 与缩减率**
   - 完成标准：$R=L/[\delta_f(1+\xi_{4WS})]$；同时给 $R_0=L/\delta_f$ 与缩减率 $1-1/(1+\xi)$；用三个锚点自检（0 / 0.5 / 1）。
   - 自检：$\xi=0.5$ 必须给 33.3%、$\xi=1$ 必须给 50%；给不出就说明口径反了。
4. **判低速/高速方向**
   - 低速（泊车、大转角、低车速）：后轮**反向**，收益是半径。
   - 高速（原文举例 **20 mph 或更高**）：后轮**同向**、角度很小，收益只在**瞬态**（横摆振荡、侧滑角）；稳态觉察不到。
   - 完成标准：写出所用判据（车速 / 机械式转角代理 0°–250° 转向盘）与判据类型；写“20 mph 是原文举例值，不是标定阈值”。
5. **轨迹偏移（判停点）**
   - 判据：用户要“轨迹偏移/内轮差”的数值。
   - 完成标准：**停**。式(8-17) 在 source 中只剩 $L^2(1-\ ^2)$，$\xi$ 的幂次与分母丢失（硬伤 #2）→ **严禁补全**；只能给两个边界：$\xi_{4WS}=0$ 退化为式(6-4)、$\xi_{4WS}=1$ 为 0。
6. **交付**
   - 完成标准：一句话形如“$L=100$ in、$\delta_f=6°$、$\xi_{4WS}=0.5$ → $R=636.6$ in（基准 954.9，缩 33.3%），$\delta_r=3°$ 未越限；低速反向、高速（≥20 mph）同向小角度；轨迹偏移不在本卡（式 8-17 残缺）”。

**计算约定（原书未规定，本卡设定）**：$R$ 保留 1 位小数（in）；缩减率保留 1 位小数（%）；$\delta$ 统一先转 rad 再算 $R$，或直接用 deg 比值（$L/R$ 与 $\delta$ 同单位即可，但必须前后一致）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **算轨迹偏移**（硬伤 #2）：式(8-17) 残缺（只剩 $L^2(1-\ ^2)$，分母与 $\xi$ 幂次丢失）→ **严禁补全**（不得写成 $L^2(1-\xi^2)/(2R)$ 之类）；只可给两个边界：$\xi=0$ → 式(6-4)、$\xi=1$ → 0。
- **混用两种 $\xi$ 符号口径**：叠加口径（反相位为正）与 SAE 口径（同相位为正）都能算对，但混用必错；判据是“$\xi=0.5$ 时应缩 1/3”，给不出就是口径反了。
- **用错章的 $\xi$**（硬伤 #7）：$\xi$ 全书四章四义——第 1 章拖车重力比（原书符号疑为 $\zeta$）、第 2 章传动比、第 7 章前轴制动力占比、本章后/前转角比（**可负**）；**第 3 章无 $\xi$**，第 9 章是形近的 $\zeta$（侧倾阻尼比）。卡内一律写 $\xi_{4WS}$。
- **用一套固定反相位比例覆盖全速域**（ce17）：高速用反相位 → 过多转向、变道发飘；反过来全速域同向 → 低速半径一点没减小，4WS 白装。
- **把 4WS 当全速域纯增益**（ce18）：高速收益只在**瞬态**；稳态巡航“其存在是觉察不到的”。用稳态圆周试验评价 4WS 会得出“没用”的结论。
- **把自行车模型当精确解**（ce20）：式(8-15) 假设前、后轮取平均转角、后轮转角是前轮的固定比例，丢掉左右差角与侧偏角；不能用于厘米级泊车路径规划，也不能外推到 $\xi>1$ 或后轮 $>5°$。
- **把 $\xi=1$ 当设计目标**：$\xi=1$ → 偏移 0 是**数学边界**；工程上后轮受 5° 限位不可能与前轮同角，追求 $\xi=1$ 只会得到越限的执行器指令。
- **把“后轮 5°”当精确规格**：原文是“一般限制在约 5° 之内”，是量级约束，不是每个车型的标定值；机械限位还是控制策略限制，原文未说。

### 作者在书中警告的失败模式

- ce17：反向后轮“不适于高速转向，这是因为后轮的反向运动会带来过多转向的影响”；高速需要同向、且限制在很小角度内。
- ce18：4WS 的收益是低速机动性 + 高速瞬态；“在其他高速行驶工况下，其存在是觉察不到的”。
- ce20：作者两次用“简化/近似”标注模型（二自由度自行车模型、平均转角），边界由作者自己划出。

### 作者的盲点 / 时代局限

- **式(8-17) 残缺**：轨迹偏移在本章实际上**零覆盖**；只能给两个边界条件（$\xi=0$ 退化为 6-4、$\xi=1$ 为 0）。
- **符号约定原文未给**：只能由两个数值锚点反解；式(8-13)(8-14) 的 OCR 还严重损坏（“$\delta=\xi\delta_f\delta_f+\delta_r$”），第一行就要回纸书核。
- **切换车速无曲线**：“20 mph”是举例值；电控按算法切换、机械式按转向盘 0°–250° 转角代理切换——两者不是同一个量，跨方案不可比。
- 1992 年语境：机械/液压 4WS（本田 Prelude 类），无现代电控后轮转向、无扭矩矢量；本章**未讨论** 4WS 对侧倾/侧翻裕度与极限转向储备的影响（ce19，⚠️需第 9 章，本章无据，禁止外推）。
- 高速收益只有定性（图 8.24/8.25 无刻度）→ **不得出现“降低 X%”**。

### 容易混淆的邻近方法论

- **$\xi_{4WS}$（后/前转角比，可负） vs 第 7 章 $\xi$（前轴制动力占比，0–1） vs 第 2 章 $\xi$（传动比）**：三者都无量纲、范围高度重叠，量纲与范围检查都抓不住，只能回定义式。
- **转向半径 $R$（本卡） vs 轨迹偏移（式 8-17，不可用） vs 侧倾率 $R_\phi$（第 6/9 章）**：裸 $R$ 在本章一律是半径。
- **主动 4WS vs 被动柔顺转向**：后者靠悬架刻意设计的柔度提供后轮转向增量（定量走 `steering-geometry-error-direction` / `roll-steer-gradient`），两者不是同一套机理。
- **低速收益（几何、半径） vs 高速收益（瞬态、阻尼）**：两件事，不可用一个指标评价。
