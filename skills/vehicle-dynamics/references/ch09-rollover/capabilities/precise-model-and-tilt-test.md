# 手算够不够、折线怎么读、台架能不能用：四项机制、图 9.4 的两个读数口径与倾斜平台 45° 陷阱

## R — 原文 (Reading)

> **原书要点**（p241 §9.2，图 9.4）：实车前后悬架与载荷不同，前后轮往往不会一齐抬离地面；多轴货车每抬起一只内侧轮，折线斜率就变一次，于是分成三四段。内侧第二只轮离地，即到侧翻临界值。
>
> — 9.2，图 9.4 及正文，p241

> **原书要点**（p241 §9.2）：台面倾角一大，重力沿垂直于台面方向的分量就明显变弱（到 45° 时少了 30%）。悬架和轮胎的载荷随之下降，车身相对台面被顶得比正常载重时还高，于是车会提前翻掉，测出来的门槛也就失去了意义。
>
> — p241（倾斜平台段）

## I — 方法论骨架 (Interpretation)

一句话：**式(9-6) 是"两个参数的两条通道"；真车有四条通道，而且它们不是同时退出——所以侧倾响应是折线，门槛要读第二根轴；而台架测量本身在高门槛车上会失真。**

- **四项机制**（原文逐条列出，除第 3 项给 5% 外**均无定量**）：①悬挂质量绕侧倾中心的横移；②侧倾中心相对轮距的横移（刚性车轴侧倾或独立悬架外倾）；③转向力与变形造成的轮胎垂直力作用点侧移；④前后悬架与车轮性能差异。若都要考虑，"计算机程序为计算准静态侧翻临界值的常用方法"。
- **折线的物理**：第一根内侧轮离地后，那个悬架能提供的抗侧倾能力退出，响应斜率**变小**；第二根内侧轮离地才是门槛。所以"第一轴离地加速度"与"侧翻临界值"是图上**两个不同的点**，口径错就在这两个点之间。
- 两条错误方向恰好相反：**假设四轮同时离地**（等于退回刚体模型）⇒ **高估**门槛；**用第一段斜率外推到底**、或把第一轴离地当门槛上报 ⇒ **低估**门槛。要拿最高门槛，须把前后悬架匹配到"内侧轮在**同一侧倾角**同时离地"。
- **台架那一段**：倾斜平台测的是"翻时的角度"，换算 $\tan\theta=t/2h$（几何必然，**非原书公式**）。但倾角 $\theta$ 时垂向重力分量只剩 $Mg\cos\theta$：45° 时 $0.707Mg$，即**载荷减少 30%**，悬架伸张、车体被抬高、$h$ 变大 ⇒ **过早翻** ⇒ 试验无效。替代方案：把侧向力加在**重心高度**（缆绳拖曳），或在车体上施加**纯力偶**。
- 所以本卡的交付物是三个闸门：①**要不要上计算机**（前后侧倾刚度差 / 多轴 / 前后载荷差）；②**读哪个点**（第一轴离地 / 第二轴离地 / 台架角）；③**台架数据能不能用**（$\theta$ 与 45° 的距离）。
- 硬伤同挂：p241 那句"侧倾率尽可能的**高**"按式(9-6) 应为"尽可能**低**"（⚠️ 见 `suspension-threshold-correction` B 段）；图 9.4 **只有曲线、无数据表**，只给折线读法，**零读数**。

## A1 — 应用示例 (Application Example)

### 示例 1：折线的两个读数（**合成演练**，输入自造）

- **类型与来源**：**合成演练**。原文只给折线**形状**与读法文字（"第一轴抬起""第二车轴抬起"），图 9.4 的数值不可读，故数值为自造。
- **输入**：某车第一轴内侧轮在 $a_y=1.10$ g 离地、第二轴在 $a_y=1.25$ g 离地。
- **方法的使用**：①认折点；②取**第二**根轴离地点；③检查是否有人报了 1.10。
- **结论/预期输出**：门槛 $=\mathbf{1.25}$ g，**不得**报 1.10 g（那是"第一轴离地"，会低估 12%）。若把前后悬架匹配到同一侧倾角同时离地 ⇒ 无第二段、门槛最高。

### 示例 2：倾斜平台可用性判定（**复算 + 原书论断**）

- **类型与来源**：原书论断（45°/30%/失效/两种替代法，p241）+ 本卡复算的角度换算（$\tan\theta=t/2h$ 为几何必然、**非原书公式**）。
- **输入**：轿车 $t/2h=1.3$；重型货车 $t/2h=0.5$。
- **方法的使用**：①$\theta=\arctan(t/2h)$；②算 $\cos\theta$ 看载荷还剩多少；③与 45° 比。
- **结论/预期输出**：轿车 $\theta=\arctan(1.3)=\mathbf{52.4°}$ ⇒ 越过 45° ⇒ **落在失效区，不可用倾斜平台**，改缆绳拖曳/纯力偶；重型货车 $\theta=\arctan(0.5)=\mathbf{26.6°}$，$\cos26.6°=\mathbf{0.894}$ ⇒ 垂向载荷仍有 89% ⇒ **可用** ✓。⇒ 误判的方向是**低估门槛**（台架给出偏低的"实测值"），正好与本章其他错误相反。

### 示例 3：什么时候手算不够（**原书论断 + 本卡判据**）

- **类型与来源**：原书论断（四项机制清单、"计算机程序为常用方法"）；"可忽略"的**门限原文未给**，本卡只用可判的条件式。
- **输入**：前后侧倾刚度 1:1、单胎、单轴轿车 ⇒ 判 (2)(3)(4) 可忽略 ⇒ 式(9-6) 够用；前后侧倾刚度 2:1 + 多轴货车 ⇒ 判 (4) 不可忽略 ⇒ 必须建模。
- **结论/预期输出**：前者可直接用 `suspension-threshold-correction`；后者必须建模，否则系统性偏离（通常继续**高估**），且读数取第二轴。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 手算式(9-6) 算出来的数被质疑"和实测差很多"。
2. 手上有一条侧倾响应曲线（$a_y$ vs 侧倾角），问"哪一点才是门槛"。
3. 前后悬架差异大、多轴车、或前后载荷差别大，问"两参数公式还够用吗"。
4. 有倾斜平台数据，问"这个数能不能用/为什么偏低"。
5. 要做侧翻试验，问该选哪种方法、力加在哪里。

### 语言信号（中英双写）

- 「第一轴离地」「第二根轴」「折线」「piecewise」「侧倾响应折线」「哪个点算门槛」「内侧轮先后离地」
- 「倾斜平台」「tilt-table」「45 度测不出来」「缆绳拖曳」「rope pull」「纯力偶」「台架实测值和理论差太多」
- 「四项机制」「前后侧倾刚度差」「多轴货车门槛」⇒ 命中本条

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `suspension-threshold-correction`：那张卡是**两参数手算**（$R_\phi$、$h_r/h$）；本卡判"手算够不够"以及折线读数口径，并在必要时把交付物换成"必须建模"。
- 与 `rollover-onset-staging`：本卡只解决"门槛值取哪一点"；三档状态与可救窗口是那张卡。
- 与 `transient-threshold-damping`：本卡全程**准静态**；阶跃/正弦是另一维（时间），本卡不解释"低于门槛也翻"。
- 与 `rigid-rollover-threshold`：假设四轮同时离地就等于退回那张卡的刚体模型——是本卡要防的错误方向之一。

## E — 可执行步骤 (Execution)

**必需输入**：$t$、$h$、$R_\phi$、$h_r/h$（同前卡）+ **前后悬架/载荷是否对称** + **轴数** + 数据形态（曲线 / 台架角度 / 只有两个参数）。若是台架数据，还需：车型、平台角、是否做载荷补偿。

**交付物与完成标准**：三个闸门的判定 + （若读曲线）两个读数 + （若用台架）可用性结论与替代方案。

1. **判"手算够不够"（闸门 1）**
   - 判据：前后侧倾刚度比接近 1:1、单轴、单胎 ⇒ 式(9-6) 够用；否则 ⇒ 建模。完成标准：写出判定与理由（哪一项机制不可忽略）。**注意**："差多少算大"的**门限原文未给**，本卡只给可判的条件式，不编阈值。
2. **读曲线（闸门 2，判停点）**
   - 判据：曲线是否出现折点。完成标准：**同时报两个值**——"第一轴离地 $a_y$"与"最终门槛 $a_y$"；若只有一段直线，说明为什么（前后同时离地/单轴）。
   - 判停：若用户只给了一个"离地加速度"且车型是多轴/前后差异大 ⇒ **停**，要求补第二读数。
3. **检查"四轮同时离地"假设（闸门 3）**
   - 完成标准：若有人用刚体 $t/2h$ 当门槛，明确标出这是**上限**（高估方向），并要求给出折线口径的修正值。
4. **台架数据可用性（若输入是台架）**
   - 判据：$\theta=\arctan(t/2h)$；$\theta>45°$（或平台角 >25–30° 且未补偿）⇒ 判**失效**。完成标准：给出 $\cos\theta$ 与载荷剩余百分比，并给出替代方案（缆绳拖曳须把力加在**重心高度**；或纯力偶）。
   - 判停：报告里"实测门槛"与 $t/2h$ 相差 >20% ⇒ **先查台架，不要先改模型**（ce11）。
5. **设计建议（若被问怎么改）**
   - 完成标准：方向写成"提高侧倾**刚度** ⇒ 降低侧倾率 $R_\phi$ ⇒ 抬高门槛"，并加"匹配前后悬架使内侧轮在**同一侧倾角**同时离地"。⚠️ 引用原文 p241 时必须标"原文作'侧倾率尽可能的高'，与式(9-6) 方向相反，按公式应为'尽可能低'"。
6. **交付**
   - 完成标准：模板句"该车前后侧倾刚度 2:1、三轴，式(9-6) 不够用；须建模取**第二轴**离地 1.25 g；台架 $\arctan(1.25)=51.3°$ 已进失效区，改用缆绳拖曳（力加在重心高度）。"

**计算约定（原书未规定，本卡设定）**：角度 1 位小数（度）；门槛 3 位小数；$\cos\theta$ 保留 3 位；两读数必须成对出现，缺一即判"口径不完整"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **把第一轴离地当侧翻临界值上报**（ce16，明确警告）。触发信号：只记录一个"离地加速度"、没有"第一轴/最终门槛"两个值；多轴车只用一段斜率。方向：**低估门槛**。
- **假设四轮同时离地、直接用 $t/2h$**（ce16 的另一半）。方向：**高估门槛**，等于退回刚体模型。同一份报告里两个方向混用 ⇒ "理论值 vs 试验值"根本不可比。
- **用倾斜平台测高门槛车（≈45°）**（ce11，明确警告）。触发信号：平台角 >25–30°、或"实测门槛"与 $t/2h$ 差 >20% 却不怀疑台架。方向：**低估门槛**（虚报危险）→ 误判性能、污染模型标定。
- **把"型式"当"参数"**（ce24，⚠️推断）。悬架型式只决定 $h_r$ 的量级；侧倾刚度是另一个独立旋钮，两者不可互相替代；"侧倾中心越高越好"也**不是**绝对论（还有外倾变化与操稳副作用）。
- **从图 9.4 里读任何一个数**（硬伤 #13）。该图只有曲线，无数据表，OCR 只留轴标；只能给"第一轴/第二轴"两个读数**口径**，**零读数**。
- **给"可忽略"编一个门限**（如"侧倾刚度差 <20% 即可忽略"）。原文未给任何定量门限，本卡只用条件式判断。

### 作者在书中警告的失败模式

- ce16（p241 括注）：前后轮不一定同时离地；多轴车"三四段折线"——这一段是作者主动写出的读图警告。
- ce11（p241）：倾斜平台在 45° 附近"使试验无效"，并给出两条替代法——这是本章唯一一条"测量工具会污染被测对象"的警告。
- ce24（p240）：作者明说"与独立悬架系统（侧倾中心低）相比，刚性车轴（侧倾中心高）…可减小侧向转移所造成的影响"——与"独立悬架更先进"的直觉相反。

### 作者的盲点 / 时代局限

- **四项机制除轮胎项（5%）外，全部没有定量影响幅度**；"可忽略"的门限也未给。本卡不得自造系数。
- **两种替代试验（缆绳拖曳、纯力偶）的装置参数、误差、标准号，原文全无**；"倾斜平台对（某类）车相当有效"那句在 p241 断句，**无法确认原文是对哪类车**——本卡的"低门槛车误差小"是按 $\cos\theta$ 机制推演的，**非原文直述**。
- **图 9.4 的刻度对应丢失**：折线的具体数值不可读，只能取两个口径。
- 1992 年、无计算机辅助设计普及：原文把"计算机程序"当常用方法，但没有给任何模型字段表；本卡只能说"该建模"，不能给建模细节。

### 容易混淆的邻近方法论

- **第一轴离地 vs 侧翻临界值**：图上两个点，本章最常见的口径事故。
- **倾斜平台（改重力方向）vs 缆绳拖曳（改载荷方向）**：前者在高门槛车上失真，后者要求力作用在**重心高度**（低/高于重心都会额外引入侧倾力矩，测的就不是同一个量）。
- **$\tan\theta=t/2h$ 换算 vs 原书公式**：几何必然、**非原书**；引用须标注。
- **"侧倾率尽可能低"（本卡）vs 原文"尽可能高"**：硬伤 #1，照抄即反向。
