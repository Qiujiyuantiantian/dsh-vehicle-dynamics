# 事故统计怎么读：门槛与侧翻率相关但**不决定**，同门槛可差 3 倍

## R — 原文 (Reading)

> **原书要点**（p248 §9.4）：图上 $t/2h$ 越大，侧翻率越低；但散点铺得很开，可见门槛不是唯一成因。水星 Capri 与 Vega 门槛相同，Capri 的事故数却达到 Vega 的三倍。
>
> **原书要点**（p248 §9.4，图 9.13）：各车表现本来就有差别，所以把侧翻临界值做大，并不能保证防侧翻能力跟着变好——设计者对此并无把握。
>
> — 9.4，p248（图 9.13）

> **原书要点**（p249 §9.4）：在各影响因素及其彼此关联尚未弄清之前，就单靠卡住侧翻临界值这一条去压低侧翻发生率，未免操之过急。
>
> — p249

## I — 方法论骨架 (Interpretation)

一句话：**$t/2h$ 与侧翻率之间是"相关但不决定"——趋势有，发散大（同门槛差 3 倍）；所以它只能当准入筛查，不能当评级/因果/收益预测。**

- 读这类图之前先做三道分层（原文列为分类维度）：①**路面内 / 越野**；②**侧翻是首事件 / 唯一事件 / 别的事故的后续事件**；③**用途与暴露因素**（谁在开、在哪开、开多少）。任一层不做，频率就不可比。
- 四类车型（本章定义）：轿车 / **多功能车**（高重心 + 四驱 + 个人运输，≠ 今天口语的 SUV）/ 轻型货车 / 重型货车。分组错了，图 9.7/9.8/9.14 的数值全部对应错对象。
- 结论只有两条合法落点：**"筛掉明显不合格"**（准入初判，见 `fmvss-1-2-screening`）与**趋势/设计收益评估**（货车图 9.15 的用法）。**非法落点**：给两台车排名、做保险定价、把"门槛从 1.15 提到 1.25"换算成按比例的事故率下降。
- 作者做过一轮**排除法**（这份"已被排除的嫌疑犯清单"能省掉整轮重复归因）：驾驶者特性（吊销执照、违章记录、DWI 前科、事故时 BAC）——"并未能得出任何合理的解释"；道路环境（城市/乡村、州际/其他、直/弯、干/湿）——"对侧翻的发生也无联系"；里程利用率——"把高事故率归咎于车辆的高利用率明显是不合理的"。**唯一**重要的环境因素是"是否离开路面"。
- 结论性警告必须一起引：在搞清各因素关系之前，靠限值降事故率"过于草率"。但它**不是**反对设下限（作者自己引用了 FMVSS 1.2）——反对的是"只设下限，并把门槛当预测工具"。
- 四个"没有"随卡：三张图**点位与曲线数值全部不可读**（只留轴标）；图 9.13（口径宽：第一事故或后续事件）与图 9.14（口径窄：首要危害事件）**不可互比**；数据是 1980s 美系车，不外推；空载/满载两条线**孰上孰下不可辨**（硬伤 #8）。

## A1 — 应用示例 (Application Example)

### 示例 1：同门槛、3 倍差（**原书论断**，p248）

- **类型与来源**：原书论断（Capri vs Vega）。
- **输入**：两台车门槛**相同**、侧翻率相差 3 倍。
- **方法的使用**：不得据此反推"另一台车的门槛更高"；也不得据"门槛相同"预言"事故率相同"。
- **结论/预期输出**："门槛相关但不决定"；作者的推论是"不能确保增大门槛就一定能提高防侧翻性能"。**注意**：原文**没有**给出"1.325"这个数值（阶段 0 的推断已被判伪），"同样的侧翻临界值"是唯一的表述。

### 示例 2：不可排名的两台车（**合成演练**，输入自造）

- **类型与来源**：**合成演练**。原文给的是定性结论与一条 3 倍差的事实，没有可复现的表。
- **输入**：两台车门槛同为 1.25，侧翻率 10 与 30（每 10 万车·年）。
- **方法的使用**：①先查是否同口径（图 9.13 宽 / 9.14 窄）；②分层（是否出路面、首事件、用途）；③若仍无解释，才回到车辆参数。
- **结论/预期输出**："只做趋势判断，**不得**排名/定级"；列出待查项（是否出路面、轴距、操稳、暴露因素）；结论写成"门槛相关但不决定"。

### 示例 3：排除清单的用法（**原书论断**，p249）

- **输入**：某车型侧翻率高，怀疑是车的问题。
- **方法的使用**：先跳过已被排除的五项（驾驶者偏好冒险、违规/DWI/BAC、道路环境、里程利用率、以及"人更冒险"这条——因为非侧翻致命事故率 SUV 并不高于轿车）。
- **结论/预期输出**：剩下唯一重要的环境分层是"路面内/外"。**注意硬伤 #7**：p247 说"多功能车更容易越野侧翻"、p249 说"在路面上…频率明显高于离开路面"，两句方向相反，**两条均不采信**；本卡只用"路面内/外是必须分层的维度"，不采信任何方向。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 看到"某车侧翻率 30，另一台 12"，想直接比。
2. 要用 $t/2h$ 给车型评级、采购筛选、保险定价。
3. 问"门槛提高 0.1，事故率能降多少"。
4. 某车型侧翻率高，要判断是车的问题还是使用/人的问题。
5. 看到"SUV 更容易翻""多功能车事故多"这类结论，要判断能否采信。

### 语言信号（中英双写）

- 「侧翻率」「每 10 万车·年」「involvement rate」「事故统计」「门槛和事故率的关系」「3 倍」「评级/排名/打分」
- 「SUV 是不是更容易翻」「是不是开 SUV 的人爱冒险」「提高门槛能降多少事故」
- 出现"图 9.13/9.14/9.15""首要危害事件""暴露因素"⇒ 命中本条

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `fmvss-1-2-screening`：本卡说"相关但不决定、不能评级"；那张卡只做"$\ge1.2$ 的准入初判"。两者共用 p37 的张力：**限值当准入线合理，当安全目标不合理**。
- 与 `rigid-rollover-threshold`：本卡**消费**那个门槛值，并给它划出使用边界（必要不充分）。
- 与 `slide-vs-trip-diagnosis`：那张卡解释"为什么轿车统计上不该翻却翻了"（机制层）；本卡解释"统计本身能说到哪一步"（口径层）。
- 与 `tripped-rollover-energy`：统计里"是否离开路面"是最重要的分层维度，但该维度**不解释机制**；机制在绊倒那张卡。

## E — 可执行步骤 (Execution)

**必需输入**：①要比较的对象（车型/年款/数据源）；②口径（哪张图、什么分母、首事件还是首要危害事件）；③是否做了分层。可选：样本量与显著性。

**交付物与完成标准**：一份"可以说什么/不可以说什么"的结论 + 分层清单 + 待查项 + 明确的口径声明。

1. **先问口径（判停点）**
   - 判据：分母是"注册车·年"还是"事故总数/里程"？是图 9.13（宽）还是图 9.14（窄）？**不明就停**。完成标准：写出"口径：每 10 万车·年，图 9.14，首要危害事件"。
2. **做三道分层**
   - 完成标准：逐条答——路面内/外？首事件/后续事件？用途与暴露因素？任一条缺 ⇒ 判"频率不可比"，**不出排序**。
3. **判"能说到哪一步"**
   - 完成标准：只能给两条——趋势（门槛↑⇒率↓，但发散）与准入筛查；**禁止**给排名、评级、定价、按比例的收益预测。
4. **报"3 倍差"与"不可读"（强制）**
   - 完成标准：写出"同门槛可差 3 倍（Capri vs Vega，原文未给具体数值）"；写出"三张图的点位与曲线数值不可读，本结论为定性"；**零读数**。
5. **写结论性警告与它的边界**
   - 完成标准：引"过于草率"时必须同时写"作者反对的是'只设下限并把门槛当预测工具'，不是反对设下限（他引用了 FMVSS 1.2）"。
6. **交付**
   - 完成标准：模板句"两台车口径相同（图 9.14、每 10 万车·年、首要危害事件）、分层后仍差 3 倍 ⇒ 门槛相关但不决定；**不做排名**。可说的只有趋势与准入筛查；若要解释差异，按'是否出路面 → 轴距/操稳 → 瞬态与绊倒机制'顺序查。"

**计算约定（原书未规定，本卡设定）**：不重算任何率；样本为 1980s 美系车，任何外推必须标"不外推"；"3 倍"保留原文措辞（无小数、无置信区间）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **用单指标排名/评级/定价**（ce13，明确警告）。触发信号：单指标排序、散点拟合优度低却照样外推、变量名是"率"但分母未定义。方向：**把弱相关当因果**，给出虚假的高置信收益预测。
- **不按暴露因素/事故类型分层就比频率**（ce17，明确警告）。方向：**归因错误 → 措施打偏**（或误伤一类用户）。注意不得走向两个极端："统计不可信"或"SUV 就是危险"。
- **用限值法规降事故率、把"合规"叙述成"安全"**（ce18，明确警告）。方向：**高估单一措施的收益**。
- **混用两套"侧翻"判据**（ce22，⚠️推断）。数据源与判据必须匹配：事故库＝90° 触地口径；台架/仿真＝离地口径。方向：**双向口径错配**。
- **用整车总重反推组合车门槛、把空载/满载混为一谈**（ce23，⚠️推断）。方向：**取决于取错哪一端**。图 9.15 的**两条曲线孰上孰下不可辨**（硬伤 #8）⇒ 只使用"存在两条曲线"这一事实，**不写方向、不读数**。
- **把图 9.13 与图 9.14 的数并列**。两图口径不同（宽 / 窄），并列即制造虚假排序。
- **补"1.325"这个数**（阶段 0 推断，已判伪）。原文只有"同样的侧翻临界值"。
- **报"CJ-5≈30"这类读图值**（阶段 1.5 明令不予采信）。

### 作者在书中警告的失败模式

- ce13（p248）："并不能确保增大车辆侧翻临界值就一定能提高其防侧翻性能"——本章对 $t/2h$ 的最后一次降格（必要不充分）。
- ce18（p249）："过于草率"——对"只靠限值"的政策批评。
- p36（p249）：五项排除（驾驶者特性、道路环境、里程利用率等）——"未发现联系"不等于"证明无联系"，作者也只写到"未能得出任何合理的解释"。
- F6（非反例）：作者批评的是**时序与证据**，不是限值本身；他把 FMVSS 1.2 当既有事实引用。

### 作者的盲点 / 时代局限

- **9.4 的统计结论是软的**：作者自己承认"不同的研究经常得出不同的结论"，却仍用"多功能车过量涉及"引向 FMVSS——这是从统计相关推到设计规范的跳跃。
- **三张图的数值全部不可恢复**（G7）：只能定性；货车"设计收益曲线"的算法（p38）缺"平均装载密度"与"典型轮胎/弹簧/几何特性"的取值 ⇒ 流程可照搬、结果不可复现，p38 已入 needs_review，**不进本 Bundle**。
- **数据是 1986 年前后的美系车**（图 9.14 的样本），不外推到现代 SUV/皮卡/新能源车（重心与质量分布都变了）。
- **未做统计显著性检验**；"3 倍"是两个点值的比较，不是率比检验。
- **硬伤 #7 未解**：p247 与 p249 方向相反，本章无法自证哪一句对；本卡的处理是"两条均不采信"。

### 容易混淆的邻近方法论

- **侧翻率（结果）vs 侧翻临界值（参数）**：一个是因变量、一个是自变量；相关不等于因果。
- **"首要危害事件"（时序第一）vs "最严重事件"（severity）vs "第一或唯一事故"**：三个口径，不可互换。
- **图 9.13（宽口径）vs 图 9.14（窄口径）vs 图 9.15（货车、按总重反推）**：三张图三个总体，**都不可互比**。
- **"门槛高所以安全"vs"门槛是必要不充分条件"**：后者才是作者立场；前者会导致单指标治理。
