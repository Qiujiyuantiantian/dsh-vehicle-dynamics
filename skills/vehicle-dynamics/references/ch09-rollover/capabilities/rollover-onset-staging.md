# 侧翻的三档判定：未离地 / 已离地可救 / 重心越线，以及为什么设计边界取"离地"

## R — 原文 (Reading)

> **原书要点**（p239 §9.1，图 9.2）：内侧轮一抬，车就失去稳定，因此把抬轮算作侧翻起点是合理的。理论上须等侧倾角大到重心越过外侧轮接地线外端，翻转才不可挽回，该极限对应侧向加速度为零那一点（$\Phi=\arctan(t/2h)$）。
>
> — 9.1，p239（图 9.2 及正文）

> **原书要点**（p239 §9.1，图 9.2）：车轮一旦有一侧抬离地面，绝大多数司机既反应不过来，也无从驾驭这种失稳，所以在工程上更该做的是把车辆性能调好，让这种局面压根不出现。
>
> — p239

## I — 方法论骨架 (Interpretation)

一句话：**"翻"不是一个开关，而是三个时刻——轮子刚离地、重心越线、车体触地；工程上把第一个当边界，把第二个当不可逆点，中间那段只有几分之一秒到两秒。**

- 三个状态由两个几何量分开：**门槛**（$a_y/g=t/2h$，轮子开始离地）与**角度**（$\Phi=\arctan(t/2h)$，重心越过外侧接触线，平衡 $a_y$ 降为 0）。二者不是同一件事：门槛是个加速度，越线是个角度。
- 门槛之上是**不稳定区**：由力臂缩短（重心抬高并外移），平衡所需的 $a_y$ 随 $\Phi$ 单调下降；任何正扰动都在**两秒内**发展成完全侧翻。"两秒内"是量级陈述，原文**没有** 1 s 下界。
- 三档的可判状态是：①未离地（还在稳定分支）；②已离地但未越线（进不稳定分支，**理论上**驾驶员快速反向转向仍可救，要求在几分之一秒内完成）；③$\Phi\ge\arctan(t/2h)$（无平衡解，不可避免）。
- 于是设计/预警取**第②档的门槛**而不是第③档的角度——理由不是力学，是**人**：作者给的工程假设是"大部分驾驶者没有这个反应能力"。这条把人从安全裕度里剔出去，是本卡最有价值的输出。
- 三个口径必须分清：①**侧翻**（绕纵轴 ≥90° 且车体触地，事件）；②**侧倾**（任意角度的 $\Phi$，状态量）；③**离地**（侧翻的开始）。混用会把 5° 的正常侧倾超调判成侧翻，或把"已失稳未翻"的样本漏掉。

## A1 — 应用示例 (Application Example)

### 示例 1：三档判定的走查（**合成演练**，输入自造）

- **类型与来源**：**合成演练**。原文给的是三档的**定义与判据**（p239）以及"两秒内"的量级陈述，**没有**给出任何带数值的三档判定算例。
- **输入**：$t/2h=1.3$（轿车量级）、某次操纵的侧向加速度 $a_y=1.35$ g、当前侧倾角 $\Phi=12°$。
- **方法的使用**：①比 $a_y$ 与门槛；②比 $\Phi$ 与 $\arctan(t/2h)$。
- **结论/预期输出**：$1.35>1.3$ ⇒ **已离地**（进入不稳定分支）；$\arctan(1.3)=\mathbf{52.4°}$，$12°\ll52.4°$ ⇒ **未到不可逆点** ⇒ 输出"已离地、窗口期可救，但不得把可救写进裕度"。再取 $\Phi=55°$ ⇒ "**不可避免**" ✓。

### 示例 2：设计边界的取法（**原书论断**）

- **类型与来源**：原书论断（p239 的工程假设句 + p238–p239 的"两秒内"）。
- **输入**：某车 $t/2h=1.3$（越线角 52.4°）。
- **方法的使用**：把"离地"（$a_y=1.3$ g，$\Phi\approx0$）与"越线"（$\Phi=52.4°$）两个候选边界代入设计目标。
- **结论/预期输出**：HMI 预警阈值与结构目标都应落在**离地之前**；"驾驶员反打/回正"**不计入**裕度。若有人用 52.4° 做边界，等于假设驾驶者能在几分之一秒内完成大角度反向转向——这正是作者要否掉的假设。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 问"轮子离地了算不算翻""已经离地了还能救回来吗"。
2. 要定预警阈值（LTR、侧倾角、$a_y$）该落在哪里。
3. 分析一段仿真/试验时程：什么时候算"开始翻"、什么时候算"翻定了"。
4. 看到"侧翻率"数据，要判断它用的是离地口径还是 90° 触地口径。
5. 有人把驾驶员反打/专业车手能力算进安全裕度。

### 语言信号（中英双写）

- 「离地算不算侧翻」「两轮离地还能救吗」「预警阈值定在哪」「侧翻开始的判据」「wheel lift」「LTR=1」「curb trip 之后多久翻」
- 「侧倾角多少度就翻定了」「arctan(t/2h)」「三档」「可恢复窗口」
- 出现"两秒内""几分之一秒"这类时间词 ⇒ 命中本条

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `rigid-rollover-threshold`：那张卡出**门槛值**（$a_y/g$），本卡把这个值放进**事件链**并给出角度判据与时间尺度。
- 与 `slide-vs-trip-diagnosis`：本卡假设车已经"到了门槛附近"；"它到底会先滑还是先翻"是那张卡。
- 与 `transient-threshold-damping`：本卡的"两秒内"是准静态不稳定分支的演化；阶跃/共振把**门槛本身**压低，是另一条通道（本卡不解释为什么"低于门槛也翻"）。
- 与 `tripped-rollover-energy`：绊倒工况下没有"门槛 $a_y$"这一步，判据换成能量；本卡的三档只适用平路侧滑/转向型侧翻。

## E — 可执行步骤 (Execution)

**必需输入**：$t$、$h$（算门槛与越线角）+ 当前状态（$a_y$ 或 $\Phi$ 的实测/仿真值）+ **口径声明**（数据源是事故库、台架还是仿真）。可选：时间历程。

**交付物与完成标准**：三档之一的明确判定 + 两个临界量（$t/2h$ 门槛、$\arctan(t/2h)$ 角度）+ 一句"可救窗口不计入裕度"。

1. **先定口径（判停点）**
   - 判据：数据来自事故库 ⇒ 口径是 90° 触地；来自台架/仿真 ⇒ 通常是离地。**两者不可互比**。完成标准：写出"本判定用离地口径"。
2. **算两个临界量**
   - 完成标准：$a_y/g=t/2h$（3 位小数）与 $\Phi_{crit}=\arctan(t/2h)$（度，1 位小数）；并说明"这两个不是同一个量的两种写法"。
3. **判当前状态**
   - 完成标准：三档之一；若已离地，必须写"进入不稳定分支，平衡 $a_y$ 随 $\Phi$ 单调下降"。
4. **给时间尺度（定性）**
   - 完成标准：写"扰动在**两秒内**发展成完全侧翻"（原文量级陈述，**不得**写"1–2 s"，无 1 s 下界）；可救窗口写"几分之一秒"（原文措辞，不给具体毫秒数）。
5. **给设计边界建议（判停点）**
   - 判据：用户要的是预警阈值/结构目标 ⇒ 取**离地**，不取越线。完成标准：明确写"驾驶员反打、专业车手能力、训练水平均**不计入**裕度"。
6. **交付**
   - 完成标准：模板句"该车 $t/2h=1.30$ g（离地）／$\Phi=52.4°$（不可避免）；当前 $a_y=1.35$ g、$\Phi=12°$ ⇒ 已离地、未越线；可救窗口存在但不得计入裕度。"

**计算约定（原书未规定，本卡设定）**：$\Phi_{crit}$ 保留 1 位小数（度）；门槛 3 位小数；"两秒"与"几分之一秒"一律保留原文措辞，不做区间化。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **把"离地"写成"已翻"或"必翻"**（非反例 F1）。离地只是进入不稳定态；理论上只有 $\Phi=\arctan(t/2h)$ 才不可避免，特技驾驶员可长时间两轮行驶（p239）。反例是"离地后还指望驾驶员"，不是"离地即翻"。
- **把驾驶员干预计入安全裕度**（ce12，明确警告）。触发信号：策略依赖"松油/反打/回正"、把 LTR=1 当"可恢复预警态"、用专业驾驶员表现论证可控性（另见 ce26）。方向：**高估可恢复性 → 低估风险**。
- **用特技/试车员的能力当设计假设**（ce26，明确警告）。两轮行驶力学上确实可平衡（重心投影仍在外侧接触线内），"有人能做到"是事实，错在把它当分布上界。安全裕度应取**人群分位数**。
- **在同一份报告里混用离地与 90° 触地两个"侧翻"**（ce22，⚠️推断）。方向：**双向口径错配**——用触地率当离地率会低估，用离地当触地会漏掉"已失稳未翻"的样本。
- **写"1–2 s"**。原文只有"在两秒内"，1 s 下界无出处（阶段 1.5 已删）。
- **拿本卡解释绊倒工况**。绊倒没有"门槛 $a_y$"这一步，车是被路缘卡住转为绕轮缘旋转，判据是能量（转 `tripped-rollover-energy`）。

### 作者在书中警告的失败模式

- ce12（p239）：离地后的纠正"需要很快的反应（在几分之一秒以内）"，而这短于普通驾驶者的感知—判断—操作链路；作者由此给出工程假设，而不是给出"可以救"的希望。
- ce26（p239）：特技驾驶员能长时间两轮行驶，但"对于一般的驾驶者而言，处于这种状态时是很难避免侧翻事故的发生"。
- p11（p239）：全章唯一以"应"开头的设计原则——"汽车工程师**应假设**……应专注车辆性能的优化"。

### 作者的盲点 / 时代局限

- **"两秒"的推导、初值、是否含阻尼，原文全无**；"几分之一秒"的具体数量也未给。
- **未计离地后的次生损害**（脱圈、悬架触底、翻倒过程的触地冲击）——三档只到"重心越线"，不含"翻倒后"。
- **无 ESC、无主动防倾杆**（1992 年）：现代车辆可以在离地前介入，"可救窗口"的宽度与本章假设不同；但**机制不变**，不能因此认为本章失效。
- p11 里"这条原则是 FMVSS 1.2 与事故统计之间的逻辑连接点"是**提取者的推断**，原文未如此表述——引用不得升格为原话。

### 容易混淆的邻近方法论

- **离地 vs 越线 vs 90° 触地**：三个时刻，三套判据；本卡的核心就是不让它们互换。
- **$\Phi$（侧倾角）vs $\phi$（超高角）**：本卡全是 $\Phi$；原文在式(9-5) 里把 $\Phi$ 写成了同形的 $\phi$（硬伤 #2）。
- **不稳定分支（本卡）vs 瞬态超调（`transient-threshold-damping`）**：前者在门槛**之上**演化，后者把门槛**本身**压低；两者可以叠加，但机制不同，不得互相代替。
