# 刚体准静态侧翻门槛：$a_y/g=t/2h$（含超高、2h/t、表 9.1），它是**上限**不是预测值

## R — 原文 (Reading)

> **原书要点**（p238 §9.1 式 9-4）：坡度取零时，门槛即 $t/2h$，只需轮距与重心高度两项便能算出，这正是它讨喜之处。但它给的数偏高，故多用来横向比较不同车型，而不预测某一台车的实际表现。
>
> — 9.1 式(9-4) 之下，p238（表 9.1 同页）

> **原书要点**（p238 §9.1 式 9-4 括注）：也有学者反着用，取 $2h/t$ 衡量防翻潜力；该比值越大，门槛反倒越低。
>
> — p238 同段括注

> **原书要点**（p238 §9.1）：⚠️ 这里的“保守”是个反向词——括注已写明算出的门槛大于真实值，等于把裕度算多了，结论偏乐观；与中文工程习惯里“保守＝留余量、宁小勿大”恰好拧着。别只照搬“保守”二字，要写成“高估真实门槛”。

## I — 方法论骨架 (Interpretation)

一句话：**侧翻的准静态门槛退化成一个几何比值 $t/2h$——分子是抗侧翻的力臂（半轮距），分母是抬高重心的力臂（重心高）；能算，但只能当"标尺"用。**

- 全章只有一条母式：对外侧轮胎接触中心取矩（式 9-1），令内侧轮垂直载荷 $F_{zi}$ 降到 0，解出的侧向加速度就是门槛。水平路面即式(9-4) 的 $\phi=0$ 特例：$a_y/g=t/2h$。
- 这个式子的**唯一优点是可比较**：只要 $t$、$h$ 两个数，任何两台车都能排序。它不是精度工具——刚体假设（悬架与轮胎不形变）把抗侧翻力臂当常数，而真车侧倾时力臂会缩短，所以算出来偏大。
- 于是它有三个合法的落点：①**横向排序**；②**法规准入初判**（$t/2h\ge1.2$，见 `fmvss-1-2-screening`）；③**解释矛盾**（门槛高于 $\mu$ 峰值却照样翻，见 `slide-vs-trip-diagnosis`）。非法的落点是：**报"这辆车多少 g 会翻"**。
- 三个换算/口径必须同时在场：$2h/t=1/(t/2h)$ 且**越大越差**；$h$ 的载荷状态原文未标；表 9.1 的区间**不能由 $h$、$t$ 端点复算**（端点组合不对应真实车型）。
- 交付物不是一个数，而是**一个数 + 一句限定 + 一张下游折扣清单**：$t/2h$ → 悬挂约 −5% → 轮胎约 −5% → 瞬态（货车阶跃近 −50%）。

## A1 — 应用示例 (Application Example)

### 示例 1：表 9.1 七类车型（**原书数据表**，p238）

| 车型 | $h$/in | $t$/in | 侧翻临界值/g |
|---|---|---|---|
| 跑车 | 18–20 | 50–60 | 1.2–1.7 |
| 小型轿车 | 20–23 | 50–60 | 1.1–1.5 |
| 豪华轿车 | 20–24 | 60–65 | 1.2–1.6 |
| 轻型货车 | 30–35 | 65–70 | 0.9–1.1 |
| 旅行车 | 30–40 | 65–70 | 0.8–1.1 |
| 中型货车 | 45–55 | 65–75 | 0.6–0.8 |
| 重型货车 | 60–85 | 70–72 | 0.4–0.6 |

- **复算校验（本卡自己做的，非原书）**：重型货车取 $t=70$ in、$h=60$ in ⇒ $70/(2\times60)=\mathbf{0.583}$ g，落在表值 0.4–0.6 内 ✓。
- **已知表值不可复算**：中型货车取端点 $t=75$、$h=45$ ⇒ $75/90=\mathbf{0.833}$ g，**越出表值 0.6–0.8**；轻型货车端点 $70/(2\times30)=1.17$、旅行车同算 1.17 亦越界。⇒ **端点组合不对应真实车型，表值只能查、不能推**。

### 示例 2：$2h/t$ 方向自检（**合成演练**，输入自造）

- **类型与来源**：合成演练。自造车 N9：$t=60$ in、$h=23$ in。
- **方法的使用**：①$t/2h=60/46$；②查表 9.1 落在"小型轿车 1.1–1.5"；③取倒数 $2h/t=46/60$。
- **结论/预期输出**：$t/2h=\mathbf{1.304}$ g（模板句："这是刚体、准静态、水平路面下的**上限**"）；$2h/t=\mathbf{0.767}$（越大越差）。反向自检：若见 $2h/t=1.8$，必须读成 $1/1.8=\mathbf{0.556}$ g，若读成"门槛 1.8 g"则高估 **3.2 倍**。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 手上有轮距和重心高度，问"这车多少 g 会翻 / 抗侧翻能力多强"。
2. 想快速比较几台车（轿车 vs SUV vs 货车）谁更容易翻。
3. 看到"SSF 1.25""侧翻临界值 0.5"这类数字，要判断口径与量级是否合理。
4. 看到一张只写"侧翻参数/稳定系数"的表，数值落在 0.4–2.5，要判断是 $t/2h$ 还是 $2h/t$。
5. 要一个合规/准入门槛的初判输入（$\ge1.2$）。

### 语言信号（中英双写）

- 「侧翻临界值怎么算」「t/2h 是多少」「这车多少 g 会翻」「轮距重心高度算抗侧翻」「2h/t 是什么」
- 「SSF」「static stability factor」「rollover threshold」「track width over CG height」「这车稳不稳」
- 报告里只有 $t$、$h$ 两项输入，没有侧倾率/阻尼比 ⇒ 命中本条

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `superelevation-and-neutral-speed`：本卡是 $\phi=0$ 的水平路面口径；一旦有弯道超高或要算中性车速，转那张卡（$\phi$ 是**加法项**，不是折扣）。
- 与 `suspension-threshold-correction`：本卡给的是**上限**；要出"这辆车"的数，必须转那张卡做 $1/(1+R_\phi(1-h_r/h))$ 与轮胎 −5%。
- 与 `slide-vs-trip-diagnosis`：本卡只出一个门槛值；"先滑还是先翻"是另一问，需 $\mu$ 峰值。
- 与 `accident-statistics-reading`：本卡给参数，那张卡说"这个参数不能当事故率预言机"。

## E — 可执行步骤 (Execution)

**必需输入**：$t$（轮距，in 或 m，须注明是**轮心距**还是**接地中心距**——原文未规定取法）、$h$（**整车**重心距地高度，同单位）。可选：$\phi$（横向坡度，有则转 `superelevation-and-neutral-speed`）、车型标签（用于查表对照）。

**交付物与完成标准**：一行门槛值（g）+ 一句"上限"限定 + $2h/t$ 对照 + 表 9.1 区间比对 + 下游折扣清单。

1. **统一单位并声明口径**
   - 完成标准：$t$、$h$ 同单位；若用 SI，写明"本章原式为英制 in，比值无量纲故换算不影响结果"；写明 $h$ 的载荷状态（空载/满载/设计载荷）——**原文未标，不知就写"载荷状态未说明"**。
2. **算 $t/2h$**
   - 完成标准：$\dfrac{t}{2h}$ 保留 3 位小数；同时写出 $g$ 数读法（$1.304$ g）。
3. **判是否含超高（判停点）**
   - 判据：$\phi\neq0$ 且用户给了坡向 ⇒ **停**，转 `superelevation-and-neutral-speed`（门槛变成 $t/2h+\phi$）；$\phi$ 只给数值不给坡向 ⇒ **也停**，先问坡向（见 `slide-vs-trip-diagnosis` 的符号反例）。
4. **与表 9.1 对照 + 量级自检**
   - 完成标准：报出对应车型区间并说明是否落在内；**若 $t/2h<0.3$ 或 $>2.0$，停**，先怀疑 $t$ 用了半轮距、$h$ 用了 mm/in 混排。
5. **写"上限"限定与下游折扣清单**
   - 完成标准：一句话"真实门槛 $\le$ 本值"，并列出三笔折扣（悬挂约 −5%、轮胎约 −5%、阶跃工况重型货车近 −50%），各给去向卡名。
6. **交付**
   - 完成标准：模板句"该车 $t/2h=1.304$ g 是**刚体上限**；按悬挂修正约 1.24 g、再叠轮胎约 1.18 g（见 `suspension-threshold-correction`），阶跃工况还要再降"。

**计算约定（原书未规定，本卡设定）**：门槛保留 3 位小数；$t/2h$ 与 $2h/t$ 一律成对输出；$g=32.2$ ft/s²（英制）或 $9.81$ m/s²（SI），但比值计算不用 $g$。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **报"这辆车多少 g 会翻"**（ce01，明确警告）。原文限定它只用于**比较**。触发信号：报告里只有 $t$、$h$、没有侧倾率/阻尼比，结论句是"$t/2h=1.25>1.2$ 故安全"。偏差方向：**高估门槛 → 低估风险**，掉幅约 5%（悬挂）+5%（轮胎），货车阶跃可达 −50%。
- **把 $2h/t$ 与 $t/2h$ 混进同一张表**（ce02，暗示）。两者都无量纲、都落在 0.4–2.5，看数字无法自辨。偏差方向：**排序整体翻转**，最差的车被排成最好的。触发信号：表头只写"侧翻参数/稳定系数"、没写"越大越好/越差"、没标定义式。
- **拿表值去反算"某车型的 $h$ 和 $t$ 该是多少"**（p08 订正）。端点组合会越界（中型货车 0.833 > 0.8），表值不是由端点算出来的。
- **把"保守"当"留了裕度"引用**（硬伤 #5、g05）。这是本章最容易反向的一条。正确写法只有一个："$t/2h$ 高估真实门槛（作者括注：所得出的侧翻临界值大于实际值）"。
- **用它判"这车不会翻"**（ce03，最危险）。门槛高于 $\mu$ 峰值只说明"稳态平路条件下先滑"，不说明风险消失——见 `slide-vs-trip-diagnosis`。

### 作者在书中警告的失败模式

- ce01（p238）：把标尺当预测器 ⇒ 余量虚高。
- ce03（p238）：由"先滑后翻"推出"这类车很少翻"，而"事故统计表明事实却正好相反"——作者用一整章的篇幅反驳这条推理。
- ce02（p238）：$2h/t$ 的方向只写在括号里，是本章最容易被顺手抄错的一处。

### 作者的盲点 / 时代局限

- **$h$ 的载荷状态全章未标**：表 9.1 七行的 $h$ 是空载、满载还是设计载荷？原文没说。重型货车 0.4–0.6 的跨度主要来自装载（见 `accident-statistics-reading` 的空载/满载两条线），引用表值必须声明这一点。
- **$t$ 的取法未给**：轮心距还是接地中心距、双胎按什么算，原文没有；而轮胎侧向变形恰恰通过"载荷中心内移"改变有效轮距（−5%）。
- **1980s 美系车数据 + 1992 年成书、无 ESC**：机制层（几何门槛）可迁移，数值层不可外推；"侧翻无法预防"这种措施层结论必须用现代 ESC 证据补正（不在本章）。
- 表 9.1 的七类与 9.4 统计的四类（轿车/多功能车/轻型货车/重型货车）**不映射**，跨表联结前必须先定映射。

### 容易混淆的邻近方法论

- **$t/2h$ vs $2h/t$**：互为倒数、方向相反，是本卡第一号口径事故。
- **"侧翻临界值"三义**：本卡是**加速度（g）**；9.3.3 图 9.12 是**能量**（且 23.075 是初始侧向速度 ft/s）；9.4 图 9.13/9.14 横轴是**无量纲 $t/2h$**。三者互不可比。
- **"离地" vs "90° 触地"**：本卡算出的门槛对应**内侧轮离地**（侧翻的开始），不是 90° 事件；两个口径之间隔着约两秒的不可控过程（见 `rollover-onset-staging`）。
- **刚体门槛 vs 图 9.2 的不稳定分支**：门槛只是曲线上的分叉点，过点之后平衡 $a_y$ 随侧倾角**下降**；别把门槛当"翻车判据"。

- **第 0 步（必须先做）：判工况。** 用户问的是 ①**静态/倾斜平台**（t/2h 直接适用）②**等速过弯**（用 $a_y=V^2/R$ 与门槛比，不要把这个门槛直接当成"能过多快的弯"）③**瞬态/阶跃/正弦**（准静态式**偏乐观**，要按瞬态章节打折）④**绊倒/撞击**（须走能量判据）。跳过这一步，会把静态门槛一路算到 1.2 g 的荒谬结论。

- **若问"这条 R=… 的弯，最快多少码会翻"**：把门槛换成极限车速 $v_{max}=\sqrt{(t/2h)\,gR}$（$g$=32.2 ft/s² 或 9.81 m/s²；$R$ 用 ft 或 m；算得 ft/s 或 m/s 再换 mph 或 km/h）。**这是由 $a_y=V^2/R$ 反解，原书没有这一式**，须标"本卡换算"；只在等速、已计入超高、准静态条件下成立。例：$t/2h$=1.2、$R$=40 m ⇒ $v_{max}=\sqrt{1.2\times9.81\times40}=21.7$ m/s = **78 km/h**。
