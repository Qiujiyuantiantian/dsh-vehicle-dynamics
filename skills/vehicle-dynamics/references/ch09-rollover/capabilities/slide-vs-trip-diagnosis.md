# 先翻还是先滑：门槛 vs 轮胎峰值 $\mu\approx0.8$，以及结论与统计冲突时该查什么

## R — 原文 (Reading)

> **原书要点**（p238 §9.1）：按轮胎附着极限（峰值摩擦系数约 0.8）算出的过弯能力，本就低于让轿车与轻型货车翻覆所需的侧向加速度；照此推理车只该原地打转（spinout）而不该翻。统计结果却正相反，这才是人们重新深究侧翻机理的原因。
>
> — 9.1，p238

## I — 方法论骨架 (Interpretation)

一句话：**把几何失稳门槛和附着极限放在同一根 $a_y$ 轴上比大小——小的那个先到；而当"先滑"的结论和事故统计冲突时，错的不是判据，是判据的适用域。**

- 两条边的性质完全不同：$t/2h$ 是**几何失稳边界**（力矩平衡能否成立）；$\mu$ 峰值是**附着边界**（地面最多能给多大侧向力）。准静态、平路、四轮着地时，$t/2h>\mu$ ⇒ 车先滑（spinout，绕垂直轴打转）而不是翻。
- 判据极简（二值）：$t/2h>\mu_{peak}$ ⇒ 先滑；$t/2h<\mu_{peak}$ ⇒ 先翻。轿车 1.1–1.5 对 0.8 ⇒ 全部"先滑"；重型货车 0.4–0.6 对 0.8 ⇒ "先翻"。作者本人点明：货车驾驶者若在干路面上让车急剧回转，很可能翻。
- 但作者立刻给出全章的驱动力：**事故统计正好相反**——轿车天天翻。这就把"算一个数"变成"这个数解释不了现实，还缺哪一环"。
- 缺的那几环在本章后三节逐条出现，可以当检查清单用：①悬挂柔顺（−5%）；②轮胎侧向变形（−5%）；③瞬态超调（阶跃，货车近 −50%）；④共振（货车 <1 Hz 怕 2 s 变道）；⑤相位差与 4WS；⑥**绊倒**（路缘把"侧滑"变成绕轮缘的枢轴旋转，$\mu$ 不再是上限而是支点）；⑦挂车耦合。其中 ⑥ 是唯一"根本不用 $a_y$ 门槛"的路径。
- 所以本卡的交付物不是"先滑/先翻"三个字，而是**三段式**：结论（限定在稳态平路）+ 域界判断（与统计是否冲突）+ 待查机制清单。
- 两个陷阱必须随卡：$\mu=0.8$ 是"典型峰值"不是常数（湿滑/磨损可降到 0.5 以下，连货车都可能先滑）；"保守"在本章指"算高了"（偏乐观），不是"留裕度"。

## A1 — 应用示例 (Application Example)

### 示例 1：三类车的分诊（**原书论断**，p238）

- **类型与来源**：原书论断 + 本卡套算。
- **输入**：轿车 $t/2h=1.3$、轻型货车约 $1.0$、重型货车 $0.5$；$\mu_{peak}=0.8$。
- **方法的使用**：逐类比 $t/2h$ 与 0.8。
- **结论/预期输出**：轿车 $1.3>0.8$ ⇒ **先滑**；轻型货车 $1.0>0.8$ ⇒ 先滑；重型货车 $0.5<0.8$ ⇒ **先翻**。原文同段还给出"货车在干路面急剧回转很可能翻"的结论。

### 示例 2：与统计冲突时怎么办（**合成演练**，输入自造）

- **类型与来源**：**合成演练**。原文只给"统计相反"这一事实与随后的机制清单，**没有**给"冲突时怎么处置"的流程；流程是本卡按 f03 的 V2 整理的。
- **输入**：某轿车 $t/2h=1.3$、$\mu_{peak}=0.8$，但该车型侧翻事故并不少。
- **方法的使用**：①判"先滑"；②做冲突检查（结论 vs 统计）；③若冲突 ⇒ 判**适用域越界**（纯准静态界 vs 瞬态/绊倒/多体事件），**不判判据算错**；④输出待查机制清单。
- **结论/预期输出**："在稳态平路条件下先滑；该车型的侧翻不是准静态门槛能解释的失效路径。待查：悬挂 −5%、轮胎 −5%、阶跃瞬态（货车口径近 −50%，轿车降幅原文缺失）、共振、相位差、绊倒能量。"⇒ 下一步转 `suspension-threshold-correction` / `transient-threshold-damping` / `tripped-rollover-energy`。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 问"这车在极限时是先甩尾还是先翻"。
2. 用"门槛高于摩擦极限"论证"这类车不会翻"——需要被纠正。
3. 要判断某一类车（轿车/SUV/货车）的侧翻风险归属。
4. 事故统计与理论算出来的结论相反，要解释差在哪。
5. 湿滑路面/磨损轮胎下重算"先滑还是先翻"。

### 语言信号（中英双写）

- 「先翻还是先滑」「spinout」「甩尾还是翻车」「门槛比 μ 高是不是就不会翻」「急剧回转」
- 「contact 到摩擦极限了」「μ=0.8」「这车理论上不该翻啊」「事故统计为什么对不上」
- 分析里**只有两个数**（$t/2h$ 与 $\mu$）且结论是"因此不会翻" ⇒ 命中 ce03

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `rigid-rollover-threshold`：本卡把那个门槛**当一个输入**用，输出的是"失效路径归属"，不是门槛值。
- 与 `suspension-threshold-correction` / `transient-threshold-damping` / `tripped-rollover-energy`：本卡负责**指出**该转哪一条（因为冲突说明缺机制），不负责算这些机制。
- 与 `accident-statistics-reading`：本卡只说"统计与判据冲突"这一现象；"门槛与事故率到底什么关系"是那张卡。
- 与 `rollover-onset-staging`：本卡判"会不会进入侧翻分支"，那张卡在进入后判"到了哪一档"。

## E — 可执行步骤 (Execution)

**必需输入**：$t/2h$（或 $t$、$h$）、$\mu_{peak}$（**必须带路面与轮胎状态**）。可选：该车型的事故率/统计口径。

**交付物与完成标准**：三行结论——①判定（先滑/先翻）；②限定句（"稳态平路条件下"）；③待查机制清单（若与统计冲突）。

1. **问清 $\mu$ 的来源（判停点）**
   - 判据：只给"$\mu=0.8$"、没有路面与胎况 ⇒ 允许用 0.8 但**必须**写"典型峰值、量级而非定值"，并给出敏感性。完成标准：写清 $\mu$ 的取值依据与不确定范围。
2. **二值判定**
   - 完成标准：$t/2h$ 与 $\mu$ 并排写出，判"先滑/先翻"；同时给两者的**差值**（$1.3-0.8=0.5$ g），因为差值决定结论对 $\mu$ 的敏感度。
3. **写限定句（强制）**
   - 完成标准：结论只能是"**在稳态平路、四轮着地条件下**先滑"；**禁止**写成"该车不会翻"。
4. **冲突检查（判停点）**
   - 判据：结论="先滑"，但该车型侧翻事故/统计并不少 ⇒ 判**适用域越界**（不是判据算错），进第 5 步。完成标准：明确写"准静态门槛不构成其失效路径"。
5. **给机制清单并指定去向**
   - 完成标准：逐条列出并标注"本章是否给了定量"——悬挂（约 −5%，有数）、轮胎（约 −5%，有数）、阶跃超调（货车近 −50%，轿车**未说明**）、共振（货车 <1 Hz）、相位差（1 Hz 时 0.2 s≈70°）、绊倒（能量判据，无 $a_y$ 门槛）、挂车耦合（仅双节组合车）。
6. **交付**
   - 完成标准：模板句"该车 $t/2h=1.30$、$\mu_{peak}=0.8$ ⇒ 稳态平路下先滑；但该车型侧翻并不罕见，故准静态门槛不是其失效路径。下一步按顺序查：悬挂（→1.24 g）、轮胎（→1.18 g）、阶跃瞬态、绊倒。"

**计算约定（原书未规定，本卡设定）**：$\mu$ 取 2 位小数；门槛 3 位小数；结论里必须出现"稳态平路"四字，缺此限定即判为越界输出。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **由"先滑"推出"这类车不会翻"**（ce03，明确警告，**最危险的一条**）。它删掉了后续全部分析。触发信号：分析里只有 $t/2h$ 与 $\mu$ 两个数、没有瞬态门槛也没有绊倒工况、结论句是"因此不会翻"。方向：**高估门槛 → 否定整个风险类别**。
- **用一个 $\mu=0.8$ 覆盖所有路面/胎况**（ce27，暗示）。方向：**双向**——干路 + 高性能胎（$\mu>0.9$）时"先滑"的裕度在收窄；湿滑/磨损（$\mu<0.5$）时连重型货车都可能先滑。$\mu$ 的量级足以跨越 $t/2h$ 的典型区间（0.4–1.7），所以结论对 $\mu$ 高度敏感。
- **把"先滑"写成车型的固有属性**。它是随工况翻转的判据，不是标签。
- **把"保守"读成"留了裕度"**（硬伤 #5）。作者写 $t/2h$ "相当保守"，括注明确是"所得出的侧翻临界值**大于**实际值"⇒ 用它做"先滑"判定时，$t/2h$ 偏大 ⇒ **更容易判成"先滑"** ⇒ 对风险偏乐观。方向必须写明。
- **不给出路面与轮胎状态就下结论**（ce27 同源）。判停，先问。
- **在绊倒/出路面工况里继续用本判据**。绊倒时 $\mu$ 不再是上限而是支点，判据换成能量（转 `tripped-rollover-energy`）。

### 作者在书中警告的失败模式

- ce03（p238）：由准静态比较推出"这类车很少翻"，与统计相反——作者的整章结构就是对这个推理的反驳。
- ce27（p238）：原文自己写的是"典型的摩擦系数峰值为 0.8 **左右**"，量级说明被当成常数用就会翻结论。
- F2（非反例）：作者否定的是**越界用法**（单车定量预测），不是 $t/2h$ 本身；"先滑"结论用于稳态平路排序仍然有效。

### 作者的盲点 / 时代局限

- **$\mu$ 的路面/轮胎对应表本章没有**：只说 0.8 是典型峰值，湿路/雪地/高性能胎要换值，但换多少不给。
- **判据忽略"未到门槛轮胎已饱和"的过渡区**，也忽略内外轮 $\mu$ 利用不均。
- **1992 年、无 ESC**：现代 ESC 会在"先滑"之前介入，但介入的是**操纵**而不是侧翻机制；本章的力学层结论仍可用，措施层必须补现代证据。
- 作者用"多功能车大量涉及"推进到 FMVSS 1.2，这一步是从统计相关推到设计规范；本卡不承担该跳跃（见 `fmvss-1-2-screening`）。

### 容易混淆的邻近方法论

- **门槛（几何失稳）vs $\mu$ 峰值（附着极限）**：两条性质不同的边界，比大小只在同一 $a_y$ 轴上才有意义。
- **spinout（绕垂直轴打转）vs 侧翻（绕纵轴 ≥90°）**：前者是"滑"，后者是"翻"；侧滑撞路缘后可能触发后者（绊倒），所以"先滑"不等于"安全"。
- **"先滑"结论 vs 事故率**：前者是单点工况的判据，后者是全条件统计；两者不一致是常态，不是矛盾。
