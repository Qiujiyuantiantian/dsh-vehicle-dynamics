# 侧翻法规准入门槛 1.2：达标初判怎么做，以及为什么它不是"安全线"

## R — 原文 (Reading)

> **原书要点**（p248–249 §9.4）：门槛落在 1.25～1.6 区间的车，看不出规律；推动法规的其实是多功能车卷入事故过多，于是 FMVSS 把新车门槛下限定为 1.2。
>
> — 9.4，p248–p249

> ⚠️ **硬伤 #9（G8，必标）**：原文**没有任何标准编号**。1.2 的口径是**无量纲 $t/2h$**（与图 9.13/9.14 横轴一致），不是"1.2 g 的实测量"。**严禁**补成 "FMVSS 216"——216 是**车顶强度**（压溃试验），与本条无关。法规原文、适用车型、测量方法（计算 or 平台）、生效年份，**均不在本章**。

## I — 方法论骨架 (Interpretation)

一句话：**拿刚体门槛 $t/2h$ 与 1.2 比大小，得到"达标/不达标"；但 1.2 是准入线，不是安全线，也不是给单车用的性能目标。**

- 判据极简：$t/2h\ge1.2$ ⇒ 达标；$<1.2$ ⇒ 不达标。口径必须写清楚是**无量纲 $t/2h$**。
- 这条线的**来源**是统计观察（1.25–1.6 区间无明显趋势 + 多功能车过量涉及），不是力学推导。所以它本身带着统计的软性——作者紧接着就说"过于草率"（见 `accident-statistics-reading`）。
- 按表 9.1 逐类筛一遍就知道这条线的实际约束力：跑车 1.2–1.7、小型轿车 1.1–1.5、豪华轿车 1.2–1.6 部分达标；**轻型货车 0.9–1.1、旅行车 0.8–1.1、中型货车 0.6–0.8、重型货车 0.4–0.6 全部不达标** ⇒ 该门槛实际只约束**乘用车**。
- 两个必须一起说的限定：①"达标"只说明该车的**刚体上限**越过了准入线，真实门槛还要打折（悬挂约 −5%、轮胎约 −5%、阶跃可达 −50%）；②作者从未说"1.2 以上就安全"。
- 交付物：达标/不达标 + 口径声明 + 三条限定（无量纲口径 / 只约束乘用车 / 准入非安全）+ 一句"真实门槛更低"。

## A1 — 应用示例 (Application Example)

### 示例 1：两台车的判定（**合成演练 + 原书论断**）

- **类型与来源**：原书论断给的是"最低 1.2"这条要求（p248–249）；判定动作与数值是本卡按判据做的演练，$t/2h$ 取值来自表 9.1 的区间端点。
- **输入**：新车 A $t/2h=1.25$；车 B $t/2h=1.1$（轻型货车表值上限）。
- **方法的使用**：与 1.2 比大小。
- **结论/预期输出**：A ⇒ **达标**；B ⇒ **不达标**。

### 示例 2：逐类筛表（**复算**，数据来自表 9.1）

| 车型 | 表 9.1 区间 | 对 1.2 的判定 |
|---|---|---|
| 跑车 | 1.2–1.7 | 端点恰好达标（下限 1.2） |
| 小型轿车 | 1.1–1.5 | 区间**跨越** 1.2 ⇒ 视具体车型 |
| 豪华轿车 | 1.2–1.6 | 端点恰好达标 |
| 轻型货车 | 0.9–1.1 | **全部不达标** |
| 旅行车 | 0.8–1.1 | **全部不达标** |
| 中型货车 | 0.6–0.8 | **全部不达标** |
| 重型货车 | 0.4–0.6 | **全部不达标** |

- **结论**：该门槛实际只约束**乘用车**；对货车是系统性"不达标"。⇒ 这解释了为什么它是"准入线"而不是普适安全目标。

### 示例 3：达标 ≠ 安全（**合成演练**）

- **输入**：某车 $t/2h=1.25$（达标）。
- **方法的使用**：按下游折扣链算真实门槛。
- **结论/预期输出**：$1.25/1.05=\mathbf{1.19}$ g（悬挂）→ $\times0.95=\mathbf{1.13}$ g（轮胎）；阶跃工况还要再降（重型货车可达 −50%，轿车降幅**原文未说明**）。⇒ "达标"只说明上限过了线。
- **必须同时输出**：作者的原话边界——在搞清各因素关系之前，用限值降事故率"过于草率"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 问"这车侧翻达标吗""1.2 是什么要求"。
2. 新车/改款要过侧翻准入，问该拿哪个数去比。
3. 看到"FMVSS 216 要求侧翻 1.2"这类说法，要判断真假（**假**：216 是车顶强度）。
4. 要判断某类车（货车/SUV/轿车）是否被这条线覆盖。
5. 有人把"合规"直接当"安全"写进结论。

### 语言信号（中英双写）

- 「FMVSS 1.2」「侧翻临界值最低 1.2」「达标吗」「合规吗」「rollover requirement」「SSF 1.2」「准入线」
- 「FMVSS 216 是不是规定 1.2」「国标/ECE 有没有对应要求」「货车要满足 1.2 吗」
- 出现"1.25–1.6 无明显趋势""多功能车大量涉及"⇒ 命中本条

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `accident-statistics-reading`：本卡只做"$\ge1.2$"的准入判定；那张卡负责"这条线为什么软、能说到哪一步"。**两张卡必须一起用**，否则会把合规说成安全。
- 与 `rigid-rollover-threshold`：本卡的口径就是那张卡的输出（$t/2h$）；不要用修正后的实际门槛去比 1.2（口径不同）。
- 与 `suspension-threshold-correction`：真实门槛在本卡之后才算，且**不**参与合规判定。
- 与任何非美标（ECE R13 / GB）：**本章不覆盖**，不得替用户下非美标结论。

## E — 可执行步骤 (Execution)

**必需输入**：$t$、$h$（或已算好的 $t/2h$）+ 车型类别 + 目的（准入初判 / 安全评估）。

**交付物与完成标准**：达标/不达标 + 口径声明 + 三条限定 + "真实门槛更低"的量化提示。

1. **口径归一（判停点）**
   - 判据：用户给的是"实测门槛 1.2 g"（台架/仿真）⇒ **停**，说明"法规口径是**计算的无量纲 $t/2h$**，实测值不可直接比"。完成标准：写出"$t/2h=1.25$（无量纲，刚体、准静态、水平路面）"。
2. **比大小**
   - 完成标准：给出达标/不达标；边界情形（$=1.2$）写"恰好达标"，不作四舍五入。
3. **声明三条限定（强制）**
   - 完成标准：①口径＝无量纲 $t/2h$；②适用范围＝原文只提"新车"，按表 9.1 实际只约束乘用车（货车系统性不达标）；③**准入线 ≠ 安全线**，作者未说"1.2 以上就安全"。
4. **禁止补编号（强制自检）**
   - 完成标准：全文检索确认没有出现"FMVSS 216 / 226"作为 1.2 的出处；若用户提到，直接纠正"216 是车顶强度"。
5. **给"真实门槛更低"的量**
   - 完成标准：按 `suspension-threshold-correction` 给修正值（如 1.25 → 1.19 → 1.13 g），并注明轿车阶跃降幅**原文未说明**。
6. **交付**
   - 完成标准：模板句"该车 $t/2h=1.25$（无量纲）≥1.2 ⇒ **达标**（作者所述 FMVSS 要求，原文无标准编号）。但这是准入线：悬挂修正后约 1.19 g、再叠轮胎约 1.13 g；作者同时警告，在搞清各因素关系之前单靠限值降事故率'过于草率'。"

**计算约定（原书未规定，本卡设定）**：$t/2h$ 保留 3 位小数；1.2 为**严格下限**（恰好 1.200 判达标）；不引入任何换算（1.2 不乘 $g$、不换 ft/s²）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **补标准编号**（硬伤 #9）。"FMVSS 216 规定侧翻临界值 1.2"是**错的**：216 是车顶强度压溃试验。触发信号：回答里出现具体编号却没原文依据。正确写法只有"作者所述：美国联邦机动车辆安全标准（FMVSS）要求新车的侧翻临界值最低为 1.2"。
- **把 1.2 当"1.2 g 的实测门槛"**。口径是**无量纲 $t/2h$**；用实测值比会系统性错位。
- **把"达标"写成"安全"**（ce18，明确警告）。方向：**高估单一措施的收益**。触发信号：政策/设计目标只有一个数字、没有配套的瞬态/绊倒/使用条件措施、把"合规"叙述成"安全"。
- **用修正后的真实门槛去比 1.2**。法规口径是刚体上限；混用会让所有车都"不达标"。
- **对货车下"不达标所以违规"的结论**。表 9.1 显示货车 0.4–1.0 系统性低于 1.2；原文只说"新车"，未说货车适用，也未说货车因此违规。
- **给 ECE / GB / 其他市场结论**。本章不覆盖；只能声明"本章只涉及作者所述的 FMVSS 要求"。
- **把 1.2 当设计目标值**。作者对"只设下限"的批评（p37）与这条线的存在并不矛盾：**准入线合理，安全目标/收益承诺不合理**。

### 作者在书中警告的失败模式

- ce18（p249）：单靠限值降事故率"过于草率"——这是本卡最重要的边界，且必须与"作者自己引用了 1.2"一起呈现，否则会读成"作者反对法规"。
- p37（p249）："必须对各种因素进行合理的组合"——限值只是组合中的一项。
- p35（p248–249）：1.2 的来源是统计观察（1.25–1.6 无趋势 + 多功能车过量涉及），**不是**力学推导；这个"出身"决定了它不能当性能目标。

### 作者的盲点 / 时代局限

- **法规原文、适用车型、测量方法（计算 or 平台）、生效年份、标准编号全部不在本章**（G8）。任何"某年某法规第几条"的补充都是外部知识，必须标来源，不得冒充本章。
- **书中成于 1992 年**：此后 FMVSS 侧翻相关要求（含 ESC 强制）已变化；本章的 1.2 只是"作者所述"的时点状态。**机制层可迁移，法规层必须现查。**
- **"多功能车过量涉及 → 立法"这条链条是统计相关推到规范**：BOOK_OVERVIEW §3 已把它列为作者的立场盲点。
- 作者未讨论 1.2 对**空载/满载**、对**组合车**、对**改装车**的适用性。

### 容易混淆的邻近方法论

- **准入线（1.2，无量纲 $t/2h$）vs 实际门槛（g，修正后）vs 实测门槛（台架角度换算）**：三个数三个口径。
- **FMVSS 216（车顶强度）vs 本条（侧翻准入）**：最容易补错的编号。
- **"合规"vs"安全"**：前者是分布的一个参数被移动，后者是事故率；两者之间隔着瞬态、绊倒、使用环境、驾驶员。
- **本章的 1.2 vs 其他市场的对应要求**：不可互推。
