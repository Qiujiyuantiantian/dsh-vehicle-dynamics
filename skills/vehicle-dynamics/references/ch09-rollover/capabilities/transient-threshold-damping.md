# 阶跃工况的瞬态门槛：侧倾角超调把门槛压到准静态值以下，阻尼比是最坏端的开关

## R — 原文 (Reading)

> **原书要点**（p243 §9.3.1）：侧倾角会出现超调，说明瞬态工况下顶起车轮所需的侧向加速度小于准静态值；也正因超调，阶跃输入即便略低于准静态门槛，仍可能在瞬态中翻车——瞬态门槛因此偏低。
>
> — 9.3.1，p243

> **原书要点**（p243 §9.3.1）：阻尼比由 0 提到临界阻尼的一半，轿车门槛可抬高近 1/3。轿车与多功能车受阶跃输入时，瞬态过程会把门槛自 $t/2h$ 往下拉（原文这里 OCR 断裂），重型货车则掉近一半。
>
> — p243

> ⚠️ **硬伤 #6（G1）**：轿车/多功能车那一栏的降幅百分比在 `source.md` 264–268 行**断裂**（该处还混入一条与本章无关的第 2 章伪公式）。本节**只保留**"低于 $t/2h$、降幅原文未说明"与重型货车的"近 50%"，**严禁编数**，也**不得**从图 9.7 纵轴刻度反推。

## I — 方法论骨架 (Interpretation)

一句话：**准静态门槛回答"慢慢加力到多少会翻"，阶跃门槛回答"猛地加到多少会翻"——后者更低，因为侧倾角会冲过头；冲多少由阻尼比决定，阻尼比＝0 是最坏端。**

- 机理是一条二阶系统链：阶跃输入 → 侧倾角欠阻尼响应 → **峰值超过稳态值**（超调）→ 瞬时侧倾角更大 → 抬轮所需的 $a_y$ 更低。所以"门槛"不是常数，而是**输入形状的函数**。
- 两个端点的定性结论（原文都有）：**无阻尼时门槛最低**；随阻尼比增大而增长，但**增长率递减**。
- 三个数量锚点（本卡唯一可报的数）：
  - 轿车 ζ 从 0 提到临界值的 **50%** ⇒ 门槛升**近 1/3**（$1.3\to$ 约 $1.73$ 的方向，不是精确值）；
  - 重型货车阶跃 ⇒ 门槛相对 $t/2h$ 降**近 50%**（$0.5\to\mathbf{0.25}$ g，可当设计下界）；
  - 轿车/多功能车阶跃降幅 ⇒ **未说明**（OCR 缺失），只能写"低于 $t/2h$"。
- 关键纪律：**等效门槛的降幅 ≠ 理论超调量**。侧翻判据还叠加了侧向载荷转移的动态，所以只能用"方向 + 原文给的百分比"，**不得**用 $\theta_{max}$ 公式直接换算门槛。反过来，`门槛/(1+超调率)` 这类换算是通用知识/本卡重写，引用必须标"非原书"。
- 交付物：一个**区间**（最坏端−最好端）+ 一条方向性判据（ζ 未知就取最坏端）+ 一句"这是阶跃口径，不覆盖共振/绊倒"。

## A1 — 应用示例 (Application Example)

### 示例 1：重型货车阶跃下界（**原书论断 + 复算**）

- **类型与来源**：原书论断（"重型货车则将减少近 50%"）+ 复算。原文对应曲线为图 9.7（**只有曲线、无数据表**，此处**不读图**）。
- **输入**：重型货车 $t/2h=0.5$、阶跃输入、ζ 未知。
- **方法的使用**：取原文锚点"近 −50%"作最坏端。
- **结论/预期输出**：**$0.5\times0.5=\mathbf{0.25}$ g** 作设计下界（"近半"⇒ 下界取半是保守取法，标注为本卡约定）。

### 示例 2：轿车阻尼改善（**原书论断 + 复算**）

- **输入**：轿车 $t/2h=1.3$，ζ 从 0 提到 50%。
- **结论/预期输出**：+近 1/3 ⇒ $1.3\times1.333\approx\mathbf{1.73}$ g 的方向（**方向 + 量级**，不写成精确值）；反向自检：若算出"阻尼增大 ⇒ 门槛下降"，立刻判方向错。

### 示例 3：超调换门槛（**合成演练，标注非原书**）

- **类型与来源**：**合成演练**。`门槛/(1+超调率)` 与二阶超调率解析式 $e^{-\pi\zeta/\sqrt{1-\zeta^2}}$ 都是**通用知识/本卡重写**，不在本章文字中。
- **输入**：准静态门槛 1.3 g、超调率 30%。
- **方法的使用**：$1.3/(1+0.3)$。
- **结论/预期输出**：约 **1.0 g**。**必须同时写**"这个换算只给方向与量级，原文明确说等效门槛降幅 ≠ 理论超调量（还叠加侧向载荷转移动态）"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 问"紧急避障/突然打方向，多少 g 会翻"（而不是"慢慢加到多少"）。
2. 要评估安全余量：准静态门槛留了 5–10%，够不够。
3. 要论证阻尼器/减震器是不是安全件。
4. 手上只有 ζ 或只有车型，问门槛该往哪边调。
5. 报告里用稳态门槛做安全边界，且输入被描述为"突然/紧急/瞬间"。

### 语言信号（中英双写）

- 「阶跃转向」「突然打方向」「紧急避障多少 g 会翻」「瞬态门槛」「超调」「overshoot」「阻尼比」「damping ratio」「减震器算不算安全件」
- 「留 10% 余量够不够」「准静态门槛打几折」「重型货车为什么降一半」
- 出现"ζ 0→50%""+1/3""−50%"这类锚点 ⇒ 命中本条

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `suspension-threshold-correction`：那张卡是**准静态**折减（约 −5%，几何机制）；本卡是**瞬态**折减（可达 −50%，动力学机制）。两者不可相加、不可互替。
- 与 `step-vs-sine-selection`：那张卡判"该不该用阶跃工况"；本卡假设已经是阶跃，算降多少。
- 与 `phase-lag-and-four-wheel-steer`：本卡的降幅来自**侧倾模态超调**；相位差是**横摆-侧倾耦合**导致侧向加速度本身变小，机制不同（且方向相反：一个压低门槛，一个压低实际 $a_y$）。
- 与 `tripped-rollover-energy`：绊倒时间尺度极短（零点几秒），悬架来不及吞吐能量，本卡的阻尼杠杆在那里几乎无效。

## E — 可执行步骤 (Execution)

**必需输入**：$t/2h$（或修正后门槛）+ 车型 + ζ（阻尼比，%;若未知则声明"未知/假定 0"）+ 输入形状（确认是阶跃类：突然施加、抱死松开、低 $\mu\to$ 高 $\mu$）。

**交付物与完成标准**：最坏端门槛 + 最好端（ζ=50%）门槛 + 判定口径 + "未说明"标记（轿车）。

1. **确认输入形状（判停点）**
   - 判据：输入建立时间与 $1/f_n$ 同量级 ⇒ 阶跃口径适用；是持续正弦/共振 ⇒ **停**，转 `step-vs-sine-selection`。完成标准：写出"本次按阶跃口径"。
2. **取最坏端**
   - 完成标准：ζ 未知 ⇒ 取 ζ=0（门槛最低）为设计下界；**重型货车**取 $\times0.5$（原文"近 50%"）；**轿车/多功能车**只写"低于 $t/2h$、降幅原文未说明"，**留空不给数**。
3. **取最好端**
   - 完成标准：ζ=50% ⇒ 轿车门槛升近 1/3（$1.3\to\approx1.73$ 的方向）；增长率递减，**不得**线性外推到 ζ>50%。
4. **禁止项自检（强制）**
   - 完成标准：逐条确认——①未从图 9.7 纵轴（0.25–1.25）反推任何车型数值；②未把"近 50%"套到轿车/SUV；③未把等效门槛降幅等同理论超调量；④未把"阻尼拉满"当无限收益。
5. **给方向性判据**
   - 完成标准：一句话"门槛随 ζ 单调上升，ζ=0 是最坏端；若某次计算得出反向，即为超调方向搞错"。
6. **交付**
   - 完成标准：模板句"该车 $t/2h=0.500$ g；阶跃工况按原文锚点取最坏端 $\mathbf{0.25}$ g（重型货车，−近 50%），设计下界用该值；轿车同类降幅原文未说明，只能写'低于准静态值'，不得报数。"

**计算约定（原书未规定，本卡设定）**：门槛 3 位小数；百分比给整数（"近 1/3""近 50%"保留原文措辞）；"未说明"是一个**合法输出**，不得用 0 或空白替代。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **用稳态门槛做安全边界、只留 5–10% 余量**（ce07，明确警告）。触发信号：余量 <20%、ζ 未知或假设为 0/临界、输入被描述为"突然/紧急"而模型里没有时间项。方向：**高估门槛 → 余量被超调吃掉**。
- **给轿车/SUV 的阶跃降幅报一个数**（硬伤 #6/G1）。原文该处 OCR 断裂；**任何**具体百分比（包括"约 10%""约 25%"）都是编造。合法写法只有："低于 $t/2h$，降幅原文未说明。"
- **从图 9.7 反推数值**（硬伤 #13）。纵轴刻度 0.25–1.25 与三条曲线的对应关系不可靠，只引趋势（ζ 越低门槛越低）。
- **把 −50% 套到轿车/SUV**。原文明确只属重型货车；两者在图上分处不同区间。
- **用超调率公式直接换算门槛**（ce07 边界）。等效门槛降幅 ≠ 理论超调量。
- **把本卡的结论外推到共振/绊倒工况**（F4 非反例）。阻尼改善的是**阶跃瞬态门槛**；原文没说正弦共振下同样有效，也没给最优 ζ；绊倒的时间尺度让悬架来不及吸收（见 `tripped-rollover-energy`）。
- **把"阻尼越高越好"推到无限**。增长率递减；原文无"足够"的设计目标值。

### 作者在书中警告的失败模式

- ce07（p243）："由于侧倾角超调，一个刚低于准静态临界值的侧向加速度阶跃转向操纵也有可能导致瞬态状况的侧翻"——这句直接推翻"留 5–10% 余量就安全"。
- p20（p242–p243）：超调的因果链（超调 → 瞬时侧倾角大于稳态 → 抬轮所需 $a_y$ 更低）是作者完整写出的。
- p21（p243）：三条结论（无阻尼最低、单调升且增长递减、0→50% 轿车 +近 1/3）均为原文——但轿车降幅那一栏断裂。

### 作者的盲点 / 时代局限

- **图 9.7 是本条唯一的信息载体，而它的数值在数字化中不可恢复**：所以"轿车降多少"永远只能是"未说明"。这是本章唯一"交付物的一部分拿不出来"的实质缺口（G1/task-07）。
- **"临界值的 50% 阻尼"这个基准的数值原文未给**；"阻尼比多少算够"也没有设计目标值。
- **未讨论超调峰值时刻与"两秒内翻完"的相互作用**：两条机制（瞬态超调、不稳定分支演化）本章没有合成分析。
- 1992 年、无可调阻尼/主动悬架：现代 CDC 能在阶跃瞬间提高阻尼，本卡的最坏端（ζ=0）在现代车上可能不成立，但"ζ 低即门槛低"的方向不变。

### 容易混淆的邻近方法论

- **准静态降 5% vs 阶跃降 50%**：数量级差 10 倍，是本章"余量虚高"的最大来源；两者不可相加。
- **超调（侧倾角峰值）vs 门槛（抬轮所需 $a_y$）**：前者是响应特征，后者是输出量；换算关系不是 1:1。
- **阻尼比 ζ（侧倾模态）vs 减震器软硬**：ζ 由减震器 + 悬架几何 + 轮胎共同决定，不是单个零件属性。
- **阶跃降幅（本卡）vs 相位差折减 0.5g/0.8g**：后者是侧向加速度**本身**变小（$\cos$ 合成的结果），方向相反，不能当门槛降幅用。
