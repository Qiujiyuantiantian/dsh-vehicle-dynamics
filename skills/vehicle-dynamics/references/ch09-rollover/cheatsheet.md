# 决策规则速查 — 《车辆动力学基础》第 9 章 车辆侧翻

| 能力 | 一句话规则 |
|---|---|
| 刚体准静态侧翻门槛 $t/2h$（含超高、$2h/t$、表 9.1），它是上限不是预测值 | $a_y/g=t/2h$ 只是**上限**；报值必须同时给 $2h/t$、表 9.1 区间与三笔折扣，禁止用它预测单车。 |
| 弯道超高与中性车速：$a_y/g=t/2h+\phi$，以及"$a_y=g\phi$ 不是最安全车速" | 超高是**加法项** $+\phi$（内侧低为正）；中性车速 $a_y=g\phi$ 是平衡点，不是推荐车速。 |
| 侧翻的三档判定：未离地 / 已离地可救 / 重心越线，以及为什么设计边界取"离地" | 离地＝侧翻**开始**，$\Phi=\arctan(t/2h)$ 才是**不可避免**；中间可救窗口不得计入安全裕度。 |
| 先翻还是先滑：门槛 vs 轮胎峰值 $\mu\approx0.8$，以及结论与统计冲突时该查什么 | $t/2h$ 与 $\mu_{peak}$ 比大小只是**稳态平路**判据；与统计冲突时判"适用域越界"，转机制清单，不判判据算错。 |
| 悬挂车辆的准静态门槛 式(9-6)：$1/(1+R_\phi(1-h_r/h))$，两笔各约 5% 的折扣 | $t/2h$ 除以 $1+R_\phi(1-h_r/h)$ 得实际门槛；$R_\phi$ 必须 rad/g；轮胎 −5% 是**独立第二笔**，不与悬挂 5% 相加。 |
| 手算够不够、折线怎么读、台架能不能用：四项机制、图 9.4 两个读数口径与倾斜平台 45° 陷阱 | 前后侧倾刚度差大/多轴 ⇒ 手算不够；读折线取**第二**根轴；$\theta>45°$ 的倾斜平台数据不可用。 |
| 阶跃还是正弦更危险：按侧倾共振频率分车型判别（货车怕变道，轿车怕阶跃） | 比"激励频率"与"侧倾共振频率 $f_n$"：$f\approx f_n$ ⇒ 正弦危险；$f\ll f_n$ ⇒ 阶跃危险。 |
| 阶跃工况的瞬态门槛：侧倾角超调把门槛压到准静态值以下，阻尼比是最坏端的开关 | 阶跃门槛低于准静态值；ζ=0 最坏（货车取 $\times0.5$）；轿车/SUV 降幅原文未说明，严禁编数。 |
| 前后轴相位差（1 Hz 时 0.2 s≈70°，$a_y$ 0.8→0.5 g）与四轮转向的"灵敏度换裕度" | 相位差压低实际 $a_y$（保护）却抬高驾驶员补偿需求（风险）；4WS 消除它 ⇒ 侧翻可能性增大。 |
| 挂车"抽鞭"：反相 180° + 放大，牵引车的小操纵翻掉全挂车——解法在挂钩，不在挂车 | 2 s 正弦 + 后车 $a_y$ 更大 + 近 180° 反相 ⇒ 抽鞭；措施是**保留相位差**的侧倾耦合挂钩，不是刚性连接。 |
| 绊倒侧翻的能量判据：旋转动能 + 重心升高势能 vs 抬到外侧轮上方所需势能 | 绊倒没有 $a_y$ 门槛；只能解读 E(t) 曲线（临界时动能分量≈0），不能从零算临界初速，23.075 不可移植。 |
| 事故统计怎么读：门槛与侧翻率相关但**不决定**，同门槛可差 3 倍 | 门槛↑⇒侧翻率↓是趋势，但发散大（同门槛差 3 倍）；只能做准入筛查，不能排名/定价/按比例预测收益。 |
| 侧翻法规准入门槛 1.2：达标初判怎么做，以及为什么它不是"安全线" | $t/2h\ge1.2$（无量纲）⇒ 达标；这是准入线不是安全线，原文无标准编号，严禁补 216。 |
| 先选模型层级，再算数：准静态的闸门、五个层级、以及每层"不能回答什么" | 五层模型答五个不同问题；输入建立时间与 $1/f_n$ 同量级 ⇒ 准静态失效，必须升级。 |
