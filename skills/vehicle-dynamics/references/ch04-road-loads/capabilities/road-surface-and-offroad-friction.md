# 典型 $f_r$ 表与路面层级：三车型 × 三路面，越野是 20 倍的量级跳变

## R — 原文 (Reading)

> **原书要点**（p104 §4.2 开篇）：若只求最粗一档的估算精度，完全可以把滚动阻力系数当成一个不随工况变化的定值。
>
> **原书要点**（p108）：以混凝土路面为例，轿车、重型货车、牵引车分别取 **0.015 / 0.012 / 0.02**；中等路面为 **0.08 / 0.06 / 0.04**；沙地为 **0.30 / 0.25 / 0.20**。
>
> **原书要点**（第4章 道路负载）：在非铺装的水平地面上行驶时，滚动阻力几乎是唯一的阻力来源；而在硬质路面上慢速行驶，它同样是运动阻力的主要成分。
>
> **原书要点**（p108–109 §4.2.2 式(4-16)）：路面系数 $C_h$ 的取值：光滑混凝土取 1.0，热拌沥青取 1.5。可以确定，路面越硬、越平整、越干，滚动阻力越小；若路面已被严重磨坏，阻力差不多翻一倍。
>
> — 4.2.2 典型表与式(4-16) 说明（p108–109）；4.2 开篇（p104）

## I — 方法论骨架 (Interpretation)

一句话：**路面不是一个标签，而是"材料 + 磨耗 + 湿度"三层状态；每一层都能让 $f_r$ 跳一档，而铺装路面与越野之间是 20 倍，不是 20%。**

- 典型表是**常数层级**的答案：只认"车型 × 路面大类"，精度 10%~20%。它的价值是"没有实测数据时的第一选择"，不是精细标定。
- 两条反直觉读数必须一起报：①**重车不一定 $f_r$ 高**——硬路面上重货 0.012 < 轿车 0.015 < 牵引车 0.02（轮胎结构与胎压的差别，不是重量的差别）；②**沙地上排序反转**——轿车 0.30 > 重货 0.25 > 牵引车 0.20。
- 量级意识：铺装 0.015 vs 沙地 0.30 = **20 倍**。这比任何其它修正项（温度 ±、胎压 ±、速度 ∝V⁰·⁵、侧偏 ×2）都大一个数量级。所以先判"这条路该不该换层级"，再谈精度。
- 铺装路内部还有两层：材料（$C_h$：混凝土 1.0 / 热沥青 1.5）与磨耗（"几乎加倍"，≈2.0）；湿度第三层只有定性（"更高的滚动阻力"）。
- 交付物：选用哪个层级 + $f_r$ 与 $R_x$ + 一条"这个数能支持什么结论"的精度声明。

## A1 — 应用示例 (Application Example)

### 示例 1：仓 B 轿车在沙地（引用数据 + 复算）

- **类型与来源**：**引用数据**（典型表 p108）+ 复算。
- **输入**：$W=3650$ lb、$f_r=0.30$（沙地）、55 mph（80.65 ft/s）、同工况风阻 $D_A=60.8$ lb。
- **方法的使用**：$R_x=0.30\times3650$；$hp=R_xV/550$；与 $D_A$ 比。
- **结论/结果（复算值）**：$R_x=\mathbf{1095}$ lb、$hp=\mathbf{160.6}$ hp；与同工况风阻之比 $\mathbf{18:1}$ → 验证正文"非公路水平地面滚动阻力是唯一主要阻力"。

### 示例 2：同车在三条路上的排序（引用数据 + 复算）

- **类型与来源**：**引用数据**（典型表）+ 复算。
- **输入**：$W=3650$ lb；$f_r$ = 0.015 / 0.08 / 0.30。
- **结论/结果（复算值）**：$R_x$ = **54.8 / 292.0 / 1095** lb。在沙地上，"把 $f_r$ 降 0.05"（1095→912.5，省 182.5 lb）比"把 $C_D$ 降 10%"（60.8→54.7，省 6.1 lb）收益大约 **30 倍**。

### 示例 3：$C_h$ 三层叠加的边界（合成演练，非书中事实）

- **类型与来源**：**合成演练**（把材料与磨耗两层叠起来，检验"能不能加"）。
- **输入**：仓 A 货车 72500 lb；$C_h=1.0$（光混凝土）→ 1.5（热沥青）→ ≈2.0（磨损路面）。
- **结论/预期输出**：$f_r$ = **0.006847 / 0.01027 / 0.01369**；$R_x$ = **496.6 / 744.6 / 992.5 lb**。注意：磨损"几乎加倍"是**在已有材料系数之上再乘**，不是加 0.5；且湿路还有第三层，本章无数值。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 问"沙地/碎石/土路上滚阻多少""越野油耗为什么这么高"。
2. 没有实测数据，要从表里取一个 $f_r$。
3. 问"重卡是不是滚阻更高"（反直觉：硬路上不一定）。
4. 问"热沥青比混凝土高多少""磨损路面高多少"。
5. 判断一个 1%~5% 的模型改进有没有意义（vs 20 倍的层级错）。

### 语言信号（中英双写）

- 「沙地滚阻系数」「越野油耗」「典型滚阻表」「重卡和轿车的滚阻」「热沥青路面系数」
- 「rolling resistance table」「off-road」「sand」「unpaved」「road surface coefficient」「C_h」
- 反向信号：「用 0.015 算一下这条土路」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `rolling-resistance-baseline`：那张卡是"$f_r$ 已知怎么乘"；本卡是"这条路该给多少 $f_r$"。
- 与 `rolling-resistance-coefficient-models`：本卡的 $C_h$ 1.0/1.5 是式(4-16) 的**参数档**；"用哪个式子、幂律段怎么给"在那张卡。
- 与 `rolling-resistance-state-corrections`：本卡管"路面本身（材料/磨耗/湿度）"，那张卡管"轮胎状态（预热/胎压/磨损/侧偏）"；两者都改 $f_r$，但**来源不同、不可互借量级**。
- 与 `road-load-and-power`：本卡给第一项的输入，那张卡做合计与功率。

## E — 可执行步骤 (Execution)

**必需输入**：车型（轿车/重货/牵引车）+ 路面大类（铺装/中等/沙地或非铺装）+ 路面材料（混凝土/沥青）+ 路面状态（新/磨损/潮湿）+ 精度要求。**缺路面大类不得取 $f_r$**。

**交付物与完成标准**：层级选择（表值 or 越野层级）+ $f_r$ 数值 + 精度声明（常数层级 → 10%~20%）+ （可选）$C_h$ 的乘子链 + 一句"这条路上滚阻是不是唯一主项"的判定。

1. **先判层级（判停点）**
   - 判据：铺装 vs 非铺装。
   - 完成标准：铺装 → 走典型表 + $C_h$；非铺装/沙地 → 走越野层级（0.08 与 0.30 之间**没有可插值的物理意义**，因为耗散路径不同：轮胎迟滞 → 地面变形）。
2. **查表取值**
   - 完成标准：写出车型行与路面列；同时报两条反直觉读数（硬路重货 < 轿车；沙地排序反转）。
3. **叠 $C_h$（仅铺装 + 式 4-16 口径）**
   - 完成标准：$C_h$ 写成**乘子**；材料层 1.0/1.5、磨耗层 ≈2.0 分别标注来源；湿路只给"更高"的定性。
4. **算 $R_x$ 与精度声明**
   - 完成标准：$R_x=f_rW$；精度声明必须与层级匹配（常数层级不许报 5%）；若用户要求 5% → **拒绝**并说明要实测。
5. **判"是不是主项"**
   - 完成标准：给 $R_x$ 与同工况 $D_A$ 的比值；比值 >5 时明确写"滚阻是唯一主项，先改这里"。
6. **交付**
   - 完成标准：一句话"该车 3650 lb 在沙地 $f_r=0.30$ → 1095 lb、55 mph 需 160.6 hp，是同工况风阻的 18 倍"。

**计算约定（原书未规定，本卡设定）**：$f_r$ 保留 3 位小数（表值原样）；$R_x$ 保留 3~4 位有效；$C_h$ 只取 1.0/1.5/≈2.0 并注明"≈"的含义。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **用铺装路面的 $f_r$ 估越野/沙地。** 0.015→0.30 是 **20 倍**，误差量级远大于任何其他修正项（ce31）。检出信号：越野工况用公路 $f_r$；同一 $f_r$ 用于硬土与沙；用"沙地 0.30"解释所有非铺装路面。
- **在 0.08 与 0.30 之间插值。** 两者是两条不同的耗散路径（路面变形主导 vs 轮胎迟滞主导），中间值**没有物理意义**。
- **用表值做精细油耗对标。** 它是"常数层级"，精度 10%~20%；要求 5% 精度 → 拒绝（p33 判停）。
- **$C_h$ 一律取 1.0。** 忽略磨耗（≈×2）与潮湿（更高）（ce33）。反过来，也不能拿 $C_h$ 编码湿地——湿路机制是"胎温→柔度→迟滞"，不是路面变形。
- **把 $C_h$ 当加项、或与 $C_D$ 混。** $C_h$ 是乘在 $f_r$ 上的路面系数（OCR 常作 `C，`）。
- **把"牵引车"当"牵引车-挂车组合"。** 表里的"牵引车"是 tractor（单轴驱动单元），与 tractor-trailer 组合不是同一对象（p33 边界）。
- **把"sand 0.30"外推到硬土/碎石。** 表只给三档，中间地形没有条目；外推等于编造。
- **跨仓搬 $f_r$。** 仓 A 用货车式得 0.00685（不是表值）；仓 B 用设定值 0.02。**仓 B 的 0.02 与表里"牵引车 0.02"同值不同义。**

### 作者在书中警告的失败模式

- ce31：用铺装路面 $f_r$ 估越野（p104 + 七机制第(5) 项）。
- ce33：$C_h$ 一律取 1.0（p109）。
- p33 判停：要求 5% 精度时不得用本表。

### 作者的盲点 / 时代局限

- 表只有三档路面 × 三车型，1992 年口径；现代碎石路、草地、雪地、泥地均无条目。
- 湿路的"更高"没有数字；磨耗只有"几乎加倍"这一个量级。
- "非公路是唯一主项"这句话只在低速水平地面成立；高速时风阻仍会反超（交叉点见 `road-load-and-power`）。
- 未讨论越野时的轮胎变形/胎压联合优化（那部分在 `rolling-resistance-state-corrections` 的胎压段）。

### 容易混淆的邻近方法论

- **路面层级（0.015 vs 0.30）vs 路面材料（$C_h$ 1.0 vs 1.5）**：前者是 20 倍跳变，后者是 50%；混用会把 20 倍的事当 50% 修。
- **$f_r$ 表 vs 经验式**：表是常数层级，式(4-14)(4-15)(4-16) 是速度相关层级，混用会重复计入速度效应。
- **"重车 $f_r$ 高" vs "胎压高 $f_r$ 低"**：硬路上重货 $f_r$ 反而更低（胎压高、胎体结构不同）。
- **滚阻大 vs 附着好**：沙地的 0.30 是"能量耗散大"，不是"抓地好"。
