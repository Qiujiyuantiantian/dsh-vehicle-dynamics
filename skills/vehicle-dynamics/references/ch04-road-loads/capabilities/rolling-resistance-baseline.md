# 滚动阻力基线：$R_x=f_rW$，用静态重量就够，只对直线成立

## R — 原文 (Reading)

> **原书要点**（p104–105 §4.2.2 式(4-12)）：以整车为对象时，前后各轮所受阻力加总即总滚阻，可写成 $R_x=f_rW$，也就是 $R_{xf}+R_{xr}$ 之和。
>
> **原书要点**（第4章 道路负载）：综合上述原因，求滚动阻力时一般直接用静态重量，精度已经够用。若改用动态重量，只会让计算变复杂，精度却并未明显提高，况且还要"忽略空气升力"。
>
> **原书要点**（p104–105 §4.2.2）：严格讲，前面那套算法只在走直线时成立。一旦车辆被侧向力（过弯或气动载荷）推着，滚阻的指向就不再与实际运动方向重合，此时驱动力要平衡的是侧向力与滚阻的矢量和。
>
> — 4.2.2 式(4-12)（p104–105）

## I — 方法论骨架 (Interpretation)

一句话：**滚阻是"整车重量 × 一个经验系数"，不是"轮子越多越大"，也不是"路面越滑越小"。**

- 公式只有两个输入：$W$（车辆重量 lb）与 $f_r$（无量纲经验系数）。七个耗散机制全部被 $f_r$ 打包了，本章不给理论公式，只给经验值与经验式。
- **静态重量就够**是一条被作者明确推荐的工程取舍：$R_x=R_{xf}+R_{xr}=f_r(W_f+W_r)=f_rW$，只要前后 $f_r$ 相同，轴荷怎么转移总和都不变。用动态重量白增状态量而无精度收益。
- 反过来说，只有当**前后 $f_r$ 不同**（不同胎、不同胎压、驱动轴差异）时，载荷转移才有**一阶**影响——此时该修的是 $f_r$ 的差异，不是把整套动态轴荷搬进来。
- 前提是**直线**。有侧向力时滚阻方向偏离行驶方向，必须做矢量合成；本章只给这个要求，**不给合成公式**（定量属第 5/6 章）。
- 认知纠正两条：①$f_r$ ≠ 摩擦系数（量级差两个数量级、物理机制不同）；②"路面越滑滚阻越小"是错的——沙地 0.30 是混凝土 0.015 的 20 倍，因为路面变形机制占了主导（见 `road-surface-and-offroad-friction`）。
- 交付物：一个 lb 数 + 一句"用的是静态重量、直线前提、$f_r$ 出处"。

## A1 — 应用示例 (Application Example)

### 示例 1：例题 1 的货车滚阻（原书例题，引用数据）

- **类型与来源**：**原书例题 1**（p111–112）。
- **输入**：$W=72500$ lb、$f_r=0.00685$（由式(4-16a) 在 67 mph、$C_h=1.0$ 算得，见 `rolling-resistance-coefficient-models`）。
- **方法的使用**：$R_x=f_rW=0.006847\times72500$。
- **结论/结果（复算值）**：$R_x=\mathbf{496.6}\to$ 书印 **497 lb**；$hp_R=R_xV/550=496.6\times98.3/550=\mathbf{88.8}$ hp。
- **注意**：书里把式(4-16a) 的结果印成"0.00685 **lb**"——**$f_r$ 无量纲**，这是排版/OCR 错，照录但不改，引用时按无量纲处理。

### 示例 2：仓 B 轿车的三个口径（引用数据 + 复算）

- **类型与来源**：p30 的复算演练（**引用数据**：$f_r=0.02$ 是 4.3 节示例车的设定值，$0.015$ 是典型表值）。
- **输入**：$W=3650$ lb；$f_r=0.015$（常数层级典型值）与 $f_r=0.02$（4.3 示例车）。
- **结论/结果（复算值）**：$0.015\times3650=\mathbf{54.8}$ lb；$0.02\times3650=\mathbf{73.0}$ lb。

### 示例 3：轴荷怎么转移都不影响总和（合成演练，非书中事实）

- **类型与来源**：**合成演练**（ce22 的关键复算）。
- **输入**：总重 3650 lb、$f_r=0.02$；轴荷分两种：2100/1550 与 2400/1250。
- **方法的使用**：$R_x=f_rW_f+f_rW_r=f_r(W_f+W_r)$。
- **结论/预期输出**：两种分法都得 **73.0 lb**——只要前后 $f_r$ 相同，转移对总和**零影响**。若前后 $f_r$ 不同（例如前 0.02、后 0.015）：$0.02\times2100+0.015\times1550=\mathbf{65.3}$ lb，与 73.0 差 **10.6%** → 此时该修 $f_r$ 的差异，不是引入动态轴荷。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 问"这车滚阻多少磅""滚阻占道路负载多少"。
2. 要判断"要不要用动态轴荷算滚阻"（能不能更准）。
3. 问"弯道/制动时滚阻怎么算"。
4. 拿到 $f_r$ 与车重，要做道路负载的第一项。
5. 有人把滚阻当"摩擦"处理（路面越滑越小）。

### 语言信号（中英双写）

- 「滚动阻力多少」「滚阻系数乘车重」「要不要用动态轴荷」「弯道滚阻」「滚阻和摩擦的区别」
- 「rolling resistance」「R_x」「rolling resistance force」「tire drag」「hysteresis」
- 反向信号：「滚阻是不是摩擦力」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `rolling-resistance-coefficient-models`：本卡只做"$f_r$ 已知时怎么算力"；"$f_r$ 该取多少、用哪个经验式"→ 那张卡。
- 与 `rolling-resistance-state-corrections`：本卡默认 $f_r$ 是一个给定的数；"温度/胎压/速度/材料/侧偏怎么改这个数"→ 那张卡。
- 与 `road-surface-and-offroad-friction`：本卡用铺装路的 $f_r$；"这条路该不该换层级（越野/沙地）"→ 那张卡。
- 与 `road-load-and-power`：本卡出第一项，那张卡做三项相加与功率。
- 与第 3 章制动：制动时的滚阻是"帮手"，符号与本章（阻碍）相反——跨章引用须改号。

## E — 可执行步骤 (Execution)

**必需输入**：$W$（车辆总重 lb，**静态**）、$f_r$（无量纲，须给来源与层级）。**缺 $f_r$ 的来源不得开算**（本章不给估算法，只有典型表与经验式）。

**交付物与完成标准**：$R_x$ 一行（公式、代入、结果 lb）+ 口径声明（静态重量、直线、$f_r$ 出处与精度层级）+ 一句"是否需要用动态重量"的判定 + （若给车速）对应功率。

1. **确认 $W$ 的口径**
   - 完成标准：写出"$W$=整车静态重量 ___ lb"；若用户给的是满载/空载两值 → 各算一次，不给单值。
2. **确认 $f_r$ 的层级**
   - 完成标准：写明 $f_r$ 来自"典型表常数层级 / 线性式 / 幂式 / 货车双式"中的哪一个，以及它的精度层级；**不同层级不可混用**（会重复计入速度效应）。
3. **算 $R_x$**
   - 完成标准：$R_x=f_rW$，单位 lb；同时给出 $R_x/W$ 反算（应回到 $f_r$）。
4. **判"要不要动态重量"（判停点）**
   - 判据：前后 $f_r$ 是否相同。
   - 完成标准：相同 → 明说"轴荷转移对总和零影响，用静态重量"；不同 → 用加权和 $f_{rf}W_f+f_{rr}W_r$，并修 $f_r$ 的差异而不是引入动态轴荷模型。
5. **判直线前提**
   - 完成标准：若工况含转弯/侧向风 → **停**，声明"本公式只适用直线；有侧向力须用矢量合力（本章无公式）"，并给出下界估计而不是单值。
6. **交付**
   - 完成标准：一句话"该车 3650 lb、$f_r=0.02$，滚阻 73.0 lb；用静态重量即足够（前后同为 0.02 时轴荷转移不改变总和）"。

**计算约定（原书未规定，本卡设定）**：$R_x$ 保留 3 位有效（lb）；$f_r$ 保留 4 位小数；精度声明必须与 $f_r$ 的层级匹配（常数层级不报 1%）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **把 $f_r$ 当摩擦系数 $\mu$ 用。** 量级差两个数量级（$\mu$ 0.7~1.0 vs $f_r$ 0.012~0.30），物理机制也不同（迟滞 vs 接触剪切）。拿 $f_r$ 去算制动距离或附着极限是跨体系错误。
- **用动态重量算滚阻。** 作者明说静态就够（ce22）；动态重量使计算复杂化而无显著精度收益。**括号里的"忽略空气升力"是硬条件**：$C_L$ 接近 1（侧风）时静态不再够用。
- **把 $R_x=f_rW$ 用在转弯、制动、驱动工况。** 有侧向力时滚阻方向偏离行驶方向，必须矢量合成（p31）；本章**不给**合成公式与侧偏修正因子，只能给"下界 + 修正项"或拒绝给单值。
- **以为"路面越滑滚阻越小"。** 沙地 0.30 是混凝土 0.015 的 20 倍（路面变形机制主导）；机制切换见 `road-surface-and-offroad-friction`。
- **在同一个报告里混用不同层级的 $f_r$。** 常数层级 + 速度式 = 速度效应被计两次；反过来用常数层级却要求 5% 精度也是越界。
- **忘记 $f_r$ 无量纲。** 原文（OCR/排版）曾把它写成"0.00685 lb"；引用时按无量纲处理并注明。
- **跨仓搬 $W$ 与 $f_r$。** 仓 A 是 72500 lb 货车 + 货车式 $f_r$；仓 B 是 3650 lb 轿车 + **设定值 0.02**。**仓 B 的 0.02 与典型表里"牵引车 0.02"同值不同义**（一个是示例车设定，一个是车型表值），不得互引。

### 作者在书中警告的失败模式

- ce22：为"精确"用动态重量算滚阻（p104–105 整段）。
- p31：滚阻公式只适用直线；有侧向力须矢量合成（p105）。
- p30 边界：忽略空气升力（括号条件）。

### 作者的盲点 / 时代局限

- 七个机制只有定性清单，无逐项定量贡献（图 4.29–4.33 的曲线数值不可读）。
- $f_r$ 的"常数层级"是 1992 年轮胎口径；现代低滚阻胎的绝对值已系统性偏低，借用时必须重标定。
- 挂车拖挂力、驱动轴与非驱动轴的差异只在"前后 $f_r$ 不同"这一层提到，未展开。

### 容易混淆的邻近方法论

- **$R_x$（滚阻合力，lb）vs $f_r$（无量纲系数）vs $\mu$（附着系数）**：三个量、三套体系。
- **静态重量（推荐）vs 动态重量（不必要）**：只有在前后 $f_r$ 不同时才有一阶差别。
- **滚阻（阻碍前进）vs 制动时的滚阻（帮制动）**：同一物理量，符号随语境变。
- **滚阻 vs 路面变形阻力**：后者已包含在 $f_r$ 的机制 (5) 里，不是另加一项。
