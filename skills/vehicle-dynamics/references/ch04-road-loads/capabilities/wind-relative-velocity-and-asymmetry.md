# 顺逆风与相对速度：$V=V_v\pm V_w$，平方项让"逆风代价 > 顺风收益"

## R — 原文 (Reading)

> **原书要点**（第4章 道路负载）：自然风迎面吹来即"逆风"，式（4-2）里的总速度取 $V=V_v+V_w$；与行车方向一致的风为"顺风"，此时两速度相减。式（4-2）中速度以平方出现，所以同样风速下，顶风所添的阻力比顺风所省的阻力大得多。
>
> **原书要点**（p97 §4.1.6 式(4-5)）：从统计角度看，相对风相当于在圆周上随便挑一点画出的矢量，于是实际道路上的平均阻力并不能简单由平均车速推出来。这里的关键变量是 $C_D$ 怎样随侧风分量改变。
>
> — 4.1.6 式(4-5)（p97）；例题 2（p112）

## I — 方法论骨架 (Interpretation)

一句话：**风不是加到"阻力"上，而是加到"速度"上——先把车速与风速合成相对速度，再平方。**

- 这条规则之所以反直觉，是因为人的直觉是"加减风阻"。实际链条是：$V\pm v$ → 平方 → 阻力。于是 $(V+v)^2-(V-v)^2=4Vv>0$，**逆风的增量永远大于顺风的减量，且对任意 $(V,v)$ 恒成立**（与 $V$、$v$ 的取值无关）。
- 所以"顺逆风平均一下等于无风"在数学上就不成立。这条路线上做经济性计算，任何"用平均风速算平均阻力"的做法都会系统性低估——因为 $E[(V+v)^2]=V^2+\sigma^2>V^2$，风速的方差本身就是在增加阻力。
- 第二个偏差来自 $C_D$：有偏转角时 $C_D$ 还要再涨 5%~10%，与上面那一重偏差**同号**。
- 三个锚点（无风/逆风/顺风）是这条规则的完整表达：只要报告里缺一个，"不对称"这件事就没被表达出来。
- 判据层面的用法：**不要问"今天风大不大"，要问"逆风占多少比例的小时数"**。

## A1 — 应用示例 (Application Example)

### 示例 1：例题 2 的三工况（原书例题，引用数据）

- **类型与来源**：**原书例题 2**（p112）。**题干在 OCR 中丢失**，车型未说明（记为仓 C）；$A=21$ ft²、$C_D=0.42$ 是解答式里的**显式代入值**，非推测。
- **输入**：$V_v=55$ mph、风速 25 mph（逆/顺）、$A=21$ ft²、$C_D=0.42$、$\rho=0.00236$。
- **方法的使用**：①逆风 $V=55+25=80$ mph；②顺风 $V=55-25=30$ mph；③各自 ÷0.682 得 ft/s，$q=\rho V^2/2$，$D_A=qC_DA$。
- **结论/结果（复算值）**：无风 $V=80.65$ ft/s → **$D_A=67.7$ lb（书印 68）**；逆风 $V=117.30$ ft/s → **143.2 lb（书印 143）**；顺风 $V=43.99$ ft/s → **20.1 lb（书印 20）**。增量 **+75.5 lb（+112%）** vs **−47.6 lb（−70%）**，比值 1.59；按书印整数计为 +110%/−71%。
- **原书未给的部分**：题目要求"空气阻力和所需马力"，解答**只给阻力，未给马力** → 马力留空，不代填。

### 示例 2：另一组车速与风速（合成演练，非书中事实）

- **类型与来源**：**合成演练**（自造 $V_v,v$，与例题 2 的 55/25 不同）。
- **输入**：60 mph 车、$\pm15$ mph 风、$A=21$ ft²、$C_D=0.42$、$\rho=0.00236$。
- **方法的使用**：同三步；另算 $E[V^2]$ 的偏差作对照。
- **结论/预期输出**：无风 **80.6 lb**、逆风（75 mph）**125.9 lb（+45.3，+56%）**、顺风（45 mph）**45.3 lb（−35.3，−44%）**；加 45.3 > 减 35.3，不对称方向一致。若取风速标准差 5 mph 做平均（本例车速 60 mph）：$E[V^2]=60^2+5^2=3625$ 对 $(E[V])^2=3600$，**+0.69%**，再叠加 $C_D$ 的 +5%~10%，两重同号。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 问"今天 25 mph 逆风，风阻多少""顺风能省多少油"。
2. 做线路/季节对比，想用"平均风速"折算成平均阻力。
3. 问"顺逆风是不是能互相抵消"。
4. 发现高速实测阻力比计算高 5%~10%，怀疑是风的问题，要拆成"速度项 + 偏角项"。
5. 车队管理：大风季油耗上升，要判断有多少是风、多少是路况。

### 语言信号（中英双写）

- 「逆风风阻」「顺风省多少」「风速 25 mph 时阻力」「顺逆风能不能平均」「平均风速」
- 「headwind」「tailwind」「relative wind」「crosswind component」「average wind speed」
- 反向信号：「风玫瑰两边对称所以抵消」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `aero-drag-and-power`：那张卡是"无自然风"的单工况全链；本卡是它的**风况分支**，多出"相对速度合成 + 三工况 + 不对称"三件事。单工况问"风阻多少"→ 那张卡。
- 与 `crosswind-sensitivity-and-tradeoff`：本卡只处理**纵向**分量（$V\pm v$）；一旦风有侧向分量、问题变成"车会不会被吹偏"→ 转那张卡（它管 CP/NSP 与横摆）。
- 与 `road-load-and-power`：本卡出的是 $D_A$ 的三种取值；把它们与滚阻/坡阻相加、算总功率 → 那张卡。
- 与 `fuel-economy-chain-and-attribution`：本卡不说"省多少油"，只说"阻力变了多少"。

## E — 可执行步骤 (Execution)

**必需输入**：车速 $V_v$（mph）、风速 $v$（mph）、风与车的相对方向（逆风/顺风/有侧向分量）、$A$（前端投影 ft²）、$C_D$、$\rho$（默认标准 0.00236 并声明）。**缺风速或方向不得开算**。

**交付物与完成标准**：三行表（无风 / 逆风 / 顺风：$V$、$q$、$D_A$）+ 两个增量与其比值 + 一句不对称结论 + 口径声明（只含纵向分量）。

1. **判方向（第一步，决定走哪条路）**
   - 完成标准：明确写出"风是逆风/顺风/偏转角 $\delta$"。**若有侧向分量：停**，说明本卡的 $(V\pm v)$ 只处理纵向分量，侧向须走偏转角→$C_D$（转 `crosswind-sensitivity-and-tradeoff`），否则会低估。
2. **合成相对速度**
   - 完成标准：逆风 $V=V_v+v$、顺风 $V=V_v-v$；若 $V_v-v\le0$ 立即判"顺风超过车速，阻力反向"，停。
3. **算三个 $D_A$**
   - 完成标准：三行都算出并给出书印/复算两列（若有原书锚点）。
4. **算增量与比值**
   - 完成标准：$\Delta_+=D_{逆}-D_{无}$、$\Delta_-=D_{无}-D_{顺}$；报 $\Delta_+/\Delta_->1$ 并给比值；**必须写出"不对称恒成立"的代数依据 $4Vv>0$**，而不只是"这次是这样"。
5. **平均风分支（判停点）**
   - 判据：用户若要求"用平均风速代表全年/全线路"→ **停**，改为输出"方向 + 同号 + 必须给风速分布"。
   - 完成标准：给出 $E[V^2]-V^2=\sigma^2$ 的偏差量级（有 $\sigma$ 才算，无 $\sigma$ 只给定性），并声明本章不给风速分布模型。
6. **交付**
   - 完成标准：一句话"55 mph 车遇 25 mph 风：无风 68 lb、逆风 143 lb（+112%）、顺风 20 lb（−70%）；加的是减的 1.6 倍"。

**计算约定（原书未规定，本卡设定）**：$D_A$ 保留 3 位有效（lb），增量百分比保留整数；mph→ft/s ÷0.682；$\rho$ 用标准值时必须声明。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **假设顺风收益 = 逆风损失。** 这是本章最反直觉的一条（ce10）。量化：+75 lb（+110%）对 −48 lb（−71%）；净效应恒偏向"风使阻力上升"。用平均风速做线性修正、或假设风玫瑰对称"互相抵消"，都会系统性低估。
- **用平均风速算平均阻力。** 作者原话是"不简单的等价于车辆的平均速度"（ce11）。两重偏差同号：$E[V^2]>V^2$（量级 $\sigma^2/V^2$：本例 60 mph、$\sigma$=5 时为 **+0.69%**，随 $\sigma$ 变）+ $C_D$ 随偏角 +5%~10%。**本章不给风速分布模型**，所以只能给方向与"同号"，不给固定百分比。
- **把含侧向分量的风塞进 $(V\pm v)$。** 一旦有侧向分量，必须走偏转角→$C_D$（$C_S$、$C_{YM}$ 也随之出现）；只用纵向公式会把横风工况算成"顺风"或"逆风"。
- **把 mph 的 $V$ 直接代进式(4-2)。** 见 `aero-drag-and-power` 的 ce03；反向地，把 ft/s 代进 $f_r$ 经验式同样错。
- **照抄例题 2 的公式号。** 原书解答写"用方程(4-4) 计算相对速度"，而 **(4-4) 是 $C_D$ 的定义式，应为式(4-5)**——这是原文笔误，照录不改，但引用时必须指出。**同时：题干在 OCR 中丢失，车型/车重不在源文本内，不得补。**
- **把例题 2 的参数用于其它算例。** 仓 C（55 mph、$A=21$、$C_D=0.42$、车型未知）与仓 A（货车）、仓 B（3650 lb 轿车）互不相通；**仓 C 的 $C_D=0.42$ 与阻力分解表的"合计 0.42"纯属数值巧合，严禁互引**；$\rho$ 用标准 0.00236，**不得借用仓 A 的 0.00207**。
- **把本卡的结论用到阵风上。** 阵风是瞬态，本章模型是稳态；"逆风代价 > 顺风收益"是稳态结论，不预测阵风冲击。

### 作者在书中警告的失败模式

- ce10：以为顺风收益等于逆风损失（p97 原话 + 例题 2 三数）。
- ce11：用平均风速算平均阻力（p97 原话，并给出第二重偏差——$C_D$ 随侧风分量变化）。
- ce12：用零偏角 $C_D$ 算有偏转角的实际行驶（p98）。

### 作者的盲点 / 时代局限

- 只给"自然风典型 10–20 mph、大风 50–60 mph"的量级，不给风速分布/风玫瑰的处理方法；经济性归因因此只能定性。
- 偏转角→$C_D$ 只有曲线（图 4.23，读数不可用）与 5%~10% 经验带，**没有解析式**。
- 未讨论阵风、侧风与纵向风同时存在的瞬态叠加；也未讨论车队层面的统计口径（逆风小时数占比）。
- 例题 2 只给阻力、不给马力，题干丢失——原文证据到此为止，**不得为了"完整"而补一个车型或一个马力值**。

### 容易混淆的邻近方法论

- **气象风 vs 相对风**：所有公式里的 $V$ 是相对风（车速矢量 + 自然风矢量的模），不是天气预报的风。
- **偏转角 $\delta$ vs 轮胎侧偏角 $\alpha$**：两个都是"角"，前者是气动的，后者是轮胎力学的（第 5/6 章），混用会污染两套分析。
- **"逆风更费油" vs "逆风增量大于顺风减量"**：前者是一阶事实，后者才是本卡的量化结论（1.6 倍）。
- **nc01（顺风确实减阻）**：本卡不能因为"不对称"就删掉顺风项——68→20 lb（−71%）是真实收益，错的是"相等"，不是"减阻"。
