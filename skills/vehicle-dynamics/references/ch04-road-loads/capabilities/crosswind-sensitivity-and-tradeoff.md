# 横风敏感度与降阻取舍：看 CP–NSP 的距离，不看 CP 的坐标；灵敏度随速度上升

## R — 原文 (Reading)

> **原书要点**（p101 §4.1.12）：要判断一辆车怕不怕横风，关键气动参数有两个：压力中心（CP）落在何处，以及它比中性转向点靠前多少。
>
> **原书要点**（第4章 道路负载）：把轴距加大，或把轮胎侧偏刚度的有效值调高，都能让分母变大，从而压低横风敏感度……然而车速升高会使上述力臂大幅缩短，所以速度越快，横风敏感度反而越高。
>
> **原书要点**（第4章 道路负载）：各车在主观评价上的差别，几乎都能用它们在侧风中的横摆率响应来解释（拟合 $y=2.488x+2.464$，$r^2=0.974$）。
>
> **原书要点**（p101–104 §4.1.12）：汽车气动造型持续优化，而阻力下降的同时往往伴随横风敏感度上升，这两件事是绑在一起发生的。
>
> **原书要点**（p101–104 §4.1.12）：前面的讨论建立在静态假设上，可能漏掉了若干同样牵动整车横风敏感度的动态特性。例如侧倾柔度——一旦它经悬架放大成侧倾转向，其影响就超出简化分析能覆盖的范围。
>
> — 4.1.12（p101–104），式(4-11) 变量表与正文；图 4.27

## I — 方法论骨架 (Interpretation)

一句话：**横风敏感度不是一个力，而是"压力中心离中性转向点多远"加上"这车多快"共同决定的响应增益——它的分母在 OCR 里坏了，所以只能给方向，不能给公式。**

- 结构（只保留定性）：分子里有"CP 到 NSP 的距离"与 $C_{YM}$ 项，分母里有轮胎侧偏刚度与一个随速度变小的力臂。作者明确点出：**分子第二项就是"中性转向点至空气动力学压力中心的距离"**。
- 三条可操作结论（都有原话）：①CP 越靠近 NSP，车道偏离越小；②加长轴距、提高轮胎有效侧偏刚度（高侧偏刚度胎 + 消除转向/悬架柔度）能拉大分母；③速度上升会侵蚀这条力臂，**所以高速的横风问题不能用低速数据验收**。
- 这里的"敏感度"是**人-车-风闭环**属性：气动、车辆动力学、转向系统、驾驶员四类因素。因此它不能被"侧向力大小"替代。
- 评价代理：横摆率响应能解释主观评价的绝大部分差异（$r^2=0.974$，$n=7$ 台改型车）。但它**只能排序**：截距 2.464 与"1=基准线"的零点关系未澄清，绝对分值不可引；也不能跨车型外推。
- 整章唯一的反单目标优化结构：**降阻与横风敏感度相伴随**。作者只说"相结合"，未证明因果——所以本卡一律写成条件式（"若 CP 前移或 CP–NSP 变大 → 记账"），不断言"降 $C_D$ 必然增敏感度"。
- **硬约束**：式(4-11) 的分母在 OCR 中损坏（变量表有 $C_f/C_r$ 与 $\xi_d$，正文说分母含"轮胎力横摆阻力矩的力臂"，但只剩 $(d_{ns}+\xi_d)$）→ 本卡**不写、不引任何 $r/\alpha$ 公式或数值**。重建前，横风敏感度只能定性。

## A1 — 应用示例 (Application Example)

### 示例 1：降阻方案的横风记账（框架演练，输入为假定值）

- **类型与来源**：**合成演练**（f12 的 V2 框架演练；原书只给七构型定性对比，无此算例）。
- **输入/问题**：某方案把 $C_D$ 从 0.34 降到 0.30，尾部收缩更陡。
- **方法怎么执行**：①重算 CP 相对 NSP 的位置（转 `aero-moments-and-pressure-center` 反算 CP）；②若两者距离变大 → 判"降阻换来的敏感度上升"并**显式记账**；③先在非气动侧找补偿（重心后移 / 降侧倾刚度 / 提高有效侧偏刚度）；④用横摆率响应做排序代理；⑤任何"纯降阻"结论必须附横风与升力两句。
- **结论/预期输出**：若给不出 CP 或 NSP 任一位置 → 输出"需实测"，**不得给结论**；若能给出 → 交付"降阻 $\Delta C_D=-0.04$ + 敏感度方向上升 + 待补偿项清单"三行。

### 示例 2：横摆率响应只作排序（引用数据 + 复算）

- **类型与来源**：**原书回归式**（图 4.27，$n=7$）；复算用于说明"只能排序"。
- **输入**：$y=2.488x+2.464$；两台车 $x=0.8$ 与 $x=1.6$（正则化均方根横摆率，无单位）。
- **方法的使用**：代入求 $y$，只比较大小，不报绝对分。
- **结论/预期输出**：$y(0.8)=\mathbf{4.45}$、$y(1.6)=\mathbf{6.45}$ → 排序 4.45 < 6.45；每 +1 单位正则化横摆率 ≈ **2.49 分**（评分尺度 1–10）。**判停**：截距 2.464 与"1=基准线"不自洽（$x=0$ 时应为 1），故绝对分值不可引；样本只有 7 台改型车，跨车型外推 → 拒绝。

### 示例 3：速度陷阱（决策演练，输入为假定值）

- **类型与来源**：**合成演练**（ce18 的 V2；"超线性"说法已在阶段 1.5 作废）。
- **输入**：某车只在 60~80 km/h 场地做了横风试验，报告称"高速没问题"。
- **结论/预期输出**：判**无效**——用低速数据外推 120 km/h 属越界；只保留"随速度上升"的方向，**不给指数、不写"超线性"**。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 问"这车横风稳不稳、侧风为什么总要修方向"。
2. 降阻方案评审：$C_D$ 降了，横风会不会变差、要不要补偿。
3. 问"压力中心该往前还是往后""要不要加配重/换高侧偏刚度胎"。
4. 横风试验报告只有低速数据或只有静态增益，要判断能不能验收。
5. 两台车横风主观评价差异大，要找可测的代理指标。

### 语言信号（中英双写）

- 「横风敏感度」「侧风发飘」「CP 和 NSP」「压力中心位置」「横摆率响应」「高速更飘」
- 「crosswind sensitivity」「CP vs NSP」「yaw rate response」「lane keeping in crosswind」「static margin」
- 反向信号：「侧向力大所以横风差」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `lateral-force-and-lift`：那张卡给"风推多狠"（$S_A$、$L_A$），本卡给"这车对这种推力有多敏感"。**力大不等于敏感**，两者必须分开报。
- 与 `aero-moments-and-pressure-center`：那张卡算 CP 的绝对位置与力矩；本卡只用"CP–NSP 的距离"。
- 与 `drag-source-breakdown-and-drag...`（`drag-source-breakdown-and-modifications`）：降阻那一半在那边，代价这一半在本卡；两卡成对给。
- 与第 6 章稳态转向：NSP、不足转向梯度、侧偏刚度都在那边有定量模型；本章只给"哪三个杠杆动 NSP/分母"。

## E — 可执行步骤 (Execution)

**必需输入**：CP 位置与 NSP 位置（或至少其一 + 定性描述）、轴距 $L$、轮胎有效侧偏刚度（$C_f$、$C_r$）、车速范围、是否有侧倾转向/转向柔度信息。**缺 CP 与 NSP 任一，不得给"敏感/不敏感"的结论**，只能给"需实测"。

**交付物与完成标准**：一张"四因素清单"（气动 / 车辆动力学 / 转向系统 / 驾驶员）+ CP–NSP 距离的方向判定 + 三到四条可动杠杆（含方向）+ 速度复核结论 + 静态分析的适用边界声明。**输出里不得出现 $r/\alpha$ 的公式或数值。**

1. **定位两个点**
   - 完成标准：写出 CP 与 NSP 各自的位置（或"未给"），并明确"决定敏感度的是两者距离，不是 CP 的坐标"。
2. **判方向**
   - 完成标准：距离变大 → 敏感度上升；变小 → 下降。用条件式表述（"若 CP 前移或 NSP 后移 → 记账"），不断言因果。
3. **列杠杆（四条，全带方向）**
   - 完成标准：①加长轴距 $L$；②提高轮胎有效侧偏刚度（高侧偏刚度胎 + 消除转向/悬架柔度）；③把 CP 后移靠近 NSP；④调重量分配/轮胎特性移动 NSP。每条注明"动的是分子还是分母"。
4. **速度复核（判停点）**
   - 判据：验收速度是否覆盖实际使用速度。
   - 完成标准：写明"同一套改善在高速会被侵蚀，不能用低速结论验收"；**只写"随速度上升"，不给指数、不写"超线性"**。
5. **静态边界声明**
   - 完成标准：必须写出四条被忽略项——侧倾柔度（尤其经悬架侧倾转向）、驾驶员闭环、瞬态（阵风）、0~20° 线性段之外；并说明式(4-11) 分母残缺，**本次只作初步估计**。
6. **代理指标（若用）**
   - 完成标准：只用横摆率响应做**排序**；声明 $r^2=0.974$ 来自 7 台改型车 + "腹背受击"交替风；**不报绝对分、不跨车型外推**。

**计算约定（原书未规定，本卡设定）**：距离保留 2 位小数（ft）；排序只给名次与差值，不给分数预测；任何"敏感度百分比"一律拒绝。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **把式(4-11) 写成公式或给 $r/\alpha$ 数值。** 分母 OCR 损坏（只剩 $(d_{ns}+\xi_d)$，变量表里的 $C_f/C_r$ 与 $\xi_d$ 的构成不明）→ 任何数值都是编造。用户要求"算一个敏感度增益"→ **停**，只给方向与杠杆。
- **声称"敏感度随速度超线性增长"。** 阶段 1 候选 ce18 的这句话**已在阶段 1.5 作废**：按式(4-11) 的结构（分子含 $q\propto V^2$、分母含 $V$），增益约为 $\propto V$（线性）；且分母残缺不可定指数。**本 Bundle 任何卡片都不得写"超线性"。**
- **用低速数据外推高速。** 作者原话"前向速度很大程度上减小了此力臂"（ce18）。检出信号：只在低速场地做横风试验；换高侧偏刚度胎后高速仍发飘；报告只给一个速度点。
- **用稳态横风响应代替瞬态/动态分析。** 作者自己承认局限（ce17）：侧倾柔度（尤其经侧倾转向）、驾驶员闭环、阵风瞬态都不在静态模型内。判停：把式(4-11) 当**验收指标** → 错，它只是"初步估计"（nc07：它是工具，不是废纸）。
- **只看 CP 的绝对位置。** 决定敏感度的是 CP–NSP 的**距离**（ce16）。量化演练：CP 前移 0.5 ft、NSP 同时前移 0.5 ft → 距离不变、敏感度不变（图 4.27 的构型 2/3 与 4 正是成对改变）。
- **拿横摆率响应的绝对分值排名或外推。** $r^2=0.974$ 来自 $n=7$ 的改型车与特定风型；截距与零点关系未澄清 → 只作排序。
- **把"降 $C_D$"当成必然增敏感度。** 作者只说二者"相结合"，未证明因果；反过来也不能因为"要保横风"就拒绝降阻（nc11：降 $C_D$ 本身是正确目标，反例是"只"优化 $C_D$）。
- **用 RM 的大小判稳定性。** 见 `aero-moments-and-pressure-center`（RM 最大但影响很小，真实通道是侧倾转向）。

### 作者在书中警告的失败模式

- ce17：静态分析忽略动态特性（p104 原话）。
- ce18：忽略速度放大（p103–104 原话；但"超线性"是候选的推断，已作废）。
- ce16：只看 CP 绝对位置（p102–103 原话）。
- ce09 / f12：降阻的四条代价链（横风、升力、热负荷/视野、积灰）。

### 作者的盲点 / 时代局限

- 式(4-11) 的分母在数字化中损坏 → 本章定量能力永久缺失一半（覆盖缺口 G4）；补读须回原书 p103 或英文原版 Eq.(4-11)。
- $r^2=0.974$ 的证据强度被作者措辞放大（"几乎解释所有差异"），样本仅 7 台改型车。
- 静态分析不含侧倾柔度、驾驶员闭环、瞬态；1992 年无 ESC，现代 ESC 会显著改变"横风敏感度"的实车表现——**这属章外，不得当章内结论**。
- 未讨论主动气动（主动尾翼、主动格栅）对 CP 的调节能力。

### 容易混淆的邻近方法论

- **CP（气动合成点）vs NSP（无横摆作用点）vs CG（质量中心）**：三者定义不同，只有 CP–NSP 距离进敏感度。
- **静态增益 vs 动态横摆率响应**：$r^2=0.974$ 是**实测动态**与主观评价的相关，不能反证静态增益有效（ce17 边界）。
- **横风敏感度 vs 侧向力大小**：前者是闭环响应属性，后者是单项力。
- **"CP 越靠后越好"**：不是口诀——要看 NSP 在哪（ce16）。
