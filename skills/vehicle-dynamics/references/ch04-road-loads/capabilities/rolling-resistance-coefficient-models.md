# 滚阻系数四式选型：常数 / 线性 / 幂式 / 货车双式，先定精度再选式

## R — 原文 (Reading)

> **原书要点**（p106）：以中等及偏低的车速行驶时，滚动阻力系数受车速的影响很小，工程计算中往往干脆按定值处理。
>
> **原书要点**（p108 式 4-14）：车速不高时，该系数大致随车速线性上升——$f_r=0.01(1+V/100)$；符号表中注明 $V$——速度（mph）。
>
> **原书要点**（p108 式 4-15）：若把速度范围放宽，该系数的增长大体接近速度的平方关系——$f_r=f_o+3.24f_s(V/100)^{2.5}$。
>
> **原书要点**（p109 式 4-16a/b）：$C_h$ 是路面系数，光滑混凝土取 1.0，热沥青路面取 1.5；子午线胎用 $(0.0041+0.000041V)C_h$，斜交胎用 $(0.0066+0.000046V)C_h$。
>
> **原书要点**（p109）：不难理解，路面越硬、越光滑、越干爽，滚动阻力就越低；而一旦路面被严重磨耗，其滚动阻力差不多要翻上一倍。
>
> — 4.2.1 速度段（p106）；4.2.2 三式与典型表（p108–109）

## I — 方法论骨架 (Interpretation)

一句话：**没有"最好的 $f_r$ 公式"，只有"标定域对不对"——选式前先回答三件事：什么车、什么速度段、什么路面。**

- 四套口径是**精度阶梯**，不是四个可互换的答案：(4-12) 常数（最粗，只认车型×路面）、(4-14) 线性（只含 $V$，低速）、(4-15) 幂式（混凝土 + 大速度范围，系数要按胎压查图）、(4-16a/b) 货车双式（含 $C_h$，只对重型货车轮胎成立）。
- 混用的代价是**2.4 倍量级**，不是几个百分点：67 mph 时式(4-14) 给 0.0167、式(4-16a) 给 0.00685，差 2.4 倍——一个像"坏路面轿车"，一个像"子午线货车"。
- $C_h$ 是**乘子**不是加项：热沥青让整条曲线抬高 50%，而不是"加 0.5"。把乘子当加项，在低速时误差最大（$V\to0$ 时 0.0041×1.5=0.00615 对 0.0041+0.5=0.5041）。
- "常数"不是错误做法——作者明确说中低速可当常数。错的是"高速/沙地/弯道仍用常数"（那是 ce26/ce31/ce21 的地盘）。
- 两个只能给"形式"不能给"数"的位置：式(4-15) 的 $f_o$、$f_s$ 需要读图 4.34（**读数缺失**）→ 幂律段只能给形式；式(4-13) 的载荷律与"$f_r\propto W$"结构冲突 → **标为 conflict，不采用**。
- 交付物：选定式 + 标定域声明 + $f_r$ 数值 + 与另一式的对照值（说明差多少、为什么）。

## A1 — 应用示例 (Application Example)

### 示例 1：例题 1 的货车式（原书例题，引用数据）

- **类型与来源**：**原书例题 1**（p111–112）。
- **输入**：67 mph、子午线胎、$C_h=1.0$（光滑混凝土）。
- **方法的使用**：$f_r=(0.0041+0.000041\times67)\times1.0$。
- **结论/结果（复算值）**：$f_r=\mathbf{0.006847}\to$ 书印 **0.00685**；$R_x=0.006847\times72500=\mathbf{496.6}\to$ 书印 **497 lb** ✓。

### 示例 2：同车的四条支线（引用数据 + 复算，全部可核）

- **类型与来源**：p36/ce32/ce33 的复算演练（**引用数据**：$C_h$ 与轮胎结构取值来自 p109）。
- **输入**：同车 72500 lb、67 mph。
- **结论/结果（复算值）**：
  - $C_h=1.5$（热沥青）：$f_r=0.006847\times1.5=\mathbf{0.01027}$、$R_x=\mathbf{744.6}\to745$ lb（**+50%**）；
  - 斜交胎同条件：$f_r=0.0066+0.000046\times67=\mathbf{0.009682}$（比子午线高 **41%**）；
  - 磨损路面按"几乎加倍"取 $C_h\approx2.0$：$f_r=\mathbf{0.01369}$、$R_x=\mathbf{992.5}\to993$ lb。
  - 同速轿车线性式(4-14)：$f_r=0.01(1+67/100)=\mathbf{0.0167}$ → 与货车式差 **2.4 倍**（**这就是"不可跨车型套用"的量化**）。

### 示例 3：选式决策（合成演练，非书中事实）

- **类型与来源**：**合成演练**（自造工况）。
- **输入**：3650 lb 轿车、55 mph、铺装混凝土、要求精度 10%~20%。
- **方法的使用**：①判车型（轿车，不是重货）→ 排除 (4-16)；②判速度段（中低速）→ 可用常数或线性；③判是否要速度修正。
- **结论/预期输出**：常数层级 $f_r=0.015$ → $R_x=\mathbf{54.8}$ lb；同车用线性式(4-14) → $f_r=0.01(1+0.55)=\mathbf{0.0155}$ → $R_x=\mathbf{56.6}$ lb（差 **3%**，说明低速段两法可互换）。若要求 5% 精度 → **拒绝**用常数层级，须换实测。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 问"$f_r$ 取多少、用哪个公式"。
2. 两个来源给的 $f_r$ 差一倍，要判断谁对、是不是套错了标定域。
3. 问"路面热了/磨损了，滚阻变多少"。
4. 做油耗预测，需要在"常数级"与"带速度式"之间选精度。
5. 读到 $(0.0041+0.000041V)C_h$，不确定 $C_h$ 是乘还是加。

### 语言信号（中英双写）

- 「滚动阻力系数怎么取」「$f_r$ 用哪个公式」「热沥青滚阻高多少」「子午线比斜交低多少」「$C_h$ 怎么用」
- 「rolling resistance coefficient」「$f_r$ formula」「road surface coefficient」「radial vs bias」
- 反向信号：「滚阻系数是 0.00685 lb」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `rolling-resistance-baseline`：那张卡做"$f_r$ 已知 → $R_x$"；本卡做"$f_r$ 该取哪个式子/哪个数"。
- 与 `rolling-resistance-state-corrections`：本卡给"式子的形状"；"温度/胎压/磨损/侧偏把这条曲线怎么改"→ 那张卡（它管五个修正方向）。
- 与 `road-surface-and-offroad-friction`：本卡只做铺装路的 $C_h$（1.0/1.5）与"磨耗≈2.0"；**越野/沙地的 20 倍层级跳变**在那边。
- 与 `road-load-and-power`：本卡产出 $R_x$ 的输入，那张卡做相加与功率。

## E — 可执行步骤 (Execution)

**必需输入**：车型（轿车/重型货车/牵引车）+ 轮胎结构（子午线/斜交，仅货车式需要）+ 速度范围（mph）+ 路面类型与状态 + 精度要求。**缺车型或速度段不得选式**。

**交付物与完成标准**：选定式 + 标定域声明（车型/速度段/路面/胎压）+ $f_r$ 数值（4 位小数）+ 一条"换用另一式会得多少"的对照 + 精度声明（与所选的层级匹配）。

1. **筛标定域**
   - 完成标准：逐条核对①车型（(4-16) 只对重型货车）；②速度段（(4-14) 只在中低速）；③路面（(4-15) 只对混凝土）；④轮胎结构（子午线/斜交）。任一条不符 → 换式或判"无可用式"。
2. **选式并算 $f_r$**
   - 完成标准：写出所用式的编号与全部代入值；$V$ **必须 mph**（代 ft/s 会高报：见下条）。
3. **单位自检（判停点）**
   - 自检：$V$ 用 ft/s 代入式(4-16a) → 0.00685 变 **0.00813（×1.19）**，量级仍"像滚阻"。
   - **⚠️ 候选勘误（不得复用）**：阶段 1 候选 ce03 写"$f_r$ 高报 **2.15 倍**"，**该子句已在阶段 1.5 作废**（2.15 是速度平方比，而式(4-16a) 含常数项，实际 ×1.19）。**本 Bundle 任何卡片不得写"2.15 倍"。**
4. **$C_h$ 用乘法**
   - 完成标准：写成"$(\cdots)\times C_h$"；并给一个反例数值说明加项错在哪（$V=0$ 时 0.00615 对 0.5041）。
5. **给对照值**
   - 完成标准：至少给一条"同车同速换用另一式"的数值（例：67 mph 时 0.0167 vs 0.00685），用它证明"选式不是选数"。
6. **声明不可算的段**
   - 完成标准：若用户要幂律段（式 4-15）的数值 → **停**：$f_o$、$f_s$ 需读图 4.34，**该图读数缺失**，只能给形式；若用户引用式(4-13) 的"随载荷线性增加" → **停**：与 $f_r\propto W$ 代入 $R_x=f_rW$ 得 $R_x\propto W^2$ 冲突，**标 conflict，不采用**。

**计算约定（原书未规定，本卡设定）**：$f_r$ 保留 4 位小数；$R_x$ 保留 3 位有效；$C_h$ 只取 1.0/1.5/≈2.0 三档并注来由。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **高速仍用常数 $f_r$ 或线性式。** 作者把三段分工写清了：常数（中低速）/ 线性（较低速度）/ 幂律（大速度范围）。同一 $f_r$ 式跨 0~150 mph 使用 → 判越界（ce26）。物理终止条件是**驻波**（限制轮胎速度等级的结构失稳），但本章只给方向不给曲线。
- **跨车型/跨速度区间套用经验式。** 67 mph 时式(4-14) 0.0167 对式(4-16a) 0.00685，差 2.4 倍；斜交 vs 子午线差 41%（ce32）。判停：公式里没有胎压项却在算胎压影响；参考文献年代/车型与目标车差 30 年 → 判标定域不符。
- **把 $C_h$ 一律取 1.0。** 它只编码"路面类型"，**不含**磨耗与潮湿的定量（ce33）；磨损路面"几乎加倍"，湿路"更高"（后者作者用"这可能是由于"标明是推测）。反过来，也不能拿 $C_h$ 去编码湿地（机制不同：湿路是胎温→柔度→迟滞，不是路面变形）。
- **把 $C_h$ 当加项或与 $C_D$ 混。** $C_h$ 是乘在 $f_r$ 上的路面系数；OCR 作 `C，`，极易与 $C_D$ 互串。
- **采用式(4-13) 的"载荷律"。** 原文称"滚动阻力……随载荷呈线性增加"，但 $f_r\propto W$ 代入 $R_x=f_rW$ 会得 $R_x\propto W^2$ → **口径冲突未解决**（阶段 1.5 判 needs_review / conflict）。本卡只采用 (4-12)(4-14)(4-15)(4-16a/b) 与典型表；(4-13) 只保留"$D\uparrow\to f_r\downarrow$、$h/w\downarrow\to f_r\downarrow$"的趋势，**不给绝对律**。
- **引用式(4-15) 的数值。** $f_o$、$f_s$ 需图 4.34（随充气压力 20–50 psi）的读数，**该图读数缺失**（覆盖缺口 G2）→ 只能给形式。
- **跨仓搬 $f_r$。** 仓 A 用货车式得 0.00685；仓 B 用**设定值 0.02**（示例车假设）；两者不可互推。**仓 B 的 0.02 与典型表"牵引车 0.02"同值不同义。**

### 作者在书中警告的失败模式

- ce26：高速仍用常数/线性式（p106、p108 两处）。
- ce32：跨车型/跨速度区间套用（三式标定对象逐条注明）。
- ce33：$C_h$ 一律取 1.0（p109 原话 + 两条定性修正）。
- p39（reference）：驻波是幂律段的物理终止条件（"若仅持续中等长度的时间，都将引发灾难性的事故"）。

### 作者的盲点 / 时代局限

- 幂律式的两个系数依赖胎压，只能读图；1992 年后低滚阻胎配方已使绝对值系统性下移。
- 没有"多因素耦合"的公式（作者在 ce29/reference 中明确反对追求"万能公式"）；本章的方法是"按精度选式"。
- 湿路"更高的滚动阻力"只有定性，无数字。
- 未讨论电动车（高胎压、窄胎、低滚阻）与 C 级标签体系。

### 容易混淆的邻近方法论

- **"选式" vs "选数"**：四式的差别是标定域，不是同一曲线的四种精度。
- **$C_h$（路面乘子）vs $C_D$（气动无量纲系数）vs $f_r$（滚阻系数）**：三者都是无量纲，语义完全不同。
- **线性式(4-14) 的 $V$=mph vs 阻力式(4-2) 的 $V$=ft/s**：章内相邻，最容易串。
- **"常数 $f_r$ 是错的" vs "常数 $f_r$ 在适用区间是正解"**：后者是作者原话（nc02）。
