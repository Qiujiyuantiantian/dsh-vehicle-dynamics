# 阻力来源分解与降阻定位：9 项加总 0.42，车体占 65%，后部单项最大

## R — 原文 (Reading)

> **原书要点**（第4章 道路负载）：其中约 65%，即 0.275 占 0.42 的比例……阻力主要由车尾部分贡献；也正是在这一部位，减阻的余地最大。
>
> **原书要点**（p93–94 §4.1.5）：扰流器本身会带来压差阻力，但在深度不大的阶段，它替车身底部省下的阻力更可观；深度继续加大后，新增的压差阻力反超底部那部分收益，总阻力转为上升。
>
> **原书要点**（第4章 道路负载）：概括地说，无论是上盖板扰流器还是翼面，这类附加件都倾向于把阻力推高。
>
> **原书要点**（p89–90 §4.1.4 图 4.11）：累计削减幅度能做到 21%，这件事本身就说明：逐项抠细节对降阻是有效的。
>
> — 4.1.4 图 4.11 全表与脚注（p89–90）；4.1.5（p93–94）

## I — 方法论骨架 (Interpretation)

一句话：**把 $C_D$ 从"一个数"变成"一份账"——先确认这车还在账本的适用区间，再按"单项占比 × 可改空间"排序。**

- 账本结构：车体 0.275（前 0.05 + 后 0.14 + 底 0.06 + 摩擦 0.025）+ 突出物 0.12（轮坑 0.09 + 雨水槽/车窗/后视镜各 0.01）+ 冷却 0.025 = **0.42**。九项、三大类。
- 两步用法（都由原文支撑）：①三项加总 ≈0.42 才说明该车落在该分解的适用区间（70 年代轿车），否则只能"借排序思路"；②按单项占比排序，占比最大且可改空间最大的先动。
- 排序结果（不是直觉结果）：后部 33.3% > 轮坑 21.4% > 底部 14.3% > 前部 11.9% > 摩擦 5.95% ≈ 冷却 5.95% > 三项各 2.4%。**轮坑排第二是反直觉的**——按投影面积分摊会严重低估它（车轮面积占比小，但因涡流贡献 0.09）。
- 附件类（扰流器、导风板、翼面）不是"降阻件"，而是**用阻力换升力/稳分离**的装置，且存在最优深度。判断它们的净收益必须先问"目标函数是降阻还是降升力"。
- 21% 的细节优化总量是真实的（导风板、发动机罩轮廓、A 柱、D 柱），但逐项 ΔC% 未在文本中恢复，**只能给总量与方向**。
- 交付物：三级清单（先动哪、再动哪、别动）+ 每级的改法与期望降幅区间。

## A1 — 应用示例 (Application Example)

### 示例 1：图 4.11 账本的加和与排序（引用数据，原书表格）

- **类型与来源**：**原书表格**（图 4.11，p89–90；脚注注明"根据 20 世纪 70 年代生产的轿车"）。
- **输入**：九项分项值 0.05 / 0.14 / 0.06 / 0.025 / 0.09 / 0.01 / 0.01 / 0.01 / 0.025。
- **方法的使用**：①三组加和；②除合计得占比；③排序。
- **结论/结果（复算值）**：车体 $0.05+0.14+0.06+0.025=\mathbf{0.275}$；突出物 $0.09+3\times0.01=\mathbf{0.12}$；冷却 **0.025**；合计 $\mathbf{0.42}$ ✓。占比：后部 **33.3%** > 轮坑 **21.4%** > 底部 **14.3%** > 前部 **11.9%** > 摩擦/冷却各 **5.95%** > 雨水槽/车窗/后视镜各 **2.4%**；车体 **65.5%**（作者写"大约 65%"）。定位结论：**后部 0.14 是单项最大**。

### 示例 2：把占比迁移到另一台车（合成演练，非书中事实）

- **类型与来源**：**合成演练**（自造车：80 年代轿车实测 $C_D=0.36$，与本账本的 0.42 不同）。
- **输入**：$C_D=0.36$；只迁移**占比**，不迁移绝对值。
- **方法的使用**：①先核"这车是否还在 70s 区间"——0.36 属 80 年代，**只能借排序，不能借绝对值**；②按占比给优先级。
- **结论/预期输出**：优先级 **后部 → 轮坑 → 底部**；若后部项降 10%，$\Delta C_D=0.36\times0.333\times0.10=\mathbf{0.012}\to C_D\approx0.348$；把精力全投在"后视镜 0.01"这一级，最多值 **0.0086**（0.36×2.4%），量级差 5 倍 → 判为"改的都是 0.01 级小项"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 问"想降风阻先改哪里""造型评审该盯哪一块"。
2. 拿到一个 $C_D$，要判断它"差在哪"、还有多少空间。
3. 有人主张"加尾翼/加扰流板降风阻"，要判断方向对不对。
4. 做降阻预算分配：几个方案各值多少 $C_D$。
5. 读到一个"细节优化累计 21%"，想知道这条路走到头值多少。

### 语言信号（中英双写）

- 「风阻该从哪里降」「0.42 的分解」「车身/轮坑/底部各占多少」「后部是不是最大」「加尾翼能降多少」
- 「drag breakdown」「drag budget」「where to reduce drag」「spoiler」「air dam」「C_D contribution」
- 反向信号：「扰流器就是降阻件吧」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `tail-shape-and-separation-limit`：本卡的"后部 0.14"是**账本里的一个位置**；"后部具体该做到多少度、要不要卡曼-背"→ 那张卡。
- 与 `aero-drag-and-power`：本卡不重算 $D_A$，只解释 $C_D$ 的构成与定位。要先有 $C_D$ 才有账可拆。
- 与 `crosswind-sensitivity-and-tradeoff`：降阻有代价（横风、升力），那张卡是"记账的那一半"；本卡只做"降阻这一半"，**两卡必须成对给**。
- 与 `lateral-force-and-lift`：附件"降升力"的量化在那边（$L_A$ 的变化）；本卡只给"增阻是价格"这一句。

## E — 可执行步骤 (Execution)

**必需输入**：目标车的 $C_D$（风洞/滑行/文献值，须标年代）+ 车型与年代 + 目标函数（降阻 / 降升力 / 两者）。**缺 $C_D$ 不得开算账**（账本只能按占比迁移，不能凭空生成）。

**交付物与完成标准**：九行账本表（分项、数值、占比）+ 初步核验（加总是否 ≈0.42）+ 三级清单（先动/次动/别动）+ 每级的改法与期望降幅区间 + 一句"适用区间"声明。

1. **核适用区间（先做，决定能不能用绝对值）**
   - 完成标准：若目标车 $C_D$ 在 0.4~0.5（70s 口径）→ 可用绝对值；若在 0.30~0.36 → **只借占比排序**，并写明这句。
2. **填账本并加和**
   - 完成标准：九项齐全，$0.275+0.12+0.025=0.42$ ✓；若用户给的分项加不到 0.42，标"该车不在本分解适用区间"。
3. **算占比并排序**
   - 完成标准：给出降序表；必须点明两条反直觉读数——后部单项最大（33.3%）、轮坑第二（21.4%，按面积分摊会低估）。
4. **配改法与量级**
   - 完成标准：每级给一条改法与期望降幅区间（前端圆弧 5%~15%、细节组合累计 21% 等，均标"原文量级"）；**不逐项相加**（分项耦合）。
5. **附件分支（判停点）**
   - 判据：用户提到扰流器/导风板/翼面 → 先问目标函数。
   - 完成标准：若目标是降升力/稳分离 → 说明"增阻是价格，不得记作失败"；若目标是净降阻 → 说明存在**最优深度**，浅时净减、深时净增，必须逐档试（无风洞/CFD → 输出"只能逐档试"，不给单点结论）。
6. **交付**
   - 完成标准：一句话"后部优先（0.14，占 33%），其次轮坑（0.09，21%）；把预算投在 0.01 级的三个突出物上，最多值 0.024 的 $C_D$"。

**计算约定（原书未规定，本卡设定）**：占比保留 1 位小数（%）；$\Delta C_D$ 保留 3 位小数；分项收益不相加，只给"单项目标值"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **把 0.42 当这辆车的实测 $C_D$。** 它是 70 年代轿车的**估计账本**（脚注明说），不是单车实测；现代车 0.30–0.35 只能借排序思路。
- **把 0.42 与仓 C 的 $C_D=0.42$ 互引。** **纯属数值巧合，严禁互引**（阶段 1.5 在两处边界特别加固）。
- **把分项收益直接相加。** 各项耦合（底部↔车轮、冷却↔前端），"每项都改 10%"不等于"总降 10%"。
- **以为降阻没有代价。** 四条代价链：横风敏感度（作者原话"相结合"）、升力（扰流器降升力但增阻）、热负荷与视野（挡风玻璃角度）、积灰（图 4.9）。任一出现 → 该方案**不得单目标定案**（ce09）。注意四条链的**因果强度不同**：扰流器增阻、挡风玻璃热负荷是作者明说；"尾部收缩→CP 前移"只是两趋势并列，未证明因果——引用须分级。
- **按投影面积比例分摊部件阻力。** 车轮的面积占比小但贡献 0.09（21.4%），因为它的机制是涡流而非迎风面积（ce08 属 reference，量化事实已在账本里）。
- **引用逐项 $\Delta C\%$。** 图 4.19 的细节优化只恢复了总量 21%，**逐项数值未恢复**，不得编造。
- **用扰流器"增阻"判它为失败设计。** 目标函数是降升力+稳分离时，增阻是价格（nc04）；本卡与 `crosswind-sensitivity-and-tradeoff` 必须成对给出，否则会把作者的正解当反例删掉。

### 作者在书中警告的失败模式

- ce09：以为降阻没有代价（p101、p94、p93、p91、p88 五处）。
- f05：扰流器的最优深度（p93 原话"当扰流器深度增加，最终增加的压力阻力超过底部部件上减小的阻力"）。
- ce08（reference）：按投影面积比例分摊部件阻力。

### 作者的盲点 / 时代局限

- 账本是 1970s 轿车的估计值；现代车（0.22–0.25）的分项占比已变，作者未给更新方法。
- 逐项改进量的定量只到"21% 总量"，无分项 ΔC%，也无耦合矩阵。
- 没有 CFD，细节优化靠试凑；未讨论主动格栅、底盘整流、轮毂整流等现代手段。
- 冷却阻力只给 0.025 一个数，未讨论"冷却需求 vs 阻力"的权衡曲线。

### 容易混淆的邻近方法论

- **账本（p13）vs 动手流程（f03）**：本卡两者都给——账本是"数值与排序"，流程是"核区间→填表→排序→配改法"。
- **形状阻力（合计约 0.395）vs 摩擦阻力（0.025）**：账本里把两者分列；把"摩擦阻力"接到轮胎附着上会串章（g16）。
- **后部 0.14 是"位置"还是"机制"**：它是分离导致的压差（形状阻力）在车后部的贡献，不是"后部有一块面积"。
- **降阻（本卡）vs 横风敏感度（另一卡）**：同一枚硬币的两面，单给一面会得到"越流线越好"的错误结论。
