# $f_r$ 的状态修正五项：温度 / 胎压 / 速度 / 材料 / 侧偏——$f_r$ 是状态量不是常数

## R — 原文 (Reading)

> **原书要点**（第4章 道路负载）：轮胎要滚过 20 mile 以上，状态才会趋于稳定；所以常规试验都会先让轮胎走 20 min 以上作为预热……而许多汽车那种短途行驶的工况下，胎温始终升不到能让滚动阻力降到最低的水平。
>
> **原书要点**（第4章 道路负载）：在沙地这类松软地面上，胎压偏高会让压穿地面所耗的功增多……可见最佳胎压要看地表变形的性质。归结起来，在沙地上给轮胎放气所换来的"附着力提高"，实质上是滚动阻力下降的结果。
>
> **原书要点**（第4章 道路负载）：只要侧偏角达到几度，该系数的大小就差不多会翻倍。
>
> **原书要点**（第4章 道路负载）：磨得光秃的旧胎，滚动阻力系数比新胎低约 20%；而细密叠层会把它抬高约 25%。胎面胶的迟滞损失虽有利于湿路面抓地，却拖累了轮胎的滚动阻力表现。
>
> — 4.2.1 图 4.29–4.33 各段文字结论（p105–107）

## I — 方法论骨架 (Interpretation)

一句话：**同一个轮胎在不同状态下可以给出差一倍的 $f_r$，所以任何 $f_r$ 数值都必须带"状态标签"，否则不可比。**

- 五个方向、四组硬量级：温度（20 mile / 20 min 才稳定，冷高稳低）、胎压（**取决于路面**：沙地降压、松土基本无关、硬路升压）、材料（磨胎 **−20%**、细密叠层 **+25%**）、侧偏（**几度就近乎翻倍**）、速度（低速线性、高速 ∝$V^{2.5}$，见 `rolling-resistance-coefficient-models`）。
- 这五项**不能逐项叠加**：温度与胎压有交互、侧偏与速度不是简单相加、路面变形与轮胎迟滞是两条不同的耗散路径。所以输出只能是"方向 + 区间"，不是"精确值"。
- 两个反直觉结论必须成对给：①沙地降压降阻是正解（nc08），但**不存在通用的"最优胎压"**（ce25）——"最优"是路面的函数；②磨胎 −20% 是**事实**，不是维护建议——它是"湿地性能被记成了收益"（ce28/nc09）。
- 最实用的一问不是"$f_r$ 是多少"，而是"**这个 $f_r$ 能不能与既有数据比较**"：预热到没到 20 mile？胎压是不是最优？路面是什么？有没有侧偏？测试是不是直线？
- 侧偏这一项的分量最重：直线 $f_r=0.015$ → 几度侧偏 ≈0.030，仓 B 的滚阻从 54.8 升到 109.5 lb、55 mph 功率从 8.03 升到 16.1 hp——**与同工况风阻功率（8.9 hp）同量级**，直接推翻"高速滚阻不重要"的直线结论。
- 交付物：可用区间 + 可比性结论 + 需要补测的项。

## A1 — 应用示例 (Application Example)

### 示例 1：一条 $f_r=0.012$ 的实测值能怎么用（排障演练，输入为假定值）

- **类型与来源**：**合成演练**（f09 的 V2 排障演练；原书无此算例，只有五个方向的规则与量级）。
- **输入/问题**：某报告给出 $f_r=0.012$，来源未标预热条件，要拿它与厂家数据对比。
- **方法怎么执行（五问）**：①预热里程/时间够 20 mile / 20 min 吗？②胎压与路面是什么（沙地/松土/硬路）？③速度段？④磨损与胎体结构？⑤是否有侧偏/转弯？
- **结论/预期输出**：预热未达标 → **不得与稳态最低值比较**（短途车永远到不了最低值）；硬路+升压+长方形胎面 → 数值偏低是正常的；若有几度侧偏 → 该值可能已被抬高近一倍，**不可与直线数据混比**。输出写成"可用区间 + 能否比较"的结论，**不给单点**。

### 示例 2：侧偏让滚阻翻倍（引用数据 + 复算）

- **类型与来源**：**引用数据**（p106–107 原话"几度几乎翻一番"）+ 复算。
- **输入**：常数层级 $f_r=0.015$、$W=3650$ lb、55 mph（80.65 ft/s）。
- **方法的使用**：$f_r\to0.030$，$R_x=f_rW$，$hp=R_xV/550$。
- **结论/结果（复算值）**：$R_x$ 由 **54.8 → 109.5 lb**；功率由 **8.03 → 16.1 hp**；对照同工况风阻功率 **8.9 hp** → 弯道里滚阻已是与风阻同量级的项。

### 示例 3：沙地与硬路的胎压方向相反（决策演练）

- **类型与来源**：**合成演练**（ce24/ce25 成对演练）。
- **输入**：同一车队要在沙地、松土、热沥青三种路面运行。
- **结论/预期输出**：沙地 → **降压**（机制：减少地面穿透功）；松土 → **与胎压基本无关**（由附着/磨耗/舒适定）；硬路 → **升压**（减少胎体弯曲功）。必须附一句"沙地降压带来的是滚阻减少，不是附着系数变大"。判停：要求给"一个最优 psi" → **拒绝**，输出必须是"路面标签 + 方向"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 问"为什么实测 $f_r$ 比手册高/低""这份数据能不能用"。
2. 问"短途/城市工况该取哪个 $f_r$"。
3. 问"沙地要不要放气""高速胎压打多少省油"。
4. 发现弯道多的路线油耗算不准，怀疑滚阻模型。
5. 轮胎选型：低滚阻胎值不值得、磨胎是不是更省油。

### 语言信号（中英双写）

- 「滚阻系数为什么差这么多」「冷胎热胎」「20 分钟预热」「沙地放气」「胎压省油」「弯道滚阻」
- 「tire warm-up」「cold tire」「inflation pressure」「slip angle effect」「low rolling resistance tire」「wet grip tradeoff」
- 反向信号：「$f_r$ 就是一个常数，抄手册就行」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `rolling-resistance-coefficient-models`：那张卡选**式子**（形状），本卡修**状态**（数值）。两者不可互相替代：式(4-16a) 给出 0.00685 之后，还要问"这是热胎还是冷胎、什么路面、有没有侧偏"。
- 与 `road-surface-and-offroad-friction`：本卡管"路面状态对 $f_r$ 的定性修正"，那张卡管"这条路该不该换层级（0.015→0.30 的 20 倍跳变）"。
- 与 `rolling-resistance-baseline`：那张卡做乘法，本卡改乘数。
- 与第 3 章湿附着：迟滞既是滚阻的来源也是湿地附着的前提；"制动距离变长多少"属第 3 章，本卡不给数值。

## E — 可执行步骤 (Execution)

**必需输入**：$f_r$（或 $R_x$、$W$ 让本卡反算）、测试/使用条件五问的答案（预热里程与时间、胎压与路面、速度段、磨损与胎体结构、是否有侧偏/转弯）+ （可选）比较对象的口径。**缺 $f_r$ 本身不得开算**；五项条件缺项时**只能给"不可比"结论**，不得默认理想状态。

**交付物与完成标准**：五行条件表（项、实测条件、方向、量级、是否需修正）+ 可用区间（不是单点）+ "能否与既有数据比较"的明确判定 + 需要补测的项清单。

1. **建条件表（先填，不先算）**
   - 完成标准：五问逐条有答案或标"未知"；任何一项未知 → 该行的修正是"不确定"，不得当"无影响"。
2. **温度/预热**
   - 完成标准：写明预热里程/时间；未达 20 mile 或 20 min → 判"该值与稳态最低值不可比"，并说明短途工况应取冷端值。
3. **胎压（判停点：先问路面）**
   - 判据：路面是沙地/松土/硬路。
   - 完成标准：沙地→降压有利；松土→与胎压基本无关；硬路→升压有利。**禁止给"通用最优 psi"**（图 4.30 三条曲线的极小点不可读）。
4. **材料/磨损**
   - 完成标准：磨胎 **−20%**、细密叠层 **+25%** 两个数照录；必须同时给出取舍（湿附着下降），**不得把它写成维护建议**。
5. **侧偏（量级最大的一项）**
   - 完成标准：若存在转弯/驱动/制动侧向力 → 按"几度≈×2"给区间；并说明"与速度项不是简单相加，不得逐项叠加"。
6. **交付**
   - 完成标准：一句话"该 $f_r$ 只能与同预热、同胎压、同路面、同侧偏条件的直线数据比较；可用区间 0.014~0.017（或 ×2 的弯道区间），需补测预热时间与路面"。

**计算约定（原书未规定，本卡设定）**：所有修正只给方向与量级（×1、×2、−20%、+25%），**不给乘性修正因子**（本章无解析式）；区间给出时标明是"哪两项的组合"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **用冷胎数据与稳态最低值比较。** 需 20 mile / 20 min 才稳定；短途车永远到不了（ce23）。检出信号：报告不写预热里程/时间；实测油耗高于用标称 $f_r$ 的预测且短途偏差更大。
- **在沙地上用高胎压，或把"降压"推广到硬路。** 最优胎压取决于路面（ce24/ce25）。判停：要求给"一个最优 psi" → 拒绝；把沙地降压收益说成"抓地更好" → 判错（作者本人点名）。
- **忽略侧偏。** 几度侧偏就让 $f_r$ 近乎翻倍（ce21）；用定圆/绕桩工况套直线 $f_r$ → 判错。**但也不得把侧偏修正与速度修正简单相加**（候选此前的推断已在阶段 1.5 收窄为"不得简单相加"）。
- **以为降低滚阻没有代价。** 迟滞阻力是湿地附着的前提（ce28）：磨胎 −20% / 叠层 +25% 都是"用湿地性能换滚阻"。用"磨胎省油"当维护建议 → 判错。
- **把五项修正逐项相乘/相加。** 温度与胎压有交互、侧偏与速度不同源；输出只能是方向 + 区间。
- **引用图 4.29–4.33 的曲线数值。** 五条曲线在 OCR 中只有形状描述，**逐点数值不可读**（覆盖缺口 G3）→ 只能给四个孤立量级（20 mile/20 min、−20%、+25%、几度×2）。
- **把本卡的"×2"用到 $R_x$ 之外的量上。** 它改的是 $f_r$；对总道路负载的影响还要与其他两项合成。
- **跨仓搬 $f_r$。** 仓 A 的 0.00685（货车式子午线）、仓 B 的 0.02（设定值）不可互推；**仓 B 的 0.02 与典型表"牵引车 0.02"同值不同义**。

### 作者在书中警告的失败模式

- ce23：冷胎测滚阻（p105 原话，三个量都给了）。
- ce24 / ce25：沙地高胎压 / 通用最优胎压（p105–106）。
- ce21 / p41：忽略侧偏（p106–107 原话）。
- ce28：降低滚阻的代价（p106 原话，两个数字并排给出）。

### 作者的盲点 / 时代局限

- 五项修正**全部以曲线给出，无解析修正因子**，也不可逐项叠加——这是本章"只能定性"的根源之一。
- 1992 年无 C 级轮胎标签、无电动车专用低滚阻胎；"最优胎压"的讨论只到"取决于路面"，不含滚动阻力与磨耗/舒适的多目标优化。
- 湿路"更高的滚动阻力"只有定性（作者用"这可能是由于"标明推测）。
- 驻波（速度上限）只在速度段提到，本章未给驻波发生的临界速度公式。

### 容易混淆的邻近方法论

- **$f_r$ 的状态依赖 vs 材料的固有属性**：同一配方在不同温度/胎压下给不同 $f_r$，不是"数据打架"。
- **"冷胎高" vs "冷胎更费油"**：方向对，但短途工况的 $f_r$ 本就该取冷端值——不是"数据偏大"。
- **磨胎 −20%（滚阻）vs 磨胎湿附着下降**：同一个磨损状态的两个后果，只报一个就是单边建议。
- **沙地降压（降滚阻）vs 降压（增附着）**：作者明确纠正的归因错误。
