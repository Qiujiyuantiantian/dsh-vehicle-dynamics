# 风阻与风阻功率：$D_A=qC_DA$、$hp=D_AV/550$，三个输入各有一个静默陷阱

## R — 原文 (Reading)

> **原书公式**（p98）：$D_A=\rho V^2C_DA/2$（式 4-2，符号表：$D_A$——空气阻力，$\rho$——空气密度，$V$——相对速度，$C_D$——阻力系数，$A$——前端面积）
>
> **原书要点**（第4章 道路负载）：式中 $\rho V^2/2$ 就是动压，习惯记作 $q$，英制下多以每平方英尺的磅数来度量。
>
> **原书要点**（p98 §4.1.6）：书里特意点明：进公式的参考面积取车头正投影，不能拿侧面轮廓面积顶替。
>
> **原书要点**（p98 §4.1.7）：轿车跑在正常路面上时，常遇到的那段偏角会让风阻系数在此基础上再涨约 5%~10%。
>
> — 4.1.6 式(4-2)(4-4) 与符号表（p94–96）；4.1.7 式(4-6) 后（p98）

## I — 方法论骨架 (Interpretation)

一句话：**$q=\rho V^2/2$ 是把"速度"翻译成"压强"的转换器，$D_A=q\cdot C_DA$ 就是"压在一个前端投影面积上的压差"，马力再把力乘一次速度。**

- 三个输入对应三个互不相关的陷阱，而且**三个都不报错**：$\rho$ 忘除 $g$（×32.2）、$A$ 用侧面/表面积（×3 起）、$V$ 用 mph（÷1.47）。错完得到的数仍落在"像货车阻力"的量级里。
- $C_D$ 是**归一化系数**，参考面积一换它就变。所以"$C_D$ 是多少"这个问题必须先答"按哪个面积算"。跨尺寸比较改用 $C_DA$（有量纲，ft²/m²）。
- $C_D$ 的另一个隐含前提是**偏转角**：风洞给的 0.34 是零偏角，路上跑的车在典型偏转角内会到 0.357~0.374。风洞数 ≠ 路上数。
- 功率是力的二次关系的再乘一次 $V$，所以 $hp\propto V^3$（详见 `road-load-and-power`）。
- 这一段交付的不是一个数，而是**一条可核对的链**：$\rho\to q\to D_A\to hp$，每一步带单位与一句自检。任何一步的口径错了，链上其它数字都"看起来对"。

## A1 — 应用示例 (Application Example)

### 示例 1：例题 1 的货车风阻段（原书例题，引用数据）

- **类型与来源**：**原书例题 1**（p111–112）。
- **输入**：$W=72500$ lb、67 mph（98.3 ft/s）、$A=8\times13.5=108$ ft²、$C_D=0.65$、$\rho=0.00207$（丹佛）。
- **方法的使用**：①$q=\tfrac12\times0.00207\times98.3^2$；②$D_A=qC_DA$；③$hp=D_AV/550$。
- **结论/结果（复算值）**：$q=\mathbf{9.99}$ lb/ft²；$D_A=\mathbf{701.3}\to$ 书印 **702 lb**；$hp_A=\mathbf{125.3}\to$ 书印 **125 hp**（差 <0.2%，纯取整）；$C_DA=0.65\times108=\mathbf{70.2}$ ft²。

### 示例 2：轿车换一组输入（合成演练，非书中事实）

- **类型与来源**：**合成演练**（自造参数，与三个仓都不同，避免把例题结果当演练结果）。
- **输入**：70 mph、$A=22$ ft²、$C_D=0.31$、标准状态 $\rho=0.00236$。
- **方法的使用**：①$V=70/0.682=102.64$ ft/s；②$q=12.43$ lb/ft²；③$D_A=12.43\times0.31\times22$；④$hp=D_AV/550$。
- **结论/预期输出**：$q=\mathbf{12.43}$ lb/ft²、$D_A=\mathbf{84.8}$ lb、$hp=\mathbf{15.8}$ hp、$C_DA=\mathbf{6.82}$ ft²。自检：$D_A/(qA)=84.8/(12.43\times22)=0.310$ ✓ 回到输入 $C_D$。

### 示例 3：参考面积错位的量化（引用数据 + 复算）

- **类型与来源**：p07 的判停演练（**引用数据**，$A$ 以 p98 警告为准）。
- **方法的使用**：拿示例 2 的 $D_A=84.8$ lb 反算，若误用轿车侧面面积（约 66~70 ft²，约为前端面积的 3 倍）。
- **结论/预期输出**：$C_D=84.8/(12.43\times66)=\mathbf{0.103}$——落进"无任何经验值可对"的区间；而 0.103 仍是"看起来像 0.1"的小数，不会报警。这就是 ce01 的检出信号：**轿车 $C_D<0.1$ 一律先查参考面积**。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 给车速、迎风面积、$C_D$，问"风阻多少磅、要多少马力"。
2. 反算：已知实测风阻或实测油耗反推 $C_D$ / $C_DA$，判断这车的风阻水平。
3. 问"两个 $C_D$ 能不能直接比"——需要先确认是不是同一参考面积、同一偏转角。
4. 做等速巡航功率预算，风阻项就是第一块。
5. 查出"我算出来的风阻大得离谱/小得离谱"，要定位是 $\rho$、$A$ 还是 $V$ 的问题。

### 语言信号（中英双写）

- 「风阻怎么算」「60 mph 风阻多少磅/多少匹」「$C_D$ 0.3、面积 2.2 平米，阻力多少」「迎风面积」
- 「aerodynamic drag」「drag force」「drag horsepower」「frontal area」「C_DA」「CdA」
- 反向信号：「我的风阻算出来两万磅」「侧面面积能不能算风阻」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `air-density-and-standard-atmosphere`：本卡**调用**那张卡交付的 $\rho$，不重复推导；凡问题核心是"用哪个密度/高原怎么算"→ 那张卡。
- 与 `wind-relative-velocity-and-asymmetry`：本卡默认 $V$ 是相对风；一旦有自然风的大分量或问"逆风/顺风"→ 转那张卡（它带三工况数值与不对称结论）。
- 与 `road-load-and-power`：本卡只出风阻这一项；一旦要和滚阻/坡阻相加、或问"总功率/多开 5 mph 的代价"→ 转那张卡。
- 与 `drag-source-breakdown-and-modifications`：本卡出"风阻是多少"，那张卡出"该改哪里"。
- 与 `lateral-force-and-lift`/`aero-moments-and-pressure-center`：同属六力家族、共用 $q$ 与 $A$，但本卡只管纵向的 $D_A$。

## E — 可执行步骤 (Execution)

**必需输入**：$V$（mph 或 ft/s，须注明）、$A$（ft²，**前端投影**）、$C_D$（无量纲，须注明偏转角与来源）、$\rho$（或 $P$、$T$ 让本卡调 `air-density-and-standard-atmosphere` 算）。**缺 $A$ 或 $C_D$ 不得开算**：本章不给 $C_D$ 估算法（要风洞或滑行试验）。

**交付物与完成标准**：$\rho\to q\to D_A\to hp$ 四行链 + $C_DA$ + 每个量的单位 + 三条自检 + 口径声明（参考面积=前端投影、$V$=相对风、$C_D$ 的偏角前提）。

1. **定参考面积（最先做）**
   - 完成标准：写出"$A$ = 前端投影面积 = ___ ft²"，并注明"不是侧面面积、不是表面积"；若用户给的是"迎风面积"但数值明显偏大（如轿车 70 ft²），先反问。
2. **定 $\rho$**
   - 完成标准：给出 $\rho$ 与其单位 lb·s²/ft⁴；若用标准值 0.00236，必须写明"按标准状态，未含湿度"。
3. **统一速度**
   - 完成标准：$V$ 全部化成 ft/s（mph÷0.682）；同时写出两制对照行（例：67 mph = 98.3 ft/s）。
4. **算 $q$、$D_A$、$hp$**
   - 完成标准：$q=\rho V^2/2$；$D_A=qC_DA$；$hp=D_AV/550$；三个数都带单位；给出 $C_DA$。
5. **三条自检 + 一条口径声明**
   - 自检①：反算 $C_D=D_A/(qA)$ 应回到输入值（±0.5%）。
   - 自检②：轿车 $C_D$ 应落在 0.30–0.35（80 年代口径）或 0.22–0.30（现代），$C_D<0.1$ 或 $>1$ → **停**，先查参考面积。
   - 自检③：$q$ 的量级应为个位数~十几 lb/ft²（60–80 mph），若差 10 倍 → 查 mph/ft/s 与 $\rho$ 单位。
   - 口径声明：$C_D$ 是否含偏转角（风洞零偏角值 vs 路面典型偏角值）。
6. **偏转角分支（判停点）**
   - 判据：若这车要跑有自然风的路且用户问"实际路上"，轿车按 **$C_D\times(1.05\sim1.10)$** 记账（另算一个数，不要覆盖原值）；若目标是箱式车/挂车 → **不许套 5%~10%**（那是轿车值）。
   - 完成标准：给出零偏角值与典型偏角值两组，并说明差 5%~10%。

**计算约定（原书未规定，本卡设定）**：$q$ 保留 3 位有效，$D_A$ 保留 3 位有效（lb），$hp$ 保留 1 位小数；中间量不提前舍入；**$1$ mph $=1.466$ ft/s**（$=1/0.682$），故 ft/s $=$ mph $\div 0.682$。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **用侧面面积或表面积作参考面积。** 这是作者唯一亲自加警告的地方（p98），也是本章最"安静"的错：侧面面积只比前端面积大 3 倍，错完数值仍在合理区间（ce01）。连带后果：$C_S$ 斜率、$C_{YM}$ 斜率会与 0.035~0.06/deg、0.007~0.017/deg 的经验带同时错位。
- **把 mph 直接代进式(4-2)，或把 ft/s 代进 $f_r$ 经验式。** 两条式子在章内相邻出现，是最容易串的地方（ce03）。量化：mph 直代 → 702 lb 变 **327 lb（低报 53%）**；ft/s 代进式(4-16a) → 0.00685 变 **0.00813（×1.19）**。
  - **⚠️ 候选勘误（不得复用）**：阶段 1 候选 ce03 曾写"反向代入使 $f_r$ 高报 **2.15 倍**（0.00685→0.0147）"，**该子句已在阶段 1.5 作废**：2.15 是速度平方比，而式(4-16a) 含常数项，实际只有 ×1.19。**本 Bundle 任何卡片都不得写"2.15 倍"。**
- **把零偏角 $C_D$ 当有偏转角的实际行驶。** 轿车典型偏转角内 $C_D$ 增 5%~10%；55 mph 时 60.8 lb → 63.8~66.9 lb（ce12）。反向错误：把 5%~10% 当所有车型、所有角度的上限（30° 的牵引车-挂车是另一量级，本章无数值）。
- **用伯努利方程解释"为什么有风阻"。** 本章逻辑恰好相反：无粘、无摩擦时前后压力刚好平衡，**阻力为零**（p85，g03）。阻力必须由边界层（摩擦阻力）与分离（形状阻力）解释。用伯努利推风阻会推出 0。
- **以为 $C_D>1$ 一定是错。** $C_D$ 度量的是尾迹规模，不是"前脸顺不顺"：平板 1.95、半球 1.42/0.38。反例是"用 $C_D>1$ 判错"而不是"$C_D>1$ 本身错"（ce06 属 reference）。
- **要求本卡估 $C_D$。** 本章只给定义、量级带与"风洞/滑行取得"，**不给估算法**；没有 $C_D$ 就只能停（章外缺口 G6）。
- **把 $C_D$ 或 $\rho$ 跨仓搬运。** 仓 A 的 $C_D=0.65$（货车）、仓 B 的 0.34（轿车）、仓 C 的 0.42（车型未知）互不通用；$\rho=0.00207$ 只属仓 A。**仓 C 的 0.42 与阻力分解表的"合计 0.42"纯属数值巧合，严禁互引。**

### 作者在书中警告的失败模式

- ce01：前端面积（p98，作者唯一专门预警）。
- ce02：密度必须除以 $g$（p95，见 `air-density-and-standard-atmosphere`）。
- ce03：作者在式(4-14)(4-16) 的符号表里逐式注明"$V$——速度（mph）"，与式(4-2) 的 ft/s 要求并存。
- ce12：偏转角 5%~10% 是作者亲自给的区间（p98）。

### 作者的盲点 / 时代局限

- $C_D$ 的"现代水平"是 0.30–0.35（1992 年），今天量产 0.22–0.25；引用量级带必须标年代，否则会把"现在很好的车"判成"很正常"。
- 没有地面移动效应的讨论（$A$ 与 $C_D$ 的风洞值在无移动带下会偏高），只在与参考文献标题接壤处露出。
- 未讨论主动格栅、底盘整流、轮毂整流等现代降阻手段——**不得补造**。
- 图 4.8 的 OCR 错行：**严禁编造"车型↔$C_L$/$C_D$"配对**；章内可用于取值的只有正文的系数带。

### 容易混淆的邻近方法论

- **$C_D$（无量纲）vs $C_DA$（有量纲 ft²/m²）**：跨尺寸比车用后者；把 0.84 m² 当 $C_D$ 用会算出大得多的阻力，而且它"看起来像个系数"（g21，见 `book/glossary.md` 的勘误）。
- **动压 $q$（压强 lb/ft²）vs 力（lb）**：$q$ 差一个面积就是力。
- **风阻 $D_A$ vs 总道路负载 $R_{RL}$**：$D_A$ 只是三项之一；把它当总阻力会漏掉低速时最大的滚阻项。
