# 总道路负载与功率：$R_{RL}=f_rW+qC_DA+W\sin\theta$、$hp=R_{RL}V/550$——力是二次，功率是三次

## R — 原文 (Reading)

> **原书要点**（p109 §4.3 式(4-17)）：把滚动阻力、空气阻力以及有坡度时的爬坡阻力三项叠加，就得到车辆行驶须克服的驱动阻力，书中定名为"道路负载"，写作 $R_{RL}=\sin\theta\cdot W+Wf_r+C_DA\rho V^2/2$。
>
> **原书要点**（第4章 道路负载）：把式（4-17）与车速相乘，再乘上相应的换算系数，即得道路负载功率 $hp_{RL}=R_{RL}V/550$；式(4-18)呈三次方关系，功率随速度上升得格外陡。所以在高速段，车速略增就会让所需功率涨很多，燃油经济性也随之变差。
>
> **原书要点**（p104 §4.2）：在阻力—车速图上，滚阻项与坡阻项都表现为整条曲线向上平移，平移量只取决于各自的数值大小。
>
> **原书要点**（p104 §4.2）：实际算下来，气动阻力要到 50~60 mph 这个区间，才会涨到和滚动阻力差不多的水平。
>
> — 4.3 式(4-17)(4-18)（p109–110）；4.2 开篇（p104）

## I — 方法论骨架 (Interpretation)

一句话：**把三笔账（滚阻 ∝W、风阻 ∝V²、坡阻 ∝Wsinθ）加成一条曲线，再乘一次速度换成马力——那一次乘法把"力"的二次变成了"功率"的三次。**

- 三项的性质完全不同：滚阻随 $W$ 一次、**与 $V$ 无关**（用常数 $f_r$ 时）；风阻随 $V$ 二次；坡阻随坡度一次、与 $V$ 无关。所以在"道路负载—速度"图上，坡阻是**平行上移**、风阻是**二次上翘**。
- 功率 = 力 × 速度，所以：风阻功率 $\propto V^3$、滚阻功率 $\propto V^1$、坡阻功率 $\propto V^1$。**"总功率对速度是三次"只在 $f_r$ 为常数时成立**；若 $f_r$ 带速度项，滚阻项的次数升到 $V^2\sim V^{3.5}$，总功率的增长低于纯 $V^3$——两个百分比不可互换。
- 交叉点（风阻 ≈ 滚阻）是这条曲线上的一个**可算的点**：它由 $C_DA$、$W$、$f_r$ 决定，不是常数。作者给"50~60 mph"是轿车量级的典型带；换车必须重算。
- 计算口径三处必写：$V$ 用 ft/s（因 550 ft·lb/s=1 hp）、坡度用 $\sin\theta$（% 坡度 = 100·tanθ，只在**小角度**近似）、不含加速阻力（惯性项属第 2 章）。
- 交付物：一条表（若干车速下的 $R_{RL}$ 与 hp）+ 交叉点 + 一句"多开 x mph 的代价按 $V^3$ 算"。

## A1 — 应用示例 (Application Example)

### 示例 1：仓 B 示例车的两点一线（引用数据 + 复算）

- **类型与来源**：**引用数据**（4.3 示例车参数：$W=3650$ lb、$f_r=0.02$、$A=23.3$ ft²、$C_D=0.34$、平路、标准 $\rho$；原书只给曲线、未给任何 lb/hp 数值）。**注意原文正文写"典型大型车辆"、图题写"典型轿车"→ 以轿车为准，判为笔误。**
- **输入**：55 mph 与 80 mph、$\theta=0$。
- **方法的使用**：①$R_x=0.02\times3650=73$ lb；②55 mph：$q=7.675$、$D_A=60.8$ lb；③合计；④$hp=R_{RL}V/550$。
- **结论/结果（复算值）**：
  - 55 mph：$73+60.8=\mathbf{133.8}$ lb、$hp=\mathbf{19.6}$ hp；
  - 80 mph：$q=16.24$、$D_A=128.6$ lb → $73+128.6=\mathbf{201.6}$ lb、$hp=\mathbf{43.0}$ hp；
  - 分解：风阻功率 8.92→27.45 hp（**×3.08 = (80/55)³**），滚阻功率 10.70→15.57 hp（**×1.45 = (80/55)¹**），总功率 **×2.19**（明显低于 3.08——两个百分比不可互换）。

### 示例 2：例题 1 的两项合计（原书例题，引用数据）

- **类型与来源**：**原书例题 1**（p111–112）。
- **结论/结果（复算值）**：风阻 702 lb / **125.2 hp** + 滚阻 497 lb / **88.7 hp** = 合计 **213.9 hp**，对应书中"将近 215 hp"。比例校验：$hp_A/hp_R=1.41$，与"风阻在 50~60 mph 才与滚阻相当"在 67 mph 已越过交叉点一致。
- **本条只验证到 215 hp**：例题 1 的油耗段有硬伤（油耗链不闭合），**见 `fuel-economy-chain-and-attribution` 的 B 段**；本卡不出 mpg。

### 示例 3：加 5% 坡与交叉点（合成演练，非书中事实）

- **类型与来源**：**合成演练**（自造坡度与交叉点输入，仓 B 参数）。
- **输入**：仓 B 轿车、5% 坡（$\theta=\arctan0.05=2.8624°$、$\sin\theta=0.04994$）、10% 坡（$\theta=5.7106°$、$\sin\theta=0.09950$）。
- **结论/预期输出**：5% 坡 $W\sin\theta=\mathbf{182.3}$ lb → $R_{RL}=\mathbf{316.1}$ lb、55 mph **46.3 hp**（相对平地 +136%，因坡阻与滚阻同量级）；10% 坡 $363.2$ lb → $\mathbf{497.0}$ lb。**坡阻只平移、不改曲率** ✓。
- **交叉点**：令 $0.5\times0.00236\times V^2\times(0.34\times23.3)=73$ → $V^2=7809.4$ → $V=88.4$ ft/s = **60.3 mph**（落在作者 50~60 mph 带的上沿）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 问"这车 80 mph 巡航要多少马力""总阻力多少磅"。
2. 问"多开 10 mph 多费多少功率"——必须按 $V^3$ 回答。
3. 问"风阻和滚阻哪个大、从多少速度开始风阻为主"。
4. 做等速工况的功率预算，或给第 2 章加速性能提供分母。
5. 问"上坡 5% 要多多少力/多少马力"。

### 语言信号（中英双写）

- 「道路负载」「总阻力多少磅」「巡航要多少匹」「多开 5 mph 多费多少」「风阻和滚阻交叉点」「上坡多耗多少」
- 「road load」「road load horsepower」「road load power」「power required at speed」「gradability」
- 反向信号：「功率和速度是平方关系」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `aero-drag-and-power`：那张卡只算风阻一项；本卡做三项合成与功率。要"只看风阻"→ 那张卡。
- 与 `rolling-resistance-*`：本卡**调用**它们给的 $f_r$ 与 $R_x$，不重复推导；$f_r$ 的选式/状态修正在那几张卡。
- 与 `fuel-economy-chain-and-attribution`：本卡交付到 hp 为止；hp → lb/h → gal/h → mpg 的链条与硬伤在那边。
- 与第 2 章加速性能：本章的 $R_{RL}$ 是加速方程的分母项之一；加速阻力（惯性项）**不在本章**，不得并进来。

## E — 可执行步骤 (Execution)

**必需输入**：$W$（lb）、$f_r$（含层级与来源）、$A$、$C_D$、$V$（一个或多个点）、坡度（% 或 θ）、$\rho$（或 $P$、$T$）。**缺 $f_r$ 或 $C_D$ 不得开算**（两项都无法估算）。

**交付物与完成标准**：一张多行表（$V$、$R_x$、$D_A$、$W\sin\theta$、$R_{RL}$、hp）+ 交叉点速度 + 各分量功率的增长倍数 + 口径声明（不含加速阻力、$\sin\theta$、$V$ 用 ft/s）。

1. **统一口径**
   - 完成标准：$V$ 全部 ft/s（mph÷0.682）；坡度 % → θ → $\sin\theta$（写出 $\arctan$ 与 $\sin$ 两步，例：5% → 2.8624° → 0.04994）；声明"不含加速阻力"。
2. **三项分别算**
   - 完成标准：$R_x=f_rW$（可用常数 $f_r$ 或速度相关式，须注明；**若用速度相关式，后面的"V³"结论要改口**）；$D_A=qC_DA$；$W\sin\theta$（平路写 0 并说明）。
3. **求和**
   - 完成标准：$R_{RL}=$ 三项之和；同时给三项占比（用于判断主项）。
4. **换成功率**
   - 完成标准：$hp=R_{RL}V/550$；**必须写出 550 的来由**（ft·lb/s → hp），并检查"有 550 就有 ft/s"。
5. **交叉点（判停点）**
   - 完成标准：$f_rW=0.5\rho V^2C_DA$ 解 $V$，换算 mph；与作者"50~60 mph"带对照；若换车 → **必须重算**，不得沿用。
6. **增长倍数**
   - 完成标准：给风阻功率的 $\times(V_2/V_1)^3$ 与总功率的实际倍数，并写明"两个百分比不可互换"；若 $f_r$ 速度相关，改写为"总功率增长低于纯 $V^3$"。

**计算约定（原书未规定，本卡设定）**：$R_{RL}$ 保留 3 位有效（lb）、hp 保留 1 位小数；$q$ 保留 3 位有效；交叉点保留 1 位小数（mph）；$g=32.2$ ft/s²。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **说"功率 ∝ $V^2$"。** 漏乘了一个 $V$（$P=FV$，而 $F\propto V^2$）（ce34）。量化：55→70 mph 风阻功率 ×2.06（按 $V^2$ 只有 1.62）；55→80 mph ×3.08；总道路负载功率 55→80 是 ×2.19。
- **把"总功率 ×3.08"当成"总功率对速度三次"。** 3.08 是**风阻分量**的倍数；总功率因含 ∝V 的滚阻项只有 ×2.19。两个百分比混用会系统性高估高速代价。
- **用 %/100 直接当 $\sin\theta$。** 只在**小角度**近似；5% 时 $\sin\theta=0.04994$（略小于 0.05）、10% 时 0.0995（略小于 0.10），陡坡高估更明显。
- **把加速阻力并进来。** 本章三项**不含**惯性项（属第 2 章）；把它加进来会让"道路负载"与第 2 章的分母重复计入。
- **要求本卡出 mpg。** 本卡只到 hp；油耗链有硬伤（见 `fuel-economy-chain-and-attribution`）。
- **照抄"典型大型车辆"。** 4.3 正文与图题冲突，**以"典型轿车"为准**（3650 lb / 23.3 ft² / $C_D$=0.34 全是轿车量级），判为原文笔误。
- **沿线用"50~60 mph"交叉点。** 交叉点是 $C_DA$、$W$、$f_r$ 的函数；仓 B 算出 60.3 mph 只是这一个参数集的答案。
- **跨仓混参数。** 仓 B 的 $f_r=0.02$ 是设定值、仓 A 的 0.00685 来自货车式、$\rho=0.00207$ 只属仓 A；**仓 C 的 $C_D=0.42$ 与阻力分解表的 0.42 纯属数值巧合，严禁互引。**

### 作者在书中警告的失败模式

- ce34：以为功率 ∝ $V^2$（p110 原话"三次方关系"）。
- p45：交叉点（p104 原话 + "非公路水平地面滚阻是唯一主项"）。
- p43：三项"平行上移"（p109 原话）。

### 作者的盲点 / 时代局限

- "三项独立相加"只在**直线准稳态**成立：侧偏使 $f_r$ 翻倍、升力改 $W_{eff}$、横风改 $C_D$（作者本人承认这是工程近似）。
- 4.3 的示例车只给曲线、不给数值，正文与图题还冲突——引用时必须自己复算并声明口径。
- 未讨论传动效率、附件功率：$hp_{RL}$ 是**轮上需求**，不是发动机功率。
- 未讨论电动车/混合动力的能量回收（减速时滚阻/坡阻的符号会反）。

### 容易混淆的邻近方法论

- **道路负载（$R_{RL}$）vs 路面载荷/轴荷**：前者是行驶阻力总和，后者是地面垂直反力。
- **$R_{RL}$（力，lb）vs $hp_{RL}$（功率）**：相差一个 $V$ 与 550。
- **风阻功率的三次 vs 总功率的实际倍数**：见上。
- **坡度 % vs 坡角 θ vs $\sin\theta$**：三个量，逐级换算。
