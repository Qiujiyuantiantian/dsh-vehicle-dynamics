# 尾部倾角与分离阈值：≤15° 收缩一直降阻，>15° 因分离回升

## R — 原文 (Reading)

> **原书要点**（p89 §4.1.4）：尾部收窄角在 0°~15° 之间时，阻力随角度单调下降；越过 15° 再加大角度，气流开始分离，阻力反而回升（书中补了一句：假如始终不分离，能用的角度还可以更大）。
>
> **原书要点**（第4章 道路负载）：从空气动力学角度看，最理想的车尾收成泪滴状，好比一个以不超过 15° 的角缓缓收拢成尖的圆锥。而钝形尾部并不会明显加大阻力，这类造型即所谓 Kamm-back（卡曼-背）。
>
> — 4.1.4（p89）；4.1.2（p87）

## I — 方法论骨架 (Interpretation)

一句话：**15° 是"边界层还附着得住"的上限，不是"气动最优"的坐标——越过它，角度再大也只会让分离区变大。**

- 这条规则只在"无分离"的前提下单调：只要还没分离，尾部收缩得越平缓，尾迹越小、阻力越低。一旦越过阈值，气流分离，压差主宰，阻力回升。
- 括号里那句"在没有气流分离的情况下可以达到更大的倾斜角度"是这条规则的**另一半**：15° 属于"给定当前分离控制水平"的工程阈值，不是物理极限。所以看到"某车 20° 也很好"时，正确反应是问"它靠什么压住了分离"，而不是宣布 15° 错了。
- 工程上有两条并列的路：①平缓收缩（长尾、泪珠形）；②在"分离区还很小"的位置**截断**（卡曼-背），用一点小的稳定分离换后排空间与车长。两条都成立，判据都是"分离区大小"。
- 因此判断一个尾部造型需要**两个**输入：倾角 + 后部延伸长度。只报倾角，结论不成立——图 4.12 本来就是"倾角 × 延伸长度"两族参数。
- 交付物是三档判定（可继续加大 / 必须先解决分离 / 用卡曼-背），而不是一个"好/不好"。

## A1 — 应用示例 (Application Example)

### 示例 1：原书规则的三档判定（决策演练，输入为假定值）

- **类型与来源**：**合成演练**（p04 的 V2 决策演练；原书未提供这条规则的算例，只有规则与图）。输入为本卡假设，不代表任何真实车型。
- **输入/问题**：三个造型提案——A：后窗/行李箱盖倾角 12°，无分离控制手段；B：倾角 20°，无消除分离的手段；C：后排要求钝尾、车长受限。
- **方法怎么执行**：①判倾角与 15° 的关系；②判有无分离控制；③按"分离区大小"选路。
- **结论/预期输出**：
  - A（12° < 15°，未分离）→ **可以继续加大倾角，阻力仍会下降**；完成标准是给出"下一档试到多少度"的区间，而不是停在 12°。
  - B（20° > 15°，无控制）→ **净损失**：先解决分离（导流、尾部收缩段、涡流发生器）再谈角度；此时"更流线"的直觉失效。
  - C（钝尾）→ 采用**卡曼-背**：≤15° 锥形收拢后截断，验收指标写"分离区小而稳定"，而不是"造型够钝"。
- **判停**：若只报倾角、不报后部延伸长度 → **结论不成立**（图 4.12 的两族参数缺一）。

### 示例 2：把"15° 教条"改写成条件判断（合成演练，非书中事实）

- **类型与来源**：**合成演练**（本卡构造的反向检验）。
- **输入**：某方案倾角 22°，但后部延伸长度很短（近似卡曼-背截断），且有尾部导流。
- **方法的使用**：不套 15°，改为问三件事：①分离点在哪（逆压梯度最大处）；②分离区是否小而稳定；③有没有实测 ΔC_D。
- **结论/预期输出**：若三问答不出 → 输出"需风洞/CFD 逐档试"，**不得**给"22° 一定比 15° 差"的判定；若实测 $C_D$ 在 22° 反而更低 → 记录为该车"分离控制有效"，并回写"15° 阈值在本车不适用"的备注。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 造型评审：后窗/行李箱盖倾角定多少、要不要做长尾。
2. 问"是不是越流线越好""尾部能不能再斜一点"。
3. 后排空间/车长与气动冲突时，要在"长尾"与"卡曼-背"之间选。
4. 风洞/CFD 出现"某角度后阻力跳变"，要解释与处理。
5. 有人拿"15°"当硬约束但又说不出依据，需要澄清它的适用前提。

### 语言信号（中英双写）

- 「后窗倾角多少合适」「尾部越斜越省油吗」「卡曼-背」「泪珠形」「倾角 20 度会不会分离」
- 「rear window angle」「boat tail」「Kamm-back」「flow separation」「15 degrees」
- 反向信号：「凡是倾角小于 15 度就一定对」

- 与 `drag-source-breakdown-and-modifications`：那张卡说"后部是最大单项（0.14）"，本卡说"后部该做成什么形状"。一个是账本定位，一个是形状判据。

- 与整车造型/人机工程：本卡只给气动判据，不代替后排头部空间、法规、制造可行性。

## E — 可执行步骤 (Execution)

**必需输入**：后窗/行李箱盖**倾角**（deg）+ 后部**延伸长度**（或"卡曼-背截断"这一事实）+ 有无分离控制手段 + （可选）实测/CFD 的 $C_D(\text{角度})$ 数据。**缺延伸长度不得给结论。**

**交付物与完成标准**：三档判定之一 + 判据链（倾角 vs 15°、有无分离控制、分离区大小）+ 若走卡曼-背则给"锥形收拢角度 + 截断位置" + 验收方式 + "定量 ΔC_D 不可得"的声明。

1. **取两个几何量**
   - 完成标准：倾角与延伸长度都写出来；若只有倾角 → **停**，要求补延伸长度或声明"结论只到方向"。
2. **判阈值**
   - 完成标准：给出"倾角 ≤15°：未分离，继续加大仍降阻"或"倾角 >15°：已进入分离区，方向反转"的判定，并**同时写出前提"无分离"**。
3. **判分离控制**
   - 完成标准：若 >15° 且有分离控制手段（导流、涡流发生器、收缩段）→ 结论改为"需实测该角度下的净收益"；若无 → 判"净损失，先解决分离"。
4. **选路（判停点）**
   - 判据：空间/车长是否是硬约束。
   - 完成标准：硬约束 → 给卡曼-背方案（≤15° 收拢后截断），验收写"分离区小而稳定"；非硬约束 → 给"平缓收缩到更低角度"的方案与试算区间。
5. **声明定量缺口**
   - 完成标准：必须写出"图 4.12 的 ΔC_D(倾角, 延伸长度) 在 OCR 中读数缺失，故本卡只给方向与阈值，不给 ΔC_D"；用户若坚持要数 → 只能"回原书读图或做风洞/CFD"。

**计算约定（原书未规定，本卡设定）**：角度保留整数（deg）；阈值判定以"≤15° / >15°"二分，不用连续函数拟合（本章无此函数）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **把尾部倾角做得越大越好。** 越过 15° 后因分离阻力回升（ce07）。检出信号：只报倾角、不报后部延伸长度；风洞/CFD 在某角度"跳变"而无解释；把 15° 当硬约束却不知来源。
- **把 15° 当绝对阈值/教条。** 原文括号已说明"在没有气流分离的情况下可以达到更大的倾斜角度"，括号说的是**分离阈值**而非气动极限；卡曼-背存在的理由正是"截断也是有效设计"。
- **引用图 4.12 的 ΔC_D。** 该图在 OCR 中只剩坐标轴与图例（倾角 15/30/45/60/75/90°，延伸长度 0.09/0.18/0.27/0.36/0.45），**无曲线坐标** → 一切定量 ΔC_D 不可引（覆盖缺口 G1）。补读动作：回原书 p90 或英文原版 Fig. 4.12。
- **用图 4.8 编造"尾部造型↔升力系数"配对。** 图 4.8 的 OCR 错行未恢复，**严禁编造车型↔系数配对**。
- **把"分离点"当几何棱线。** 锐边只让分离**位置确定、波动减小**，不减小分离区（g13）。因此"加个锐边就控制住分离"是错的方向。
- **把这条规则套到车头/底面。** 15° 是**尾部收缩**的阈值；车头（驻点位置、$Z_s/Z_v$）与底面是另外的判据，本章未给同类阈值。

### 作者在书中警告的失败模式

- ce07：把尾部倾角做得越大越好（p89 原话 + 括号里的例外条件）。
- p05（reference）：分离不可避免，只能管它的大小——这是本卡的统一判据来源。
- ce09：降阻有代价（尾部收缩常牵动升力与横风）。

### 作者的盲点 / 时代局限

- 没有 CFD：分离点位置、分离区尺寸都靠风洞烟流与经验，作者无法给"给定倾角与延伸长度的 ΔC_D"。
- 15° 的适用前提是"无分离"，而实际分离点还取决于车顶线锐度与侧向气流卷入（图 4.7），三维效应未量化。
- 未讨论主动式尾部（可变形尾翼、主动扩散器）、尾部涡流发生器——**不得补造**。
- 图 4.12 的两族参数只在文字里有定性描述，定量读数在数字化中丢失。

### 容易混淆的邻近方法论

- **"更流线 = 更好" vs "≤15° 才好"**：前者是无分离时的正确方向，后者是含分离阈值后的工程判据；混用会得出"卡曼-背是妥协所以不好"或"15° 是铁律"两种极端。
- **卡曼-背 vs 方屁股**：前者是"在分离区还小时截断"，后者是"随便切"——切过 15° 反而增阻。
- **倾角（deg）vs 延伸长度（相对量）**：图 4.12 的两个自变量，缺一不可。
- **分离（separation）vs 分流（split）**：本译本 OCR 多处把"分离区"印成"分流区"，语义相反（见 `book/glossary.md` 校勘表）。
