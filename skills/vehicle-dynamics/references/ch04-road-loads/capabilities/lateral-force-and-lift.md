# 横向力与升力：$S_A=qC_SA$、$L_A=qC_LA$，横风时侧向力是风阻的 2~3.5 倍

## R — 原文 (Reading)

> **原书要点**（第4章 道路负载）：$S_A=\rho V^2C_SA/2$，式中 $C_S$ 为横向力系数（随相对风角度而变），$A$ 取车头正投影面积。**需留意式中代入的是前端面积，而非侧面面积。**（$C_S$ 的斜率通常介于 0.035/deg 与 0.06/deg 之间）
>
> **原书要点**（第4章 道路负载）：车顶与车底所受压强不等，由此产生升力，$L_A=\rho V^2C_LA/2$；现代轿车在风向角为零时升力系数多在 0.3~0.5，一旦遭遇侧风则可能急剧攀升，达到 1 乃至更大。升力让轮胎能提供的控制力下降，对操纵性不利。
>
> **原书要点**（p98–99 §4.1.7–4.1.8）：横风很强时，侧向分量远远超过迎面阻力分量，结果合力风的方向明显偏离相对风的方向。
>
> — 4.1.7 式(4-6)、4.1.8 式(4-7)（p98–99）；4.1.6（p98）

## I — 方法论骨架 (Interpretation)

一句话：**六力是同一张模板的六个实例——都乘 $q$、都乘 $A$、只换一个系数；力矩类再多乘一个轴距 $L$。**

- 模板本身：力 $=q\cdot C\cdot A$；系数是"这个方向上有多大一块迎风面积被有效利用"。所以 $A$ 永远是**前端投影面积**，与力指向哪个方向无关——侧风吹在侧面，参考面积仍是前端面积。这是作者唯一专门加警告的地方。
- $S_A$ 的意义是**量级排序的翻转**：$S_A/D_A=C_S/C_D$。$C_D=0.34$ 时，10° 处 $S_A$ 已是 $D_A$ 的 1.03~1.76 倍，20° 时 2~3.5 倍。所以"横风评估只看风阻"不是精度问题，是**看错了主项**。
- $L_A$ 的意义是把"发飘"翻译成法向载荷损失：$C_L=0.3$ 时约 53.6 lb（车重的 1.5%），侧风下 $C_L\to1$ 时约 178.8 lb（4.9%）。轮胎能提供的侧向力正比于法向载荷，所以升力是**通过抽走控制力**削弱操纵性的，不是直接产生一个侧向力。
- 系数的前提必须写在输出里：$C_S$ 是偏转角的函数、$C_S(0°)=0$、线性只在 0~20° 附近、斜率带 0.035~0.06/deg；$C_L$ 的 0.3~0.5 是零偏角值。
- 交付物是一张"量级排序表"，不是两个孤立的力。

## A1 — 应用示例 (Application Example)

### 示例 1：仓 B 车速下的 $S_A$ 与 $L_A$（引用数据 + 复算）

- **类型与来源**：p19/p20 的复算演练（**引用数据**：系数带取自正文 p98/p99，不取图 4.8）。
- **输入**：55 mph 标准状态（$q=7.675$ lb/ft²）、$A=23.3$ ft²、偏转角 $\delta=10°$、$C_S=0.35\sim0.60$、$C_L=0.3$（并取 1.0 作侧风对照）、$C_D=0.34$（只用于比值）。
- **方法的使用**：①$q=\rho V^2/2$；②$S_A=qC_SA$；③$L_A=qC_LA$；④比值 $S_A/D_A=C_S/C_D$。
- **结论/结果（复算值）**：$S_A=\mathbf{62.6\sim107.3}$ lb；$L_A=\mathbf{53.6}$ lb（$C_L=0.3$）→ **178.8 lb**（$C_L=1.0$）；$S_A/D_A=\mathbf{1.4\sim2.5}$（10°）、20° 时 $C_S=0.7\sim1.2$ → $S_A=125\sim215$ lb、**比值 2.1~3.5**。量级校验：$L_A/W=53.6/3650=\mathbf{1.5\%}$，$C_L=1$ 时 **4.9%**。

### 示例 2：换一台车、换一个偏转角（合成演练，非书中事实）

- **类型与来源**：**合成演练**（自造 $A$、$V$、$\delta$，与三个仓都不同）。
- **输入**：$V=70$ mph（102.64 ft/s）、$A=22$ ft²、$\rho=0.00236$、$\delta=8°$、$C_S=0.28\sim0.48$、$C_L=0.25$。
- **方法的使用**：$q=12.43$ → $S_A=12.43\times22\times C_S$；$L_A=12.43\times22\times0.25$。
- **结论/预期输出**：$S_A=\mathbf{76.6\sim131.3}$ lb、$L_A=\mathbf{68.4}$ lb。自检：$C_S/\delta$ 应在 0.035~0.06/deg 内（0.28/8=0.035、0.48/8=0.06 ✓ 恰在带的端点上，说明这组输入是"带边界"，不是任意值）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 问"侧风 20° 时车受多大侧向力/升力"。
2. 做横风评估时只有风阻一项，被追问"侧向力呢"。
3. 问"高速发飘是升力还是悬架的问题"——需要把发飘折算成法向载荷损失。
4. 拿到风洞六分量数据，要把 $C_S$、$C_L$ 换成力和力矩。
5. 比较两台车的横风稳定性，但一人给的是 $C_S$、一人给的是侧向力（lb）。

### 语言信号（中英双写）

- 「侧向力多大」「横风把车推多狠」「升力/下压力多少磅」「发飘是不是升力」「侧风 20 度」
- 「side force」「lateral force」「lift force」「downforce」「C_S」「C_L」「crosswind angle」
- 反向信号：「风从侧面吹来，是不是该用侧面面积」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `aero-moments-and-pressure-center`：本卡出力（$S_A$、$L_A$），那张卡出力矩（PM/YM/RM）与 CP。**同一张模板、同一套系数来源**，但输出契约不同：只要问"力矩/压力中心/车会不会被吹转"→ 那张卡。
- 与 `aero-drag-and-power`：同一家族的纵向成员；本卡常在"横风"语境下与它并出，但两者不可互相替代（$S_A\ne D_A$）。
- 与 `crosswind-sensitivity-and-tradeoff`：本卡给"力有多大"，那张卡给"这车敏不敏感、怎么改"。有 $C_S$ 不等于能判敏感度（还要 CP、NSP、侧偏刚度）。
- 与轮胎侧偏力（第 5/6 章）：$S_A$ 是气动力、作用在压力中心；轮胎 $F_y$ 作用在接地面。**两者同名不同源，不得相加混淆。**

## E — 可执行步骤 (Execution)

**必需输入**：$V$（相对风）、$A$（前端投影 ft²）、偏转角 $\delta$、系数（$C_S$ 或 $C_L$，**必须给取值依据**）。**缺系数不得开算**——本章只给典型带与斜率，系数需风洞/试验（章外缺口 G6）。

**交付物与完成标准**：一张两行表（$S_A$、$L_A$：公式、代入、结果 lb）+ 比值 $S_A/D_A$ + 法向载荷损失百分比 + 口径声明（参考面积、$\delta$、系数来源与线性区间）。

1. **确认参考面积**
   - 完成标准：写出"$A$=前端投影面积"，并声明"即使算侧向力也用前端面积"；若用户给的是侧面面积 → **停**，先换算或重取。
2. **确认偏转角与系数**
   - 完成标准：写出 $\delta$ 与"$C_S$ 按 0.035~0.06/deg 的斜率带取值"或"$C_L$ 取 0.3~0.5（零偏角）/ 侧风可到 1+"；若 $|\delta|>20°$ → **判越界**，只给"量级更大"的定性（本章无数据）。
3. **算 $q$ 与两个力**
   - 完成标准：$q$ 保留 3 位有效；$S_A$、$L_A$ 各给区间（系数带的两端），不只给中点。
4. **比值与载荷损失**
   - 完成标准：给 $S_A/D_A$ 并指出"横风时侧向力是主项"；给 $L_A/W$ 百分比；若 $L_A/W>5\%$ → 明确提示"轮胎可用侧向力被显著抽走"。
5. **量级自检（判停）**
   - 自检①：$S_A/D_A$ 应在 1~3.5（$\delta$ 10°~20°、轿车 $C_D$ 0.34 口径）；若 <0.5 → 查参考面积或 $\delta$。
   - 自检②：$C_S/\delta$ 应落在 0.035~0.06/deg；差一个量级 → 查参考面积（ce01 的检出信号）。
   - 自检③：$L_A$ 为负表示下压力，符号不要丢。

**计算约定（原书未规定，本卡设定）**：力保留 3 位有效（lb）；区间按系数带两端给，不取中值冒充；$g$、$\rho$ 口径同上游卡。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **强横风下只算阻力、据此说"风可以忽略"。** 作者原话："横向力比阻力大得多"（ce13）。量化：20° 时 $S_A/D_A=2.1\sim3.5$。用"风阻占比只有 x%"论证"侧风不重要"是量级错误，不是精度问题。
- **用侧面面积当参考面积。** 五式全用前端面积；侧面面积约为前端 3 倍，$S_A$、$L_A$、三力矩会同时错，而数值仍"像合理值"（ce01，作者唯一亲自预警处）。
- **把 $S_A$ 当轮胎侧偏力 $F_y$ 用。** 一个是气动力（作用在 CP、随 $V^2$），一个是轮胎力学量（作用在接地面、随侧偏角与载荷）；混算会重复计力。
- **把 $C_S$ 往外推过 20°。** 原文措辞含糊（"从零开始的 20°~40° 角度范围内近似为线性"），只能给斜率带、不能给外推上限；30° 的牵引车-挂车是另一量级，本章无数值。
- **编造"车型↔$C_L$/$C_D$"配对。** **图 4.8 的 OCR 错行**，四组标注无法分配给具体车型；章内可用的只有正文的 $C_L$ 0.3~0.5 与"侧风可到 1+"。凡要"某车型的 $C_L$"→ **停**，要求用户提供风洞数据。
- **把 $C_L$ 当常数用。** 它对**车身攻角**与偏转角都敏感（侧风下可剧烈增加），不是定值。
- **跨仓搬系数。** 仓 C 的 $C_D=0.42$、仓 A 的 $C_D=0.65$ 都不是"通用轿车值"；$C_S$/$C_L$ 也必须按目标车型重取。**仓 C 的 0.42 与分解表"合计 0.42"纯属数值巧合，严禁互引。**

### 作者在书中警告的失败模式

- ce01：前端面积（p98，作者唯一专门加警告处，且警告就写在式(4-6) 之后）。
- ce13：强横风只算阻力（p98）。
- p20 边界：整车 $C_L$ 与按轴的 $C_{Lf}/C_{Lr}$ 不可混用——后者须相加才与整车可比。

### 作者的盲点 / 时代局限

- 系数全部要试验取得，本章**无估算法**；$C_S$ 的线性上限措辞含糊，无法作为工程限值。
- 只讨论稳态风；阵风（瞬态）不在模型内，而"发飘"的主观感受往往来自瞬态。
- 现代轿车 $C_L$ 已显著低于 0.3（很多接近 0 甚至负值），书中的 0.3~0.5 是 1992 年口径——引用时必须标年代。
- 升力与降阻常互相冲突（扰流器增阻降升力），本章只在附件段落讨论取舍，未量化。

### 容易混淆的邻近方法论

- **$S_A$（气动侧向力，∝$V^2$）vs $F_y$（轮胎侧偏力，∝侧偏角）**：跨章最常见的一处串用。
- **$C_S$（侧向力系数）vs $C_{YM}$（横摆力矩系数）**：前者给力，后者给"力臂×力"，量纲不同。
- **升力 $L_A$ vs 轴距 $L$**：同一个字母，只靠下标 A 区分——力矩式里的 $L$ 是轴距。
- **"侧面面积大所以侧向力大"**：错，参考面积固定为前端面积，侧向力大是因为 $C_S$ 大。
