# 决策规则速查 — 《车辆动力学基础》第 4 章 道路负载

| 能力 | 一句话规则 |
|---|---|
| 空气密度与标准大气：$\rho=0.00236(P_r/29.92)(519/(460+T_r))$，英制必须先除以 $g$ | 先判单位制与用途 → 英制用 $\rho=0.00236(P_r/29.92)(519/(460+T_r))$（$T$ 换绝对温度）→ 公制用 1.225 式 → 两式互核差应 ≤1% → 报 $\rho$ + 相对标准值偏差（$\rho$ 与 $D_A$、hp 同比例）。 |
| 风阻与风阻功率：$D_A=qC_DA$、$hp=D_AV/550$，三个输入各有一个静默陷阱 | $q=\rho V^2/2$（$V$ 用 ft/s）→ $D_A=qC_DA$（$A$=前端投影）→ $hp=D_AV/550$；反算 $D_A/(qA)$ 回 $C_D$、轿车 $C_D<0.1$ 先查参考面积、有自然风再按 +5%~10% 记账。 |
| 顺逆风与相对速度：$V=V_v\pm V_w$，平方项让「逆风代价 > 顺风收益」 | 先把车速与风速合成相对速度（逆风加、顺风减）再平方 → 三工况（无风/逆/顺）各报一个 $D_A$ → 增量与减量之比（仓 C 为 +75.5 vs −47.6，1.59 倍）→ 平均风分支只能给方向（$E[V^2]>V^2$，与 $C_D$ 偏角修正同号）。 |
| 横向力与升力：$S_A=qC_SA$、$L_A=qC_LA$，横风时侧向力是风阻的 2~3.5 倍 | 力 $=q\cdot C\cdot A$（$C_S$ 按 0.035~0.06/deg，线性只在 0~20°）→ 必报 $S_A/D_A$（10° 约 1.03~1.76 倍、20° 约 2.1~3.5 倍）与 $L_A/W$（$C_L$=0.3 时约 1.5%、$C_L$=1 时约 4.9%）→ 缺系数即停。 |
| 三力矩与压力中心：$PM/YM/RM=qCAL$，力矩没有「作用点」，CP 不是重心 | 先算基准量 $qAL$ 再乘系数（力矩单位必须 lb·ft，出现 lb 即漏乘 $L$）→ 三力矩同报并注明 RM 最大但不重要 → 由 $L\cdot C_{YM}/C_S$ 反算 CP（中点前 2.27 ft、重心前 2.57 ft）→ 禁止把 $\tau/L$ 当力。 |
| 阻力来源分解与降阻定位：9 项加总 0.42，车体占 65%，后部单项最大 | 先核适用区间（0.42 是 70s 轿车估计值）→ 九项加总核验 → 按占比排序（后部 33.3% > 轮坑 21.4% > 底部 14.3% > 前部 11.9%）→ 每级配改法量级 → 附件先问目标函数（降升力则增阻是价格）。 |
| 尾部倾角与分离阈值：≤15° 收缩一直降阻，>15° 因分离回升 | 取倾角与后部延伸长度两个量 → ≤15° 且未分离则可继续加大；>15° 且无分离控制则判净损失、先解决分离；空间受限走卡曼-背（≤15° 收拢后截断），验收写「分离区小而稳定」。 |
| 横风敏感度与降阻取舍：看 CP–NSP 的距离，不看 CP 的坐标；灵敏度随速度上升 | 定位 CP 与 NSP（缺一即停）→ 判距离方向（变大→更敏感）→ 四条杠杆（加长轴距、提高有效侧偏刚度、CP 后移、移 NSP）→ 速度复核只写「随速度上升」→ 声明静态分析忽略侧倾柔度/驾驶员/瞬态。 |
| 滚动阻力基线：$R_x=f_rW$，用静态重量就够，只对直线成立 | $R_x=f_rW$（$W$ 静态、$f_r$ 给层级与出处）→ 反算 $R_x/W$ 回 $f_r$ → 判「要不要动态重量」（前后 $f_r$ 相同则零影响）→ 判直线前提（有侧向力即停）。 |
| 滚阻系数四式选型：常数 / 线性 / 幂式 / 货车双式，先定精度再选式 | 按「车型/速度段/路面/轮胎结构」筛标定域 → 选式并算 $f_r$（$V$ 必须 mph）→ $C_h$ 用乘不用加 → 给一条换式对照（67 mph 时 0.0167 vs 0.00685）→ 幂律段与 (4-13) 载荷律一律停。 |
| $f_r$ 的状态修正五项：温度 / 胎压 / 速度 / 材料 / 侧偏——$f_r$ 是状态量不是常数 | 先填五项条件表（预热里程/时间、胎压与路面、速度段、磨损与结构、有无侧偏）→ 逐项给方向与量级（20 mile/20 min、−20%、+25%、几度≈×2）→ 输出可用区间与「能否与既有数据比较」，不给单点。 |
| 典型 $f_r$ 表与路面层级：三车型 × 三路面，越野是 20 倍的量级跳变 | 先判铺装/非铺装（0.08 与 0.30 之间无插值意义）→ 查表取车型 × 路面 → 铺装再叠 $C_h$（1.0/1.5/≈2.0，乘子）→ 算 $R_x$ 并声明精度层级 → 报「滚阻是不是唯一主项」（沙地与风阻之比 18:1）。 |
| 总道路负载与功率：$R_{RL}=f_rW+qC_DA+W\sin\theta$、$hp=R_{RL}V/550$——力是二次，功率是三次 | 三项分别算（$R_x=f_rW$、$D_A=qC_DA$、$W\sin\theta$ 用 sin 不用 %）→ 求和 → $hp=R_{RL}V/550$（$V$ 用 ft/s）→ 解交叉点 $f_rW=qC_DA$ → 报「风阻功率 ×(V2/V1)³ vs 总功率实际倍数」两个不同百分比。 |
| 油耗链与归因：$\Delta C_D$ 不能线性外推成 $\Delta$mpg，必须带循环 | 先问循环（未定即停）→ 算 $\Delta R_{RL}$ 与占比 → 接功率 $\Delta hp=\Delta R\cdot V/550$ → 接燃油（BSFC→lb/h→gal/h→mpg，密度须给来源）→ 例题 1 必报缺口（75.3 vs 82.6，+9.8%，236 bhp 不补）。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
