## 符号约定（先读这一段，否则后面的 $C$ 会读串）

| 符号 | 书中含义 | 备注 |
|---|---|---|
| $p_s$, $q$（$p_d$）, $p_t$ | 静压、动压 $\rho V^2/2$、总压 | 全为压强 lb/ft²，**不是力** |
| $V$ | **相对**风速（车速＋自然风的合成） | 式(4-2) 用 ft/s；$f_r$ 经验式用 mph（**1 mph = 1.466 ft/s**，即 ft/s = mph ÷ 0.682） |
| $\rho$ | 空气**质量**密度 | **lb·s²/ft⁴**＝lb/ft³÷32.2；标准 0.00236 |
| $A$ | **前端投影面积** ft² | ≠表面积、≠侧面面积；式(4-2)(4-6)~(4-10) 全用它 |
| $C_D$, $C_DA$ | 阻力系数（无量纲）、阻力面积（ft²/m²） | $C_DA$ **有量纲** |
| $C_S$, $C_L$ | 侧向力系数（0.035–0.06/deg）、升力系数（0.3–0.5，侧风 1+） | 偏转角的函数 |
| $C_{PM}$, $C_{YM}$, $C_{RM}$ | 俯仰（0.05–0.2）、横摆（0.007–0.017/deg）、侧倾（0.018–0.04/deg） | 力矩类都乘轴距 $L$ |
| $L$ | ⚠️**轴距**（力矩的特征长度） | 与升力 $L_A$ 撞符号，靠下标 A 区分 |
| $W$ | 整车重量 lb | $M=W/32.2$（slug） |
| $f_r$ | 滚动阻力系数（**无量纲**） | ⚠️OCR 作 `f，`；教材曾误标 lb |
| $C_h$ | 路面系数（乘子，1.0/1.5） | ⚠️OCR 作 `C，`，易与 $C_D$ 混 |
| $R_{RL}$, $hp_{RL}$ | 道路负载 lb、道路负载功率 hp | **不含加速阻力**；轮上需求 |
| $\theta$ | 坡角 | 用 $\sin\theta$；% 坡度=100·tanθ |
| CP / NSP | 压力中心 / 中性转向点 | 二者距离决定横风敏感度 |
| $\alpha_{cw}$ | 偏转角（相对风与纵轴夹角） | ≠轮胎侧偏角 |

## A. 气动原理与流场（g01–g18）

| id | 术语 | 作者的定义 / 本章口径 | 关键区分 / 易错点 |
|---|---|---|---|
| g01 | 道路负载 road load | `滚动阻力+空气阻力（有爬坡阻力还要加上）的和构成车辆的驱动负载`，即 $R_{RL}=f_rW+\rho V^2C_DA/2+W\sin\theta$ | ≠「路面载荷/轴荷」（那是地面垂直反力）；**不含加速阻力**（惯性项属第 2 章）；三项标量和 |
| g02 | 空气动力学（车身外流） | 外流产生「三个力 + 三个力矩」六力家族，影响燃油经济性、操纵性、NVH | ≠发动机进气/冷却的内部流动（冷却阻力 0.025 是按动量损失折算的外部阻力项） |
| g03 | 伯努利方程 | $p_s+\rho V^2/2=p_t$；前提：不可压、流动平滑、摩擦可忽略 | ⚠️**不能用来解释阻力**：原文「车辆尾部压力会和前端压力刚好平衡，因此不会产生阻力」；≠「流速快压力低」的半句口诀 |
| g04 | 静压 $p_s$ | 流动中当地的、垂直于流动方向的压力，可高于也可低于环境压力 | ≠大气压/「车停了」；「静」指相对流动方向 |
| g05 | 动压 $q$（$p_d$） | `方程中 ρV²/2 一项是空气动压，常用 q 表示，典型单位是每平方英尺磅` | ≠压力波动（无时间含义）；≠力（差一个面积） |
| g06 | 总压 $p_t$ | 静压＋动压；每条流线各自守恒，远前方均匀时数值相同 | ≠空间常数；驻点处 $p_s=p_t$；皮托管测的就是它 |
| g07 | 流线 / 流管 | `一束流线组成流管`；管内质量流量守恒 → 截面收缩则加速、降压 | ≠示踪粒子轨迹；≠实体管道；本章唯一的可视化推理工具 |
| g08 | 驻点 | `一簇流线必须沿直线到达物体后停滞下来……在那点上，相对速度降为零`；边界层由此开始 | ≠车头几何中心/格栅中心；**位置随车速与来流方向移动**；设计判据 $Z_s/Z_v$ 越小越好 |
| g09 | 边界层 | 壁面到主流之间速度从 0 过渡到 $V_\infty$ 的流层，由零厚度逐渐增厚，最终转湍流 | ≠「边界线/分界面」（有厚度）；≠贴壁静止空气膜（内部有剪切） |
| g10 | 层流 / 湍流（过渡区） | 边界层内的两种流态，沿同一车身先后出现，中间有过渡区 | ⚠️**章外补充**：本章**没有**「湍流边界层更耐逆压梯度」这句；引用必须标注，否则会与卡曼-背叙述混淆层次 |
| g11 | 顺压梯度 | $dp/dx<0$，「因为它抑制了边界层的增长」 | ≠顺风；=加速区（车头圆弧、发动机罩前缘下弯段） |
| g12 | 逆压梯度 | $dp/dx>0$，压力回升使边界层减速增厚 → 分离的**唯一**成因（本章口径） | ≠逆风/顶风；找分离区就是找逆压梯度区 |
| g13 | 分离点 / 分离区 | 近壁气流速度降为零并开始倒流的纵向位置；下游贴体区即分离区，区内压力低于环境 | ≠棱线/断点（锐边只让分离**位置确定**，不减小分离区）；⚠️OCR 多处把「分离区」印成「分流区」 |
| g14 | 卡门涡街 | 钝体绕流时**交替、周期性**脱落的涡列，有确定频率 | ≠车后「一团乱流」；后视镜抖/天线啸叫/天窗轰鸣的成因 |
| g15 | 形状阻力 | 分离区低压与前端高压之间的压差沿车身的合力（故又称压力阻力） | ≠造型好看与否；≠摩擦阻力；账上最大一块（后部 0.14 单项最大） |
| g16 | 摩擦阻力 | 边界层内粘性剪应力在车表面的积分；账上 0.025（约 6%） | ≠轮胎与地面的摩擦（串章到 4.2/第 5 章） |
| g17 | 尾流 | 分离之后向下游延伸的涡系与低速区（原文「两侧气流被拖入后部低气压区」） | ≠分离区（贴体、压力最低的那一小块） |
| g18 | 压力系数 $C_p$ | 车表压力相对环境压力表示为正或负；图 4.6 纵轴即此 | ⚠️本章**只给图未给公式**；$C_p=(p-p_\infty)/q$ 属章外补充；OCR「C, 4」易误读为 $C_D$ |

## B. 气动系数与参考量（g19–g23、g27、g28）

| id | 术语 | 作者的定义 / 本章口径 | 关键区分 / 易错点 |
|---|---|---|---|
| g19 | 空气阻力 $D_A$ | $D_A=\rho V^2C_DA/2$；`SAE 标准的阻力符号 D，在文中加上脚标 A 表示空气阻力` | ≠滚阻、≠总阻力；下标 A 是作者自加的消歧手段（$L$ 同时是升力与轴距） |
| g20 | 阻力系数 $C_D$ | $C_D=D_A/(\rho V^2A/2)$；「通过风洞测试或滑行试验确定」；轿车 0.30–0.35（80 年代）、70 年代 0.4–0.5 | ≠$\mu$；≠粗糙度指标；**换参考面积 $C_D$ 就变**；本章无估算法 |
| g21 | $C_DA$（阻力面积） | `车辆的阻力特性有时候也用「C_D A」的值表征` | ⚠️**有量纲**（ft²/m²），不是 $C_D$；跨尺寸比车用它。**勘误**：候选「会算出大 20 倍」不成立——同单位下约 **2 倍**，20 倍只在「m² 面积值当 $C_D$ 且面积按 ft² 取」的双重单位混用下出现 |
| g22 | 前端面积 $A$ | `A——车辆的前端面积`；半尺寸模型面积 1/4、阻力 1/4 | **最高频误读**：≠表面积（湿面积，只与摩擦阻力有关）；≠侧面面积（**即使算侧向力也用前端面积**） |
| g23 | 空气密度 $\rho$ | 英制质量密度 lb·s²/ft⁴；$\rho=0.00236(P_r/29.92)(519/(460+T_r))$；公制 $1.225(P_r/101.325)(288.16/(273.16+T_r))$ | ≠重度 0.076 lb/ft³（那是 $\gamma=\rho g$，差 32.2 倍）；≠常数；**本章式不含湿度** |
| g27 | 侧向力 / 横向力 $S_A$ | $\rho V^2C_SA/2$；$C_S$ 斜率 0.035–0.06/deg，$C_S(0°)=0$ | ≠轮胎侧偏力 $F_y$（第 5/6 章的轮胎量）；强横风时「横向力比阻力大得多」 |
| g28 | 升力 $L_A$ / $C_L$ | 车顶-车底压差；$C_L$ 0.3–0.5，侧风「到 1 甚至更高」；「通过降低对轮胎处可用的控制力」削弱操纵性 | ≠机翼升力（车用是要消除的坏东西，负值=下压力才好）；⚠️与轴距 $L$ 撞符号 |

## C. 风向与风况（g24–g26）

| id | 术语 | 作者的定义 / 本章口径 | 关键区分 / 易错点 |
|---|---|---|---|
| g24 | 相对风 | `相对于车辆的风主要由本身行驶速度产生的部分加上小得多的方向任意的自然风分量组成`；自然风典型 10~20 mph（大风 50~60） | ≠气象风；≠车速；**平均风 ≠ 平均阻力** |
| g25 | 偏转角 / 相对风角 | 相对风与车辆纵轴的夹角；$C_S$、$C_{YM}$、$C_{RM}$ 都是它的函数，0~20° 近似线性 | ≠转向角；≠轮胎侧偏角 $\alpha$；线性上限原文措辞含糊（20° 或 40° 两解） |
| g26 | 逆风 / 顺风 | 逆风 $V=V_v+V_w$、顺风相减；「因为速度在方程（4-2）中是平方项，逆风导致的阻力增加……要大得多」 | ≠对称加减；55 mph 车 ±25 mph → 68 / 143（+112%）/ 20 lb（−70%） |

## D. 力矩与参考点（g29–g35）

| id | 术语 | 作者的定义 / 本章口径 | 关键区分 / 易错点 |
|---|---|---|---|
| g29 | 俯仰力矩 $PM$ / $C_{PM}$ | $\rho V^2C_{PM}AL/2$；$C_{PM}$ 0.05–0.2；来自「不作用在地平面上的阻力」与「升力没有精确地作用于轴距的中点」 | ≠加速/制动引起的惯性载荷转移（本项**与加速度无关**，匀速也存在）；需要特征长度 $L$ |
| g30 | 横摆力矩 $YM$ / $C_{YM}$ | $\rho V^2C_{YM}AL/2$；0°~20° 线性，斜率 0.007–0.017/deg | ≠轮胎回正力矩；与 CP 位置**等价地**进入式(4-11) 分子 |
| g31 | 侧倾力矩 $RM$ / $C_{RM}$ | $\rho V^2C_{RM}AL/2$；斜率 0.018–0.04/deg；「这一力矩对车辆稳定性影响很小」 | ≠横摆力矩（绕 x vs 绕 z）；量级最大**但不可当主因**；也不可删（经悬架侧倾转向进入敏感度） |
| g32 | 压力中心 CP | 「侧向力和横摆力矩作用的合成作用点」；一般位于重心**之前** | ≠重心；≠轴距中点（风洞测力点故意放在中点，故「有侧向力就必然有横摆力矩」是几何必然） |
| g33 | 中性转向点 NSP | 「侧向力能在车辆前后轴上产生相同的侧偏角的作用点」，即「外来侧向力将不引起车辆横摆的纵向点」；受轮胎、转向柔度、悬架、配重影响 | ≠重心；横风敏感度 = **NSP 到 CP 的距离**（不是 CP 的坐标） |
| g34 | 横风敏感度 | 四类因素：空气动力学特性、车辆动力学特性、转向系统特性、**驾驶员闭环行为**；用「保持路径时的横摆率响应」度量 | ≠侧向力大小；≠单车属性（是**人-车-风闭环**）；本章只能定性（式 4-11 分母残缺） |
| g35 | 横摆率响应 $r/\alpha_{cw}$ | 「横风中的横摆率响应几乎可以解释车辆之间主观评定的所有差异」；拟合 $y=2.488x+2.464$，$r^2=0.974$ | ⚠️量化依赖残缺的式(4-11)；**绝对分值不可引**（零点待核），只可排序；$n=7$ 台改型车，不可跨车型外推 |

## E. 尾部与附件（g36–g37）

| id | 术语 | 作者的定义 / 本章口径 | 关键区分 / 易错点 |
|---|---|---|---|
| g36 | 卡曼-背 / 泪珠形 | 理想尾部是「以 15° 或更小的角逐渐变成到一个点的圆锥」；钝尾「不会显著增加阻力」即为卡曼-背 | ≠「方屁股」；判据是**倾角 ≤15°**（分离阈值，不是气动极限） |

## F. 滚动阻力与能量（g38–g44）

| id | 术语 | 作者的定义 / 本章口径 | 关键区分 / 易错点 |
|---|---|---|---|
| g38 | 滚动阻力 $R_x$ | 七机制（胎侧变形、胎面变形、接触区刮擦、纵横向滑动、路面变形、内外空气阻力、颠簸损失）；$R_x=f_rW$ | ≠库仑摩擦；主体是材料**迟滞**；用静态重量就够（「大多数情况下，静态重量……已足够精确」） |
| g39 | 滚动阻力系数 $f_r$ | 「一个无量纲因子」；$f_r=R_x/W$；四套口径（常数/线性/幂式/货车双式）；五因素（温度、胎压、速度、材料磨损、侧偏） | ≠$\mu$（量级差两个数量级）；≠常数；⚠️OCR 作 `f，`，例题曾误标「lb」 |
| g40 | 驻波 | 「轮胎接地区域后面的胎体处产生高能驻波……若仅持续中等长度的时间，都将引发灾难性的事故」，是「限制轮胎额定速度的一个主要因素」 | ≠振动/噪声（是**结构失稳**）；≠弦管中的同名驻波 |
| g41 | 迟滞 hysteresis | 「胎面材料的迟滞阻力导致的能量损失」；「尽管……对于良好的湿路面的附着力很重要，它却降低了轮胎在滚动阻力方面的性能」 | ≠时间延迟；= 橡胶加载-卸载回线面积；**湿地附着的前提** |
| g42 | 路面系数 $C_h$ | 「=1.0 为光滑混凝土，=1.5 为热的沥青路面」；只出现在货车双式里作**乘子** | ≠附着系数；≠$f_r$ 本身；⚠️OCR 作 `C，`；**不含**磨耗（≈×2）与潮湿（更高）两条定性修正 |
| g43 | 道路负载功率 | $hp_{RL}=R_{RL}V/550$；「由于式(4-18)中是三次方关系……高速情况下，速度的微小增加可能引起车辆所需功率的巨大增长」 | ≠发动机功率（未含传动损失、附件、加速储备）；**轮上需求**。⚠️口径注：55→60 mph 的 **+30%** 是**风阻分量**的三次口径；**总道路负载功率约 +18%**，两者不可互换 |
| g44 | 坡度阻力（爬坡阻力） | $W\sin\theta$；图 4.35 上「只是根据它们的大小简单地将曲线平行上移一段距离」 | ≠$W\times$坡度%（% 坡度=100·tanθ，只在**小角度**近似 sinθ）；三式中**唯一与 $V$ 无关**的一项 |

## 易混对照（下游最常踩的 4 组表 + 4 组要点）

### 1. $C_D$ vs $C_DA$

| | $C_D$ | $C_DA$ |
|---|---|---|
| 量纲 | 无量纲 | ft²（英制）/ m²（公制） |
| 定义 | $D_A/(qA)$ | $C_D\times A$，阻力面积 |
| 用途 | 比**同尺寸**车的不同造型 | 比**尺寸不同**的车 |
| 本章数值 | 轿车 0.30–0.35；平板 1.95；翼面 0.007 | 图 4.37 小型轿车 $C_DA=0.84$ m² |
| 混用后果 | 把 $C_DA$ 当 $C_D$ 上报，数值「像个系数」但偏大（同单位约 2 倍，双重单位混用可到 20 倍），无报警 | 把 $C_D$ 当 $C_DA$ 会算出「阻力面积 0.32 ft²」的荒唐车 |

### 2. 前端面积 vs 表面积 vs 侧面面积（**最高频误读**）

| 面积 | 定义 | 在本章用在哪 | 用错的后果 |
|---|---|---|---|
| **前端面积 $A$** | 正面投影面积 | 式(4-2)(4-6)(4-7)(4-8)(4-9)(4-10) **六个式子全部** | —（正确用法） |
| 表面积（湿面积） | 车身与空气接触的全部表面 | 只与**摩擦阻力**有关，本章未给公式（账上 0.025） | 用它除得 $C_D$ 会偏小一个数量级 |
| 侧面面积 | 车身侧向投影 | **不用于任何公式** | 侧向力/升力/三力矩全错，且错得像「合理值」（侧面面积只比前端大 3~4 倍） |

### 3. CP vs 重心 CG vs NSP

| 参考点 | 由什么决定 | 作者定义 | 在横风里的角色 |
|---|---|---|---|
| **CG** | 质量分布（前后配重） | 质量中心 | 惯性参考；与轮胎侧偏刚度一起**决定** NSP |
| **NSP** | CG + 轮胎侧偏刚度 + 转向系统柔度 + 悬架运动学 + 重量分配 | 「不引起车辆横摆的纵向点」 | **目标点**：CP 越靠近它越好 |
| **CP** | 纯气动（车身形状、偏转角） | 「侧向力和横摆力矩作用的合成作用点」 | **可调点**：与 NSP 的距离 = 横风敏感度 |

三条判据：①CP 在 CG 之前 → 车被吹得**偏离**风向；②CP 越接近 NSP → 车道偏离越小；③风洞在**轴距中点**测力 → 只要有侧向力就必然有横摆力矩（几何必然）。

### 4. $f_r$ vs 摩擦系数 $\mu$

| | 滚动阻力系数 $f_r$ | 摩擦（附着）系数 $\mu$ |
|---|---|---|
| 定义 | $R_x/W$：滚动的**能量损失比** | $F/F_z$：接触面的**附着极限比** |
| 量级 | 0.012 ~ 0.30 | 0.7 ~ 1.0（干沥青） |
| 随载荷 | $R_x\propto W$，$f_r$ 基本与 $W$ 无关 | 随载荷增大略降 |
| 随速度 | **强相关**（∝V 或 ∝V^2.5） | 弱相关 |
| 物理来源 | 迟滞＋刮擦＋路面变形＋滑动＋空气＋颠簸 | 接触面微观剪切 |
| 典型误读 | 「路面越滑 $f_r$ 越小」→ 但沙地 0.30 是混凝土 0.015 的 **20 倍** | 认为 $f_r$ 是 $\mu$ 的小写版，拿去算制动距离 |

### 5. 形状阻力 vs 摩擦阻力（要点）

形状阻力＝分离造成的前后压差，杠杆是「缩小分离区/尾部倾角/卡曼-背」；摩擦阻力＝边界层粘性剪切，占 0.025（约 6%），杠杆是突出物与车底平整度。**两者都不是「表面光洁度」问题，也都不是轮胎与地面的摩擦。**

### 6. 顺压梯度 vs 逆压梯度（要点）

判据是 $dp/dx$ 的符号（压力沿流向**下降/升高**），与「顺风/逆风」毫无关系；顺压＝加速＝边界层变薄，逆压＝减速＝边界层增厚→**分离**。

### 7. 三个气动力矩的轴（要点）

$RM$ 绕 **x 轴（纵向）**、$PM$ 绕 **y 轴（横向）**、$YM$ 绕 **z 轴（垂直）**；配对是「力与其**同轴**力矩」（x 力↔侧倾、y 力↔俯仰、z 力↔横摆），不是「力↔效果」。⚠️图 4.10 的 OCR 把「垂向」标成「（x轴）」，应为 **z 轴**。

### 8. 逆风 vs 顺风：不是对称的加减（要点）

55 mph 车、±25 mph：无风 68 lb / 逆风 143 lb（+112%）/ 顺风 20 lb（−70%）。原因：$V$ 是平方项 → $E[(V_v+V_w)^2]=V_v^2+\sigma_w^2>V_v^2$。**平均风 ≠ 平均阻力**，顺逆风不能相互抵消（但顺风确实减阻，错的只是「对称」）。
