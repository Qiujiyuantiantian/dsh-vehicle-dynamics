# 关键术语（第 7 章 悬架）

> 来源：阶段 1 glossary 候选 `candidates/glossary.md`（32 条）整理为 32 条（g01–g32 全收，无一条转入 needs_review——术语的交付形态本来就是本表）。
> 用法：凡能力卡或回答中出现这些词，一律按本表的语义使用，不得回退到日常义。原书 p191–p214，全章英制。
> **⚠️待核** 标记＝该术语绑定的公式在本章存在未解决的符号/基准问题，凡据其给定量结论必须标"需纸书复核"（详见文末「待核清单」）。

## 符号约定（先读这一段，否则下面的 e/d 会读反）

| 符号 | 书中含义 | 备注 |
|---|---|---|
| $e$, $d$ | 等效拖曳臂虚拟铰接点相对**车轮接地点**的垂向高度与水平距离；$F_z/F_x=e/d$ | $e>0$ 为地面之上；**$d$ 的正方向书中从未明说**，靠式(7-21) 负号旁证"支点位于车轴后方" |
| $h$, $L$ | 重心高度、轴距 | 例题 1：$h=20.5$ in、$L=108.5$ in |
| $K_r$, $K_f$ | 后／前悬架弹簧刚度，**左右两侧之和** | 例题题面明注"此刚度为左右两侧之和"，正文未强调 |
| $\Delta W_r$, $\Delta W_f$ | 后／前悬架载荷变化 | 加速时后增前减 |
| $\delta_r$, $\delta_f$ | 后／前悬架挠度，**弹簧压缩为正** | $\Delta W=K\delta$ |
| $\theta_p$ | 俯仰角；本处**前仰（车头抬起）为正** | 由 $\theta_p=(\delta_r-\delta_f)/L$ 与例题 1 的 1.43 deg/g 反推 |
| $a_x$ | 纵向加速度（加速为正、制动为负） | 全章英制，$g=386$ in/s² |
| $\xi$ | ⚠️**一词两义**：7.3.6＝前轮驱动力占总驱动力百分比；7.4＝前轴制动力所占比例 | **不是轴荷比**；跨节引用必须重新定义 |
| $r$ | 车轮半径 | 仅独立悬架出现，因存在反作用扭矩 $T=rF_x$ |
| $\beta_f$, $\beta_r$ | ⚠️待核：抗点头条件里的等效臂倾角，$\tan\beta=e/d$ | **基准未定义**（相对水平面还是接地点连线） |

## 本表怎么用

本章术语分六族，下游引用时按族取，别跨族混用：

| 族 | 术语 | 作用 |
|---|---|---|
| A 结构与机构 | g01–g12 | 决定"用哪套方程、哪个侧倾中心求法"的第一分叉 |
| B 分析工具 | g13–g16 | 把任意杆系折算成单摆臂的公共接口 |
| C 纵向姿态 | g17–g21 | $e/d$ 的四个条件式（后蹲／前仰／百分率／点头／提升） |
| D 侧向姿态 | g22–g26 | 侧倾中心三层概念 + 正负摆动臂 + 举升 |
| E 主动悬架 | g27–g29 | 分级与能力边界 |
| F 基础量与译名陷阱 | g30–g32 | 中文译名一错，整章读歪 |

## A. 结构与机构

| id | 术语 | 作者的定义 | 关键约束 / 易错点 |
|---|---|---|---|
| g01 | 整体式车轴（solid axle） | 车轮装在刚性轴两端，一侧的任意移动必然传给另一侧，从而导致转向与外倾角同时变化 | ≠"非独立悬架"的同义词；定义核心是**运动耦合**。覆盖整体式驱动轴与刚性梁前轴，**与驱动形式无关** |
| g02 | 独立悬架 | 允许每个车轮垂向运动而不影响另一侧 | ≠"每轮一个弹簧"；"独立"只指**运动解耦**。⚠️反直觉论断：同样弹簧垂向刚度下独立悬架**侧倾刚度更高**（p193 讲了两遍），不能读成"更硬" |
| g03 | 叶片弹簧承推（Hotchkiss） | 车轴装在半椭圆叶片弹簧上，弹簧兼任推力/扭力杆 | ≠"一种弹簧形式"，是**力传递方案**。软簧片→扭转刚度不足→**必须**加拖曳臂抵抗制动扭矩（刚度条件，不是风格） |
| g04 | 四连杆（整体式车轴） | 下臂管纵向、上臂承受制动/驱动扭矩与侧向力；上臂可合一为三角臂 | ⚠️**本章唯一同名两机构**：§7.1.2 整体轴四连杆（A/B 两点法）vs §7.2.4 每轮四杆（单点连线法）。选错即侧倾中心算错；"数杆子"数不出来，要数受力分工 |
| g05 | 第迪安式（De Dion） | 横轴管 + 装在底盘上的差速器与半轴；车轮保持垂直，非悬挂质量减轻 | 作者归为**介于两者之间**的第三类。处置：侧倾中心按整体式算，非悬挂质量按"去掉差速器"算。代价是滑动轴管/花键摩擦 |
| g06 | 拖曳臂 | ① 实物纵臂 ② 一类独立悬架（平行等长 + 横置扭杆）③ **可以不存在**的等效构件 | ⚠️**一词三义**，本章最大术语陷阱。§7.3 里的"拖曳臂"多为第三义（"过短"指有效臂长 $d$）；"纯拖曳臂"的判据是"相对车身没有外倾变化" |
| g07 | 长短臂式（SLA / A 臂 / 叉形臂） | 上下横臂不等长，外倾补偿改善外侧轮 | 外倾补偿是**内外侧零和**：等长平行臂消除内侧不利，但失去外侧补偿。A 臂/叉形臂/SLA 是同一物的三国叫法 |
| g08 | 麦弗逊撑杆（MacPherson strut） | 与减振器结合的滑柱，下端与车轮刚性连接以保持外倾，上端固定于车身 | ≠"减振器"：撑杆是结构件、承力、带翻转力矩（内侧偏置所致，靠斜置弹簧抵消）。侧倾中心的虚拟点必须取"下臂轴线×撑杆垂线" |
| g09 | 多连杆式（multi-link） | 连杆端部球铰、不承受弯矩；额外连杆产生过多约束但利用衬套柔顺性精确控制前束 | 判据是**球铰**不是杆数。⚠️此处作者自己破了全章刚体假设 → 名义几何≠实车运动，必须写进 B 段 |
| g10 | 拖曳臂式后悬（纵臂式 / Corvette 型） | 纵臂承受纵向力与制动扭矩并控制后蹲与"升起"；半轴兼上横臂 | 功能复用的唯一样本（与多连杆"专杆专用"相反）⚠️"升起"原文**未定义**，引用须标注 |
| g11 | 半拖曳臂（semi-trailing arm） | 铰接轴与横向线约 25°；外倾介于纯拖曳臂与摆动轴之间 | ⚠️"**侧倾**不足转向"＝由侧倾引起的不足转向，**不是**"侧倾时表现为不足转向"（译名陷阱）。不控制则柔顺转向翻成过多转向 |
| g12 | 摆动轴（swing axle） | 外倾变化完全由绕靠近差速器的万向节摆动引起 | ⚠️**全章唯一"虚拟作用点＝真实铰点"**；"摆动半径小"是病根（外倾随行程剧变 + 举升）。侧倾中心高于轮心，是"高侧倾中心"的极端样本 |

## B. 分析工具与几何量

| id | 术语 | 作者的定义 | 关键约束 / 易错点 |
|---|---|---|---|
| g13 | 举升（jacking / tuck under） | 外侧承重轮转向力大 → 向内侧的转弯力有垂向分量 → 两轮"折起" → 车身抬升、抗倾翻阻力下降 + 外倾推力吃转向力 → 急速回转/侧翻 | ≠"车身变高"；是**失稳前兆**。对**任何独立悬架**都关键（摆动轴/半拖曳臂最明显）；防治只有一条：加控制臂限制行程 |
| g14 | 等效拖曳臂 | 所有悬架在功能上都与拖曳臂式等效，可用绕虚拟点摆动的单臂替换，$F_z/F_x=e/d$ | ≠"拖曳臂式悬架"；它**不必存在**。等价判据是力比，不是几何相似。**所有**悬架都适用（不是"没有纵臂就不适用"） |
| g15 | 虚拟作用点 | 任一对控制臂轴线的交点；在该点两臂的拉压力可合成为一个侧向力 | ⚠️刻意**不叫瞬心**（力分解点 vs 运动中心）；**同名用在两个投影面**（侧视分解纵向/垂向力、俯视合并侧向力）；可落在无穷远；摆动轴是例外 |
| g16 | 虚拟铰接点（A 点） | 车身侧视图中的等效铰接点，"虚拟作用点"的另一种命名视角 | 与"虚拟作用点"是**同一个点**；当两个点建自由体图会多画一个铰点、多一个未知力。对 A 点取矩，对错点会让 $F_xe$ 与 $\Delta W_rd$ 的符号一起翻 |

## C. 纵向姿态

| id | 术语 | 作者的定义 | 关键约束 / 易错点 |
|---|---|---|---|
| g17 | 抗后蹲 / 动力后蹲（anti-squat） | $e/d=h/L$ 时后悬架加速中不出现挠度；轨迹＝过接地点、斜率 $h/L$、终点在前轴上方重心高度 | **纯几何，与弹簧刚度无关**。反直觉冲突：想要的"高支点"在侧向会变成过多转向。独立后驱要换成 $(e-r)/d$ |
| g18 | 抗前仰（anti-pitch-up）⚠️待核 | 完整式 $e/d=h/L+(h/L)(K_r/K_f)$；作者近似 $e/d\approx 2h/L$ | ≠抗后蹲的加强版：要求后轴**抬升**去补偿前轴回弹，故严格大于 $h/L$。⚠️$2h/L$ 与例题 1 冲突：真值 **0.301**、近似 **0.378**、偏大 **25.5%**；独立后驱分支（式 7-19）**符号待核** |
| g19 | 悬架抗后蹲百分率 | 达到"理论所需高度"的程度；例：$e/d=0.5h/L$ → 50% | **纯几何比值、不含 K**；不是力/载荷百分比。>100% 与负值原文未定义；"抗前仰百分率""抗点头百分率"书中**没有定义** |
| g20 | 抗点头（anti-dive）⚠️待核 | 前轴：$e_f/d_f=\tan\beta_f=-h/(\xi L)$；后轴抗提升：$e_r/d_r=h/[(1-\xi)L]$；支点在 100% 线下方＝部分抗点头、上方＝前轴提升后轴后蹲 | 只讲**前轴**（后轴那半叫抗提升）；$\xi$ 此处是**制动力占比**。⚠️式(7-28) **负号含义未定义**、$\beta$ 基准未定义 → 本章给不出抗点头数值；作者经验上限"抗点头很少超过 50%"＋8 条理由 |
| g21 | 抗提升（anti-lift）⚠️待核 | ①**加速·前轴**（前驱）：抑制前轴上抬，θ_p/a_x 由 4.2 降到 2.61 deg/g；②**制动·后轴**：与抗点头配对 | ⚠️**一词两义，覆盖两个轴两个工况**。例 2 措辞"省略第二项"数值对但术语不精确（实为几何项抵消前轴弹簧项）。含 $r$ 是因独立悬架有反作用扭矩 |

## D. 侧向姿态

| id | 术语 | 作者的定义 | 关键约束 / 易错点 |
|---|---|---|---|
| g22 | 侧倾中心（roll center） | 通过车轮中心的横向垂直平面上的一点，侧向力作用于该点不引起侧倾；高度由地面量起 | ≠"车身绕它转的圆心"（作者亲口说"并不是一个真正意义上的中心"）。可为**负**（负摆动臂）；随位形移动 |
| g23 | 侧倾轴线（三层） | ①悬架侧倾轴线＝非悬挂相对悬挂旋转的瞬时轴；②侧倾中心＝①与过两轮心垂直平面的交点；③车辆侧倾轴线＝前后侧倾中心的连线、整车相对地面的瞬时轴 | ⚠️①与③参照系不同（相对 vs 绝对）→"斜率"含义不同；混用会把前后轴侧倾力矩分配算反 |
| g24 | 瞬时轴线（"瞬时"作限定词） | 提醒"只有没有侧倾时轴线位置才是确定的" | ⚠️"瞬时"是**位形限定**，不是时间导数；下游不要要求 $\mathrm{d}(\text{roll axis})/\mathrm{d}t$ |
| g25 | 正摆动臂 / 负摆动臂 | 交点在地面之上＝正、之下＝负 | 命名只由交点相对地面的位置决定，**不是好坏评价**；"正"是**静态属性**，一侧倾就衰减（外侧轮虚拟点下移）。谱系：正/负 → 水平平行杆（恰在地平面）→ 倾斜平行杆（抬到地面上） |
| g26 | 动力跳动 / 制动跳跃（power hop / brake hop） | 加速度接近附着极限时，若拖曳臂很短，后轴可能发生动力跳动；制动时同理 | 同病（**有效臂过短**）两工况，书中未声明二者同源；"拖曳臂"指有效臂长 $d$，不是实物杆长 |

## E. 主动悬架

| id | 术语 | 作者的定义 | 关键约束 / 易错点 |
|---|---|---|---|
| g27 | 自调水平悬架（load leveling） | 被动悬架的改进，主要举升元件（通常空气弹簧）随负荷调节；5 s 以上时间间隔修平均位置 | ≠主动；真正保证的是**固有频率恒定**（刚度随载荷变），"高度不变"只是手段。表 7.1：乘适性/高度=高，侧倾/点头/后蹲/接地=**无** |
| g28 | 半主动（慢主动/低频带/高频带） | 特性可由外部控制改变：慢主动＝分级切换 + 延时回退；低频带＝跟 1–3 Hz 连续调；高频带＝同时跟 1–3 Hz 与 10–15 Hz | ⚠️"低频/高频"是**模态归属**不是响应速度；慢主动与低频带的本质差别是**离散 vs 连续**；"自适应（adaptive）"是慢主动的别名，不是第四类 |
| g29 | 全主动悬架 | 含作动器（通常液压缸）提供力，需外部能源；分低带宽/高带宽 | 界：只改**力**不改**运动学**（不能改侧倾中心/外倾曲线，p210）。天花板：≈10 Hz 与被动相近，强行压低会反噬乘适性。价值主张是打破"乘适性 vs 操控性"的折中 |

## F. 基础量与译名陷阱

| id | 术语 | 作者的定义 | 关键约束 / 易错点 |
|---|---|---|---|
| g30 | 悬挂质量 / 非悬挂质量 | 与弹簧一起运动的（车身+载荷）vs 不由弹簧支承的（车轴、车轮、制动器） | ⚠️中文陷阱："悬挂质量"**不是**"悬架本身的质量"，而是"被悬架支承的质量"。读错则"减非悬挂质量"的选型理由（第迪安、Corvette 装车身差速器）全部失效 |
| g31 | 跳动 / 回弹 / 压缩 | ①**jounce**：悬架向上行程（与回弹相对，等价于压缩）；②**hop**：车轮垂向自激振动模态（≈10–15 Hz） | ⚠️书中一词多义且无过渡说明：讲**行程/几何**的是①，讲**振动/频率/附着极限**的是②（p208 写"跳动（压缩）"锁①、p213 写"跳动（hop）"锁②） |
| g32 | 侧倾转向 / 侧向力柔顺转向 | 侧倾引起的车轮转向角（前束）变化 / 侧向力经衬套杆系柔度引起的转向角变化 | ⚠️作者反复使用却**从未定义**、无符号无公式；本章只能给方向与选型提示（半拖曳臂→后轴侧倾不足转向；四连杆轴线斜度变化大→侧倾转向变化大），**不得据此推导定量式** |

## 易混术语对照（引用前先过这张表）

| 容易混的一对 | 区别（一句话） | 后果 |
|---|---|---|
| 抗后蹲 vs 抗前仰 | 前者只要后轴不压缩（$e/d=h/L$）；后者要后轴**抬升**（多一个刚度比项） | 后者数值更大（0.189 vs 0.301）；混用会低估 |
| 抗后蹲 vs 抗后蹲百分率 | 条件式 vs $(e/d)/(h/L)$ 的比值 | 百分率不含弹簧刚度 |
| 抗点头（前轴）vs 抗提升（后轴） | 同一制动工况的两端；"抗提升"另有一义指加速时的前轴 | 前后轴会算成同一式子 |
| 悬架侧倾轴线 vs 车辆侧倾轴线 | "非悬挂相对悬挂"的轴 vs 前后侧倾中心的连线（整车相对地面） | 参照系不同，斜率含义不同 |
| 侧倾中心 vs 侧倾轴线 vs 瞬时轴线 | 点 / 悬架的轴 / "仅零侧倾位形有效"的限定词 | "瞬时"不是时间导数 |
| 虚拟作用点 vs 虚拟铰接点 | 侧视图里同一点的两个命名视角；俯视图只叫虚拟作用点 | 当两个点会多一个未知力 |
| 虚拟作用点 vs 瞬时中心 | 作者刻意不用"瞬心"：要力分解点，不是运动中心 | 用瞬心语言会导出"运动中心存在"的错误前提 |
| 等效拖曳臂 vs 拖曳臂 | 假想分析构件（可不存在）vs 实物/结构类 | §7.3 里的"拖曳臂"多为前者 |
| 摆动轴 vs 正/负摆动臂 | 结构类 vs 独立悬架的几何分类 | 名词撞车，范畴不同 |
| 举升（jacking）vs 高度控制 | 危险失稳 vs 主动悬架的一项舒适/气动功能 | 一个是病，一个是功能 |
| 自调水平 vs 主动 | 5 s 时间常数只修平均位置 | "空气悬架≠主动悬架" |
| 低频带 vs 高频带 | 不是速度，是"车身模态 1–3 Hz vs 车轴模态 10–15 Hz" | 按字面读会整级误判 |
| 动力跳动 vs 制动跳跃 | 同病（有效臂过短）两工况 | 书中未声明二者同源 |
