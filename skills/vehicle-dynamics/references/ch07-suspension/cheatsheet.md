# 决策规则速查 — 《车辆动力学基础》第 7 章 悬架

| 能力 | 一句话规则 |
|---|---|
| 悬架结构选型：先定两族，再按「存在理由 ↔ 代价」逐条核对 | 先判「两侧车轮是否允许互相影响」定族，再按原文为该结构写下的存在理由匹配约束、按代价逐条核对，输出结构 + 代价清单（不打分）。 |
| 主动悬架分级选型：按性能模式查能力矩阵，取最低够用等级 | 需求落到六模式 → 查 4×6 能力矩阵取最低够用等级 → 逐格给能/不能 → 用 1–3 Hz / 10–15 Hz 带宽回检。 |
| 虚拟作用点法：把任意杆系折算成绕一点摆动的单摆臂 | 判本次分析纵向还是侧向 → 只留承受该方向力的那一对杆件 → 取轴线交点 → 无穷远退化另案处理。 |
| 平行杆的无穷远极限法：交点在无穷远时方向由杆件斜率决定 | 一旦判平行就把连线方向取成杆件方向，侧倾轴=过另一有限点平行于该杆，再与车轮垂直中心线求交。 |
| 满额几何补偿的否决检查：把 e/d 调到 100% 之前先过 8 条 | 拟做满额前逐条核对 8 条后果，命中且无替代手段（加长有效臂 / 主动控制）就降额，作者经验上限是抗点头不超 50%。 |
| 举升（jacking）风险判定：条件齐发才成立，防治只有一条 | 结构命中（摆动轴/半拖曳臂或其他独立悬架）+ 外侧承重轮承担更多转向力 + 无行程限位 → 高风险，处置只有加控制臂限制行程。 |
| 等效拖曳臂归一化：纵向力比只由几何决定 F_z/F_x=e/d | 把悬架换成绕虚拟点摆动的单臂、对该点取矩，得 F_z/F_x=e/d；e 从接地点量起、d 是有效水平臂长。 |
| 100% 抗后蹲判据：e/d=h/L，与弹簧刚度无关（独立后驱用 (e−r)/d） | 算 h/L，令 e/d=h/L 即后轴零压缩；独立后驱（差速器在车身）必须换成 (e−r)/d=h/L。 |
| 抗后蹲百分率：(e/d)÷(h/L)，一个不含弹簧刚度的几何比例 | 百分率=(e/d)/(h/L)×100，纯几何、不含 K；0–100% 有定义，>100% 与负值原文未定义，只报越界不解释。 |
| 完全抗前仰：e/d=h/L+(h/L)(K_r/K_f)，2h/L 只作速算 | 用精确式 e/d=h/L+(h/L)(K_r/K_f)（K 为左右之和）；只有刚度比与 1 的偏差 ≤10% 才允许用 2h/L 速算且必须同时写精确值。 |
| 前驱动整体式轴：零前仰条件 e/d=−h/L−(h/L)(K_f/K_r)，支点落在前轴后方 | 前驱整体轴取负号、刚度比用 K_f/K_r；第一项 −h/L 单独就是 100% 抗提升，负号含义是支点在前轴后方而非地面之下。 |
| h/L≈0.2 速算：完全抗后蹲约需 5 倍 e 的有效拖曳臂长度 | d≈e/(h/L)；轿车 h/L≈0.2 时 d≈5e；反用可判欠补偿/过补偿，但比值达标不等于绝对臂长够。 |
| 俯仰角变化率 θ_p/a_x：三项结构与 rad/(in/s²)→rad/g→deg/g 单位链 | θ_p=(1/L)(W/g)a_x[(1/K_r)(h/L)−(1/K_r)(e/d)+(1/K_f)(h/L)]，×386→rad/g，×57.2958→deg/g。 |
| 整体式车轴侧倾中心：三步作图，四种结构只换「谁承受侧向力」 | 平面图定 A、B（只留承受侧向力的杆系）→ 侧视图连成侧倾轴线 → 与车轮垂直中心线求交，由地面量高。 |
| 独立悬架侧倾中心：单侧虚拟点→接地点连线→与中心线求交，外加正/负摆动臂命名 | 取单侧虚拟点 A（麦弗逊取「下臂轴线×撑杆垂线」）→ 连接地点与 A → 与车辆中心线交点即侧倾中心，地上为正摆动臂、地下为负摆动臂。 |
| 主动悬架六种性能模式与各自的传感信号 | 六模式取信号：乘适性=车体加速度；高度=载荷/气动；侧倾=车速+转向角+转向速率/侧向加速度；点头=制动灯+制动压力/纵向加速度；后蹲=节气门+挡位/纵向加速度；接地性=车轮动态载荷。 |
| 例题 1 的三个数值锚点：0.189 / 0.301 / 1.43 deg/g 的回归自检 | 用 h=20.5、L=108.5、W=4074、K_f=285、K_r=169（左右之和）复算 0.189/0.301/1.43，三者命中即口径正确。 |
| 例题 2 的两个锚点：4.2 / 2.61 deg/g，比值 1.606 是自检式 | 无抗提升 0.0455+0.0276 rad/g=4.2 deg/g，完全抗提升只剩 0.0455=2.61 deg/g，比值 1.606 必须等于 1+K_r/K_f。 |
