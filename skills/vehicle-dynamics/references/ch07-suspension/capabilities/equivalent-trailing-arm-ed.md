# 等效拖曳臂归一化：任何悬架的纵向力比只由几何决定 $F_z/F_x=e/d$

## R — 原文 (Reading)

> **原书要点**（p197–198 §7.3.1，式7-9）：要弄清一辆车在外力与外扭矩作用下如何响应，最省事的做法是把任何一种悬架都当作拖曳臂来对待——在功能层面，二者并无分别。
>
> **原书要点**（p197–198 §7.3.1，式7-9）：若改用一个单臂顶替原控制臂，并让它的摆动轴穿过控制臂轴线在车身上的投影交点，式（7-9）的形式依旧成立。这个交点即所谓虚拟作用点：把作用于控制臂的扭矩挪到该点上，就能拆成车身受到的等效纵向力与铅垂向力。
>
> — 7.3.1（p197–p198），式(7-9)

## I — 方法论骨架 (Interpretation)

一句话：**把悬架换成一条绕虚拟点 A 摆动的假想单臂，对 A 取矩消掉所有杆件内力，垂向反力与纵向力之比就等于两个几何力臂之比。**

- $e$ 是 A 点相对**车轮接地点**的垂向高度，$d$ 是水平力臂（有效拖曳臂长度）；式(7-9)：$F_z/F_x=e/d$。
- 它的威力在于**统一**：四连杆、SLA、麦弗逊、摆动轴全部套同一组式子，因此"抗后蹲条件对所有结构是同一个式子"。不归一化，每换一种结构就重推一遍自由体。
- 归一化的代价是三条假设：小角度（$\tan\theta\approx\theta$）、忽略静态垂向载荷、刚体二维侧视图。三条都写在原文，不是本卡添加。
- 输出必须声明取值约定：$e$ 从接地点量起（地面之上为正）、$d$ 是水平臂长且**方向按图 7.11 的取法**——原文从未单列 $d$ 的正方向，这是本章一个已知的表述缺口。
- 这条比值是后续全部纵向判据的母式：抗后蹲、抗前仰、抗点头、动力跳动都从它派生。

## A1 — 应用示例 (Application Example)

### 示例 1：一组给定几何的复算（合成演练，非书中事实）

- **类型与来源**：**合成演练**。原书式(7-2)–(7-9) 是推导，**没有给数值算例**（结果栏：未说明）；下面这组输入由本卡设定，只用于检验流程。
- **输入**：上下控制臂铰点高度 $z_1=8$ in、$z_2=5$ in，水平臂长 $d=20$ in，虚拟点垂向力臂 $e=12$ in。
- **方法论的使用**：①由几何得 $\tan\theta_1=(z_2+z_1-e)/d=(5+8-12)/20=0.05$、$\tan\theta_2=(e-z_2)/d=(12-5)/20=0.35$；②代入式(7-7)：$F_z/F_x=(z_2/z_1)\tan\theta_1+(1+z_2/z_1)\tan\theta_2=0.625\times0.05+1.625\times0.35$；③与式(7-9) 对照。
- **结论/预期输出**：$0.03125+0.56875=\mathbf{0.6000}=e/d$ ✓（与直接取 $12/20$ 一致）。可另做代数核验：把式(7-8) 代入式(7-7) 化简后分子为 $z_1e$、分母为 $z_1d$，即 $e/d$——两条路径必须给出同一个数，这是本卡的自检式。

### 示例 2：把等效臂读成实物杆的反例（原书对照，非算例）

- **类型与来源**：**原书对照**（p191、p193、p197–p198）。作者在 §7.3 直接用"拖曳臂"指等效构件，而 §7.1–§7.2 里同一个词指实物纵臂或一类独立悬架。
- **用法**：如果一台 SLA 悬架"没有纵臂"，等效拖曳臂**依然存在**（它由几何定义，不由零件定义）。
- **结论**：判据是"能否给出同样的 $F_z/F_x$"，不是"图上有没有那根杆"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 手上有一张悬挂侧视图，要算"纵向力会转化出多少垂向力"。
2. 要算抗后蹲/抗前仰，但结构不是拖曳臂式，怀疑公式能不能用。
3. 想从图纸直接读出等效臂长 $d$ 与力臂 $e$，供后面所有纵向判据使用。
4. 需要向别人解释"为什么不同结构可以用同一个抗后蹲条件"。
5. 怀疑某结构的 $e$、$d$ 取法与我们用的不一样（符号/基准不同）。

### 语言信号（中英双写）

- 「纵向力和垂向力的比怎么算」「等效拖曳臂是什么」「这车没有纵臂还能用 e/d 吗」
- 「equivalent trailing arm」「Fz/Fx = e/d」「instantaneous center side view」「anti-squat geometry from hardpoints」
- 「e 和 d 从哪里量」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `virtual-point-method`：那张卡只负责"点在哪"；本卡负责"用这个点算力比"。
- 与 `anti-squat-100` / `anti-pitch-up-precision`：那两张卡把 $e/d$ 与 $h/L$（及刚度比）比较，得具体目标；本卡只给比值本身。
- 与 `roll-center-solid-axle` / `roll-center-independent`：那是把同一套虚拟点法用在**侧向**上；本卡是**纵向**分支。

## E — 可执行步骤 (Execution)

**必需输入**：侧视图硬点坐标（至少给出虚拟点 A 的水平与垂向位置、接地点位置、车轮中心位置）、受力方向（驱动/制动）、单位制。**缺硬点坐标时停止**——本卡不接受"典型值"。

**交付物与完成标准**：$e$、$d$（带单位与正负约定）、$F_z/F_x$ 数值（保留 3 位小数）、所用假设与图号对应关系、口径声明。

1. **建立自由体**
   - 完成标准：画出（或文字描述）控制臂内力 $P_1$、$P_2$、$F_x$、$F_z$、静态载荷与其作用线；标注"忽略静态垂向载荷、小角度"。
2. **取虚拟点并取矩**
   - 完成标准：写明 A 点的坐标来源（哪一对臂的交点、哪个投影面）；对 A 点写力矩平衡，消去 $P_1$、$P_2$。
   - 判停条件：若某对臂平行 → 转 `parallel-arm-infinite-point`，本卡的取矩形式不适用。
3. **算比值**
   - 完成标准：给出 $F_z/F_x=e/d$，并同时给出 $e$、$d$ 各自的量与正负；数值可由两法（式 7-7 展开 / 直接 $e/d$）互验。
4. **口径检查（必做）**
   - 完成标准：逐条确认——$e$ 从**接地点**量起、$d$ 是**水平**臂长、角度按图上同一取法、单位一致（全章英制）。
5. **交付**
   - 完成标准：一句话"该悬架在纵向等效为 $e/d=\dots$ 的单臂"，并声明"$e$、$d$ 的正负号约定原文未单列，改结构须按图 7.11 重画"。

**计算约定（原书未规定，本卡设定）**：比值保留 3 位小数；$e$、$d$ 用 in；若用户给 SI，先换算再算并注明换算。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **把等效拖曳臂当实物杆件去找。** 它可以不存在；判据是"给出同样的 $F_z/F_x$"，不是几何相似。反过来，"没有纵臂"不等于"不适用"。
- **在 $d$ 很小的几何上只报比值。** 比值对了不等于能用：$d$ 过短会在接近附着极限时引发动力跳动/制动跳跃（见 `five-e-quick-rule` 的 B 段）。
- **用衬套柔度显著的多连杆做刚体结论。** 作者自己写道多连杆"利用衬套的柔顺性"解过约束；此时名义 $e/d$ 只是名义值。
- **把侧视图结论搬到俯视图。** 本卡的点在侧视图（分解纵向/垂向力）；侧向力用的是俯视图上的另一个点。
- **不做正负号声明就跨结构比较。** 原文未单列 $e$、$d$ 的正方向，只有式(7-21) 的负号旁证"支点位于前轴后方"；改结构必须按图 7.11 同一取法重画。

### 作者在书中警告的失败模式

- ce21：把整体式车轴的 $e/d$ 直接套到独立后驱上，漏掉反作用扭矩项 → 力臂应是 $(e-r)$，按 $e$ 定支点会系统性偏低约一个车轮半径。
- ce08：只约束比值、不约束绝对尺寸 → 有效臂太短，纵向力被几何放大成周期性垂向力。
- ce15：平行臂退化时把无穷远当有限点 → 力比算错（属平行杆分支的失败模式）。

### 作者的盲点 / 时代局限

- 小角度、忽略静态垂向载荷、刚体二维；未讨论大行程（悬架跳动改变 $e$、$d$）下的非线性。
- 未给 $e$、$d$ 的文字定义与正负号约定（原文只有图 7.11 标注）——这是本章的表述缺口，不是本卡可以补造的。
- 未讨论轮胎垂向柔度、衬套柔度对力传递路径的分流。

### 容易混淆的邻近方法论

- **等效拖曳臂 vs 拖曳臂**：前者是分析构件（可不存在），后者在本章还有"实物纵臂""一类独立悬架"两义。
- **虚拟作用点 vs 虚拟铰接点**：侧视图里同一点的两个命名；当两个点建自由体图会多一个未知力。
- **$e/d$ vs $h/L$**：$e/d$ 是**几何能提供多少**，$h/L$ 是**载荷转移要求多少**；抗后蹲把它们相等，抗前仰则还要加一个刚度比项。
