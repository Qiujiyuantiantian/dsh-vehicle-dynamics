# 主动悬架分级选型：按"要哪个性能模式"查能力矩阵，取最低够用等级

## R — 原文 (Reading)

> **原书要点**（p211）：书中按悬架里各部件“主动”程度的高低排序，性能由低到高依次是：被动悬架，然后是自调水平悬架，接着是半主动悬架，最高一档为全主动悬架。
>
> **原书要点**（p211）：这类悬架每隔约 5 s（或更长）做一次判断；一旦发现悬架的平均高度偏离了正常行驶高度，就改变弹簧内部的气压，从而让悬架的固有频率维持不变。
>
> — 7.7.1（p211）

## I — 方法论骨架 (Interpretation)

一句话：**把需求落到"六种性能模式"上，到能力矩阵里查能满足的最低等级；等级够用就不要再往上买。**

- 六级阶梯＝被动 → 自调水平 → 半主动（慢主动 / 低频带 / 高频带）→ 全主动。分级依据是"含多少'主动'品质"，**不是"有没有电子控制"**。
- 矩阵是 4 行 × 6 列（乘适性 / 高度 / 侧倾 / 点头 / 后蹲 / 接地性）。关键几格：自调水平只有"乘适性=高、高度=高，其余全无"；半主动是"乘适性中、侧倾/点头/后蹲低、接地性中、高度无"；主动六项全高；被动整行只写"折中"。
- 所以"空气悬架 = 主动悬架 = 能控侧倾"这个常见链条**在第一格就断了**：自调水平那行的侧倾/点头/后蹲写的是"无"。
- 第二条约束是带宽：车身模态 1–3 Hz、车轴模态 10–15 Hz。"低频带/高频带"是**模态归属**不是响应速度；高频带买到的是车轮载荷稳定（操控/接地性），不是乘适性。
- 最后一条界（必须一起给）：主动组件改变的是**力**，不是**运动学**——它不能改侧倾中心、不能改外倾曲线，也不能替代几何设计。

## A1 — 应用示例 (Application Example)

### 示例 1：原书"性能潜力"表（原书表格，非例题）

- **类型与来源**：**原书表格**（表 7.1，p213）。不是算例，没有阈值、没有试验方法。
- **内容**：被动 = "性能为各种模式之间的折中"；自调水平 = 高/高/无/无/无/无；半主动 = 中等/无/低/低/低/中等；主动 = 六项全高。
- **用法与结论**：这张表只能回答"**最低够用等级是哪一级**"和"这一级不能做什么"，不能回答"这级比那级好多少"。

### 示例 2：两个需求的等级判定（合成演练，非书中事实）

- **类型与来源**：**合成演练**。原书未提供这两个需求的判定；结论由本卡按表 7.1 逐格读出，只用于检验流程。
- **输入 A**："只需保持行驶高度，成本敏感"。**执行**：查表 → 自调水平"高度控制=高"，其余五项"无"。**结论**：够用即止，不必上半主动（半主动的高度控制反而是"无"）。
- **输入 B**："乘适性与接地性都要求高"。**执行**：查表 → 半主动这两项只到"中等"；主动两格都"高"。**结论**：按表只能上全主动，否则回需求端砍指标——**不存在"半主动够用"的读法**。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 面对"空气悬架/电磁悬架/CDC/主动防倾杆"的宣传，想知道"这算哪一级、能做什么"。
2. 明确要求"抑制侧倾"或"抑制点头"，判断被动几何做不到时该上哪一级。
3. 采购/配置评审：被问"要不要加钱上更高一级"，需要给出"够/不够"的依据。
4. 读"主动悬架六项全高"就以为它在所有工况都更好，需要纠正到频段与代价。
5. 想把主动系统当"几何设计的替代方案"，需要先确认边界（只改力不改运动学）。

### 语言信号（中英双写）

- 「空气悬架算不算主动悬架」「半主动够不够」「CDC/电磁悬架能控侧倾吗」「主动悬架能不能替代调校」
- 「active vs semi-active vs adaptive suspension」「load-leveling vs active」「can active suspension fix body roll」
- 「花这个钱值不值」「哪一级够用」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `active-mode-signals`：本卡决定"哪一级"，那张卡决定"这一级用什么信号、切什么模式"。
- 与 `structure-family-selection`：本卡是纵向的等级阶梯，那张卡是横向的结构族。
- 与 `full-compensation-veto`：那张卡的替代手段之一是"主动点头/后蹲控制减轻几何要求"（p212），本卡给的是这条替代的成本与等级。

## E — 可执行步骤 (Execution)

**必需输入**：需求清单（乘适性 / 高度 / 侧倾 / 点头 / 后蹲 / 接地性，各自"高/中/低/不重要"）、预算约束、是否已有空气弹簧、目标工况（1–3 Hz 车身模态还是 10–15 Hz 车轮模态）。**缺"需求优先级"时先问**——矩阵只能按已声明需求查，不能替用户排优先级。

**交付物与完成标准**：等级名称 + 逐格"能/不能"清单 + 缺口（哪项需求这一级做不到）+ 带宽回检结论 + 一句"不能做什么"。

1. **需求落表**
   - 完成标准：六项模式各写一个等级要求；无法量化的写"定性：高/中/低"并声明这是定性。
2. **查最低够用等级**
   - 完成标准：从被动往上一级一级查，**第一个全满足的等级即为答案**；同时列出该级"无/低"的格子。
   - 判停条件：若需求集中在 10–15 Hz 车轮模态（碎石路、搓板路乘适性）→ 跳到步骤 5，先讲天花板，不要继续升级。
3. **带宽回检**
   - 完成标准：写出需求对应的频段（1–3 Hz / 10–15 Hz）；若选高频带而采购理由是"乘适性"，判为**买错东西**并纠正。
4. **边界声明（必做）**
   - 完成标准：写明"主动只改力、不改运动学"——不能改侧倾中心、不能改外倾曲线、不能替代抗后蹲/抗点头几何；并写明表内"高"是相对被动悬架的**潜力**，不是无代价。
5. **天花板提示**
   - 完成标准：给出 ≈10 Hz 结论——该区间主/被动相近，且强行压低车轮运动的反力会反作用到车身使乘适性变差（p213）。

**计算约定（原书未规定，本卡设定）**：等级只取"最低够用"，不设"性能分"；若用户要求跨等级比较，只能比较"能/不能"的格子数，不得换算成百分制。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **把"主动"当"所有工况都更好"的万能解。** ≈10 Hz 处主动与被动"性能相近"，且压低车轮运动的控制力会反作用于车身、**使乘适性变差**（p213）。
- **把自调水平当主动。** 5 s 时间常数只修平均位置；表内侧倾/点头/后蹲三格是"无"。
- **承诺"主动悬架可以任意设定姿态"或"改侧倾中心"。** 原文界线：只改垂直方向受力，不改悬架运动情况（p210）。
- **用本章表格做定量对标。** 表是"高/中/低/无"四级定性，无阈值、无试验方法、无带宽↔作动器功率对应、无失效模式与能耗。
- **为乘适性买高频带。** 高频带买到的主要是车轮载荷稳定（操控/接地性），"对改善乘适性作用较小"（p213）。

### 作者在书中警告的失败模式

- p25（本章最重的一条边界）：需求集中在 ≈10 Hz 车轮跳动 → 主动无优势，且强行压低会反噬乘适性；不要把"带宽更高"当采购理由。
- ce19：按"带宽越高=性能越好"选半主动，为乘适性买高频带 → 成本上升而主观乘适性无变化。
- ce20：读"主动一行全高"就以为每个频段都能改善 → 实际在 10 Hz 附近是以乘适性换操控性。
- p212 的两条限制：主动"完全消除转向侧倾是可行的"（未给代价），"侧倾力矩可以有选择地施加于前轴或后轴"（→ 会改变载荷转移分配，接第 6 章 K）。

### 作者的盲点 / 时代局限

- 1992 年：只讨论到液压作动器 + 带宽，无电控空气悬架、磁流变、48V 主动防倾杆。
- 未讨论模式间的冲突与优先级、未给作动器功率/带宽数值、未讨论失效模式（fail-safe）与能耗。
- 频域结论引自 Chalasani 的整车模型（文献[12]），对货车/赛车是否成立未说明。
- "为操控牺牲乘适性是允许的取舍"是原文的设计取向（p213），不是普适结论。

### 容易混淆的邻近方法论

- **"主动/半主动"vs"自调水平"**：前者改变特性（阻尼/刚度），后者只改变平均位置；空气弹簧属于后者。
- **"低频带/高频带"**：是模态归属（车身 1–3 Hz / 车轴 10–15 Hz），不是控制器的响应速度；按速度读，整级分类就废了。
- **"慢主动 = 自适应"**：同一物的两个名字（离散切换 + 延时回退），不是第四类。
- **主动悬架 vs 悬架几何**：几何决定力**作用点**（侧倾中心、e/d），主动决定**力的大小**；两者不可互换。
