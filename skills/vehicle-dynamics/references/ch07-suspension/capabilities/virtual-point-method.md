# 虚拟作用点法：把任意一套杆系折算成"绕一点摆动"的单摆臂

## R — 原文 (Reading)

> **原书要点**（p205）：这套做法与连杆运动学中的“瞬心”异曲同工，只是书中特意没有沿用那个名称——瞬心是运动学意义上的转动极点，车身上找不到这么一处实实在在的铰点。求法本身很直接：任取一对控制臂，把各自轴线延长，两条线的交点即虚拟作用点。
>
> — 7.6.1（p205）；侧视图用法见 7.3.1（p198）

## I — 方法论骨架 (Interpretation)

一句话：**先问"这次分析的是纵向力还是侧向力"，再只留下真正承受该方向力的那一对杆件，取它们轴线的交点，用这个点替换整套路杆系。**

- 它是全章唯一的公共接口：**同一套动作**用在侧视图上得到纵向力与垂向力之比（$F_z/F_x=e/d$，抗后蹲/抗前仰），用在俯视图上得到侧倾中心。不建立这个点，两种分析都得按结构各推一遍。
- 三条容易漏的规则：
  1. **按受力方向筛杆件**。三连杆后悬里上控制臂只承回转扭矩、不承侧向力，分析侧向力时必须剔除（p206）；不筛就会多一个未知力。
  2. **名字刻意不叫"瞬心"**。作者要的是"力的分解点"，不是运动中心——这个区分决定了它能在实车上"不存在"却仍然有用。
  3. **可以落在无穷远**。平行臂、叶片弹簧都会让交点在无穷远，此时构型退化为"一个点 + 一个方向"，要转 `parallel-arm-infinite-point` 处理。
- 输出必须带**投影面与受力方向**两个标签：同一个名字在侧视图和俯视图里指的是不同的点、不同的坐标。

## A1 — 应用示例 (Application Example)

### 示例 1：三连杆后悬架的两个作用点（合成演练，非书中事实）

- **类型与来源**：**合成演练**。原书给的是方法陈述（p206），没有这道题；结论按原文的剔除规则执行，用于检验流程。
- **输入/问题**：三连杆后悬架（一根横向拉杆 + 两根下控制臂 + 两根上控制臂），求其承受**侧向力**时的作用点。
- **方法论的使用**：①判方向＝侧向；②筛杆件——横向拉杆直接承受侧向力、两下臂合成侧向力，上控制臂只受回转扭矩 → 剔除；③取交点——A＝横向拉杆与车辆中心线的交点，B＝两下控制臂的虚拟作用点。
- **结论/预期输出**：A、B 两个点；上控制臂**不参与**；A、B 连线即悬架侧倾轴线。若把上臂算进去，会得到第三个点并破坏力平衡。

### 示例 2：四连杆后悬架 A/B 的取法（原书代入，非数值题）

- **类型与来源**：**原书方法代入**（p205–p206）。原书以四连杆为例写明 A、B 取法，但没有给出数值算例。
- **内容**：顶视图中侧向力以拉/压形式作用于控制臂；两条**长**控制臂的虚拟作用点在轴前 B 点，两条**短**控制臂的虚拟作用点在轴后 A 点；每对臂绕各自的虚拟点旋转，这些点构成悬架侧倾轴线。
- **结论**：A、B 需按控制臂长度反比分配侧向力（A 处力大、B 处力小），这是后续求侧倾中心时"两个力合成"的前提；**未说明**该结构的实际高度（需图纸）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 手上一套杆系图，问"它的虚拟作用点/等效作用点在哪"。
2. 计算侧倾中心或抗后蹲前，先要确定"用哪两根杆的交点"。
3. 多连杆/三连杆分析时纠结"某根杆要不要算进去"（承不承该方向力）。
4. 遇到平行杆、叶片弹簧，"交点不存在/在无穷远"时该怎么办。
5. 想知道"虚拟作用点"和"瞬心"到底是不是一回事。

### 语言信号（中英双写）

- 「这套杆系的虚拟作用点在哪」「三连杆的上臂要不要算」「平行下臂的交点在哪」「虚拟作用点和瞬心一样吗」
- 「virtual point / instantaneous center of the linkage」「which links carry lateral force」「force decomposition point」
- 「等效成一根摆臂怎么画」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `parallel-arm-infinite-point`：本卡处理有限交点；交点跑到无穷远时由那张卡接手（方向由杆件斜率决定）。
- 与 `equivalent-trailing-arm-ed`：本卡只给"点在哪"，那张卡用这个点算 $e/d$（纵向）。
- 与 `roll-center-solid-axle` / `roll-center-independent`：本卡是它们的第一步；那两张卡负责作图与求交得到高度。
- 与第 6 章的瞬心类概念：本章刻意**不用**"瞬心"这个词，用瞬心语言会导出"运动中心存在"的错误前提。

## E — 可执行步骤 (Execution)

**必需输入**：杆系布置图（正视图 + 平面图 + 侧视图，至少三视图中的两张）、本次分析的受力方向（纵向/侧向）、各杆的类别（控制臂/拉杆/撑杆/半轴兼横臂）。**缺图纸或受力方向时停止**——虚拟作用点不能凭口述"大概位置"确定。

**交付物与完成标准**：点名（A/B 或"上/下臂交点"）+ 所属投影面 + 受力方向 + 被剔除杆件及理由 + 是否为退化情形（无穷远/例外）。

1. **定方向**
   - 完成标准：一句话写清"本次分析纵向力还是侧向力"，并据此选投影面（纵向→侧视图；侧向→俯视图）。
2. **筛杆件**
   - 完成标准：逐根杆写"承受/不承受该方向力"；被剔除的必须给理由（如"只承回转扭矩"）。剔除后剩余杆件应恰好给出两个交点（或一个点 + 一个无穷远方向）。
3. **取交点**
   - 完成标准：写出每对臂的交点；交点可在轴前或轴后，位置用坐标或相对轴心的距离表示。
   - 判停条件：若某对臂平行 → 交点在无穷远，转 `parallel-arm-infinite-point`，**不得写"无解"或强行取有限值**。
4. **命名与投影面声明**
   - 完成标准：同一名字若在另一个投影面出现，明确写"这是另一个点"；摆动轴是唯一例外（虚拟点＝真实铰点，p210）。
5. **交付**
   - 完成标准：给出点 + 后续用途（"用于求侧倾轴线"或"用于对 A 点取矩"），并声明刚体假设与"该点不是真实运动中心"。

**计算约定（原书未规定，本卡设定）**：坐标统一取"轴心/接地点"为原点并在输出中声明；不引入书中未出现的位移导数。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **把虚拟作用点当真实瞬心去求导/求运动。** 作者明确："这个运动中心并不存在"（p205）；把侧倾中心当几何圆心会推出"绕该点的圆弧运动"这类错误结论。
- **对无法定义虚拟点的杆系硬套。** 纯叶片弹簧在侧视图中两侧都退化到无穷远，原文只为**侧倾中心**给了无穷远处理，没有给"抗后蹲虚拟点"的作图细则。
- **在含衬套柔度的多连杆上宣称"名义几何＝实车运动"。** 作者自己写道：额外的连杆对车轮产生过多约束，"但利用衬套的柔顺性"使前束角控制更精确（p195）——刚体假设在这里是破了口的。
- **把同一名字用于两个投影面却不标注。** 侧视图的虚拟作用点分解纵向/垂向力，俯视图的合并侧向力——坐标与物理含义都不同。
- **在侧倾姿态下发结论。** 虚拟点只在**无侧倾（零位形）**下确定；侧倾后外侧轮虚拟点下移、内侧上移，两轮中心不再重合（p208）。

### 作者在书中警告的失败模式

- ce07：连杆堆到过约束，按刚体标注硬点，实际运动由衬套决定 → 图纸曲线不再是整车运动学。
- ce13：把静态虚拟点算出的侧倾中心当固定值去预测侧倾中的载荷转移（有效侧倾中心低于静态值，偏差随侧向加速度增大）。
- ce15：平行下臂四连杆里盯着上臂（它决定 A 点），忘了 B 点在无穷远、整条侧倾轴线由下臂斜率决定。
- 三连杆的剔除规则本身是"反面教材点"：不剔除上臂会多算一个不存在的力。

### 作者的盲点 / 时代局限

- 全章刚体、二维、静态/稳态假设；虚拟点的作图依赖手绘三视图，现代 K&C 台架会直接给出实测值，两者可能明显不一致。
- 书中未给多连杆（球铰 + 衬套）的柔度修正方法。
- 摆动轴是"虚拟点＝真实铰点"的例外，作者特意点出，但未系统列出所有例外结构。

### 容易混淆的邻近方法论

- **虚拟作用点 vs 虚拟铰接点**：侧视图里同一点的两个命名视角（力的分解 / 机构铰接）；当两个点建自由体图会多一个铰点、多一个未知力。
- **虚拟作用点 vs 瞬时中心**：作者刻意不用后者的名字。
- **等效拖曳臂 vs 拖曳臂**：前者是可不存在、绕虚拟点摆动的分析构件；后者在本章还有"实物纵臂""一类独立悬架"两个含义。
