# 俯仰角变化率 $\theta_p/a_x$：挠度差／轴距，走 rad/(in/s²)→rad/g→deg/g 三层单位

## R — 原文 (Reading)

> **原书要点**（p199）：加速工况下，车身的俯仰角 $\theta_p$ 由前后悬架挠度之和算出，再除以轴距即可。
>
> 例题 1 解答行：$=0.000\,064\,5\ \text{rad}/(\text{in/s}^2)=0.0249\ \text{rad/g}=1.43\ \text{deg/g}$
>
> — 7.3.2 式(7-13)(7-14)（p199）；例题 1（p203）

## I — 方法论骨架 (Interpretation)

一句话：**把前、后悬架的挠度写成"载荷变化÷弹簧刚度"，两者之差除以轴距即俯仰角；单位一路从 rad/(in/s²) 换成 rad/g 再换成 deg/g。**

- 结构上只有三项：后轴弹簧项 $\frac{1}{K_r}\frac{h}{L}$、后轴几何项 $-\frac{1}{K_r}\frac{e}{d}$、前轴弹簧项 $\frac{1}{K_f}\frac{h}{L}$（式 7-14）。几何项带负号，因为它把后轴载荷"扛"掉一部分。
- 当 $e/d=h/L$ 时，后轴两项**严格相消**，只剩前轴项——例题 1 的 1.43 deg/g 就是这么来的。这不是巧合，而是"100% 抗后蹲"的必然结果。
- 单位链是本章最易错的地方：$a_x$ 在英制里以 in/s² 计，$g=386$ in/s²（**不是 32.2**）；rad→deg 用 57.2958。三步缺一，结果差 386 倍或 57 倍。
- 三个锚点值构成回归集：例题 1 的 **1.43**、例题 2 的 **4.2**（无抗提升）与 **2.61**（完全抗提升）。它们属于**两辆不同的车**，不可混用。
- 输出必须声明结构分支：后驱整体轴（式 7-14）、前驱整体轴（式 7-20）；独立后驱（式 7-18）在本章**不可恢复**，四驱（式 7-26/27）**符号不闭合**。

## A1 — 应用示例 (Application Example)

### 示例 1：例题 1 的俯仰角变化率（原书例题）

- **类型与来源**：**原书例题**（例题 1，p203）。题面给全参数并要求"当后悬架设定为完全抗后蹲几何参数时的前仰角变化率"。
- **输入**：$W=4074$ lb、$h=20.5$ in、$L=108.5$ in、$K_r=169$ lb/in、$K_f=285$ lb/in（左右之和）、$e/d=0.189$。
- **方法论的使用**：①$\frac{1}{L}\frac{W}{g}=\frac{1}{108.5}\times\frac{4074}{386}=0.097276$；②括号 $=\frac{0.18894}{169}-\frac{0.189}{169}+\frac{0.18894}{285}=6.6295\times10^{-4}$；③$0.097276\times6.6295\times10^{-4}=6.449\times10^{-5}$ rad/(in/s²)。
- **结论/结果（复算值）**：$\times386=0.02489$ rad/g，$\times57.2958=\mathbf{1.426}$ deg/g，即书印 **1.43 deg/g** ✓（三项全中）。

### 示例 2：例题 2 的两个值（原书例题）

- **类型与来源**：**原书例题**（例题 2，p203–204），前驱车，两种情形。
- **输入**：$W=4549$ lb、$K_f=287$、$K_r=174$（左右之和）、$h$、$L$ 同前。
- **结论/结果（复算值）**：无抗提升 $\mathbf{4.19\approx4.2}$ deg/g（后轴项 0.045526 + 前轴项 0.027601 rad/g）；完全抗提升 $\mathbf{2.6085\approx2.61}$ deg/g（只剩后轴项 0.045526 rad/g）。比值 $1.606=1+K_r/K_f$ ✓。

### 示例 3：同一辆车取消几何补偿（合成演练，非书中事实）

- **类型与来源**：**合成演练**。原书未算"无几何补偿"的情形；输入沿用例题 1 的参数、令 $e/d=0$，属本卡按式(7-14) 的复算。
- **输入**：例题 1 的车，$e/d=0$（没有抗后蹲几何）。
- **方法论的使用**：括号 $=\frac{h/L}{K_r}+\frac{h/L}{K_f}=1.11799\times10^{-3}+6.6293\times10^{-4}=1.78092\times10^{-3}$；乘 $0.097276$、$\times386$、$\times57.2958$。
- **结论/预期输出**：$\mathbf{3.83}$ deg/g（对比 100% 抗后蹲时的 1.43 deg/g）。含义：几何把俯仰率压掉约 63%——**这就是 e/d 的真实作用量级**，可用于给用户一个"值不值"的直观。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 算"加速时车身抬头多少度每 g"（deg/g），用于对标或写设计目标。
2. 已定几何（$e/d$），要算该几何下的实际俯仰角变化率。
3. 算完发现和书中 1.43 / 4.2 / 2.61 对不上，需要定位是单位、项序还是口径错。
4. 比较"加几何补偿"与"加硬弹簧"两条路线的效果量级。
5. 拿到别处给的 deg/g 结果，需要复核其结构分支是否适用。

### 语言信号（中英双写）

- 「加速抬头多少度每 g」「俯仰角变化率怎么算」「θp/ax」「1.43 是怎么来的」「和例题对不上」
- 「pitch gradient deg/g」「theta_p per g」「pitch angle rate acceleration」
- 「rad/g 和 deg/g 怎么换」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `anti-squat-100` / `anti-pitch-up-precision`：那两张卡算**几何目标**；本卡算**结果量**（deg/g），可以有几何也可以没有。
- 与 `example1-anchors` / `example2-anti-lift-anchors`：本卡给计算口径与三项结构，那两张卡给"三/两个锚点值 + 比值自检"的回归用法。
- 与 `front-drive-anti-lift`：前驱分支的几何条件在那张卡；本卡的式(7-20) 前驱俯仰方程与之配套使用。

## E — 可执行步骤 (Execution)

**必需输入**：$W$（车重）、$h$、$L$、$K_f$、$K_r$（左右之和）、$e/d$（或 $e$、$d$）、**结构分支**（后驱整体轴 / 前驱整体轴 / 独立后驱 / 独立前驱 / 四驱）。**缺结构分支不得开算**——五种分支里本章只有两种可用。

**交付物与完成标准**：三项分解（后轴弹簧项、后轴几何项、前轴弹簧项）、括号值、rad/(in/s²)、rad/g、deg/g、结构分支声明、锚点比对结果。

1. **选式**
   - 完成标准：后驱整体轴 → 式(7-14)；前驱整体轴 → 式(7-20)；独立后驱 → **停**（式 7-18 不可恢复，需纸书复核）；四驱 → **停**（7-26 与 7-12 符号相反、7-27 前轴项不闭合）。
2. **算前置系数**
   - 完成标准：$\frac{1}{L}\frac{W}{g}$，$g=386$ in/s²（写明"不是 32.2"）。
3. **算括号（规范项序）**
   - 完成标准：按 $\frac{1}{K_r}\frac{h}{L}-\frac{1}{K_r}\frac{e}{d}+\frac{1}{K_f}\frac{h}{L}$ 的规范顺序写，三项分别列出数值；**不得照抄原书代入行的 OCR 排布**（例题 1 的代入行分式顺序被打乱）。
4. **走单位链**
   - 完成标准：$\times386$ → rad/g；$\times57.2958$ → deg/g；中间量各保留 4 位有效数字。
5. **锚点自检（必做）**
   - 完成标准：与 1.43 / 4.2 / 2.61 对比；若差约 386 倍 → 漏乘 g；差约 57 倍 → 漏换算 deg；差约 1.6 倍 → 结构分支或抗提升判断错；差约 2 倍 → $K$ 用了单侧值。

**计算约定（原书未规定，本卡设定）**：中间量保留 4 位有效数字，最终 deg/g 报 2–3 位；rad/g 与 deg/g 同时给出；同一辆车的结果不跨车比较。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **用独立后驱的式(7-18)。** 该式在本章 OCR 中只剩碎片（不可恢复）；任何"独立后驱 θ_p = …"的数值结论都必须标"**需纸书复核**"。
- **用四驱分支。** 式(7-26) 的载荷转移项与式(7-12) 符号相反，式(7-27) 前轴几何项方向不自洽；三种写法不能同时自洽 → **四驱分支不可用**。
- **把 1.43 / 4.2 / 2.61 混用。** 1.43 属例题 1 的车（$W=4074$、$K_f=285$、$K_r=169$），4.2 / 2.61 属例题 2 的车（$W=4549$、$K_f=287$、$K_r=174$）；两组严禁互相代入。
- **用瞬态数据对标。** 本式是准静态俯仰角，不含俯仰阻尼与瞬态超调；实测的"入弯/制动瞬间"曲线不能直接取斜率当 $\theta_p/a_x$。
- **忽略 $K$ 的单侧/双侧口径。** 例题明说"此刚度为左右两侧之和"；用单侧值会把结果放大 2 倍。

### 作者在书中警告的失败模式

- 原书例题 1 的代入行 OCR 排布错乱（分式顺序被打乱），照抄会算出错误结果——必须以规范项序复现。
- ce10：把"零俯仰"当目标去追，实际需要 5 倍 $e$ 的臂长与多子系统妥协。
- 例题 2 的"省略第二项"措辞不精确：实际是几何项抵消了前轴弹簧项，不是该项不存在（照抄会误解项结构）。

### 作者的盲点 / 时代局限

- 刚体、线性弹簧、准静态、小角度；忽略非悬挂质量转动惯量与轮胎垂向柔度；不含瞬态俯仰动力学。
- 全章英制、无 SI 换算表；$g=386$ in/s² 这个数必须随规则携带。
- 未讨论弹簧非线性（渐进弹簧、缓冲块）与悬架行程限位对俯仰率的影响。

### 容易混淆的邻近方法论

- **$\theta_p/a_x$ vs $e/d$**：前者是结果（deg/g），后者是几何输入（无量纲比）；两者不是同一坐标系里的量。
- **前仰（车头抬起）vs 后蹲（车尾下沉）**：本卡按"前仰为正"约定（由 $\theta_p=(\delta_r-\delta_f)/L$ 与例题 1 反推）；符号约定不一致会让结论方向反。
- **rad/g vs deg/g**：差 57.2958；与 rad/(in/s²) 又差 386。
