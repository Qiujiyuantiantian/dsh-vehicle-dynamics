# 整体式车轴侧倾中心：三步作图，四种结构只换"谁承受侧向力"

## R — 原文 (Reading)

> **原书要点**（p205–206）：第一步，在平面图上找出承担侧向力的那套杆系，沿车身中心线定出作用点 A 与 B；若杆件成对出现，这两个点即虚拟作用点。第二步，转到侧视图量出 A、B 的位置，据此得到侧倾轴线。第三步，仍在侧视图中，把侧倾轴线与车轮竖直中心线的交点取作侧倾中心。
>
> — 7.6.1（p205–p206）

## I — 方法论骨架 (Interpretation)

一句话：**平面图里找两个力作用点 → 侧视图里连成侧倾轴线 → 与车轮垂直中心线求交，交点高度就是侧倾中心高度。**

- 三步法是**共同骨架**；四种整体式结构（四连杆、三连杆、平行下臂四连杆、叶片弹簧）只在第 1 步"谁是 A、谁是 B"上不同：四连杆 A＝短臂虚拟点（轴后）、B＝长臂虚拟点（轴前）；三连杆 A＝横向拉杆与中心线交点、B＝两下臂虚拟点（**上控制臂只承回转扭矩，剔除**）；平行下臂 → B 在无穷远（转 `parallel-arm-infinite-point`）；叶片弹簧 → A、B 都在无穷远。
- 两个容易漏的细节：①A、B 要**投影到车辆中心线上**，侧向力按控制臂长度反比分配到两点；②"侧倾中心"是这一步的输出，但它只是**这一姿态下的值**——侧倾后几何变化，中心会移动。
- 输出永远是"**高度**"，不是"该取多高"。本章没有目标值，任何"侧倾中心应在 X mm"的说法都不来自本书。
- 结构差异带来可预期的后果：四连杆侧倾轴线斜度变化大（→ 侧倾转向与载荷转移随工况漂移）；三连杆通常更低且斜度几乎不变——这是"取舍"，不是"谁更高级"。

## A1 — 应用示例 (Application Example)

### 示例 1：三种结构的 A、B 取法（原书方法代入，非数值题）

- **类型与来源**：**原书方法代入**（p206–p207）。原书逐一说明四连杆、三连杆、平行下臂四连杆的 A/B 取法，但**没有给出数值算例**（结果栏：未说明）。
- **内容**：四连杆→长臂虚拟点 B 在轴前、短臂虚拟点 A 在轴后，A、B 构成悬架侧倾轴线；三连杆→横向拉杆直接承受侧向力，A 在横向拉杆与中心线交点，B 为两下臂虚拟作用点，**上控制臂在分析中忽略**；平行下臂四连杆→B 在无穷远，整条轴线平行于下控制臂。
- **结论**：换结构时只有第 1 步变，第 2、3 步不动——这正是"三步法"的价值。

### 示例 2：四连杆的高度求解（合成演练，非书中事实）

- **类型与来源**：**合成演练**。原书未给这组尺寸；数值由本卡设定，只用于检验作图流程。
- **输入**：侧视图量得长臂虚拟点 B 在轴前、高 18 in；短臂虚拟点 A 在轴后、高 12 in；轮胎接地点在地面。
- **方法论的使用**：①平面图定 A、B 并投影到中心线；②侧视图连 A(12 in)–B(18 in) 得斜线；③斜线与车轮垂直中心线求交，由地面量高。
- **结论/预期输出**：得到**唯一**交点与一个确定的高度（数值取决于 A、B 的水平位置，本卡不补造）；退化测试：把下臂改成平行 → B 跑到无穷远，改用"过 A、平行于下臂"的直线，程序仍收敛（转 `parallel-arm-infinite-point`）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 有整体式后轴（四连杆/三连杆/叶片弹簧）的正视图+平面图，要算侧倾中心高度。
2. 改装（降车身、换短簧、改四连杆臂长）后想知道侧倾中心怎么变。
3. 需要把侧倾中心高度接到侧向载荷转移/第 6 章转向特性上。
4. 三连杆与四连杆对比：哪个侧倾中心更低、哪个更稳。
5. 被问到"侧倾中心该取多高"（→ 本章无目标值，需明确回答做不到）。

### 语言信号（中英双写）

- 「四连杆后悬的侧倾中心在哪」「整体桥侧倾中心怎么画」「侧倾中心高度多少合适」
- 「roll center of a solid axle」「four-link roll center」「roll axis side view」
- 「三连杆和四连杆哪个侧倾中心低」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `roll-center-independent`：本卡是整体式（两轮由轴相连，A/B 两点法）；独立悬架只算**单侧**杆系的虚拟点，接地点连线求交（三步不同）。
- 与 `virtual-point-method`：本卡的第 1 步就是那张卡；不先定虚拟点，三步法无法开始。
- 与 `parallel-arm-infinite-point`：平行下臂与叶片弹簧的退化分支由那张卡处理。
- 与 `jacking-risk`：本卡只给高度；侧翻风险判定与"侧倾中心高低不是判别式"的告诫在那张卡。

## E — 可执行步骤 (Execution)

**必需输入**：正视图（含车轮垂直中心线）、平面图（含各控制臂与车辆中心线）、侧视图（含 A、B 的垂向位置）、轮胎接地点位置、结构类型。**缺侧视图中的 A、B 高度时停止**——本卡不接受口述"大概在轴心附近"。

**交付物与完成标准**：A、B 的名称与坐标（投影到中心线）+ 侧倾轴线描述 + 侧倾中心高度（由地面量起，带正负）+ 姿态声明（零侧倾）+ 结构类型。

1. **判结构并筛杆件**
   - 完成标准：写明结构类型；只保留承受侧向力的杆系（三连杆剔除上控制臂，理由："只承车轴回转扭矩"）。
2. **定 A、B（平面图）**
   - 完成标准：给出 A、B 的定义式描述（哪两对臂的交点/哪根拉杆与中心线的交点），并投影到车辆中心线；侧向力按控制臂长度反比分配。
   - 判停条件：某对臂平行 → 转 `parallel-arm-infinite-point`，不得强行取有限交点。
3. **连侧倾轴线（侧视图）**
   - 完成标准：在侧视图中标出 A、B 的高度并连线；写出该线的斜率含义。
4. **求交得高度**
   - 完成标准：与车轮垂直中心线求交，给出高度数值（可为负）与"由地面量起"的声明。
5. **姿态与限制声明（必做）**
   - 完成标准：写"该值在**零侧倾**姿态下确定；侧倾后外侧轮虚拟点下移、内侧上移，有效侧倾中心低于静态值"；并写"本章不提供侧倾中心的目标高度"。

**计算约定（原书未规定，本卡设定）**：高度用 in 或 mm 并与输入同单位；正值表示地面之上；交点若在无穷远（两侧同时平行）→ 报"轴线平行于车辆中心线"，不报数值。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **给出"侧倾中心该取多高"的建议。** 全章**没有**经验值或判据（作者盲点，已在覆盖审计中定为长期空白）；任何"应在 50–100 mm"的说法都不是本章内容，不得补造。
- **拿静态值去预测侧倾中的载荷转移。** 原文明确：只有在没有侧倾时轴线位置才确定；侧倾后外侧轮虚拟点下移、内侧上移，两轮中心不再重合，**有效侧倾中心低于静态值** → 用静态值会高估几何抗侧倾。
- **引用 p206 那句"四连杆侧倾中心相对较高，在后轮上施加了过多的侧倾力矩"作定量结论。** 该句与 p210（倾斜平行杆、**前轴**语境）"减少外侧载荷转移→导致不足转向"方向相反，原文未裁决。引用时**必须带"哪根轴、哪种结构"**，且只能作原文登记，不能推出"侧倾中心高→过多转向"。
- **把四连杆当"最优整体轴"。** 它的可控性好，代价是侧倾轴线斜度随侧倾变化最大 → 侧倾转向与载荷转移随工况漂移（p206）。
- **忽略衬套与三维耦合。** 全章刚体、二维（正视+平面+侧视）；多连杆/带衬套结构的名义几何不等于实车运动。

### 作者在书中警告的失败模式

- ce13（最直接）：把侧倾中心当固定几何量，忽略"瞬时"二字与左右不对称。
- ce14：因为四连杆"几何设计允许更好控制"就默认它最优，把调校建立在"侧倾中心是固定值"的前提上——实际它的轴线斜度变化最大。
- ce15：平行下臂四连杆盯着上臂（A 点），忘记 B 在无穷远、轴线由下臂斜率决定。
- 三连杆剔除规则的反面：不剔除上控制臂会多一个不存在的力。

### 作者的盲点 / 时代局限

- 全章没有侧倾中心的目标值（真实缺陷，BOOK_OVERVIEW 已列为作者盲点）。
- 叶片弹簧一节的侧视图作图步骤原文较略，只给结论。
- 非对称（侧倾中）情形的作图细则缺失；"有效侧倾中心"没有计算方法。
- 只讲几何，不讨论轮胎特性、衬套柔度、车身变形如何"糊掉"这些点。

### 容易混淆的邻近方法论

- **悬架侧倾轴线 vs 车辆侧倾轴线**：前者描述"非悬挂相对悬挂"的转动，后者是前后侧倾中心连线、"整车相对地面"的转动；参照系不同，斜率含义不同。
- **侧倾中心 vs 侧倾轴线 vs 瞬时轴线**：点 / 悬架的轴 / "仅零侧倾位形有效"的限定词。
- **"瞬时"vs 时间导数**：作者的"瞬时"是**位形限定**，不是随时间变化；不要去求 $\mathrm{d}(\text{roll axis})/\mathrm{d}t$。
