# 抗后蹲百分率：$(e/d)\div(h/L)$，一个不含弹簧刚度的几何比例

## R — 原文 (Reading)

> **原书要点**（p199）：$e/d=h/L$ 意味着加速时后悬架完全不产生挠度（压缩—跳动为零）。实际几何达不到这一程度时，就用抗后蹲百分率来度量；比如 $e/d=0.5h/L$，便称该悬架具有 50% 的抗后蹲。
>
> — 7.3.2（p199）

## I — 方法论骨架 (Interpretation)

一句话：**几何支点达到"理论所需高度"的几成——纯粹是比值的比值，不是力、不是载荷、不含刚度。**

- 定义：$\%\text{anti-squat}=\dfrac{e/d}{h/L}\times100$。原文只给了一个数值例（$e/d=0.5h/L$ → 50%）推得这条线性关系，**没有写出代数式**——本卡把它写成公式，属于读法整理，不是原文写法。
- 为什么必须强调"不含刚度"：抗后蹲的 100% 条件 $e/d=h/L$ 本身与 $K$ 无关；而抗前仰、抗点头的条件都含刚度或刚度比。把 $K_r$ 塞进抗后蹲百分率，就把三种百分率混成了一种。
- 区间纪律：0–100% 有定义；**>100% 与负值原文未定义**，只能报"超过 100%"或"为负"，不得解释其物理含义（更不得说是"反向抗后蹲"）。
- 输出一般配一句话的物理解释："几何承担了加速姿态载荷转移的 X 成"，并同时给出 $e/d$ 与 $h/L$ 两个原始值，便于复核。

## A1 — 应用示例 (Application Example)

### 示例 1：例题 1 的抗后蹲率（原书例题参数 + 本卡复算）

- **类型与来源**：**原书例题参数**（例题 1，p203；$h=20.5$、$L=108.5$、$e/d=0.189$）。原书没有把"百分率"这一步做出来，本卡按 7.3.2 的定义补算，属**复算**而非书中原有结论。
- **输入**：$h/L=0.18894$、$e/d=0.189$。
- **方法论的使用**：$0.189/0.18894\times100$。
- **结论/结果（复算值）**：$0.189/0.18894=100.03\%\approx\mathbf{100.0\%}$；若 $e/d$ 也取全精度（$e/d=h/L=0.18894$）则恰好 100.00%。这个"约 100%"正是例题 1 的题设（要求 100% 抗后蹲），可作定义自检：若算出 90% 或 110%，通常是 $h/L$ 取位或把刚度塞进了分母。

### 示例 2：66.9% 与越界测试（合成演练，非书中事实）

- **类型与来源**：**合成演练**。原书未给这组输入；数值由本卡按定义算出，只用于检验流程与区间纪律。
- **输入 A**：$e/d=0.1263$、$h/L=0.1889$。**执行**：$0.1263/0.1889=0.6686$。**结论**：$\mathbf{66.9\%}$。
- **输入 B（越界）**：$e/d=0.2834$、$h/L=0.1889$ → $150\%$。**结论**：按本卡纪律，**只报"超过 100%"**，不解释 $150\%$ 的物理含义（原文未定义过补偿区）。
- **输入 C（等于 100%）**：$e/d=h/L$ → 100%，与 `anti-squat-100` 一致。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 现场沟通："这台车现在是几成抗后蹲？"
2. 拿到一组硬点与整车参数，判"几何够不够"，而不是重算一遍目标值。
3. 被人给了一个"60% 抗后蹲"的说法，需要核对分母是 $h/L$ 还是别的量。
4. 讨论"抗后蹲率能不能超过 100%"或"负值是什么意思"。
5. 想做"抗前仰百分率/抗点头百分率"的换算，需要先确认本章只定义了哪一个。

### 语言信号（中英双写）

- 「抗后蹲率是多少」「这是几成抗后蹲」「60% 抗后蹲怎么算」「能不能超过 100%」
- 「percent anti-squat」「anti-squat percentage definition」「is anti-squat a force percentage」
- 「抗前仰百分率怎么算」（→ 本章无定义，需说明）

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `anti-squat-100`：本卡把 $e/d$ 与 $h/L$ 的比值翻译成百分率；那张卡负责推导 100% 条件与几何解。
- 与 `anti-pitch-up-precision`：抗前仰的条件含刚度比，且本章**没有**定义"抗前仰百分率"——不能用同一公式套。
- 与 `full-compensation-veto`：百分率是"现状"，否决门是"该不该做满"。

## E — 可执行步骤 (Execution)

**必需输入**：$e$、$d$（或已算好的 $e/d$）、$h$、$L$、结构判定（决定 $e$ 还是 $(e-r)$）。**缺 $h$ 或 $L$ 时停止**——百分率的分母就是 $h/L$，不能估。

**交付物与完成标准**：$e/d$（4 位小数）、$h/L$（4 位小数）、百分率（1 位小数）、区间声明（0–100% / 超过 100% / 负值）、一句话物理解释。

1. **核对口径**
   - 完成标准：写明 $e/d$ 来自哪条条件（整体式后驱 $e/d$、独立后驱 $(e-r)/d$），并确认 $e$ 从接地点量起。
2. **算比值**
   - 完成标准：百分率保留 1 位小数；同时给出原始两个比值，便于第三方复核。
3. **区间判定**
   - 完成标准：落在 0–100% → 正常报数；>100% → 只报"超过 100%"并注明原文未定义其含义；负值 → 只报"为负"并注明原文未定义。
   - 判停条件：用户要求解释 >100% 的物理含义 → 停，说明需回原文/纸书，本卡不补造。
4. **交付**
   - 完成标准：一句话"几何承担了 X 成（$e/d=…$，$h/L=…$）"，并声明**该百分率不含弹簧刚度**。

**计算约定（原书未规定，本卡设定）**：百分率保留 1 位小数；0.5 位以上进位按常规四舍五入；100% 用"0.18894/0.18894"这类同源数值计算，避免因取位产生 99.9%。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **把它当"力/载荷的百分比"引用。** 它是几何支点高度相对理论所需高度的比例；当成载荷百分比会让后续力矩换算全错。
- **往里塞弹簧刚度。** 抗后蹲的 100% 条件与 $K$ 无关；掺入 $K$ 就把它与抗前仰/抗点头混成一种东西。
- **解释 >100% 或负值。** 原文未定义这两个区间；"过补偿""反向抗后蹲"都是本卡之外的杜撰。
- **用它代替"该不该做满"的判断。** 100% 只能说明几何够了，不能说明工程上可取（见 `full-compensation-veto`）。
- **给本章没有的百分率。** "抗前仰百分率""抗点头百分率"书中**没有定义**；若用户需要，必须先声明是自己下的定义，不能假托原文。

### 作者在书中警告的失败模式

- 把"几何比例"读成"力的比例"（本章最常见的口径错，作者在 p199 用"所达到的程度"而非"力"来措辞）。
- ce10：把抗后蹲率当考核指标一路推高 → 需要 5 倍 $e$ 的臂长、与制动操控冲突。
- ce09：为抬高百分率把后支点抬过车轮中心 → 过多转向风险（同一个几何变量的另一输出）。

### 作者的盲点 / 时代局限

- 只给了一个数值例（50%），没有写代数式，也没有讨论分母的替代口径（如以轴荷比作分母）。
- 未定义 >100%、负值，也未定义其它姿态的百分率（抗前仰、抗点头、抗提升）。
- 未讨论 $h$ 随载荷变化（乘员/载货）时百分率会漂移这一实际工程问题。

### 容易混淆的邻近方法论

- **抗后蹲（条件式）vs 抗后蹲百分率（度量）**：前者是"该等于多少"，后者是"已经到几成"。
- **抗后蹲率 vs 抗前仰率**：后者若要定义必然含刚度比，不能套本卡公式。
- **几何百分率 vs 载荷转移百分比**：加速时前/后轴载荷转移的百分比由 $h/L$ 与 $a_x$ 决定，与 $e/d$ 无关；两者数值接近是巧合，不是同一个量。
