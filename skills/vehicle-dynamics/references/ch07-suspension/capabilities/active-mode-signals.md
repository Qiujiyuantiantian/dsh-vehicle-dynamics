# 主动悬架六种性能模式与各自的传感信号

## R — 原文 (Reading)

> **原书要点**（p212 §7.7.2）：弯道里抑制车身倾斜有两条手段：加大减振器阻尼，或直接施加一股反抗车身倾斜的力，二者都能让过弯姿态更稳。至于何时该介入，可由车速、方向盘转角、转角变化的快慢以及横向加速度中的一项或几项来判断。
>
> **原书要点**（p212）：抑制点头这一功能，可依据刹车灯信号、制动压力，或者纵向加速度（也可兼用）来判断并动作。有了主动悬架承担点头控制，悬架杆系中靠几何布置实现抗点头的设计压力就减轻了。
>
> — 7.7.2（p212）

## I — 方法论骨架 (Interpretation)

一句话：**选型之后要落到实现，就把"要改善哪个模式"翻成"用哪几路信号、动哪个执行量"。**

- 六模式与信号（原文逐段）：
  | 模式 | 目标 | 可用信号 |
  |---|---|---|
  | 乘适性 | 车体俯仰、垂向跳动 | 车体加速度（直接感测） |
  | 高度 | 保持设计车高 / 高速降高 / 坏路抬高 | 载荷、空气动力学变化 |
  | 侧倾 | 抑制转向侧倾 | 车速 + 转向角 + 转向速率 / 侧向加速度 |
  | 点头 | 抑制制动前俯 | 制动灯、制动压力 / 纵向加速度 |
  | 后蹲 | 抑制加速后仰 | 节气门位置、挡位 / 纵向加速度 |
  | 接地性 | 减小车轮动态载荷波动 | 车轮动态载荷（= 车轮加速度） |
- 两个必须一起给的性质：
  1. **模式是"改善目标"，不是"能力等级"**——等级由 `active-suspension-ladder` 的矩阵决定，本卡只说到"用什么信号实现"。
  2. **主动只改力、不改运动学**（p210）。所以它"减轻几何设计要求"（点头/后蹲各有一句原文），但**不能替代几何设计**。
- 还有一条隐含杠杆：侧倾力矩"可以有选择地施加于前轴或后轴"，从而改变由侧向载荷转移引起的不足转向梯度——这是主动系统能碰到转向特性的唯一通道，且属"分配载荷转移"，不是"改侧倾中心"。

## A1 — 应用示例 (Application Example)

### 示例 1：六模式清单（原书功能陈述，非算例）

- **类型与来源**：**原书清单**（7.7.2，p212）。没有例题、没有数值、没有控制律。
- **用法**：作为"需求→信号"的查表；每条都能指到原文段落。
- **未说明**：各模式的作动器功率、带宽、切换频率、优先级、模式冲突如何处理——原文全部没有。

### 示例 2：制动点头策略（合成演练，非书中事实）

- **类型与来源**：**合成演练**。原书只给信号清单与"减轻几何要求"这一句；下面的策略表由本卡按原文条目组织。
- **输入/问题**：某车需在制动工况抑制点头，被动几何已做到 30% 抗点头，问主动系统该怎么接。
- **方法论的使用**：①定模式＝点头；②取信号＝制动灯 / 制动压力 / 纵向加速度（三者可并用，原文用"和/或"）；③动作＝提高阻尼或施加抗点头力；④副作用＝减轻杆系抗点头几何要求（p212），但不改变几何本身。
- **结论/预期输出**：策略＝"制动信号触发 + 纵向加速度闭环，向抗点头方向施加力"；同时声明：几何仍按 30% 保留（主动不替代几何），且不得承诺"完全消除点头"——原文只说"改善"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 已决定上主动/半主动，问"控制策略用什么信号"。
2. 需要把"抑制侧倾/点头/后蹲"写成可实施的功能条目（信号 + 执行量）。
3. 评审某供应商方案："它感测什么？能不能实现宣称的模式？"
4. 讨论主动系统能不能替代几何设计（抗点头/抗后蹲的杆系）。
5. 想通过主动系统改转向特性（分轴施加侧倾力矩）。

### 语言信号（中英双写）

- 「主动悬架用什么信号」「侧倾控制怎么触发」「主动能不能不做抗点头几何」「CDC 控制策略」
- 「active suspension control inputs」「roll control signals」「anti-dive via active suspension」
- 「能不能只靠软件解决点头」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `active-suspension-ladder`：那张卡决定等级（哪一级够用），本卡决定实现（信号与执行量）。
- 与 `full-compensation-veto`：本卡是那张卡"替代手段之一"（主动减轻几何要求）的具体化。
- 与 `roll-center-*`：主动不改运动学（侧倾中心、外倾曲线）；凡涉及几何，仍回那两张卡。

## E — 可执行步骤 (Execution)

**必需输入**：目标模式（六选一或多选）、该模式对应的工况（制动/加速/转向/坏路/载荷变化）、可用传感器清单、执行器类型（阻尼可调/刚度可调/力发生器）、是否允许模式间冲突（优先级要求）。**缺"可用传感器"时不能给策略**——本卡不给传感器选型之外的硬件建议。

**交付物与完成标准**：模式 → 信号 → 执行量 → 副作用 → 边界的五列清单；每条信号注明原文出处；明确"不能替代几何"的声明。

1. **模式定位**
   - 完成标准：把需求落到六模式之一（或明确说明跨模式，并指出原文没有优先级规则）。
2. **取信号**
   - 完成标准：只从原文列出的信号中选（乘适性=车体加速度；高度=载荷/气动；侧倾=车速+转向角+转向速率/侧向加速度；点头=制动灯+制动压力/纵向加速度；后蹲=节气门+挡位/纵向加速度；接地性=车轮动态载荷）。
   - 判停条件：需求是 10–15 Hz 车轮模态（碎石路乘适性）→ 停，先讲 `active-suspension-ladder` B 段的 ≈10 Hz 天花板。
3. **定执行量**
   - 完成标准：写明"提高阻尼 / 改变刚度 / 施加力"中的哪一个；说明它只影响力，不改变几何。
4. **写副作用与替代关系**
   - 完成标准：点头/后蹲两模式必须写"减轻杆系几何设计要求"；侧倾模式写"侧倾力矩可选择性施加于前/后轴 → 改变载荷转移分配与不足转向梯度"。
5. **交付与边界**
   - 完成标准：给出五列清单，并声明本章未给功率/带宽/优先级/失效模式，不得替原文承诺性能数值。

**计算约定（原书未规定，本卡设定）**：不设控制参数（增益、阈值、切换时间）；只给"信号—动作"映射，参数由后续标定确定。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **承诺"主动悬架能改侧倾中心/外倾曲线/轮距变化"。** 原文界线：主动组件只改变垂直方向受力，不改变悬架运动情况（p210）——运动学是几何的事。
- **用它给性能数值或带宽。** 本章无作动器功率、无带宽数值、无"带宽↔性能"的定量对应；不得把"高频带"换算成 Hz 指标。
- **把六模式当可任意叠加。** 原文未说六模式可独立叠加，也未给模式冲突与优先级；"完全消除侧倾"（p212）原文未给代价（对轮胎载荷转移的副作用未讨论）。
- **在 ≈10 Hz 频段宣称改善乘适性。** 该频段主/被动相近，且压低车轮运动的力会反作用到车身（p213）。
- **用"分轴施加侧倾力矩"替代几何调校。** 它改变的是载荷转移的分配，属主动分配，不是改变侧倾中心高度。

### 作者在书中警告的失败模式

- ce20：把"主动一行全高"读成"每个频段都更好" → 实际在 10 Hz 附近是以乘适性换操控性。
- ce19：为乘适性买高频带（买到的是车轮载荷稳定，不是乘适性）。
- p212 的隐含代价：主动"完全消除转向侧倾是可行的"——但载荷转移不会消失，只会被重新分配（属本卡按第 6 章框架的推论，原文未展开）。

### 作者的盲点 / 时代局限

- 1992 年：液压作动器 + 带宽讨论，无电控空气悬架、磁流变、48V 主动防倾杆。
- 未讨论：模式优先级、故障降级（fail-safe）、能耗、传感器失效策略、与 ESC 的协调。
- 六模式的能力矩阵是定性等级（高/中/低/无），不是可验证指标。

### 容易混淆的邻近方法论

- **模式（乘适性/侧倾/…）vs 等级（被动/自调水平/半主动/主动）**：一个是"改善什么"，一个是"用什么手段"。
- **高度控制 vs 举升（jacking）**：前者是功能，后者是失稳前兆。
- **"主动减轻几何要求"vs"主动替代几何"**：原文只说减轻（降低要求），不是取消。
