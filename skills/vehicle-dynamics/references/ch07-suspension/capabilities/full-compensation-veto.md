# 满额几何补偿的否决检查：把 e/d 调到 100% 之前先过 8 条

## R — 原文 (Reading)

> **原书要点**（p202–203 §7.4）：真车上几乎见不到 100% 抗点头，通常把上限压在 50% 以内，理由之一是：要做到完全不点头，支点得架到 100% 抗后蹲点之上，而这样一来，整体式驱动桥在加速时就会被抬起。
>
> **原书要点**（p202–203）：书里补充道，加速时车身总归要留一点前仰与后蹲，因此把两者完全抵消掉的做法在实际中很少见。
>
> — 7.4（p202–p203）、7.3.2 末段（p200）

## I — 方法论骨架 (Interpretation)

一句话：**几何能做到 100%，工程通常不做——做满之前先把原文那 8 笔账逐条勾一遍，命中且无替代手段就降额。**

- 这 8 条不是 8 个独立缺点，而是**同一个几何选择的 5 个出口**：支点抬高（换姿态）→ 驱动轴摆角（传动）、主销后倾变化（转向）、后轴侧倾中心（操稳）、有效拖曳臂变短（接地）、硬连接（NVH）。所以正确的心智模型是"把姿态问题从弹簧转移到其他子系统"，而不是"抗点头有副作用"。
- 判据的方向是**否决**，不是选优：任一条命中且无替代手段 → 降额；作者给的经验上限是"很少超过 50%"。
- 原文只给了两处替代手段：**加长有效拖曳臂**（缓解制动跳跃，p203）、**主动悬架的点头/后蹲控制可以减轻几何要求**（p212）。除此之外的手段都属本卡外部。
- "50%"是**经验判断**（原文只说"很少超过"），只能当上限提示，不能当计算判据，也不能反推"50% 最好"。
- 本卡不做抗点头的**数值**计算：式(7-28) 的负号含义与 $\beta$ 基准在本章都未定义（见 B 段），凡依赖它的定量结论一律标"需纸书复核"。

## A1 — 应用示例 (Application Example)

### 示例 1：原文的 8 条否决理由（原书陈述，非算例）

- **类型与来源**：**原书清单**（7.4，p202–p203）。不是例题，没有权重、没有推导。
- **内容（压缩）**：① 完全抗点头的支点高于完全抗后蹲点 → 整体驱动轴加速时出现提升；② 主观上并不需要车身平直地停车；③ 制动中前悬架主销后倾角变化明显增加制动转向；④ 所需转向系统几何相当复杂；⑤ 跳动/回弹时驱动轴角速度变化过大 → 齿轮抖动与噪声；⑥ 后悬架支点过高 → 过多转向；⑦ 拖曳臂过短 → 制动跳跃（加长有效臂可缓解）；⑧ 影响 NVH。
- **用法**：这 8 条是**评审表**，逐条回答"命中/未命中/无判断依据"，不作加权。

### 示例 2：整体式后驱动轴拟取 100% 抗点头（合成演练，非书中事实）

- **类型与来源**：**合成演练**。原书没有这道评审；输入由本卡设定，输出按原文条款逐条判读，不能当作者结论。
- **输入/问题**：某整体式后驱动轴，被动悬架（无主动作动器），为消除制动点头拟把前轴抗点头做到 100%。
- **方法论的使用**：逐条核对 → 命中①（支点在完全抗后蹲点上方 → 该轴加速时提升）、⑥（后支点过高 → 过多转向风险）、⑦（为凑比率把有效臂做短 → 制动跳跃）。
- **结论/预期输出**：**不得取满**；无替代手段可用（被动系统、布置不允许加长有效臂）→ 依原文量级降到"最大不超 50%"，并把三条命中项写进设计风险清单。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 有人提议"把抗后蹲/抗点头做到 100%，姿态最漂亮"，需要一份否决依据。
2. 设计评审：指标已定 100%，需要列出必须同时接受的代价。
3. 已经出现"制动时后轴跳""换挡/制动齿轮噪声""制动跑偏"等症状，怀疑与满额几何有关。
4. 讨论"几何 vs 主动悬架"的替代关系：几何要求能不能被主动系统降低。
5. 被问"抗点头率是不是越高越好"。

### 语言信号（中英双写）

- 「抗后蹲/抗点头做到 100% 行不行」「为什么原厂只做一半」「做到满额有什么代价」
- 「100% anti-dive / anti-squat trade-offs」「why don't OEMs use full anti-dive」「anti-dive percentage limit」
- 「刹车点头能不能完全消掉」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `anti-squat-100` / `anti-pitch-up-precision`：那两张卡算**需要多大的 e/d**；本卡判**要不要做这么大**。
- 与 `five-e-quick-rule`：那张卡管"布置空间够不够"（$d\approx5e$），本卡管"该不该做满"；两者常一起用。
- 与 `active-suspension-ladder`：本卡的第 1 条替代手段（主动控制）需要那张卡的等级判定来落实。
- 与"抗点头计算"：本 bundle **不提供**抗点头的数值能力（式 7-28 符号待核），只能做本卡的否决评审。

## E — 可执行步骤 (Execution)

**必需输入**：拟取的目标百分率（抗后蹲/抗点头/抗提升）、轴的类型与驱动形式、悬架是被动还是含主动组件、有效拖曳臂长度是否可加长（布置约束）、是否已出现相关症状。**缺"能否加长有效臂"与"是否主动"两项时先问**——它们决定替代手段是否存在。

**交付物与完成标准**：目标率 + 8 条逐条判读（命中/未命中/无依据）+ 可用替代手段 + 建议降额与残余风险清单。**不交付"最优百分率"**。

1. **确认目标与结构**
   - 完成标准：写明是哪根轴、哪种工况（加速后蹲 / 加速前仰 / 制动点头 / 制动提升）、当前拟取百分率。
2. **逐条核对 8 条**
   - 完成标准：每条给"命中/未命中/本章无依据"三态之一，并附页码；"主观上不需要平直停车"（第 2 条）单独标为**主观偏好，不作工程判据**。
   - 判停条件：若涉及**抗点头的数值**（多少度、多少 e/d）→ 停，转 B 段说明：式(7-28) 符号未定义、$\beta$ 基准未定义，本章给不出可用数值，需纸书复核。
3. **找替代手段**
   - 完成标准：只允许两类——加长有效拖曳臂（p203）、主动点头/后蹲控制（p212）；其它手段标注"非本章依据"。
4. **降额与残余风险**
   - 完成标准：给出建议降额（引用"很少超过 50%"作为上限提示，并声明这是经验判断）；列出降额后仍存在的症状与监测项（制动跳跃、齿轮噪声、制动转向、过多转向）。
5. **交付**
   - 完成标准：一句话结论形如"取 X%，因为命中 ①⑥⑦；替代手段不可用；残余风险为……"，并注明本章无权重、无量化代价模型。

**计算约定（原书未规定，本卡设定）**：8 条按"命中/未命中"二值记录，不做打分；"50%"只作上限提示，不作通过线。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **把"50%"当计算判据或最优值。** 原文只说"很少超过"，是作者的经验判断；它既不是合格线，也不是推荐值。
- **用它给抗点头率算数值。** 式(7-28) $e_f/d_f=\tan\beta_f=-h/(\xi L)$ 的**负号含义未定义**、$\beta_f/\beta_r$ 的**基准面未定义**，本章无法把"支点在直线哪一侧"几何定位 → 任何"抗点头率 = X%"的定量结论一律标"**需纸书复核**"，不得发布。
- **把 $\xi$ 跨节复用。** $\xi$ 在 7.3.6 是"前轮驱动力占总驱动力百分比"，在 7.4 是"前轴制动力所占比例"——同符号两义，原文未提醒；跨节引用必须重新定义。
- **只核悬架图纸就下结论。** 8 条里有 4 条落在别的子系统（传动、转向、NVH、后悬架操稳），单看悬架图永远看不到这几笔账。
- **把"某种程度的前仰和后蹲是需要的"（p200）当审美偏好。** 原文用它说明完全补偿"不常见"，这是工程判断，不是可选项清单。

### 作者在书中警告的失败模式

- ce11（最重）：把抗点头率当"越大越好"的单一指标做到 100%——收益只有姿态，代价分散在五个子系统。
- ce10：把"零俯仰"写成硬指标 → 需要 5 倍 $e$ 的臂长 → 布置做不到就缩 $d$ → 与制动、操控冲突 → 传动轴摆角、齿轮噪声、衬套变形被放大。
- ce09：只为抗后蹲抬高后支点 → 后侧倾中心抬升 + 侧倾转向 → 整车平衡向过多转向偏移（原文两处独立警告：p200、p203 第 6 条）。
- ce08：为凑比值把有效拖曳臂做短 → 加速度接近附着极限时后轴"动力跳动"（p200）；制动时"制动跳跃"（p203 第 7 条）。
- ce12：支点越过 100% 线 → 符号翻转（制动时前轴提升、后轴后蹲）；但该条依赖式(7-28) 的直线对象，**只能作原文陈述引用，不能据此给定量判据**。

### 作者的盲点 / 时代局限

- 8 条无权重、无排序、无量化；"哪一条最重要"书中没有回答。
- 1992 年没有电控阻尼/主动防倾杆，替代手段的清单按当时技术写的；现代可用的半主动手段未讨论。
- 作者站在整车厂视角：假设能改硬点、能试制样件；售后改装场景（只能改衬套/弹簧）本章覆盖不足。
- 全章刚体、准静态；跳动类症状（hop）被当作几何后果，未讨论与轮胎垂向刚度、阻尼的耦合。

### 容易混淆的邻近方法论

- **抗后蹲 vs 抗前仰 vs 抗点头 vs 抗提升**：四个目标、四组数值；抗后蹲与抗前仰差一个刚度比项，抗点头只讲前轴，后轴那半叫抗提升（且"抗提升"另有一义指加速时的前轴）。
- **满额否决 vs 100% 抗后蹲判据**：后者是"需要多大"的条件式，前者是"要不要做到"的否决门。
- **"零俯仰"vs"后轴不压缩"**：前者要求后轴抬升去补偿前轴回弹，后者只要后轴不动——两者不是同一件事。
