# 平行杆的无穷远极限法：交点在无穷远时，方向由杆件斜率给出

## R — 原文 (Reading)

> **原书要点**（p207）：下控制臂彼此平行时，这两个虚拟作用点被推到无限远。换到侧视图上看，点 B 相应落在下控制臂中心线延长方向的无穷远处；于是这类悬架的侧倾轴线成了一条与下控制臂平行的直线。正因如此，下控制臂的倾角在此类结构中举足轻重。
>
> — 7.6.1（p207）

## I — 方法论骨架 (Interpretation)

一句话：**一对杆件一旦平行，就不要写有限交点——把"接地点→虚拟作用点"的连线方向直接取成杆件方向。**

- 有限交点的情形是"两点连线"；平行情形退化为"**一个点 + 一个方向**"。侧倾轴线＝过另一个有限点、平行于该平行杆的直线，再与车轮垂直中心线求交。
- 三条可直接套用的原文结论：
  1. **平行下臂四连杆**：侧倾轴线平行于下控制臂 → 下臂斜度变成最重要的设计变量（p207）。
  2. **叶片弹簧**：两点都退到无穷远，侧倾轴线平行于车辆中心线 → 侧倾中心落在地平面附近（p207）。
  3. **水平平行杆**：侧倾中心在地平面上（p209）；**倾斜平行杆**：抬到地面以上，等长连杆时该位置不随侧倾移动（p210）。
- 输出必须注明"这是退化情形"，并写出参考方向（哪根杆、倾角多少）——否则下游会把"方向"当成"某个具体点"再算错一次。

## A1 — 应用示例 (Application Example)

### 示例 1：原书的两处退化结论（原书方法，无算例）

- **类型与来源**：**原书代入**（p207、p209）。原书只给结论与作图，**未给数值算例**（结果栏：未说明）。
- **内容**：平行下臂四连杆 → 侧倾轴线平行于下臂；设计载荷下水平的等长平行杆 → "连接接地点到无穷远的直线"与车辆中心线交点在地平面，即侧倾中心高度为 0。
- **结论**：高度 0 不是"没有侧倾中心"，而是"侧倾中心落在接地点所在平面"——这个区别决定了后续载荷转移力臂取 $h$ 还是 $h-0$。

### 示例 2：倾斜平行杆的抬升（合成演练，非书中事实）

- **类型与来源**：**合成演练**。原书描述了"倾斜平行杆→侧倾中心抬到地面以上、等长时位置不随侧倾移动"（p210），但没有给角度与高度的数值；下面这组输入由本卡设定，只用于检验流程。
- **输入/问题**：独立悬架、上下等长平行杆、设计载荷下杆轴线相对水平倾斜 5°，求侧倾中心相对地面的位置。
- **方法论的使用**：①判平行（等长 + 平行）→ 虚拟点在无穷远；②方向＝杆件方向（5°）；③过接地点作 5° 斜线，与本侧车轮垂直中心线求交 → 交点在地面之上。
- **结论/预期输出**：侧倾中心高于地平面（具体高度由轮距与倾角几何决定，本卡不补造数值）；且因连杆等长，侧倾时该位置基本不动。若把杆改成水平，交点回到地平面——**下臂斜度是唯一的敏感变量**。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 求侧倾中心时发现"上下臂平行，交点算不出来/除零"。
2. 叶片弹簧整体轴，问"它的侧倾中心怎么定"。
3. 想知道"下控制臂角度改一点，侧倾中心会变多少"（敏感度/调校）。
4. 判断某独立悬架"侧倾中心在地面还是在地面上"（正/负摆动臂的边界情形）。
5. 看到"等长平行臂"的简化设计，想知道它对侧倾中心意味着什么。

### 语言信号（中英双写）

- 「上下摆臂平行，侧倾中心怎么算」「平行杆的交点在无穷远怎么办」「叶片弹簧的侧倾中心在哪」
- 「parallel control arms roll center」「infinite virtual point」「roll center at ground level」
- 「下摆臂角度改一点侧倾中心变多少」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `virtual-point-method`：那张卡处理有限交点，本卡是它的**退化分支**；先判平行再选卡。
- 与 `roll-center-solid-axle` / `roll-center-independent`：本卡只给"方向/轴线"，高度仍由那两张卡的三步法落图。
- 与 `five-e-quick-rule`：同为"数量级/方向"级结论，但一个管侧向（侧倾中心），一个管纵向（$d\approx5e$）。

## E — 可执行步骤 (Execution)

**必需输入**：哪一对杆件平行（或等长平行）、该对杆件的倾角（相对水平或相对设计位置）、另一个有限点的位置（另一对臂的虚拟点，或接地点）、车轮垂直中心线位置。**缺倾角时停止**——退化情形下方向就是全部信息，没有倾角就无法给结论。

**交付物与完成标准**：退化判定 + 参考方向（杆件与倾角）+ 侧倾轴线描述 + 与垂直中心线的交点（或"在地平面上/在地面之上"的定性结论）+ "位置是否随侧倾移动"的声明。

1. **判退化**
   - 完成标准：写明"哪一对杆件平行/等长平行"，并声明"该对杆件的虚拟作用点在无穷远"。
   - 判停条件：若杆件并不平行（斜率差 > 制造公差量级），回到 `virtual-point-method` 取有限交点。
2. **取方向**
   - 完成标准：把"接地点→虚拟作用点"的连线方向写成杆件方向（含角度与正负）。
3. **定侧倾轴线**
   - 完成标准：过另一个有限点作平行于该方向的直线；若两个点都在无穷远（叶片弹簧），轴线平行于车辆中心线。
4. **求交并交付**
   - 完成标准：与车轮垂直中心线求交，给出高度（可正可负可为零）；标注"退化情形，方向依赖杆件斜度"。
5. **敏感度提示（必做）**
   - 完成标准：写一句"该几何下侧倾中心对下臂斜度/垫片厚度高度敏感"；不得给出未经原文支持的灵敏度数值。

**计算约定（原书未规定，本卡设定）**：角度用度、正负按"前端抬高为正"声明；交点在地平面上记 $h_{rc}=0$，不写"无"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **把无穷远当有限点做除法/求交。** 退化情形的正确操作是"取方向"，任何"用很大的坐标代入"的做法都会得到荒谬的高度。
- **把"位置不随侧倾移动"外推到所有平行杆几何。** 原文该结论附有条件：**连杆等长**（p210）；不等长时不成立。
- **用叶片弹簧的结论替代作图。** 原文叶片弹簧一节只给结论、未给完整侧视图作图步骤，照此推广到相似结构需自行重画。
- **在非零侧倾姿态下用静态方向。** 与其他侧倾中心结论一样，只在零侧倾位形下确定；侧倾后轴线随几何移动。
- **忽略制造公差。** 退化构型对下臂斜率极敏感：一侧垫片厚度的差异会直接变成左右侧倾中心不对称。

### 作者在书中警告的失败模式

- ce15：在平行下臂四连杆上盯着上臂（A 点），忘记 B 点在无穷远、整条轴线由下臂斜率决定 → 侧倾中心算错且调校扑空。
- ce13：把某一姿态下的侧倾中心当固定值——倾斜平行杆恰恰是"侧倾时中心在中心线上移动"的原文例证（p210）。
- ce16：用"轮距变化带来的横向刮擦有助于减小车身跳动"为负摆动臂/大轮距变化辩护——作者明确否定（以轮胎磨损为代价）。

### 作者的盲点 / 时代局限

- 退化处理只覆盖侧倾中心；纵向分析（抗后蹲）里"虚拟铰接点在无穷远"的作图细则原文没有。
- "等长平行"在实车上几乎不可能严格成立（衬套柔度、制造公差），本章给的是理想刚体结论。
- 叶片弹簧的侧倾中心结论未附推导，只有文字与图。

### 容易混淆的邻近方法论

- **正/负摆动臂**：命名只看交点相对地面的位置；水平平行杆是"恰好在地平面"的临界情形，既不正也不负。
- **"平行"vs"等长"**：平行决定方向，等长决定"位置是否随侧倾移动"——两个条件要分开核。
- **无穷远虚拟点 vs 无穷远侧倾轴线**：前者是点退化，后者是线退化（叶片弹簧两点都在无穷远）。
