# 独立悬架侧倾中心：单侧虚拟点→接地点连线→与中心线求交，外加正/负摆动臂命名

## R — 原文 (Reading)

> **原书要点**（p208）：先把上、下摆臂各自的虚拟作用点找出来。然后由轮胎接地印迹向该点连一条直线，这条线与车身中心线的交点就是侧倾中心。若求得的点高于地面，此类几何便称作“正摆动臂”。
>
> — 7.6.2（p208）；负摆动臂见 p209，麦弗逊与摆动轴的取法见 p210

## I — 方法论骨架 (Interpretation)

一句话：**只算一侧：取该侧杆系的虚拟作用点 A，连"接地点→A"，这条线与车辆中心线的交点就是侧倾中心。**

- 与整体式车轴的关键差别：整体式用"两点（A、B）连线成轴"，独立式用"一点 + 接地点"连线。所以**同一个三步法骨架，第 1 步的取法完全不同**，混用会算出完全不同的高度。
- 正/负摆动臂是**命名**，不是评价：交点在**地面之上**叫正摆动臂，在**地面之下**叫负摆动臂；名字与摆臂"朝上朝下"无关，也不是"好/坏"。
- 谱系思想：正/负摆动臂 → 水平平行杆（恰好在地平面）→ 倾斜平行杆（抬到地面以上），是同一构造公式的连续结果，不是三种不同悬架。
- 特殊取法（都在这张卡里）：
  - **麦弗逊**：虚拟作用点＝"下控制臂轴线 × 撑杆垂直（轴）线"的交点；撑杆就是被砍掉的上 A 臂，所以不能按双 A 臂找交点。
  - **摆动轴**：虚拟作用点＝**真实的万向节铰点**（全章唯一例外），侧倾中心在中心线上、**高于车轮中心**。
- 动态修正：侧倾时外侧轮（压缩）虚拟点**下移**、内侧（回弹）上移 → 两侧中心不再重合，承重外侧的有效侧倾中心**低于静态值**。所以任何输出都要标"零侧倾姿态"。

## A1 — 应用示例 (Application Example)

### 示例 1：双 A 臂的高度求解（合成演练，非书中事实）

- **类型与来源**：**合成演练**。原书给了三步法与正/负命名，但**没有数值算例**；输入由本卡设定，用于检验流程。
- **输入**：左侧轮胎接地点在 $x=+30$ in（轮心正下、地面）；左侧杆系虚拟作用点 A 在 $x=-40$ in、高 $10$ in。
- **方法论的使用**：①连线 $(30,0)\to(-40,10)$；②与车辆中心线 $x=0$ 求交，参数 $t=30/70=0.4286$；③高度 $=0.4286\times10$。
- **结论/结果（复算值）**：$h_{rc}=\mathbf{4.29}$ in $>0$ → **正摆动臂**。若把 A 压到地面以下（负摆动臂），交点随之为负——同一个公式，符号由 A 的垂向位置决定。

### 示例 2：三种结构的取法（原书代入，非数值题）

- **类型与来源**：**原书方法代入**（p208、p210）。原书未给这三组数值（结果栏：未说明）。
- **内容**：①双 A 臂 → 上下臂轴线交点为 A；②麦弗逊 → 下控制臂轴线与撑杆垂直线的交点为 A；③摆动轴 → A 就是真实铰点（万向节），连线穿过该点，侧倾中心在中心线上、高于车轮中心。
- **结论**：三种结构共用"接地点→A→与中心线求交"，差别全在 A 怎么定；这也是本章唯一"虚拟点不虚拟"的例外。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 有双 A 臂/麦弗逊/多连杆/摆动轴的单侧杆系图，要算侧倾中心高度。
2. 想知道"这台车是正摆动臂还是负摆动臂"以及这个称谓意味着什么。
3. 改装降车身/加长球头后侧倾中心怎么变（几何敏感度）。
4. 麦弗逊悬架被按双 A 臂画错，需要纠正取点方法。
5. 需要把侧倾中心接到载荷转移与转向特性（第 6 章 K）上。

### 语言信号（中英双写）

- 「麦弗逊的侧倾中心怎么画」「负摆动臂是什么意思」「独立悬架的侧倾中心在哪」「降车身后侧倾中心变多少」
- 「MacPherson roll center」「positive / negative swing arm geometry」「roll center height independent suspension」
- 「摆动轴的侧倾中心为什么高于轮心」

### 与相邻能力的区分（初稿，阶段 3 定稿）

- 与 `roll-center-solid-axle`：整体式用两点连线，独立式用一点+接地点；两者不能互换取法。
- 与 `parallel-arm-infinite-point`：水平/倾斜平行杆、叶片弹簧的退化情形由那张卡处理。
- 与 `jacking-risk`：摆动轴既是本卡的几何样本，也是举升风险的原型；风险判定在那张卡，本卡只给高度。

## E — 可执行步骤 (Execution)

**必需输入**：单侧杆系布置图（正视图为主，必要时用平面图辅助）、轮距与接地点位置、车轮垂直中心线（即过轮心的竖直线）、结构类型（SLA/麦弗逊/多连杆/摆动轴/平行杆）、连杆是否等长。**缺单侧杆系图时停止**。

**交付物与完成标准**：A 点的定义与坐标 + 连线描述 + 侧倾中心高度（可负）+ 正/负摆动臂称谓 + 姿态声明 + 轮距变化提示。

1. **判结构并取 A**
   - 完成标准：按结构写 A 的定法：SLA→上下臂轴线交点；麦弗逊→下臂轴线×撑杆垂线；摆动轴→真实铰点；多连杆→按 `virtual-point-method` 逐杆筛后取交点。
   - 判停条件：若某侧杆系平行（等长平行/水平平行）→ 转 `parallel-arm-infinite-point`。
2. **连"接地点→A"**
   - 完成标准：明确接地点取"轮胎与地面的接触中心点"；连线可向两侧延长。
3. **求交与命名**
   - 完成标准：与车辆中心线求交，给出高度（in 或 mm）；$>0$ 记"正摆动臂"、$<0$ 记"负摆动臂"、$\approx0$ 记"水平平行杆/侧倾中心在地平面"。
4. **姿态与动态修正（必做）**
   - 完成标准：写"该值在零侧倾姿态下确定"；写"侧倾时外侧轮虚拟点下移→有效侧倾中心低于静态值"；不得把静态值当恒定量。
5. **代价提示**
   - 完成标准：写"该几何在跳动/回弹中轮距会变化，会导致接地区横向刮擦与轮胎磨损"；并写"刮擦不是阻尼"（作者明确否定旧说法）。

**计算约定（原书未规定，本卡设定）**：高度用 in 或 mm 并与输入同单位；正负按"地面之上为正"；$|h_{rc}|<0.5$ mm 记"约等于地平面"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **给出侧倾中心的目标高度。** 本章**没有**经验值或判据；"正摆动臂 = 高 = 好"是误读——"正"只是静态属性，一侧倾就衰减。
- **把"侧倾中心高度→转向"讲成单向结论。** p210（倾斜平行杆、**前轴**语境）说低侧倾中心"减少外侧车轮的载荷转移…导致不足转向"，而 p206（四连杆、**后轴**语境）说侧倾中心"相对较高、在后轮上施加了过多的侧倾力矩"——两句方向相反，原文未裁决。引用**必须带"哪根轴、哪种结构"**，且只作原文登记；本章没有任何"侧倾中心高→过多转向"的定量判据。
- **把负摆动臂当错误设计。** 作者只说侧倾中心在地面下 + 轮距变化导致刮擦，**没有说它是错的设计**；低侧倾中心会减少外侧载荷转移（p210 的机制），属可选方案。
- **用轮距变化的刮擦当"免费阻尼"。** 作者明确否定：过去曾认为刮擦有助于减小车身跳动，"但这以导致轮胎磨损为代价"（p209）。
- **按双 A 臂画麦弗逊。** 麦弗逊的 A 必须取"下臂轴线×撑杆垂线"；按上下两臂找交点没有上臂可用，会算错。
- **在非零侧倾姿态下给单一数值。** 对称三步法只在静态/无侧倾成立；侧倾后左右各自求，原文未给非对称作图细则。
- **用侧倾中心高低判断举升风险。** 举升的判别式不是中心高低（见 `jacking-risk`）。

### 作者在书中警告的失败模式

- ce13：把静态侧倾中心当固定值去预测侧倾中的载荷转移与转向 → 预测的分配、梯度都与实测对不上，且偏差随侧向加速度增大。
- ce16：为负摆动臂/大轮距变化辩护，把轮胎磨损当"换取舒适性的合理代价"。
- ce02（摆动轴）：摆动半径小 → 单轮跳动直接变成外倾剧变 → 转向性能无法稳定。
- ce07：多连杆过约束，实际运动由衬套决定 → 按刚体求出的侧倾中心只是名义值。

### 作者的盲点 / 时代局限

- 无"侧倾中心该取多高"的判据（全章空白，不得补造）。
- 非对称（侧倾中）作图细则缺、"有效侧倾中心"没有计算法。
- 麦弗逊只给取点法与代价（撑杆偏置→翻转力矩→摩擦，靠斜置弹簧抵消），未给偏置量容差。
- 轮距变化的代价只能定性，无允许量指标。

### 容易混淆的邻近方法论

- **正/负摆动臂 vs 摆动轴（swing axle）**：前者是独立悬架的几何分类（中心在地面上/下），后者是结构类；名词撞车、范畴不同。
- **虚拟作用点 vs 真实铰点**：摆动轴是唯一例外。
- **悬架侧倾中心 vs 车辆侧倾中心**：前者是单轴的点，后者是前后两点的连线。
