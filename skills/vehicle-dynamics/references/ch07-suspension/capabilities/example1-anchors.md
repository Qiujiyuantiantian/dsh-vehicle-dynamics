# 例题 1 的三个数值锚点：0.189 / 0.301 / 1.43 deg/g 的回归自检

## R — 原文 (Reading)

> **原书要点**（p203 §7.5 例题 1）：本题对象是下面那辆采用整体式车桥的后驱车。要求解两套硬点几何：一套让后悬架做到满额（100%）抗后蹲，一套让它完全抗前仰；再把后悬架按前一套参数装好，算出此时前仰角的变化率。
>
> **原书要点**（7.5 例题 1，p203）：$e/d=20.5/108.5+20.5/108.5\times169/285=0.189+0.112=0.301$
>
> — 7.5 例题 1（p203）

## I — 方法论骨架 (Interpretation)

一句话：**这道题的价值不在"做题"，而在它给出三个可以立刻对照的数——它们是本章唯一可复算的回归基准。**

- 输入只有五个参数：$h=20.5$ in、$L=108.5$ in、$W=4074$ lb、$K_f=285$ lb/in、$K_r=169$ lb/in（**弹簧刚度为左右两侧之和**，题面明说，正文未强调）。
- 三个输出：
  - 100% 抗后蹲 $e/d=h/L=\mathbf{0.189}$；
  - 完全抗前仰 $e/d=h/L+(h/L)(K_r/K_f)=\mathbf{0.301}$（分项 0.189 + 0.112，其中 0.112＝0.18894×0.59298）；
  - 抗后蹲几何下的俯仰角变化率 $\theta_p/a_x=\mathbf{1.43}$ deg/g。
- 第三个值的计算路径解释了为什么它这么小：$e/d=h/L$ 时，式(7-14) 的后轴弹簧项与几何项**严格相消**，只剩前轴弹簧项——1.43 deg/g 是"后轴完全不动、只有前轴在回弹"的结果。
- 这三个值同时是**口径探针**：若 $K_f$、$K_r$ 记反，0.301 变 0.508、1.43 变 2.41 deg/g；若 $K$ 用了单侧值，结果差 2 倍；若 $g$ 用了 32.2 而非 386，1.43 差 12 倍。

## A1 — 应用示例 (Application Example)

### 示例 1：原书例题 1 的完整复算（原书例题）

- **类型与来源**：**原书例题**（7.5 例题 1，p203）。作者给了题面、代入行与三个结果。
- **执行**：①$h/L=20.5/108.5=0.18894$；②$K_r/K_f=169/285=0.59298$；③$0.18894\times(1+0.59298)=0.30098\approx0.301$；④$\frac{1}{L}\frac{W}{g}=\frac{1}{108.5}\times\frac{4074}{386}=0.097276$，括号 $=\frac{0.18894}{169}-\frac{0.189}{169}+\frac{0.18894}{285}=6.6295\times10^{-4}$，乘积 $6.449\times10^{-5}$ rad/(in/s²) → $\times386=0.02489$ rad/g → $\times57.2958$。
- **结论/结果（复算值）**：$e/d=\mathbf{0.189}$（抗后蹲）、$\mathbf{0.301}$（抗前仰）、$\theta_p/a_x=\mathbf{1.426\approx1.43}$ deg/g —— **三条全部命中书印值**。
- **注意**：原书代入行的分式排布被 OCR 打乱；复现必须按式(7-14) 的规范项序（后轴弹簧项 − 后轴几何项 + 前轴弹簧项）。

### 示例 2：把刚度记反会怎样（合成演练，非书中事实）

- **类型与来源**：**合成演练**。原书未做这个对照；数值由本卡按同一组式算出，用于证明这三个值能当"口径探针"。
- **输入**：同一辆车，但把 $K_f$、$K_r$ 记反（$K_f=169$、$K_r=285$）。
- **执行**：抗前仰 $=0.18894\times(1+285/169)=0.5076$；俯仰率 $=\frac{1}{108.5}\frac{4074}{386}\times\frac{0.18894}{169}\times386\times57.2958=2.405$。
- **结论/预期输出**：$\mathbf{0.508}$ 与 $\mathbf{2.41}$ deg/g——与真值 0.301 / 1.43 明显不符。**只要拿这三个锚点对一次，刚度归属错就藏不住**；这也是本卡存在的理由。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个方法？

1. 自己算出的 $e/d$ 或 $\theta_p/a_x$ 与书上/别人的结果对不上，需要定位差错在哪一层。
2. 写脚本/表格实现本章公式，需要一组回归测试值。
3. 怀疑 $K_f$、$K_r$ 记反，或把"左右之和"当成了单侧值。
4. 教别人本章方法时，需要一个"小而全"的算例。
5. 校验 OCR/二手资料的数值是否可靠（书印 0.189/0.301/1.43 与复算一致）。

## E — 可执行步骤 (Execution)

**必需输入**：待校验的结果（$e/d$ 或 deg/g）+ 你使用的四个参数（$h$、$L$、$K_f$、$K_r$）。**若你的车参数与例题不同，不能用本卡判对错**——只能判"方法是否实现正确"。

**交付物与完成标准**：三个锚点值（0.189 / 0.301 / 1.43）与自算值并排 + 差异归因（口径/单位/项序/刚度方向）+ 结论"方法实现正确/有错"。

1. **先复现锚点**
   - 完成标准：用例题 1 的四个参数内部复算，得到 0.189 / 0.301 / 1.426；三者与书印值一致（±0.5%）。不一致 → 先修自己的实现，**不要**去修书。
2. **再比对你的车**
   - 完成标准：把你的参数代入同一实现，输出 $e/d$ 与 deg/g；与锚点比较时必须声明"参数不同，只能比实现不能比数值"。
3. **差异归因（按概率排序）**
   - 完成标准：依次查——①$K$ 是否左右之和（差 2 倍）；②$K_f/K_r$ 方向（0.301↔0.508、1.43↔2.41）；③$g$ 是否 386（差 ~12 倍）；④rad→deg 是否 ×57.2958（差 ~57 倍）；⑤项序是否按式(7-14)（几何项负号）。
4. **交付**
   - 完成标准：给出"锚点命中表"（三项各自 ✓/✗）+ 一句差异归因 + 修正后的结果。

**计算约定（原书未规定，本卡设定）**：锚点比对容差取 ±0.5%（覆盖取位差）；$e/d$ 报 3 位小数、deg/g 报 2 位。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此方法

- **把三个锚点当"典型值"去套别的车。** 它们属于一辆具体的车（$W=4074$、$K_f=285$、$K_r=169$、$h/L=0.189$）；别的车参数不同，数值必然不同。
- **用 1.43 反推"抗后蹲几何一定把俯仰降到 1.4 左右"。** 1.43 之所以小，是因为本题 $e/d=h/L$ 使后轴两项严格相消；换一组 $e/d$ 就不是这个数（同一辆车 $e/d=0$ 时约 3.83 deg/g）。
- **拿它校核抗点头或制动工况。** 例题 1 只讲加速；制动分支依赖式(7-28)（符号待核），本章给不出可用数值。
- **用书印的中间量反推公式。** 代入行 OCR 排布错乱（分式顺序被打乱），只能按规范项序复现，不能照抄那行。
- **用 0.301 与 0.378（$2h/L$）互相"验证"。** 两者不是同一口径：0.378 是近似式的值，偏大 25.5%，本章已知硬伤。

### 作者在书中警告的失败模式

- 近似式 $2h/L$（式 7-16）与本题冲突：本题真值 0.301，近似给 0.378 → 偏大 25.5%；书中既未声明适用范围，也未修正配套的几何判据。
- ce10：把例题的"完全抗前仰 0.301"当目标去追 → 需要 5 倍 $e$ 的臂长、与制动操控冲突。
- 弹簧刚度"左右两侧之和"这条只在题面括注，正文未强调——是排版层的坑。

### 作者的盲点 / 时代局限

- 题面未给轴距分配、簧上/簧下质量、车轴拖动效应；只按四个参数算。
- 全章英制、无 SI 换算表。
- $e/d=h/L$ 使后轴两项相消是本题的特殊性，作者的解答没有点明这一点，读者容易误以为"1.43 是抗后蹲的固有值"。

### 容易混淆的邻近方法论

- **0.301（完全抗前仰）vs 0.508（$K$ 记反的错值）**：两者差一个刚度比方向，是本章最容易被"看起来合理"掩盖的错。
- **1.43（本题）vs 2.41（同一辆车 $K$ 记反）vs 3.83（同一辆车无几何补偿）**：三个数说明"结果对参数有多敏感"，不是三个典型值。
- **例题 1 vs 例题 2**：不同车（$W$、$K$ 都不同），4.2 / 2.61 不能与 1.43 混。
